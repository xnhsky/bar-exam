47の11、続きから行くよ。

じゃあ規範を小問イにあてはめてこう。

まず移審の範囲。共同訴訟人独立の原則、39条ね。これにより、Y2 の控訴は X・Y1 間の訴訟に影響を及ぼさない。だから移審しない。

次に X・Y1 間の帰結。X が控訴期間内に控訴しない。控訴期間は、判決書の送達を受けた日から2週間の不変期間。285条ね。不変期間っていうのは、裁判所が伸ばしたり縮めたりできない期間。徒過したら回復の余地がない。だから X の Y1 に対する請求は、棄却のまま確定する。

X・Y2 間は、Y2 の控訴によって移審して、控訴審の審理の対象になる。

ここで適用型のクイズいくよ。じゃあ X は、この両負けを防ぐには何をすべきだった? 答えは、Y1 に対しても控訴を提起しておくこと。これしかない。両方が控訴審に係属すれば、41条3項で併合が強制されて、同じ裁判体が同じ弁論で判断するから、両負けは防げたんだ。

じゃあもう一問。附帯控訴っていう手があるよね。293条。X は Y2 の控訴について被控訴人になるんだから、附帯控訴で Y1 を引き込めない? ……できないんだよ。附帯控訴は、被控訴人が控訴人に対してするもの。X にとっての控訴人は Y2 だけ。Y1 はその控訴審の当事者じゃない。だから附帯控訴では Y1 を引っ張ってこられない。

もう一問いくよ。じゃあ X は Y2 に対して控訴すべきだった? ……違うよ。X は Y2 に勝訴してるんだから、控訴の利益がない。ここを取り違える答案が毎年あるんだけど、X が起こせた控訴は Y1 に対するものだけ。これは5点飛ぶミスね。

事実から評価、結論の三点セットでいくよ。

一つ目。Y2 のみが控訴した。これは共同訴訟人各自の独立した訴訟行為と評価できる。よって移審は X・Y2 間の請求に限られる。

二つ目。X は Y1 に対して控訴しなかった。これは控訴の利益がありながら行使しなかった、すなわち自己責任と評価できる。よって X・Y1 間は棄却のまま確定する。

三つ目。第一審が Y1 請求棄却・Y2 請求認容としたこと。これは無過失を肯定する判断の表れと評価できる。よって控訴審でこれが覆れば、両請求とも理由がないことになる。

四つ目。控訴審に係属するのが一方のみであること。これは41条3項の適用の前提の欠如と評価できる。よって併合強制が働かず、両負けを防げない。

五つ目。X が第一審で Y2 に勝訴していること。これは Y2 に対する控訴の利益の不存在と評価できる。よって X が起こせた控訴は Y1 に対するものに限られる。

評価に行くよ。通説は自己責任説ね。X は第一審で Y1 に敗訴してるんだから、Y1 に対して控訴する利益と機会があった。両方を控訴審に上げれば41条3項で併合が強制されて両負けは防げた。それをしなかったんだから、不利益は X が負うべき。これで切る。

で、もう一つ立法不備説っていうのがある。41条は原告のための制度なのに、原告が常に控訴しなければ安心できないっていうのでは保護として不十分だ。だから主観的予備的併合を認める必要性はなお残る、っていう見解ね。41条ができた平成8年当時は「これで主観的予備的併合と同じことができるんだから、あの概念はもういらないんじゃないの」って見方が有力だったんだけど、上訴段階の限界が残ったから、今でもこういう指摘が続いてる。

ただここ、大事なことを言うよ。この二つの説、現行法の解釈としては同じ結論なんだ。どっちも「両負けはやむを得ない」に立つ。違うのは立法論としての評価だけ。だから答案では、まず自己責任説で書き切って、そのあとに一文だけ「立法不備があり主観的予備的併合を認める必要があるとする見解もある」って添える。両論併記で紙幅を使う場面じゃないからね。

反対方向の反論も知っとくと厚みが出る。立法不備説に対しては、被告の地位の安定と原告の両負け防止の徹底は二律背反だ、って反論できる。移審効を広げれば勝訴被告の地位が他人の行動に左右されて、まさに最判昭和43年が主観的予備的併合を否定した理由が復活しちゃう。41条の限界は設計の失敗じゃなくて価値選択の帰結。この一言が言えると、評価がもう一段上がるよ。

結論を書き分けるね。X の Y1 に対する請求は棄却のまま確定する。X の Y2 に対する請求は控訴審における審理の対象となる。この二文。

差がつくポイント。上位と中位が分かれるのは、41条3項の「適用の前提」を引用して、本件でそれが欠けることを指摘できたかどうか。ここを書けた答案は少数だよ。逆にここで3項を根拠に「併合が強制されるから両負けにならない」って書いちゃうと、小問イは全滅。10点から15点飛ぶ。

ほかのミスも潰しとこう。40条1項を援用して「一人の控訴で全員につき移審する」って書く。41条は必要的共同訴訟じゃない。結論を一方しか書かない。設問は「それぞれ」って聞いてる。それと、不利益変更禁止の304条と混同する人。あれは控訴審の審判範囲の問題で、移審の範囲の問題じゃないからね。

じゃあこの論点まとめるね。ここ大事だよ。規範のコアは「41条は移審の特則を置いてないから通常共同訴訟の規律による。Y2 の控訴は X・Y1 間に影響せず移審しない。41条3項は両請求が控訴審に係属していることを前提とする」。あてはめのキーは、両負けを「控訴審で Y2 に対する請求が棄却されれば」っていう仮定の形で具体的に書くこと。

想起クイズ。一つ、41条3項が働くための前提は? 両方の控訴事件が控訴審に係属していることだね。二つ、X がとれた手段は? 控訴期間内の Y1 に対する独立の控訴だけ。三つ、附帯控訴はなぜダメ? 附帯控訴は控訴人に対してするもので、Y1 は控訴審の当事者じゃないから。言えなかったら47の10に戻って。

じゃあ続きは47の12でね。
