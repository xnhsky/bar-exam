  - 取引行為・平穏公然・善意無過失＝即時取得成立／盗品・半年後＝193条で回復可／「同種の物を販売する商人」B・善意購入C＝194条で代価30万円と引換えでのみ返還（引換給付）。ここまでは要件あてはめで淡々と。
- 【効く事実】「194条占有者の使用収益権（設問1後半の核心）」のあてはめで使う事実
  - 194条適用 → 同種の物を販売する商人B・善意購入C／転換の理由 → 被害者は代価弁償か回復断念かを選べる・弁償代価に利息を含まない／帰結 → Cの使用収益は「法律上の原因」あり＝不当利得不成立。事実は必ず194条の趣旨と結びつける。
- 【規範の要点】「任意返還後の独立の代価弁償請求権（設問2）」の規範
  - 194条を抗弁権にとどめると、任意に返した占有者は代価を受けられず、返還を拒み続けた者だけが弁償を受けるという不均衡が生じる。占有者は「回復断念か代価弁償か」を選択し得る地位で引渡しを受けたのだから、194条は抗弁権にとどまらず独立の代価弁償請求権を含む（最判平12.6.27）。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 「使用収益権も独立請求権も、根拠は194条の趣旨（保護の均衡）」と橋を架ける。バラバラに規範を並べない。
- 【まぎらわしい選択肢・論点】背信的悪意者からの取得の可否／94条2項の類推適用
- 【まぎらわしい選択肢・結論】Aの使用利益請求 認められる／Cは代価弁償を請求できない
- 【まぎらわしい選択肢・規範】即時取得者帰属説
- 【まぎらわしい選択肢・事実】占有改定による取得

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

設問1前半＝206→即時取得192→盗品193（2年内）→194（商人・善意）で代価と引換え。設問1後半＝所有権は原所有者・でも194条の趣旨＋利息不算入で占有者に使用収益権→Aの使用利益請求×。設問2＝抗弁権だけなら任意返還者が不均衡・選択し得る地位で引渡し→独立請求権→Cは30万円請求○。軸＝ぜんぶ194条の趣旨（保護の均衡）。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 194条により引渡しを拒みうる占有者が、代価弁償の提供があるまで盗品等の使用収益権を有するとする2つの理由づけを述べよ。
  - 模範解答：①194条の趣旨＝占有者と被害者との保護の均衡（被害者は回復断念か代価弁償かを選べ、断念すれば占有者が使用利益を得られるのに、弁償を選ばれた途端に占有者が使用利益を失うのでは地位が不安定）。②弁償される代価には利息が含まれないから、その均衡上も占有者の使用収益を認めるのが公平（最判平12.6.27）。
- **［規範クイズ 2/3］** 占有者が盗品を任意に返還した後も、なお194条に基づき独立の請求権として代価弁償を請求できるとする理由を述べよ。
  - 模範解答：194条を単なる抗弁権と解すると、任意に返還した占有者が代価弁償を受けられず、かえって返還を拒み続けた者だけが弁償を受けられるという不均衡が生じ、保護の均衡という趣旨に反する。占有者は「回復を諦めるか代価弁償を受けて回復するか」を選択し得る地位で引渡しを受けたものだから、任意返還後もなお代価弁償を請求できる（最判平12.6.27）。
- **［規範クイズ 3/3］** 無権利者から盗品を善意取得した者に対する返還請求で、所有権に基づく返還請求から代価弁償の抗弁までの「反論の連鎖」を、適用条文の順に挙げよ。
  - 模範解答：①所有権に基づく返還請求（206条）→ ②即時取得の反論（192条・無過失は188条推定）→ ③盗品回復の再反論（193条・2年内）→ ④代価弁償の再々反論（194条・商人から善意購入）。結論は「代価と引換えでのみ返還」（引換給付）。

## 4. ○×クイズ（全10問・1問目から最後まで全部出す）

- **［○×クイズ 1/10］** 所有権に基づく返還請求権（物権的請求権）は、明文の規定はないが、所有権が物を全面的に支配する権利であることの当然の効力として認められる。
  - 正解：○（正しい）
  - 理由：物権的請求権は明文にないが、物権が物に対する排他的支配権であることから当然に承認される（206条は所有権の内容規定）。返還請求は「誰が誰に何を」を確定する出発点で、まず所有権に基づく返還請求を立てるのが筋。
- **［○×クイズ 2/10］** 即時取得（192条）が成立するには、前主が無権利者であることについて取得者が善意・無過失であることを要し、この無過失は188条により推定される。
  - 正解：○（正しい）
  - 理由：即時取得は①動産②取引行為による占有取得③平穏・公然④善意・無過失を要する。占有者は188条により適法に権利を有すると推定されるので、取得者の無過失も推定され、原則として立証を要しない（最判昭41.6.9）。本問のCは無過失が推定され即時取得が成立する。
- **［○×クイズ 3/10］** 動産が盗品である場合には、取引の安全よりも被害者保護が優先されるから、即時取得（192条）はおよそ成立せず、被害者は期間の制限なくいつでも回復を請求できる。
  - 正解：×（誤り）
  - 理由：盗品でも即時取得自体は成立する。ただ193条が特則として、被害者に盗難の時から2年間に限り回復請求を認めるにとどまる。「期間無制限で回復できる」は誤り。2年を過ぎれば即時取得者の権利が確定する。
- **［○×クイズ 4/10］** 盗品については、被害者は盗難の時から2年間、占有者に対してその物の回復を請求することができる（193条）。本問は盗難から半年後であり、この期間内にある。
  - 正解：○（正しい）
  - 理由：193条は即時取得の例外として、盗品・遺失物につき盗難・遺失の時から2年間の回復請求を認める。本問は半年後なので期間内で、Aの回復請求は認められうる。ただし194条の代価弁償の抗弁が次に控える。
- **［○×クイズ 5/10］** 被害者が代価を弁償しなければ盗品を回復できない（194条）のは、占有者がその物を競売・公の市場において、又は同種の物を販売する商人から善意で買い受けた場合に限られる。
  - 正解：○（正しい）
  - 理由：194条は購入経路を「競売・公の市場・同種の物を販売する商人」に限定する。信頼性ある場面での善意購入者に限って代価回収を保障する趣旨。本問のBは中古パソコン販売業者＝「同種の物を販売する商人」で、Cは善意購入だから194条が適用される。
- **［○×クイズ 6/10］** 194条により被害者が代価弁償を要するためには、占有者が善意であるだけでなく、無過失であることまで条文上明示的に要求されている。
  - 正解：×（誤り）
  - 理由：194条の文言は「善意で買い受けたとき」であり、条文上は無過失を明示していない（無過失は192条による即時取得の成立要件として別に問題となる）。「194条が無過失を明示的に要求する」は誤り。要件は条文の文言に忠実に拾うのがあてはめの基本。
- **［○×クイズ 7/10］** 194条により盗品の引渡しを拒みうる占有者は、代価弁償の提供があるまで、その盗品について使用収益を行う権限を有する（最判平12.6.27）。
  - 正解：○（正しい）
  - 理由：判例は、194条の趣旨（保護の均衡）と代価に利息を含まないこととの均衡から、引渡しを拒みうる占有者に代価弁償の提供まで使用収益権を認める。したがって占有者の使用収益は「法律上の原因」を欠かず、被害者の使用利益返還請求（不当利得）は認められない。
- **［○×クイズ 8/10］** 盗品の回復請求が認められる2年間はその所有権が原所有者にとどまる以上、その間の使用利益も当然に原所有者に帰属し、占有者は原所有者に対して使用利益を返還する義務を負う。
  - 正解：×（誤り）
  - 理由：所有権の所在（原所有者）と使用収益権の帰属は必ずしも一致しない。判例は、所有権が原所有者に残ることを前提としても、194条が特別の権能として占有者に使用収益権を付与したと解する。194条の趣旨で転換する一手が核心。
- **［○×クイズ 9/10］** 194条の代価弁償は被害者の回復請求に対する抗弁権にとどまるから、占有者が目的物を任意に返還した後は、もはや被害者に対して代価の弁償を請求することはできない。
  - 正解：×（誤り）
  - 理由：判例は194条を抗弁権にとどめず独立の代価弁償請求権をも認める。抗弁権説では任意返還者が保護されず不均衡だからである。したがって任意返還したCも、なおAに代価30万円の弁償を請求できる。「抗弁権のみ・任意返還後は請求不可」は誤り。
- **［○×クイズ 10/10］** 194条の占有者の使用収益権と、任意返還後の独立の代価弁償請求権は、いずれも「占有者と被害者との保護の均衡」という194条の趣旨を共通の根拠とする。
  - 正解：○（正しい）
  - 理由：最判平12.6.27は、使用収益権（前段）も独立の代価弁償請求権（後段）も、194条の趣旨たる保護の均衡から導く。趣旨を共通の軸に据えると、設問1と設問2が一本の論理でつながり上位答案になる。
