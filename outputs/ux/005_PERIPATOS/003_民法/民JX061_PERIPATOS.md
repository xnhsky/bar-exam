## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

Aは、内縁の妻であるBを助手席に乗せて、ドライブをしていた。Aが自動車で走行中にハンドル操作を誤って反対車線に乗り入れてしまった。反対車線では、D社の従業員であり、取引先に向かっていたCが運転していた自動車が走行していたが、Cは、D社の業務のため、連日深夜まで残業を強いられていたため、寝不足であり、居眠り運転をしてしまった。そのため、Cは、A運転の自動車を避けることができず、両自動車は、衝突し、Bは、即死した（以下「本件事故」という。）。Bの母親であり、Bに扶養されている唯一の相続人であるEは、本件事故によって発生した損害について、D社に対して、賠償請求をしようとしている。Eの請求が認められるか、また、D社がEの請求に応じた場合、Cに対していかなる請求をすることができるかを論じなさい。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- A（内縁の夫）がB（内縁の妻）を同乗させ運転
- Aがハンドル操作を誤り反対車線へ進入
- C（D社業務中）が過重労働で寝不足・居眠り運転
- 両車衝突 → B即死
- 母E（扶養・唯一の相続人）がD社へ賠償請求／D社はCへ求償を検討

### 入口の問い（3問）

- **［入口 1/3・事案の整理］** 登場人物と「誰が誰に何を請求するか」を挙げて
  - 答え：請求の当事者はE（原告）とD社（前段の被告・後段の求償権者）。Bは即死した被相続人、CはD社の被用者、AはBの内縁の夫（運転者）。
  - 答え：Bの損害は相続で、Aの過失は被害者側の過失で、Cの居眠りは求償の制限で効いてくる。ここで役割を仕分けるのが第一歩。
- **［入口 2/3・見当づけ］** 各請求は「何条っぽい？」 ― 見当をつけて
  - 答え：D社＝Cの「使用者」→ 使用者責任（715条1項）。Bの死で発生した損害の相続 → 709条・710条＋896条。Eは母で扶養されていた → 固有損害（709・711条）。後段のD社→Cは 求償（715条3項）。
- **［入口 3/3・論点］** 問題になる論点を挙げて（3つ）
  - 答え：CP①：Bは即死 → その瞬間に権利能力を失う → 財産的損害賠償請求権が発生・相続されるか（相続構成）。（相続構成＝被害者に発生した賠償請求権を相続人が承継する考え方）

### 骨子（2項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　前段　EのD社に対する請求

1. D社の責任＝使用者責任（715条1項）（C＝被用者・業務執行中・免責事由なし＝争いなし）
2. Bは即死 → 【論点】財産的損害賠償請求権の相続（規範：致命傷時に発生）→ Eが相続
3. 【論点】慰謝料請求権の当然相続 → 規範：単純な金銭債権・意思表示不要（896ただし書の例外にならない）→ Eが相続
4. E固有の損害 → 扶養利益（709）＋固有慰謝料（711）＝相続分と併存
5. 【論点】被害者側の過失（内縁の夫Aの過失）→ 規範：身分上・生活関係上一体をなす者の過失 → 内縁も一体
- 結論：Eは相続分＋固有分を、Aの過失を考慮した限度で請求可

#### 第2　後段　D社のCに対する請求

1. D社がEに賠償 → 求償（715条3項）／代位責任＝原則全額の可能性
2. 【論点】求償権の制限 → 規範：報償責任・損害の公平な分担 → 信義則上相当な限度
   - あてはめ：Cの居眠りはD社の連日深夜残業（過重労働）に起因＝制限を基礎づける
- 結論：D社の求償は信義則上相当な限度に制限される

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「即死した」 → Bへの賠償請求権の発生・相続の起点
- 【拾う事実】「Bに扶養されている」「唯一の相続人」「Bの母親」 → E固有損害（扶養利益・711）と全部承継
- 【拾う事実】『「内縁の妻」＝AとBは内縁』 → 被害者側の過失（一体性）
- 【拾う事実】「D社の従業員」「取引先に向かっていた」 → 使用者責任の使用関係・業務執行性
- 【拾う事実】「連日深夜まで残業」「寝不足」「居眠り運転」 → 求償権の制限を基礎づける事情
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 使用者責任の4要件（使用関係／事業の執行について／被用者の709充足／免責事由なし）は本問では全て充足＝争いなし→さらっと通す。山は「即死でも相続できるか」と「内縁の夫の過失を相殺できるか」。
- 【効く事実】あてはめで使う事実
  - 相続構成 → 「即死」を引用し致命傷時に発生／当然相続 → 意思表示なし・特別の事情なし＝単純な金銭債権／E固有損害 → 「Bに扶養されている」「唯一の相続人」「Bの母親」／被害者側の過失 → 「内縁」の共同生活。
- 【規範の要点】信義則上制限説の規範
  - 使用者責任は報償責任・危険責任に基礎を置く → 使用者も損害を一定程度分担すべき → 求償権は、損害の公平な分担の見地から、事業の性格・労働条件・損失分散への配慮の程度等に照らし、信義則上相当と認められる限度に制限される（最判昭51.7.8）。本問はCの居眠りがD社の過重労働に起因＝制限の典型。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

前段＝D社に使用者責任、即死でも致命傷時に賠償請求権発生・相続、慰謝料も単純な金銭債権で当然相続、Eは扶養利益＋711の固有損害も併存、内縁の夫Aの過失は被害者側の過失で相殺。後段＝D社→Cは715条3項、報償責任で損害の公平な分担、過重労働起因だから信義則上相当な限度に制限。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 被害者が即死した場合に、その財産的損害賠償請求権が発生し相続されるとする規範（理由づけ）を述べよ。
  - 模範解答：受傷後に死亡した場合には賠償請求権を取得するのに、即死の場合には取得しないと解するのは均衡を欠く。そこで、即死の場合でも致命傷を与えられた時点で被害者に損害賠償請求権が発生し、相続人に承継されると解する（時間的間隙・大判大15.2.16）。
- **［規範クイズ 2/3］** 慰謝料請求権が、被害者の請求の意思表示がなくとも当然に相続されるとする理由を述べよ。
  - 模範解答：慰謝料請求権も、損害の発生と同時に発生する単純な金銭債権であって、財産的損害賠償請求権と別異に取り扱う法的根拠はない。したがって、被害者が請求の意思を表明する等の格別の行為をしなくとも、死亡により相続人が当然に相続する（最大判昭42.11.1・当然相続説）。
- **［規範クイズ 3/3］** 「被害者側の過失」の意義（過失相殺で被害者本人以外の過失を考慮しうる範囲）を規範の形で述べよ。
  - 模範解答：過失相殺は損害の公平な分担を図る制度である。そこで、被害者本人の過失に限らず、被害者と身分上ないし生活関係上一体をなすとみられる者の過失も、被害者側の過失として考慮しうる（最判昭51.3.25）。単に被害者を監督する立場にすぎない者（保育園の保母等）は含まれない。

## 4. ○×クイズ（全7問・1問目から最後まで全部出す）

- **［○×クイズ 1/7］** 不法行為に基づいて被害者に生じた損害賠償請求権は、一身専属権ではなく、原則として相続の対象となる財産権である（896条本文）。
  - 正解：○（正しい）
  - 理由：相続人は相続開始の時から被相続人の財産に属した一切の権利義務を承継する（896条本文）。被害者の財産的損害賠償請求権は財産権として相続される。慰謝料請求権が一身専属権（896条ただし書）として例外にならないかは別途論点になる。
- **［○×クイズ 2/7］** 使用者責任（715条1項）が成立するには、その前提として、被用者の行為が不法行為（709条）の一般的要件を満たしていることが必要である。
  - 正解：○（正しい）
  - 理由：使用者責任は被用者の不法行為を前提に使用者へ責任を拡張する制度だから、被用者に709条の要件（故意・過失、権利侵害、損害、因果関係）が備わることが前提になる（通説）。本問ではCの居眠り運転がこれを満たす。
- **［○×クイズ 3/7］** 過失相殺（722条2項）は、損害賠償責任の成立と賠償すべき損害額を確定したうえで、その賠償額を減額する場面で問題となる。
  - 正解：○（正しい）
  - 理由：過失相殺は責任の成否ではなく賠償額の調整の問題。まず損害（相続分・固有分）を確定し、そのうえで被害者側の過失を考慮して減額する。順序を逆にすると論理が崩れる。
- **［○×クイズ 4/7］** 使用者責任（715条1項）の「事業の執行について」の要件は、被用者の行為が外形上・客観的にみて職務の範囲内に属すると認められれば足りる（外形標準説）。
  - 正解：○（正しい）
  - 理由：取引的不法行為でも事実的不法行為でも、事業執行性は外形的・客観的に職務の範囲内といえるかで判断する（外形標準説）。本問のCは「取引先に向かう業務の遂行中」だから、この要件は容易に充たされる。
- **［○×クイズ 5/7］** 被害者本人の慰謝料請求権を相続人が相続する場合には、その相続人は、近親者固有の慰謝料請求権（711条）を重ねて取得することはできない。
  - 正解：×（誤り）
  - 理由：相続する慰謝料請求権（710条）は被害者本人の精神的苦痛を、711条の固有の慰謝料請求権は近親者自身の精神的苦痛を対象とし、被侵害利益を異にする。両者は併存する（最大判昭42.11.1）。本問のEは、Bから相続した慰謝料と、母としての固有の慰謝料をいずれも取得する。
- **［○×クイズ 6/7］** 使用者が被用者に対してする求償権（715条3項）は、損害の公平な分担の見地から、信義則上相当と認められる限度に制限される場合がある。
  - 正解：○（正しい）
  - 理由：使用者責任は報償責任・危険責任に基礎を置くから、使用者もリスクを分担すべきである。判例は、事業の性格・規模、労働条件、加害行為の態様、損失分散・予防への配慮の程度等に照らし、信義則上相当な限度に求償権を制限する（最判昭51.7.8＝茨城石炭商事事件）。
- **［○×クイズ 7/7］** 過失相殺で考慮しうる「被害者と身分上ないし生活関係上一体をなす者」には、婚姻の届出をしていない内縁の配偶者も含まれる。
  - 正解：○（正しい）
  - 理由：内縁の夫婦も、相協力して夫婦としての共同生活を営み、身分上・生活関係上一体をなす関係にあるから、内縁の配偶者の過失は被害者側の過失として考慮しうる（最判平19.4.24）。損害の公平な分担の見地からは、法律婚か事実婚かで区別する理由はない。

（○×クイズはここまで＝全7問。最後の7問目まで出したら「○×クイズ、全7問クリア！」と言って復習へ）
