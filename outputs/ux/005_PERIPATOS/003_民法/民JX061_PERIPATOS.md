## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

Aは、内縁の妻であるBを助手席に乗せて、ドライブをしていた。Aが自動車で走行中にハンドル操作を誤って反対車線に乗り入れてしまった。反対車線では、D社の従業員であり、取引先に向かっていたCが運転していた自動車が走行していたが、Cは、D社の業務のため、連日深夜まで残業を強いられていたため、寝不足であり、居眠り運転をしてしまった。そのため、Cは、A運転の自動車を避けることができず、両自動車は、衝突し、Bは、即死した（以下「本件事故」という。）。Bの母親であり、Bに扶養されている唯一の相続人であるEは、本件事故によって発生した損害について、D社に対して、賠償請求をしようとしている。Eの請求が認められるか、また、D社がEの請求に応じた場合、Cに対していかなる請求をすることができるかを論じなさい。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- A（内縁の夫）がB（内縁の妻）を同乗させ運転
- Aがハンドル操作を誤り反対車線へ進入
- C（D社業務中）が過重労働で寝不足・居眠り運転
- 両車衝突 → B即死
- 母E（扶養・唯一の相続人）がD社へ賠償請求／D社はCへ求償を検討

### 参考（読み上げない。入口の問いの答えを含むので判定にだけ使う）

登場人物：
- E｜Bの母・唯一の相続人＝原告（→D社へ賠償請求）
- D社｜Cの使用者（→使用者責任・Cへ求償）
- C｜D社従業員・居眠り運転（→過重労働で求償制限）
- A｜内縁の夫・運転（→過失＝被害者側の過失）
- B｜内縁の妻・即死＝被相続人

一行要約：内縁の夫AのハンドルミスとCの居眠り（D社業務中）で衝突、B即死。母E（扶養・唯一の相続人）がD社へ請求。

### 入口の問い（3問）

- **［入口 1/3・事案の整理］** 登場人物と「誰が誰に何を請求するか」を挙げて
  - 答え：請求の当事者はE（原告）とD社（前段の被告・後段の求償権者）。Bは即死した被相続人、CはD社の被用者、AはBの内縁の夫（運転者）。
  - 答え：Bの損害は相続で、Aの過失は被害者側の過失で、Cの居眠りは求償の制限で効いてくる。ここで役割を仕分けるのが第一歩。
- **［入口 2/3・見当づけ］** 各請求は「何条っぽい？」 ― 見当をつけて
  - 答え：D社＝Cの「使用者」→ 使用者責任（715条1項）。Bの死で発生した損害の相続 → 709条・710条＋896条。Eは母で扶養されていた → 固有損害（709・711条）。後段のD社→Cは 求償（715条3項）。
- **［入口 3/3・論点］** 問題になる論点を挙げて（3つ）
  - 答え：CP①：Bは即死 → その瞬間に権利能力を失う → 財産的損害賠償請求権が発生・相続されるか（相続構成）。（相続構成＝被害者に発生した賠償請求権を相続人が承継する考え方）
  - 答え：CP②：慰謝料請求権は一身専属的 → 意思表示なくとも当然に相続されるか（当然相続）。（一身専属権＝その人だけに帰属し相続に馴染まない権利＝896条ただし書）
  - 答え：CP③：事故を招いたのは内縁の夫A → Aの過失を被害者側の過失として相殺できるか。

- 順番：第1　前段　EのD社に対する請求 → 第2　後段　D社のCに対する請求

  - 論点2：慰謝料請求権の当然相続

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 被害者が即死した場合に、その財産的損害賠償請求権が発生し相続されるとする規範（理由づけ）を述べよ。
  - 模範解答：受傷後に死亡した場合には賠償請求権を取得するのに、即死の場合には取得しないと解するのは均衡を欠く。そこで、即死の場合でも致命傷を与えられた時点で被害者に損害賠償請求権が発生し、相続人に承継されると解する（時間的間隙・大判大15.2.16）。
- **［規範クイズ 2/3］** 慰謝料請求権が、被害者の請求の意思表示がなくとも当然に相続されるとする理由を述べよ。
  - 模範解答：慰謝料請求権も、損害の発生と同時に発生する単純な金銭債権であって、財産的損害賠償請求権と別異に取り扱う法的根拠はない。したがって、被害者が請求の意思を表明する等の格別の行為をしなくとも、死亡により相続人が当然に相続する（最大判昭42.11.1・当然相続説）。
- **［規範クイズ 3/3］** 「被害者側の過失」の意義（過失相殺で被害者本人以外の過失を考慮しうる範囲）を規範の形で述べよ。
  - 模範解答：過失相殺は損害の公平な分担を図る制度である。そこで、被害者本人の過失に限らず、被害者と身分上ないし生活関係上一体をなすとみられる者の過失も、被害者側の過失として考慮しうる（最判昭51.3.25）。単に被害者を監督する立場にすぎない者（保育園の保母等）は含まれない。

## 4. ○×クイズ（全7問・1問目から最後まで全部出す）

- **［○×クイズ 1/7］** 不法行為に基づいて被害者に生じた損害賠償請求権は、一身専属権ではなく、原則として相続の対象となる財産権である（896条本文）。
