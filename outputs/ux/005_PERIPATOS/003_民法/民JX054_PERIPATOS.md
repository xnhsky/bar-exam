工場用機械メーカーAは、Bから工場用機械の製作を請け負い、これを製作してBに引き渡した。その工場用機械（以下「本件機械」という。）は、Bが使用してみたところ、契約では1時間当たり5000個程度の商品生産能力があるとされていたのに、不具合があって1時間当たり2000個程度の商品生産能力しかないことが判明した。そこで、Bは、直ちに本件機械の不具合をAに告げて修理を求めた。小問1　本件機械を契約どおりの生産能力とする修理は可能である。Aが修理をしようとしないので、Bは代金を支払っておらず、また、営業上の損害が発生している。この場合に、Bの代金債務の連帯保証人Cは、Aからの保証債務の履行請求に対してどのような主張をすることができるか。小問2　Aが修理をしようとしないため、BはやむをえずDに本件機械の修理を依頼し、Dは修理を完了した。その後、Bは営業不振で多額の債務を残して行方不明となり、Dへの修理代金も支払っていない。この場合に、Aは引渡しの際にBから代金全額の支払を受けているものとして、Dは、Aに対してどのような請求をすることができるか。（各問いは独立の問いである。）

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- A・B間で請負契約 → 本件機械を製作・引渡し（代金は引渡時に全額支払＝小問2の前提）
- 使用したら5000個→2000個の不具合（契約不適合）判明・BがAに修理を求める
- Aが修理に応じず。Bは代金未払い・営業損害発生（小問1）
- BがDに修理を依頼→D修理完了（小問2）
- Bが多額の債務を残し行方不明（無資力）・Dへの修理代金も未払い

#### 第1　小問1　連帯保証人Cの主張

- 見出しの補足（結論を含む。項目の終わりに読む）：457条
0. 前提：本件機械は品質の契約不適合（559条・562条）→ Bは修補・損賠・解除を有する
1. 付従性 → CはBの抗弁を援用できる（457条2項）
2. 【論点】損賠と報酬の同時履行の範囲 → 全額対全額（修補に代わる損賠は実質不可分・最判平9.2.14）
3. 【論点】抗弁権付着債権の相殺の可否 → 原則不可も請負は例外（実質的に代金減額・最判昭53.9.21）
4. 【論点】相殺権・解除権の援用の性質 → 行使不可・履行拒絶にとどまる（457条3項）
- 結論：Cは全額の履行を拒める

#### 第2　小問2　DのAに対する債権者代位

- 見出しの補足（結論を含む。項目の終わりに読む）：423条
1. 被保全債権＝Dの修理代金／履行期到来／Bは無資力（行方不明） → 要件充足
2. 損害賠償請求権の代位（423条）
3. 【論点】解除権の一身専属性 → 財産的利益ゆえ否定（大判大8.2.8）→ 解除・原状回復（代金返還）を代位
4. 金銭は自己へ支払請求（423条の3）＋相殺 → 事実上の優先弁済
- 結論：Dは損賠・代金返還を代位できる

#### 第3　小問2　転用物訴権

- 見出しの補足（結論を含む。項目の終わりに読む）：703条
1. 【論点】「法律上の原因」なしの意義 → 契約全体で対価関係なきときに限る（最判平7.9.19）
2. AはBに損害賠償義務＝対価関係あり
- 結論：不当利得は否定

- 【拾う事実】「Bから代金全額の支払を受けている」 → 転用物訴権の対価関係の判断
- 【事案の整理】棚卸しの起点
  - 本問の背骨はBの権利。請負でも559条で売買の契約不適合責任（562条以下）が準用され、Bは修補（追完）・損害賠償・解除を得る。これを先に確定すれば、Cは何を援用でき、Dは何を代位できるかが自動的に決まる。
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 契約不適合＝5000個→2000個で明白／修補可能＝問題文が明記／解除の「軽微」除外＝半分以下の能力＋Aが修補拒否で軽微でない。争いの薄い要件は一文で通し、同時履行の範囲と相殺の可否に筆を残す。
- 【効く事実】効く事実と規範
  - 同時履行＝損賠と報酬が全額対全額（最判平9.2.14）／相殺＝抗弁権付着でも請負は実質的に代金減額だから例外的に可（最判昭53.9.21）／相殺・解除は行使不可・履行拒絶にとどまる（457条3項）。
- 【ポイント】代位の「対象選び」が肝
  - Dのゴールは金銭の回収。だから代位するのは損害賠償請求権と解除→原状回復（代金返還）請求権＝Dのもとに金銭が入る権利。同時履行の抗弁を代位しても実益ゼロ。解除権は財産的利益に関し一身専属でない（大判大8.2.8）から代位できる。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 「法律上の原因」なしとは、契約全体としてみて対価関係なく利益を受けた場合に限られる（最判平7.9.19）。本問はAがBに損害賠償義務を負う＝対価関係あり → 不当利得は否定。
- 【まぎらわしい選択肢・論点】危険負担による報酬拒絶の可否／詐害行為取消権の成否
- 【まぎらわしい選択肢・結論】代金減額請求 認容／転用物訴権 肯定
- 【まぎらわしい選択肢・規範】狭義説／債権者主義
- 【まぎらわしい選択肢・事実】無資力は不要／対価関係なし

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

小問1＝Bは修補・損賠・解除、Cは付従性で援用、同時履行は全額対全額、相殺は請負の例外で可、相殺・解除は履行拒絶（457条3項）。小問2＝Dは修理代金でBの損賠・解除を代位、無資力あり、解除権は財産的で一身専属でない、423の3＋相殺で優先弁済。転用物訴権＝対価関係ありで法律上の原因を欠かず否定。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 保証人が、主債務者の有する相殺権・取消権・解除権について取りうる主張の内容と、その根拠条文を述べよ。
  - 模範解答：保証人はこれらの形成権を自ら行使することはできない。それらの行使によって主債務者がその債務を免れるべき限度において、債権者に対して債務の履行を拒むことができるにとどまる（457条3項＝履行拒絶権構成）。行使の可否は主債務者の意思に委ねられるべきだからである。
- **［規範クイズ 2/3］** 本来型の債権者代位権（423条）の4要件を挙げよ。
  - 模範解答：①被保全債権の存在（強制執行により実現できる債権）②被保全債権の履行期到来（保存行為を除く・423条2項）③債務者の無資力（本来型）④被代位権利が一身専属権・差押禁止債権でないこと（423条1項ただし書）。転用型では③無資力は不要。
- **［規範クイズ 3/3］** 抗弁権が付着した債権を自働債権とする相殺が原則許されないのはなぜか、また請負の損害賠償で例外が認められる実質的根拠を述べよ。
  - 模範解答：原則不可の理由＝相殺を認めると相手方の同時履行の抗弁権を一方的に奪う結果となるから。請負の例外＝損害賠償請求は実質的に代金（報酬）減額の意味を持ち、相手方の抗弁権を任意に奪うことにならないから、相殺を認めても不当でない（最判昭53.9.21）。

## 4. ○×クイズ（全9問・1問目から最後まで全部出す）

- **［○×クイズ 1/9］** 連帯保証人は、催告・検索の抗弁を有しないが、保証債務の付従性は失われないから、主たる債務者が債権者に対して主張できる抗弁を援用して債権者に対抗することができる（457条2項）。
  - 正解：○（正しい）
  - 理由：連帯保証で失われるのは補充性（催告・検索の抗弁）にとどまり、主債務への付従性は維持される。したがって連帯保証人も主債務者の同時履行の抗弁等を援用できる（457条2項）。「連帯だから主債務者の抗弁を使えない」と誤ると出発点で崩れる。
- **［○×クイズ 2/9］** 主たる債務者が債権者に対して解除権を有する場合、保証人は、その解除権を自ら行使して主債務の発生原因である契約を解除し、保証債務を消滅させることができる。
  - 正解：×（誤り）
  - 理由：保証人は主債務者の相殺権・取消権・解除権を自ら行使することはできない。これらの権利を行使するか否かは本来主債務者の意思に委ねられるべきだからである。保証人ができるのは、その行使によって主債務者が債務を免れるべき限度で債務の履行を拒むことにとどまる（457条3項＝履行拒絶権構成）。
- **［○×クイズ 3/9］** 請負契約の目的物が種類・品質に関して契約の内容に適合しない場合、559条により売買の契約不適合責任の規定（562条以下）が準用され、注文者は修補（追完）・損害賠償・解除を求めうる。
  - 正解：○（正しい）
  - 理由：平成29年改正で請負固有の担保責任規定（旧634条以下）は削除され、559条を介した売買の契約不適合責任（562条追完・563条減額・564条損賠/解除）の準用に一元化された。冒頭で「559条により準用し」と一言置くのが定石。
- **［○×クイズ 4/9］** 請負の目的物の契約不適合について、修補に代わる損害賠償債権と報酬債権は同時履行の関係に立ち、注文者は、信義則に反する特段の事情がない限り、損害賠償債権をもって報酬債権全額の支払を拒むことができる。
  - 正解：○（正しい）
  - 理由：修補に代わる損害賠償債権はそれ自体は可分でも実質は目的物の修補であり不可分だから、同時履行の範囲は報酬債権全額に及ぶ（最判平9.2.14）。改正後は533条本文かっこ書が「債務の履行に代わる損害賠償」も反対給付に含めることを明文化した。
- **［○×クイズ 5/9］** 抗弁権の付着した債権を自働債権とする相殺は相手方の抗弁権を一方的に奪うため一切許されないから、請負の注文者は、目的物の契約不適合に基づく損害賠償請求権を自働債権として報酬債権と相殺することはできない。
  - 正解：×（誤り）
  - 理由：原則として抗弁権付着債権を自働債権とする相殺は許されないが、請負の損害賠償請求は実質的に代金減額の意味を有し、相殺を認めても相手方の抗弁権を任意に奪うことにならないから、例外的に相殺が認められる（最判昭53.9.21）。
- **［○×クイズ 6/9］** 契約の解除権は、行使するか否かが債務者の意思に委ねられるべき一身専属権であるから、債権者は、債務者の解除権を代位行使することができない。
  - 正解：×（誤り）
  - 理由：解除権は当事者の財産的利益にのみ関し、純粋な債務者の身分・人格そのものと結合するものではないから、423条1項ただし書の一身専属権にあたらず、債権者代位の対象となる（大判大8.2.8）。「意思を尊重すべき」だけでは代位を否定できない。
- **［○×クイズ 7/9］** 債権者が金銭の支払を目的とする債権を代位行使する場合、相手方に対し、その支払を自己に対してすることを求めることができ（423条の3）、受領した金銭の返還債務と自己の被保全債権とを相殺することで事実上の優先弁済を受けうる。
  - 正解：○（正しい）
  - 理由：423条の3は、金銭・動産の代位行使につき債権者が自己への引渡しを請求できると定める。債権者は受領金銭の返還債務（債務者への）と被保全債権を相殺することで、事実上の優先弁済を得られる。
- **［○×クイズ 8/9］** 契約上の給付が契約の相手方以外の第三者の利益になった場合、給付者は、その第三者に対して常に不当利得返還請求（転用物訴権）をすることができる。
  - 正解：×（誤り）
  - 理由：かつては広く肯定されたが（最判昭45.7.16・ブルドーザー事件）、現在は契約全体としてみて第三者が対価関係なく利益を受けたときに限り「法律上の原因」を欠くとして限定された（最判平7.9.19）。「常に認められる」は誤り。
- **［○×クイズ 9/9］** 不当利得における「法律上の原因」がないというためには、形式的・一般的には正当視される財産的価値の移動が、正義・公平の観点から実質的・相対的に正当視されないことを要する。
  - 正解：○（正しい）
  - 理由：不当利得の制度趣旨は正義・公平にあり、「法律上の原因」の有無は形式的な財産移動が実質的・相対的に正当視されるかで判断される。転用物訴権では、これを「契約全体としてみて対価関係なく利益を受けたか」で具体化する（最判平7.9.19）。

（○×クイズはここまで＝全9問。最後の9問目まで出したら「○×クイズ、全9問クリア！」と言って復習へ）
