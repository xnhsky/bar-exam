## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

AはBとの間で自己所有の甲建物について賃貸借契約を締結し、BはAの承諾を得て同建物をCに転貸した。小問1　AB間で賃貸借契約が合意解除された場合における、AC間の法律関係について論ぜよ。小問2　Aは、B及びCと交渉し、AC間で新たに甲建物に関する賃貸借契約を締結することとした。その後、Cは、甲建物に内縁の妻Dと居住していた。高齢のためCは死亡したが、引き続きDは同建物に居住し続けていた。なお、Cには相続人として子Eがいる。(1)　この場合において、A、D及びEの法律関係について論じなさい。(2)　AE間で賃貸借契約が合意解除された場合において、AがDに対して甲建物の明渡しを請求することができるか。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- AB賃貸借 → Aの承諾でBがCへ転貸（適法転貸）
- 小問1：AB間で合意解除
- 小問2前提：AC間で新賃貸借（B・C従前関係を離脱・Cが賃借人）
- Cが内縁の妻Dと同居 → C死亡（相続人＝子E）・Dは居住継続
- 小問2(1)：A・D・Eの三者関係／小問2(2)：AE合意解除後のA→D明渡し

### 参考（読み上げない。入口の問いの答えを含むので判定にだけ使う）

登場人物：
- A｜賃貸人・甲建物所有者
- B｜賃借人（転貸人）→ 小問2で離脱
- C｜転借人 → 小問2で新賃借人・死亡
- D｜Cの内縁の妻・居住継続（相続権なし）
- E｜Cの子・相続人（賃借権を承継）

一行要約：小問1＝適法転貸後にAB合意解除→A→C明渡し可否と帰趨。小問2(1)＝AC新契約→C死亡（内縁D同居・相続人E）→A→D／E→Dの明渡しと賃料。小問2(2)＝AE合意解除後のA→D明渡し。

### 入口の問い（5問）

- **［入口 1/5・事案の整理］** 当事者と「誰が誰に何を請求するか」を挙げて
  - 答え：小問1：Aは所有権でCに明渡しを求めたい → Cは転借権で拒む。小問2(1)：Aは所有権でDに明渡し／Eは相続した賃借権でDを排除しにいく（代位）。小問2(2)：AがEと合意解除してから A→D 明渡し。
  - 答え：A＝所有者で一貫、B＝小問2で離脱。ここを最初に切ると論点が自然に並ぶ。
- **［入口 2/5・見当づけ］** 各請求は「何条・何の権利か」 ― 見当をつけて
  - 答え：A→C・A→D＝所有権に基づく明渡請求。抗弁は Cが転借権＋613条3項、Dが援用理論。E→D＝賃借権を武器にした債権者代位権の転用（423条）。GUESSの段階で「請求＋抗弁のペア」を作るのがコツ。
- **［入口 3/5・見当づけ］** 各請求は「何条・何の権利か」 ― 見当をつけて（3つ）
  - 答え：小問1：A→C 明渡し ⇔ C＝転借権＋合意解除の対抗制限（613条3項）。
  - 答え：小問2(1)：A→D 明渡し ⇔ D＝Eの賃借権を援用／E→D ⇔ 妨害排除は対抗要件不備で不可 → 代位（423条）／Dの再抗弁＝権利濫用（1条3項）。
- **［入口 4/5・論点］** 問題になる論点を挙げて（4つ）
  - 答え：CP①：合意解除は転借人に対抗できない → 対抗できない結果のAC間の帰趨（3説）。（存続説／原賃貸借引継説／転貸借引継説）
  - 答え：CP②：相続人Eがいる → 借地借家法36条は使えない → 援用理論で居住を守れるか。（＝相続人が承継した賃借権を内縁配偶者が援用）
  - 答え：CP③：Eの妨害排除は対抗要件不備で不可 → 債権者代位権の転用／請求主体がEに変わると援用できない → 権利濫用。
  - 答え：CP④：AE合意解除後の A→D → 援用の弱点と信義則。
- **［入口 5/5・論点］** 橋の架け方を言って（1つ）
  - 答え：「小問1で学んだ『合意解除は適法な地位を築いた第三者に対抗できない』という発想は、賃借権を援用して居住するDにも妥当する。すなわち、AE間の合意解除は、特段の事情がない限り、信義則上Dに対抗できない」。

### 骨子（3項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　小問1

- 見出しの補足（結論を含む。項目の終わりに読む）：AC間の法律関係
1. 適法転貸後にAB合意解除 → 【論点】合意解除を転借人に対抗できるか（規範：613条3項本文・ただし書）

2. 【論点】対抗できない場合のAC間の帰趨（規範：3説→転貸借引継説）
   - あてはめ：Bは転貸借関係から離脱、Aが転貸人の地位を承継（Cの従前の地位を保存）
- 結論：AC間にBC間と同一内容の賃貸借関係が成立 ＝ 明渡請求は認められない

#### 第2　小問2(1)

- 見出しの補足（結論を含む。項目の終わりに読む）：A・D・Eの法律関係
1. 相続人Eあり → 借地借家法36条不可 → 【論点】内縁配偶者Dの居住保護（規範：援用理論）
   - あてはめ：DはEが承継した賃借権を援用して対Aの明渡しを拒む
2. Eの請求：対抗要件不備で605条の4不可 → 【論点】債権者代位権の転用（規範：423条・無資力不要）
3. 対Eでは援用不可（請求主体がEでその意思に反する）→ 【論点】権利濫用（規範：1条3項）が受皿
4. Dは共同賃借人にならない → 賃料負担はE

- 【拾う事実】『Dが実際に居住継続』 → 保護の必要性・賃料負担者の論点を起動
- 【争いのない要件】論点にならず、あっさり認定する要件
  - Aの所有権・占有＝争いなし／転貸の適法性＝Aの承諾あり＝○／Cの死亡と相続＝E承継＝○ で一言素通り。詰まるのは 613条3項の帰趨・援用の可否・代位の転用・信義則の4つ。
- 【ポイント】帰趨3説の急所
  - 対抗できない結果の説明は3つ。①原賃貸借存続説＝AB間は消滅・対Cで存続（二重関係で複雑）／②原賃貸借引継説＝AB賃貸借がAC間へ（Cを無関係な契約に縛り不当）／③転貸借引継説＝Bが離脱しAが転貸人の地位を承継（Cの従前の地位をそのまま保存）。③を採り、Cの地位保存を理由にするのが書きやすい。
- 【効く事実】小問1で効く事実
  - 対抗制限の発動 → Aの承諾ある適法な転貸＋合意解除＋債務不履行解除権をうかがわせる事情なし（ただし書非該当）。帰趨 → Cの使用収益を従前どおり保存できるのが③の長所。事実は必ず評価と結合させる。
- 【ポイント】場合分けの急所
  - 同じDの居住でも誰が請求するかで武器が変わる。対Aなら援用が効くが、対Eでは援用できない（Eの賃借権を、そのEの意思に反して援用するのは筋が通らない）。だからEに対しては権利濫用（1条3項）という別の受皿に切り替える。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 援用理論には弱点がある＝相続人Eが合意解除すれば援用対象の賃借権が消え、Dは援用できなくなるのでは？ という疑問。ここで「合意解除は第三者（援用者）に対抗できない」という小問1と同じ価値判断を信義則で持ち込む。最高裁判例はなく、反対の結論（他人の権利に乗るだけの援用者は保護されない）にも一言配慮すると上位答案。
- 【まぎらわしい選択肢・論点】即時取得の成否／賃借権の時効取得
- 【まぎらわしい選択肢・結論】AはCに明渡しを請求できる
- 【まぎらわしい選択肢・規範】原賃貸借存続説
- 【まぎらわしい選択肢・事実】債務不履行による解除権あり／Dが賃借権の登記を備える

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

小問1＝適法転貸＋合意解除で613条3項、対抗できず明渡し不可、帰趨は転貸借引継説でAが転貸人の地位承継。小問2(1)＝相続人ありで36条不可、援用理論で対A拒める、対Eは代位で来て援用不可・権利濫用が受皿、賃料はE。小問2(2)＝援用の弱点、信義則で特段の事情なき限り対抗不可。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 適法な転貸後に原賃貸借が合意解除された場合の帰結を定める条文と、その例外（ただし書）を挙げよ。
  - 模範解答：613条3項本文＝賃貸人は合意解除を転借人に対抗できない。ただし書＝その解除の当時、賃貸人が賃借人の債務不履行による解除権を有していたときは対抗できる。令和2年改正で判例法理（最判昭37.2.1等）を明文化したもの。
- **［規範クイズ 2/3］** 建物賃借人が死亡し相続人がいるとき、同居していた内縁配偶者が賃貸人の明渡請求を拒む法律構成（援用理論）と、賃料負担の帰結を述べよ。
  - 模範解答：相続人でない内縁配偶者は、相続人が承継した賃借権を援用して賃貸人に居住を対抗できる（最判昭42.2.21）。もっとも内縁配偶者は共同相続人と並んで共同賃借人となるわけではないため、賃料支払義務は賃借権を相続した相続人が負う。借地借家法36条は相続人がいない場合の規定で本件では使えない。
- **［規範クイズ 3/3］** 対抗要件を備えない賃借人が、目的物を占有する第三者を排除するために採りうる法律構成を、条文とともに述べよ。
  - 模範解答：対抗要件不備で605条の4は使えないから、賃借権を被保全債権として、賃貸人が第三者に対して有する返還請求権を代位行使する（423条の転用・最判昭29.9.24）。責任財産保全目的でなくても保全の必要性の限度で許され、代位債権者への直接明渡しも認められる。

## 4. ○×クイズ（全7問・1問目から最後まで全部出す）

- **［○×クイズ 1/7］** 賃貸借契約は、当事者の一方がある物の使用収益を相手方にさせることを約し、相手方がこれに賃料を支払うこと及び引渡しを受けた物を契約終了時に返還することを約することで、その効力を生ずる諾成契約である。
  - 正解：○（正しい）
  - 理由：賃貸借は諾成・双務・有償契約（601条）。使用収益させる義務と賃料支払・返還義務が対価関係に立つ。物の引渡しは成立要件ではなく履行の問題。この基本骨格が「誰の何の請求か」を整理する出発点になる。
- **［○×クイズ 2/7］** 賃借人が賃貸人の承諾を得て適法に転貸した後、賃貸人と賃借人が原賃貸借を合意解除したときは、賃貸人はその合意解除の効果を転借人に対抗して、当然に転借人に対し目的物の明渡しを請求することができる。
  - 正解：×（誤り）
  - 理由：適法な転貸後は、賃貸人は原賃貸借の合意解除を転借人に対抗できない（613条3項本文）。承諾を得て適法に地位を築いた転借人を、当事者間の任意の合意で一方的に追い出すことは許されないからである。例外はただし書＝解除当時に賃借人の債務不履行による解除権を有していた場合のみ。
- **［○×クイズ 3/7］** 設問が「AC間の法律関係について論ぜよ」と問うている場合、賃貸人Aの転借人Cに対する明渡請求が認められないことさえ示せば足り、合意解除を対抗できない結果としてAC間にどのような法律関係が残るかまで論ずる必要はない。
  - 正解：×（誤り）
  - 理由：「法律関係を論ぜよ」は請求の可否にとどまらず両者の間に残る関係の帰趨まで問う。合意解除を対抗できない結果、賃借人は転貸借関係から離脱し賃貸人が転貸人の地位を承継する等（3説の対立）を論じてはじめて設問に答えたことになる。可否だけで止めると設問の半分を落とす。
- **［○×クイズ 4/7］** 対抗要件を備えていない不動産の賃借人は、その不動産を占有する第三者に対して、賃借権に基づき自ら妨害の停止や返還を請求すること（605条の4）はできない。
  - 正解：○（正しい）
  - 理由：605条の4の妨害停止・返還請求は対抗要件（登記・建物なら引渡し）を備えた賃借人にのみ認められる。対抗要件を欠く賃借人は本条によれず、賃借権を被保全債権とする債権者代位権の転用（423条）で賃貸人の返還請求権を代位行使する道が残る。
- **［○×クイズ 5/7］** 適法な転貸後の合意解除を賃貸人が転借人に対抗できない場合、その後の賃貸人・転借人間の法律関係は、賃貸人と賃借人との間の原賃貸借がそのまま賃貸人・転借人間に引き継がれる（原賃貸借引継説）と解するのが、転借人の地位を最も無理なく保存できる点で妥当である。
  - 正解：×（誤り）
  - 理由：転借人の地位を最も無理なく保存できるのは転貸借引継説（賃借人が離脱し賃貸人が転貸人の地位を承継＝賃貸人・転借人間は従前の転貸借内容で規律）。原賃貸借引継説は、転借人を自分が当事者でない原賃貸借の条件に縛る点でかえって不当とされる。理由づけ（従前の地位の保存）とセットで説を選ぶのがコツ。
- **［○×クイズ 6/7］** 賃借権を被保全債権として、賃貸人が不法占有者に対して有する返還請求権を代位行使するには、債務者である賃貸人が無資力であることが必要である。
  - 正解：×（誤り）
  - 理由：賃借権のような特定債権を保全するための転用型の債権者代位（423条・423条の7参照）では、金銭債権の保全（本来型）と異なり債務者の無資力は不要で、保全の必要性があれば足りる。無資力を要求するのは本来型だけ。
- **［○×クイズ 7/7］** 建物賃借人の死亡後、その内縁配偶者が相続人の承継した賃借権を援用して居住している場合、賃貸人と賃借権の相続人との間でされた合意解除は、援用者に不信な行為があるなど信義則に反しないような特段の事由がある場合を除き、その賃借権の援用者に対抗することができない。
  - 正解：○（正しい）
  - 理由：合意解除を常に対抗できるとすると援用者の地位が甚だ不安定になり、合意解除の濫用を招いて援用を認めた趣旨を没却する。そこで特段の事情がない限り、合意解除を援用者に対抗できない（1条2項・東京地判昭63.4.25）。613条3項の下敷き判例法理をパラレルに用いた処理で、最高裁判例はなく反対説もある。

（○×クイズはここまで＝全7問。最後の7問目まで出したら「○×クイズ、全7問クリア！」と言って復習へ）
