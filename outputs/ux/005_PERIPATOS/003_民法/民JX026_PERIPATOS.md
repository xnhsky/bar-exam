### 問題文（最初にゆっくり読み上げる）

Aは、Bに対し同人所有の動産を売却し、これを引き渡した。その際、Aは、当該売買代金債権を担保するため、Bの所有する甲建物に抵当権を設定し、その登記を経由した。BはC社に甲建物を賃貸し、さらにC社はこれをDへ転貸した。Bに対する売買代金債権の弁済期が経過したにもかかわらず弁済がされない場合、Aは、C社のDに対する転貸賃料債権に物上代位することができるか。C社のDに対する転貸賃料債権がEに対して譲渡され、C社からDに対して内容証明郵便による債権譲渡の通知が行われていた場合はどうか。なお、C社は、Bを代表取締役とする実体のない株式会社であり、転貸賃料はBの生活費に充てられていたものとする。以上について論ぜよ。

この順番の理由（参考。結論・配点には触れず、一言で言い直す）：設問は前段・後段の順で問い、かつ後段は前段の肯定を論理的前提とする（前段で物上代位を否定すれば後段に進めない）。だから前段（転貸賃料への物上代位の可否）→ 後段（債権譲渡との優劣）で書く。

### 骨子（3項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　前段 ― 転貸賃料債権への物上代位

- 見出しの補足（結論を含む。項目の終わりに読む）：372条・304条1項
1. 抵当権に物上代位の直接規定なし → 372条が304条を準用（条文操作）
2. 対象は賃借人C社の転貸賃料 → 【論点】304条1項の「債務者」に賃借人（転貸人）を含むか
   - あてはめ：規範：原則含まれない（∵物的責任を負うのは所有者・賃借人は自己の債権を弁済に供する立場にない）
3. 【論点】所有者と同視することを相当とする例外 → 規範：法人格濫用・賃貸借仮装
   - あてはめ：C社は実体のない会社（Bが代表）・賃料はBの生活費 → 法人格濫用＝同視相当
- 結論：Aは転貸賃料債権に 物上代位できる

#### 第2　後段 ― 物上代位と債権譲渡との優劣

- 見出しの補足（結論を含む。項目の終わりに読む）：304条1項但書・467条
1. 転貸賃料債権をEへ譲渡・内容証明で通知 → 確定日付＝第三者対抗要件（467条2項）
2. 【論点】「払渡し又は引渡し」に債権譲渡を含むか → 規範：第三債務者保護説
   - あてはめ：差押えの趣旨＝第三債務者Dの二重弁済回避（譲受人保護のためではない）
3. ゆえに債権譲渡は含まれない → 対抗要件具備後もAは差し押さえて物上代位可
- 結論：Aは 物上代位権を行使できる

#### 第3　加点 ― 担保権の種類による差異

   抵当権は登記で公示（譲受人は負担を予測可）→ 公示を欠く動産売買先取特権（平17判決＝譲渡後は否定）と結論が逆 → 本問は物上代位可

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「Bを代表取締役とする実体のない株式会社」 → 法人格濫用の評価根拠（前段の例外）
- 【拾う事実】「転貸賃料はBの生活費に充てられていた」 → 賃料が実質所有者Bに帰属＝同視相当
- 【拾う事実】『対象は「転貸」賃料債権（C社→D）』 → 所有者の賃料でなく賃借人の債権＝「債務者」争点
- 【拾う事実】「内容証明郵便による債権譲渡の通知」 → 確定日付＝第三者対抗要件（467条2項）
- 【拾う事実】『担保は甲建物への「抵当権」（登記あり）』 → 先取特権と結論を分ける公示の有無
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 準用＝372条で一言。対象＝所有者Bの賃料なら明文で可・争いなし。本問は「転貸」賃料だから「債務者」が争点に浮く。
- 【効く事実】「例外該当のあてはめ」のあてはめで使う事実
  - 法人格濫用 → C社は「Bを代表取締役とする実体のない株式会社」／賃料の帰属 → 転貸賃料は「Bの生活費」に充てられていた＝実質的に所有者Bの賃料。事実は必ず「所有者と同視することを相当とする」の評価と結合させる。
- 【規範の要点】第三債務者保護説の規範
  - 差押要件の趣旨は第三債務者（D）を二重弁済の危険から保護する点にある。だから差押えは第三債務者保護の制度であって譲受人保護のためではなく、「払渡し又は引渡し」に債権譲渡は含まれない。ゆえに対抗要件具備後も、抵当権者は自ら差し押さえて物上代位できる。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 先取特権＝公示方法なし→譲受人の取引安全を厚く守る必要→対抗要件具備後は物上代位不可（平17判決）。抵当権＝登記で公示→譲受人は負担を予測できる→対抗要件具備後も可（平10判決）。本問は登記された抵当権だから物上代位できる、と切り分ける。
- 【まぎらわしい選択肢・論点】177条の対抗問題／即時取得の成否
- 【まぎらわしい選択肢・結論】物上代位できない／債権譲渡が優先する
- 【まぎらわしい選択肢・規範】特定性維持説／優先権保全説
- 【まぎらわしい選択肢・事実】動産売買先取特権／公示なし

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

前段＝372→304準用、対象は転貸賃料、「債務者」に賃借人は原則含まれない（物的責任は所有者）、でも法人格濫用で所有者と同視相当→物上代位可。後段＝差押えの趣旨は第三債務者保護、債権譲渡は「払渡し・引渡し」に含まれない→対抗要件具備後も差押えて物上代位可。加点＝抵当権は登記あり、先取特権（公示なし）と結論が逆。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 転貸賃料債権への物上代位が例外的に肯定される場合の規範（判例）を述べよ。
  - 模範解答：所有者の取得すべき賃料を減少させ、又は抵当権の行使を妨げるために、法人格を濫用し、又は賃貸借を仮装した上で転貸借関係を作出したなど、抵当不動産の賃借人を所有者と同視することを相当とする場合には、その賃借人が取得すべき転貸賃料債権への物上代位を許すべきである（最決平12.4.14）。
- **［規範クイズ 2/3］** 抵当不動産の賃料一般（所有者Bが取得する賃料）に物上代位できることの条文上の根拠を述べよ。
  - 模範解答：304条1項が物上代位の対象として「賃貸……によって債務者が受けるべき金銭」を明文で挙げており、賃料債権への物上代位自体は争いがない。本問で争点になるのは、それが所有者の賃料ではなく賃借人C社の「転貸」賃料だという一点。
- **［規範クイズ 3/3］** 差押えを物上代位の要件とした趣旨をめぐる諸説を挙げ、判例の立場を示せ。
  - 模範解答：①特定性維持説（差押えは目的債権の特定性を保つため→譲渡を含みうる）②優先権保全説（抵当権者の優先権を保全するため）③第三債務者保護説（第三債務者の二重弁済回避のため→譲渡を含まない）。判例（最判平10.1.30）は第三債務者保護説を採る。

## 4. ○×クイズ（全9問・1問目から最後まで全部出す）

- **［○×クイズ 1/9］** 抵当権には物上代位に関する直接の規定はないが、372条が先取特権に関する304条を抵当権に準用しているため、抵当権者も物上代位権を行使することができる。
  - 正解：○（正しい）
  - 理由：抵当権は価値権であり、目的物が形を変えた代替物（売却代金・賃料・保険金等）にも効力を及ぼす必要がある。もっとも抵当権の章に独自規定はなく、372条が先取特権の304条を準用することで抵当権にも物上代位を認める。
- **［○×クイズ 2/9］** 抵当不動産の賃借人（転貸人）が転借人に対して有する転貸賃料債権については、賃借人も抵当不動産について物的責任を負う以上、常に抵当権に基づく物上代位が認められる。
  - 正解：×（誤り）
  - 理由：物的責任を負うのは抵当不動産の所有者であって、賃借人（転貸人）は物的責任を負わない。ゆえに転貸賃料債権への物上代位は原則として否定される（304条1項の「債務者」に賃借人は原則含まれない）。「常に可」とするのは全面肯定説の帰結で、判例・通説ではない。
- **［○×クイズ 3/9］** 304条1項の「債務者」には、原則として抵当不動産の賃借人（転貸人）は含まれず、その転貸賃料債権に対する物上代位は原則として否定される。
  - 正解：○（正しい）
  - 理由：判例（最決平12.4.14）は「債務者」に賃借人（転貸人）は原則含まれないとする。ただし所有者と同視することを相当とする場合（法人格濫用・賃貸借仮装）には例外的に物上代位を許す。原則で切って終わらせず、必ず例外を検討するのが前段の勝負どころ。
- **［○×クイズ 4/9］** 転貸賃料債権への物上代位が原則として否定されるのは、所有者は被担保債権について抵当不動産をもって物的責任を負担するのに対し、賃借人はそのような責任を負担せず、自己に属する債権を被担保債権の弁済に供されるべき立場にないからである。
  - 正解：○（正しい）
  - 理由：これが最決平12.4.14の示す原則否定の理由。担保物権の基本構造＝「物的責任を負う所有者」と「負わない賃借人」の区別から導く。理由まで書き切ると規範の説得力が増す。
- **［○×クイズ 5/9］** 抵当不動産の賃借人（転貸人）を所有者と同視することを相当とする例外は、賃貸借が仮装された場合に限られ、実体はあるが所有者に支配された法人が賃借人となっている場合には認められない。
  - 正解：×（誤り）
  - 理由：判例（最決平12.4.14）は例外事由として「法人格を濫用し、又は賃貸借を仮装した上で転貸借関係を作出した」を並列に挙げる。賃貸借仮装型に限られない。本問は「実体のない会社（法人格濫用）＋賃料がBの生活費」で、法人格濫用型の例示にドンピシャ該当する。
- **［○×クイズ 6/9］** 差押えを物上代位の要件とした趣旨を第三債務者の二重弁済回避に求める立場（第三債務者保護説）によれば、「払渡し又は引渡し」に債権譲渡は含まれず、目的債権が譲渡され第三者対抗要件が備えられた後も、抵当権者は自ら差し押さえて物上代位権を行使できる。
  - 正解：○（正しい）
  - 理由：最判平10.1.30の規範。差押えは第三債務者が弁済先を誤らないための制度であって、目的債権の譲受人の利益を保護するものではない。この趣旨から「債権譲渡は払渡し・引渡しに含まれない」を導き、対抗要件具備後の物上代位を肯定する。趣旨→結論の論理の橋を必ず架ける。
- **［○×クイズ 7/9］** 目的債権が譲渡され、確定日付のある証書による通知（467条2項）で第三者対抗要件が備えられた場合、その債権譲渡は304条1項ただし書の「払渡し又は引渡し」に当たるから、抵当権者はもはや物上代位権を行使できない。
  - 正解：×（誤り）
  - 理由：判例（第三債務者保護説）は「払渡し又は引渡し」に債権譲渡は含まれないとする。よって対抗要件具備後でも抵当権者は自ら差し押さえて物上代位できる。「譲渡＝払渡し・引渡し」と当てはめて物上代位を否定するのは、特定性維持説的な帰結で判例ではない。
- **［○×クイズ 8/9］** 動産売買の先取特権に基づく物上代位については、目的債権が譲渡され第三者に対する対抗要件が備えられた後は、もはや物上代位権を行使することができない（判例）。
  - 正解：○（正しい）
  - 理由：最判平17.2.22。動産売買先取特権は公示方法を欠くため、譲受人その他の第三者の取引安全を保護する必要が高い。ゆえに対抗要件具備後の物上代位は否定される。抵当権（平10判決）とは結論が逆になる。
- **［○×クイズ 9/9］** 被担保債権が動産売買代金債権である場合には、担保として登記された抵当権が設定されているときでも、目的債権が譲渡され対抗要件が備えられた後は物上代位できない。
  - 正解：×（誤り）
  - 理由：物上代位の可否は被担保債権の種類ではなく担保権の種類で決まる。担保が登記された抵当権である以上、公示があり譲受人は負担を予測できるから、対抗要件具備後も物上代位できる（平10判決）。被担保債権が動産売買代金債権であることに引きずられて先取特権（平17判決）の結論を持ち込むのが典型的な失点。
