- **［入口 2/7・見当づけ］** 各財産は「誰がどの手段で」を仮当てする ― 見当をつけて

- **［入口 4/7・論点］** 賃料をめぐる問題になる論点を挙げて（3つ）

  - 答え：CP③：Dは登記だけでRに請求できるか → 特例法4条2項の債務者対抗要件（＝登記＝第三者対抗要件にとどまる）。
- **［入口 5/7・論点］** Dの譲渡担保が判例射程に入る理由を言って
  - 答え：譲渡担保＝債権譲渡か（＝担保のための債権譲渡も「債権譲渡」の一類型）。譲渡担保も担保目的の債権譲渡である以上、最判平10.1.30（債権譲渡の事案）の射程が正面から及ぶ。Dが特例法登記で第三者対抗要件を備えていても、Bの物上代位が優先する。
- **［入口 6/7・論点］** 「通知だけ取り消せるか」を答えて（2つ）
  - 答え：CP②：本体の債権譲渡（代物弁済）は2027年＝無資力前で詐害行為に当たらない。対抗要件具備行為（通知）は財産を減少させる行為ではないから、原因行為が詐害行為でない以上、通知だけを取り消せない（最判平10.6.12）→ B・DはEに対抗できず、Eが4000万円の限度で優先。
  - 答え：CP③：乙不動産抵当は無権代理で無効が原則（113条）。権利証・実印・印鑑証明の交付が代理権授与の表示（109条）に当たり、Dが善意無過失なら有効化の余地。ただし授権表示・善意無過失の認定は困難で確定的結論は導きにくい。Dが賃料をRに請求するには特例法4条2項の通知が必要。
- **［入口 7/7・論点］** 各人の最終的な取り分を言って（3つ）

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 抵当権に基づく物上代位と、目的債権の譲渡（担保）とが競合した場合の優劣の規範と結論を、304条1項但書の差押えの趣旨から述べよ。
  - 模範解答：差押えの趣旨は第三債務者を二重弁済の危険から保護する点にあり、304条1項但書の「払渡し又は引渡し」に債権譲渡は含まれない。抵当権の効力が目的債権に及ぶことは抵当権設定登記で公示されており譲受人も不測の損害を受けない。よって、目的債権が譲渡され対抗要件が備えられた後でも、抵当権者は払渡前に差し押さえれば物上代位で優先する（最判平10.1.30）。
- **［規範クイズ 2/3］** 債権譲渡の本体行為が無資力前でされ詐害行為に当たらない場合、無資力後にされた対抗要件具備行為（確定日付ある通知）だけを詐害行為として取り消せるか。規範と理由を述べよ。
  - 模範解答：詐害行為取消しの対象は責任財産を減少させる原因行為である。対抗要件具備行為は、既にされた債権譲渡の効力を第三者に対抗しうるものとするにとどまり、それ自体は債務者の一般財産を減少させる行為ではない。したがって、原因行為たる債権譲渡が詐害行為を構成しない以上、通謀虚偽表示等でない限り、通知のみを詐害行為として取り消すことはできない（最判平10.6.12）。
- **［規範クイズ 3/3］** 権限がないのに本人の代理人と称してされた抵当権設定行為が、なお本人に効果帰属しうる場合（民法109条＝代理権授与の表示による表見代理）の要件を述べよ。
  - 模範解答：①本人が第三者に対し他人に代理権を与えた旨を表示したこと、②その表示された代理権の範囲内の代理行為であること、③相手方（第三者）が代理権の不存在につき善意無過失であること。これらを満たせば、本人は無権代理行為の責任を負う（109条1項）。無権代理は原則本人に効果不帰属（113条）で、表見代理はその例外である。

## 4. ○×クイズ（全10問・1問目から最後まで全部出す）

- **［○×クイズ 1/10］** 抵当権の効力は、目的不動産そのものだけでなく、その交換価値が形を変えた賃料債権にも物上代位として及びうる（372条・304条）。
  - 正解：○（正しい）
  - 理由：304条は先取特権の物上代位を定め、372条が抵当権に準用する。目的物の「賃貸……によって……受けるべき金銭」＝賃料は交換価値の実現物であり、物上代位の目的となる（最判平元.10.27）。だから抵当不動産を持つ債権者は、賃料からも回収を狙える。
- **［○×クイズ 2/10］** 抵当権者が賃料債権に物上代位するには、賃料が賃借人から債務者へ払い渡された後であっても、差押えさえすればいつでも物上代位できる。
  - 正解：×（誤り）
  - 理由：304条1項但書は「払渡し又は引渡しの前に差押えをしなければならない」と定める。払渡し後は目的債権が消滅・混同等で失われるため物上代位できない。物上代位は払渡前の差押えが生命線で、この「前」を落とすと優劣の議論に入れない。
- **［○×クイズ 3/10］** 動産・債権譲渡特例法上の債権譲渡登記は、第三者に対する対抗要件を具備させるが、これだけでは債務者に対して直接権利を行使できず、債務者対抗要件は別途必要である。
  - 正解：○（正しい）
  - 理由：特例法4条1項の譲渡登記は第三者対抗要件を与えるだけで、同4条2項により、債務者に登記事項証明書を交付して通知するか債務者の承諾を得なければ債務者対抗要件を具備しない。だからDは登記だけでは賃借人Rに直接賃料を請求できない（論点3の核）。
- **［○×クイズ 4/10］** 物上代位の目的債権が第三者に譲渡され、確定日付ある通知で対抗要件が備えられると、抵当権者はもはや当該債権を差し押さえて物上代位することはできない。
  - 正解：×（誤り）
  - 理由：最判平10.1.30は、目的債権が譲渡され第三者対抗要件が備えられた「後」であっても、抵当権者は自ら差し押さえて物上代位できるとした。304条1項但書の差押えは第三債務者の二重弁済防止の趣旨で、「払渡し又は引渡し」に債権譲渡は含まれず、抵当権は登記で公示済みだから譲受人も不測の損害を受けないためである。
- **［○×クイズ 5/10］** 賃料債権の譲渡担保も担保目的でされる債権譲渡である以上、物上代位と債権譲渡の優劣に関する判例法理（最判平10.1.30）の射程が及ぶ。
  - 正解：○（正しい）
  - 理由：譲渡担保は「担保のための債権譲渡」であり、債権譲渡の一類型にほかならない。よって、物上代位と債権譲渡の優劣を決した最判平10.1.30の射程がそのまま及び、抵当権者は払渡前に差し押さえれば譲渡担保権者に優先する。
- **［○×クイズ 6/10］** 304条1項但書が物上代位に払渡前の差押えを要求した趣旨は、抵当権者に早期の権利行使を促す点にあり、第三債務者の保護とは関係がない。
  - 正解：×（誤り）
  - 理由：判例（最判平10.1.30）は差押えの趣旨を、主として第三債務者が弁済の相手方を誤り二重弁済を強いられる危険を防ぐ点（第三債務者保護）に求める。この趣旨から「払渡し又は引渡し」に債権譲渡は含まれないと導き、譲渡後の物上代位を肯定する。趣旨の設定を誤ると結論の理由づけが崩れる。
- **［○×クイズ 7/10］** 債権譲渡の本体行為が無資力前でされ詐害行為に当たらない場合でも、対抗要件具備行為（通知）が無資力後にされた以上、その通知を詐害行為として取り消すことができる。
  - 正解：×（誤り）
  - 理由：対抗要件具備行為は責任財産を減少させる行為ではないから、原因行為（債権譲渡）が詐害行為でない限り、通知が無資力後でも取消しの対象にならない（最判平10.6.12）。無資力の基準時は原因行為時で判断する。
- **［○×クイズ 8/10］** 将来発生すべき債権であっても、発生原因・期間・金額等により特定される限り、原則として有効に譲渡することができる（466条の6）。
  - 正解：○（正しい）
  - 理由：466条の6第1項は、譲渡の意思表示時に債権が現に発生していることを要しないと定める。最判平11.1.29を明文化したもので、発生原因・期間・金額で特定される限り将来債権譲渡は有効。ただし譲渡範囲が譲渡人の営業を不当に制約し公序良俗に反する特段の事情があれば例外的に無効となりうる。
- **［○×クイズ 9/10］** 法人が債権を譲渡し債権譲渡登記をしても、債務者に対しては、登記事項証明書を交付して通知するか債務者の承諾を得なければ、その債権を行使することができない（特例法4条2項）。
  - 正解：○（正しい）
  - 理由：特例法4条1項の譲渡登記は第三者対抗要件にすぎず、同2項により、登記事項証明書を交付した通知又は債務者の承諾がなければ債務者に対抗できない。本問のDはRに未通知だから、登記だけではRに直接賃料を請求できず、賃料からの回収は事実上困難。「登記＝万能」ではない点が問われる。
- **［○×クイズ 10/10］** 詐害行為取消権を行使する債権者は、原則として詐害行為より前の原因に基づいて生じた債権（被保全債権）を有していなければならない。
  - 正解：○（正しい）
  - 理由：詐害行為取消権の被保全債権は、原則として詐害行為の前の原因に基づいて生じたものである必要がある（424条3項）。取消権は責任財産保全のための制度だから、詐害行為時に既に責任財産を引当てにしていた債権者を保護する趣旨。もっとも本問では、そもそも本体の債権譲渡が無資力前で詐害行為に当たらず、通知も取消対象外なので、B・DはEに対抗できない。
