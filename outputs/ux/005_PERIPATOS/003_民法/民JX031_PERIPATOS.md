## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

A社は、B社に対し、実験用マウス30匹を売り渡した。ところが、この中に、人及びマウスに有害なウイルスに感染したものが混じっていた。その後、Bの従業員Cがこのウイルスに感染して発病し、長期の入院治療を余儀なくされた。Bは、このウイルスに感染した他のマウス200匹を殺すとともに、Bの実験動物飼育施設に以後の感染を防止するための処置を施した。右の事例において、AB間及びAC間の法律関係について論ぜよ。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- A→B、実験用マウス30匹を売却（一部が有害ウイルス感染）
- Bの従業員Cが感染・発病 → 長期入院
- B、感染した他のマウス200匹を殺処分
- B、飼育施設に以後の感染防止処置を施す
- B→A（契約不適合責任）・C→A（不法行為）が問題化

### 参考（読み上げない。入口の問いの答えを含むので判定にだけ使う）

登場人物：
- A社｜売主（有害ウイルス入りマウスを売却）
- B社｜買主・使用者（→Aへ契約不適合責任）
- C｜Bの従業員（感染・長期入院／→Aへ不法行為）

一行要約：Aが有害ウイルス入りマウスをBに売却、C（Bの従業員）が感染し長期入院、Bは他マウス200匹殺処分＋施設に防止処置。

### 入口の問い（3問）

- **［入口 1/3・事案の整理］** 当事者と請求権を棚卸し ― 契約の線／契約外の線
  - 答え：検討するのは B→A（契約不適合責任） と C→A（不法行為） の2本。A→B（代金）は問題文に出てこないので切る。
  - 答え：C入院分の損害は、AB間ではBの損害・AC間ではCの損害という「二つの顔」を持つ。ここが後の二重払（交錯）に効いてくる。
- **［入口 2/3・見当づけ］** 各請求は「何責任っぽい？」 ― 見当をつけて
  - 答え：AB：目的物（マウス）に品質の不適合 → 契約不適合責任（562〜564・415）系。AC：契約なし・身体侵害 → 不法行為（709条）系。どちらも山は損害の範囲（416条）。
- **［入口 3/3・論点］** ABで問題になる論点を挙げて（3つ）
  - 答え：CP①：損害①殺処分損②防止費③C入院費を、どこまで賠償できるか（416条）。（＝賠償範囲＝相当因果関係の問題）
  - 答え：CP②：各損害は通常損害（1項）か特別損害（2項）かの振り分け。（通常＝予見不要／特別＝予見必要）
  - 答え：CP③：特別損害なら債務者Aの予見可能性（予見すべきであったか・基準時＝不履行時）。

- 順番：第1　AB間の法律関係 → 第2　AC間の法律関係 → 第3　両請求の交錯

### 骨子（3項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　AB間の法律関係

- 見出しの補足（結論を含む。項目の終わりに読む）：契約不適合責任・562〜564条・415条・416条
1. 目的物（マウス）に品質の契約不適合 → 追完(562)・減額(563)・解除(564条・541条)を条文順に一巡
2. 損害賠償(564条・415条)：帰責事由＝感染原因不明 → 「あれば」と仮定
3. 【論点】損害賠償の範囲（416条）（規範：通常損害／特別損害＋債務者の予見）
   - あてはめ：①殺処分損・②防止費＝感染拡大は予見可能 → 賠償可
   - あてはめ：③C入院費＝Bの安全配慮義務経由の損害としてAは予見すべき → 賠償可
- 結論：①②③いずれも賠償範囲 ＝ 契約不適合に基づく損害賠償 認容

#### 第2　AC間の法律関係

- 見出しの補足（結論を含む。項目の終わりに読む）：不法行為・709条・416条類推
1. 契約関係なし → Cの請求は不法行為(709)
2. 過失＝結果回避義務違反 → 予見を「従業員の誰か」に抽象化し肯定余地
3. 【論点】不法行為の損害賠償の範囲 → 416条を類推適用（相当因果関係・富喜丸事件）
   - あてはめ：C個人の治療費・逸失利益の予見可能性
- 結論：C個人の損害は予見不可 ＝ Cの賠償請求 否定（肯定も可）

#### 第3　両請求の交錯

- 見出しの補足（結論を含む。項目の終わりに読む）：二重払の調整
   【論点】C損害分の二重払回避 → いずれか一方への支払でA免責 → 二重払を回避

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「人及びマウスに有害なウイルス」 → 予見可能性を基礎づける核の事実
- 【拾う事実】『他のマウス200匹を殺す／施設に防止処置』 → ①②の損害（通常/特別の振り分け）
- 【拾う事実】『従業員Cが感染・長期入院』 → ③C入院費＝Bの損害／Cの損害の二面
- 【拾う事実】『感染した原因は不明（記載なし）』 → 帰責事由は「あれば」と仮定
- 【拾う事実】『AC間に契約関係なし』 → Cの請求は709条へ切替え
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 追完・減額・解除は条文を挙げて軽く当てはめ。帰責事由＝感染原因不明で「あれば」と仮定。山は損害賠償の範囲。
- 【効く事実】あてはめで使う事実
  - 「人及びマウスに有害なウイルス」→ 感染拡大・防止措置・従業員被害の予見可能性を基礎づける。①殺処分損・②防止費＝他個体感染・施設汚染は予見可能で賠償可／③C入院費＝従業員が感染すればBが安全配慮義務等で手当てを迫られる＝Bの損害としてAは予見すべき。
- 【規範の要点】相当因果関係説の規範
  - 不法行為の賠償範囲は明文を欠くため、416条を類推適用して相当因果関係の範囲に画する（富喜丸事件）。もっとも、C「個人」の治療費・逸失利益の発生まで売却時点でAが予見できたかは一段難しく、模範答案は予見不可能として賠償を否定する（肯定の余地も可）。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 同一被害を二重に塡補させない。C損害相当分はB・Cのいずれか一方への支払でAを免責し、他方への義務は消滅させる。模範答案のようにAC間でC個人の損害を予見不可能として否定すれば、二重払は顕在化しない（調整は肯定説で意味を持つ）。
- 【まぎらわしい選択肢・論点】危険負担の債務者主義／同時履行の抗弁権
- 【まぎらわしい選択肢・結論】契約不適合に基づく損害賠償 全部否定／Cの賠償請求 全部認容
- 【まぎらわしい選択肢・規範】完全賠償主義／事実的因果関係説
- 【まぎらわしい選択肢・事実】代金減額の催告／先行行為

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

AB＝契約不適合（追完・減額・解除・賠償を条文順に一巡）、帰責事由あれば、416条で①殺処分損②防止費③C入院費を通常/特別に振り分け予見あり＝賠償可。AC＝契約なしで709、過失は予見の抽象化で肯定余地、範囲は416類推、C個人の損害は予見不可で否定（肯定も可）。交錯＝C損害分の二重払はいずれか一方への支払で免責。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 民法416条が定める損害賠償の範囲の規範（1項・2項）を述べよ。
  - 模範解答：1項＝通常生ずべき損害（通常損害）は予見可能性を問わず当然に賠償＝相当因果関係の原則。2項＝特別の事情による損害（特別損害）は、当事者（＝債務者）がその事情を予見すべきであったときに賠償。判例・伝統的通説は416条を相当因果関係を定めた規定と理解する（富喜丸事件）。
- **［規範クイズ 2/3］** 不法行為の損害賠償の範囲を画する判例の枠組みと、その根拠・判例名を述べよ。
  - 模範解答：不法行為（709条）は賠償範囲につき明文を欠く。判例は民法416条を類推適用し、通常損害のほか予見可能な特別損害を賠償範囲に含める（相当因果関係説）。根拠判例＝富喜丸事件（大連判大正15年5月22日民集5巻386頁）。最判昭48.6.7（判例百選Ⅱ）が踏襲。
- **［規範クイズ 3/3］** 同一の被害が、使用者の損害としても被害者本人の損害としても賠償されうる場合の、加害者の二重払を避ける調整の考え方を述べよ。
  - 模範解答：損害賠償は現実の損害塡補が目的で、同一被害の重複塡補は認められない。加害者は使用者・被害者のいずれか一方への支払で免責され、他方への賠償義務は消滅する（求償・調整で最終清算）。賠償範囲論で被害者本人の損害を予見不可能として否定すれば、そもそも二重払は顕在化しない。

## 4. ○×クイズ（全7問・1問目から最後まで全部出す）

- **［○×クイズ 1/7］** 売買契約の当事者でない第三者は、その売買契約に基づく契約不適合責任（追完・減額・解除・損害賠償）を売主に対して追及することはできない。
  - 正解：○（正しい）
  - 理由：契約不適合責任は売買契約の効果であり、契約の相対効から契約当事者間でのみ主張できる。契約関係のない第三者が売主に損害を求めるときは、契約責任ではなく不法行為（709条）による。だから「契約でつながる線」と「契約外の線」を最初に切り分ける。
- **［○×クイズ 2/7］** 買主が売主に対し契約不適合を理由として損害賠償を請求する場合、その賠償の範囲は民法416条によって画される。
  - 正解：○（正しい）
  - 理由：契約不適合に基づく損害賠償は564条を介して415条によることになり、その賠償範囲は債務不履行の一般規定である416条で画される。契約不適合責任は瑕疵担保責任を債務不履行責任へ一元化したものだから、範囲論も債務不履行と同じ416条に乗る。
- **［○×クイズ 3/7］** 契約不適合を理由とする損害賠償（564条・415条）が認められるには、債務者の帰責事由が必要であり、帰責事由がなければ免責される（415条1項ただし書）。
  - 正解：○（正しい）
  - 理由：契約不適合責任のうち損害賠償は415条によるから、帰責事由が要件（1項ただし書は債務者側の免責事由）。追完・代金減額・解除は帰責事由を要しない点と対比する。本問は感染原因不明で帰責事由の判断が難しいため「あれば」と仮定して範囲論へ進むのが定石。
- **［○×クイズ 4/7］** 民法416条2項の特別損害について「予見すべきであった」か否かを判断する主体は債権者であり、その予見の基準時は契約締結時である。
  - 正解：×（誤り）
  - 理由：予見の主体は債務者であり、基準時は債務不履行時と解するのが判例・通説。債務者が特別事情を予見すべきであったなら責任を負わせても不当でない、という趣旨だから主体は債務者。「債権者・契約締結時」とすり替える誤りに注意（平成29年改正で文言は「予見し又は予見しえた」→「予見すべきであった」＝規範的・客観的判断へ）。
- **［○×クイズ 5/7］** 民法416条1項の通常損害も、債務者がその損害を予見すべきであった場合に限って賠償の対象となる。
  - 正解：×（誤り）
  - 理由：通常損害（1項）は予見可能性を問わず当然に賠償される。予見可能性が問題になるのは特別損害（2項）だけ。「通常＝予見不要／特別＝予見必要」の役割分担を取り違えないこと。だからあてはめでは、各損害をまず通常か特別かに振り分け、特別と整理したものについてのみ債務者の予見を検討する。
- **［○×クイズ 6/7］** 不法行為による損害賠償の範囲について、判例は明文を欠くため民法416条を類推適用し、相当因果関係の範囲に賠償を限定する。
  - 正解：○（正しい）
  - 理由：富喜丸事件（大連判大15.5.22）以来、不法行為の賠償範囲も416条を類推適用して相当因果関係説で処理するのが判例（最判昭48.6.7も踏襲）。709条は範囲について規定を欠くため、債務不履行の416条を借りてくる。「類推」であって直接適用ではない点を明示するのが差のつくポイント。
- **［○×クイズ 7/7］** 同一の被害について、使用者の被る損害としても被害者本人の損害としても賠償されうる場合、加害者は使用者と被害者の双方に対して重ねて全額を支払う義務を負う。
  - 正解：×（誤り）
  - 理由：損害賠償は現実に生じた損害の塡補を目的とするから、同一被害を二重に塡補させることはできない。加害者は一方への支払で免責され、他方への義務は消滅する。片方が被害者に手当てした後は求償・調整で最終清算する。「二つの顔」を持つ損害では、この二重払回避の一言が上位答案を分ける。
