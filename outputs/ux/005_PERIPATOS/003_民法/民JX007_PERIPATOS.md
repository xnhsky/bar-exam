## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

(1)　Aは、Bが未成年者であることを知らずに、Bに対し、A所有の絵画（以下「本件絵画」）を売却することを依頼し（以下「本件契約」）、そのための代理権を授与した。Bは、Cとの間で、Aを代理して本件絵画を100万円で売却する契約（以下「本件売買契約」）を締結し、Aにその旨を伝えた。Cは契約締結当時、Bが未成年者であることについて善意無過失であった。その後、Bは本件契約を、未成年者であることを理由に取り消した。AC間の法律関係を論ぜよ。(2)　(1)と異なり、Aが未成年者であってBが未成年者でなかったとし、Aが本件契約を未成年者であることを理由に取り消した場合における、AC間の法律関係を論ぜよ。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- Aが本件絵画の売却をBに依頼＋代理権授与（本件契約）
- BがAを代理し（顕名）Cと本件売買契約（100万円）
- Cは締結当時、B（小問1）／A（小問2）の未成年につき善意無過失
- 基礎契約（本件契約）を取消し ─ 小問1＝B／小問2＝A
- 本件売買契約の効果がなおAに帰属するか＝AC間の法律関係の確定

登場人物：
- A｜本人・絵画所有者（→Cへの引渡義務を争う）
- B｜代理人（小問1で未成年・本件売買契約を締結）

### 入口の問い（3問）

- **Q01［事案の整理］** 請求・登場人物と「誰が未成年で何を取り消したか」を挙げて
  - 答え：攻防はCの引渡請求 → Aの反論（効果は帰属しない）→ その当否。AB間の本件契約は取り消されているので、AからCへ請求する形ではなく、C→Aの引渡請求で組むと収まる。
  - 答え：取り消したのは、小問1＝代理人B（未成年）／小問2＝本人A（未成年）。この違いだけを最初に握る。
- **Q02［見当づけ］** 各場面で「何が問題か」 ― 見当をつけて
  - 答え：①代理人に行為能力は不要（102条本文）＝本件売買契約自体に瑕疵なし。②基礎契約と代理権授与は一体（事務処理契約説）＝基礎契約の取消しで代理権も消え、121条の遡及効で遡及的無権代理（113条1項）が原則。③そこからCをどう救うかが小問1と小問2の分かれ道。
- **Q03［論点］** 問題になる論点を挙げて（3つ）
  - 答え：CP①：代理人Bが未成年 → 102条本文で代理行為に瑕疵なし。（代理人に行為能力は不要＝取消しの対象は基礎契約に限られる）
  - 答え：CP②：基礎契約の取消しが代理権に及ぶか → 事務処理契約説で一体→遡及的無権代理。（基礎の事務処理契約と代理権授与はセット＝一方が消えれば他方も消える）
  - 答え：CP③：善意無過失のCの保護 → 取消権者が代理人か本人かで構成が変わる。

### 骨子（3項目。第1から【論点】ごとに、何が問題→規範→使う事実→結論 の順で組み立てる）

#### 前提　102条本文と代理権授与行為の性質

1. 代理人Bは未成年 → 102条本文：代理に行為能力不要 → 本件売買契約に瑕疵なし（一言）
2. 【論点】代理権授与行為の法的性質 → 規範：事務処理契約説（基礎契約と一体）
   - あてはめ：基礎契約（本件契約）取消し → 代理権授与も取消し → 遡及効（121）→ 遡及的無権代理（113条1項）が原則

#### 第1　小問(1)　代理人B（未成年）が取消し

1. C→A：効果帰属（99条1項）で本件絵画引渡請求／A反論：基礎契約取消しで不帰属
2. 【論点】相手方Cの保護（代理人取消し型） → 規範：遡及効否定（将来効）説
   - あてはめ：本人保護不要（取消したのは代理人）・相手方保護の要請高・代理権は代理人に不利益なし
3. Cは善意無過失 → 効果はAに帰属
- 結論：Aの反論は認められず CのAに対する本件絵画引渡請求は認められる

#### 第2　小問(2)　本人A（未成年）が取消し

1. 共通骨格は小問1と同様＝遡及的無権代理が原則
2. 無条件帰属だと 未成年者Aが害される → 【論点】相手方保護（本人取消し型） → 規範：112条1項の類推適用

- 【拾う事実】「Bが未成年」「Aが未成年」 → 取消権者が代理人か本人か（構成の分岐点）
- 【拾う事実】「Aを代理して」「Aにその旨を伝えた」 → 顕名あり（99条1項の効果帰属）
- 【拾う事実】「売却を依頼し、そのための代理権を授与」 → 本件契約＝事務処理契約＋代理権授与（一体性）
- 【拾う事実】「Cは善意無過失」 → 相手方保護要件（どの構成でも充足）
- 【拾う事実】『「Bが未成年であることを知らずに」（小問1）』 → Aを保護すべき要請の高低の評価
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 顕名＝「Aを代理して」で充足／代理行為の瑕疵＝102条本文で遮断／効果帰属＝99条1項。争いのない前提は一言で通し、対立点（基礎契約と代理権の一体性／相手方保護の法律構成）に筆を集める。
- 【効く事実】あてはめで使う事実
  - 本人保護不要 → 取り消したのは代理人B／効果帰属してもBは何ら不利益を受けない。相手方保護必要 → Cは有効な代理と信じ、しかも善意無過失。本人の帰責 → Aは未成年者に授権したリスクを引き受けている。この利益状況から、遡及効を否定し将来効にとどめる＝効果はAに帰属。事実は必ず評価と結合させる。
- 【規範の要点】112条1項類推の規範
  - 112条1項は「代理行為時に代理権が既に消滅」の規定であり、遡及的に消滅した本問には直接は当たらない。もっとも、消滅した代理権に対する相手方の信頼を保護する点で類推の基礎があるから、第三者が取消原因に関する事実について善意無過失であれば同項を類推適用できる。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 小問1（代理人取消し）＝本人保護不要→遡及効否定（将来効）説で端的に救済。小問2（本人取消し）＝本人＝未成年者保護の要請→善意無過失を要件とする112条1項類推。この利益状況の対比を明示できるかが平均答案と上位答案を分ける最大の得点源。結論はどちらも効果はAに帰属＝Cの引渡請求認容。
- 【まぎらわしい選択肢・論点】94条2項類推適用の可否／即時取得の成否
- 【まぎらわしい選択肢・結論】Cの引渡請求は認められない／無権代理として効果不帰属
- 【まぎらわしい選択肢・規範】無因性説／112条1項の直接適用
- 【まぎらわしい選択肢・事実】代理人の行為能力／Cの悪意

## 3. 規範クイズ（3問）

- **Q04［規範］** 代理権授与行為の法的性質について、基礎となる契約が取り消されると代理権授与も取り消されるとする説の名称とその帰結を述べよ。
  - 模範解答：事務処理契約説（一体説）。代理権授与行為は基礎となる事務処理契約（委任等）と一体であり、両者を切り離すと内部関係の瑕疵が外部に反映されず不当。よって基礎契約が取り消されれば代理権授与も取り消され、取消しの遡及効（121条）により代理行為は遡及的に無権代理（113条1項）となるのが原則。この原則を立てたうえで相手方保護を論ずる。
- **Q05［規範］** 代理人の側から基礎契約（代理権授与契約）が取り消された場合に、相手方を保護するための「遡及効否定（将来効）説」の論拠と帰結を述べよ。
  - 模範解答：代理人から取り消した場合には本人を保護する必要がなく、他方で相手方保護の要請が高い。また代理権は代理人に不利益を及ぼさないから、遡及効の原則を堅持する必要はない。そこで、その取消しの効果は将来効にとどまり、代理行為が遡って無権代理になるものではないと解する。結果、代理行為の効果はなお本人に帰属する。
- **Q06［規範］** 本人の側から基礎契約が取り消された場合に、相手方を保護するための「112条1項類推適用説」の理由づけ（なぜ直接適用でなく類推か・要件）を述べよ。
  - 模範解答：無条件の効果帰属では未成年者である本人が害されるため、相手方保護との調整を図る必要がある。112条1項は本来「代理行為時に代理権が既に消滅」していた場合の規定で、代理権が遡及的に消滅した本問には直接当たらない。もっとも、消滅した代理権に対する相手方の信頼を保護する点で類推の基礎があるから、第三者が取消原因に関する事実につき善意無過失であれば同項を類推適用できる（授権による外観作出に着目すれば109条1項類推も可）。

## 4. ○×クイズ（8問）

- **Q07［○×］** 代理人が権限内で本人のためにすることを示して（顕名）した意思表示は、直接本人に対して効力を生ずる（99条1項）。したがって有権代理が成立すれば、契約の効果は代理人ではなく本人に帰属する。
  - 正解：○（正しい）
  - 理由：代理の効果帰属の基本ルール（99条1項）。顕名＋権限内の代理行為＋代理権の存在が揃えば、効果は本人に直接帰属する。相手方が本人に履行を請求できる根拠がこれ。本問の出発点は「Cは99条1項で本人Aに引渡しを請求できるか」。
- **Q08［○×］** 制限行為能力者が代理人としてした行為は、行為能力の制限を理由に取り消すことができる（102条本文）。
  - 正解：×（誤り）
  - 理由：逆。102条本文は「制限行為能力者が代理人としてした行為は、行為能力の制限によっては取り消すことができない」と定める。代理の効果は本人に帰属し代理人は不利益を受けないため、代理人保護を考慮する必要がないのが根拠。よって代理人Bが未成年でも本件売買契約（代理行為）自体には瑕疵がない。取消しの対象になりうるのは基礎契約の方。
- **Q09［○×］** 取り消された行為は、初めから無効であったものとみなされる（121条）。この遡及効の結果、代理権授与の基礎となる契約が取り消されて代理権授与も取り消されると、代理行為は遡って無権代理（113条1項）となるのが原則である。
  - 正解：○（正しい）
  - 理由：取消しの効果は遡及的無効（121条）。事務処理契約説で基礎契約と代理権授与を一体と見れば、基礎契約の取消しは代理権授与も遡及的に消し、代理行為は遡って無権代理（113条1項）になる。これが両小問に共通する「原則」で、相手方保護はこの原則をどう修正するかの問題。
- **Q10［○×］** 代理人が制限行為能力者である場合、その代理人が本人のためにした代理行為の効果は、代理人自身に帰属し、制限行為能力者である代理人がこれを取り消すことができる。
  - 正解：×（誤り）
  - 理由：代理行為の効果は本人に帰属する（99条1項）のであって代理人には帰属しない。だからこそ代理人が制限行為能力者でも代理人は不利益を受けず、行為能力の制限を理由に代理行為を取り消せない（102条本文）。効果が本人に帰属する点と、代理行為が取り消せない点はセットで押さえる。
- **Q11［○×］** 代理権は、代理人に義務や不利益を負わせるものではなく、代理行為の効果が本人に帰属しても代理人自身は不利益を受けない。
  - 正解：○（正しい）
  - 理由：代理権は権限であって義務ではなく、代理行為の効果は本人に帰属する（99条1項）。だから代理人が制限行為能力者でも、効果帰属を維持しても代理人は害されない。この一点が、①代理行為を取り消せない（102条本文）ことと、②代理人取消し型で相手方を端的に保護できる（将来効説）ことの共通の理由。
- **Q12［○×］** 代理権が遡及的に消滅した場合には、代理権消滅後の表見代理（112条1項）を、その文言どおり直接適用して相手方を保護することができる。
  - 正解：×（誤り）
  - 理由：112条1項は「代理権の消滅後」＝代理行為の時点で代理権が既に消滅していた場合の規定。取消しによって代理権が遡及的に消滅した本問は文言に直接当たらないから、類推適用による。消滅した代理権への信頼保護という共通性が類推の基礎。
- **Q13［○×］** 表見代理（109条・110条・112条）は、虚偽の外観・外観作出についての本人の帰責性・外観を信頼した相手方の善意無過失を要件に外観どおりの効果を認める権利外観法理の現れであり、明文の要件を超える場面にも類推適用されうる。
  - 正解：○（正しい）
  - 理由：表見代理は権利外観法理の現れで、判例・通説はこの枠組みを共有し、重畳適用・類推適用にも及ぼしてきた。本問小問2は代理権が遡及的に消滅した場面で112条1項の文言に直接は当たらないが、消滅した代理権への相手方の信頼保護という共通性から類推の基礎がある。相手方の善意無過失を要件とする点で、本人（未成年者）保護とのバランスが取れる。
- **Q14［○×］** 基礎契約の取消しによって代理行為が遡及的に無権代理となる場合、相手方は常に無権代理人の責任（117条）を追及するほかなく、代理行為の効果が本人に帰属する余地はない。
  - 正解：×（誤り）
  - 理由：遡及的無権代理は「原則」にすぎず、これを貫く見解はほとんどない。代理人取消し型では遡及効否定（将来効）説、本人取消し型では112条1項類推等により、善意無過失の相手方には本人への効果帰属を認めるのが一般的。効果帰属が認められる以上、117条の無権代理人責任に追い込まれるとは限らない（本問のCも本人Aへ請求できる）。
