1. Bは本件遺言書を根拠にEの差押え排除を主張
2. 【論点】相続させる旨の遺言の性質 → 規範：遺贈と解すべき特段の事情なき限り遺産分割方法の指定（908条・1014条2項） → 死亡時に直ちに承継
3. 【論点】相続分を超える部分の対抗要件 → 規範：法定相続分を超える部分は登記等を要する（899条の2条1項）

#### 第2　小問(2)

- 見出しの補足（結論を含む。項目の終わりに読む）：受益相続人の先死
1. Bの先死 → 代襲（887条2項）が生じるとも思える（一度肯定的に振る）
2. 【論点】先死と遺言の効力 → 視点転換：性質論でなく遺言者の意思解釈

3. 遺言書は「B」とのみ記載・Aは先死を何ら考慮せず（Dが可愛がられた点も至らず）→ 特段の事情なし → 失効
- 結論：法定相続へ → 甲土地はDとCが各1条・2条で共有（896・898・900条4号・887条2項）

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「甲土地をBに相続させる」 → 遺言の性質（遺贈か指定か）を決める文言
- 【拾う事実】『甲土地全部をBが取得／Bは登記なし』 → 相続分1/2を超える承継・対抗要件の欠缺（小問(1)）
- 【拾う事実】『Eは代位で相続登記＋Cの持分差押え』 → 899条の2の「第三者」該当性
- 【拾う事実】「Bが先に死んだ場合を何ら考慮せず」 → 代襲者への承継意思の不存在（小問(2)の決め手）
- 【拾う事実】『DはAに可愛がられていた』 → 特段の事情の積極材料だが至らない（両にらみ）
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 小問(1)＝性質決定→死亡時に直ちに承継→甲土地全部は相続分を超える→899条の2で対抗要件必要→Bは登記なし→第三者Eに対抗不可。小問(2)＝代襲が起きそう→意思解釈へ転換→特段の事情なし→失効→法定相続。
- 【効く事実】小問(1)で効く事実
  - 超過部分 → 甲土地全部の取得は法定相続分1/2を超える／対抗要件欠缺 → Bは移転登記を具備していない／第三者性 → Eは代位で相続登記をした上でCの持分を差し押さえた差押債権者。事実は必ず評価語（「相続分を超える承継」「対抗要件の欠缺」）と結合させる。
- 【規範の要点】最判平23.2.22の規範
  - 遺言者は通常、遺言時の特定の推定相続人に取得させる意思にとどまり、その代襲者にまで相続させる意思は有しない。よって、代襲者に相続させる遺言者の意思がうかがわれる特段の事情のない限り、遺言は効力を生じない（原則失効）。失効すれば甲土地は法定相続へ戻る。
- 【まぎらわしい選択肢・論点】遺留分侵害額請求の可否／遺贈の承認・放棄
- 【まぎらわしい選択肢・結論】Bが甲土地全部を単独取得／遺言は有効でDが甲土地を単独取得
- 【まぎらわしい選択肢・規範】対抗要件不要説（改正前判例）／994条1項の直接適用
- 【まぎらわしい選択肢・事実】Bが移転登記を具備／予備的遺言あり

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

小問(1)＝相続させる＝遺産分割方法の指定、死亡時に直ちに承継、超える部分は899条の2で登記いる、Bは登記なし＝第三者Eに対抗不可＝差押え排除できず。小問(2)＝代襲起きそう→意思解釈へ→「B」記載・先死を考慮せず＝特段の事情なし→遺言失効→法定相続でDとC各1条・2条。

## 3. 規範クイズ（全2問・1問目から最後まで全部出す）

- **［規範クイズ 1/2］** 相続による権利承継のうち法定相続分を超える部分について対抗要件を要求する条文と、その立法趣旨を述べよ。
  - 模範解答：899条の2第1項。趣旨＝遺言の有無・内容を知り得ない相続債権者・債務者等の取引の安全を保護すること。平成30年改正で新設され、承継態様（遺産分割・相続分の指定・特定財産承継遺言）を問わず横断的に規律する。
- **［規範クイズ 2/2］** 相続させる旨の遺言の受益相続人が遺言者より先に死亡した場合の効力について、判例（最判平23.2.22）の規範を述べよ。
  - 模範解答：性質論から演繹せず遺言者の意思解釈で決する。遺言書の記載・遺言がなされた目的等から、代襲者その他の者に相続させる遺言者の意思がうかがわれる特段の事情のない限り、遺言はその効力を生じない（原則失効）。失効後は法定相続による。

## 4. ○×クイズ（全10問・1問目から最後まで全部出す）

- **［○×クイズ 1/10］** 遺言は、遺言者の死亡の時からその効力を生ずる（985条1項）。したがって、相続人となるべき者や遺言の効力は、遺言作成時ではなく遺言者の死亡時を基準に判断される。
  - 正解：○（正しい）
  - 理由：遺言は死亡時に効力を生じる（985条1項）。だから相続人の確定も遺言の効力も遺言者の死亡時が基準になる。受益相続人が遺言者より先に死亡すると効力の有無が問題化する（小問(2)の出発点）のは、この基準時ゆえである。
- **［○×クイズ 2/10］** 「甲土地を長男Bに相続させる」という遺言は、常に受遺者Bに対する特定遺贈（964条）と解され、遺贈としての効力が問題となる。
  - 正解：×（誤り）
  - 理由：判例は、遺言書の記載から遺贈と解すべき特段の事情のない限り、「相続させる」旨の遺言を遺産分割方法の指定（908条）＝特定財産承継遺言（1014条2項）と解する（最判平3.4.19）。「常に遺贈」ではない。ここを取り違えると小問(1)(2)とも規律を誤る。
- **［○×クイズ 3/10］** 「相続させる」旨の遺言は、遺言書の記載から遺贈と解すべき特段の事情のない限り、遺産分割方法の指定（908条）と解され、遺産分割手続を経ることなく被相続人の死亡時に直ちに当該遺産が当該相続人に承継される（最判平3.4.19）。
  - 正解：○（正しい）
  - 理由：最判平3.4.19の到達点。原則＝遺産分割方法の指定、効果＝死亡時に直ちに単独承継（分割協議不要）。現行法はこれを特定財産承継遺言（1014条2項）として明文化した。両小問の共通の出発点になる。
- **［○×クイズ 4/10］** 899条の2第1項によれば、相続による権利の承継は、法定相続分の範囲内の部分も含め、登記等の対抗要件を備えなければ第三者に対抗することができない。
  - 正解：×（誤り）
  - 理由：対抗要件を要するのは法定相続分を超える部分だけ（899条の2第1項）。法定相続分に応じた承継は当然の承継で、登記なくして権利を保持できる。「全部に登記が必要」とすると誤り。本問でBが登記を要するのは1/2を超える部分である。
- **［○×クイズ 5/10］** 相続分を超える権利承継につき対抗要件を要求される「第三者」には、相続債権者や、相続人の持分を差し押さえた差押債権者など、遺言の有無・内容を知り得ない者が含まれる。
  - 正解：○（正しい）
  - 理由：899条の2の「第三者」は、遺言の有無・内容を知り得ない相続債権者・債務者・持分の譲受人・差押債権者等を広く含む（取引安全の保護）。本問のEは代位で相続登記をした上でCの持分を差し押さえた差押債権者で、これに当たる。
- **［○×クイズ 6/10］** 相続させる旨の遺言による権利取得は法定相続分の相続と同様であるから、改正後の現行法でも、受益相続人は登記なくしてその取得の全部を第三者に対抗することができる。
  - 正解：×（誤り）
  - 理由：これは改正前の判例（最判平14.6.10）の立場。平成30年改正で899条の2が新設され、法定相続分を超える部分は対抗要件が必要となり、判例は実質的に変更された。現行法で「登記なくして全部対抗できる」は誤り。
- **［○×クイズ 7/10］** 受益相続人が遺言者より先に死亡した場合、相続させる旨の遺言は遺産分割方法の指定として法定相続分の相続に近いから、当然に代襲相続が生じ、代襲者が当該遺産を取得する。
  - 正解：×（誤り）
  - 理由：性質論からそのまま代襲を肯定するのは判例の採らない処理。判例は遺言者の意思解釈により、特段の事情のない限り遺言は失効する（原則否定説・最判平23.2.22）。もっとも本問では、遺言失効の結果として法定相続の場面でBの子Dの代襲相続（887条2項）が働く点は別問題である。
- **［○×クイズ 8/10］** 相続させる旨の遺言が受益相続人の先死により失効した場合、当該遺産は被相続人の遺産として法定相続の対象となり、先死した受益相続人の子は代襲相続人となりうる（887条2項）。
  - 正解：○（正しい）
  - 理由：遺言が失効すると甲土地はAの遺産として法定相続の対象になる（896条・898条）。相続人は子Cと、先死したBを代襲するその子D（887条2項）で、相続分は各1/2（900条4号）。設問は「誰に帰属するか」なので、この帰属計算まで書き切る。
- **［○×クイズ 9/10］** 特定遺贈による不動産取得を第三者に対抗するには、受遺者は登記を備える必要がある（177条・最判昭39.3.6）。
  - 正解：○（正しい）
  - 理由：遺贈は受遺者と第三者が対抗関係に立ち、177条により登記が必要（最判昭39.3.6）。他方、相続させる旨の遺言（遺産分割方法の指定）は、改正後は超過部分につき899条の2で対抗要件を要する。両者は「登記がいる」点で接近したが、条文の根拠が異なる。
- **［○×クイズ 10/10］** 相続放棄をした者の持分について、他の相続人が法定相続分を超えて取得する部分は、899条の2により登記を備えなければ第三者に対抗できない。
  - 正解：×（誤り）
  - 理由：相続放棄は遡及効により初めから相続人でなかったものとみなされ（939条）、その効果は登記なくして第三者に対抗できる（最判昭42.1.20）。放棄は899条の2の枠外＝別扱いで、判例は改正後も維持されている。承継態様の横断整理で混同しやすい一点。
