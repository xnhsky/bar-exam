### 骨子（3項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　設問1①（C悪意・D善意）― A→D 甲土地明渡請求

1. AB間は仮装売買 → 94条1項で無効・Bは無権利 → 原則Aの請求は認められる
2. Dは転得者 → 【論点】転得者も「第三者」（94条2項）か（規範：第三者の意義＋転得者を含む・最判昭45.7.24）
3. 【論点】善意の意義・登記の要否 → 善意で足り無過失不要／登記不要
4. 「Dは知らなかった」＝善意／名義はCのまま＝未登記でも保護
- 結論：D＝善意の第三者として保護 ＝ Aの明渡請求は認められない

#### 第2　設問1②（C善意・D悪意）― A→D 甲土地明渡請求

1. D悪意 → 自己を「善意の第三者」とする主張は不可
2. C善意で確定的に権利取得 → 【論点】善意者Cを経た悪意転得者Dの保護（規範：絶対的構成・大判昭6.10.24）
   - あてはめ：わら人形（意図的介在）なら信義則・権利濫用で制限 ─ 本問は事情なし
3. DはCの地位を承継して権利取得
- 結論：Aの明渡請求は認められない（なお相対的構成ならA勝訴）

#### 第3　設問2（G善意／H＝Eからの譲受人）― G→H 乙土地明渡請求

1. EF間は仮装 → 94条1項で無効／Gは善意の第三者（94条2項）
2. Hは真の権利者Eからの譲受人 → 【論点】Gと真の権利者からの譲受人Hの優劣（規範：94条2項の効果＝権利移転類似→二重譲渡類似→対抗関係177条・登記の先後・最判昭42.10.31）
3. 名義はFのまま＝G・Hとも登記未了 → 互いに対抗不可
- 結論：Gの明渡請求は認められない（H→Gも同様）

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「Dは知らなかった」 → 設問1①のDの善意
- 【拾う事実】「Cは知らなかった」＋「Dは知っていた」 → 設問1②＝C善意・D悪意（絶対的構成へ）
- 【拾う事実】「登記名義はCのまま」 → D未登記（第三者に登記不要の当てはめ）
- 【拾う事実】『「真の権利者Eから」Hが譲受』 → Hは転得者でない＝二重譲渡類似
- 【拾う事実】「登記名義はFのまま」 → G・Hとも未登記（対抗要件不具備）
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 1項無効＝「差押え回避／固定資産税回避のため」と目的まで書いてある＝通謀虚偽表示は明らか＝一言で切る。争いは全部2項側。前さばきは必ず通すが、争いが無ければ一文でよい。
- 【効く事実】あてはめで使う事実
  - ①D善意 → 「Dは知らなかった」を直接引用／D未登記 → 名義はCのまま／② D悪意 → 「Dは知っていた」だがC善意＝Cが確定的取得 → DはCの地位を承継。
- 【規範の要点】権利移転類似構成の規範
  - 94条2項で真の権利者EはGに無効を対抗できず、E→G直接移転類似。EがさらにHへ譲渡 → E→G・E→Hの二重譲渡類似 → GとHは対抗関係（177条）、優劣は登記の先後（最判昭42.10.31）。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 同じ「94条2項の第三者」でも、相手が真の権利者本人なら前主後主＝登記不要（設問1）、相手が真の権利者から買った別人なら二重譲渡類似＝登記必要（設問2）。誰と争うかで登記の要否が切り替わる、と一文で締める。
- 【まぎらわしい選択肢・論点】即時取得の成否／背信的悪意者の排除／表見代理の成否
- 【まぎらわしい選択肢・結論】Aの明渡請求 認められる／Gの明渡請求 認められる
- 【まぎらわしい選択肢・規範】無過失必要説／相対的構成／権利保護要件説
- 【まぎらわしい選択肢・事実】登記を備えている／意思連絡あり

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

設問1①＝1項無効、Dは転得者でも第三者、善意で足り登記不要＝D保護でA敗訴。設問1②＝D悪意でも善意Cの地位を承継（絶対的構成）、わら人形なし＝D保護でA敗訴。設問2＝Gは善意の第三者、Hは真の権利者から譲受＝二重譲渡類似の対抗関係、双方未登記＝Gの請求は認められない。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 94条2項の「第三者」の意義（定義）と、転得者が含まれるかを規範として述べよ。
  - 模範解答：「第三者」＝虚偽表示の当事者及びその包括承継人以外の者で、虚偽表示に基づき新たに独立の法律上の利害関係を有するに至った者。保護根拠（外観信頼）は転得者にも妥当するから、転得者も含む（最判昭45.7.24）。
- **［規範クイズ 2/3］** 善意者を経由した悪意の転得者の保護について、絶対的構成の内容と例外（歯止め）を述べよ。
  - 模範解答：善意の第三者の出現により権利関係は確定し、転得者はその善意悪意を問わず善意者の地位を承継取得する（絶対的構成）。もっとも、悪意者が意図的に善意者を介在させた「わら人形」型では、信義則（1条2項）・権利濫用（1条3項）で権利取得を否定しうる。
- **［規範クイズ 3/3］** 94条2項の善意の第三者と、真の権利者からの譲受人との優劣を決する規範と、双方未登記のときの帰結を述べよ。
  - 模範解答：94条2項の効果＝真の権利者から第三者への直接移転類似。真の権利者からの譲受人とは二重譲渡類似の対抗関係となり、優劣は登記の先後で決する（177条・最判昭42.10.31）。双方未登記なら互いに対抗できず、物権的請求は認められない。

## 4. ○×クイズ（全11問・1問目から最後まで全部出す）

- **［○×クイズ 1/11］** 通謀虚偽表示（94条1項）による無効は、当事者間では原則として誰でも主張できるが、善意の第三者に対しては対抗することができない。
  - 正解：○（正しい）
  - 理由：94条1項の無効は原則として誰との関係でも主張できる（絶対的無効）が、2項が「前項の規定による意思表示の無効は、善意の第三者に対抗することができない」として例外を定める。だから検討の的は「誰が2項の第三者に当たるか」に絞られる。
- **［○×クイズ 2/11］** 94条2項の「第三者」として保護されるためには、虚偽表示について善意であることに加え、無過失であることを要する。
  - 正解：×（誤り）
  - 理由：94条2項は「善意」とのみ規定し、96条3項（詐欺取消し。「善意でかつ過失がない」）と異なり無過失を要求しない。自ら虚偽の外観を作り出した真の権利者の帰責性は大きいので、第三者は善意で足りるとするのが判例・通説。文言の違いが結論を分ける。
- **［○×クイズ 3/11］** 通謀虚偽表示が94条1項により無効である場合、仮装譲受人から目的物を譲り受けた者は、原則として無権利者からの譲受人であり、そのままでは目的物の権利を取得できない。
  - 正解：○（正しい）
  - 理由：1項で仮装譲渡が無効なら仮装譲受人は無権利者。無権利者からは権利を承継取得できない（無権利の法理）のが原則で、これが出発点。94条2項はこの原則の例外として、善意の第三者に限り権利取得を認める仕組み。まず原則（無権利）を確認してから例外（2項）へ進むのが筋。
- **［○×クイズ 4/11］** 94条2項の「第三者」とは、虚偽表示の当事者及びその包括承継人以外の者であって、虚偽表示に基づき新たに独立の法律上の利害関係を有するに至った者をいう。
  - 正解：○（正しい）
  - 理由：これが「第三者」の定義。ポイントは虚偽の外観を信頼して新たに取引関係に入ったこと。単なる一般債権者や不動産の差押え前の債権者などは「新たな独立の利害関係」に欠け該当しない。定義を正確に書けるかが規範段階の要。
- **［○×クイズ 5/11］** 94条2項の「第三者」には、仮装譲受人から直接に権利を取得した者に限られ、その者からさらに目的物を取得した転得者は含まれない。
  - 正解：×（誤り）
  - 理由：虚偽の外観を信頼して取引に入ったという保護根拠は、直接の第三者でも転得者でも変わらない。判例は転得者も「第三者」に含めて保護する（最判昭45.7.24）。「Dは転得者だから2項の話ではない」と早合点して論点を落とすのが典型ミス。
- **［○×クイズ 6/11］** 94条2項の善意の第三者として保護されるためには、その第三者が目的物について対抗要件である登記を備えていることが必要である。
  - 正解：×（誤り）
  - 理由：真の権利者と94条2項の第三者とは前主・後主の関係に立ち、対抗関係（177条）に立たない。だから第三者は登記を備えなくても保護される（最判昭44.5.27）。本問のDは名義がCのままの未登記でも保護される。ただし設問2の「別ルートの譲受人との対抗」とは局面が違う（そこは登記必要）ので混同注意。
- **［○×クイズ 7/11］** 善意の第三者が虚偽表示の目的物について権利を取得した後、その者から目的物を譲り受けた転得者は、たとえ悪意であっても、善意者の地位を承継して権利を取得する（絶対的構成）。
  - 正解：○（正しい）
  - 理由：善意者の出現で権利関係は確定し、目的物はいわば"洗浄"される。以後の転得者は主観を問わず善意者の地位を承継取得する（絶対的構成・大判昭6.10.24）。法律関係を各人の主観で分断すると不安定になり取引安全を害するためである（これが絶対的構成の規範の趣旨）。設問1②のD（悪意）が救われる筋がこれ。
- **［○×クイズ 8/11］** 絶対的構成を貫くと悪意者が善意者をわざと間に挟んで権利を得る濫用（わら人形）を招くため、そのような意図的介在の事案では信義則・権利濫用により転得者の権利取得が否定されうる。
  - 正解：○（正しい）
  - 理由：絶対的構成の「歯止め」。原則は絶対的構成でD保護だが、悪意者が善意者を道具のように使った濫用型は信義則（1条2項）・権利濫用（1条3項）で例外的に否定する。本問には意図的介在の事情がないので歯止めは働かず、原則どおりD保護。例外に一言触れて「本問は事情なし」と限定できると加点。
- **［○×クイズ 9/11］** 94条2項の善意の第三者と、虚偽表示をした真の権利者からその目的物を譲り受けた者とは対抗関係に立ち、両者の優劣は登記の先後によって決せられる。
  - 正解：○（正しい）
  - 理由：94条2項の効果を「E→Gへ直接権利が移転したのと同様」と構成すると、EがHへも譲渡した場面はE起点の二重譲渡類似になり、GとHは対抗関係（177条）に立つ（最判昭42.10.31）。設問1の「第三者に登記不要（前主後主）」とは当事者関係が違うので、ここは登記が必要になる。
- **［○×クイズ 10/11］** 対抗関係に立つ二重譲渡類似の関係において、双方とも登記を備えていない場合には、先に目的物の引渡しを受けて占有している者が当然に優先する。
  - 正解：×（誤り）
  - 理由：不動産の対抗関係の優劣は登記の先後で決する（177条）。双方が登記を備えていなければ、いずれも相手に物権変動を対抗できず、互いに明渡し等を請求できない（引渡し・占有では決まらない）。本問はGもHも未登記なのでGの請求は認められない。
- **［○×クイズ 11/11］** 同じ94条2項の第三者でも、真の権利者本人に対しては登記なくして権利を主張でき、真の権利者から別に譲り受けた者に対しては登記の先後で優劣が決まる。この違いは当事者関係（前主後主か二重譲渡類似か）の差で説明される。
  - 正解：○（正しい）
  - 理由：「登記不要（最判昭44.5.27）」と「登記必要（最判昭42.10.31）」は矛盾しない。真の権利者との関係は前主後主＝対抗関係でないから登記不要、真の権利者からの譲受人との関係は二重譲渡類似＝対抗関係だから登記必要。誰と争うかで切り替わるという一貫理解を示せると上位。
