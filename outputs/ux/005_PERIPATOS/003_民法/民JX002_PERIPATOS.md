## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

一般社団法人Yの定款では、固定資産の取得又は処分については理事会の承認を必要とする旨定められていた。Yの代表理事Aは、資金繰りに窮していたYの資金を調達するため、Yを代表して、理事会の承認を得ないまま、Xに対して、Y所有の甲土地を1000万円で売却した（以下「本件売買契約」という。）。Xは、これをBに1200万円で転売する契約を締結した。なお、Xは、本件売買契約の際、Aに対して、甲土地をBに1200万円で転売する予定であることを伝えていた。しかし、Yは、理事会の承認がないことを理由として、甲土地をXに引き渡さず、登記名義をXに移転することもしない。なお、Xは、本件売買契約以前にYとの間で乙土地の売買をしたことがあったため（乙土地の売買では、理事会の事前の承認を得ていた。）、本件売買契約当時、上記定款の存在を知っていた。そこで、Xは、本件売買契約の際、Aに対して、理事会の承認決議書の閲覧を要求したが、Aが乙土地の売買の際に作成した承認決議書と同じ書式を用いて偽造した承認決議書を提示したため、理事会の承認があると信じ込んでいた。XがYに対して、いかなる請求をすることができるかについて、論じなさい。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 乙土地の売買（理事会の事前承認あり）→ Xは定款の存在を知る
- 本件甲土地売買：Aが承認なしで売却／Xが承認決議書の閲覧要求
- Aが乙土地と同一書式で偽造した承認決議書を提示 → Xは承認ありと誤信
- XがBへ1200万円で転売契約（差益200万・予定はAに告知済み）
- Yが承認欠缺を理由に引渡し・登記移転を拒絶

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「固定資産の取得又は処分には理事会の承認を必要とする」 → 代表権に加えた制限（77条5項・110条類推の起点）
- 【拾う事実】『「理事会の承認を得ないまま」売却』 → 承認欠缺＝一種の無権代表・効果不帰属の原則
- 【拾う事実】『乙土地取引を通じ「定款の存在を知っていた」』 → Xは悪意（77条5項で切れる）
- 【拾う事実】『乙土地売買と「同じ書式を用いて偽造した承認決議書を提示」』 → 正当な理由（無過失）を基礎づける中心事実
- 【拾う事実】「承認決議書の閲覧を要求した」 → 調査義務の履践（無過失の評価）
- 【拾う事実】『Bへ「1200万円で転売する予定であることを伝えていた」』 → 賠償範囲（416条類推）の予見可能性
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 売買の成立＝目的物・代金の合意あり＝争いなしで一文。引渡し・登記請求権の発生＝債権的効果として当然。要件事実論のように細かく認定しない。詰まるのは「承認欠缺の効果」と「悪意のXをどう救うか」の2点だけ。
- 【効く事実】「110条類推正当な理由が」のあてはめで使う事実
  - 正当な理由（＝信頼＋無過失）→ Aが乙土地取引と同一書式で偽造した承認決議書を提示／Xは承認決議書の閲覧を要求して調査を尽くした／過去取引と同じ書式ゆえ疑うきっかけがない。悪意の認定 → 乙土地取引を通じ定款を知っていた。
- 【規範の要点】外形標準説の規範
  - 「その職務を行うについて」とは、行為の外形から客観的に観察して職務の範囲内の行為と認められる場合を包含する（外形標準説）→ 資金調達目的の不動産売却は外形上代表理事の職務に属し、Xに悪意・重過失もない＝該当。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 一つの利益状況に複数の手段が併存する（錯誤取消と契約不適合責任のように）ときは、最後に優先関係を一言整理すると答案が締まる。①110条優先／②選択自由／③110条不成立時のみ78条 ── 理由を付せばどれでもよい。長く論じない。
- 【まぎらわしい選択肢・論点】94条2項類推の可否／表見代理109条の成否／錯誤取消の可否
- 【まぎらわしい選択肢・結論】履行請求は認められない／損害賠償請求のみ認められる
- 【まぎらわしい選択肢・規範】制限解除不知説／主観説
- 【まぎらわしい選択肢・事実】Xは定款を知らなかった／承認決議書は真正だった

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

履行＝承認欠缺で効果不帰属が原則、Xは定款を知る悪意で77条5項ダメ、でも偽造決議書を信じた正当理由で110条類推、効果帰属で引渡し・登記OK。損賠＝Aの偽造は709条、外形標準説で「職務を行うについて」該当、416条類推で200万。両立＝110条（履行）優先で履行請求のみ。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 法77条5項の「善意」の意義（判例）を述べ、その「善意」に当たらない相手方をなお救いうる枠組みを挙げよ。
  - 模範解答：「善意」＝代表権に制限が加えられていること（＝制限の存在）を知らないこと（最判昭60.11.29）。制限を知る悪意者でも、必要な手続（理事会の承認等）を経て適法に代表する権限があると信じ、かつそう信じるにつき正当な理由があれば、民法110条を類推適用して効果を法人に帰属させる。
- **［規範クイズ 2/3］** 制限の存在を知る（＝77条5項では善意でない）相手方を、なお法人に効果帰属させて保護する民法110条類推の規範を述べよ。
  - 模範解答：制限の存在を知る第三者であっても、代表者が必要な手続を経て適法に法人を代表する権限を有すると信じ、かつそう信じるにつき正当な理由があるときは、取引の安全を図る民法110条の趣旨が妥当する。そこで同条を類推適用し、代表行為の効果を法人に帰属させる。「正当な理由」＝信頼＋無過失。
- **［規範クイズ 3/3］** 法人の不法行為責任（法78条・民法715条）における「職務を行うについて／事業の執行について」の判断基準（外形標準説）を、除外事由まで含めて述べよ。
  - 模範解答：行為の外形から客観的に観察して職務（事業）の範囲内の行為と認められる場合を含む。代表者が職務権限を逸脱していても、また自己・第三者の利益を図る意図でも該当しうる。ただし取引的不法行為では、相手方がその行為が職務の範囲外であることを悪意又は重過失で知った場合は、保護すべき信頼がなく除外される。

## 4. ○×クイズ（全7問・1問目から最後まで全部出す）

- **［○×クイズ 1/7］** 一般社団法人の定款で代表理事の代表権に加えられた制限に違反してされた代表行為は、代表権のない者の行為に準じ、原則として法人に効果が帰属しない。
  - 正解：○（正しい）
  - 理由：定款による代表権の制限に違反した代表行為は、代表権のない者の行為に準じるものとして、原則として本人たる法人に効果が帰属しない（民法113条1項類推）。これが相手方（買主）の請求を阻む「Yの反論」の骨格。ここを出発点に据え、そのうえで第三者保護（77条5項・110条類推）へ進む。
- **［○×クイズ 2/7］** 一般社団・財団法人法77条5項にいう「善意」とは、代表権に制限があること自体は知りつつ、今回はその制限が解除された（承認を得た）と信じたことをいう。
  - 正解：×（誤り）
  - 理由：これは少数説（制限解除不知説）の理解。判例（最判昭60.11.29）・通説は、77条5項の「善意」を代表権に制限が加えられていること（制限の存在）を知らないこととする（制限存在不知説）。制限を知りつつ「今回は承認を得た」と信じたにすぎない者は、なお「善意」にあたらず、救済は民法110条類推に委ねられる。
- **［○×クイズ 3/7］** 株式会社の代表取締役の代表権に加えた制限も、善意の第三者に対抗することができない（会社法349条5項）。これは一般社団法人の代表理事に関する法77条5項と同趣旨である。
  - 正解：○（正しい）
  - 理由：会社法349条4項・5項は、法77条4項・5項と対をなす同趣旨の規定で、判例法理（善意＝制限存在の不知、悪意者には110条類推）も共通する。株式会社の代表取締役の事案でも同じ枠組みが妥当する。法人横断の取引安全の準則として整理しておくと応用が利く。
- **［○×クイズ 4/7］** 定款で代表理事の権限に制限を定めておけば、法人はその制限を、制限の存在を知らない第三者に対しても対抗することができる。
  - 正解：×（誤り）
  - 理由：法77条5項は「前項の権限に加えた制限は、善意の第三者に対抗することができない」と定める。制限の存在を知らない善意の第三者には対抗できず、その者との関係では代表行為の効果が法人に帰属する。定款・登記による制限を常に対抗できるわけではない（取引安全の要請）。悪意の第三者には対抗でき、その者の救済は110条類推に移る。
- **［○×クイズ 5/7］** 民法110条にいう「正当な理由」とは、第三者が代理人（代表者）に権限があると信じ、かつそう信じることについて過失がないことをいう。
  - 正解：○（正しい）
  - 理由：110条の「正当な理由」は、権限ありと信じたこと（信頼）＋そう信じたことに過失がないこと（無過失）で判断する。本問では、Xが偽造承認決議書を信じたことに過失があるかが核心。閲覧要求という調査の履践、過去取引と同一書式で疑う事情がない点を無過失の評価語と結合させて正当理由を肯定する。
- **［○×クイズ 6/7］** 一般社団・財団法人法78条にいう「その職務を行うについて」は、代表者が定款上の権限の範囲内で適法に行為した場合に限られ、権限を逸脱した行為はこれに含まれない。
  - 正解：×（誤り）
  - 理由：判例（外形標準説）は、「職務を行うについて」を行為の外形から客観的に判断し、職務権限を逸脱した行為や自己・第三者の利益を図る意図の行為も含むとする。相手方の信頼保護のためで、相手方が範囲外を悪意・重過失で知った場合のみ除外する。承認欠缺・偽造という権限逸脱でも、資金調達目的の売却は外形上職務に属する。
