### 骨子（2項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　設問1　A・C間の法律関係

1. 売掛代金債権をC・Dへ二重譲渡＋確定日付通知が同時到達 → 【論点】確定日付通知の同時到達の処理（規範：各譲受人が全額請求可）
   - あてはめ：到達時説では優劣不能（最判昭49.3.7）→ 同時到達＝各自全額の債権者たる地位（最判昭55.1.11）→ Cは債権者
2. Cの相殺（売掛代金債権×貸金債務＝相殺適状あり）／Aの相殺（BへのA貸金債権は具備時より前に取得＝469条1項で対抗可）
3. 【論点】逆相殺の優劣 → 相殺の意思表示の先後で決する（最判昭54.7.10）
   - あてはめ：Cが先に意思表示 → C優先。Aの相殺は対立債権を欠き効力なし
- 結論：Cの相殺で売掛代金債権とCの貸金債務が対当額消滅 ＝ Aの相殺の主張は認められない

#### 第2　設問2　Fの主張の当否

1. GのFへの報酬請求に対しFは解除を抗弁。解除は具備後の事情
2. 【論点】468条1項「事由」に解除の基礎が含まれるか → 抗弁権発生の基礎となる事由も含む（最判昭42.10.27）
   - あてはめ：譲渡時に反対給付義務（仕事完成義務）が未履行＝具備時までに事由あり → F対抗可
3. 【論点】Gは545条1項ただし書の「第三者」か → 消滅する債権そのものの譲受人は含まない（大判明42.5.14）→ G非該当
- 結論：Fは解除をGに対抗でき ＝ Fの主張は認められる

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「通知は同時にAに到達」 → 優劣を決められない（同時到達の処理へ）
- 【拾う事実】『「Cは……Aは……相殺」の順』 → 相殺の意思表示の先後（優劣の基準）
- 【拾う事実】『AのBへの貸金債権は譲渡前から存在』 → 469条1項「具備時より前に取得」該当
- 【拾う事実】『譲渡時に工事の約半分／残りの未成工事部分』 → 未履行状態が具備時までに存在（468条の事由）
- 【拾う事実】『Gは消滅する報酬債権そのものの譲受人』 → 545条1項ただし書「第三者」から除外
- 【ポイント】攻防で読む
  - 設問1「A・C間の法律関係」は問題文に書かれていないが、AのCへの貸金返還請求に対しCが相殺で抗弁し、Aがさらに相殺で再反論する、という掛け合い（逆相殺）を前提に読むと収まりがよい。
- 【効く事実】「同時到達＋逆相殺」のあてはめで使う事実
  - 同時到達 → 「確定日付ある通知が同時にAへ到達」で優劣不能。逆相殺の優劣 → 「Cが先に相殺の意思表示」を直接引用。
- 【ポイント】防御線は2本ある
  - 468条でFが勝っても、Gが「自分は545条の第三者だ」と粘れる。ここを潰さないと結論が出ない。468条（抗弁対抗）と545条（第三者）は別個の防御線として独立に検討する。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 467条・468条・469条・545条は一見バラバラだが、「譲渡前に債務者が持っていた地位を、譲渡で奪わない」という一本の糸で貫かれている。
- 【まぎらわしい選択肢・論点】債権者不確定による供託の可否／差押えと相殺の優劣／将来債権譲渡の有効性
- 【まぎらわしい選択肢・結論】Aの相殺が優先し貸金債権全額が存続／Fの主張は認められない
- 【まぎらわしい選択肢・規範】相殺適状先後説／按分説
- 【まぎらわしい選択肢・事実】確定日付の先後／解除権が具備時までに発生

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

設問1＝二重譲渡・同時到達で各自全額請求可（Cは債権者）、Cの相殺（適状あり）・Aの相殺（469条で対抗可）、優劣は意思表示の先後でCが先＝C優先。設問2＝解除は具備後だが「事由」＝基礎となる事由も含む（未履行状態あり）でF対抗可、Gは消滅する債権の譲受人＝545条の第三者でない、よってFの主張は認められる。

## 3. 規範クイズ（全4問・1問目から最後まで全部出す）

- **［規範クイズ 1/4］** 債権が二重に譲渡され、確定日付ある各譲渡通知が債務者に同時に到達した場合の、各譲受人の地位を規範で述べよ。
  - 模範解答：各譲受人は、第三債務者に対しそれぞれの譲受債権について全額の弁済を請求できる。弁済の請求を受けた第三債務者は、他の譲受人への弁済等の債務消滅事由がない限り、単に同順位の譲受人が他に存在することを理由に弁済を免れることはできない（最判昭55.1.11）。債務者に対する対抗要件は通知で足りる（467条1項）以上、履行を免れる理由がないためである。優劣を決する発想を捨て、各自が全額の債権者たる地位を主張できると扱うのが結論である。
- **［規範クイズ 2/4］** 同一の受働債権をめぐって複数の相殺が衝突する場合（逆相殺）の、優劣の判断基準を規範で述べよ。
  - 模範解答：相殺適状は原則として相殺の意思表示時に現存を要するから、優劣は相殺適状に達した先後ではなく、相殺の意思表示の先後によって決する（最判昭54.7.10）。先に意思表示をした者の相殺で受働債権が遡及的に消滅すれば、後行の相殺は対立債権を欠き効力を生じない。債権回収に勤勉であった者を保護するという価値判断にも整合する。
- **［規範クイズ 3/4］** 468条1項の「対抗要件具備時までに……生じた事由」の「事由」の範囲を、規範で述べよ。
  - 模範解答：「事由」とは、既発生の抗弁や抗弁権の発生原因にとどまらず、抗弁権発生の基礎となる事由も含む（最判昭42.10.27）。譲渡通知のみによって債務者を従前より不利益な地位に置くべきでないからである。請負では、譲渡時に反対給付義務（仕事完成義務）が既に発生し未履行状態にあれば、後の解除も具備時までに生じた「事由」に基づくものとして対抗できる。
- **［規範クイズ 4/4］** 545条1項ただし書の「第三者」の意義（保護される者の範囲）を規範で述べよ。
  - 模範解答：解除された契約から生じた法律効果を基礎として、解除までに新たな利害関係を取得した者をいい、解除によって消滅する債権そのものの譲受人は含まれない（大判明42.5.14）。含めれば、債権が譲渡された途端に解除が無意味になり、解除制度が機能しなくなるからである。

（規範クイズはここまで＝全4問。最後の4問目まで出したら「規範クイズ、全4問クリア！」と言って次へ）

## 4. ○×クイズ（全7問・1問目から最後まで全部出す）

- **［○×クイズ 1/7］** 債権譲渡を債務者に対抗するには通知又は承諾で足り確定日付を要しないが、債務者以外の第三者に対抗するには確定日付のある証書による通知・承諾を要する（467条1項・2項）。
  - 正解：○（正しい）
  - 理由：467条は対抗要件を二段に分ける。債務者対抗要件＝通知・承諾（1項）、第三者対抗要件＝確定日付ある証書による通知・承諾（2項）。二重譲渡の優劣（設問1）はこの第三者対抗要件どうしの競合として現れる。
- **［○×クイズ 2/7］** 同一債権が二重に譲渡され、確定日付ある各譲渡通知が債務者に同時に到達したときは、各譲受人は互いに優劣を主張できないため、債権額を頭割りで按分した割合の限度でのみ弁済を請求できる。
  - 正解：×（誤り）
  - 理由：按分説は判例・通説の採らない立場。同時到達では優劣を決する発想を捨て、各譲受人が全額の弁済を請求できる（最判昭55.1.11）。債務者への対抗要件は通知で足りる以上（467条1項）、履行を免れる理由がないからである。
- **［○×クイズ 3/7］** 相殺をするには、原則として、相殺の意思表示がされた時に相殺適状（対立する両債権が現存し弁済期にあること）が現存していなければならない。
  - 正解：○（正しい）
  - 理由：相殺適状は原則として相殺の意思表示時に現存を要する。506条2項の遡及効は「効果」が相殺適状時に遡るという話にすぎず、意思表示の時点で対立債権が消えていれば相殺はできない（508条はその例外）。この理解が設問1後段の逆相殺の優劣を決める鍵になる。
- **［○×クイズ 4/7］** 債務者が譲渡人に対して有していた債権による相殺を譲受人に対抗できるかは、抗弁一般の対抗を定める468条1項ではなく、相殺について特に定めた469条によって判断する。
  - 正解：○（正しい）
  - 理由：抗弁一般の対抗が468条1項、そのうち相殺という特殊な抗弁の対抗を特に定めたのが469条。設問1後段（相殺）は469条、設問2（解除）は468条1項という条文の振り分けを意識すると答案が締まる。
- **［○×クイズ 5/7］** 相殺の意思表示は相殺適状を生じた時に遡って効力を生じる（506条2項）から、いったん相殺適状が生じていれば、その後に自働債権が弁済等によって消滅した後であっても、相殺の意思表示をすることができる。
  - 正解：×（誤り）
  - 理由：506条2項の遡及効は効果が相殺適状時に遡るという意味にすぎず、相殺適状は意思表示の時点で現存していなければならない。意思表示前に一方の債権が消滅していれば相殺は許されない（508条はその例外規定）。この理解が「意思表示の先後で優劣を決する」結論（最判昭54.7.10）を支える。
- **［○×クイズ 6/7］** 解除によって消滅する債権そのものの譲受人は、解除の遡及効から第三者を保護する545条1項ただし書の「第三者」には当たらない。
  - 正解：○（正しい）
  - 理由：545条1項ただし書が保護するのは、解除の遡及効で覆される目的物・権利について新たな利害関係を取得した者（例：解除された売買の目的物の転得者）である。消滅すること自体が予定されている債権の譲受人まで保護すると、債権譲渡により解除が骨抜きになる。ゆえに消滅する債権の譲受人は「第三者」に含まれない（大判明42.5.14）。
- **［○×クイズ 7/7］** 468条・469条は、いずれも「債務者は債権譲渡によって従前より不利益な地位に置かれない」という同一の原理の現れであり、譲渡前に債務者が有していた抗弁や相殺の期待を保護する趣旨である。
  - 正解：○（正しい）
  - 理由：債権譲渡は債務者の関与なく行われるから、譲渡によって債務者の地位を悪化させてはならない。468条（抗弁一般の対抗）も469条（相殺の対抗）も、この債務者保護の原理を具体化した規定であり、両者の役割分担（相殺は469条・その他の抗弁は468条）もこの原理から理解できる。
