### 骨子（2項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　小問(1)　AのBに対する乙建物収去・甲土地明渡請求

1. 根拠＝甲土地賃貸借の終了（【論点】建物譲渡で敷地賃借権も随伴：87条2項類推）
2. 譲渡担保は612条の「譲渡」か → 【論点】使用収益基準（規範：譲渡担保権者が引渡しを受け現実に使用収益すれば譲渡・転貸）
   - あてはめ：Cは鍵を即返還・居住中止 → 使用主体の現実的交替なし
3. 仮に612条充足でも → 【論点】信頼関係破壊の法理（規範：背信的行為と認めるに足りない特段の事情）
   - あてはめ：賃料・返済に滞りなし／要求に逆らいがたく／即中止＝特段の事情
- 結論：解除不可 ＝ Aの主張は認められない

#### 第2　小問(2)　DのBに対する法律関係

1. D＝甲土地の新所有者、所有権に基づき乙建物収去・甲土地明渡請求
2. 【論点】他人名義（C名義）建物登記の対抗力 → 肯定説（譲渡担保権者名義でも対抗力肯定）
   - あてはめ：D対抗時に乙建物はなおC名義（自己名義回復はD登記の後）→ BはDに借地権を対抗可
3. 【論点】賃貸人たる地位の移転 → 605条の2第1項・3項（Dは移転登記ありで地位取得・対抗）
4. 【論点】解除権の移転 → 契約上の地位の移転（包括承継）（Aの下で解除権発生が前提）
5. Cの1か月居住で使用収益明白＝612条充足 → だが短期・AはC居住を不認識＝特段の事情
- 結論：解除不可・ただし賃料請求可 ＝ Dは明渡請求できない（賃料請求は可）

- 【拾う事実】『担保目的で乙建物をCへ譲渡・C名義登記』 → 「譲渡」該当性・対抗力を起動
- 【拾う事実】『〔(1)〕鍵を渡したが即返還・居住中止』 → 使用主体の交替の有無（微妙）
- 【拾う事実】『賃料・返済とも滞りなし／要求に逆らいがたく』 → 背信性を否定する特段の事情
- 【拾う事実】『〔(2)〕Cが1か月居住』 → 使用収益は明白（(1)と差）
- 【拾う事実】『〔(2)〕D対抗時に乙建物はなおC名義』 → 他人名義登記の対抗力を起動
- 【拾う事実】『〔(2)〕AはC居住を1か月認識せず』 → 背信性評価・権利濫用否定の材料
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 詰まるのは612条の「譲渡」該当性と使用収益の有無だけ。
- 【効く事実】小問(1)で効く事実
  - 使用収益 → 鍵を渡したが、明渡請求を受けると直ちに居住を中止させ、その場でCから鍵の返還を受けた＝使用主体の現実的交替なし。信頼関係 → 賃料50万・返済いずれも滞りなし／Cの要求に逆らいがたく引き渡した／即中止。事実は必ず評価語（「使用主体が交替したとはいえない」「背信的行為と認めるに足りない」）と結合させる。
- 【規範の要点】3段の規範
  - ①借地借家法10条1項の建物登記は借地権者自身の所有権登記を要し、他人名義では公示不十分（最大判昭41.4.27）。もっとも譲渡担保権者名義は担保化の途を閉ざさぬよう対抗力を肯定（肯定説）→ BはDに借地権を対抗できる。②対抗要件を備えた不動産の譲渡で賃貸人たる地位はDに移転し（605条の2第1項）、対抗には所有権移転登記を要する（同条3項）。③地位の移転は契約上の地位の移転＝Aの下で発生した解除権もDに移転する。
- 【まぎらわしい選択肢・論点】即時取得（192条）の成否／法定地上権の成否／背信的悪意者排除
- 【まぎらわしい選択肢・結論】Aの主張は認められる／Dは明渡請求できる
- 【まぎらわしい選択肢・規範】所有権的構成説／対抗力否定説（例外なし）
- 【まぎらわしい選択肢・事実】Aの承諾あり／賃料の不払

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

小問(1)＝建物譲渡で敷地賃借権も随伴（87条2項類推）、譲渡担保でも譲渡担保権者が使えば無断譲渡（使用収益基準）だが鍵を即返還で交替なし＋賃料返済履行で特段の事情＝解除不可・Aの主張認められず。小問(2)＝1か月居住で使用収益明白、C名義でも対抗力肯定（肯定説）→地位移転（605の2）→解除権も移転、だが短期・A不認識で背信性否定＝解除不可・ただしDは賃料請求可。

## 3. 規範クイズ（全4問・1問目から最後まで全部出す）

- **［規範クイズ 1/4］** 借地上建物の譲渡担保が敷地賃借権の「譲渡又は転貸」（612条）に当たるかの判断基準（使用収益基準）を述べよ。
  - 模範解答：612条は信頼関係破壊行為の防止を趣旨とするから、譲渡担保の法的構成いかんを問わず、譲渡担保権者が建物の引渡しを受けて現実に使用又は収益をするときは、敷地の使用主体が交替し信頼関係が破壊されるため「譲渡又は転貸」に当たる。設定者が従前どおり使用する限りは当たらない（最判平9.7.17）。
- **［規範クイズ 2/4］** 612条2項の要件を充たしても解除が制限されうる信頼関係破壊の法理の規範を述べよ。
  - 模範解答：賃貸借は当事者間の信頼関係を基礎とする継続的契約であるから、無断譲渡・転貸があっても、賃借人の行為が賃貸人に対する背信的行為と認めるに足りない特段の事情があるときは、賃貸人は612条2項による解除権を行使しえない（最判昭39.7.28等）。「賃料・返済の履行、無断使用の程度・期間、原状回復の有無」等を総合判断する。
- **［規範クイズ 3/4］** 借地上建物が譲渡担保権者名義で登記されている場合に、借地権者が借地借家法10条1項により借地権を対抗できるかの規範（判例と本問の処理）を述べよ。
  - 模範解答：10条1項の建物登記は借地権の存在を公示するものだから、借地権者自身の所有権登記を要し、他人名義では建物所有権の帰属を公示できず対抗力を欠く（最大判昭41.4.27）。判例は譲渡担保権者名義も他人名義として対抗力を否定するが、これを貫くと借地上建物の担保化の途を閉ざし抵当権設定との均衡を失するため、肯定説（本問の採用）は譲渡担保権者名義でも対抗力を肯定する。
- **［規範クイズ 4/4］** 対抗要件を備えた不動産が譲渡された場合の賃貸人たる地位の移転と、旧賃貸人の下で発生した解除権の移転の規律を述べよ。
  - 模範解答：賃借人が対抗要件を備えた不動産が譲渡されると、賃貸人たる地位は譲受人に移転し（605条の2第1項）、これを賃借人に対抗するには賃貸物の所有権移転登記を要する（同条3項）。賃貸人たる地位の移転は契約上の地位の移転であり契約関係に伴う地位が全体として移転するから、旧賃貸人の下で発生していた解除権も新賃貸人に移転する（前提として旧賃貸人の下で解除権が発生していることを要する）。

（規範クイズはここまで＝全4問。最後の4問目まで出したら「規範クイズ、全4問クリア！」と言って次へ）

## 4. ○×クイズ（全8問・1問目から最後まで全部出す）

- **［○×クイズ 1/8］** 賃貸借契約が終了した場合、賃貸人は、契約の相手方である賃借人に対し、賃貸借の終了に基づく目的物返還請求権として、目的物の返還（土地上の建物の収去・土地の明渡し）を求めることができる。
  - 正解：○（正しい）
  - 理由：契約当事者間では、所有権に基づく請求に加え、賃貸借の終了に基づく目的物返還請求という契約上の筋が立つ。貸主本人（本問A）が請求する小問(1)は、この契約構成が素直。他方、契約関係のない第三者（本問D＝土地の買主）が請求する小問(2)は、まず所有権に基づく請求から入る。「誰が請求するか」で立て方が変わるのが出発点。
- **［○×クイズ 2/8］** 賃借人が賃貸人の承諾を得ずにその賃借権を譲り渡し、第三者に賃借物を現実に使用又は収益させたときは、賃貸人は、賃貸借契約を解除することができる（民法612条）。
  - 正解：○（正しい）
  - 理由：612条1項が無断譲渡・転貸を禁じ、2項が違反に解除権を与える。趣旨は、賃貸借が当事者間の信頼関係を基礎とする継続的契約であり、無断で第三者に使用収益させる行為が信頼関係を破壊する点にある。この趣旨が、後の使用収益基準と信頼関係破壊の法理の理論的な根っこになる。
- **［○×クイズ 3/8］** 借地上の建物とその敷地の賃借権は経済的に一体をなすから、建物の譲渡は、特別の事情がない限り、従たる権利である敷地賃借権の譲渡を伴うと解される（民法87条2項類推）。
  - 正解：○（正しい）
  - 理由：87条2項は「従物は主物の処分に従う」と定め、判例・通説はこれを従たる権利（借地上建物に対する敷地賃借権）にも類推する（最判昭47.3.9）。だから乙建物をCへ譲渡すれば、特段の事情なき限り甲土地の賃借権も随伴して移転し、無断譲渡（612条）の土俵に乗る。この一枚をかませずに「建物を譲渡した→当然明渡し」と飛ぶと大幅減点。
- **［○×クイズ 4/8］** 借地上建物に譲渡担保権が設定された場合、譲渡担保は形式上所有権移転の形をとる以上、譲渡担保権設定者が引き続き建物を使用していても、当然に敷地賃借権の「譲渡」（612条）に当たる。
  - 正解：×（誤り）
  - 理由：判例は譲渡担保の法的構成にコミットせず、使用収益の主体が現実に交替したかで決める（最判平9.7.17）。設定者が従前どおり建物を使用している限りは「譲渡又は転貸」に当たらず、譲渡担保権者が引渡しを受けて現実に使用収益して初めて該当する。形式的な所有権移転の形だけで即断すると誤り。
- **［○×クイズ 5/8］** 賃借人が賃貸人の承諾なく第三者に賃借物の使用収益をさせた場合でも、その行為が賃貸人に対する背信的行為と認めるに足りない特段の事情があるときは、賃貸人は612条2項による解除権を行使することができない。
  - 正解：○（正しい）
  - 理由：信頼関係破壊の法理。612条2項の解除も、賃貸借が信頼関係を基礎とする継続的契約である以上、背信性を欠く特段の事情があれば制限される。小問(1)では、賃料・返済の履行と鍵の即返還を特段の事情として評価し、解除を否定する筋になる。
- **［○×クイズ 6/8］** 譲渡担保権者が建物の引渡しを受けても、譲渡担保権が実行されておらず設定者に受戻権が残っている以上、敷地について612条にいう賃借権の譲渡又は転貸がされたと解する余地はない。
  - 正解：×（誤り）
  - 理由：判例は、譲渡担保権が未実行で受戻権が残っていても、譲渡担保権者が引渡しを受けて現実に使用又は収益をするときは「譲渡又は転貸」に当たるとする（最判平9.7.17）。受戻権の存在は結論を左右しない＝基準は使用主体の現実的交替。小問(1)は鍵の即返還で交替が微妙、小問(2)は1か月居住で交替明白、と事実であてはめが分かれる。
- **［○×クイズ 7/8］** 借地権を対抗できない借地権者に対し、土地の新所有者が明渡しを請求する場合、新所有者が土地購入後にその借地関係の経緯を知ったときは、当然に権利濫用（1条3項）として明渡請求は認められない。
  - 正解：×（誤り）
  - 理由：権利濫用が認められるのは新所有者に害意等の特段の事情がある場合に限られる。購入後に経緯を知ったにすぎず、害意をもって買い受けたのでなければ権利濫用には当たらない。本問のDも購入後に事情を知ったにすぎず、権利濫用は否定が筋。
- **［○×クイズ 8/8］** 賃貸人たる地位の移転（605条の2第1項）を賃借人に対抗するためには、賃貸物である不動産について所有権移転の登記をしなければならない（同条3項）。
  - 正解：○（正しい）
  - 理由：605条の2第3項は、賃借人が誰に賃料を払えばよいかを明確にするため、地位移転の対抗に所有権移転登記を要求する。本問のDは甲土地の移転登記を備えているから、賃貸人たる地位を取得しBに対抗できる（＝賃料請求は可）。もっとも解除は、旧賃貸人Aの下で解除権が発生していて初めて承継されるので、612条・信頼関係破壊の判断に戻る。
