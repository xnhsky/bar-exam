### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】『被担保債権の債務者はA・引渡請求者はC（別人）』 → 牽連性＝同一性の判断を起動
- 【拾う事実】『登記のC移転でAのB向け移転義務が履行不能に』 → 填補賠償（415条）の発生根拠
- 【拾う事実】『Cは購入当時Bへの売却を知らず（善意）＋登記具備』 → 177条でCが優先（争いなし）
- 【拾う事実】『Eの占有は賃貸借で適法に開始し解除で不法化』 → 2項の直接適用を否定→類推へ
- 【拾う事実】『Eは解除を認識しながら費用支出』 → 悪意＝類推適用を肯定する決め手
- 【拾う事実】『費用は台風被害の屋根修理』 → 必要費（196条1項）の性質決定
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 小問1＝①占有○・③弁済期○（期限の定めなき債権は請求時に到来）・④占有は不法開始でない○ → 詰まるのは②牽連性だけ。小問2＝①〜③○・直接適用の④も文言上は○に見える → 詰まるのは④を類推で否定できるか。4要件は必ず通すが、問題が無ければ一文でよい。
- 【効く事実】小問1で効く事実
  - 同一性 → 被担保債権の債務者はA・甲土地の引渡請求者はC＝別人／債権の性質 → Aへの移転義務が履行不能で態様を変じた損害賠償にすぎない／背後 → 留置権を認めると177条（C善意・登記）が骨抜き。
- 【規範の要点】類推適用肯定説の規範
  - 295条2項の趣旨は当事者間の公平にある。そうだとすれば、占有が中途から不法になり、占有者が権原のないことを知り（悪意）、または過失で知らずに費用を支出し、留置権を認めるのが公平に反するときは、2項を類推適用して留置権を否定する。Eは解除を認識＝悪意。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 複数の場面で同じ制度（留置権）が出たら、最後に「切断点の違い」を一言でまとめる。本問はどちらも留置権不成立で請求者（C・D）が勝つ。留置権は物権ゆえ第三者Cにも主張しうる点が、債権的な同時履行の抗弁との分かれ目。
- 【まぎらわしい選択肢・論点】背信的悪意者の該当性／同時履行の抗弁の成否／有益費償還請求権の成否
- 【まぎらわしい選択肢・結論】留置権成立・明渡拒絶可／Cの請求は認められない
- 【まぎらわしい選択肢・規範】物自体牽連性説（一元説）／文言重視説（類推否定説）
- 【まぎらわしい選択肢・事実】占有が不法行為で開始／Eは善意無過失

## 3. 規範クイズ（4問）

- **Q04［規範］** 留置権の成立要件（295条）を4つ挙げよ。
  - 模範解答：①他人の物を占有すること ②その物に関して生じた債権を有すること（牽連性・1項本文）③被担保債権が弁済期にあること（1項ただし書）④占有が不法行為によって始まったものでないこと（2項）。否定するなら1つ欠けば足りる。
- **Q05［規範］** 留置権の趣旨から導かれる、「その物に関して生じた債権」（牽連性）の判断基準を、二重譲渡型を否定できる形で述べよ。
  - 模範解答：留置権は物の返還拒絶で債務者に心理的圧迫を加え弁済を促す担保物権である。そうだとすれば、成立時点において被担保債権の債務者と目的物の引渡請求権者とが同一人であることを要する。引渡請求者が債務者でなければ、物を留置しても弁済を促す関係にないからである（同一性基準説）。
- **Q06［規範］** 牽連性が認められる2類型（二元説）を挙げ、二重譲渡の損害賠償がいずれにも当たらないことを一言で述べよ。
  - 模範解答：(ⅰ)債権が物自体から生じた場合（費用償還請求権等）／(ⅱ)債権が物の返還請求権と同一の法律関係・事実関係から生じた場合。二重譲渡の損害賠償は、物自体を目的とする債権が態様を変じたにすぎず(ⅰ)に当たらず、債務者A≠引渡請求者Cで(ⅱ)にも当たらない。
- **Q07［規範］** 占有が中途から不法になった場合の295条2項類推適用の規範（趣旨→要件）を述べよ。
  - 模範解答：2項の趣旨は当事者間の公平にある。ゆえに、占有が中途から不法になった場合でも、占有者が占有権原のないことを知り、または過失により知らないで費用を支出し、留置権を認めることが公平に反するときは、295条2項を類推適用して留置権の成立を否定する（最判昭46.7.16・百選I76）。

## 4. ○×クイズ（7問）

- **Q08［○×］** 留置権は法定担保物権であり、物権であるから、契約当事者以外の第三者に対しても主張することができる。
  - 正解：○（正しい）
  - 理由：留置権は公平の理念に基づく法定担保物権（295条）で、物権であるから第三者にも対抗できる。この点が、契約当事者間の債権的抗弁にすぎず第三者に主張できない同時履行の抗弁（533条）と決定的に異なる。だから小問1でBは、契約当事者でないCにも留置権なら主張しうる。
- **Q09［○×］** 賃貸借の存続中に賃借人が賃借物について必要費を支出した場合、その償還請求権の根拠条文は、占有者の費用償還を定める196条1項である。
  - 正解：×（誤り）
  - 理由：賃貸借存続中の必要費は賃借人の費用償還請求権（608条1項）で処理する。196条は「占有者」と回復者の関係の規定で、賃貸借終了後の占有者が支出した費用に用いる。本問のEは解除（＝賃貸借終了）後に支出しているので196条1項が根拠。どちらの費用償還かで条文が切り替わる。
- **Q10［○×］** 留置権の成立を否定する側は、成立要件（①占有②牽連性③弁済期④不法占有でない）のうち、いずれか1つの要件の不充足を示せば足りる。
  - 正解：○（正しい）
  - 理由：要件は積み重ね（連言）なので、否定するなら1要件を欠けば足りる。逆に成立を肯定する側は全要件を丁寧に当てる必要がある。だから否定の答案は、切れる要件を厚く・他を簡潔に、というメリハリが命。
- **Q11［○×］** 不動産が二重に譲渡され登記を先に備えた第二譲受人が、目的物を占有する第一譲受人に明渡しを求めた場合、第一譲受人が売主に対して有する履行不能の損害賠償請求権は「その物に関して生じた債権」に当たらず、これを被担保債権とする留置権は成立しない。
  - 正解：○（正しい）
  - 理由：判例（最判昭43.11.21）は、この損害賠償請求権を「物自体を目的とする債権がその態様を変じたものにすぎず、その物に関し生じた債権とはいえない」として牽連性を否定した。留置権を認めると対抗要件主義（177条）が潜脱されてしまう点にも理由がある。二重譲渡型は牽連性否定が原則。
- **Q12［○×］** 賃借人が賃借建物に付加した造作の買取請求権（造作買取代金債権）は、その建物に関して生じた債権であるから、賃借人はこれを被担保債権として建物を留置することができる。
  - 正解：×（誤り）
  - 理由：判例（最判昭47.11.16）は、造作買取代金債権は「造作」に関して生じた債権であって「建物」に関して生じた債権ではないとして、建物の留置を否定した。牽連性は物「自体」との結びつきを厳格に見る。他方、屋根修理費のような必要費償還請求権は物自体への投下で牽連性が認められる（小問2で被担保債権になりうる理由）。「どの物に関して生じたか」を峻別するのがコツ。
- **Q13［○×］** 賃貸借契約が解除された後、賃借人が権原なく占有を継続する間に費用を支出した場合、その占有は「不法行為によって始まった」（295条2項）といえるから、同項が直接適用されて留置権が否定される。
  - 正解：×（誤り）
  - 理由：占有は賃貸借契約に基づき適法に開始しており、「占有が不法行為によって始まった」とはいえないから2項の直接適用はない。判例（最判昭46.7.16・百選I76）は、権原なきを知り／過失で知らず費用を支出したときは2項を類推適用して留置権を否定した。
- **Q14［○×］** 留置権（295条）は物権であり第三者にも対抗できるのに対し、同時履行の抗弁権（533条）は双務契約の当事者間でのみ主張できる債権的抗弁であって、契約外の第三者には主張できない。
  - 正解：○（正しい）
  - 理由：両者は「相手が払うまで渡さない」という機能は似るが、留置権は法定担保物権で第三者にも対抗でき、同時履行の抗弁は双務契約から生じる債権的抗弁で当事者間限り。だから小問1でBが契約当事者でないCに対抗しうるのは留置権のみ。機能の類似に引きずられず、物権か債権かで対抗範囲を切り分ける。
