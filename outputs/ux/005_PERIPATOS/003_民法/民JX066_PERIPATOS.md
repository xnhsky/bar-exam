#### 第1　小問1　協議離婚の無効原因

1. 無効原因の明文なし（742条と対照）→ ①離婚意思②届出（763・764→739）の反対解釈 → 【論点】離婚意思の内容（規範：形式的意思説）
2. 届出あり → 勝負は離婚意思／仮装離婚に見えても法律上の解消意思で足りる
   - あてはめ：例外：届出意思すら欠く場合にのみ無効
- 結論：仮に仮装でも直ちに無効でない ＝ 原則として有効

#### 第2　小問2　詐害行為取消権の要件

1. 前提：Zは177条の第三者＝Xは対抗不可／対Y請求は無資力で実効性なし
2. 一般要件（無資力・詐害行為・詐害意思）充足 → 【論点】受益者の悪意は無資力の認識で足りる（売却の不知は無関係）
3. 【論点】特定物債権が被保全債権となりうるか → 転形説（行使時基準） → 損害賠償請求権へ転形済み＝○
4. 【論点】財産分与は424条2項で対象外か → 原則対象外・過大部分例外（768条3項の趣旨）→ 不相当に過大＋仮託の特段の事情
- 結論：不相当に過大な部分につき取消対象

#### 第3　小問2　取消しの範囲・効果と権利実現

1. 【論点】取消しの範囲 → 一部取消し（過大部分・424条の8）
2. 目的物が不可分の不動産 → 価額償還（424条の6条1項後段）→ 直接引渡し（424条の9条2項前段）＋相殺（505条）
- 結論：相殺による事実上の優先弁済で権利実現

- 【拾う事実】『移転登記を経由しないうちにZへ移転登記』 → 177条でXは対抗不可（所有権的請求の限界）
- 【拾う事実】『財産分与を原因として』 → 424条2項「財産権を目的としない行為」該当性を起動
- 【拾う事実】『甲不動産以外にめぼしい資産なし・債務超過』 → 無資力・詐害性・不相当に過大の認定根拠
- 【拾う事実】『Zは債務超過を知っていた／売却は知らなかった』 → 受益者の悪意は無資力の認識で足りる
- 【拾う事実】『甲不動産（一個の不動産＝不可分）』 → 一部取消しの実現＝価額償還を導く
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 小問2の一般要件（無資力・唯一の資産の移転＝財産減少・詐害意思・受益者悪意）は本問で素直に充足＝一言。詰まるのは、小問1＝離婚意思の内容／小問2＝被保全債権（特定物債権）・財産分与の取消対象性の計3点。
- 【効く事実】「離婚意思の内容（仮装離婚）」のあてはめで使う事実
  - 形式的意思説 → 「法律上の解消意思」の有無だけ問えばよい／届出は明らかにある → 勝負は離婚意思の有無に絞る／本問に届出意思の欠缺をうかがわせる事情はない → 原則どおり有効。事実は必ず評価語（法的安定を害さない・内縁に戻る意思と区別できる）と結合させる。
- 【ポイント】受益者の悪意
  - 受益者Zの悪意は債務者が無資力であることの認識で足り、特定の債権者を害する意思は不要。ZがYの債務超過を知っていた以上、悪意は認められる。Zが甲不動産の売却を知らなかったことは悪意を否定しない。
- 【効く事実】「特定物債権・財産分与（詐害行為取消権の要件）」のあてはめで使う事実
  - 被保全債権 → Zの登記具備でXの特定物債権が履行不能 → 損害賠償請求権へ転形（行使時基準で足りる）／財産分与 → 甲不動産以外に資産なし・持分2分の1相当を超える部分は不相当に過大＋仮託の特段の事情。事実は評価語（不相当に過大・仮託してされた財産処分）と結合させる。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 取消しは不相当に過大な部分に限る（一部取消し・424条の8）。目的物が不可分の不動産だから価額償還（424条の6Ⅰ後段）で処理し、Xは受益者Zへ直接自己への金銭引渡しを請求（424条の9Ⅱ前段）→損害賠償請求権と相殺（505条）＝事実上の優先弁済。424条と177条は要件・効果を異にする別制度で矛盾しない。
- 【まぎらわしい選択肢・論点】離婚意思＝実質的意思まで要するか／177条の対抗問題の処理／債権者代位権の可否
- 【まぎらわしい選択肢・結論】協議離婚は無効／財産分与全部が取消対象
- 【まぎらわしい選択肢・規範】実質的意思説／詐害行為時基準（転形）
- 【まぎらわしい選択肢・事実】背信的悪意者／登記を先に備えた

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

小問1＝無効原因の明文なし、①離婚意思②届出の反対解釈、離婚意思は形式的意思で足りる、仮装でも有効・届出意思欠く場合のみ無効。小問2要件＝177条・無資力で前提潰し、特定物債権は転形で被保全債権、財産分与は原則対象外だが不相当に過大＋仮託で過大部分は取消対象、受益者悪意は無資力の認識で足りる。小問2効果＝一部取消し、不可分ゆえ価額償還、直接引渡し＋相殺で優先弁済。

## 3. 規範クイズ（全4問・1問目から最後まで全部出す）

- **［規範クイズ 1/4］** 協議離婚が効力を生じるための2つの要件と、それを前提に無効原因をどう導くかを述べよ。
  - 模範解答：①離婚意思 ②離婚の届出（763条・764条→739条）。協議離婚は①②により効力を生じるから、その反対解釈として①②のいずれかが欠ける場合に無効となる（②届出を欠く場合は不成立と整理されることが多い）。婚姻無効（742条）と同じ骨格で対応させる。
- **［規範クイズ 2/4］** 協議離婚の「離婚意思」の内容について判例・通説（形式的意思説）が採る規範と、その理由を述べよ。
  - 模範解答：離婚意思は法律上の夫婦関係を解消する意思（＝離婚届を出す意思）で足りる。理由は、法律上の婚姻関係を解消した後も事実上の夫婦関係を継続する意思での離婚も可能であり、これを無効とすると法的安定を害すること、内縁に戻る意思と区別できれば足りることにある（最判昭57.3.26・最判昭38.11.28）。
- **［規範クイズ 3/4］** 特定物の引渡請求権（特定物債権）が詐害行為取消権の被保全債権となりうるとする規範と、その理由を述べよ。
  - 模範解答：特定物債権も究極において損害賠償請求権に変じ得る以上、債務者の一般財産による担保が必要な点は金銭債権と変わらない。そこで判例は、取消権行使時までに損害賠償請求権に変じていれば被保全債権たる「債権」の要件を満たすと解する（最大判昭36.7.19）。本問はZの登記具備でXの特定物債権が履行不能→損害賠償請求権へ転形済みであるから、被保全債権として肯定される。
- **［規範クイズ 4/4］** 不相当に過大な財産分与が取り消される場合の「取消しの範囲」と、目的物が不可分の不動産である場合の「権利実現の方法」を述べよ。
  - 模範解答：取消しは不相当に過大な部分に限る（一部取消し・424条の8）。目的物が不可分の不動産なら価額償還（424条の6第1項後段）で処理し、Xは受益者Zへ直接自己への金銭引渡しを請求できる（424条の9第2項前段）。受領金銭の返還義務と自己の損害賠償請求権を相殺（505条）して事実上の優先弁済を受ける。

## 4. ○×クイズ（全7問・1問目から最後まで全部出す）

- **［○×クイズ 1/7］** 詐害行為取消権（424条）を裁判上行使する場合、受益者に対する取消請求の訴えの被告となるのは、債務者ではなく受益者である。
  - 正解：○（正しい）
  - 理由：受益者に対する詐害行為取消請求の被告は受益者である（424条の7第1項1号）。債務者は被告とならず、債権者は債務者へ訴訟告知をする（同条2項）。財産を握る受益者へ向かうのが筋で、無資力の債務者に請求しても回収できない。
- **［○×クイズ 2/7］** 財産分与は「財産権を目的としない行為」（424条2項）に当たるから、離婚に伴う財産分与が詐害行為取消権の対象となる余地はない。
  - 正解：×（誤り）
  - 理由：財産分与は身分行為性を帯び原則として取消しの対象外だが、768条3項の趣旨に反して不相当に過大で、財産分与に仮託してされた財産処分と認めるに足りる特段の事情がある部分は、その限度で取消対象となる（最判平12.3.9）。
- **［○×クイズ 3/7］** 登記を備えた財産分与の受益者Zは、177条の「第三者」に当たり、登記を備えないXは甲不動産の所有権取得をZに対抗することができない。
  - 正解：○（正しい）
  - 理由：Zは背信的悪意者ではなく177条の「第三者」に当たる。Xは登記を備えないから所有権取得をZに対抗できず、所有権に基づく移転登記・引渡請求はできない。
- **［○×クイズ 4/7］** 協議離婚については、婚姻の無効（742条）と同様に無効原因が民法に明文で列挙されているから、その列挙事由に当たらない限り、協議離婚の無効を主張することはできない。
  - 正解：×（誤り）
  - 理由：婚姻には無効原因の明文（742条）があるが、協議離婚には無効原因の明文がない。763・764→739条から①離婚意思②届出により効力を生じることの反対解釈で、いずれかが欠ける場合に無効と解釈で導く。この導出過程を書けるかが小問1の勝負どころ。
- **［○×クイズ 5/7］** 協議離婚の届出が、専ら債権者からの追及や履行義務を免れる方便としてされた仮装離婚である場合には、当事者に婚姻共同生活を実質的に解消する意思がないから、その協議離婚は当然に無効となる。
  - 正解：×（誤り）
  - 理由：判例・通説（形式的意思説）は、離婚意思を法律上の夫婦関係を解消する意思で足りると解する。方便・仮装であっても法律上の解消意思がある限り離婚は有効で、例外的に届出意思すら欠く場合にのみ無効となる（最判昭57.3.26）。婚姻意思（実質的意思説）とは非対称である点に注意。
- **［○×クイズ 6/7］** 詐害行為取消権は総債権者の共同担保（責任財産）の保全を目的とする制度であるから、特定物の引渡請求権（特定物債権）は、いかなる場合にも被保全債権となり得ない。
  - 正解：×（誤り）
  - 理由：特定物債権も究極において損害賠償請求権に変じ得るから、取消権行使時までに損害賠償請求権へ転形していれば被保全債権足りる（最大判昭36.7.19）。責任財産保全制度との緊張は、転形により金銭債権と同視できる点で解消される。「特定物債権は一律に不可」とするのは誤り。
- **［○×クイズ 7/7］** 詐害行為取消しの目的物が不可分で、受益者からの現物返還が困難な場合には、取消債権者は受益者に対し、その価額の償還を請求することができる。
  - 正解：○（正しい）
  - 理由：受益者から財産の返還を請求する場合において、その返還が困難であるときは、取消債権者は価額の償還を請求できる（424条の6第1項後段）。本問は不可分の不動産ゆえ価額償還で処理し、直接引渡し（424条の9）＋相殺（505条）で優先弁済に至る。
