- 【拾う事実】「騒音の影響で難聴に罹患し、1000万円の損害」 → 被害の内容と結びつき
- 【拾う事実】『「予見することができた」（前提）』 → B社が結果を見通せた点
- 【拾う事実】「実質的な債務超過状態にあり、破産の危機」 → 投融資判断に関わる事情
- 【拾う事実】『「十分に認識していたにもかかわらず」説明せず勧誘』 → C社(D)の認識と不提供
- 【拾う事実】『2020.11.1 契約・500万円／2021.6.1 倒産・回収不能』 → 損害の確定した時点
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 709条：予見可能（前提）→ 過失／難聴＝身体（聴力）という法益侵害／因果・損害あり ＝ 一文で成立。415条は「債務（安全配慮義務）の存在」で止まる＝そこを規範で基礎づける。
- 【効く事実】「安全配慮義務」のあてはめで使う事実
  - 特別な社会的接触 → 従業員として長年就労＝雇用契約に基づく労務指揮関係／義務違反 → メンテを十分に行わず通常より大きな騒音・耳栓等を与えず／損害・因果 → 難聴に罹患・1000万円／帰責事由 → 「予見することができた」（前提）。
- 【規範の要点】一種の背理の規範
  - 信義則上の説明義務違反により相手方が本来なら締結しなかった契約を締結し損害を被った場合、後に締結された契約は説明義務違反によって生じた結果であり、その義務を当該契約に基づく債務（本来的債務か付随義務かを問わず）とみるのは一種の背理である → 債務不履行責任は否定。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 平成29年改正（令和2年4月施行）で、生命・身体侵害の消滅時効は債務不履行・不法行為でほぼ平準化（167条＝20年／724条の2＝5年）。かつて安全配慮義務構成が重宝された時効面の実益は縮小し、むしろ遅延損害金は不法行為が有利（損害発生時から当然に遅滞）。
- 【まぎらわしい選択肢・論点】詐欺取消の可否／取締役の対第三者責任
- 【まぎらわしい選択肢・結論】債務不履行も不法行為も不成立／安全配慮義務違反は成立しない
- 【まぎらわしい選択肢・規範】法条競合説／契約責任説
- 【まぎらわしい選択肢・事実】遅延損害金は債務不履行が有利／近親者慰謝料は債務不履行で肯定

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

小問(1)A＝不法行為は予見可能で過失あり成立。債務不履行は、賃金支払義務が中心でも特別な社会的接触＋信義則で安全配慮義務あり、メンテ・耳栓の懈怠で違反、予見可能で帰責事由あり＝両構成で1000万円。小問(2)E＝契約締結前の説明義務違反は契約の「結果」で一種の背理＝債務不履行×。投融資の資力説明義務違反で不法行為○＝500万円。

## 3. 規範クイズ（全4問・1問目から最後まで全部出す）

- **［規範クイズ 1/4］** 安全配慮義務の発生根拠を規範の形で述べよ（判例の定式）。
  - 模範解答：ある法律関係に基づいて特別な社会的接触の関係に入った当事者間において、当該法律関係の付随義務として、信義則（1条2項）上当然に発生する（最判昭50.2.25）。現在は労働契約法5条が明文化。
- **［規範クイズ 2/4］** 安全配慮義務の具体的内容は何によって定まるか（義務内容の画定基準）。
  - 模範解答：労務提供が行われる場所・設備・器具等の使用状況、労務の内容等の具体的状況によって個別に定まるという判例の規範である（最判昭59.4.10・川義事件）。この規範から、本問では機械のメンテナンス義務・耳栓等の保護具供与義務に義務内容が具体化され、その懈怠が安全配慮義務違反として成立する。
- **［規範クイズ 3/4］** 債務不履行に基づく損害賠償で、債務者が免責されるのはどのような場合か（415条1項ただし書）。
  - 模範解答：その不履行が、契約その他の債務の発生原因及び取引上の社会通念に照らして債務者の責めに帰することができない事由によるものであるとき。本問はB社が予見可能であったから免責されない。
- **［規範クイズ 4/4］** 投融資契約において、勧誘した側が負う信義則上の説明義務の対象を述べよ。
  - 模範解答：投融資を行う者は相手方の資力を十分に検討して可否を判断するのが通常だから、投融資の可否を判断する上で重要な事項（資力＝実質的債務超過・破産の危機等）について説明する義務を負う。これに違反して契約を締結させ損害を被らせれば不法行為（709条）が成立する。

（規範クイズはここまで＝全4問。最後の4問目まで出したら「規範クイズ、全4問クリア！」と言って次へ）

## 4. ○×クイズ（全7問・1問目から最後まで全部出す）

- **［○×クイズ 1/7］** 同一の事実が債務不履行と不法行為の双方の要件を充たす場合、被害者はいずれの請求権をも選択的に行使することができる（請求権競合説）。
  - 正解：○（正しい）
  - 理由：判例・通説は請求権競合説に立ち、被害者はいずれの請求権も選択的に行使できる。契約責任のみが成立するとする法条競合説は被害者保護に欠けるとして支持されていない。この立場ゆえ、同じ損害を415条・709条の双方から検討できる。
- **［○×クイズ 2/7］** 雇用契約における使用者の中心的債務は賃金支払義務であり、労働者の生命・身体の安全に配慮する義務（安全配慮義務）は、当初から民法典に明文の規定が置かれている。
  - 正解：×（誤り）
  - 理由：安全配慮義務は民法に明文がなく、判例（最判昭50.2.25等）が信義則上の付随義務として形成した。後に労働契約法5条が「労働契約に伴い」生じる義務として明文化したが、民法典自体には規定がない。だからこそ「明文なき義務をどう基礎づけるか」が小問(1)の山場になる。
- **［○×クイズ 3/7］** 安全配慮義務（債務不履行）構成と不法行為構成とでは、帰責事由（過失）の立証責任の所在が異なり、債務不履行では債務者の側が免責事由を立証しなければならない（415条1項ただし書）。
  - 正解：○（正しい）
  - 理由：債務不履行では、免責事由（債務者の責めに帰することができない事由）の立証責任は債務者にある（415条1項ただし書）。他方、不法行為では被害者が加害者の過失を立証する。立証責任の所在は、どちらの構成を選ぶかの実益の一つ。
- **［○×クイズ 4/7］** 安全配慮義務は、ある法律関係に基づいて特別な社会的接触の関係に入った当事者間において、当該法律関係の付随義務として、信義則上、当事者の一方又は双方が相手方に対して負う義務である。
  - 正解：○（正しい）
  - 理由：最判昭50.2.25（陸上自衛隊八戸車両整備工場事件）の定式。公法上の勤務関係にすら認めた出発点判例で、「特別な社会的接触の関係」＋「信義則上の付随義務」がキーワード。本問は雇用契約そのものがあるから当然に肯定される。
- **［○×クイズ 5/7］** 安全配慮義務は、直接の雇用契約が存在する当事者間に限って認められ、直接の雇用契約がない元請企業と下請労働者との間では、両者が特別な社会的接触の関係に入っていても認められる余地はない。
  - 正解：×（誤り）
  - 理由：最判平3.4.11は、直接の雇用契約がない元請企業と下請労働者との間でも、事実上元請の指揮監督下で労務を提供し設備を利用する関係にあれば「特別な社会的接触の関係」に入ったといえ、元請も安全配慮義務を負うとした。雇用契約がなくても認めた以上、雇用契約のある本問では当然に肯定される。
- **［○×クイズ 6/7］** 一方当事者が信義則上の説明義務に違反したために相手方が本来なら締結しなかった契約を締結し損害を被った場合、その説明義務違反は、当該契約上の債務不履行による賠償責任を生じさせる。
  - 正解：×（誤り）
  - 理由：最判平23.4.22は、後に締結された契約は説明義務違反によって生じた「結果」であり、その義務を当該契約に基づいて生じた債務とみることは、本来的債務というか付随義務というかにかかわらず一種の背理だとして、債務不履行責任を否定した。責任の性質は不法行為であって債務不履行ではない。
- **［○×クイズ 7/7］** 不法行為に基づく損害賠償債務は、催告を要せず損害の発生時（不法行為時）から遅滞に陥るのに対し、債務不履行に基づく損害賠償債務は、原則として債権者から履行の請求を受けた時から遅滞となる（412条3項）。
  - 正解：○（正しい）
  - 理由：不法行為による損害賠償債務は期限の定めのない債務だが、判例上、催告を要せず損害発生時から遅滞に陥る。他方、債務不履行（安全配慮義務違反）による損害賠償は、期限の定めのない債務として履行の請求を受けた時から遅滞となる（412条3項）。遅延損害金の起算点では不法行為が有利で、これも構成選択の実益。

（○×クイズはここまで＝全7問。最後の7問目まで出したら「○×クイズ、全7問クリア！」と言って復習へ）
