2. 絵画焼失で現物返還不能（412条の2条1項）→ 【論点】一方の原状回復義務が履行不能の処理 → 規範：客観的価値の価額賠償に転化

3. 利息・使用利益 → 【論点】189条・190条の給付利得への適用可否 → 規範：侵害利得の規律ゆえ不適用→545条2項3項類推で全面返還

#### 第2　設問2　甲社→丙

- 見出しの補足（結論を含む。項目の終わりに読む）：侵害利得・191条

3. 【論点】賠償額は時価か譲渡額か → 規範：原則売却代金（最判平19.3.8）／才覚差益は射程外＝客観的価値説 → +20万は丙の才覚で50万

#### 第3　設問2　甲社→丁

- 【拾う事実】『「事情を打ち明けた上で」丙に売却』 → 丙の悪意（即時取得せず）
- 【拾う事実】『丙50万で買い70万で転売（+20万）』 → 才覚による差益＝賠償額の限定
- 【拾う事実】『丁は「処分権限があると信じ、信ずるにつき過失がなかった」』 → 善意無過失＝即時取得＝法律上の原因
- 【拾う事実】『丁が製品1を加工し製品2に』 → 加工(246条2項)・原物滅失
- 【事案の整理】2つの流れを分ける
  - 設問1＝AB間の契約が取消しで巻き戻る流れ＝給付利得。設問2＝甲社の物が乙→丙→丁と無権原で流れる流れ＝侵害利得。原因が「契約」か「侵害」かで返還ルールが変わる。
- 【ポイント】「法律上の原因」が最後の関門
  - 丁は即時取得（192条）で所有権を取得している＝甲社が所有権を失ったことに「法律上の原因」がある。だから703条の要件を欠き、丁への償金請求はここで切れる。要件を機械的に流すと、④で自然に結論が出る。
- 【効く事実】あてはめで使う事実
  - 価額賠償の額 → 「500万円程度の価値しかない」（客観的価値＝500万・代金5000万ではない）／清算方法 → Bの5000万返還とAの500万価額賠償を相殺→差額4500万／片面性 → 善意A・悪意B（189条・190条を機械適用すると不均衡）。
- 【規範の要点】賠償額の限定の規範
  - 悪意占有者が物を処分した場合の返還額は原則売却代金相当額（最判平19.3.8）。もっとも侵害利得の返還は物権的返還請求権の補完物であり返すべきは物の客観的価値だから、客観的価値を超える分が受益者の才覚によるときはその差益は対象外 → 本問の+20万は丙の販売業者としての才覚 → 時価50万円にとどまる。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - この対比を答案の最後（または冒頭）に一言置くと、2つの設問がバラバラの知識問題でなく一本の軸で貫かれ、評価が上がる。「不当利得は類型で返還ルールが変わる」——これが本問の出題意図。
- 【まぎらわしい選択肢・論点】危険負担による反対給付の消滅／94条2項類推適用の可否／使用者責任の成否
- 【まぎらわしい選択肢・結論】甲社は丁に200万円を請求できる／丙は譲渡額70万円を返還する
- 【まぎらわしい選択肢・規範】衡平説（統一説）／準事務管理肯定説
- 【まぎらわしい選択肢・事実】丁の悪意／代金5000万円

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

設問1＝取消しで原状回復（121条の2）、絵画滅失で価額賠償500万に転化、5000万と相殺で差額4500万、189・190条は侵害利得の規律で不適用→545条2項3項類推で利息・使用利益を全面返還。設問2丙＝悪意で即時取得せず、譲渡も「滅失」（昭2.2.16）で191条、原則売却代金だが才覚差益は射程外（平19.3.8）で50万、代価控除は補完物ゆえ否定（昭12.7.3）。設問2丁＝加工で製品2、しかし即時取得＝法律上の原因で703条遮断、194条も原物滅失で機能せず、請求不可。

## 3. 規範クイズ（全4問・1問目から最後まで全部出す）

- **［規範クイズ 1/4］** 不当利得（703条）の一般的成立要件を4つ挙げよ。
  - 模範解答：①他人の財産又は労務によって利益を受けたこと（受益）②他人に損失を及ぼしたこと（損失）③受益と損失との間の因果関係 ④法律上の原因がないこと。類型論はこの④を「給付の欠缺」「割当内容の侵害」に類型化して具体化する。
- **［規範クイズ 2/4］** 取消しによる原状回復として返還すべき物が滅失し現物返還が不能となった場合、返還義務はどうなるか（規範）。
  - 模範解答：返還義務は消滅せず、その物の客観的価値を返還する価額賠償義務に転化する。滅失を理由に一方だけ返還を免れると、他方だけが返還義務を負い給付の巻き戻しとして不公平だから。
- **［規範クイズ 3/4］** 双方が履行した契約が取消しで巻き戻る場合、利息・使用利益の清算に189条・190条を適用しないとすれば、代わりにどの規定で処理する見解が有力か。理由も一言。
  - 模範解答：解除の原状回復に関する545条2項3項を類推適用し、利息・使用利益をいずれも返還させる（全面返還）。契約を存在しなかった状態に戻す以上、双方の得た利益をすべて返すのが原状回復の趣旨に適うから。利息と使用利益を相殺したとみる575条類推（双方返還不要）の見解もあり、自説で書けばよい。
- **［規範クイズ 4/4］** 悪意占有者が取得のために支払った代価の控除が侵害利得の返還で認められない理由を述べよ。
  - 模範解答：侵害利得の返還請求は物権的返還請求権の補完物であり、物が現存すれば所有者はそれをそっくり返還請求できるだけで代価控除の余地はない。現物が失われ金銭賠償に転じても同じだから、取得の代価は控除されない（大判昭12.7.3）。

## 4. ○×クイズ（全7問・1問目から最後まで全部出す）

- **［○×クイズ 1/7］** 不当利得は一枚岩ではなく、当事者間の給付の巻き戻し（給付利得）と、他人の財貨からの無権原な利得（侵害利得）とで返還のルールが構造的に異なるとする類型論が、現在は有力である。
  - 正解：○（正しい）
  - 理由：かつては703条・704条を公平の理念に基づく統一的制度と捉える衡平説（統一説）が通説だったが、現在は類型論が有力。給付利得は「契約を存在しなかった状態に戻す全面返還」、侵害利得は「物権的返還請求権の補完物」で発想が異なる。まず各利得移動がどちらの類型かを仕分けるのが出発点。
- **［○×クイズ 2/7］** 錯誤又は詐欺により法律行為が取り消されると、その行為は初めから無効であったものとみなされ、給付を受けた各当事者は、原状に復させる義務（原状回復義務）を負う（121条の2第1項）。
  - 正解：○（正しい）
  - 理由：取消しの遡及効（121条）を受け、平成29年改正で新設された121条の2第1項が給付の巻き戻し（原状回復義務）を正面から定めた。給付利得の清算の起点条文はこれ。703条一本で処理しないのが類型論の作法。
- **［○×クイズ 3/7］** 即時取得（192条）が成立するには、取引行為によって平穏・公然に動産の占有を始め、かつ前主が権利者であると信じたこと（善意）を要するが、そう信じたことについての無過失までは要求されない。
  - 正解：×（誤り）
  - 理由：即時取得は取引の安全のための制度だが、真の権利者の犠牲の上に成り立つため要件は厳格で、善意かつ無過失を要する（192条）。本問の丁は「処分権限があると信じ、かつ信ずるにつき過失がなかった」ので善意無過失を充たし、所有権を取得する。この取得が甲社の損失に対する「法律上の原因」となる。
- **［○×クイズ 4/7］** 189条・190条は、本来、他人の物を無権原で占有する者（侵害利得の場面）について、果実の帰属を占有者の善意・悪意で振り分ける規律である。
  - 正解：○（正しい）
  - 理由：189条は善意占有者に果実取得を認め、190条は悪意占有者に果実返還・代価償還を課す。これは占有回復（侵害利得）の場面の果実帰属ルール。だからこそ、双方が履行した契約の巻き戻し（給付利得）にそのまま適用すると、善意者と悪意者で扱いが割れて片面的になる、という問題意識が立つ。
- **［○×クイズ 5/7］** 取消しによる原状回復では、返還すべき価額は、当事者が現実に授受した対価（代金額）を基準に算定され、目的物の客観的価値がこれと異なる場合であっても代金額を返還すれば足りる。
  - 正解：×（誤り）
  - 理由：原状回復は「受領した給付そのもの」を返す制度だから、物が滅失したときに転化する価額賠償の額はその物の客観的価値である。本問の絵画は贋作で客観的価値は500万円だから、Aが返すのは500万円（代金5000万円ではない）。
- **［○×クイズ 6/7］** 悪意の占有者が他人の物を第三者に売却した場合、回復者への不当利得返還額は常に現実の売却代金額であり、売却価格が物の客観的価値を上回った分（受益者の才覚による差益）も含めて返還しなければならない。
  - 正解：×（誤り）
  - 理由：最判平19.3.8は原則「売却代金相当額」とするが、同判決の調査官解説は受益者の才覚で客観的価値より相当高く売れた分は射程外とする。侵害利得の返還は物権的返還請求権の補完物であり、返すべきは物の客観的価値。よって才覚による差益は返還対象外で、本問の丙は時価50万円にとどまる（常に70万ではない）。
- **［○×クイズ 7/7］** 双方が履行した契約が取消しにより巻き戻る給付利得の清算では、189条・190条をそのまま適用せず、解除に関する545条2項3項を類推適用して利息・使用利益を全面的に返還させる見解が有力である。
  - 正解：○（正しい）
  - 理由：189条・190条は侵害利得（占有回復）の果実帰属ルールで、双務契約の巻き戻しに機械適用すると善意者・悪意者で片面的結論になる。契約を存在しなかった状態に戻す給付利得では、解除の原状回復（545条2項3項）と平仄を合わせ全面返還とするのが均衡上妥当。利息と使用利益を相殺したとみる575条類推もある。
