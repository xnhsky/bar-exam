- **Q01［事案の整理］** 三面関係と各当事者の請求・抗弁を挙げて
  - 答え：契約の線は B⇄C（原賃貸借・解除済み） と C⇄D（適法転貸借） の2本。B→A は相続で賃貸人の地位を承継（896条）。
  - 答え：B と D の間には契約が無い。接点は所有権と613条だけ。ここを掴むと請求の性質（賃料か・不当利得か）が見えてくる。
- **Q02［見当づけ］** 各請求は「何請求っぽい？」 ― 見当をつけて
  - 答え：Cへ：契約終了 → 目的物返還請求（601条）＋未払賃料／解除後の不当利得（704条）。Dへ：契約が無い → 所有権に基づく明渡し＋使用利益の不当利得。「解除後」の金銭は賃料でなく不当利得（契約が消えたから名前が変わる）。
- **Q03［論点］** Dへの明渡しで問題になる論点を挙げて（3つ）
  - 答え：CP①：解除に際し転借人への催告は要るか。（催告＝履行の機会を与える通知。Dに払う機会を与えねば明渡せないか）
  - 答え：CP②：解除で転貸借はどうなるか（基礎喪失・占有権原の対抗不能）。（Dの権原はどこから来て、いつ消えるか）
  - 答え：CP③：占有権原の喪失時期と、後の金銭請求の基準となる転貸借の終了時期は別問題。

### 骨子（3項目。第1から【論点】ごとに、何が問題→規範→使う事実→結論 の順で組み立てる）

#### 第1　BのCに対する主張

1. Bは相続で賃貸人の地位承継（896条本文）／6か月超不払 → 【論点】541条解除・信頼関係破壊なし（一文）→ 返還請求（601）
2. Cの抗弁 → 【論点】敷金 or 有益費のどちらで留置できるか（規範：295条）
   - あてはめ：敷金返還は明渡し後発生（622の2 I①）＝留置× ／ 有益費630万＝物に関して生じた債権＝留置○
3. 賃料 → 解除まで20万、【論点】解除後は不当利得（704）／有益費との清算で30万／Cは有益費で相殺（505）
- 結論：返還請求は有益費償還と引換え・不当利得は相殺で減額

#### 第2　BのDに対する明渡請求

1. 【論点】転借人への催告の要否 → 613条1項の反対解釈（片面性）で不要
2. 【論点】解除による転貸借の帰趨 → 基礎喪失で占有権原の対抗不能（昭36.12.21・613条3項ただし書）
3. Dの敷金はCに差入れ → Bに敷金返還請求権なし（大9.9.28）＝抗弁不可
- 結論：所有権に基づき無条件で明渡請求可

#### 第3　BのDに対する賃料・不当利得

- 見出しの補足（結論を含む。項目の終わりに読む）：三期間
1. ①解除前 → 613条1項前段で20万、ただしDは既払で対抗（後段反対解釈）＝実質請求不可
2. ②解除後〜明渡請求 → 【論点】転貸借存続中の利得消滅（平9.2.25＝明渡請求時終了）→ 他人物賃貸借類似・DのCへの支払で利得消滅／189条1項も
3. ③明渡請求後 → 転貸借も終了 → Dは不法占拠・悪意（190条）＝利得消滅せず
- 結論：①②は請求不可・③のみ月30万の不当利得請求可（704）

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「Aの承諾を得て…630万円をかけて改装」 → 有益費該当（留置権・相殺の被担保債権）
- 【拾う事実】「2022年9月分以降、全く支払われていない」 → 6か月超＝信頼関係破壊・解除の可否
- 【拾う事実】「Aの承諾を得て…Dに転貸」 → 適法転貸＝613条・帰趨の前提
- 【拾う事実】「所有者にはCが当然払っていると信じていた」「解除も知らなかった」 → Dの善意（189条・利得消滅の前提）
- 【拾う事実】「1度も延滞せず…Cの口座に振り込んでいる」 → DのCへの支払＝利得消滅の効く事実
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 賃貸人の地位＝Bが相続で承継（896条）／解除＝催告後相当期間経過（541条）＋6か月超の不払で信頼関係破壊は一文で肯定。前提は素通り、紙幅はDへ回す。
- 【効く事実】あてはめで使う事実
  - Dの善意 → 「所有者にはCが当然払っていると信じた」「解除を知らなかった」／利得消滅 → DはCに賃料を1度も延滞せず払い続けている／不法占拠化 → 明渡請求後は権原なしを直接引用。
- 【規範の要点】295条の規範
  - 敷金返還請求権は明渡し後に発生（622条の2第1項1号）＝まだ無い → 留置×。有益費償還請求権は「その物に関して生じた債権」で終了時に弁済期到来 → 留置○・相殺○（505条）。敷金の当然充当も賃借人からは請求できない（622条の2第2項）。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 複数の金銭請求は「いつの線で切るか」を先に決める。占有権原の喪失（＝明渡しの可否）と、転貸借契約自体の終了時期（＝金銭の基準）は別の線。混同すると②の利得消滅が崩れる。
- 【まぎらわしい選択肢・論点】即時取得の成否／背信的悪意者の排除
- 【まぎらわしい選択肢・結論】Dへの請求は全期間で認容／全期間で請求不可
- 【まぎらわしい選択肢・規範】解除時終了説／債権的効力説
- 【まぎらわしい選択肢・事実】Dは悪意／敷金から当然充当

## 3. 規範クイズ（4問）

- **Q04［規範］** 原賃貸借の債務不履行解除に際し、転借人への催告が不要とされる理由を、条文上の根拠を示して述べよ。
  - 模範解答：613条1項は「転借人は賃貸人に対して直接義務を負う」と定めるのみで、賃貸人が転借人に義務（履行の機会を与える義務）を負うとは定めていない。この義務の片面性の反対解釈から、賃貸人は転借人に催告・通知して代払の機会を与える必要がない（最判昭37.3.29）。
- **Q05［規範］** 適法な他人物賃貸借において、借主が貸主に賃料を支払った場合、所有者が借主に対し使用利益の不当利得返還を請求できないのはなぜか。
  - 模範解答：借主は契約上の相手方（貸主）に賃料を支払うべき立場にあり、実際に支払えば、その支出により利得は現存しない（利得の消滅・703条）。二重払を強いることは公平に反するから、所有者は借主に不当利得返還を請求できない。転貸借存続中（解除後〜明渡請求まで）のDはこれと同視できる。
- **Q06［規範］** 賃借人が支出した有益費の償還請求権を被担保債権とする留置権（295条）が認められるための要件充足を述べよ。
  - 模範解答：有益費償還請求権は、その物の価値を増加させる費用の償還債権であり「その物に関して生じた債権」（295条1項本文）に当たる。賃貸借の終了時に弁済期が到来し（608条2項・196条2項）、占有が不法行為で始まったものでもないから、留置権の各要件を充たす。よって費用の償還を受けるまで目的物の返還を拒める。
- **Q07［規範］** 原賃貸借が解除されると、転借人が占有権原を賃貸人に対抗できなくなるのはなぜか（転貸借の基礎喪失）を述べよ。
  - 模範解答：転借人の占有権原は、転貸人（賃借人）の賃貸人に対する使用収益権限を基礎とする（転貸人の権原の上に乗っている）。原賃貸借が解除で終了すると転貸人の使用収益権限が失われ、転貸借はその基礎を失う。よって転借人は賃貸人に対抗しうる占有権原を喪失し、賃貸人は所有権に基づき無条件で明渡しを請求できる（最判昭36.12.21・613条3項ただし書）。

## 4. ○×クイズ（7問）

- **Q08［○×］** 賃貸人の承諾を得た適法な転貸借がされても、賃貸人と転借人との間に直接の賃貸借契約が成立するわけではない。
  - 正解：○（正しい）
  - 理由：転貸借は賃借人（転貸人）と転借人との間の契約で、賃貸人はその当事者ではない。両者に契約関係が無いからこそ、613条1項が例外的に「転借人は賃貸人に直接義務を負う」と特別に定める。賃貸人→転借人の金銭請求が「賃料」か「不当利得」かは、この契約線の有無から決まる。
- **Q09［○×］** 賃貸借契約が債務不履行により解除された後も、賃貸人は元賃借人に対し、契約に基づく「賃料」の支払を請求することができる。
  - 正解：×（誤り）
  - 理由：解除により契約は消滅するから、以後は契約上の「賃料」を請求できない。占有・使用が続くなら、賃料相当額の不当利得返還（703・704条）又は不法行為に基づく賃料相当損害金として捉える。同じ「月○万円」でも、解除を境に請求の名前（賃料→不当利得）が変わる点を外さない。
- **Q10［○×］** 転借人に対する目的物明渡請求の可否は、原賃貸借契約が有効に終了したか否かを論理的な前提とする。
  - 正解：○（正しい）
  - 理由：転借人の占有権原は原賃貸借を基礎とする（転貸人の使用収益権限が源泉）。原賃貸借が有効に終了して初めて転貸借が基礎を失い、賃貸人が転借人に明渡しを求めうる。したがって答案は原賃貸借の解除の有効性を先に確定し、その効果としてDの権原喪失を導く順序が論理的。
- **Q11［○×］** 賃借人が賃料を6か月以上にわたり全く支払わない場合、特段の事情がない限り賃貸借の基礎となる信頼関係は破壊されたといえ、催告のうえでの解除が認められる。
  - 正解：○（正しい）
  - 理由：賃貸借の解除は信頼関係破壊の法理で規律され、賃料の長期不払は破壊を基礎づける典型。6か月超の全額不払なら「破壊されていない特段の事情」は通常なく、答案では一文で肯定して深入りしない。
- **Q12［○×］** 原賃貸借が賃借人の債務不履行を理由に解除される場合、賃貸人は転借人に対しても催告して賃料を代払する機会を与えなければ、転借人に建物の明渡しを求めることができない。
  - 正解：×（誤り）
  - 理由：613条1項は転借人が賃貸人に直接義務を負うことを定めるにとどまり、賃貸人が転借人に義務を負うとは定めていない（義務の片面性）。この反対解釈から、賃貸人は転借人に履行の機会を与える必要はなく、催告は不要（最判昭37.3.29）。
- **Q13［○×］** 賃借人は、賃貸借終了時に発生する敷金返還請求権を被担保債権として、目的物について留置権を行使し、その明渡しを拒むことができる。
  - 正解：×（誤り）
  - 理由：敷金返還請求権は賃貸借終了かつ目的物の明渡し後に、未払債務を控除した残額について発生する（622条の2第1項1号）。明渡し前にはそもそも債権が発生せず弁済期も来ていないから、これを被担保債権とする留置権も同時履行の抗弁も認められない。一方、有益費償還請求権なら「その物に関して生じた債権」で留置権を基礎づけうる（295条）。両者の振り分けが差を分ける。
- **Q14［○×］** 適法な転貸借は原賃貸借とは別個独立の契約であり、原賃貸借が解除されても当然には終了せず、賃貸人が転借人に目的物の返還を請求した時に、転貸人の債務が履行不能となって終了する。
  - 正解：○（正しい）
  - 理由：最判平9.2.25（百選II64）の射程。転貸借は別個の契約ゆえ原賃貸借の解除で当然消滅せず、賃貸人が転借人に返還請求した時に転貸人の使用収益させる債務が履行不能となって終了する。この「明渡請求時終了」が、②（転貸借存続＝利得消滅）と③（転貸借終了＝不法占拠）の分岐点になる。占有権原の対抗不能（明渡しの可否）とは別の線である点に注意。
