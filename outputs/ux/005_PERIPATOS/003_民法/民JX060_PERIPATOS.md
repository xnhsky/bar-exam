### 骨子（3項目。第1から【論点】ごとに、何が問題→規範→使う事実→結論 の順で組み立てる）

#### 第1　小問(1)(a)　AのBに対する明渡請求

1. 明渡請求の根拠＝無効に基づく 原状回復請求（121条の2第1項）から立てる
2. 前提：愛人維持の贈与 → 【論点】動機の不法（規範：表示され契約内容化した不法な動機は90条で無効）
3. 【論点】708条「不法」の意義 → 公序良俗違反説 ＝90条違反で充足
4. 【論点】708条「給付」の終局性 → 規範：未登記不動産は引渡しで足りる → 未登記・引渡し済み＝給付あり → 返還請求不可
5. 【論点】所有権的返還請求の遮断と反射的移転 → 規範：反射的効果として所有権はBに帰属
- 結論：明渡し不可・所有権はBに帰属 ＝ Bは不実登記の抹消登記手続を請求可

#### 第2　小問(1)(b)　Gの詐害行為取消請求

1. 424条の要件（被保全債権・詐害行為・詐害意思・受益者Bの悪意）＝充足（簡潔に）
2. 【論点】無効な行為を詐害行為として取り消せるか → 規範：取消しも無効も効果否定の手段 → 肯定
3. 【論点】708条と424条の抵触 → 規範：制度趣旨相違・424条は責任財産保全の債権者固有権利 → 抵触せず
- 結論：Gの取消し認容（占有はAに復帰）

#### 第3　小問(2)　FのBに対する明渡請求

1. 【論点】反射的移転の性質 → 規範：承継取得説（原始取得だと負担消滅で不当） → BF間は二重譲渡類似 → 177条
2. 【論点】177条「第三者」の範囲 → 規範：登記欠缺を主張する正当な利益を有する者・背信的悪意者は除外
3. F＝知悉＋恨み（害意） → 背信的悪意者 → 「第三者」に非該当

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「愛人関係を維持するため」 → 動機の不法（90条・708条「不法」）を基礎づける
- 【拾う事実】「未登記の建物」「引き渡した」 → 708条「給付」の終局性（未登記は引渡しで足りる）
- 【拾う事実】「自己名義に登記した」 → 名義A・実体的所有Bの分離／二重譲渡類似の基礎
- 【拾う事実】『贈与時「債務超過」を「知っていた」』 → 受益者Bの悪意（424条1項ただし書）
- 【拾う事実】『Fは「恨んで」おり事情を「知悉」』 → 単純悪意を超える害意＝背信的悪意者
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 紙幅を割くのは「引っかかる要件」＝708条の「給付」の終局性、反射的移転の性質、「第三者」の範囲。要件は全部拾うが、問題が無ければ一文で。
- 【効く事実】「給付と反射的移転」のあてはめで使う事実
  - 給付の終局性 → 建物は「未登記」で「引渡し済み」を直接引用／反射的移転 → 返還請求が封じられた以上、占有と所有の帰属を一致させる／登記名義 → Aが後から自己名義に登記＝名実の分離。
- 【規範の要点】承継取得説＋背信的悪意者排除論の規範
  - 反射的移転を原始取得と解すると目的物上の負担が消滅して不当だから承継取得と解する → BF間はAを起点とした二重譲渡類似（177条）→ 「第三者」＝登記の欠缺を主張する正当な利益を有する者で、背信的悪意者はこれに当たらない（最判昭43.8.2）。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - (1)(a)＝AのBへの請求は708条で不可。(1)(b)＝Aの債権者Gの取消しは可。矛盾に見えるが、424条は責任財産の保全という債権者固有の利益を守る別制度で、708条の「不法に助力しない」趣旨を害さない。制度趣旨の違いで一言整合させれば足りる。
- 【まぎらわしい選択肢・論点】即時取得（192条）の成否／94条2項の直接適用／177条の「登記」の意義
- 【まぎらわしい選択肢・結論】Fの明渡請求 認容／詐害行為取消請求 棄却
- 【まぎらわしい選択肢・規範】醜悪説／原始取得説
- 【まぎらわしい選択肢・事実】単純悪意／登記の先後

## 3. 規範クイズ（3問）

- **Q04［規範］** 不法原因給付（708条）により贈与者の返還請求が封じられた場合、目的物の所有権はどこに帰属するか。判例の帰結（規範）とその理由を述べよ。
  - 模範解答：不当利得返還請求も所有権的返還請求もできない以上、その反射的効果として所有権は受贈者に帰属する（最大判昭45.10.21）。返還請求権と占有・所有の帰属が不一致になるのを避けるべきだからであり、正義公平の理念に合致する。この移転は承継取得の一種と解され、小問(2)の対抗問題の前提になる。
- **Q05［規範］** 177条の「第三者」の意義を述べ、背信的悪意者が「第三者」に当たらないとされる理由を述べよ。
  - 模範解答：「第三者」とは、当事者・承継人以外で、不動産物権変動につき登記の欠缺を主張する正当な利益を有する者をいう。177条は自由競争の枠内の優劣を決する規定だから、その枠を超え登記の欠缺を主張することが信義則（1条2項）に反する背信的悪意者は正当な利益を欠き「第三者」に当たらない（最判昭43.8.2）。単純悪意者は保護される点に注意。
- **Q06［規範］** 不法原因給付として贈与者の返還請求が封じられる贈与について、債権者が詐害行為取消権（424条）を行使しても708条の趣旨が没却されないといえる理由を述べよ。
  - 模範解答：①708条の趣旨は「法が不法に助力しない」点にあり、詐害行為を理由とする取消しを認めても不法を助長しない。②708条と424条は要件・効果を異にする別個の制度であり、424条は責任財産の確保という債権者独自の利益を保護する。よって取消しを認めても708条の趣旨は没却されない。なお無効な行為も、取消しも無効も効果否定の手段にすぎないから取り消しうる。

## 4. ○×クイズ（9問）

- **Q07［○×］** 契約が無効であるとき、既に引き渡した物の返還を求めるには、原状回復請求権（121条の2第1項）や所有権に基づく返還請求権といった具体的な請求権を根拠として主張する必要がある。
  - 正解：○（正しい）
  - 理由：無効を前提に、どの請求権（原状回復請求権・所有権的返還請求権）を立てるかを特定してから要件を検討するのが民法事例の作法。請求権の特定が出発点。
- **Q08［○×］** 不法な動機に基づく契約は、その動機が相手方に表示されて契約の内容となっていなくても、動機が不法である以上つねに公序良俗（90条）に反し無効となる。
  - 正解：×（誤り）
  - 理由：動機は原則として法律行為の効力に影響しない。不法な動機が相手方に表示され契約の内容となった場合に限り、公序良俗違反として無効になる（大判昭9.5.28ほか）。「動機だから常に有効」でも「不法だから常に無効」でもなく、表示・内容化が分水嶺。
- **Q09［○×］** 708条により不当利得の返還請求が封じられる場合、同一の給付について所有権に基づく返還請求を認めると708条の趣旨を没却するため、所有権的返還請求も遮断される。
  - 正解：○（正しい）
  - 理由：708条を不当利得返還請求だけに効かせ、所有権的返還請求は素通り、では脱法を許し趣旨を没却する。そこで所有権に基づく返還請求も遮断され、その帰結として所有権の所在（＝反射的移転）の議論に進む。返還構成の違いで結論が変わってはならない。
- **Q10［○×］** 708条本文にいう「不法」とは、90条の公序良俗違反と同義に解される（708条は90条を裏返した規定である）。
  - 正解：○（正しい）
  - 理由：708条の「不法」は公序良俗違反（90条違反）を意味する（判例・通説）。90条で無効となった契約は708条の「不法」要件も満たす、と両条を接続できると論述が締まる。「不法＝反社会性の強い醜悪なもの」に限る醜悪説もあるが、通説は公序良俗違反説。
- **Q11［○×］** 登記済みの不動産を贈与した場合であっても、目的物の引渡しさえあれば、移転登記をしなくても708条の「給付」は終局的になされたといえる。
  - 正解：×（誤り）
  - 理由：「給付」は終局的給付を要する。既登記の不動産では移転登記までして初めて終局的で、引渡しだけでは足りない。未登記の不動産は引渡しで足りる（最大判昭45.10.21）。未登記／既登記の区別が「給付」概念の核心で、本問は未登記だから引渡しで完了する。
- **Q12［○×］** 未登記の不動産の贈与では、引渡しがあれば708条の「給付」は終局的になされたといえ、贈与者はその返還を請求できない。
  - 正解：○（正しい）
  - 理由：最大判昭45.10.21は、未登記建物の贈与につき引渡しにより不法原因給付が完了したとし、贈与者は返還を請求できないとした。終局的でない給付にまで708条を及ぼすと、かえって不法に助力することになるため「終局的」を要求し、その基準として未登記／既登記を分ける。
- **Q13［○×］** 不法原因給付の反射的効果としての所有権移転を「承継取得」と解すると、目的物に設定されていた抵当権等の負担は当然に消滅する。
  - 正解：×（誤り）
  - 理由：逆である。負担が消滅してしまうのは原始取得と解した場合で、これが不当だからこそ承継取得と解する。承継取得なら負担は存続し、かつ贈与者は無権利者ではないから、二重譲渡類似の関係として177条で規律できる。原始取得説では贈与者は無権利者となり、譲受人の保護は94条2項類推で決せられる。
- **Q14［○×］** 不動産物権変動における単純悪意者は、原則として177条の「第三者」に含まれ、登記の欠缺を主張することができる。
  - 正解：○（正しい）
  - 理由：177条は自由競争を前提とするため、単に先行の物権変動を知っているだけの単純悪意者は「第三者」として保護される。保護されないのは、自由競争の枠を超え信義則に反する背信的悪意者だけ。「悪意＝即排除」ではない点が背信的悪意者排除論の要。
- **Q15［○×］** 初めから無効な法律行為であっても、詐害行為取消権（424条）の対象として取り消すことができる。
  - 正解：○（正しい）
  - 理由：取消しも無効も、いずれも法律行為の効果を否定するための手段にすぎない。したがって、無効な行為を詐害行為として取り消すことも妨げられない。無効だから取消しの対象にならない、と切ってしまうと(1)(b)の中心論点を落とす。
