甲は、乙との間で、乙がその倉庫に保管中のB型ワープロ500台のうち200台を、契約の日から1週間後を引渡期日と定めて購入する契約を締結した。甲の債権は、制限種類債権であるとして、次の場合につき、甲乙間の法律関係を論ぜよ。(1)　契約の日の翌日、B型ワープロ全部が倉庫から消失してしまった場合(2)　乙が甲に引き渡すために、あらかじめ甲が指示したB型ワープロ200台を倉庫から搬出し、トラックに積載しておいたところ、トラックごとそれが消失してしまった場合

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 契約：500台のうち200台、引渡期日＝契約日から1週間後（制限種類債権）
- (1) 契約翌日：B型ワープロ全部（500台）が倉庫から消失
- (2) 乙が甲指示の200台を倉庫から搬出・トラックに積載
- (2) 積載後、トラックごと200台が消失（残300台は現存）

2. 乙帰責あれば 填補賠償（415条1項・Ⅱ①）

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「乙の倉庫内の500台のうち200台」 → 制限種類債権（母集団が限定）
- 【拾う事実】『「全部が倉庫から消失」（小問1）』 → 母集団全滅＝調達義務が消えるか
- 【拾う事実】「あらかじめ甲が指示した200台を搬出」 → 合意による特定を基礎づける
- 【拾う事実】『「トラックに積載しておいたところ」通知の記載なし』 → 取立債務の通知欠如
- 【拾う事実】「200台のみ消失（残300台現存）」 → 変更権の前提となる在庫
- 【事案の整理】制限種類債権とは
  - 種類物だが、母集団が「乙の倉庫の500台」という一定範囲に限定されたもの。この「範囲の限定」が、普通の種類債権と運命を分ける分岐点になる（範囲が尽きれば調達義務が消える）。
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 小問(1)＝母集団500台全滅 → 調達義務消滅 → 履行不能（412条の2）＝ほぼ争いなし一文。争点は小問(2)の特定。特定が決まれば、あとは(1)の処理を流用できる。
- 【効く事実】あてはめで使う事実
  - 合意による特定 → 甲が「この200台」を指示＋乙がこれを他から取り分けた／条文特定の否定 → 通知（受領の催告）の記載を欠く／変更権の前提 → 残300台が現存・B型ワープロは代替性が高い。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 変更権は「在庫が残ってこそ」機能する。母集団全滅の小問(1)では出番なし。特段の事情なき限り肯定 → 結論が「特定だけの場合」と逆転する（賠償・解除は不可、引渡し・代金は可）。
- 【まぎらわしい選択肢・論点】危険負担における債権者主義の適用／受領遅滞の効果
- 【まぎらわしい選択肢・結論】履行不能により引渡請求は認められない（変更権の検討不要）／特定は生じない
- 【まぎらわしい選択肢・規範】分離不要説／狭義説
- 【まぎらわしい選択肢・事実】通知あり／母集団全滅

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

(1)＝母集団全滅で履行不能（412の2）、賠償(415)・解除(542条1項1号)・危険負担(536条1項)、甲帰責なら543・536条2項前段で不可。(2)＝取立債務は通知欠くが合意で特定、特定後も残300台で変更権 → 賠償・解除は不可、引渡し・代金は通る。期日後＝413の2で債務者帰責みなし。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 種類債権が「特定」する2つの類型を挙げよ（401条2項）。取立債務・持参債務でどう違うかも。
  - 模範解答：①債務者が「物の給付をするのに必要な行為を完了」：持参債務＝債権者の住所で現実の提供／取立債務＝分離＋通知（口頭の提供・493条ただし書）。②「債権者の同意を得て給付すべき物を指定」（後段・指定権が債務者）。
- **［規範クイズ 2/3］** 取立債務で通知を欠き条文上は特定が否定される場合に、なお結論として特定を肯定できる法的構成を挙げ、その根拠を一言で述べよ。
  - 模範解答：合意による特定（根拠＝私的自治の原則）。401条2項は特定の一場面にすぎず、当事者が「この物」と合意すれば特定は生じる。買主が特定物を指示し売主が取り分けた本問では、当該物を目的物とする合意を認定できる（401条2項後段の累積適用と構成してもよい）。
- **［規範クイズ 3/3］** 債務者の変更権の規範（要件・根拠）と、それが認められると賠償・解除・引渡し・代金の結論がどう動くかを述べよ。
  - 模範解答：規範＝特定は履行の手段にすぎず、特段の事情なき限り債務者は他の同種物で履行しうる（大判昭12.7.7）。前提＝母集団に同種物が残存。効果＝引渡債務が存続する結果、債権者は損害賠償も解除もできない反面、引渡請求は通り、代金支払も拒めない（特定だけの場合と結論が逆転）。

（規範クイズはここまで＝全3問。最後の3問目まで出したら「規範クイズ、全3問クリア！」と言って次へ）

## 4. ○×クイズ（全7問・1問目から最後まで全部出す）

- **［○×クイズ 1/7］** 制限種類債権は、目的物の種類を一定の範囲に限定して指定した種類債権であり、その範囲内の物が全て滅失すれば、通常の種類債権と異なり債務者は調達義務を負わず、引渡債務は履行不能となる。
  - 正解：○（正しい）
  - 理由：制限種類債権は母集団が限定される点に特色がある。母集団が尽きれば調達義務が消え履行不能となる（普通の種類債権は市場から調達義務が残るため履行不能になりにくい）。この違いが小問(1)と(2)の分かれ目になる。
- **［○×クイズ 2/7］** 危険負担（536条1項）が適用されると、当事者双方の責めに帰することができない履行不能の場合、債権者の反対給付債務そのものが当然に消滅する。
  - 正解：×（誤り）
  - 理由：536条1項は反対給付の履行を拒める「履行拒絶権（抗弁）」にとどまり、反対債務を消滅させるものではない。反対債務を消滅させたいなら解除（542条）による。効果の違い（拒絶か消滅か）を取り違えない。
- **［○×クイズ 3/7］** 制限種類債権でも、母集団に同種物が残存している限り、特定が生じない限りは目的物の一部が滅失しても直ちに履行不能とはならない。
  - 正解：○（正しい）
  - 理由：母集団が残る限り調達義務は残る。特定が債権をその物に収縮させて初めて、その物の滅失＝履行不能となる。だから残300台のある小問(2)では「特定したか」が全ての鍵になる。
- **［○×クイズ 4/7］** 取立債務における種類債権の特定には、債務者が目的物を他から分離して引渡しの準備を整えれば足り、その旨を債権者に通知して受領を催告することまでは必要でない。
  - 正解：×（誤り）
  - 理由：取立債務では、分離・準備に加え、債権者への通知（受領の催告＝口頭の提供、493条ただし書）があって初めて「給付をするのに必要な行為の完了」＝特定となる（最判昭30.10.18）。本問(2)は通知を欠くため、この枠組みでは特定は生じない。
- **［○×クイズ 5/7］** 401条2項が定める特定の要件を文言上満たさない場合でも、私的自治の原則から、当事者の合意によって目的物を特定することは認められる。
  - 正解：○（正しい）
  - 理由：401条2項は特定の一場面を定めたにすぎず、私的自治の原則から当事者の合意による特定も当然に許される。本問は買主甲の指示＋売主乙の取り分けで、当該200台を引渡目的物とする合意が認定でき、遅くともこの時点で特定する（401条2項後段の累積適用と構成してもよい）。
- **［○×クイズ 6/7］** 種類債権が特定した後であっても、債務者は、特段の事情がない限り、他の同種物をもって履行することができる（変更権）。
  - 正解：○（正しい）
  - 理由：特定は種類債権を履行するための手段にすぎず、債務者から履行の自由を終局的に奪うものではない（大判昭12.7.7）。特段の事情なき限り変更権が認められ、残存する同種物での履行が可能となる。制限種類債権でも同様。
- **［○×クイズ 7/7］** 履行遅滞に陥った債務者が、その後、当事者双方の責めに帰することができない事由により目的物が滅失して履行不能となった場合、双方無責である以上、危険負担（536条1項）の問題として処理され、債務者は帰責を負わない。
  - 正解：×（誤り）
  - 理由：履行遅滞中に双方無責で履行不能となったときは、その不能は債務者の責めに帰すべき事由によるものとみなされる（413条の2第1項）。よって双方無責でも危険負担の問題は生じず、債権者は解除・損害賠償をなしうる。本問(2)で消失が引渡期日後なら、この特則で処理する。

（○×クイズはここまで＝全7問。最後の7問目まで出したら「○×クイズ、全7問クリア！」と言って復習へ）
