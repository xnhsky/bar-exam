## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

Aは、自己所有の土地（以下「本件土地」という。）をBに売却し、同土地をBに引き渡したが、まだ登記はされていない。その後、Bは、Cに対して本件土地を転売して引き渡したが、BC間でも登記はされていない。ところが、その後、Bがいつまで経ってもAに代金を支払わないので、AはBに催告した上、Bとの契約を解除し、本件土地をDに売却した。ただし、本件土地の登記は、いまだにA名義のままである。CD間の法律関係について、論じなさい。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- AB売買・引渡（登記はA名義のまま）
- BC転売・引渡（BC間も未登記／Cは解除より前に登場）
- Bの代金不払 → Aが催告の上AB契約を解除
- 解除後、AがDへ本件土地を売却
- 現在＝Cが占有・登記はA名義／DがCへ明渡請求

### 参考（読み上げない。入口の問いの答えを含むので判定にだけ使う）

登場人物：
- A｜元所有者・解除権者（→Dへ売却）
- B｜買主（代金不払で解除された）
- C｜Bからの転得者・現占有者（解除前・無登記）
- D｜解除後の買主（無登記）

一行要約：A→B→Cと土地が渡る（いずれも無登記）が、A・B間を代金不払で解除しAがDへ売却。登記は終始A名義。

### 入口の問い（3問）

- **Q01［事案の整理］** 「誰が・誰に・何を」求めているかを挙げて
  - 答え：土地は現にCが占有し、登記はA名義。素直なのはD（所有者と主張）がC（占有者）に明渡しを求める場面。
  - 答え：A・Bは背景（AB解除で権利が動いた）。攻防の当事者はCとD。ここに絞るのが棚卸し。
- **Q02［見当づけ］** 各請求の「法的根拠」と対抗の枠組み ― 見当をつけて
  - 答え：D：解除でAが所有者に戻る → Aから買ったDが所有者 → 所有権に基づく明渡請求（555条・206条）。C：①自分は所有者だ（545条1項ただし書の第三者）／②Dは登記がない（177条）の2本で反論。
- **Q03［論点］** 「進めない所（＝論点）」を挙げて（2つ）
  - 答え：論点①：Cは解除前の第三者だが登記がない → 解除前の第三者が保護されるための登記の要否。（＝ただし書は登記を明文で求めていないが、要るか）
  - 答え：論点②：解除の遡及効でCは無権利者 → 無権利者は177条の「第三者」か。（＝制限説で「正当な利益」なしと切れるか）

### 骨子（4項目。第1から【論点】ごとに、何が問題→規範→使う事実→結論 の順で組み立てる）

#### 第1　Dの請求とCの反論

1. 土地は現にC占有 → Dは所有権に基づく明渡請求（解除でAに復帰・Aから取得）
2. Cの反論＝①545条ただし書の第三者だ ②Dは無登記で177条で対抗不可
- 以下①②の当否を検討

#### 第2　反論①

- 見出しの補足（結論を含む。項目の終わりに読む）：解除前の第三者Cと登記・545条1項ただし書
1. 解除で契約は遡及的消滅（直接効果説）→ Cは「第三者」に当たらねば無権利
2. 【論点】解除前の第三者に登記を要するか（規範：権利保護要件説）
   - あてはめ：帰責なき解除権者の犠牲で保護ゆえ、権利保護要件としての登記を要する
3. あてはめ：Cは解除前の第三者だが登記はA名義のまま＝登記なし
- 結論：Cは保護されず＝反論①は認められない（Cは無権利者）

#### 第3　反論②

- 見出しの補足（結論を含む。項目の終わりに読む）：177条の「第三者」
1. 解除の遡及効でAに復帰 → Aから買ったDが所有権取得（555・176）。Dは無登記
2. 【論点】無権利者Cは177条の「第三者」か（規範：制限説）
   - あてはめ：177条＝自由競争の優劣を決する規定 → 第三者＝登記欠缺を主張する正当な利益を有する者
3. あてはめ：Cは前述のとおり無権利者 → 正当な利益なし
- 結論：Cは「第三者」に当たらず＝Dは登記なくして対抗可（反論②も認められない）

#### 第4　結論

   反論①②とも認められない → DはCに本件土地の明渡請求ができる（対抗関係に見えて非対抗）

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】『Cへの転売はAの解除より「前」』 → Cは解除前の第三者（545条ただし書の場面）
- 【拾う事実】『登記は、いまだにA名義のまま』 → CもDも登記を欠く（登記欠缺）
- 【拾う事実】『Bの代金不払を理由に催告解除』 → 解除権者Aに帰責性なし（権利保護要件の根拠）
- 【拾う事実】『解除の後にAがDへ売却』 → 遡及効でAに復帰→Dが所有権取得
- 【拾う事実】『土地は現にCが占有』 → Dの請求は所有権に基づく明渡し
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 解除の効果＝遡及的消滅（直接効果説）で一言／Dの所有権取得＝解除でAに復帰しAから買ったDが取得＝一言。進めないのは「登記なきCも保護されるか」「無権利者Cが177条の第三者か」の2点。
- 【効く事実】「解除前の第三者Cと登記の要否」のあてはめで使う事実
  - 解除前の第三者 → CはAの解除より前にBから転売・引渡しを受けた／登記の欠缺 → 登記は終始A名義のまま＝Cは登記を備えていない／解除権者の無帰責 → Aは代金不払という正当事由で解除。
- 【規範の要点】制限説の規範
  - 177条は自由競争の枠内にある者同士の優劣を決する規定 → 「第三者」＝当事者・包括承継人以外で登記の欠缺を主張する正当な利益を有する者（大連判明治41・12・15）→ 無権利者はこれに含まれない → Dは登記なくして対抗可。
- 【まぎらわしい選択肢・論点】背信的悪意者の排除／94条2項類推適用の可否
- 【まぎらわしい選択肢・結論】Cは第三者として保護される／CD間は対抗関係となり登記の先後で決する
- 【まぎらわしい選択肢・規範】無制限説
- 【まぎらわしい選択肢・事実】Cは善意

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

反論①＝Cは解除前の第三者だが、帰責なき解除権者の犠牲ゆえ権利保護要件として登記が必要、Cは登記なし＝無権利者。反論②＝177条の第三者は正当な利益ある者（制限説）、無権利者Cは含まれず、Dは登記なくして対抗可。結論＝対抗関係に見えて非対抗、明渡請求認容。

## 3. 規範クイズ（2問）

- **Q04［規範］** 545条1項ただし書で保護される「第三者」の意義（時的限界）を述べよ。
  - 模範解答：解除前に、解除された契約から生じた法律関係を基礎として新たな利害関係を取得した者。解除後に現れた者はここに含まれず（177条の対抗問題）、善意・悪意は問わない。
- **Q05［規範］** 解除前の第三者が545条1項ただし書で保護されるために登記を要する理由を、答案の規範として述べよ（権利保護要件説）。
  - 模範解答：何ら帰責性のない解除権者の犠牲の下に第三者を保護するものである以上、第三者には権利保護要件としての登記を備えることを要すると解する（判例・大判大正10・5・17も登記を要求）。登記なき第三者は保護されない。

## 4. ○×クイズ（7問）

- **Q06［○×］** 不動産物権変動は当事者の意思表示によって効力を生じ（176条・意思主義）、登記（177条）は物権変動を第三者に対抗するための要件にすぎない。
  - 正解：○（正しい）
  - 理由：意思主義（176条）の下、物権変動は登記がなくても当事者間では有効に生じる。登記は成立要件ではなく第三者対抗要件（177条）。だから「誰が権利者か（実体）」と「誰に対抗できるか（登記）」を分けて考えるのが物権変動事案の出発点。
- **Q07［○×］** 契約が解除されると、その契約から生じた物権変動は当然に覆り、解除より前に現れた第三者も一切保護されない。
  - 正解：×（誤り）
  - 理由：解除は契約を遡及的に消滅させる（直接効果説）が、545条1項ただし書は「第三者の権利を害することはできない」として解除前の第三者を保護する。遡及効を貫くと取引の安全を害するからで、「一切保護されない」は誤り。もっとも保護には登記を要する（次のステップの核心）。
- **Q08［○×］** 契約解除の後に現れた第三者と解除権者との関係は、545条1項ただし書によって処理される。
  - 正解：×（誤り）
  - 理由：545条1項ただし書が保護するのは解除前の第三者。解除後に現れた第三者と解除権者（復帰した権利者）との関係は、対抗問題として177条で処理し、登記の先後で優劣を決する（最判昭35・11・29）。「解除前か後か」の時的振り分けが条文選択を分ける。本問のCは解除前だから545条ただし書。
- **Q09［○×］** 解除によって契約は遡及的に消滅し、各当事者は原状回復義務を負う（545条1項本文・直接効果説）。
  - 正解：○（正しい）
  - 理由：判例・通説の直接効果説では、解除により契約は初めからなかったことになり（遡及的消滅）、既履行の給付は原状回復義務（545条1項本文）として清算される。この遡及効を第三者に及ぼすと取引安全を害するため、ただし書が第三者保護の例外を置く。
- **Q10［○×］** 545条1項ただし書で保護される「第三者」は善意でなければならず、解除原因を知っていた悪意の第三者は、登記を備えても保護されない。
  - 正解：×（誤り）
  - 理由：ただし書の第三者は善意・悪意を問わない。債務が履行される可能性がある以上、解除原因を知っていた第三者も保護対象となり、登記さえ備えれば保護される。分かれ目は善意悪意ではなく登記の有無。本問のCは登記を欠くから、悪意か否かを論じるまでもなく保護されない。
- **Q11［○×］** 177条の「第三者」とは、登記の欠缺を主張する正当な利益を有する者をいい、無権利者や不法占拠者はこれに含まれない（制限説）。
  - 正解：○（正しい）
  - 理由：大連判明治41・12・15の制限説。177条を文言どおり解すると無権利者・不法占拠者まで登記の欠缺を主張でき公平を欠くため、「第三者」を登記の欠缺を主張する正当な利益を有する者に限定する。無権利者Cは競争関係に立たず、この利益を有しない。
- **Q12［○×］** 無権利者と正当な権利者との間には対抗関係が生じないから、権利者は登記を備えていなくても、その物権変動を無権利者に対抗できる。
  - 正解：○（正しい）
  - 理由：177条の対抗問題は、両立しえない物権を相争う対抗関係にある者同士で登記の先後により優劣を決する仕組み。一方が無権利者なら、そもそも相争う関係にないから対抗関係は生じず、権利者は登記なくして無権利者に対抗できる。本問のCは無権利者ゆえ、Dは未登記でも対抗可。
