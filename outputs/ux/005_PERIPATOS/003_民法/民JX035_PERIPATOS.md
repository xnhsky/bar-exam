2. Fは423条の7でEのDに対する移転登記請求権を代位行使（無資力不要）

#### 第3　設問(3)

- 見出しの補足（結論を含む。項目の終わりに読む）：転用型・肯定
1. Iの支払拒絶＝同時履行の抗弁（533条）／代位の狙い＝抗弁の消滅
2. 【論点】転用型で無資力を要するか → 責任財産保全でないから無資力不要（最判昭50.3.6）
3. 代位でHが登記→抗弁消滅→代金回収＝保全との関係性あり

#### 第4　設問(4)

- 見出しの補足（結論を含む。項目の終わりに読む）：転用型・否定

2. 【論点】保全との関係性はあるか → 代位で債務者が受ける利益で債権者の権利が保全される関係を要す（最判昭38.4.23）
3. Jが得るのは建物代金債権（金銭債権）にすぎずLの賃借権は保全されない＝関係性なし

- 【拾う事実】『「建物買取請求権」（形成権・代金債権を生む）』 → 代位で得るのは金銭債権＝賃借権を保全せず
- 【事案の整理】矢印は2本だけ
  - 代位図は「債権者 ─被保全債権→ 債務者 ─被代位権利→ 相手方」の2本。設問(1)＝A→B→C（貸金／慰謝料）、(2)＝F→E→D（登記／登記）、(3)＝G→I→H（代金／登記）、(4)＝L→J→K（賃借権／建物買取請求権）。書けたら要件検討は半分終わり。
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 設問(1)なら①貸金は履行期到来・強制執行可能／②Bは無資力＝保全の必要あり／④Bは慰謝料請求せず＝不行使、はいずれも一文で素通り。立ち止まるのは③一身専属性だけ。ここに紙幅を寄せる。
- 【効く事実】あてはめで使う事実
  - 原則一身専属 → 慰謝料＝精神的苦痛の賠償・行使を本人の意思に委ねるべき人格的性格／前段 → 「慰謝料請求をしていない」＝額未確定＝否定／後段 → 「200万円の認容判決」＝額が客観的に確定＝肯定（未回収でも結論を左右しない）。
- 【規範の要点】転用型の規範
  - 無資力の要求は代位が責任財産保全に用いられることに由来する。だから責任財産保全を目的としない場合は無資力不要（最判昭50.3.6）。もっとも、代位により債務者が受ける利益によって債権者の権利が保全される関係は必要（最判昭38.4.23）。
- 【ポイント】(3)と(4)の分岐
  - 設問(3)＝代位でHが登記→Iの同時履行の抗弁（533条）が消え代金回収できる＝関係性あり→肯定／設問(4)＝代位でJが得るのは建物代金債権（金銭債権）にすぎず、Lの賃借権は保全されない＝関係性なし→否定。
- 【まぎらわしい選択肢・論点】詐害行為取消権の成否／中間省略登記請求の可否そのもの／同時履行の抗弁の成否
- 【まぎらわしい選択肢・結論】前段も代位が認められる／設問(4)も代位が認められる
- 【まぎらわしい選択肢・規範】無資力必要説／関係性は不要
- 【まぎらわしい選択肢・事実】回収済みであること／Iが無資力であること

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

(1)＝慰謝料は原則一身専属、額が客観的に確定で喪失→前段否定・後段肯定（＋423条の3で自己へ支払）。(2)＝中間省略登記は原則不可→423条の7で登記代位（無資力不要）。(3)＝転用型で無資力不要、同時履行の抗弁が消え代金保全→肯定。(4)＝転用型でも代金債権を得るのみで賃借権は保全されず関係性なし→否定。

## 3. 規範クイズ（全4問・1問目から最後まで全部出す）

- **［規範クイズ 1/4］** 債権者代位権の要件のうち「自己の債権を保全するため必要があるとき」が、原則型と転用型でどう違うかを述べよ。
  - 模範解答：原則型（責任財産の保全が目的＝被保全債権が金銭債権の通常の場合）＝債務者の無資力が必要。転用型（責任財産保全が目的でない）＝無資力不要。ただし転用型でも「代位により債務者が受ける利益で債権者の権利が保全される関係（保全との関係性）」は必要。
- **［規範クイズ 2/4］** 慰謝料請求権が債権者代位の対象となるか否かの判断基準と、その根拠（一身専属性がいつ失われるか）を述べよ。
  - 模範解答：慰謝料請求権は、賠償を請求するか・いくらで満足するかを本人の意思に委ねるべき人格的性格をもつため原則として行使上の一身専属権で代位不可。もっとも、加害者との間で具体的金額が客観的に確定した後は本人の意思を尊重する理由が失われ単純な金銭債権となり一身専属性を失うから代位できる（最判昭58.10.6）。基準＝額の客観的確定の有無（回収の有無は無関係）。
- **［規範クイズ 3/4］** 転用型の債権者代位権における「保全との関係性（債権保全の必要性）」の規範を述べ、これが認められる場合と認められない場合の典型を挙げよ。
  - 模範解答：規範＝代位行使により債務者が利益を享受し、その利益によって債権者の権利が保全される関係が存在することを要する（最判昭38.4.23）。この関係を欠けば「自己の債権を保全するため必要がある」といえず代位は否定される。認められる例＝同時履行の抗弁を消して代金を回収する場合（最判昭50.3.6・設問(3)＝肯定）。認められない例＝代位で得るのが金銭債権にすぎず、保全したい賃借権が守られない場合（設問(4)＝建物買取請求権の代位＝否定）。
- **［規範クイズ 4/4］** 不動産の転得者が登記を得るための法的手段（中間省略登記の可否と423条の7）を、順を追って述べよ。
  - 模範解答：①中間省略登記は物権変動の過程を登記に反映すべき要請から原則として認められない（最判昭40.9.21）。②そこで、譲受人は譲渡人が第三者に対して有する登記手続請求権を代位行使できる（423条の7）。同条は無資力を要件としない（登記請求権保全の転用型を明文化）。設問(2)＝Fは423条の7でEのDに対する移転登記請求権を代位行使できる。

（規範クイズはここまで＝全4問。最後の4問目まで出したら「規範クイズ、全4問クリア！」と言って次へ）

## 4. ○×クイズ（全12問・1問目から最後まで全部出す）

- **［○×クイズ 1/12］** 債権者代位権（423条）は、債権者が「債務者に属する権利（被代位権利）」を、自己の名で行使する制度である。債権者が第三者に対して有する自己の権利を行使するものではない。
  - 正解：○（正しい）
  - 理由：代位の対象は債務者が第三者に対して有する権利。だから常に「債権者→債務者→相手方」の三面になる。行使するのは自分の権利ではなく他人（債務者）の権利で、その効果は債務者に帰属するのが原則。
- **［○×クイズ 2/12］** 被代位権利が金銭の支払を目的とするときでも、代位債権者は相手方に対し「自己に支払え」と請求することはできず、必ず債務者に支払わせなければならない。
  - 正解：×（誤り）
  - 理由：被代位権利が金銭の支払・動産の引渡しを目的とするときは、債権者は相手方に自己への支払・引渡しを求めうる（423条の3）。債務者が受領を拒むと代位が空振りになるのを防ぐ趣旨。設問(1)後段でAはCに「自分に払え」と言える。
- **［○×クイズ 3/12］** 債権者代位権の要件は、①被保全債権の存在（原則、履行期到来・強制執行可能）、②自己の債権を保全する必要（原則型では債務者の無資力）、③被代位権利が一身専属権・差押禁止債権でないこと、④債務者がその権利を行使していないこと、である。
  - 正解：○（正しい）
  - 理由：この4要件が代位検討の「型」。②の「無資力」は原則型（責任財産保全）でのみ要求される点が転用型との分かれ目。
- **［○×クイズ 4/12］** 被保全債権は、必ず金銭債権でなければならず、登記請求権や賃借権のような非金銭債権を被保全債権として債権者代位権を行使することはできない。
  - 正解：×（誤り）
  - 理由：非金銭債権も被保全債権になりうる（＝転用型）。登記請求権保全は423条の7で明文化され（設問(2)）、賃借権保全も理論上は可（設問(4)）。ただし転用型は責任財産保全でないため無資力は不要で、代わりに「保全との関係性」が問われる。
- **［○×クイズ 5/12］** 転用型の債権者代位権では、代位により債務者が受ける利益で債権者の権利が保全される関係（保全との関係性）は不要であり、無資力さえ不要ならば常に代位が認められる。
  - 正解：×（誤り）
  - 理由：転用型でも「代位により債務者が受ける利益によって債権者の権利が保全される関係」は必要（最判昭38.4.23）。これを欠けば「自己の債権を保全するため必要がある」といえない。設問(3)＝関係性あり→肯定／設問(4)＝関係性なし→否定で、この一点が結論を分ける。
- **［○×クイズ 6/12］** 債権者は、その債権の期限（履行期）が到来しない間は、原則として被代位権利を行使できない。ただし、時効の完成猶予など保存行為はこの限りでない（423条2項）。
  - 正解：○（正しい）
  - 理由：被保全債権は原則履行期到来が必要（423条2項本文）で、保存行為は例外（同項ただし書）。さらに強制執行により実現できない債権では代位できない（同条3項）。設問(1)の貸金は「履行期の到来した」債権と明示されており、この要件は一文で通る。
- **［○×クイズ 7/12］** 差押えを禁じられた権利（差押禁止債権）であっても、債務者に属する権利である以上、債権者は常にこれを代位行使することができる。
  - 正解：×（誤り）
  - 理由：423条1項ただし書は「一身に専属する権利及び差押えを禁じられた権利」を代位の対象から除く。差押禁止債権は債務者の生活保障等のためのもので、責任財産の引当てにならないから代位もできない。除外事由は一身専属権と差押禁止債権の2つ。
- **［○×クイズ 8/12］** 加害者との間で慰謝料額が認容判決により客観的に確定しても、債権者が実際にその金銭を回収するまでは、慰謝料請求権はなお一身専属性を保持し、債権者代位の対象とならない。
  - 正解：×（誤り）
  - 理由：一身専属性を失わせる基準は額の客観的確定であって回収ではない。確定判決で額が確定すれば当事者間で客観的に確定したといえ、未回収でも代位できる（最判昭58.10.6）。
- **［○×クイズ 9/12］** 423条1項ただし書の「一身に専属する権利」とは、譲渡や相続になじまない権利（帰属上の一身専属権）を意味し、行使するか否かが権利者の意思に委ねられるという意味（行使上の一身専属権）ではない。
  - 正解：×（誤り）
  - 理由：代位で問題となるのは行使上の一身専属権（行使を専ら権利者の意思に委ねるべき権利）。帰属上の一身専属権（896条ただし書＝譲渡・相続になじまない権利）とは別概念で、両者を混同しないことが規範定立の前提。
- **［○×クイズ 10/12］** 被保全債権が金銭債権であれば、その代位行使は常に責任財産保全型（原則型）であり、債務者の無資力が要件となる。
  - 正解：×（誤り）
  - 理由：無資力の要否は「金銭債権か」ではなく「責任財産保全が目的か」で決まる。設問(3)は金銭債権（売買代金債権）だが、目的は同時履行の抗弁を消すこと＝責任財産保全でない転用型だから無資力不要（最判昭50.3.6）。
- **［○×クイズ 11/12］** 登記・登録を対抗要件とする財産を譲り受けた者は、譲渡人が第三者に対して有する登記手続請求権を譲渡人が行使しないとき、これを代位行使できる（423条の7）。この場合、譲渡人の無資力は要件とされない。
  - 正解：○（正しい）
  - 理由：423条の7は登記請求権保全の転用型を明文化した規定。準用されるのは423条の4〜6で、無資力を要求する規定は含まれないから無資力不要。中間省略登記が原則不可であるため、転得者に登記を得る手段を保障する趣旨。
- **［○×クイズ 12/12］** 数次に譲渡された不動産について、最終譲受人は、中間者の同意の有無にかかわらず、登記名義人に対して直接自己への移転登記（中間省略登記）を請求することができる。
  - 正解：×（誤り）
  - 理由：物権変動の過程を忠実に登記に反映すべき登記制度の趣旨から、中間者の同意なしに中間省略登記を請求することはできない（最判昭40.9.21）。現行不動産登記法（登記原因証明情報の要求）下ではいっそう困難。だからこそ423条の7による登記請求権の代位が必要になる。
