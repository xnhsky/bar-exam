- 見出しの補足（結論を含む。項目の終わりに読む）：94条2項・110条類推

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「登記済証、実印等を預けて長期間放置」 → 甲の帰責性の基礎（同視し得るほど重いか）
- 【拾う事実】「勝手に自己名義に所有権移転登記」 → 乙は無権利者（94条2項の直接適用を否定）
- 【拾う事実】「丙に対する債務を担保するため抵当権を設定・登記」 → 丙は乙名義を信頼／丁より先に取得
- 【拾う事実】「登記は、いまだ丁に移転されていない」 → 丁は対抗要件を欠く（177条の壁）
- 【拾う事実】「できる場合及びこれをすることができない場合」 → 丁の主観×丙の主観で場合分け
- 【事案の整理】まず「誰が本当の所有者か」
  - 出発点は甲＝真の所有者、乙＝勝手に登記した無権利者。ここを外すと全部ずれる。乙が作った「乙が所有者」という虚偽の外観を、丙（抵当権）と丁（買主）が信頼した二重構造を掴む。
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 「無権利者から買った」で即あきらめない。虚偽の外観があれば94条2項の類推で救済の道がある。まず通謀がないことを断って直接適用を否定し、そこから類推へ橋を架けるのが作法。
- 【効く事実】あてはめで使う事実
  - 帰責性 → 登記済証・実印等を預けて長期間放置＝自ら外観を作出した場合と同視し得るほど重い（意思外形非対応型・平18型）／主観 → 丁・丙それぞれの善意無過失／登記 → 丁は移転登記なし（94条2項類推では不要・177条では対抗の壁）。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 本問の骨格は同じ枠組みが二度回ること。丁の所有権取得で一度、丙が「第三者」になれるかでもう一度。抹消請求が通るのは丁が保護され（○）かつ丙が保護されない（×）ときだけ、と場合分けする。
- 【まぎらわしい選択肢・論点】通謀虚偽表示の成否／即時取得の成否／表見代理の成否
- 【まぎらわしい選択肢・結論】抹消請求は常に認められる／丁は登記なくして常に対抗できる
- 【まぎらわしい選択肢・規範】無制限説／公信の原則
- 【まぎらわしい選択肢・事実】通謀あり／丁は登記を具備

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

①丁＝無権利者乙から通謀なしで94条2項類推、甲は登記済証・実印の預託放置で同視し得るほど重い帰責性、110条併用で善意無過失なら所有権取得（登記不要）。②丙＝無権利者からの取得で原則「第三者」でない、but 丙自身が94条2項類推で保護されれば「第三者」。結論＝丁○かつ丙×のときだけ抹消請求可。

## 3. 規範クイズ（3問）

- **Q04［規範］** 94条2項を類推適用するための3要件を挙げよ。
  - 模範解答：①虚偽の外観の存在 ②真の権利者の帰責性 ③外観への（第三者の）信頼。94条2項を権利外観法理の一場面と捉え、この3要件が揃えば通謀がなくとも類推適用して第三者を保護する。帰責性が弱い意思外形非対応型では③に無過失まで要求（110条併用）。
- **Q05［規範］** 民法177条にいう「第三者」の意義（制限説による定義）を述べよ。
  - 模範解答：当事者及びその包括承継人以外の者で、登記の欠缺を主張する正当な利益を有する者に限られる（大連判明41.12.15）。自由競争の枠内で正当な利益を持つ者に不測の損害を与えないためである。無権利者・不法占拠者・背信的悪意者はこの正当な利益を欠くから除外される。
- **Q06［規範］** 無権利者から抵当権の設定を受けた者が、なお177条の「第三者」となりうる理路を述べよ。
  - 模範解答：無権利者から取得しても原則として権利を取得できず「第三者」に当たらない。もっとも、その取得者自身が94条2項・110条の類推適用により保護されれば、有効に権利（抵当権）を取得し、登記の欠缺を主張する正当な利益を有する「第三者」となる。丙が善意無過失なら、この理路で「第三者」となり、丁は対抗できない。

## 4. ○×クイズ（7問）

- **Q07［○×］** 所有権に基づく妨害排除請求権は、物権の効力から導かれる物権的請求権であり、明文の規定がなくても認められる。
  - 正解：○（正しい）
  - 理由：物権的請求権は物権の排他的支配性から当然に導かれ、明文はなくても承認される（占有訴権〔197条以下〕の存在等が根拠）。抹消登記手続請求は、この妨害排除請求権を根拠とする。まず「何権に基づく請求か」を確定するのが検討の第一歩。
- **Q08［○×］** 無権利者から不動産を譲り受けた者は、その者を所有者だと信じて取引したのであれば、原則としてその不動産の所有権を取得することができる。
  - 正解：×（誤り）
  - 理由：不動産には公信の原則がない（動産の即時取得〔192条〕のような制度がない）。したがって無権利者から譲り受けても原則として所有権を取得できない。信頼した第三者の保護は、94条2項の類推適用など個別の権利外観法理によってのみ図られる。「無権利者から買った＝即あきらめる」ではなく、外観法理で救えるかを検討する。
- **Q09［○×］** 登記の欠缺を主張する正当な利益を有しない無権利者は、民法177条の「第三者」に当たらない。
  - 正解：○（正しい）
  - 理由：177条の「第三者」は制限説により、当事者・包括承継人以外で登記の欠缺を主張する正当な利益を有する者に限られる（大連判明41.12.15）。実体上の権利を持たない無権利者はこの正当な利益を欠くから「第三者」に当たらない（最判昭34.2.12）。本問の丙が原則「第三者」でない出発点はここ。
- **Q10［○×］** 通謀虚偽表示（94条1項）が存在しない場合であっても、虚偽の外観・真の権利者の帰責性・その外観への第三者の信頼があるときは、94条2項を類推適用してその第三者を保護しうる。
  - 正解：○（正しい）
  - 理由：94条2項は、虚偽の外観を作出した本人と、その外観を信頼した第三者との権利外観法理（利益衡量）の規定と理解される。そうであれば、通謀がなくとも①虚偽の外観②真の権利者の帰責性③外観への信頼が揃えば同項を類推適用してよい（判例・通説）。本問の乙名義の不実登記がこの外観に当たる。
- **Q11［○×］** 94条2項の類推適用によって保護される第三者は、その保護を受けるために、あらかじめ登記を備えていなければならない。
  - 正解：×（誤り）
  - 理由：94条2項（類推を含む）の「第三者」は登記を備えることを要しない（最判昭44.5.27）。真の権利者と第三者は物権変動の当事者類似の関係に立ち、対抗問題ではないからである。本問で丁が移転登記を欠いても、94条2項類推による所有権取得の場面（要件①）では不利にならない。登記が壁になるのは177条の対抗（要件②）の場面。
- **Q12［○×］** 真の権利者が自ら虚偽の外観を作出したのではなく、これを放置したにとどまる意思外形非対応型でも、第三者は善意でありさえすれば保護され、無過失までは要求されない。
  - 正解：×（誤り）
  - 理由：真の権利者が自ら外観を作出しておらず帰責性が相対的に弱い意思外形非対応型では、両者の利益衡量上、第三者側により重い信頼＝善意かつ無過失を要求する（110条を併用類推）。これが最判平18.2.23の枠組み。本人が積極的に外観を作出・承認した対応型では善意で足りるのと対比する。
- **Q13［○×］** 登記の欠缺を主張することが信義則に反すると認められる背信的悪意者は、民法177条の「第三者」から除外される。
  - 正解：○（正しい）
  - 理由：単なる悪意者は「第三者」に含まれる（自由競争）が、登記の欠缺を主張することが信義則に反する背信的悪意者は正当な利益を欠き除外される（最判昭43.8.2）。本問では、丙は丁に先んじて抵当権を取得しているため背信的悪意者とは考え難く、この除外は問題になりにくい。
