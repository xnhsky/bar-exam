## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

Bは、老人ホームへの入居を考えていたところ、A社が販売する本件マンションのチラシに、購入者は近接地にA社が建設中の有料老人ホームへ先着順で優先的に入居できると謳われているのを見て魅力を感じた。A社担当者Cは、Bに対し、購入者には老人ホームの入居優先権がある旨と、老人ホームは1年後に完成予定である旨を述べた。そこでBはA社と本件マンションの売買契約（本件売買契約）を締結して代金を支払い、A社はマンションを引き渡し登記名義を移転した。ところがA社の業績が傾き、本件老人ホームの建設は頓挫。Cは繰り返し完成を約束したが、締結から半年後、Cは1年後の完成が不可能であることを認め謝罪した。〔設問1〕 Bは本件売買契約を解除したい。その主張は認められるか。〔設問2〕 本件売買契約時にBがA社と本件老人ホームに入居する契約（本件入居契約）を締結し1年分の利用料を前払していたとする。Bは本件入居契約だけでなく本件売買契約を解除できるか（契約書は別個・入居契約の締結は任意。設問1で論じた点には触れなくてよい）。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- チラシ・Cの説明（優先入居権／1年後完成予定）→ Bが魅力を感じる
- 本件売買契約締結・代金支払／A社が引渡し・登記移転（主たる給付＝履行済み）
- A社業績悪化 → 老人ホーム建設が頓挫
- Cは繰り返し完成を約束（Bは強く問い質せず半年経過）
- Cが1年後完成不能を認め謝罪 → Bが解除を望む

登場人物：

- A社｜売主・事業者（担当者C／→老人ホーム完成せず）

### 入口の問い（3問）

- **［入口 1/3・事案の整理］** 当事者と「解除したい対象」を挙げて
  - 答え：設問1が解除したい対象＝本件売買契約。ところが引渡し・登記・代金という主たる給付義務はすべて履行済み。だから解除原因は「老人ホームを1年後に完成させる」という付随義務の不履行に置くしかない ── ここに気づくのが第一歩。
  - 答え：設問2は別問題。本件入居契約は当然に解除できる（主たる給付義務の不履行）。的は「別個独立の本件売買契約まで巻き込めるか」の一点。設問1と設問2を混ぜないのが第一歩。
- **［入口 2/3・見当づけ］** 「何条の解除か」を先に（541か542か） ― 見当をつけて
  - 答え：本問の老人ホームはなお完成する余地があり、定期行為でもない（＝履行不能とまで断定しにくい）。だから541条の催告解除で処理するのが素直（542条は一応検討して採らない理由を一言）。設問2の入居契約も、履行遅滞として541条で解除する。
- **［入口 3/3・論点］** 設問1で問題になる論点を挙げて（3つ）
  - 答え：CP①：引渡し・登記・代金は履行済み → 解除原因を付随義務違反に定位できるか。（付随義務＝中核給付に付随して負う「老人ホームを1年後に完成させる」義務）
  - 答え：CP②：その付随義務違反が「軽微」（541条ただし書）でないか。（軽微＝当該債務が契約の重要な部分を構成しない、と評価される不履行）
  - 答え：CP③：（設問2）別個の入居契約の不履行を売買契約の解除原因にできるか（複合契約解除・手6へ）。

### 組み立ての順序（入口の問いのあと、骨子に入る前に読み上げる）

- 順番：第1　設問1 → 第2　設問2
- 第1　設問1

  - 論点2：不履行が「軽微」（541ただし書）でないか

### 骨子（2項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　設問1

- 見出しの補足（結論を含む。項目の終わりに読む）：本件売買契約の解除・541条
1. 引渡し・登記・代金は履行済み → 主たる給付義務の不履行では攻められない
2. 【論点】付随義務（老人ホーム完成義務）違反による解除の可否（規範：541本文は排除せず・ただし書「軽微」でなければ可）
3. 【論点】不履行が「軽微」（541ただし書）でないか → 債務の重要な部分を構成するか（社会通念）
   - あてはめ：優先権を大きく謳う・Cが完成予定説明・Bが魅力を感じ購入 ＝ 債務の重要な部分＝軽微でない
4. 帰責事由（543）＝不履行はA社の業績悪化・Bに帰責なし（債務者の帰責は不要）
- 結論：Bの本件売買契約の解除は認められる

#### 第2　設問2

- 見出しの補足（結論を含む。項目の終わりに読む）：複合的契約における解除
1. 入居契約＝主たる給付義務の不履行 → 当然に解除可（541）（軽微性は問題とならない）
2. 契約書別個・締結任意 → 2個の別個独立の契約（前さばき）→ 相対効が原則
3. 【論点】別個の契約の一体的解除の可否 → 目的の密接関連＋いずれかの履行だけでは目的不達成（最判平8.11.12）
   - あてはめ：入居目的で購入・1年分前払 ＝ 目的は密接関連・売買履行だけでは目的不達成
- 結論：本件入居契約だけでなく本件売買契約も解除できる

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】『「先着順で優先的に入居できる」とチラシで謳う』 → 売主が優先権を積極提示＝重要性
- 【拾う事実】『Cが「1年後完成予定」と説明』 → 債務の内容・重要性（軽微でない）
- 【拾う事実】『Bが優先権に「魅力を感じ」購入を決めた』 → 契約目的への直結
- 【拾う事実】『引渡し・登記・代金＝履行済み』 → 解除原因を付随義務違反に定位
- 【拾う事実】『契約書が別個・入居契約の締結は任意』 → 2個の別個契約（前さばき）
- 【拾う事実】『「何としても入居したい」・1年分前払』 → 売買履行だけでは目的不達成の決め手
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 催告＝BのCへの再三の督促／相当期間経過＝半年経過し完成不能が確定／帰責事由＝不履行はA社の業績悪化ゆえBに帰責なし＝543条の壁なし。詰まるのは④の「軽微」でないことと、そもそも付随義務違反を解除原因にできるかの2点。
- 【効く事実】効く事実（軽微でないこと）
  - 優先権をチラシで大きく謳う／Cが「1年後完成予定」を説明／Bが優先権に「魅力を感じ」購入を決めた／締結後もBが1年後入居の可否を問い合わせ。これらから「老人ホーム完成はA社の債務の重要な部分」＝軽微でない、へつなぐ。
- 【規範の要点】最判平8.11.12【百選Ⅱ44】の規範
  - 同一当事者間の二個以上の契約でも、目的が相互に密接に関連付けられ、社会通念上いずれかが履行されるだけでは契約を締結した目的が全体として達成されないと認められる場合は、一方の債務不履行を理由に、法定解除権の行使として両契約を併せて解除できる。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - ①541ただし書「軽微」（催告解除）↔ 542「契約目的不達成」（無催告解除）＝別基準／②付随義務違反でも軽微でなければ解除可（改正前の「契約目的達成不能」基準を承継・明文化）／③複合契約解除＝相対効の例外（密接関連＋目的不達成で一体解除）。この3本を言えれば、契約解除の地図は完成。
- 【まぎらわしい選択肢・論点】危険負担の成否／錯誤取消しの可否／履行不能による無催告解除の可否
- 【まぎらわしい選択肢・結論】本件売買契約の解除は認められない／本件売買契約は解除できない（相対効を貫く）
- 【まぎらわしい選択肢・規範】量的僅少説／相対効貫徹説
- 【まぎらわしい選択肢・事実】契約目的の達成不能／債務者A社の帰責事由

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 541条ただし書の「軽微」かどうかを判断する枠組みを述べよ（付随義務違反解除の核心）。
  - 模範解答：「その契約及び取引上の社会通念に照らして」、不履行の対象たる債務が契約において重要な部分を構成するか（当該不履行によって契約目的の達成が妨げられるか）を総合判断する。付随義務違反でも軽微でなければ解除可。＝ゴルフ場事件（最判平11.11.30）の「債務の重要な部分を構成するか」の枠組み。
- **［規範クイズ 2/3］** 別個独立の二契約でも、一方の不履行を理由に他方も解除できるための判例の二要件を述べよ（複合的契約の解除）。
  - 模範解答：①それらの目的が相互に密接に関連付けられていること ②社会通念上、いずれかが履行されるだけでは契約を締結した目的が全体としては達成されないと認められること（最判平8.11.12）。この二要件を充たせば、一方の債務不履行を理由に、法定解除権の行使として両契約を併せて解除できる（判例＝最判平8.11.12）。②を落として「密接関連性」だけにするのが典型ミス。
- **［規範クイズ 3/3］** 密接に関連する二契約について、相対効の原則を貫かず例外的に一体解除を認める根拠を述べよ。
  - 模範解答：密接に関連する二契約で一方だけ解除でき他方が残存するのは、両契約を結んだ当事者の合理的意思に反する。また解除は、相手方の債務不履行から解除権者を反対債務から解放し（先履行なら給付の取戻しも認め）て解除権者を保護する制度であり、一方だけの解除ではその保護が全うされない。だから解除権者保護の見地から相対効の例外を認める。

## 4. ○×クイズ（全7問・1問目から最後まで全部出す）

- **［○×クイズ 1/7］** 平成29年改正後の民法において、催告解除（541条本文）が認められるために、債務者の帰責事由は不要である。
  - 正解：○（正しい）
  - 理由：改正法は解除を「債務者への責任追及」ではなく「債権者を契約の拘束力から解放する手段」と位置づけたため、解除に債務者の帰責事由を要求しない。代わりに、不履行が債権者の責めに帰すべき事由によるときは解除できない（543条）という形で処理する。「解除には債務者の落ち度が要る」は改正前の発想で、今は誤り。
- **［○×クイズ 2/7］** 将来の完成余地が残る債務の不履行は、履行不能に当たるものとして、常に無催告解除（542条）で処理される。
  - 正解：×（誤り）
  - 理由：542条の無催告解除は「債務の全部の履行が不能」等、履行不能・履行拒絶が明白な場面の武器。なお完成の余地が残り定期行為でもない債務は履行不能と断じにくいから、相当期間を定めて催告する541条で処理するのが筋。「遅れている＝即・履行不能」ではない。まず541、履行不能が明白なときだけ542、と切り分ける。
- **［○×クイズ 3/7］** 契約の主たる給付義務そのものが履行されない場合、その不履行を理由とする解除では、541条ただし書の「軽微」性はほとんど問題とならない。
  - 正解：○（正しい）
  - 理由：「軽微」性（541条ただし書）は、不履行が契約の重要部分に関わるかを問う消極要件。主たる給付義務そのものの不履行は定義上その契約の中核を外すものだから、軽微とはまず評価されない。軽微性が本当に問題になるのは、中核給付は履行済みで付随義務違反を解除原因にする場面（＝設問1の売買契約）。だから設問2の入居契約解除では軽微性に立ち入らず一行で済む。
- **［○×クイズ 4/7］** 付随義務にすぎない義務の不履行は、それが契約にとってどれほど重要であっても、541条によって契約全体を解除する理由にはできない。
  - 正解：×（誤り）
  - 理由：541条本文は付随義務違反による解除を排除していない。ただし書は不履行が「軽微」なとき解除を否定するにとどまるから、逆に言えば付随義務違反でも「軽微」でなければ解除できる。したがって、その付随義務が契約の重要な部分を構成する場合は、契約全体の解除が可能。「付随義務違反＝解除不可」と決めつけるのが典型的な誤り。
- **［○×クイズ 5/7］** 541条ただし書の「軽微」と542条の「契約をした目的を達することができない」は同一の基準であり、催告解除でも契約目的が達成不能であることまで要求される。
  - 正解：×（誤り）
  - 理由：両者は別個の基準。催告解除（541条）は不履行が「軽微でない」で足り、無催告解除（542条）が要求する「契約目的の達成不能」までは不要。催告解除の方が重大性のハードルは低い。だから設問1は、老人ホーム完成が「債務の重要な部分」で軽微でないと言えれば解除でき、契約目的不達成まで論証する必要はない。両者を混同すると、余計な立証を背負って失点する。
- **［○×クイズ 6/7］** 契約書が別個に作成され締結も任意である二つの契約は、原則として別個独立の契約と評価され、一方の債務不履行は他方の契約の解除原因とならない（契約の相対効）。
  - 正解：○（正しい）
  - 理由：契約の効力は当事者が結んだその契約ごとに生じる（相対効）から、別個独立の契約が2個あるなら、一方の不履行は他方の解除原因にならないのが原則。設問2はまずこの原則を出発点に置き（＝前さばき）、そのうえで例外を認める判例規範へ進む。
- **［○×クイズ 7/7］** 平成29年改正により、付随義務違反による解除を制限した改正前の判例法理（最判昭36.11.21）は完全に否定され、現在は付随義務の不履行では一切契約を解除できない。
  - 正解：×（誤り）
  - 理由：改正前の判例は付随義務違反による解除を「契約目的の達成が妨げられる」場合に限定していた。改正後541条ただし書の「軽微」性要件は、この判例法理を否定したのではなく承継し明文化・一般化したもの。したがって現在も、付随義務違反でも不履行が「軽微」でなければ解除できる。「付随義務違反では一切解除不可」は誤り。
