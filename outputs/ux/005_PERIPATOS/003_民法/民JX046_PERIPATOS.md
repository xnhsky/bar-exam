### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「引渡しを受けた」 → 賃借権の対抗要件具備（借地借家31）＝地位移転の入口
- 【拾う事実】『「所有権移転登記」＝B→C売却』 → 賃貸人たる地位の移転・敷金承継
- 【拾う事実】「引渡しを拒絶する」 → 留置権・同時履行の抗弁＝弁済期を問う
- 【拾う事実】「物上代位により差し押さえた」 → 抵当権の効力が賃料に及ぶ・優劣問題の土台
- 【拾う事実】「差押え前に取得した貸金債権」 → 相殺の自働債権・設定登記との前後は不明
- 【拾う事実】「敷金が充当されるため消滅」 → 充当の法的性質＝相殺か当然の効果か
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 設問1前段＝対抗要件（借地借家31）→地位移転（605の2 I）→敷金承継（同IV）で一直線。設問2の土台＝物上代位の成立（304・372）は争いなく一言。
- 【効く事実】「相殺と物上代位の優劣」のあてはめで使う事実
  - Aの貸金債権は差押えの前に取得（＝511条だけなら相殺可に見える）／しかし抵当権設定登記との前後は不明。だから優劣の基準を「登記の前後」に置き換えたうえで場合分けして結論を出す。差押えの前後で断定しないこと。
- 【規範の要点】平成14年判決の規範
  - 敷金の充当による未払賃料の消滅は、敷金契約から生ずる当然の効果であって、相殺のように当事者の意思表示を必要としない。だから意思表示を前提とする511条に妨げられず、賃貸借終了・明渡し時に賃料債権は敷金の限度で当然消滅する。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 設問2(2)で「敷金充当は相殺ではないから、(1)で述べた相殺の優劣の自説とも矛盾しない」と整合性を明示する一文を入れる。平成13年・平成14年の関係を理解している証になる。ここが平均と上位を分ける。
- 【まぎらわしい選択肢・論点】背信的悪意者の排除／即時取得の成否／債権譲渡の対抗要件
- 【まぎらわしい選択肢・結論】Bに対して請求／抗弁も認められる／Aの相殺は常に認められる／Aの反論は認められない
- 【まぎらわしい選択肢・規範】差押えの前後で判断／充当は相殺の一種
- 【まぎらわしい選択肢・事実】意思表示が必要／先取特権の消滅

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

設問1＝対抗要件→地位移転(605の2 I)→敷金承継(IV)＝Cに請求／抗弁は明渡し前で弁済期未到来(622の2 I①)＝不可。設問2(1)＝511を受けて射程外→設定登記の前後(平13)→登記との前後不明で場合分け。設問2(2)＝敷金充当は当然の効果で相殺でない(平14)→511・平13に触れず→当然消滅＝反論可、(1)と矛盾なし。

## 3. 規範クイズ（3問）

- **Q04［規範］** 賃貸人たる地位の移転（民法605条の2第1項）の要件と、それに伴う敷金返還債務の帰趨を条文とともに述べよ。
  - 模範解答：要件＝①賃借人が賃貸借の対抗要件を具備（借地借家31条・民法605条）＋②不動産の譲渡。効果＝賃貸人たる地位が承諾なく譲受人へ当然移転（605条の2第1項）。敷金返還債務も譲受人へ承継される（同条4項）。留保特約があれば移転しない（同条2項）。
- **Q05［規範］** 物上代位により差し押さえられた賃料債権を受働債権とする、賃借人からの相殺の可否の規範を、判断基準時とその理由づけとともに述べよ。
  - 模範解答：抵当権者が物上代位権を行使して賃料債権を差し押さえた後は、賃借人は、抵当権設定登記の後に賃貸人に対して取得した債権を自働債権とする相殺をもって抵当権者に対抗できない（最判平13.3.13）。理由＝物上代位により抵当権の効力が賃料債権に及ぶことは設定登記により公示されているから、登記後に取得した債権との相殺に対する賃借人の期待を抵当権の効力に優先させる理由はない。
- **Q06［規範］** 物上代位による差押えの後に発生する敷金の充当が、511条1項や平成13年判決に抵触しない理由を述べよ。
  - 模範解答：敷金充当は敷金契約から生ずる当然の効果で、相殺のように意思表示を要しないから、意思表示を前提とする511条によって当然消滅の効果は妨げられない（最判平14.3.28）。また抵当権者は差押え前は用益関係に介入できず、賃料債権はもともと敷金充当を予定した債権だから、明渡し時に残存賃料は敷金の限度で当然消滅し、賃借人はこれを抵当権者に対抗できる。相殺の優劣（平成13年）とは「意思表示の要否」で切り分けられ矛盾しない。

## 4. ○×クイズ（8問）

- **Q07［○×］** 建物の賃借人は、賃借権の登記がなくても、建物の引渡しを受けていれば、その後にその建物について物権を取得した第三者に賃借権を対抗することができる。
  - 正解：○（正しい）
  - 理由：借地借家法31条により、建物の引渡しがあれば登記がなくても対抗力が生じる。これが「賃貸借の対抗要件を備えた場合」（民法605条の2第1項）に当たり、賃貸人たる地位の当然移転を基礎づける入口になる。誰に請求するかを決める第一歩が対抗要件の有無。
- **Q08［○×］** 抵当権者は、抵当不動産から生じる賃料債権に対しても、その払渡し前に差押えをすれば、物上代位権を行使することができる。
  - 正解：○（正しい）
  - 理由：物上代位（304条）は372条により抵当権に準用され、目的物の「賃貸」による金銭（賃料）に及ぶ。行使には払渡し前の差押えを要し、これは第三債務者の二重弁済を防ぐ趣旨。抵当権者が賃料を掴む土台がここにある。
- **Q09［○×］** 敷金返還請求権は、賃貸借が終了しただけでは足りず、賃借人が賃貸物を明け渡した時に発生する（明渡し先履行）。
  - 正解：○（正しい）
  - 理由：民法622条の2第1項1号は、賃貸借が終了し「かつ賃貸物の返還を受けたとき」に返還債務が生じると定める（最判昭48.2.2の条文化）。明渡しが先履行だから、明渡し前は敷金返還請求権の弁済期が未到来＝これが設問1後段の抗弁を切る決め手になる。
- **Q10［○×］** 対抗要件を備えた賃借人がいる不動産が譲渡されて賃貸人たる地位が移転したときは、敷金の返還に係る債務は当然に譲受人に承継される。
  - 正解：○（正しい）
  - 理由：民法605条の2第1項で賃貸人たる地位が譲受人に当然移転し、同条4項により敷金返還債務も譲受人へ移転する。だから賃借人は原則として新所有者（譲受人）に敷金返還を請求する。返還額は敷金から未払賃料等を控除した残額（最判昭44.7.17）。
- **Q11［○×］** 留置権が成立するには被担保債権が弁済期にあることを要するが、同時履行の抗弁権については、反対債権が弁済期にあることは要件とされていない。
  - 正解：×（誤り）
  - 理由：どちらも「弁済期にあること」を要求する。留置権は295条1項ただし書、同時履行の抗弁は533条ただし書が、相手方（被担保・反対）債権が弁済期にないときは主張できないと定める。両者を並べて「弁済期未到来なら抗弁は立たない」と処理するのが本問後段の型。
- **Q12［○×］** 抵当権者が物上代位により賃料債権を差し押さえた後の相殺の優劣は、賃借人が自働債権を「差押えの前に取得したか後に取得したか」を基準として判断される。
  - 正解：×（誤り）
  - 理由：基準は「差押えの前後」ではなく抵当権設定登記の前後（最判平13.3.13）。賃借人は、設定登記の後に賃貸人に対して取得した債権を自働債権とする相殺をもって抵当権者に対抗できない。物上代位により抵当権の効力が賃料に及ぶことは登記で公示済みだから、登記後の相殺への期待を抵当権に優先させる理由がない。この取り違えは−15〜20点級の失点。
- **Q13［○×］** 敷金による未払賃料の充当は、賃借人が充当の意思表示をすることによって生ずる効果であり、相殺の一種として扱われる。
  - 正解：×（誤り）
  - 理由：敷金充当は敷金契約から生ずる当然の効果であり、賃借人の意思表示を要しない（最判平14.3.28）。むしろ賃借人の側から敷金を債務の弁済に充てることを請求できない（622条の2第2項後段）。相殺と性質が異なるからこそ、意思表示を前提とする511条や平成13年判決に妨げられずに物上代位に優先する。「相殺」として処理すると−10〜15点級の失点。
- **Q14［○×］** 民法511条1項は、差押えと相殺の優劣を規律する規定であって、抵当権に基づく物上代位と相殺との優劣を直接規律するものではない。
  - 正解：○（正しい）
  - 理由：511条は一般の差押え（処分禁止効）と相殺の優劣を定めるもので、物上代位と相殺の優劣はその射程外。だから物上代位が絡む場面ではまず511条を受け止めて「射程外」と切り、優劣は抵当権設定登記の前後で判断する（平成13年）。敷金充当は相殺でないためそもそも511条に妨げられない（平成14年）。まず条文を受けてから射程を切る手順が要。
