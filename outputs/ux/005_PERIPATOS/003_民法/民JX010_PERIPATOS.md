登場人物：
- A｜本人・夫（乙を単独所有・入院後死亡）

### 入口の問い（3問）

- **［入口 1/3・事案の整理］** 登場人物と「Eの請求・効果帰属の骨格」を挙げて

  - 答え：Bは「Aの代理人」と顕名して契約したが代理権を授与されていない＝典型的な無権代理（113条1項）。ここを外すと筋が立たない。
- **［入口 2/3・見当づけ］** Eの取りうる「手段」 ― 見当をつけて
  - 答え：効果帰属：①有権代理（事前の授権。ここに日常家事代理権761条）→②追認・追認強制（事後の授権。ここに無権代理と相続）→③表見代理（110条趣旨類推）。全部ダメなら責任追及：④無権代理人の責任（117条）。

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「Aの代理人と称し」「Aの承諾なし」 → 無権代理の確定（顕名＋代理権なし）
- 【拾う事実】『A・Bは夫婦／目的物は不動産』 → 日常家事代理権と範囲判断（761条）
- 【拾う事実】『乙は約1年半空き家・価格も相応・実印使用』 → Eの無過失（117条2項）＝正当理由には使わない
- 【拾う事実】『Bは自分に代理権がないと知っていた』 → 117条2項2号但書（悪意）でなお責任
- 【拾う事実】『誰が誰の地位を先に相続したか』 → 追認拒絶の可否・小問(2)(3)の分岐
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 任意代理権＝授与なし・一言で否定／法定代理権＝夫婦だから日常家事代理権あり（761条は相互に代理権を授与する趣旨と読む）／範囲判断＝乙不動産の売却は明らかに日常家事の範囲外＝有権代理否定。ここはあっさりでよい。
- 【効く事実】効く事実の振り分け（最重要）
  - 正当理由（論点1）に使う事実＝「乙の売却が日常家事の範囲内」だとEが信じたかだけ。Bの困窮・価格が良かった・実印使用は正当理由に使わず、後の117条の無過失（論点2）で使う。
- 【ポイント】117条の通し方
  - Eは善意（代理権不存在を知らない）。無過失も、乙が約1年半空き家・自宅の甲と違い売られてもおかしくない・価格も相応・実印使用から肯定。仮にEに過失があっても、Bは自己に代理権が無いことを知っていた（悪意）から2項2号但書でなお責任。
- 【まぎらわしい選択肢・論点】94条2項類推適用の可否／177条の対抗問題／即時取得の成否
- 【まぎらわしい選択肢・結論】BE間売買は当然有効／表見代理成立で効果帰属
- 【まぎらわしい選択肢・規範】109条(代理権授与表示)／110条を直接適用
- 【まぎらわしい選択肢・事実】Eの登記具備／背信的悪意

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

(1)A・E＝有権代理は761条でも不動産売却は範囲外で×、追認は本人相続で拒絶可、表見代理は110条趣旨類推だが範囲内と信じる正当理由なしで×、よって117条責任・困窮は無過失で使い履行不可で損害賠償のみ。(1)C・E＝Cも117条責任を承継（損害賠償）。(2)＝無権代理人相続後に本人相続で当然有効（昭63.3.1）。(3)＝本人相続が先なら拒絶可。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 日常家事代理権を基本代理権とする表見代理につき、判例が110条を「直接適用」せず「趣旨を類推」し、正当理由の対象を絞る理由と絞込みの内容を述べよ。
  - 模範解答：理由＝日常家事代理権を基礎に広く110条を認めると夫婦の財産的独立を害するおそれがある。そこで直接適用を避けて趣旨を類推し、正当理由の対象を「代理権の存在を信じたこと」ではなく「当該行為が当該夫婦の日常家事の範囲内に属すると信じたこと」に絞る（最判昭44.12.18）。
- **［規範クイズ 2/3］** 無権代理人の責任（117条）の要件・免責事由と、本人が無権代理人を相続した場合の効果の限定を述べよ。
  - 模範解答：要件＝①代理権を証明できず②本人の追認がないこと。効果＝相手方の選択により履行または損害賠償（1項）。免責＝相手方が代理権不存在につき悪意・有過失（2項1号・2号本文）。ただし無権代理人が悪意なら2項2号但書でなお責任。もっとも本人が無権代理人を相続した場合は、追認拒絶の趣旨を没却しないため、相手方は履行請求はできず損害賠償に限定される（最判昭40.6.18）。
- **［規範クイズ 3/3］** 無権代理人を（本人とともに）相続した者が、その後さらに本人を相続した場合の処理を述べよ（最判昭63.3.1）。
  - 模範解答：無権代理人の地位を包括承継した者は、その後本人を相続しても本人の資格で追認を拒絶する余地はなく、本人自ら法律行為をしたと同様の法律上の地位・効果を生ずる（最判昭63.3.1）。よって無権代理行為は当然有効となる。逆に本人の地位を先に相続していた場合（小問(3)）は、先に取得した追認拒絶の地位により拒絶しうる。

## 4. ○×クイズ（全8問・1問目から最後まで全部出す）

- **［○×クイズ 1/8］** 代理人が「本人の代理人」であることを示して（顕名して）相手方と契約したが、実は代理権を有しなかった場合、その法律行為の効果は原則として本人に帰属しない。
  - 正解：○（正しい）
  - 理由：代理権を欠く代理行為は無権代理であり、本人が追認しない限り本人に効果は帰属しない（113条1項）。まず「顕名あり＋代理権なし＝無権代理」と枠を確定させるのが検討の起点。ここから相手方Eの救済手段の検討が始まる。
- **［○×クイズ 2/8］** 無権代理行為について本人が追認を拒絶したときは、相手方はもはや無権代理人に対して何らの責任も追及することができない。
  - 正解：×（誤り）
  - 理由：本人の追認拒絶で効果帰属は否定されるが、相手方は無権代理人に対し履行または損害賠償の責任を追及できる（117条1項）。効果帰属（本人へ）と責任追及（無権代理人へ）は別ルート。効果帰属が全て潰れた後の受け皿が117条。
- **［○×クイズ 3/8］** 権限外の行為の表見代理（110条）が成立するためには、代理人に何らかの基本代理権（権限）が存在することが前提として必要である。
  - 正解：○（正しい）
  - 理由：110条は「その権限外の行為」を要件とし、代理人に何らかの基本代理権があることを前提とする。基本代理権が全く無ければ110条は問題にならない。本問では日常家事代理権（761条・法定代理権）を基本代理権にできるかが、まさに次のステップの山になる。
- **［○×クイズ 4/8］** 判例・通説によれば、民法761条（日常家事債務の連帯責任）は、夫婦が相互に日常の家事に関する法律行為につき法定代理権を有することを前提としている。
  - 正解：○（正しい）
  - 理由：761条は文言上「連帯してその責任を負う」としか定めないが、判例・通説は、夫婦の一方が日常家事につき法律行為をなす前提として、相互に日常家事代理権（法定代理権）を有すると解する。この法定代理権を110条の基本代理権に据えられるかが、本問の表見代理の入口になる。
- **［○×クイズ 5/8］** 夫婦の一方が他方所有の不動産を売却する行為は、その夫婦の資産・収入が高額であれば「日常の家事に関する法律行為」の範囲に含まれる。
  - 正解：×（誤り）
  - 理由：「日常の家事」の範囲は、夫婦の社会的地位・資産・収入等の主観的事情だけでなく、客観的に当該行為の種類・性質をも考慮して判断する（最判昭44.12.18）。不動産（土地・建物）の売却は、その価額・性質に照らしおよそ日常家事に属さず、資産が大きくても範囲内にはならない。範囲を主観的事情だけで広げる誤りに注意。
- **［○×クイズ 6/8］** 日常家事代理権を基本代理権とする場合、判例は110条を直接適用せず趣旨を類推し、相手方が「当該行為が当該夫婦の日常家事の範囲内に属する」と信ずるにつき正当理由があるときにかぎり第三者を保護する。
  - 正解：○（正しい）
  - 理由：最判昭44.12.18の規範そのもの。財産的独立を守るため、正当理由の対象を「代理権があると信じた」ではなく「日常家事の範囲内だと信じた」に絞る。本問では乙の売却を日常家事の範囲内とEが信じる正当理由はなく、表見代理は否定される。
- **［○×クイズ 7/8］** 無権代理人の責任（117条1項）は常に相手方の選択に従うから、本人の地位を相続した無権代理人であっても、相手方が履行を選択すれば当然に履行義務を負う。
  - 正解：×（誤り）
  - 理由：本人が無権代理人を相続した場合、本人は追認を拒絶できる（最判昭37.4.20）のだから、相続した117条責任について履行請求まで認めると追認拒絶の趣旨を没却する。そこで相手方は損害賠償を請求しうるにとどまり、履行請求はできない（最判昭40.6.18）。「常に選択できる」は誤り。
- **［○×クイズ 8/8］** 本人が無権代理人を相続した場合、相続人たる本人は、被相続人がした無権代理行為の追認を拒絶することができ、無権代理行為が当然に有効となるものではない。
  - 正解：○（正しい）
  - 理由：本人相続型では、相続人たる本人が自ら無権代理をしたわけではない以上、追認を拒絶しても何ら信義に反しない。よって当然有効とはならず、本人は追認を拒絶できる（最判昭37.4.20）。無権代理人が本人を相続する場合（追認拒絶は信義則違反で許されない）と逆向きになる点が混同しやすい。

（○×クイズはここまで＝全8問。最後の8問目まで出したら「○×クイズ、全8問クリア！」と言って復習へ）
