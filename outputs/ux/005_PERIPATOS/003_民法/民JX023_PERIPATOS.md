### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「AがBから預かっていたにすぎない」 → Aは無権利者（小問1の出発点）
- 【拾う事実】「Bの承諾なしに、自己のものとして」 → 承継取得は不可・即時取得へ
- 【拾う事実】『現在Cが所持／Aに引き渡し／Bに返還』 → 占有の所在＝対抗力の分岐
- 【拾う事実】「50万円の貸金債権の担保のため」 → 原質権の担保価値＝転質の上限
- 【拾う事実】『小問2も「Bの承諾なしに更にCに」』 → 責任転質（承諾不要型）
- 【争いのない要件】論点にならず、あっさり認定する要件
  - (1)＝Cが占有継続 → 対抗の問題は起きず100万円可。(2)＝相手Aは設定の当事者 → 「第三者」（352条）でない → 対抗要件不要で100万円可。(3)＝相手Bは第三者＋継続占有なし → 対抗不可で0円。同じ判例法理を当事者/第三者で振り分けるだけ。
- 【効く事実】あてはめで使う事実
  - 即時取得 → Aは無権利者・Cは取引行為（質権設定）で占有取得／善意無過失 → 問題文に明示なし → 「Cが善意無過失であれば」と条件付き／対抗 → (2)Aは当事者／(3)Bは第三者＋継続占有なし。事実は必ず要件に結びつける。
- 【規範の要点】質物質入説の規範
  - 転質は、原質権者が把握する質物の交換価値そのものを再度質入れする行為 → 転質権者Cが取れるのは原質権の担保価値＝50万円が上限。かつ原質権設定者Bを害せないから、BのAに対する債務の弁済期到来後にしか実行できない。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 本問の隠れた背骨は即時取得。小問1(1)で使い、小問2でもう一度使う。
- 【まぎらわしい選択肢・論点】背信的悪意者の排除／共同質入説の可否／流質契約の禁止
- 【まぎらわしい選択肢・結論】質権は消滅する／100万円全額の弁済を受けられる
- 【まぎらわしい選択肢・規範】効力存続要件説／共同質入説
- 【まぎらわしい選択肢・事実】引渡しは一度で足りる／承諾ある転質

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

1(1)＝192条は質権を含む、善意無過失なら即時取得、100万可。1(2)＝返しても質権は消えず対抗力だけ喪失、Aは当事者だから対抗要件不要、100万可。1(3)＝Bは第三者＋継続占有なし、対抗不可、0円。2＝責任転質、質物質入説で担保価値50万が上限、B弁済期到来後、50万（知らなければ即時取得で100万）。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 質権者が設定者に質物を返還したときの質権の帰趨について、通説・判例（大判大正5年12月25日）の規範を、その理由（質権の本質）まで述べよ。
  - 模範解答：質権は消滅せず、352条により第三者への対抗力を失うにとどまる。理由＝質権の本質は優先弁済的効力にあり、占有の継続（留置的作用）はこれを確保・促進する補助手段にすぎないから。345条は効力存続要件ではなく対抗要件の問題として位置づける。
- **［規範クイズ 2/3］** 質権が即時取得（192条）の対象になる理由を、条文の文言に即して述べよ。
  - 模範解答：192条は「動産について行使する権利」を取得すると定め、所有権に限定していない。質権は目的物の占有を要素とする物権であり（342条・344条）、この「行使する権利」に含まれる。ゆえに占有への公信力が及び、無権利者から質権の設定を受けた者も善意無過失なら質権を即時取得する。
- **［規範クイズ 3/3］** 質物質入説と共同質入説（債権質入説）の対立点と、両説で結論に差が出る唯一の場面を述べよ。
  - 模範解答：対立点＝転質で質入れされる客体。質物質入説＝質物の交換価値のみ／共同質入説＝質物＋原質権の被担保債権。取れる金額（50万円）も実行時期（B債務の弁済期到来後）も両説で同じ。差が出る唯一の場面は、原質権者AのBに対する原債権そのものを目的として質権を実行できるか＝共同質入説は可・質物質入説は不可、この一点のみ。

## 4. ○×クイズ（全7問・1問目から最後まで全部出す）

- **［○×クイズ 1/7］** 質権は、目的物の占有を債権者に移転し、その物から他の債権者に優先して弁済を受けることを内容とする約定担保物権である。
  - 正解：○（正しい）
  - 理由：質権（342条）は、債権者が債権の担保として債務者等から受け取った物を占有し、その物につき他の債権者に先立って弁済を受ける権利。占有の移転を要素とし、優先弁済的効力を本質とする点が、以後のすべての場面判断の土台になる。
- **［○×クイズ 2/7］** 即時取得（192条）は所有権の取得のみを対象とする制度であり、質権のように占有を要素とする担保物権を即時取得によって取得する余地はない。
  - 正解：×（誤り）
  - 理由：192条は「動産について行使する権利」を取得すると定め、これを所有権に限らない。質権は目的物の占有を要素とする物権であり（342条・344条）、この「行使する権利」に含まれる。したがって無権利者から質権の設定を受けた者も、占有への公信力によって質権を即時取得しうる。
- **［○×クイズ 3/7］** 動産質権を第三者に対抗するには、質権者が質物を継続して占有することを要する（352条）。占有を失えば、質権そのものは存続していても第三者への対抗力を失う。
  - 正解：○（正しい）
  - 理由：352条は動産質の対抗要件を「継続占有」と定める。ここが所有権移転の対抗要件（178条の引渡し＝一度あれば足りる）と決定的に違う。継続占有を失うと、質権は消えないが第三者に主張できなくなる。取得の問題と対抗の問題を切り分ける鍵。
- **［○×クイズ 4/7］** 質権者が質権設定者に質物を返還した場合、345条に反する以上、質権はその効力を失って消滅する。
  - 正解：×（誤り）
  - 理由：345条違反は質権を消滅させない。質権の本質は優先弁済的効力にあり、占有継続（留置的作用）はそれを確保・促進する補助手段にすぎない。したがって設定者に返しても質権自体は存続し、352条により第三者への対抗力を失うにとどまる（大判大正5年12月25日）。「消滅する」と書くのが本問最大の落とし穴。
- **［○×クイズ 5/7］** 動産質権を即時取得するには、平穏・公然・善意・無過失で占有を取得すれば足り、前主との間に売買・質権設定契約などの取引行為が介在することは要件ではない。
  - 正解：×（誤り）
  - 理由：即時取得は取引行為（有効な取引の外形）による占有取得を要件とする。占有への公信力で相手方（取引の安全）を保護する制度だから、取引に基づかない占有取得（例：盗取・相続）では働かない。本問はA・C間の質権設定契約という取引行為があり、この要件は充たす。
- **［○×クイズ 6/7］** 責任転質において質物質入説（通説）を採ると、転質権者が把握できるのは原質権者が把握していた担保価値の範囲に限られ、原質権の被担保債権額を超えて優先弁済を受けることはできない。
  - 正解：○（正しい）
  - 理由：質物質入説は、転質を原質権者が把握する質物の交換価値の再質入れと解する。原質権者Aが把握していたのは原質権の担保価値（被担保債権50万円）だけだから、転質権者Cもその範囲でしか権利を取得できない。100万円全額を取れると誤るのが本問の典型失点。
- **［○×クイズ 7/7］** 責任転質において、転質権者が原質権の担保価値の限度を超える被担保債権を有し、その担保価値の制限を善意・無過失で知らなかった場合には、192条により、その被担保債権額に応じた質権を即時取得する余地がある。
  - 正解：○（正しい）
  - 理由：転質権者が原質権の担保価値の制限を善意・無過失で知らなかったときは、占有への公信力（即時取得）により、制限のない質権を取得しうる。本問ではCが「Aの担保価値は50万円」と知らずに100万円を担保に取った場合、100万円の質権を即時取得できる。小問1(1)の即時取得の規範をそのまま流用する場面。
