## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

Bは、Aから甲建物の所有権を相続し、移転登記を了した。その後、甲建物はBからCに譲渡されたが、いまだに移転登記がなされていない。甲建物は、Aがその所有権を有していた当時から敷地利用については無権原であった。甲建物の建っている土地の所有者Dは、甲建物の収去・土地明渡を求めたい。Dは誰に対して請求をすればよいか。甲建物が未登記建物であった場合はどうか。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- A所有時から甲建物は敷地利用が無権原（D所有地を占拠）
- A死亡 → BがAから甲建物を相続（896条）＋移転登記を了する
- BからCへ甲建物を譲渡（C名義への移転登記は未了＝名義はBのまま）
- 土地所有者Dが収去・土地明渡を求める（相手方はB？C？）
- 場合分け：甲建物が未登記であったらどうか（後段）

### 参考（読み上げない。入口の問いの答えを含むので判定にだけ使う）

登場人物：
- D｜土地所有者・請求者（→建物収去土地明渡を求める）
- C｜現・建物所有者（B→C譲渡・移転登記は未了）
- B｜相続人・登記名義を保有（A→B相続・移転登記済）
- A｜元・建物所有者／死亡＝相続の前主

一行要約：甲建物はA→B（相続・登記済）→C（譲渡・登記未了）。現所有者C／名義はBのねじれ。無権原でD所有地を占拠。

### 入口の問い（3問）

- **Q01［事案の整理］** 登場人物と「権利変動・登記の所在」を挙げて
  - 答え：請求者はD（土地所有者）。相手方候補はC（現に建物を所有・登記未了）とB（建物は譲渡済みだが登記名義を保有）。Aは死亡した前主で相手方にならない。
  - 答え：建物所有権の流れは A → B（相続・移転登記済）→ C（譲渡・登記未了）。今の所有者はC、名義はBという「ねじれ」が本問の核。
- **Q02［見当づけ］** 「どんな請求が立つか」 ― 見当をつけて
  - 答え：甲建物が敷地たるD所有地を無権原で占拠＝土地所有権の妨害。Dが求めるのは妨害の除去＝建物収去・土地明渡＝土地所有権（206条）に基づく妨害排除請求権。ここまでは争いなし。焦点は「誰を相手方とするか」。
- **Q03［論点］** 問題になる論点を挙げて（3つ）
  - 答え：CP①：相手方の決定基準＝現に建物を所有し土地を占拠する者（原則）。（＝名義ではなく現実の所有が基準）
  - 答え：CP②：登記名義だけ残るBを相手方にできるか（例外＝平6.2.8）。（自ら登記を経由し、なお保有＝喪失主張できない）
  - 答え：CP③：甲建物が未登記なら（後段）。（例外則の要件①を欠く＝Bには請求できない）

### 骨子（3項目。第1から【論点】ごとに、何が問題→規範→使う事実→結論 の順で組み立てる）

#### 第1　Cに対する請求

- 見出しの補足（結論を含む。項目の終わりに読む）：原則
1. Dの土地所有権に基づく物上請求（妨害排除）＝建物収去・土地明渡／甲建物が無権原で占拠＝妨害
2. 【論点】物権的請求権の相手方 → 規範：現に建物を所有し土地を占拠する者
   - あてはめ：建物の所有は必然的に敷地の占有を伴う（∴現実の所有＝占有の帰属）
3. あてはめ：A→B（相続896）→C（譲渡）＝現所有者C
- 結論：DはCに請求できる

#### 第2　Bに対する請求

- 見出しの補足（結論を含む。項目の終わりに読む）：平6.2.8の例外則
1. 名義だけ残るBを相手方にできるか／原則：登記名義人は相手方とならない（昭35・昭47）
2. 【論点】登記名義人への例外 → 規範：①自らの意思で登記を経由＋②なお登記名義を保有→喪失主張不可
   - あてはめ：理由：対抗関係類似（177）＋信義則・公平（1条2項）
3. あてはめ：相続取得・自ら移転登記・C譲渡後もなお名義保有
- 結論：DはBにも請求できる

#### 第3　甲建物が未登記の場合

- 見出しの補足（結論を含む。項目の終わりに読む）：後段
1. Cへの請求：前段同様＝現所有者Cは相手方 → Cに請求できる
2. 【論点】未登記と例外則 → 自らの意思で登記を経由せず＝要件①欠如
- 結論：Bには請求できず、Cに対してのみ請求しうる

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「敷地利用については無権原」 → 土地所有権の妨害＝物上請求の要件を充たす
- 【拾う事実】「BからCに譲渡」「現に所有するのはC」 → 原則の相手方＝現所有者Cの認定材料
- 【拾う事実】「相続し、移転登記を了した」 → Bが自らの意思で登記を経由＝例外則の要件①
- 【拾う事実】『「いまだ移転登記がなされていない」（名義はB）』 → Bがなお登記名義を保有＝例外則の要件②
- 【拾う事実】「甲建物が未登記であった場合」 → 後段＝要件①を欠きBへの請求を否定
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 権利＝Dの土地所有（争いなし）／妨害＝甲建物が無権原で占拠（争いなし）／請求内容＝妨害排除としての収去明渡（争いなし）。争点は③相手方の確定の一点。ここに紙幅を集める。
- 【効く事実】あてはめで使う事実
  - 所有権の移転 → 甲建物はA→B（相続・896条）→C（譲渡）と移った／現に所有するのはC／Cが建物所有によりD所有地を占拠。→ 相手方はC。事実は必ず評価（「現に土地を占拠して妨害している」）と結合させる。
- 【規範の要点】最判平6.2.8の規範
  - 他人の土地上の建物所有権を取得した者が、①自らの意思に基づいて所有権取得の登記を経由し、②引き続き登記名義を保有する限り、建物譲渡による所有権喪失を主張して収去義務を免れることはできない。理由＝対抗関係類似（177条）＋信義則・公平（1条2項）。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 後段は新しい規範ではなく例外則の裏返し。未登記＝要件①欠如でB否定、原則に回帰してCのみ。ここでCへの請求まで否定しないのが差のつく一手（後段でも現所有者Cは当然に相手方）。
- 【まぎらわしい選択肢・論点】177条の対抗要件具備の要否／背信的悪意者の排除／占有訴権に基づく返還請求
- 【まぎらわしい選択肢・結論】B・Cいずれにも請求できない／登記名義人Bに対してのみ請求できる
- 【まぎらわしい選択肢・規範】対抗要件具備説／権利濫用説
- 【まぎらわしい選択肢・事実】背信的悪意／登記の欠缺を主張する正当な利益

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

C＝相手方は現に建物を所有し土地を占拠する者、A→B→Cで現所有者C、Cに請求可。B＝名義だけでは原則相手方でないが、自ら登記経由＋なお保有で喪失主張不可（対抗関係類似＋信義則）、Bにも請求可。未登記＝要件①欠く、Bは不可・Cのみ。

## 3. 規範クイズ（3問）

- **Q04［規範］** 土地所有権に基づく建物収去土地明渡請求の「相手方」を決する原則的規範を述べよ（＋その理由）。
  - 模範解答：現実に建物を所有することによってその土地を占拠し、土地所有権を侵害している者を相手方とすべき（最判平6.2.8）。理由＝建物は土地を離れては存立し得ず、建物の所有は必然的にその敷地の占有を伴うから、建物所有権の現実の帰属が土地占有（妨害状態）の帰属を決する。
- **Q05［規範］** 「建物を所有すること」が、なぜ「土地を占有（妨害）すること」になるのか。理由を一言で述べよ。
  - 模範解答：建物は土地を離れては存立し得ず、建物の所有は必然的にその敷地の占有を伴うから。したがって建物所有権の現実の帰属が、土地占有（妨害状態）の帰属を決する。だから「現に建物を所有する者」が妨害排除の相手方になる。
- **Q06［規範］** 最判平6.2.8が、登記名義人を建物収去土地明渡請求の相手方としうる例外の二要件を挙げよ。
  - 模範解答：①自らの意思に基づいて所有権取得の登記を経由したこと ②引き続き登記名義を保有していること。両方を満たす限り、建物を譲渡しても所有権喪失を主張して収去義務を免れることはできない。理由は対抗関係類似（177条）＋信義則・公平（1条2項）。

- **Q07［○×］** 所有権に基づく物権的請求権（物上請求権）は、民法に明文の規定はないが、物権が物に対する直接支配権であることから、解釈上当然に認められる。
  - 正解：○（正しい）
  - 理由：物権は物を直接に支配する権利だから、その支配が妨げられれば当然に除去・予防を求めうる。明文はないが、占有訴権（197条以下）が本権に基づく請求を当然の前提とすること等から解釈上承認される。妨害の態様に応じ返還・妨害排除・妨害予防の三類型がある。
- **Q08［○×］** 建物がその敷地たる他人の土地を占有権原なく占拠している場合、土地所有者は所有権に基づく妨害排除請求として、建物収去・土地明渡しを求めることができる。
  - 正解：○（正しい）
  - 理由：建物の存在によって土地所有権が妨げられているから、その除去（＝建物収去）と土地の明渡しを妨害排除請求として求めうる。土地への建物の存置は妨害排除請求の典型（返還請求と構成する立場もあるが結論に差はない）。
- **Q09［○×］** 土地所有権に基づく建物収去土地明渡請求は、常に建物の登記名義人を相手方としてしなければならない。
  - 正解：×（誤り）
  - 理由：相手方は登記名義人ではなく、現に建物を所有して土地を占拠している者である。単に登記名義を有するにすぎない者は原則として相手方とならない（最判昭35.6.17・最判昭47.12.7）。名義から入るのは典型的な誤りで、判例の出発点は現実の建物所有者。
- **Q10［○×］** 物権的請求権の相手方は現に妨害状態を生じさせている者であり、土地の不法占拠の場合は、現実に建物を所有することによってその土地を占拠している者を意味する。
  - 正解：○（正しい）
  - 理由：妨害排除は「現に妨害を生じさせている者」に向けられる。建物は土地を離れて存立し得ず、建物の所有は必然的に敷地の占有を伴うから、建物所有権の現実の帰属が土地占有（妨害）の帰属を決する。ゆえに現に建物を所有する者が相手方となる。
- **Q11［○×］** 建物の所有権が相続や譲渡によって移転した場合、土地所有者に対して建物収去土地明渡義務を負う相手方は、その時点で現に建物を所有している者である。
  - 正解：○（正しい）
  - 理由：相手方は「現に建物を所有して土地を占拠する者」だから、所有権が移転すれば相手方も現所有者へ移る。本問では A→B（相続）→C（譲渡）で現所有者はCゆえ、DはCに請求できる。前主A・譲渡人Bは（原則としては）現所有者でない。
- **Q12［○×］** 他人の土地上の建物を第三者に譲渡してもはや所有していない者であっても、自らの意思に基づいて所有権取得の登記を経由し、なお登記名義を保有している場合には、所有権喪失を主張して建物収去土地明渡義務を免れることはできない。
  - 正解：○（正しい）
  - 理由：最判平6.2.8の例外則。①自らの意思に基づく登記の経由＋②登記名義の保有の両方を満たす限り、譲渡による所有権喪失を主張して義務を免れられない。登記を自名義にしておきながら喪失を主張するのは信義則・公平に反し、また所有権喪失の帰属を争う点で対抗関係にも似るからである。
- **Q13［○×］** 建物を実際に所有したことはなく、単に自己名義の所有権取得の登記を有するにすぎない者も、土地所有者に対して建物収去土地明渡義務を負う。
  - 正解：×（誤り）
  - 理由：単に登記名義を有するにすぎず実際に建物を所有したことのない者は、義務を負わない（最判昭47.12.7）。平6の例外則は「自ら建物所有権を取得し、自らの意思で登記を経由してなお保有する」者に限られる超・例外。「登記名義があれば常に相手方」ではない点に注意。
- **Q14［○×］** 建物が未登記のまま譲渡された場合であっても、譲渡人は建物所有権の喪失を主張することができず、土地所有者は譲渡人に対して建物収去土地明渡しを請求することができる。
  - 正解：×（誤り）
  - 理由：未登記のまま譲渡した者は「自らの意思に基づいて所有権取得の登記を経由」（例外則の要件①）を欠くから例外則は妥当せず、譲渡により確定的に所有権を失う（最判昭35.6.17）。ゆえに譲渡人には請求できず、現所有者にのみ請求しうる。「未登記でも譲渡人を相手方にできる」は誤り。
