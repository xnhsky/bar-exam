Xは、友人AのBに対する債務を担保するため、Bとの間で、自己所有の甲土地に抵当権を設定する契約を締結するとともに、Bに対して、抵当権設定登記手続を行う代理権を授与した。ところが、金銭的に困窮していたBは、上記代理権があることを悪用して、Xの代理人として、甲土地をYに売却し、登記名義をYに移転してしまった（以下「本件売買契約」という。）。Bは、本件売買契約の際、Xから預かっていたXの実印を用いて委任状を偽造し、印鑑登録証明書とともに、Yに対して示した。また、Yは、Xの意思を確認するため、委任状に記載された電話番号に架電し、受話者から売買の意思を確認したが、それはBが用意した別の人物で、Xではなかった。ＸＹ間の法律関係を論ぜよ。

- Y、委任状記載の番号に架電し意思確認（受話者は別人＝Bの手配）

#### 第1　Xの請求

1. 甲土地の所有者Xは、登記名義を有するYに対し 所有権に基づく抹消登記手続請求（物権的請求権）
- 争点は本件売買の効果がXに帰属するか

#### 第2　Yの反論

- 見出しの補足（結論を含む。項目の終わりに読む）：有権代理 → 表見代理
1. 有権代理（99条1項）主張 → 授権は登記手続のみで売却権限なし → 無権代理・不成立（113条1項）
2. 次に 【論点】公法上の代理権が110条の基本代理権たりうるか（規範：原則否定＋一環性で例外肯定）

3. 売却は登記手続の範囲外 → 権限外の行為（②充足・一文）
4. 【論点】「正当な理由」＝善意無過失か・印鑑証明の評価（規範：善意無過失／印鑑証明あれば特段の事情なき限り肯定）

#### 第3　結論

   効果がXに帰属 → Yが所有権取得 → Xの抹消登記手続請求は認められない

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「抵当権設定登記手続を行う代理権」 → Bの権限の範囲（＝公法上の行為・売却は範囲外）
- 【拾う事実】「抵当権を設定する契約を締結するとともに」 → 登記手続が私法上の取引の一環である材料
- 【拾う事実】「Xの実印を用いて委任状を偽造」「印鑑登録証明書とともに」 → 正当理由を基礎づける中核事実（コンボ）
- 【拾う事実】「電話番号に架電し…意思を確認した」 → Yが調査を尽くした（無過失の補強）
- 【拾う事実】「受話者から…それはBが用意した別の人物」 → Yのあずかり知らない事情（結論を左右しない）
- 【事案の整理】攻防で捉える
  - Xは所有者として登記の抹消を求める（請求）。Yは「Bに代理権があり売買は有効」と反論する。だがBの代理権は登記手続だけ＝売却は無権代理。そこでYは最後の砦として110条の表見代理を持ち出す ── ここが本丸。
- 【争いのない要件】論点にならず、あっさり認定する要件
  - ②権限外＝登記手続の代理権で「売却」した＝明らかに範囲外＝一文で通す。争いは①と③に集中する。
- 【効く事実】「公法上の代理権と基本代理権」のあてはめで使う事実
  - 問題の所在 → 登記申請は登記官に対する公法上の行為／一環性 → 抵当権設定契約という私法上の取引の一環＋Xが実印を交付。
- 【規範の要点】私法取引一環説の規範
  - 単なる公法上の行為についての代理権は原則として基本代理権にあたらないが、それが特定の私法上の取引行為の一環としてされたときは、私法上の作用を看過できず基本代理権たりうる（最判昭46.6.3）。
- 【規範の要点】「正当な理由＝善意無過失」の規範
  - 「正当な理由」とは代理権の存在についての善意無過失をいう（最判昭35.12.27）。印鑑登録証明書を徴している場合は、特段の事情のない限り正当な理由がある（最判昭51.6.25）。
- 【効く事実】「正当な理由＝善意無過失」のあてはめで使う事実
  - 肯定方向 → 実印で偽造した委任状＋印鑑登録証明書の呈示／さらにYは架電して意思確認＝可能な調査を尽くした。過失方向 → 土地売買は高額で慎重を要する。覆滅事情（貸与が通常あり得る家族等）＝なし。受話者が別人＝Yのあずかり知らない事情で結論を左右しない。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 要件充足を並べただけで終わらせない。「表見代理が成立する（有権代理と同じ効果）→ 売買の効果がXに帰属 → Yが確定的に所有権を取得 → 抹消請求棄却」と、効果から請求の帰結まで一本で結ぶ。
- 【まぎらわしい選択肢・論点】代理権濫用の成否／94条2項類推適用の可否／即時取得の成否
- 【まぎらわしい選択肢・結論】表見代理不成立・請求認容／有権代理成立
- 【まぎらわしい選択肢・規範】狭義説／帰責性考慮説
- 【まぎらわしい選択肢・事実】相手方の悪意／重過失あり

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

X＝所有権に基づき抹消登記を請求。Y＝有権代理は登記手続の代理権だけで否定（無権代理・113条1項）→ 110条表見代理。①登記手続は公法上だが抵当権設定契約の一環＋実印交付で基本代理権、②売却は権限外、③実印・印鑑証明＋架電で善意無過失＝正当理由。結論＝表見代理成立、効果がXに帰属、Xの抹消請求は認められない。

## 3. 規範クイズ（3問）

- **Q04［規範］** 権限外の行為の表見代理（110条）の3要件を挙げよ。
  - 模範解答：①基本代理権の存在（「その権限」）②権限外の行為（「その権限外の行為」）③相手方に代理権があると信ずべき正当な理由（善意無過失）。本人の帰責＝基本代理権の授与、外観＝権限があるかのような装い、信頼＝相手方の正当理由、という権利外観法理の3要素に対応する。
- **Q05［規範］** 公法上の行為についての代理権が、例外的に110条の基本代理権たりうるのはどのような場合か。規範を述べよ。
  - 模範解答：その公法上の行為が特定の私法上の取引行為の一環としてされたとき。このとき私法上の作用を看過できず、実体上その手続をなすべき者が申請を委任して実印等を交付した外観への第三者の信頼を保護する必要は、通常の私法上の授権の場合と変わらない（最判昭46.6.3）。「原則否定→一環性で例外肯定」の二段で答える。
- **Q06［規範］** 110条の「正当な理由」の意義と、印鑑登録証明書の呈示に関する判例の規範を述べよ。
  - 模範解答：正当な理由＝代理権の存在についての善意無過失（最判昭35.12.27）。そして印鑑登録証明書を徴している場合は、特段の事情のない限り正当な理由がある（最判昭51.6.25）。あてはめでは実印・印鑑証明の呈示＋架電による調査を拾い、特段の事情がないことを認定する。

## 4. ○×クイズ（11問）

- **Q07［○×］** 不動産の登記名義が実体的な権利関係に合致しない場合、真の所有者は、所有権に基づく妨害排除請求として登記の抹消登記手続を請求できる。
  - 正解：○（正しい）
  - 理由：所有権に基づく物権的請求権（妨害排除請求）の一場面。実体に合わない登記は所有権の円満な実現を妨げる「妨害」だから、その除去＝抹消登記手続を求められる。物の所在ではなく登記名義がどこにあるかを最初に押さえるのが出発点。
- **Q08［○×］** 代理人が、本人から与えられた代理権の範囲を超えて相手方と法律行為をした場合、その行為の効果は当然に本人に帰属する。
  - 正解：×（誤り）
  - 理由：権限を超えた行為は無権代理で、本人が追認しない限り効果は本人に帰属しない（113条1項）。例外的に相手方を保護するのが表見代理（110条）であって、「当然に帰属」ではない。有権代理を否定してから表見代理へ進む順序を崩さない。
- **Q09［○×］** 表見代理は無権代理であることを前提とする制度であり、そもそも有権代理が成立する場合には、表見代理を論じる必要はない。
  - 正解：○（正しい）
  - 理由：表見代理は、無権代理により本人に効果が帰属しない場面で、外観を信頼した相手方を例外的に保護する制度。有権代理が成立すれば効果はそのまま本人に帰属するから、表見代理を持ち出す必要はない。
- **Q10［○×］** 権限外の行為の表見代理（110条）が成立するには、代理人におよそ何らの代理権も存在しないことが必要である。
  - 正解：×（誤り）
  - 理由：逆である。110条は「その権限外の行為」を対象とするから、何らかの代理権＝基本代理権が現に存在することが前提。まったく代理権がない場合は109条（授与表示型）や無権代理の問題になる。本問はBに登記手続の代理権があるからこそ110条が土俵に乗る。
- **Q11［○×］** 表見代理には、代理権授与の表示による類型（109条）、権限外の行為の類型（110条）、代理権消滅後の類型（112条）の三つがある。
  - 正解：○（正しい）
  - 理由：表見代理の三類型。109条＝代理権を与えた旨の表示、110条＝基本代理権を超える権限外の行為、112条＝かつて与えた代理権の消滅後、で外観の源が異なる。本問はBに現に登記手続の代理権があり、それを超えて売却した＝110条の土俵だと即断できる。
- **Q12［○×］** 判例は、単なる公法上の行為についての代理権は原則として110条の基本代理権にあたらないが、それが特定の私法上の取引行為の一環としてされた場合には基本代理権たりうるとする。
  - 正解：○（正しい）
  - 理由：最判昭46.6.3の規範。110条は私法上の取引安全の制度だから、私法取引と無縁の公法上の代理権は原則対象外。もっとも私法上の取引に紐づく限度では私法上の作用を無視できず、外観への信頼保護の必要は通常の授権と変わらない。原則否定＋一環性の例外肯定の二段構えで書く。
- **Q13［○×］** 登記申請は登記官に対する公法上の行為であるから、登記申請手続の代理権は、いかなる場合であっても110条の基本代理権となることはない。
  - 正解：×（誤り）
  - 理由：「一律に否定」は誤り。原則は基本代理権にあたらないが、特定の私法上の取引行為の一環としてされた場合には基本代理権たりうる（最判昭46.6.3）。本問の登記手続は抵当権設定契約の一環で、実印まで交付されており、まさに例外があてはまる。
- **Q14［○×］** 110条の「代理人の権限があると信ずべき正当な理由」とは、代理権の存在についての善意かつ無過失をいう。
  - 正解：○（正しい）
  - 理由：最判昭35.12.27の定式。単なる善意（不知）では足りず、信じたことに過失がないこと（無過失）まで要求される規範的判断。だから相手方が尽くすべき調査を尽くしたかを、取引の内容・方法・調査状況から総合評価する。
- **Q15［○×］** 判例は、相手方が印鑑登録証明書を徴している場合には、特段の事情のない限り、代理人の権限があると信ずべき正当な理由があるとする。
  - 正解：○（正しい）
  - 理由：最判昭51.6.25（民法百選I-29）。印鑑登録証明書は実印による行為の意思確認手段として重要な機能を果たすから、これを徴していれば原則として正当理由が認められる。ただし家族への貸与が通常あり得る等の特段の事情があれば覆る。本問は特段の事情がなく、かえって架電までしている。
- **Q16［○×］** 代理権の濫用（107条）は、代理人が与えられた代理権の範囲を超える行為をした場合に適用される規定である。
  - 正解：×（誤り）
  - 理由：代理権濫用（107条）は代理人が権限の範囲内で、自己または第三者の利益を図る目的で行為した場面の規定。本問のBは売却の権限をそもそも持たない＝権限外だから、107条ではなく権限外の行為の110条で処理する。「悪用」の語に引かれて107条を論じるのは誤り。
- **Q17［○×］** 権限外の行為の表見代理が成立すると、相手方との関係で有権代理と同様に、その法律行為の効果が本人に帰属する。
  - 正解：○（正しい）
  - 理由：表見代理は、外観を信頼した相手方を保護し有権代理と同様の効果を本人に帰属させる制度。本問では本件売買契約の効果がXに帰属し、Yが確定的に所有権を取得する結果、Xの抹消登記手続請求は認められない。要件充足→効果帰属→請求の帰結まで結ぶのが締めの作法。
