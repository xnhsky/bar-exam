#### 第1　小問(1) 差押えと相殺

- 見出しの補足（結論を含む。項目の終わりに読む）：511条
1. 求償権の取得は9条・23条＝差押え後 → 511条1項で相殺を対抗できないのが原則
2. 発生原因＝連帯保証契約(5条・5条)は差押え前 → 【論点】「差押え前の原因」（511条2項本文）該当性（規範：合理的期待の有無で実質判断）
   - あてはめ：委託を受けた保証ゆえ合理的期待あり／2項ただし書（他人の債権の取得）は不適用・類推否定
- 結論：Cの相殺の主張は認められる

#### 第2　小問(2)ア 保証人による解除権の援用

- 見出しの補足（結論を含む。項目の終わりに読む）：457条
1. 契約不適合（562・564・541、「軽微」でなく帰責事由なし）→ Eに解除権あり
2. 【論点】保証人は解除権を援用できるが行使まではできるか → 457条2項で援用可・3項で履行拒絶権にとどまる（行使不可）
- 結論：FはEの解除権を援用してDの請求を拒める

#### 第3　小問(2)イ 原状回復義務と保証債務の範囲

- 見出しの補足（結論を含む。項目の終わりに読む）：447条1項・545条1項
1. 解除で契約は遡及的無効（545条1項）→ 主債務消滅 → 付従性で保証債務も消滅が原則
2. 【論点】原状回復義務を保証人が保証するか → 一切保証の意思＝意思解釈で447条1項「従たるすべてのもの」に含める

- 結論：特約なき限り原状回復義務も保証範囲 ＝ DはFに請求できる

- 【拾う事実】『連帯保証契約は5/5（差押え前）』 → 511条2項「差押え前の原因」の該当性を起動
- 【拾う事実】「Bの委託を受け」 → 合理的期待・2項ただし書不適用を分ける決め手
- 【拾う事実】『ブレーキの故障／契約の目的を達せられない』 → 契約不適合による解除権の存在（562・564・541）
- 【拾う事実】「Fが本件契約に基づきEが負担する債務を保証」 → 保証の範囲（一切保証か代金限定か）の意思解釈
- 【拾う事実】『解除後に過失で損壊・返還不能・金銭賠償もしない』 → 原状回復義務が価額賠償に転化した事実
- 【事案の整理】請求の骨格をつかむ
  - 小問(1)＝A→Cへβ債権の弁済請求／Cは求償権で相殺と反論。小問(2)ア＝D→Fへ保証履行請求／FはEの解除権を援用して拒む。イ＝D→Fへ解除後の原状回復義務（価額賠償）の保証を請求。誰の何の権利がぶつかっているかを先に固める。
- 【ポイント】511条は段階操作
  - いきなり2項に飛ばない・1項で止めない。①1項で「差押え後取得だから原則対抗できない」を確認 → ②2項本文の救済を検討 → ③2項ただし書（他人の債権の取得）に当たらないか。この順を踏むと自動的に論点が立つ。
- 【効く事実】「差押え前の原因」のあてはめで使う事実
  - 連帯保証契約＝5/5（差押え9/10より前）／Bの委託あり／求償権取得＝9/23（差押え後）。連帯保証契約は「事後的に求償権を発生させるもの」だから差押え前締結ゆえ合理的期待あり。委託ありゆえ、2項ただし書（差押え後に他人の債権を取得＝相殺適状の作出）にも当たらず類推もされない。
- 【規範の要点】「援用の性質／解除後の範囲」の規範
  - ア：保証人は主債務者が主張しうる抗弁を援用でき（457条2項）、主債務者が解除権を有するときは、その行使によって免れるべき限度で履行を拒める（同条3項）＝解除権自体は行使できない。イ：解除で契約は遡及的無効となり主債務が消滅、保証も付従性で消滅が原則。もっとも保証人は主債務者の負担する一切の債務を保証する意思が通常だから、特約なき限り原状回復義務も「その債務に従たるすべてのもの」（447条1項）に含まれる。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 511条2項も、447条1項・457条3項も、いずれも条文の要件を機械的に当てはめて結論に飛びつかないのがコツ。趣旨（相殺の担保的機能への合理的期待／保証人の通常の意思）に遡って、要件の当否を実質的に判断する。
- 【まぎらわしい選択肢・論点】相殺の遡及効の有無／債権譲渡と相殺の優劣
- 【まぎらわしい選択肢・結論】Cの相殺の主張は認められない／Fは請求を拒めない
- 【まぎらわしい選択肢・規範】形式的判断説／代金債務限定説
- 【まぎらわしい選択肢・事実】無委託の保証／差押え後に締結した保証契約

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

(1)＝求償権は差押え後取得で1項不可、でも保証契約は差押え前＝2項本文の「差押え前の原因」、合理的期待で実質判断、委託ありでただし書不適用、相殺OK。(2)ア＝Eに解除権、Fは457条2項で援用可だが行使不可・3項で履行拒絶にとどまる。(2)イ＝解除で付従性消滅が原則、でも一切保証の意思＝447条1項で原状回復義務も保証、DはFに請求可。

## 3. 規範クイズ（全4問・1問目から最後まで全部出す）

- **［規範クイズ 1/4］** 511条2項本文「差押え前の原因に基づいて生じた」債権かどうかの判断基準を述べよ。
  - 模範解答：2項の趣旨＝相殺への合理的期待の保護。したがって、自働債権の発生原因が形式的・客観的に差押え前に存在したというだけでは足りず、自働債権・受働債権の内容及び相互の関連性を考慮して、相殺への合理的期待の有無を実質的に判断する（合理的期待説）。連帯保証契約は事後的に求償権を発生させるものであり、差押え前締結ゆえ合理的期待が生じる。
- **［規範クイズ 2/4］** 委託を受けた保証（本問C）と無委託保証とで、差押え後に取得した求償権による相殺の可否の結論が分かれる理由を述べよ。
  - 模範解答：委託がある場合は、求償権の発生原因（保証契約）が債務者の意思に基づいて生じており、差押え前に締結されていれば相殺への合理的期待が認められる。無委託の場合は債務者の関与なく一方的に相殺適状を作出したに等しく、合理的期待が乏しい。ゆえに委託ありの本問では相殺を対抗でき、2項ただし書の類推も否定される。
- **［規範クイズ 3/4］** 主たる債務者が契約の解除権を有する場合に、保証人ができること・できないことを、根拠条文とともに述べよ。
  - 模範解答：保証人は、主債務者が主張しうる抗弁を援用して債権者に対抗できる（457条2項）。しかし解除権という形成権を自ら行使することはできず、主債務者がその行使によって債務を免れるべき限度で、債権者に対して履行を拒むことができるにとどまる（457条3項）。
- **［規範クイズ 4/4］** 契約が解除された場合に、主債務者が負う原状回復義務を保証人が保証するかについて、原則と結論を、根拠条文とともに述べよ。
  - 模範解答：解除により契約は遡及的に無効となり（545条1項）、主債務が消滅すれば保証債務も付従性により消滅するのが原則。もっとも、保証人は主債務者の負担する一切の債務を保証する意思が通常であるから、特約なき限り原状回復義務も「その債務に従たるすべてのもの」（447条1項）に含まれ、保証人はこれを保証する。

（規範クイズはここまで＝全4問。最後の4問目まで出したら「規範クイズ、全4問クリア！」と言って次へ）

## 4. ○×クイズ（全8問・1問目から最後まで全部出す）

- **［○×クイズ 1/8］** 差押えを受けた債権について、第三債務者が相殺を差押債権者に対抗できるか否かは、差押えの「申立て」がなされた時を基準に判断される。
  - 正解：×（誤り）
  - 理由：基準となるのは差押えの効力が第三債務者に及ぶ時＝差押命令が第三債務者に送達された時（民事執行法145条5項参照）。申立て時ではない。ここを「申立て日」と取り違えると、取得の前後の判定を誤る小さな落とし穴になる。
- **［○×クイズ 2/8］** 差押えを受けた債権の第三債務者が差押え「後」に取得した債権であっても、それが「差押え前の原因に基づいて生じた」ものであるときは、その債権による相殺を差押債権者に対抗することができる。
  - 正解：○（正しい）
  - 理由：511条2項本文。1項は差押え後取得債権による相殺を原則対抗不可とするが、2項本文は「差押え前の原因に基づいて生じた」債権であれば相殺への合理的期待があるとして対抗を認める。1項で止めず2項へ進むのがGUESSの要。
- **［○×クイズ 3/8］** 連帯保証人が主たる債務者の委託を受けて保証をした場合であっても、債権者に弁済をしたときに主たる債務者に対して求償権を取得することはない。
  - 正解：×（誤り）
  - 理由：委託を受けた保証人が弁済その他自己の財産をもって主たる債務を消滅させたときは、主たる債務者に対して求償権を取得する（459条1項）。この求償権が小問(1)でCが相殺に供する自働債権となる。求償権の発生原因は「連帯保証契約」である点が、後の「差押え前の原因」の判断につながる。
- **［○×クイズ 4/8］** 相殺が有効にできるためには、原則として、当事者双方の債権が対立し、双方の債務が弁済期にあること（相殺適状）が必要である（505条1項）。
  - 正解：○（正しい）
  - 理由：505条1項は、①同種の目的を有する債権の対立、②双方の債務の弁済期到来、③債務の性質が相殺を許すこと、を相殺の要件（相殺適状）とする。差押えと相殺は、この相殺適状を前提に、差押債権者との優劣を511条が調整する構造。まず相殺適状を確認するのが出発点。
- **［○×クイズ 5/8］** 無委託の保証人が弁済して取得した求償権であっても、差押えや破産手続開始の前に保証契約さえ締結されていれば、常に相殺への合理的期待が認められ、相殺を対抗できる。
  - 正解：×（誤り）
  - 理由：無委託保証人が取得する求償権は、主たる債務者の意思に基づかずに生じ、相殺適状を一方的に作出したに等しいため、相殺への合理的期待が乏しいとされる（最判平24.5.28の趣旨）。委託の有無が結論を分ける決定的な差。委託がある本問Cは合理的期待が認められる。
- **［○×クイズ 6/8］** 主たる債務者が債権者に対して解除権を有するとき、保証人は、その解除権を自ら行使することはできないが、主たる債務者がその行使によって債務を免れるべき限度で、債権者に対して債務の履行を拒むことができる（457条3項）。
  - 正解：○（正しい）
  - 理由：457条3項は、主債務者が相殺権・取消権・解除権を有するときは、その行使によって主債務者が債務を免れるべき限度で、保証人に履行拒絶権を認める。形成権の行使は主債務者に留保されるため、保証人が解除権そのものを行使することはできない。
- **［○×クイズ 7/8］** 買主のために保証をした保証人の責任は、常に買主の代金支払債務に限定され、契約が解除された場合の原状回復義務にまで及ぶことはない。
  - 正解：×（誤り）
  - 理由：買主の代金支払債務のみを保証する趣旨とみるべき場合は例外的で、一般には買主の負担する一切の債務を保証し、その不履行によって相手方に損害を被らせない趣旨と解される（大阪地判昭52.3.24）。特約なき限り、解除後の原状回復義務も447条1項「従たるすべてのもの」に含まれる。
- **［○×クイズ 8/8］** 民法511条2項が「差押え前の原因」に基づく債権による相殺を認めるのは、相殺の担保的機能に対する第三債務者の合理的期待を保護する趣旨であり、これは債権譲渡と相殺に関する469条2項と平仄を合わせたものである。
  - 正解：○（正しい）
  - 理由：相殺の担保的機能への合理的期待の保護が、差押えと相殺（511条）・債権譲渡と相殺（469条）に共通する趣旨。平成29年改正は、無制限説（最大判昭45.6.24）を511条1項に明文化し、さらに「差押え前の原因」による救済（2項）を469条2項と平仄を合わせて新設した。趣旨に遡ると要件解釈が一本の筋で理解できる。
