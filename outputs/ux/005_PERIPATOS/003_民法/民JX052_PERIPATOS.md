### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「その後の工事を進めようとしている」 → 最終工程未了＝仕事は未完成（641条の場面）
- 【拾う事実】『「基礎工事が不完全」／Bは争う』 → 債務不履行の有無＝仮定的処理（541条）
- 【拾う事実】『「屋根の防水工事の手抜き」→雨漏り』 → 品質の契約不適合（562条以下の起動）
- 【拾う事実】『パソコン等が「使い物にならなくなった」』 → 拡大損害＝415条でのみ回復
- 【拾う事実】『補修費100万／PC等50万／残代金1000万』 → 同時履行・減額・相殺の金額計算の材料
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 契約成立・不適合の存在＝一言で認定／争いのない要件（客体・主体）は流す。「完成」の意義（小問1）と準用経路・同時履行の範囲（小問2）だけ立ち止まる。
- 【効く事実】小問1で効く事実
  - 「完成しない間」→ Bはその後の工事を進めようとしている＝最終工程未了／641条の負担 → 損害を賠償していつでも解除／541条の不履行 → 基礎工事が不完全（Aの主張＝仮定的処理）／軽微性の否定 → 基礎工事は建物の安全性の根幹。
- 【規範の要点】最判平9.2.14の規範
  - 報酬債権と修補に代わる損害賠償債権は、同一契約から生じ密接に関連するから、信義則に反する特段の事情がない限り、全部対全部で同時履行の関係に立つ → Aは150万円の賠償と引換えるまで残代金1000万全額の支払を拒める。
- 【効く事実】小問2で効く事実
  - 契約不適合 → 屋根防水の手抜き＝品質の不適合／損害 → 補修費100万＋PC等50万＝150万／同時履行 → 信義則違反の事情なし／拡大損害 → PCは追完・代金減額では回復不能＝415条のみ。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 相殺は相手の抗弁権を一方的に奪うため、抗弁権付着の自働債権では原則不可。もっとも報酬債権と修補に代わる損害賠償債権のように同一契約から生じ相互に同時履行なら、相殺を認めても不当でない（最判平9.2.14）。相殺後の残債務は意思表示の翌日から遅滞。
- 【まぎらわしい選択肢・論点】危険負担の適用の可否／手付による解除の可否
- 【まぎらわしい選択肢・結論】契約は当然に無効となる／代金減額請求のみ可能
- 【まぎらわしい選択肢・規範】一部対一部で同時履行／填補賠償の特別要件が必要
- 【まぎらわしい選択肢・事実】仕事は既に完成している／相殺は一切許されない

- **Q04［規範］** 請負の担保責任（契約不適合責任）で注文者が採りうる4手段と、その準用の入口となる条文を挙げよ。
  - 模範解答：入口＝559条本文（有償契約への売買規定の準用）。①追完（修補）請求＝562条／②代金減額請求＝563条／③損害賠償＝564条を介した415条／④解除＝564条を介した541条・542条。2020年改正で瑕疵担保責任が債務不履行責任の特則へ一元化された帰結。
- **Q05［規範］** 仕事未完成の段階で注文者が請負契約を終了させる2つの解除の根拠と、両者の要件・負担の違いを述べよ。
  - 模範解答：①641条（任意解除）＝仕事完成前ならいつでも解除可。要件は「完成しない間」だけで債務不履行不要だが、損害の賠償が条件。②541条（催告解除）＝債務不履行＋催告＋軽微でないことが要件だが、損害賠償は不要。立証できるなら541条、できなくても641条、という二段構えで書く。
- **Q06［規範］** 自働債権に同時履行の抗弁権が付着している場合の相殺の可否について、原則と、本問で相殺が認められる理由（例外）を述べよ。
  - 模範解答：原則＝相殺は相手方が自働債権について有する同時履行の抗弁権を一方的に失わせるから、抗弁権付着の自働債権による相殺は許されない。例外＝報酬債権と修補に代わる損害賠償債権は、同一の請負契約から生じ相互に密接に関連し、相互に同時履行の関係に立つから、相殺を認めても相手方を不当に害しない（最判平9.2.14）。

## 4. ○×クイズ（9問）

- **Q07［○×］** 請負契約は、労務の提供それ自体を目的とする点で雇用・委任と共通し、仕事の完成という結果は報酬発生の要件ではない。
  - 正解：×（誤り）
  - 理由：請負（632条）は、当事者の一方が仕事を完成することを約し、相手方がその仕事の結果に対して報酬を支払う契約。結果（仕事の完成）に報酬が結びつく点が、労務それ自体を目的とする雇用・委任との決定的な違い。だからこそ「完成の前後」で使える条文が切り替わる。
- **Q08［○×］** 注文者は、請負人が仕事を完成しない間は、いつでも損害を賠償して請負契約を解除することができる（641条）。
  - 正解：○（正しい）
  - 理由：641条は請負に固有の任意解除権。仕事完成前なら、請負人に落ち度がなくても、注文者は損害を賠償していつでも解除できる。「賠償と引換え」という負担がある代わりに、債務不履行の立証が要らないのが強み。基礎工事の不完全を立証できなくても切れる安全策になる。
- **Q09［○×］** 注文者による641条の任意解除は、請負人に債務不履行がある場合に限り認められる。
  - 正解：×（誤り）
  - 理由：641条の任意解除は債務不履行を要件としない。仕事完成前であれば、請負人に落ち度がなくても解除でき、代わりに注文者が損害を賠償する。債務不履行を前提に損害賠償なしで切れるのは催告解除（541条）の方。両者は要件と負担が正反対で、二本立てで用意するのが定石。
- **Q10［○×］** 請負における仕事の「完成」は、予定された最後の工程を一応終えたか否かで判断され、仕事の出来・不出来（契約不適合の有無）は完成の判断とは切り離される。
  - 正解：○（正しい）
  - 理由：「完成」＝最終工程到達説。予定された最後の工程まで一応終えていれば、出来が悪くても「完成」であり、その不完全さは完成後の担保責任（契約不適合）の問題として別に処理する。本問は工事続行中＝最終工程未了＝未完成だから、担保責任ではなく641条・541条の解除の局面になる。完成の判断と不適合の判断を混ぜないのがコツ。
- **Q11［○×］** 催告解除（541条）は、相当期間を定めた催告後もその期間内に履行がない場合でも、契約及び取引上の社会通念に照らして債務の不履行が軽微であるときは認められない（同条ただし書）。
  - 正解：○（正しい）
  - 理由：541条ただし書は、催告期間経過時の不履行が軽微なら解除を制限する。軽微性は「契約及び取引上の社会通念」に照らして判断する。基礎工事の不完全は建物の安全性の根幹に関わり軽微とはいえないから、本問では解除の制限は及ばない。逆に小問2の雨漏りは補修で是正できるため軽微と評価される余地があり、同じただし書でも結論が振れる。
- **Q12［○×］** 判例によれば、請負の報酬債権と目的物の修補に代わる損害賠償債権とは、信義則に反すると認められる事情のない限り、全部対全部で同時履行の関係に立つ。
  - 正解：○（正しい）
  - 理由：最判平9.2.14。両債権は同一の請負契約から生じ相互に密接に関連するから、可分でも全部対全部で同時履行に立つ。したがって注文者は、僅かな損害賠償額でも報酬全額の支払を拒める。ただし僅少な不適合で高額報酬全額を拒むような信義則違反の事情があれば制限される、という留保も一緒に押さえる。
- **Q13［○×］** 契約不適合から派生して注文者の他の財産に生じた拡大損害（本問のパソコン等の損害）は、代金減額請求や追完請求によって回復することができる。
  - 正解：×（誤り）
  - 理由：拡大損害（瑕疵結果損害）は、目的物そのものの価値回復を内容とする追完・代金減額では回復できない。これを回復できるのは415条の損害賠償だけ。だから本問のPC損害50万は必ず損害賠償のルートに乗せる。補修費100万（目的物の価値回復）と拡大損害50万を性質で仕分けできるかが差のつく一点。
- **Q14［○×］** 代金減額請求（563条）は、原則として、注文者が相当の期間を定めて追完の催告をし、その期間内に追完がないことを要件とする。
  - 正解：○（正しい）
  - 理由：代金減額はまず追完の機会を与えるのが原則（563条1項＝催告減額）。追完不能・追完拒絶の明確・定期行為等の場合は無催告で減額できる（同条2項）。本問では屋根補修が可能だから、催告→追完なし→補修費相当100万の減額、という順で処理する。追完請求権を軸に代金減額・解除がぶら下がる構造。
- **Q15［○×］** 請負の報酬債権を、注文者が修補に代わる損害賠償債権を自働債権として相殺した場合、相殺後に残った報酬債務について、注文者は相殺の意思表示をした日の翌日から履行遅滞の責任を負う。
  - 正解：○（正しい）
  - 理由：最判平9.2.14。相殺は相殺適状時に遡って効力を生じる（506条2項）が、相殺前の報酬残債務は同時履行の抗弁により遅滞に陥っていない。そこで残債務の遅滞は相殺の意思表示の日の翌日から生じる。本問でAが相殺すれば残850万円につき翌日から遅滞。「同時履行・相殺・遅滞の翌日起算」の三点セットが本判例の核。
