- 見出しの補足（結論を含む。項目の終わりに読む）：産業廃棄物の除去・物権的請求権

2. 【論点】産業廃棄物の所有権帰属（176条・契約解釈） → 規範：有償投棄の合理的意思解釈
   - あてはめ：「有料で」＋廃棄物の無価値性・処分負担 → 対価と引換えにAが管理処分を引受け ＝ 所有権はAへ移転

#### 第2　②請求

- 見出しの補足（結論を含む。項目の終わりに読む）：土壌の原状回復

#### 第3　③請求

3. （工作物責任717条1項＝書ければ加点・任意）
- 結論：共同不法行為成立 → A・Bは全損害を連帯

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】『「有料で」投棄を認めた』 → 所有権移転の契約解釈の基礎（対価と引換えの引受け）
- 【拾う事実】『産業廃棄物は無価値・処分に負担』 → 所有権をAへ移す合理性を支える
- 【拾う事実】『崩落防止設備を設置しなかった』 → Aの過失（709）・工作物の瑕疵（717）
- 【拾う事実】『危険な状態を認識しつつ投棄を継続』 → Bの過失の認定根拠
- 【拾う事実】『A・Bが同一の投棄契約に基づく』 → 客観的関連共同性（719Ⅰ前段）
- 【拾う事実】『大量投棄は許容せず／所有権を放棄した』 → A・Bの反論（いずれも失当）
- 【争いのない要件】論点にならず、あっさり認定する要件
  - ①の物権（Xの所有）・妨害状態（廃棄物堆積）は争いなし＝一言／③のA・Bの過失は事実から素直に認定。詰まるのは①の相手方＝所有権帰属と、③の「共同」の意義だけ。
- 【効く事実】「所有権は誰か（契約解釈が）」のあてはめで使う事実
  - 所有権移転 → 「有料で」投棄させた契約＋産業廃棄物は無価値で処分に負担が伴う＝対価と引換えにAが管理処分を引受け → 所有権はAへ。Aの反論 → 大量投棄を許容しない制限をうかがわせる事情なし＝失当。費用 → 不可抗力等なし＝A負担。
- 【規範の要点】客観的関連共同説の規範
  - 719条1項前段は各人が独立に709条の要件を具備することを前提とし、被害者保護の趣旨から「共同」は客観的関連共同で足り、意思の連絡（共謀・共同の認識）は不要（山王川事件・最判昭43.4.23）。A・Bは同一の投棄契約で結びつく＝関連共同性を肯定 → 全損害を連帯。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - ズレの理由＝妨害排除は除去権限（所有権）を要するのに対し、不法行為の成立に所有権の存否は無関係（過失があれば足りる）。だから所有権のないBは①では相手方にならないが、③では過失ゆえに責任を負う。「所有権の存否と過失の有無は一致しない」の一言がBの過失認定を支える。
- 【まぎらわしい選択肢・論点】即時取得の成否／添付による所有権取得／使用者責任の成否／過失相殺の可否
- 【まぎらわしい選択肢・結論】①請求は認められない／A・B双方に除去請求できる／②原状回復請求は認められる／各自が別個に分割責任を負う
- 【まぎらわしい選択肢・規範】主観的関連共同説／忍容請求権説
- 【まぎらわしい選択肢・事実】意思連絡あり／所有権はBに残る

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

①＝妨害排除の相手方は妨害物の所有者、有料投棄の契約解釈で所有権はAへ移転（176条）、Aの反論失当、行為請求権でA費用負担＝Aに除去請求可（Bは不可）。②＝物権的請求権も不法行為も原状回復は否定（金銭賠償の原則）＝②認められない。③＝A・Bそれぞれ709成立、719条1項前段は客観的関連共同で足り投棄契約で肯定＝全損害を連帯。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** ②土壌の原状回復（現物回復）が、物権的請求権・不法行為のいずれによっても否定される理由を述べよ。
  - 模範解答：物権的請求権は物権の効力として物の支配の回復のために認められるにとどまり、汚染された物の状態の回復までは及ばない。不法行為は金銭賠償が原則（722条1項・417条）で、原状回復を認めると原則に反し費用も過大になり加害者に酷。ゆえに②はいずれでも否定（土壌の価値減少は③の金銭で填補）。
- **［規範クイズ 2/3］** 妨害排除請求で「妨害物の所有権が誰に帰属するか」を、有償で廃棄物を引き取らせた契約から決する契約解釈の筋道を述べよ（176条）。
  - 模範解答：所有権は当事者の意思表示により移転する（176条）から、有償投棄契約の合理的意思解釈の問題。産業廃棄物は財産的価値がなく管理処分に負担が伴う特質から、廃棄業者は投棄後まで所有権を保持する意思がないのが通常で、対価と引換えに引取り側（A）が管理処分を引き受けた＝所有権はAへ移転と解する。明示の移転合意は不要。
- **［規範クイズ 3/3］** 共同不法行為（719条1項前段）の成立要件と、「共同」の意義に関する規範を述べよ（連帯責任を導く枠組み）。
  - 模範解答：①各人が独立に709条の不法行為の要件を具備すること（前段は本来別個の責任をまとめて連帯とする趣旨）＋②「共同」＝客観的関連共同で足りる（意思連絡は不要／山王川事件）。両者が満たされれば全損害について連帯責任。

## 4. ○×クイズ（全7問・1問目から最後まで全部出す）

- **［○×クイズ 1/7］** 所有権に基づく妨害排除請求権（物権的請求権）は、民法に明文の規定がなくても、物権が物に対する直接的・排他的な支配権であることから当然に認められる。
  - 正解：○（正しい）
  - 理由：物権的請求権は明文にないが、物権の直接支配性から、支配が妨げられた場合の回復手段として当然に認められる（返還・妨害排除・妨害予防の3類型）。「物をどけろ」型の①請求はこの物権的請求権が出発点。ここは争いなく1〜2文で通す。
- **［○×クイズ 2/7］** 所有権に基づく妨害排除請求の相手方は、原則として、現に違法な妨害状態を生じさせている物の所有者（＝その妨害を除去しうる地位にある者）である。
  - 正解：○（正しい）
  - 理由：判例（大判昭5.10.31ほか）は妨害を生じさせている物の所有者を相手方とする。だから本問は「滑落した産業廃棄物の所有権がA・Bどちらか」を決めないと相手方が確定しない。過去に投棄行為をしたことではなく現在の除去権限（所有権）が基準。
- **［○×クイズ 3/7］** 不法行為に基づく損害賠償は、原則として、被害者の受けた損害を原状に回復する方法（現物による回復）によって行われる。
  - 正解：×（誤り）
  - 理由：不法行為の損害賠償は金銭賠償が原則（722条1項による417条の準用）。②の土壌の原状回復（現物回復）は、この金銭賠償の原則に反しかねず、費用も過大になりうるから否定される。だから②は短く落として①③に紙幅を回すのが正解。
- **［○×クイズ 4/7］** 不法行為に基づく損害賠償の範囲は、債務不履行に関する416条を類推し、当該不法行為と相当因果関係に立つ損害に限られると解されている。
  - 正解：○（正しい）
  - 理由：判例・通説は不法行為の賠償範囲にも416条を類推し、相当因果関係に立つ損害に限定する。本問では、崩落防止設備の不設置・投棄継続と地価の大幅下落との間に、社会通念上の相当因果関係が認められる。
- **［○×クイズ 5/7］** 所有権の放棄は所有者の自由であるから、他人の土地に妨害を及ぼしている動産であっても、所有者はいつでも所有権を放棄して、その物から生じる責任を免れることができる。
  - 正解：×（誤り）
  - 理由：所有権の放棄も他人の権利を害さない限度でのみ許される（権利濫用の禁止・1条3項参照）。他人の土地に妨害を生じさせながら放棄で責任を免れることはできない。Bの反論後段（放棄した）はこれで一蹴。もっとも前段（所有権はAへ移転）で決着すれば、放棄は「仮に検討しても失当」と一言でよい。
- **［○×クイズ 6/7］** 共同不法行為（719条1項前段）が成立するには、加害者相互間に共謀または共同加害の認識（意思の連絡）が必要であり、これを欠く場合には各人が別個に損害賠償責任を負うにとどまる。
  - 正解：×（誤り）
  - 理由：判例（山王川事件）は「共同」を客観的関連共同で足り、共謀・共同の認識は不要とする。意思連絡を要求するのは主観的関連共同説で判例・通説ではない。本問はAB間に投棄契約という客観的結びつきがあり、いずれの説でも関連共同性を肯定できる。
- **［○×クイズ 7/7］** 同一の物的損害について、所有権に基づく妨害排除請求の相手方にはならない者でも、その者に過失があれば不法行為（709条）に基づく損害賠償責任を負うことがある。
  - 正解：○（正しい）
  - 理由：妨害排除の相手方要件は妨害物の所有権（除去権限）だが、不法行為の成立に所有権の存否は関係なく過失があれば足りる。両者は要件が別だから相手方がズレても矛盾しない。本問のBは所有権がAへ移転しても、危険を認識しつつ投棄を継続した過失により③で責任を負う。
