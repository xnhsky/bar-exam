- **Q02［見当づけ］** 各請求は「何条の何権利っぽい？」 ― 見当をつけて
  - 答え：問1＝Cは所有権に基づく引渡請求（206条）→ Eは「引渡し」を得た第三者（178条）で反論 → Cは「Dは背信的悪意者」で再反論。問2＝Bの物権は抵当権のみ（369条）→ 抵当権に基づく妨害排除・返還請求。
- **Q03［論点］** 両設問の問題になる論点を挙げて（3つ）

  - 答え：両問の分水嶺：CP③はいずれもEの背信性の有無に帰着する（相似形）。

- 【拾う事実】『E自身の主観の記載なし』 → 特段の事情なし＝Eは背信的悪意者でない
- 【事案の整理】請求の枠組みを先に固定

- 【争いのない要件】論点にならず、あっさり認定する要件

- 【効く事実】問1で効く事実

  - 従物性 → 庭石は独立の取引客体（200万）だが甲土地の庭に付属し継続的に効用を助ける／設定時の存在 → 「抵当権設定前から」（87条2項でも及ぶ）／妨害 → 搬出後2900万＜被担保債権3000万／対抗力喪失 → 「D自らトラックに積んで搬出」／返還先の例外 → 「A立会いの下で」搬出＝Aの維持管理を期待できない。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 問1＝所有権 vs 所有権（CとE）／問2＝抵当権 vs 所有権（BとE）。切り口は違うが、最後の分岐は同じEの主観。問題文にEの背信性の記載がない以上「特段の事情がない限り」で両問を処理する。二度目は規範を再掲せず「前記の通り」で接続すると簡潔。
- 【まぎらわしい選択肢・論点】即時取得（192条）の成否／物上代位の可否／94条2項類推適用の可否
- 【まぎらわしい選択肢・結論】Cの引渡請求は認められる／Bの請求はおよそ認められない
- 【まぎらわしい選択肢・規範】絶対的構成／物理的一体性説
- 【まぎらわしい選択肢・事実】単純悪意で足りる／被担保債権額を下回ることが必須

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

問1＝Eは引渡しで優先、しかしDは嫌がらせ目的の背信的悪意者、もっとも転得者Eは相対的構成で自身が背信的でない限り第三者、ゆえにCの請求は認められない。問2＝庭石は従物で370条により効力、搬出で妨害、分離物に効力は残るが公示の衣説で搬出後は対抗不可、ただしE自身が背信的悪意者なら対抗可。

## 3. 規範クイズ（3問）

- **Q04［規範］** 背信的悪意者が「第三者」（177条・178条）から排除される理由と、その判定に用いる考慮要素を述べよ。
  - 模範解答：理由＝「第三者」とは対抗要件の欠缺を主張する正当な利益を有する者をいい（制限説）、条文は自由競争の枠内の取引を規律する。信義則に反する背信的態様の者は自由競争を逸脱し、正当な利益を欠くから排除される。考慮要素＝害意・不当な目的・登記（引渡し）拒絶への関与等の主観的・客観的事情を総合。
- **Q05［規範］** 背信的悪意者「からの転得者」が「第三者」（177条・178条）に当たるかの規範と、その根拠（相対的構成）を述べよ。
  - 模範解答：規範＝転得者は、自身が背信的悪意者と評価されるのでない限り「第三者」に当たり、対抗要件の欠缺を主張できる（最判平8.10.29）。根拠＝背信的悪意者は信義則上主張を封じられるだけで無権利者ではないから、その者からの物権変動は有効であり、背信性は各人ごとに個別的に判断すべきである（相対的構成）。絶対的構成（無権利＝転得者も無権利）は取引の安全を害するため採らない。
- **Q06［規範］** 抵当不動産から分離・搬出された物（分離物）について、抵当権の効力の存続と第三者への対抗力をどう処理するか（公示の衣説）。
  - 模範解答：存続＝一旦効力が及んだ物は、分離しても抵当権の効力自体は失われない（交換価値維持の必要）。対抗力＝抵当権は登記を対抗要件とするから、分離物が抵当不動産上に存在し登記の公示力が及ぶ限りで第三者に対抗でき、抵当不動産上から搬出されれば対抗できなくなる（公示の衣説＝対抗要件説）。別説＝即時取得説は第三者の即時取得（192条）の成否で処理。いずれの説でも、第三者が背信的悪意者なら保護されない。

## 4. ○×クイズ（7問）

- **Q07［○×］** 動産に関する物権の譲渡は、その動産の引渡しがなければ、第三者に対抗することができない（178条）。
  - 正解：○（正しい）
  - 理由：動産物権変動の対抗要件は「引渡し」（178条）。不動産の登記（177条）に対応する。二重譲渡の優劣は原則としてどちらが先に引渡しを得たかで決まるから、まず「誰が引渡しを得たか」を棚卸しするのが出発点。
- **Q08［○×］** 抵当権は目的物の占有を設定者に残す非占有担保物権であるから、抵当権者は、抵当権に基づく物権的請求権（妨害排除請求権）を行使することはできない。
  - 正解：×（誤り）
  - 理由：抵当権も物権であり、その支配（交換価値の把握）が侵害されれば物権的請求権（妨害排除請求権）を行使できる（最大判平11.11.24等）。非占有担保であることは請求権の存在自体を否定せず、行使の場面（占有侵奪ではなく交換価値の侵害）を画するにとどまる。
- **Q09［○×］** 物権的請求権の相手方に対する請求は、まず自己の物権の存在（発生・帰属）を示し、次に相手方の占有等による妨害を示す、という順で構成する。
  - 正解：○（正しい）
  - 理由：物権的請求は「①自己に物権がある → ②相手方がそれを妨げている」の順で立てるのが基本形。問2ではさらに「③その物権を相手方に対抗できるか」が加わる。攻める順を先に決めると、要件を落とさず積み上げられる。
- **Q10［○×］** 不動産の二重譲渡において、第二譲受人が第一譲渡の事実を知っていた（悪意）というだけで、その者は「第三者」（177条・178条）から排除される。
  - 正解：×（誤り）
  - 理由：自由競争の下では、他人が先に権利を得ていることを知りつつ先に対抗要件を備えるべく行動する自由が保障される。ゆえに単なる悪意者は排除されない。排除されるのは、信義則（1条2項）に反する背信的悪意者だけ。悪意と背信的悪意の二段構えを混同しないのが要。
- **Q11［○×］** 背信的悪意者は実体上の無権利者であるから、背信的悪意者から目的物を譲り受けた転得者は、その者自身が善意であっても、およそ権利を取得できない。
  - 正解：×（誤り）
  - 理由：これは絶対的構成の帰結だが、判例・通説は相対的構成を採る。背信的悪意者は信義則上「第三者」性を否定されるだけで無権利者ではないから、その者からの物権変動は有効で、転得者は自身が背信的悪意者でない限り「第三者」に当たる（最判平8.10.29）。絶対的構成では、第一譲受人の存在を知り得ない転得者まで害され取引の安全を著しく損なう。
- **Q12［○×］** 抵当権に対する妨害状態が認められるには、目的物の交換価値が下落した結果、その価値が被担保債権額を下回っていることが必要である。
  - 正解：×（誤り）
  - 理由：抵当権は目的物の交換価値を把握する権利だから、通常の使用収益の範囲を超えて交換価値が不当に下落すれば妨害状態が生じ、被担保債権額を下回ることは必須でない。本問は搬出で担保価値2900万＜被担保債権3000万と分かりやすく割り込むので妨害は明白だが、規範としては「下回りが必須」と書くと誤り。
- **Q13［○×］** 背信的悪意者からの転得者が「第三者」に当たらないと評価されるのは、当該転得者自身に背信的悪意者と評価すべき事情がある場合に限られる。
  - 正解：○（正しい）
  - 理由：相対的構成では背信性を各人ごとに個別判断するから、転得者を「第三者」から外すには転得者自身の背信的悪意（例：専ら第一譲受人に損害を与える目的等）を要する。前主が背信的悪意者であることは転得者の背信性を基礎づけない。抵当権の分離物対抗の場面でも同じ発想でEの背信性を問う。
