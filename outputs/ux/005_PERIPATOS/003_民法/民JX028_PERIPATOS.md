## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

Xは、A社に対して1億円を貸し付けるとともに、A社に対する貸金債権を被担保債権として、A社所有の甲建物について抵当権の設定を受け、その旨の登記を経由した。その際、XA社間では、甲建物を他に賃貸する場合には、Xの承諾を得ることを合意していた。ところが、A社は、かかる合意に反して、Xの承諾を得ずに、A社の代表取締役であるYに対して、甲建物を賃料月額1万円、期間30年、敷金3億円の約定で貸し渡した。なお、甲建物の適正賃料は、月額100万円程度である。その後、弁済期を過ぎてもA社が1億円の返済をしようとしないので、Xは、抵当権の実行としての競売手続を開始した。しかし、競売手続の中で、甲建物の最低売却価額は引き下げられる一方であるにもかかわらず、甲建物の買い手は一向に現れる気配がない。そこで、Xは、Yに対して、Xに対して甲建物を明け渡すよう求めた。Xの請求は認められるか。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- X→A社に1億円貸付・甲建物に抵当権設定＋登記／賃貸承諾特約
- A社、特約に反し代表取締役Yへ賃貸（月1万・敷金3億・30年）
- 弁済期後もA社返済せず → Xが競売手続を開始
- 競売中、最低売却価額は下がる一方・買い手が現れない
- XがYに対しX自身への明渡しを請求

### 入口の問い（3問）

- **Q01［事案の整理］** 登場人物と「担保・占有・競売」の流れを挙げて
  - 答え：X＝抵当権者（甲建物に登記あり）。A社＝所有者・設定者・債務者。Y＝賃借人＝占有者でA社の代表取締役。請求はY自身に対しX自身への明渡しを求めるもの。
  - 答え：A社とYは実質的に同一体とみうる（代表取締役への背信的賃貸）。ここを掴むと、後段の「妨害目的」「自己への明渡し」が一気に見える。
- **Q02［見当づけ］** 請求の「法的根拠」 ― 見当をつけて
  - 答え：XはYと契約関係を持たない → 物権に基づく請求。Xは甲建物に抵当権（369条）を持つ → 抵当権に基づく物権的請求権（妨害排除請求）。明渡し＝占有の除去だから「妨害排除」型。賃料への追及なら物上代位だが、本問は占有の除去なので筋が違う。
- **Q03［論点］** 問題になる論点を挙げて（3つ）
  - 答え：CP①：抵当権は非占有担保 → そもそも占有者に妨害排除を観念できるか（侵害要件）。（＝交換価値の実現が妨げられ優先弁済請求権の行使が困難となる状態・最大判平11.11.24）
  - 答え：CP②：Yは賃借人＝占有権原あり → 占有権原ある者に及ぶか（競売妨害目的の加重要件）。（占有権原ある者への拡張＝最判平17.3.10）
  - 答え：CP③：Xが「自己への」明渡しを求める → 誰への明渡しか（管理占有）。（原則は設定者A社へ／例外＝維持管理を期待できない場合に自己へ）

### 骨子（3項目。第1から【論点】ごとに、何が問題→規範→使う事実→結論 の順で組み立てる）

#### 第1　妨害排除の可否

- 見出しの補足（結論を含む。項目の終わりに読む）：総論・侵害要件
1. XのYへの明渡し請求＝抵当権（369条）に基づく妨害排除請求（XY間に契約なし）
2. 抵当権は非占有担保 → 原則、占有それ自体は交換価値を左右せず侵害でない
3. 【論点】非占有担保に妨害状態を観念できるか（規範：交換価値の実現が妨げられ優先弁済請求権の行使が困難な状態＝侵害要件・平11大判）
4. 最低売却価額低下・買い手不在 → 交換価値実現の阻害＝侵害要件充足

#### 第2　占有権原ある第三者への妨害排除

- 見出しの補足（結論を含む。項目の終わりに読む）：競売妨害目的
1. Yは賃借人＝占有権原あり → 原則、妨害排除は及ばない
2. 【論点】占有権原ある者に及ぶか（規範：占有権原の設定に競売妨害目的＋侵害要件・平17判）

#### 第3　抵当権者自身への直接明渡し

- 見出しの補足（結論を含む。項目の終わりに読む）：効果・管理占有
1. 原則＝非占有担保ゆえ明渡しは所有者A社へ
2. 【論点】自己への直接明渡しの可否（規範：所有者に適切な維持管理を期待できない場合＝管理占有・平17判）

3. A社とYの実質的同一・背信的賃貸 → 維持管理を期待できない
- 結論：Xの請求は認められる

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】『最低売却価額は下がる一方・買い手が現れない』 → 交換価値の実現が妨げられ優先弁済が困難＝侵害要件
- 【拾う事実】『Xの承諾を要する特約に反する賃貸』 → 競売妨害目的の間接事実
- 【拾う事実】『YはA社の代表取締役』 → A社とYの実質的同一性
- 【拾う事実】『賃料月1万円（適正月100万）・敷金3億・30年』 → 賃貸借の実体を欠く異常条件＝妨害目的
- 【拾う事実】『XがY自身にX自身への明渡しを請求』 → 誰への明渡しか＝自己への直接明渡し
- 【効く事実】効く事実（侵害要件）
  - 競売手続の中で最低売却価額は引き下げられる一方なのに買い手が一向に現れない → 甲建物の交換価値の実現が現実に妨げられ、Xの優先弁済請求権の行使が困難となっている。
- 【ポイント】妨害目的を推認する間接事実（3つ）
  - ①承諾特約違反（Xの承諾を要する合意に反する賃貸）／②YはA社の代表取締役＝A社とYは実質的に同一／③賃料月1万円（適正は月100万）・敷金3億円・期間30年という賃貸借の実体を欠くほど著しく不合理な条件。3つを具体的に摘示して妨害目的を認定する。
- 【規範の要点】最判平17.3.10の規範
  - 抵当権は非占有担保 → 明渡しは原則として所有者（設定者A社）へ。もっとも、所有者において適切な維持管理を期待できない場合には、占有者に対し直接自己への明渡しを求めうる。この占有は使用収益権ではなく、競売を円滑に進めるための管理占有にとどまる。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 最大判平11.11.24＝不法占有者の事案で侵害要件を定立。最判平17.3.10＝占有権原ある者に競売妨害目的の加重要件を上乗せ＋自己への直接明渡しを承認。本問のYは賃借人だから平17判が主役、平11判は侵害要件の定式を借りる。抵当権侵害には損害賠償（709条）・増担保請求等も観念しうるが本問は明渡し（妨害排除）なので芋づる知識に留める。
- 【まぎらわしい選択肢・論点】抵当権に基づく物上代位の可否／法定地上権の成否
- 【まぎらわしい選択肢・結論】Xの請求は認められない
- 【まぎらわしい選択肢・規範】全面否定説／短期賃貸借の保護
- 【まぎらわしい選択肢・事実】賃料債権を差し押さえた／賃借権の登記が先

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

総論＝抵当権は非占有担保だが、交換価値の実現が妨げられ優先弁済請求権の行使が困難なら妨害排除の侵害要件充足。加重＝Yは賃借人＝占有権原ありだが、占有権原の設定に競売妨害目的あり（特約違反・代表取締役・異常条件）で妨害排除が及ぶ。効果＝原則は設定者へ、A社に維持管理を期待できないから自己へ直接明渡し（管理占有）。結論＝請求認容。

## 3. 規範クイズ（3問）

- **Q04［規範］** 抵当権に基づく妨害排除請求が認められるための侵害要件を述べよ（不法占有者の場合の一般規範）。
  - 模範解答：第三者の占有により抵当不動産の交換価値の実現が妨げられ、抵当権者の優先弁済請求権の行使が困難となる状態があること（最大判平11.11.24）。これが妨害排除請求の侵害要件の規範であり、この状態があるから抵当権者はその状態の排除を求めうるという結論になる。
- **Q05［規範］** 占有権原ある第三者に対して抵当権に基づく妨害排除請求が認められるための加重要件を述べよ（最判平17.3.10）。
  - 模範解答：抵当権設定登記後に所有者から占有権原の設定を受けた者につき、①その占有権原の設定に競売手続を妨害する目的が認められ、②その占有により交換価値の実現が妨げられ優先弁済請求権の行使が困難となる状態があること。侵害要件（②）に競売妨害目的（①）を上乗せする。
- **Q06［規範］** 抵当権者が占有者に対し直接自己への抵当不動産の明渡しを求めうるのはどのような場合か（効果の例外要件）。
  - 模範解答：抵当不動産の所有者において、抵当権に対する侵害が生じないように抵当不動産を適切に維持管理することが期待できない場合（最判平17.3.10）。原則は設定者への返還、例外としてこの場合に自己への直接明渡し（管理占有）が認められる。

## 4. ○×クイズ（7問）

- **Q07［○×］** 抵当権は、目的物の占有を設定者のもとに残したまま、その交換価値のみを把握する非占有担保である。
  - 正解：○（正しい）
  - 理由：抵当権（369条）は、目的物の占有を設定者に残して使用収益を継続させたまま、交換価値のみを把握する非占有担保である。抵当権者は目的物を占有する権能を持たない。この「占有を伴わない」性質こそが、占有者への妨害排除を認めてよいかという本問の出発点になる。
- **Q08［○×］** 抵当権者が、抵当不動産を占有する第三者に対してその明渡しを求める場合の法的根拠は、抵当権に基づく物上代位（372条・304条）である。
  - 正解：×（誤り）
  - 理由：占有の除去（明渡し）を求める根拠は、抵当権に基づく物権的請求権（妨害排除請求）である。物上代位は、目的物が形を変えた代替物（賃料・売却代金・保険金等）に対して優先弁済を及ぼす制度であって、占有の除去を目的とするものではない。請求の内容が「占有の除去」か「価値への追及」かで根拠が分かれる。
- **Q09［○×］** 占有権原のある第三者に対して抵当権に基づく妨害排除請求をするには、不法占有者の場合に要求される侵害要件に加えて、その占有権原の設定に競売手続を妨害する目的があることを要する。
  - 正解：○（正しい）
  - 理由：占有権原ある者の占有は原則として適法であり、そのままでは妨害排除は及ばない。判例（最判平17.3.10）は、①占有権原の設定に競売手続を妨害する目的が認められ、②侵害要件（交換価値実現の阻害・優先弁済請求権行使の困難）がある場合に限り妨害排除を認める。侵害要件に「競売妨害目的」を上乗せする二段構えである。
- **Q10［○×］** 抵当権に基づく妨害排除請求が認められるための侵害要件は、第三者の占有により抵当不動産の交換価値の実現が妨げられ、抵当権者の優先弁済請求権の行使が困難となる状態が生じていることである。
  - 正解：○（正しい）
  - 理由：抵当権も物権である以上、その円満な価値支配が害されれば物権的請求権を生じる。もっとも非占有担保ゆえ占有それ自体は原則侵害でないから、侵害を「交換価値の実現が妨げられ優先弁済請求権の行使が困難となる状態」に限定する（最大判平11.11.24）。「交換価値が下がる」と雑にまとめず、優先弁済請求権の行使困難まで正確に書くのが要点。
- **Q11［○×］** 抵当権の設定登記後にその不動産の賃借権の設定を受けた占有者は、正当な賃借権に基づいて占有している以上、抵当権に基づく妨害排除請求が及ぶ余地はない。
  - 正解：×（誤り）
  - 理由：占有権原ある者への占有は原則として妨害排除が及ばないが、その占有権原の設定に競売手続を妨害する目的が認められ、侵害要件も充たされる場合には、抵当権者は当該占有者に対しても妨害排除請求ができる（最判平17.3.10）。「占有権原あり＝およそ及ばない」と切ると加重要件を落とし大幅減点。原則と例外を分けて処理する。
- **Q12［○×］** 抵当権者が占有者から直接自己への抵当不動産の明渡しを受けた場合、その占有は目的物を使用収益するためのものではなく、競売手続を円滑に進めるために維持管理するための管理占有にとどまる。
  - 正解：○（正しい）
  - 理由：抵当権は非占有担保であり抵当権者は使用収益権を持たない。自己への直接明渡しが認められても、それは抵当権者に使用収益を認める趣旨ではなく、競売手続の円滑化のために目的物を維持管理する管理占有にとどまる（最判平17.3.10）。
- **Q13［○×］** 抵当権者は、抵当権に基づく妨害排除請求のほか、抵当不動産の所有者が占有者に対して有する妨害排除請求権を、債権者代位権（423条）によって代位行使することもできる。
  - 正解：○（正しい）
  - 理由：判例（最大判平11.11.24）は、抵当権自体に基づく妨害排除請求のほか、所有者の妨害排除請求権を債権者代位（423条）により行使する構成も認めた。特定債権保全の転用型として債務者の無資力は不要。抵当権自体構成を採りつつ、この代位構成に一言触れると理論的な厚みが出る。
