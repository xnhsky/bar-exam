## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

Aは、その所有の事務所用建物について、債権者甲のために抵当権を設定し、その登記をした後、抵当権の設定当時からその建物に備え付けられていた冷暖房用の機械を新式のものと取り替えた。Aは、その後、その機械を取り外して持ち出し、乙に売却した。この場合における甲・乙間の法律関係を説明せよ。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- A、建物に甲の抵当権を設定・登記（設定当時、旧冷暖房機が備付け）
- 設定「後」、旧機械を新式の本件機械に取替え

- A、本件機械を乙に売却
- 甲が乙に①返還請求・②売買代金債権への物上代位を検討（代金支払の有無は不明）

### 入口の問い（4問）

- **Q01［事案の整理］** 登場人物と「甲がとりうる手段」を挙げて
  - 答え：甲の手段は2つ。①抵当権に基づく本件機械の返還請求（乙への追及）／②Aの乙に対する売買代金債権への物上代位（372条・304条1項）。
  - 答え：A＝設定者本人は甲・乙間の当事者ではない。問いは甲・乙間の法律関係に絞られている。ここを外さない。
- **Q02［見当づけ］** 各手段は「根拠条文はどれ？」 ― 見当をつけて
  - 答え：①効力が及ぶか → 付加一体物（370条）・従物（87条）。②返還請求できるか → 追及効・対抗要件（177条）・即時取得（192条）。③代金に食らいつけるか → 物上代位（372条・304条）。
- **Q03［論点］** 問題になる論点を挙げて（3つ）
  - 答え：CP①：取外し可能＝独立性あり → 付合物ではなく従物と性質決定。（従物＝独立性を保ちつつ継続的に主物の効用を助ける物・87条1項）
  - 答え：CP②：370条の付加一体物に従物が含まれるか → 370条説／87条2項説。（370条説＝経済的一体性で拡張／87条2項説＝設定を「処分」とみる）
  - 答え：CP③：本件は設定「後」に取り替えた従物 → 87条2項説のアキレス腱。370条説なら設定時期を問わない。
- **Q04［論点］** 問題になる論点を挙げて（2つ）
  - 答え：CP①：分離物への追及の限界＝公示の衣説（対抗要件説）。搬出＝場所的支配範囲を離れた→ 対抗力なし。乙が背信的悪意者でもない。
  - 答え：CP②：即時取得説（192条）による処理も。分離＝動産 → 乙が平穏・公然・善意・無過失なら即時取得成立 → 返還否定。いずれの説でも返還請求は認められない。

1. 取外し可能＝独立性あり → 【論点】付合物か従物か → 従物と認定（飛ばさない）
2. 【論点】従物に370条の効力が及ぶか（規範：370条説＝付加一体物に従物を含む）

3. 【論点】設定後の従物への効力 → 交換事例でも及ぶ（87条2項説でも結論同旨）

#### 第2　甲の乙への返還請求の可否

- 見出しの補足（結論を含む。項目の終わりに読む）：分離物と第三者

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「備え付けられていた冷暖房用の機械」 → 付合物か従物かの性質決定
- 【拾う事実】「設定当時から…新式のものと取り替えた」 → 設定後の従物への効力（学説の急所）
- 【拾う事実】「取り外して持ち出し」 → 分離・搬出＝場所的支配範囲を離れた
- 【拾う事実】「乙に売却した」 → 第三者との優劣（対抗力・即時取得）
- 【拾う事実】『「売買代金」（支払の有無不明）』 → 払渡し前の差押え＝物上代位の可否
- 【ポイント】性質決定を飛ばさない
  - 付合物（242条）なら370条で当然に及ぶ＝論点が生じない。取外し可能な機械は独立性を保つ従物と認定してこそ「従物に及ぶか」の論点に入れる。
- 【規範の要点】公示の衣説の規範
  - 分離物にも効力自体は及ぶが、抵当権は登記で公示される以上、その追及効は抵当不動産の場所的支配範囲（公示の衣）内にある限り第三者に対抗でき、搬出されて場所的支配範囲を離れれば対抗力を失う。本件機械は搬出済み → 乙に対抗できない。
- 【ポイント】差押え要件を落とさない
  - 物上代位の行使には払渡し又は引渡しの前に差押えが必要（304条1項ただし書）。趣旨は第三債務者を二重弁済の危険から保護すること。代金支払前なら差押えで行使可、支払後は不可。本問は支払の有無不明＝場合分け。
- 【まぎらわしい選択肢・論点】法定地上権の成否／177条の第三者の範囲／抵当権に基づく妨害排除請求
- 【まぎらわしい選択肢・結論】返還請求が認められる／物上代位は認められない
- 【まぎらわしい選択肢・規範】価値権説／対抗要件具備時説
- 【まぎらわしい選択肢・事実】設定当時の従物／代金は既払い

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

①効力＝取外し可能で従物、370条説で付加一体物に従物含む、設定の前後問わず及ぶ。②返還＝分離物にも効力は及ぶが、公示の衣説で搬出＝対抗力なし、即時取得でも同じ、返還不可。③物上代位＝代金は「売却で受けるべき金銭」、否定説は射程外、304条ただし書の差押えを支払前なら行使可。

## 3. 規範クイズ（4問）

- **Q05［規範］** 従物に抵当権の効力が及ぶ根拠について、370条説と87条2項説それぞれの構成を述べよ。
  - 模範解答：370条説＝「付加して一体となっている物」に付合物のみならず従物も含めて読み、設定の前後を問わず効力が及ぶ。87条2項説＝付加一体物は付合物に限り、従物へは87条2項（抵当権の設定を「処分」とみる）により効力を及ぼす。
- **Q06［規範］** 87条2項説の「アキレス腱」（弱点）と、本問のような設定後の交換従物をどう処理するかを述べよ。
  - 模範解答：87条2項説は「設定＝処分」を基礎とするため、設定時に存在しなかった従物への効力を説明しにくい（アキレス腱）。もっとも、設定当時の従物と交換された新従物に効力が及ばないのは担保価値維持の趣旨に反するから、交換事例では効力を肯定する（多数）。結論は370条説と変わらない。
- **Q07［規範］** 分離物を動産とみる即時取得説（192条）による本問の処理を述べよ。
  - 模範解答：分離により動産となった以上、第三者は即時取得（192条）で保護されうる。乙が取引行為により平穏・公然・善意・無過失で占有を取得すれば、抵当権の負担のない所有権を原始取得し返還請求は否定される。A自身の売却で盗品・遺失物でないから193条の特則は働かない。公示の衣説と結論は同じ。
- **Q08［規範］** 304条1項ただし書が「払渡し前の差押え」を要求する趣旨を述べよ（判例の理解）。
  - 模範解答：第三債務者を二重弁済の危険から保護する趣旨（第三債務者保護説・最判平10.1.30）。第三債務者は差押えがあって初めて抵当権者への支払を要すると分かるため、払渡し前の差押えを要件とすることで、既に債務者へ弁済した第三債務者が再度支払う危険を避ける。

## 4. ○×クイズ（10問）

- **Q09［○×］** 抵当権者は、目的物の占有を設定者から自己に移転して初めて第三者に対する対抗力を取得する。
  - 正解：×（誤り）
  - 理由：抵当権は目的物の占有を設定者に留めたまま設定できる非占有担保であり、対抗要件は登記である（177条）。占有移転を要しない点が質権との決定的な違い。だからこそ「登記による公示がどこまで及ぶか」が分離物への追及（論点2）で問題になる。
- **Q10［○×］** 抵当権に物上代位（目的物の売却・賃貸・滅失等による価値変形物への権利行使）が認められる直接の根拠は、先取特権の304条を抵当権に準用する372条である。
  - 正解：○（正しい）
  - 理由：物上代位は本来304条が先取特権について定める制度で、372条が抵当権に準用する。答案で372条を落として304条だけ挙げると、抵当権への準用の根拠が欠ける。
- **Q11［○×］** 売買代金債権への物上代位を検討する前提として、まずその物（本件機械）に抵当権の効力が及んでいることを確定する必要がある。
  - 正解：○（正しい）
  - 理由：物上代位は「抵当権の効力が及ぶ物」が売却等で価値変形した場合の制度だから、効力が及ばない物の売却代金には物上代位できない。効力（前提）→返還請求→物上代位の順は、前が後の前提となる論理の階段。
- **Q12［○×］** 取り外して持ち出すことができる冷暖房用機械は、建物に付合して独立性を失った付合物（242条）であり、当然に370条の効力が及ぶから、効力の根拠は論点にならない。
  - 正解：×（誤り）
  - 理由：取外し可能な機械は独立性を保つ従物（87条1項）であって、独立性を失った付合物ではない。従物だからこそ「370条の付加一体物に含まれるか」という本問の核心論点に入る。
- **Q13［○×］** 370条説（付加一体物に従物を含めて読む見解）によれば、従物への抵当権の効力は抵当権設定の前後を問わずに及ぶと説明できる。
  - 正解：○（正しい）
  - 理由：抵当権は目的物の交換価値を把握する権利だから、経済的一体をなす従物にも効力が及ぶべきとして370条の付加一体物に従物を含める。この見解では設定時期を問わないので、設定後に取り替えた本件機械も余分な理論構成なく処理できる。
- **Q14［○×］** 公示の衣説によれば、抵当不動産から分離した物が場所的支配範囲内にある間は登記による対抗力が及ぶが、搬出されて場所的支配範囲を離れると、抵当権者は第三者にその効力を対抗できない。
  - 正解：○（正しい）
  - 理由：抵当権は登記で公示される権利だから、追及効も公示（場所的支配）を基準に画するのが公示の衣説（対抗要件説）。本件機械は取り外して持ち出され場所的支配範囲を離れているから、甲は乙に対抗できず返還請求は認められない。「搬出済み」という客観的事実で結論が出る。
- **Q15［○×］** 抵当不動産から分離・搬出された動産には、もはや抵当権の効力自体が消滅するから、抵当権者はいかなる第三者に対してもその物を主張する余地は一切ない。
  - 正解：×（誤り）
  - 理由：分離しても抵当権の効力自体は及ぶ。問題は「第三者に対抗できるか」という対抗力のレベルで、効力の消滅とは別の話。公示の衣説は場所的支配範囲を離れると対抗力を失うとするだけで、効力が消えるわけではない（例えば搬出前の分離物や、場所的支配範囲内なら対抗しうる）。効力と対抗力を混同しない。
- **Q16［○×］** 抵当権者が物上代位権を行使するには、目的債権の払渡し又は引渡しの前に差押えをすることを要する（304条1項ただし書）。
  - 正解：○（正しい）
  - 理由：差押えは物上代位行使の要件。その趣旨は第三債務者（本問の乙）を二重弁済の危険から保護する点にある（第三債務者保護説＝最判平10.1.30）。したがって代金がAに支払われる前であれば差押えにより行使できるが、支払後は行使できない。
- **Q17［○×］** 抵当目的物が売却された場合、抵当権には追及効があるのだから、その売買代金債権への物上代位はいかなる場合も一切認められない。
  - 正解：×（誤り）
  - 理由：「追及できるから物上代位は不要」とする否定説はあるが、それが念頭に置くのは抵当目的物そのものが売却された事案。本問のように従物が分離・売却され、しかも返還請求（追及）が封じられた事案まで射程に含むとは解されない。むしろ追及が事実上封じられたからこそ物上代位の必要性が高い。否定説の射程を限定して肯定するのが本問の処理。
- **Q18［○×］** 本件のように従物が分離・売却されて返還請求（追及）が事実上封じられた事案では、否定説の射程外として売買代金債権への物上代位を認めるのが相当である。
  - 正解：○（正しい）
  - 理由：物上代位否定説（追及効説）が念頭に置くのは目的物そのものの売却事案。本問は従物の分離売却で、公示の衣説により返還請求が封じられている。追及が封じられた以上、代金への物上代位を認めなければ抵当権者は担保価値を回収できない。返還不可だからこそ物上代位で拾う——三段が一本につながる。
