### 問題文（最初にゆっくり読み上げる）

A社は、ブリ、ハマチ、カンパチ等の養殖・加工・販売等を業とする株式会社である。A社は、B銀行から1億円の融資を受けるに当たり、B銀行との間で、B銀行のA社に対する1億円の貸金債権を被担保債権、今後A社の生簀内にある養殖魚（以下「本件養殖魚」という。）全部を譲渡担保の目的とする譲渡担保契約を締結し（以下「本件集合動産譲渡担保契約」という。）、占有改定の方法により本件養殖魚全部を引き渡した。以下、各小問は独立した問いである。⑴　その後、A社はCに対して本件養殖魚全部を売却し占有改定による引渡しをしたが、Cが現実の引渡しを受ける前に、B銀行は返済のないA社に対し譲渡担保を実行しようとしていた。Cは、B銀行による実行に対していかなる法的主張をすることができるか。⑵　本件契約の少し前、A社はD社から養殖用のブリ1万匹を仕入れていた（代金未払）。A社がB銀行・D社いずれにも支払をしないので、両者は担保権を行使することにした。D社はいかなる担保権を行使し得るか。また、D社の担保権とB銀行の譲渡担保権ではいずれが優先するか。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- A社がD社からブリ1万匹仕入れ（代金未払）＝先取特権発生
- A社・B銀行が集合動産譲渡担保契約・占有改定で引渡し
- A社がCへ本件養殖魚全部を売却・占有改定（現実の引渡しなし）
- A社が返済も代金支払もせず債務不履行
- B銀行が譲渡担保を実行（⑴）／B・D社が担保権行使（⑵）

登場人物：

### 入口の問い（3問）

- **Q01［事案の整理］** 登場人物と「権利関係」を挙げて
  - 答え：対立軸は2本。小問⑴＝C（譲受人）対 B銀行（譲渡担保権者）／小問⑵＝D社（先取特権者）対 B銀行。A社は設定者兼処分者で全体のハブ。
  - 答え：物（本件養殖魚＝生簀内の集合物）は客体。誰が客体に対しどの権利を持つかを線で結ぶのが第一歩。
- **Q02［見当づけ］** 各当事者が「何を主張・行使するか」 ― 見当をつけて
  - 答え：C：実行阻止 → まず担保権を潰す（有効性・対抗要件）→ ダメなら自分が所有権を取った（通常営業の範囲・即時取得 192条）。D社：代金未払で売った物 → 動産売買先取特権（311条5号・321条）→ 優劣は333条。
- **Q03［論点］** 小問⑴で問題になる論点を挙げて（3つ）
  - 答え：CP①：目的物が増減変動する集合物 → 集合物の特定性・一物一権主義（有効性の前提）。（＝流動する在庫類を一個の物として担保化できるか）
  - 答え：CP②：契約後に搬入された魚に対抗力が及ぶか → 対抗要件具備の効力の及ぶ範囲（昭62判例）。
  - 答え：CP③：A社がCに全部売却 → 通常の営業の範囲・離脱・占有改定の即時取得（192条）。

### 骨子（3項目。第1から【論点】ごとに、何が問題→規範→使う事実→結論 の順で組み立てる）

#### 第1　小問⑴前提　本件集合動産譲渡担保の有効性・対抗要件

1. 目的物は増減変動する集合物 → 【論点】集合物の特定性・一物一権主義（規範：種類・所在場所・量的範囲）
   - あてはめ：「生簀内の養殖魚全部」＝3要素充足 → 特定性あり＝有効
2. 【論点】対抗要件具備の効力の及ぶ範囲 → 同一性ある限り変動後も及ぶ
   - あてはめ：B銀行は占有改定で全部の引渡しを受済み → 後発搬入分にも対抗力
- 結論：有効・対抗要件も具備（Cの前提潰しは不発）

#### 第2　小問⑴帰結　Cの所有権取得の可否

1. 【論点】通常の営業の範囲 → 範囲内なら確定的取得／範囲外は離脱なき限り承継取得不可
   - あてはめ：「全部」売却＝範囲外・現実の引渡し前＝離脱なし
2. 【論点】占有改定による即時取得 → 外観の変更なく「占有を始めた」に当たらず否定
   - あてはめ：Cへの引渡しは占有改定にとどまる
- 結論：Cは所有権を取得できず主張はいずれも認められない

#### 第3　小問⑵　D社の担保権と優劣

1. D社＝動産売買先取特権（311条5号・321条）を行使し得る
2. 【論点】先取特権と譲渡担保の優劣（333条）→ 譲渡担保権者は「第三取得者」／占有改定も「引渡し」
   - あてはめ：特段の事情なし
- 結論：特段の事情なき限りB銀行の譲渡担保権が優先

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「生簀内にある養殖魚全部」 → 特定性の3要素（種類・所在場所・量的範囲）を認定する材料
- 【拾う事実】『「占有改定の方法により」引渡し』 → 対抗要件具備・後に333条の「引渡し」該当へつながる
- 【拾う事実】『Cに「全部」を売却』 → 通常の営業の範囲を超える処分か（範囲外の評価）
- 【拾う事実】「現実の引渡しを受ける前」 → 集合物からの離脱がない＝承継取得不可の材料
- 【拾う事実】『Cへの引渡しは「占有改定」』 → 占有改定による即時取得の否定（192条）
- 【拾う事実】『D社からブリ仕入れ・代金未払』 → 動産売買先取特権の発生（311条5号・321条）
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 被担保債権（貸金1億円）・当事者は争いなし＝一言。占有改定による対抗要件具備も事実で認定＝一言。論点になるのは「特定性」「通常営業の範囲・離脱」「占有改定と即時取得」「333条の優劣」だけ。争いなき所は淡々と通す。
- 【効く事実】「ここが」のあてはめで使う事実
  - 通常営業の範囲外 → 「全部売却」を直接引用（在庫の一部処分ではなく丸ごと）／離脱なし → 「現実の引渡しを受ける前」＝物はなお生簀内／即時取得否定 → 「占有改定にとどまる」。
- 【規範の要点】「先取特権と優劣」の規範
  - 譲渡担保権者は特段の事情なき限り333条の「第三取得者」に該当し、占有改定も同条の「引渡し」に含まれる → 先取特権者はもはや目的物を追及できず、占有改定で引渡しを受けたB銀行が優先。結論だけでなく2つの該当性を明示するのが筋。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 同じ占有改定でも ① 対抗要件（178条）＝○ 引渡しに当たる／② 即時取得（192条）＝× 「占有を始めた」に当たらない／③ 先取特権と第三取得者（333条）＝○ 「引渡し」に当たる。無権利者からの取得を治癒する即時取得だけ「外観の変更」を要するから否定される、と一本の理由で押さえる。
- 【まぎらわしい選択肢・論点】物上代位の可否／背信的悪意者の排除／即時取得の善意無過失
- 【まぎらわしい選択肢・結論】Cが所有権を取得する／D社の先取特権が優先する
- 【まぎらわしい選択肢・規範】分析論／狭義説
- 【まぎらわしい選択肢・事実】現実の引渡しあり／通常営業の範囲内

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

⑴前半＝生簀内の養殖魚全部で特定性あり有効、占有改定の対抗力は同一性ある限り後発分にも及ぶ＝Cの前提潰しは不発。⑴後半＝全部売却で範囲外、現実の引渡し前で離脱なし、占有改定は即時取得×＝Cは所有権取得できず主張は認められない。⑵＝D社は動産売買先取特権、333条で譲渡担保権者は第三取得者・占有改定も引渡し＝特段の事情なきB銀行が優先。

## 3. 規範クイズ（3問）

- **Q04［規範］** 構成部分の変動する集合動産が「一個の集合物」として譲渡担保の目的となるために必要な特定性の3要素を挙げよ。
  - 模範解答：①種類・②所在場所・③量的範囲の指定（最判昭54.2.15）。本問は「A社の生簀内にある養殖魚全部」＝種類（養殖魚）・所在場所（A社の生簀内）・量的範囲（全部）が揃い、特定性あり＝有効。
- **Q05［規範］** 設定者が目的動産を処分した場合、譲受人が確定的に所有権を取得できるのはどのような場合か、及び範囲を超える処分の場合の帰結を規範として述べよ。
  - 模範解答：設定者には通常の営業の範囲内で処分する権限が付与され、その相手方は譲渡担保の拘束を受けず確定的に所有権を取得する。範囲を超える処分では、集合物から離脱したと認められる場合でない限り、相手方は承継取得できない（最判平18.7.20）。
- **Q06［規範］** 動産売買先取特権と集合動産譲渡担保権の優劣を決する枠組み（適用条文・2つの該当性・結論）を述べよ。
  - 模範解答：333条で処理。①譲渡担保権者は特段の事情なき限り「第三取得者」に該当（最判昭62.11.10）、②占有改定も「引渡し」に含まれる（大判大6.7.26）。∴占有改定で引渡しを受けた譲渡担保権者に対し先取特権は行使できず、特段の事情なき限り譲渡担保権者（B銀行）が優先。

## 4. ○×クイズ（8問）

- **Q07［○×］** 集合動産譲渡担保では、目的物の占有は設定者（債務者）のもとに留められ、対抗要件は占有改定（183条）の方法により具備されるのが通常である。
  - 正解：○（正しい）
  - 理由：担保に供しつつ営業を継続するため、目的物は設定者の手元に残す。ゆえに引渡しは観念的な占有改定によることになり、これが「対抗要件は備えているのに物は設定者の下にある」という本問の構図（第三者Cの登場・先取特権との競合）を生む出発点になる。
- **Q08［○×］** 動産売買の先取特権（311条5号）が成立するには、売主と買主との間で当該動産を担保にする旨の合意（約定担保権の設定）があることが必要である。
  - 正解：×（誤り）
  - 理由：先取特権は法定担保物権で、法定の原因（動産の売買）があれば当事者の合意なくして当然に発生する。D社は担保設定を受けていないが、代金債権を被担保債権として売却したブリにつき当然に先取特権を有する。「担保を取っていないから無担保」と誤ると小問⑵の入口を落とす。
- **Q09［○×］** 構成部分が増減変動する集合動産を一個の物として譲渡担保の目的とすることは、一物一権主義に反するから、およそ認められない。
  - 正解：×（誤り）
  - 理由：判例（最判昭54.2.15）は、種類・所在場所・量的範囲を指定するなどの方法で目的物の範囲が特定される場合には、一個の集合物として譲渡担保の目的となり得るとする。一物一権主義の趣旨（必要性・公示可能性）を満たすからで、およそ不可なのではなく特定性を条件に有効。
- **Q10［○×］** 占有改定によって集合物について対抗要件が備えられた後は、構成部分が変動しても、集合物としての同一性が損なわれない限り、新たに構成部分となった動産を包含する集合物について対抗要件具備の効力が及ぶ。
  - 正解：○（正しい）
  - 理由：最判昭62.11.10 の規範。一個一個の動産ごとに改めて占有改定を要すると考えると当事者の合理的意思と乖離し煩雑にすぎるため、同一性が損なわれない限り変動後の動産にも及ぶとした。本問でも契約後に搬入された魚を含め対抗要件は具備されており、Cの「後発分は対抗要件なし」の主張は通らない。
- **Q11［○×］** 集合動産譲渡担保の設定者が目的物を「通常の営業の範囲」を超えて処分した場合であっても、当該目的物が集合物から離脱したと認められない限り、処分の相手方はその所有権を承継取得することができない。
  - 正解：○（正しい）
  - 理由：最判平18.7.20 の規範。範囲内なら確定的取得、範囲外なら「離脱」が承継取得の分水嶺。本問は「全部売却」＝範囲外、かつ「現実の引渡し前・物は生簀内」＝離脱なしで、Cは承継取得できない。範囲外で終わらせず離脱の有無まで検討するのが差のつくポイント。
- **Q12［○×］** 無権利者から動産を占有改定（183条）により取得した者も、即時取得（192条）の要件である「占有を始めた」に当たるから、善意無過失であれば即時取得により所有権を取得できる。
  - 正解：×（誤り）
  - 理由：判例（最判昭35.2.11）は、占有改定では一般外観上従来の占有状態に変更を生じないから「占有を始めた」に当たらず即時取得を否定する。Cは占有改定にとどまるから即時取得できない。同じ占有改定でも333条の「引渡し」には当たる（場面が違う＝手6で対比）点と混同しないこと。
- **Q13［○×］** 動産売買先取特権の目的動産が集合動産譲渡担保の目的物の構成部分となった場合、譲渡担保権者は、特段の事情がない限り、民法333条にいう「第三取得者」に該当する。
  - 正解：○（正しい）
  - 理由：最判昭62.11.10。譲渡担保は所有権移転の形式をとるから、譲渡担保権者は目的物の「第三取得者」に位置づけられる。ゆえに債務者から譲渡担保権者への引渡し後は、先取特権者は333条により追及できない。「特段の事情」（目的物の価額が被担保債権額を上回る等）が無い本問ではB銀行が優先する。
- **Q14［○×］** 占有改定は、対抗要件（178条）としても、即時取得（192条）としても、いずれも「引渡し」「占有の開始」として肯定的に扱われる。
  - 正解：×（誤り）
  - 理由：対抗要件（178条）・先取特権の第三取得者（333条）では占有改定は「引渡し」に当たるが、即時取得（192条）では否定される。即時取得は無権利者からの取得を治癒し真の権利者を害する制度ゆえ、外観の変更（現実の支配移転）を要求して適用を絞るからである。この非対称が本問の得点源。
