- 【拾う事実】「Ｙが3歳のとき」「代諾養子縁組」 → 15歳未満・法定代理人でない者の代諾
- 【拾う事実】「Ｙは、ＣＤに対し、養子縁組の追認の意思表示」 → 116条本文類推の起動
- 【拾う事実】「ＣＤの実の子であるＺ」 → 追認前からの第三者＝ただし書類推の可否
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 小問(1)＝血縁なし＝親子関係なし（争いなし）。小問(2)＝代諾者ＸＡはＹの法定代理人でない＝有効な代諾を欠く（797条1項・争いなし）。争点は「転換できるか」「権利濫用か」「追認で治るか」「ただし書で第三者を守るか」の4つ。
- 【効く事実】「権利濫用」のあてはめで使う事実
  - 期間 → 出生届(1970)から提訴(2021)まで約50年／態度 → 一度もＹの実子性を否定せず（信頼形成・矛盾挙動）／不利益 → 突然の否定による精神的苦痛・相続資格の喪失／動機 → 「全財産をＢに」＝正当とはいえない目的。
- 【規範の要点】二段の規範
  - ①法定代理人でない者の代諾は一種の無権代理 → 本人（Ｙ）が15歳到達後に追認すれば116条本文類推で縁組の時に遡って有効（本人意思の尊重・最判昭27.10.3）。②116条ただし書は取引安全の規定 → 事実関係を重視する身分行為の本質に反するから類推せず（最判昭39.9.8）。Ｚの相続分が事実上減っても身分行為ゆえやむを得ない。
- 【まぎらわしい選択肢・論点】嫡出否認の訴えの可否／表見代理（110条）の成否
- 【まぎらわしい選択肢・結論】Ｘの請求は認められる／養子縁組無効確認の訴えは認められる
- 【まぎらわしい選択肢・規範】認知届への転換の肯定／身分占有による親子関係の擬制
- 【まぎらわしい選択肢・事実】縁組意思の不存在／戸籍の訂正手続

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

小問(1)＝虚偽届で親子関係なし、養子縁組は要式行為で転換否定、でも50年・実子否定なし・「全財産をＢに」の動機＝権利濫用で請求棄却。小問(2)＝法定代理人でない代諾で無効、Ｙの追認で116条本文類推＝遡及的有効、ただし書は身分行為の本質に反し類推せず＝Ｚの請求棄却。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 虚偽の嫡出子出生届を養子縁組届とみなす「無効行為の転換」を、判例が否定する理由を述べよ。
  - 模範解答：養子縁組は所定の届出（799条・739条1項）によって法律上効力を有する要式行為であり、かつ強行法規と解すべきだから。方式を欠く嫡出子出生届で養子縁組の届出を代用することは許されない（最判昭50.4.8）。事実上の親子関係の保護は転換ではなく権利濫用法理で図る。
- **［規範クイズ 2/3］** 親子関係不存在確認の訴えが権利濫用に当たるかの判断で、判例（最判平18.7.7）が総合考慮する諸般の事情を挙げよ。
  - 模範解答：①実の親子と同様の生活の実体があった期間の長さ ②不存在確定により受ける精神的苦痛・経済的不利益 ③請求に至った経緯・請求の動機・目的 ④不存在が確定されないことで不利益を受ける者の存否 等。これらを総合し、不存在確定が著しく不当な結果をもたらすときは権利濫用（1条3項）に当たり許されない。
- **［規範クイズ 3/3］** 無効な代諾養子縁組の追認に116条ただし書を類推適用しない理由を述べよ。
  - 模範解答：116条ただし書は取引の安全のための規定であり、これを事実関係を重視する身分関係の本質に照らして養子縁組の追認に類推適用することは、その本質に反するから（最判昭39.9.8）。身分関係は誰との関係でも画一的・絶対的に定まるべきで、第三者ごとに相対化すべきでない。ゆえに追認の遡及効は第三者にも及ぶ。

## 4. ○×クイズ（全7問・1問目から最後まで全部出す）

- **［○×クイズ 1/7］** 他人の子を自分たち夫婦の嫡出子として虚偽の出生届をしても、その届出によって実親子関係（嫡出親子関係）が生じることはない。
  - 正解：○（正しい）
  - 理由：実親子関係は血縁（分娩・懐胎）を基礎とし、出生届は報告的届出にすぎない。血縁のない者の間に虚偽の出生届をしても実親子関係は発生しない（いわゆる「藁の上からの養子」）。これが本問全体の大前提で、そこから「では別の法律構成で救えないか」に進む。
- **［○×クイズ 2/7］** 親子関係不存在確認の訴えには、嫡出否認の訴え（774条以下）と異なり、提訴権者や出訴期間の法律上の制限がない。
  - 正解：○（正しい）
  - 理由：嫡出否認の訴えは提訴権者・出訴期間（令和4年改正で原則3年）が厳格に限定されるのに対し、実親子関係の不存在を争う親子関係不存在確認の訴えは確認の利益がある限り期間制限なく提起できる。両者は制度趣旨が異なるためである。もっとも、この期間制限のなさゆえに数十年後の紛争が生じうるので、判例は権利濫用（1条3項）による事後的な歯止めを認める（最判平18.7.7）。
- **［○×クイズ 3/7］** 虚偽の嫡出子出生届を養子縁組の届出とみなすこと（転換）は判例上否定されるが、非嫡出子を嫡出子として届け出た場合には、その出生届に認知届としての効力を認めうる。
  - 正解：○（正しい）
  - 理由：認知は血縁という事実の承認であり要式性の要請が緩やかなので、判例は嫡出子出生届に認知届としての効力を認める（最判昭53.2.24）。他方、養子縁組は法定の届出で新たな身分関係を創設する要式行為だから、出生届による転換は否定される（最判昭50.4.8）。同じ「無効行為の転換」でも認知＝肯定／養子縁組＝否定という使い分けが判別基準。
- **［○×クイズ 4/7］** 養子縁組は、養子縁組の届出という法定の方式によってはじめて効力を生じる要式行為であるから、他人の子を実子として届け出ても、その出生届をもって養子縁組の届出とみなすことはできない。
  - 正解：○（正しい）
  - 理由：最判昭50.4.8【百選Ⅲ39】の判示。養子縁組は799条・739条の届出で効力を生じる要式行為・強行法規であり、届出という方式は縁組意思の真意性・公示を担保する。方式を欠く出生届で代用を認めれば制度趣旨が骨抜きになるため、転換は否定される。
- **［○×クイズ 5/7］** 親子関係不存在確認の訴えが権利濫用に当たるかを判断するにあたり、請求者がその請求をするに至った動機・目的は考慮されない。
  - 正解：×（誤り）
  - 理由：判例（最判平18.7.7）は「請求がされるに至った経緯及び請求をする動機、目的」を明示的に考慮要素に挙げる。本問の「全財産をＢに相続させる」という動機は正当とはいえない目的と評価でき、権利濫用を基礎づける重要事実。
- **［○×クイズ 6/7］** 15歳未満の子について有効な代諾を欠いてされた養子縁組も、その子が15歳に達した後に自ら追認したときは、116条本文の類推適用により、縁組の時に遡って有効となる。
  - 正解：○（正しい）
  - 理由：15歳未満の子の縁組は法定代理人の代諾による（797条1項）。代諾権を欠く代諾は無権代理類似の構造なので、本人が縁組意思をもちうる15歳到達後に追認すれば116条本文の類推で遡及的に有効となる（最判昭27.10.3）。本人意思の尊重と縁組関係の維持（子の福祉）に資する。
- **［○×クイズ 7/7］** 116条ただし書・96条3項・94条2項はいずれも取引の安全（善意の第三者の保護）を目的とする規定であり、判例は事実関係を重視すべき身分関係にこれらを類推・適用することに消極的である。
  - 正解：○（正しい）
  - 理由：これらは取引の動的安全（善意者保護）のための規定。身分関係は取引の対象ではなく、誰との関係でも一律に定まるべきものだから、判例は取引安全の規定を身分行為に持ち込まない一貫した態度をとる。116条ただし書類推否定（最判昭39.9.8）はその一例。

（○×クイズはここまで＝全7問。最後の7問目まで出したら「○×クイズ、全7問クリア！」と言って復習へ）
