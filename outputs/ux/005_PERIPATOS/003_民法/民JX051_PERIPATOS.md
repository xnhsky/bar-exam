## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

Bは、Aとの間で甲建物を3000万円で建設する請負契約を締結し、完成した甲建物の所有権は注文者Bに帰属する旨の特約をした（Bは代金1000万円を支払済み・残2000万円は引渡しから2週間以内に支払う約定）。Aは、甲建物の建設を2700万円でCに一括して下請けさせた（AC間に所有権の特約はなく、AはCに代金の3分の1にあたる900万円のみを支払った）。Cは自ら木材等を調達して甲建物を完成させたが、Aが事実上倒産したため、下請代金の回収を確実にしようと甲建物をAに引き渡さず占有を続けた。BがCに甲建物の引渡しを請求したのに対し、Cは、Aから下請代金の支払を受けるまで引き渡さないとしてこれを拒んでいる（Bは下請契約の事実に気付いたが特段異を唱えていなかった）。BのCに対する甲建物引渡請求は認められるか。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 6/1 元請B–A（3000万・所有権はB特約・1000万支払）
- 6/10 下請A–C（2700万・特約なし・900万支払）／C着手・Bは下請を知るが異を唱えず
- 11月上旬 A手形不渡り＝事実上倒産
- 11/20 C甲建物を完成・回収まで占有継続
- 12/1 B引渡請求 → C拒絶（下請代金の支払まで）

### 参考（読み上げない。入口の問いの答えを含むので判定にだけ使う）

登場人物：
- B｜注文者（→所有権に基づき引渡請求）
- A｜元請負人・事実上倒産（→両契約の結節点）
- C｜下請負人・材料供給・占有中（→引渡拒絶）
- 甲建物｜請負の目的物＝所有権の帰属が争点

一行要約：Bが所有権に基づきCへ引渡請求、Cは留置権で拒む。甲は請負の目的物で所有権の帰属が前提。

### 入口の問い（3問）

- **Q01［事案の整理］** 請求・当事者・目的物を挙げて
  - 答え：Bの請求は所有権に基づく返還（引渡）請求。だから前提として「甲建物の所有権がBにあるか」を先に確定しないと請求原因が立たない。
  - 答え：Cは占有者。Cは留置権で拒む可能性がある。＝「所有権（前提）」と「留置権（抗弁）」の2段構えだと最初に見抜く。
- **Q02［見当づけ］** 各争点は「何が問題っぽい？」 ― 見当をつけて
  - 答え：甲建物は新築物＝請負目的物の原始的帰属（632条系）と元請特約が下請Cを拘束するか（最判平5.10.19系）。Cは占有＋下請代金債権 → 留置権（295条）系。
- **Q03［論点］** 問題になる論点を挙げて（3つ）
  - 答え：CP①：甲建物は新築物 → 請負目的物の原始的所有権の帰属。（請負人帰属説＋特約／代金大部分支払で注文者帰属を推認）→ AB＝B・AC＝原則C の分離）
  - 答え：CP②：AB特約はCを縛るか → 元請特約の第三者拘束。（下請負人＝履行補助者的立場・特段の事情なき限り拘束＝最判平5.10.19）
  - 答え：CP③：Cは占有＋下請代金債権 → 留置権の成否（他人の物・牽連性・弁済期）。

### 骨子（3項目。第1から【論点】ごとに、何が問題→規範→使う事実→結論 の順で組み立てる）

#### 第1　甲建物の所有権の帰属

- 見出しの補足（結論を含む。項目の終わりに読む）：Bの請求原因の前提
1. Bの請求＝所有権に基づく引渡請求 → 前提としてBの所有権取得を要する
2. 新築物 → 【論点】請負目的物の原始的所有権の帰属（規範：請負人帰属説＋特約・代金大部分で注文者帰属推認）
   - あてはめ：分離：AB＝特約でB／AC＝特約なし・代金1条・3のみで推認不可 → 原則C
3. Bの再反論 → 【論点】元請特約の下請負人への拘束（規範：下請負人＝履行補助者的立場・特段の事情なき限り拘束）
   - あてはめ：特段の事情：Bは下請を知ったが異を唱えず＝知情のみ → 否定
- 結論：甲建物の所有権は Bに帰属

#### 第2　Cの留置権

- 見出しの補足（結論を含む。項目の終わりに読む）：引渡拒絶の抗弁・295条
1. 他人の物 → 甲はB所有・債務者A以外でも 「他人の物」に当たる ＝充足
2. 【論点】牽連性（その物に関して生じた債権） → 物の返還義務と同一の法律関係から生じたこと
   - あてはめ：BA元請とAC下請は別個独立 → Bの引渡請求権とCのA下請代金債権は同一の法律関係から生じず → 否定
   - あてはめ：別ルート：残代金は引渡後2週間以内＝弁済期未到来（295条1項ただし書）＋占有補助者的立場
- 結論：留置権 不成立

#### 第3　結論

   所有権はBに帰属し留置権も不成立 → Bの引渡請求は認められる

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】『「所有権はBに帰属する特約」（AB間）』 → AB間の所有権帰属を決める
- 【拾う事実】「AC間に特約なし・900万（1/3）のみ支払」 → 代金大部分でない＝特約推認の否定
- 【拾う事実】「Cが自ら木材等を供給して建築」 → 請負人帰属（原則C）の裏づけ
- 【拾う事実】「Bは下請を知ったが異を唱えず」 → 特段の事情の評価素材（知情のみ）
- 【拾う事実】「残代金は引渡しから2週間以内」 → 弁済期未到来（留置権否定の別ルート）
- 【争いのない要件】論点にならず、あっさり認定する要件
  - Bの占有喪失・Cの占有＝争いなし／目的物＝甲建物で特定＝一言。争いのない要件は一言で通し、所有権の帰属（特約の第三者拘束）と留置権（牽連性・弁済期）に筆を集める。
- 【効く事実】「分離と特約拘束」のあてはめで使う事実
  - 特約推認の否定 → AC代金2700万のうち900万（1/3）のみ支払＝「大部分」といえない／請負人帰属の裏づけ → Cが自ら木材等を供給して建築／特段の事情の否定 → Bは下請を知ったが異を唱えず＝知情にとどまる。
- 【規範の要点】295条1項の規範
  - 「その物に関して生じた債権」（牽連性）とは、被担保債権が物自体から生じ、又は物の返還義務と同一の法律関係・事実関係から生じたことをいう → BA元請とAC下請は別個独立の契約 → Bの引渡請求権とCのA下請代金債権は同一の法律関係から生じず牽連性否定。
- 【まぎらわしい選択肢・論点】注文者帰属説の当否／加工による所有権帰属／同時履行の抗弁の可否
- 【まぎらわしい選択肢・結論】Bの引渡請求は認められない／留置権 成立
- 【まぎらわしい選択肢・規範】注文者帰属説／牽連性拡張説
- 【まぎらわしい選択肢・事実】代金全額支払済／AC間に所有権特約あり

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

所有権＝請負人帰属＋特約推認、AB＝B・AC＝原則C、平5.10.19で下請は履行補助者的立場、特段の事情なし（知情だけ）でBに帰属。留置権＝他人の物は債務者物に限らず充足、でもBA・ACは別契約で牽連性なし、留置権不成立。結論＝Bの引渡請求は認められる。

## 3. 規範クイズ（3問）

- **Q04［規範］** 請負の目的物の原始的所有権の帰属に関する規範（原則と特約による修正）を述べよ。
  - 模範解答：①特約がなければ、材料の全部又は主要部分を供給した者（原則は請負人）が完成物の所有権を原始取得する（請負人帰属説）。②特約があればそれに従い、注文者が代金の全部又は大部分を支払っている場合は注文者帰属の特約の存在が推認される。以上が帰属を決める規範で、「材料 → 特約 → 代金大部分」の3点が要件として効く。
- **Q05［規範］** 元請契約の所有権帰属特約が下請負人を拘束する根拠と限界を述べよ。
  - 模範解答：根拠＝一括下請契約は元請契約の存在・内容を前提とし元請負人の債務履行を目的とするから、下請負人は注文者との関係で元請負人の履行補助者的立場に立つにすぎず、異なる権利関係を主張し得ない。限界＝注文者と下請負人との間に格別の合意がある等特段の事情があれば拘束されない（最判平5.10.19）。相対効を原則として示してから例外へ進むのが順序。
- **Q06［規範］** 注文者が下請契約の存在を知っていた場合に、「特段の事情」を否定する論拠を述べよ（調査官解説の発想）。
  - 模範解答：請負契約では下請が介在するのが常態であり、一般に素人である注文者は元請負人のみを信用して契約し、下請契約の内容・下請代金の支払状況を知り得ず関心もないから、注文者にそこまで注意を払うことは期待できない。ゆえに下請を知っていたというだけでは、下請負人に所有権を帰属させる格別の合意（特段の事情）を認めることはできず、元請特約の拘束は否定されないという結論になる。

## 4. ○×クイズ（6問）

- **Q07［○×］** 所有権に基づく返還請求が認められるには、その前提として請求者が目的物の所有権を有していることが必要である。
  - 正解：○（正しい）
  - 理由：物権的返還請求権は所有権の効力として発生する。よって請求者が所有権を有することが請求原因の前提となり、所有権の帰属が定まらなければ相手方の占有権原（留置権等）の当否も判断できない。だから「所有権 → 占有権原」の順で検討する。
- **Q08［○×］** 請負契約において、完成した目的物（新築建物）の所有権が誰に原始的に帰属するかについては、民法に明文の規定がなく、解釈に委ねられている。
  - 正解：○（正しい）
  - 理由：請負（632条）は仕事の完成を目的とする契約だが、完成物の所有権の原始的帰属を定める明文はない。そこで判例は、材料の所有権が積み上がって完成物になるという物権法の発想から、材料の全部又は主要部分の供給者（原則は請負人）が原始取得すると解し、特約・代金支払状況で修正する。まず「明文なし＝解釈問題」と示すのが出発点。
- **Q09［○×］** 契約の効力は相対的であるから、元請契約における所有権帰属の特約が下請負人を拘束する余地は、およそ認められない。
  - 正解：×（誤り）
  - 理由：相対効が原則であることは正しいが、その例外として、下請負人は注文者との関係で元請負人の履行補助者的立場に立つにすぎず、元請負人と異なる権利関係を主張し得ない。よって特段の事情のない限り元請特約に拘束されるというのが判例（最判平5.10.19）の規範である。「およそ拘束されない」と言い切ると本問最大の得点源を落とす。
- **Q10［○×］** 注文者が下請契約の存在を知っていたという事実は、それだけで元請特約の拘束を否定する「特段の事情」に当たり、目的物の所有権は下請負人に帰属する。
  - 正解：×（誤り）
  - 理由：下請の介在は請負の常態で、素人である注文者に下請契約の内容・代金支払状況まで注意を払うことは期待できない。ゆえに注文者が下請を知っていたというだけでは特段の事情に当たらず、元請特約の拘束は否定されない。特段の事情には「注文者と下請負人との間の格別の合意」等が要る。「知っていた＝特段の事情」と即断すると結論を誤る。
- **Q11［○×］** 留置権（295条1項）の目的物である「他人の物」は、被担保債権の債務者が所有する物に限られる。
  - 正解：×（誤り）
  - 理由：留置権は物権であって第三者にも対抗できるから、「他人の物」は債務者の所有物に限られず、第三者の所有物でもよい（通説）。本問でも甲建物がB所有・債務者はAでも「他人の物」要件は充たす。ただし本問は牽連性を欠くため留置権は成立しない。「B所有だから留置権不成立」と即断するのは誤り。
- **Q12［○×］** 同時履行の抗弁権（533条）は双務契約の当事者間で認められる債権的な抗弁であり、契約当事者でない第三者に対しては主張できないのに対し、留置権は物権であり第三者にも対抗できる。
  - 正解：○（正しい）
  - 理由：同時履行の抗弁権は双務契約の効力として当事者間で機能する債権的抗弁で、契約外の第三者には主張できない。留置権は法定担保物権で第三者にも対抗できる。だから下請負人Cが第三者Bの引渡請求を拒む道具は留置権であり、AC契約に基づく同時履行の抗弁ではない。両者の性質の違いが対抗範囲を分ける。
