## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

Aは、妻とともに、子B（当時17歳）の法定代理人として、Cに対し、Bが祖父からの贈与により取得した甲土地を、時価の500万円で売却して引き渡し、所有権移転の登記をした。Aは、妻の了解の下に、その売却代金を、AのDに対する500万円の債務の弁済に充てた。Aは、Dに弁済する際、甲土地の売却代金により弁済することを秘していたが、Dは、そのことを知っていた。AがDに弁済した時、A夫婦は無資力であった。その後、Bは、成人した。1　A夫婦が売却代金をAのDに対する債務の弁済に充てるために甲土地を売却したものであり、Cは、甲土地を買い受ける際、そのことを知っていた場合において、(1) Bは、Cに対し、甲土地の返還を請求することができるか。(2) CがBに対して甲土地を返還したとき、Cは、Bに対し、500万円の支払を請求することができるか。2　A夫婦が売却代金をBの教育資金に用いるつもりで甲土地を売却したが、売却後に考えが変わり、売却代金をAのDに対する債務の弁済に充てた場合において、Bは、Dに対し、500万円の支払を請求することができるか。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- Bが祖父から甲土地を贈与で取得（B当時17歳＝未成年・A夫婦が法定代理人）
- AがBを代理しCへ甲土地を時価500万で売却・引渡し・移転登記
- Aが代金500万をDへの自己の債務の弁済に充当（弁済目的を秘すがD悪意）
- 弁済時、A夫婦は無資力
- その後Bは成人（各請求の主体となる）

### 入口の問い（3問）

- **［入口 1/3・事案の整理］** 財貨の動きと当事者を棚卸し ― 誰から誰へ・何が・どの原因で
  - 答え：元所有者はB（祖父からの贈与）。売却も弁済もしたのはA（B の法定代理人）で、A 自身は当事者にならず代理で動く。ここを取り違えると請求の主体・相手方が崩れる。
  - 答え：代金500万円は C→A→D と流れ、B の手には一度も入っていない。「誰が得て誰が失ったか」を追うのが不当利得の出発点。
- **［入口 2/3・見当づけ］** 各請求は「どの根拠か」 ― 見当をつけて
  - 答え：設問1(1)：B は元の土地を返せ＝所有権に基づく返還請求（前提＝契約の効果が B に帰属しないこと）。設問2：B・D 間に契約なし＋取り戻すのは金銭＝不当利得（703条）系。詐害行為取消し（424条の3）も候補に。
- **［入口 3/3・論点］** 問題になる論点を挙げて（3つ）

  - 答え：CP②：外形説で否定した動機の不当性をどこで拾うか → 107条の代理権濫用。親権者は広範な裁量＝特段の事情に限定。（子の利益を無視し自己の利益のみを図る等）

### 骨子（3項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　設問1(1)　Bの甲土地返還請求

- 見出しの補足（結論を含む。項目の終わりに読む）：B→C・所有権
1. 原則：法定代理（818条1項・824）→ Bに効果帰属（99条1項）
2. 【論点】利益相反行為（826条1項）の判断基準（規範：外形説）
   - あてはめ：売主B・買主C・A自ら買主でない → 該当せず（弁済流用は売却後の別行為）
3. 【論点】代理権の濫用（107）（規範：広範な裁量＝特段の事情に限定）
   - あてはめ：自己の債務弁済目的＝子の利益を無視した自己利益のみ → 特段の事情あり
4. C悪意（弁済目的を知っていた）→ 無権代理みなし（107）→ 効果不帰属
- 結論：Cは所有権を取得せず ＝ 甲土地返還請求 認められる

#### 第2　設問1(2)　Cの500万円返還請求

- 見出しの補足（結論を含む。項目の終わりに読む）：C→B・不当利得703
1. 【論点】Bに「利益（受益）」が帰属するか
   - あてはめ：前小問で効果不帰属 → Bとの関係で受領はなかったものとして扱う
2. Bに「利益」なし → 因果関係の検討に至らない
   （真の利得者はA・D＝CはA・Dへ請求すればよい）
- 結論：不当利得返還請求 認められない

#### 第3　設問2　BのDに対する500万円請求

- 見出しの補足（結論を含む。項目の終わりに読む）：B→D・不当利得703
1. 前提：教育資金目的＝有権代理（特段の事情なし・効果帰属）
2. 【論点】詐害行為取消し（424の3条1項2号） → 通謀害意を欠く → ×
3. 【論点】騙取金による弁済と不当利得（規範：因果＝社会通念の連結／原因＝受領者の悪意重過失）
   - あてはめ：因果あり（代金をそのままDへ）・D悪意 → 法律上の原因なし
- 結論：500万円の支払請求 認められる

- 【拾う事実】『Dは代金による弁済と「知っていた」・A夫婦は無資力』 → 法律上の原因・詐害行為の可否
- 【ポイント】二段で攻める
  - まず利益相反行為（826条1項）を外形説で検討→売主B・買主Cで A 自ら買主でない＝該当せず。切り捨てた動機の不当性は代理権濫用（107条）で受ける。826→107 の順が定石。
- 【効く事実】「代理権濫用の詰め」のあてはめで使う事実
  - 特段の事情 → 「AのDに対する債務の弁済に充てるために」売却＝子Bの利益を無視した自己利益のみの目的／相手方の主観 → C は弁済目的を「知っていた」＝悪意。事実は必ず評価語と結合させる（例：自己利益のみ＝法の趣旨に著しく反する特段の事情）。
- 【ポイント】一貫させる
  - 前小問（無権代理・効果不帰属）と矛盾した受益認定をしないのが最重要。受領がなかった＝B に「利益」なし＝C の請求は不成立。真に利得したのは A・D だから、C は A・D に請求すればよく、C が特に害されるわけでもない。
- 【まぎらわしい選択肢・論点】表見代理（110条）の成否／即時取得（192条）の成否
- 【まぎらわしい選択肢・結論】甲土地返還請求 認められない／不当利得返還請求 認められる
- 【まぎらわしい選択肢・規範】実質説／直接因果関係説
- 【まぎらわしい選択肢・事実】A・D間に通謀あり／Cは善意

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

1(1)＝原則効果帰属、利益相反は外形説で否定、107条の代理権濫用は特段の事情に限定、自己の債務弁済目的＝特段の事情あり、C悪意で無権代理、返還請求可。1(2)＝効果不帰属だから受領なし＝Bに利益なし、Cの不当利得請求は不可。設問2＝教育資金＝有権代理、詐害行為取消しは通謀を欠き×、不当利得は因果＝社会通念の連結・D悪意で法律上の原因なし、請求可。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 利益相反行為（826条1項）の判断基準＝外形説の内容と、その根拠を述べよ。
  - 模範解答：内容＝利益相反該当性は、親権者が子を代理してした行為自体・行為の外形から客観的に判断し、親権者の動機・意図は考慮しない。根拠＝取引の相手方は親権者の内心を知り得ず、取引の安全・相手方の予測可能性を確保する必要がある。動機の不当性は代理権濫用（107条）で捕捉するため子の保護に欠けない。
- **［規範クイズ 2/3］** 親権者の代理行為が代理権の濫用に当たるための「特段の事情」の規範を述べよ（最判平4.12.10）。
  - 模範解答：親権者が子を代理してする法律行為は、利益相反行為に当たらない限り、子のために親権を行使する親権者の広範な裁量にゆだねられている。したがって、その代理行為が、子の利益を無視して自己又は第三者の利益を図ることのみを目的としてされるなど、親権者に子を代理する権限を授与した法の趣旨に著しく反すると認められる特段の事情が存しない限り、代理権の濫用に当たらない。
- **［規範クイズ 3/3］** 既存債務への弁済（偏頗行為）を詐害行為として取り消すための特別の要件を述べよ（424条の31項）。
  - 模範解答：①その弁済が債務者の支払不能の時に行われたこと（1号）、かつ②その弁済が、債務者と受益者とが通謀して他の債権者を害する意図をもって行われたものであること（2号）。弁済は本来正当な債務消滅行為なので、通常の詐害行為より加重された要件で取消しを限定する。

## 4. ○×クイズ（全9問・1問目から最後まで全部出す）

- **［○×クイズ 1/9］** 金銭については、特段の事情がない限り、その所有権は占有の移転とともに移転し、占有者が所有者となる。
  - 正解：○（正しい）
  - 理由：金銭は高度の流通性を持つ特殊な動産で、所有権は占有とともに動く（占有＝所有）。だから代金が A を経て D に渡ると、物権的請求権では取り戻せず、不当利得という価値の巻き戻しで処理することになる。これが設問2で不当利得を選ぶ理論的な出発点。
- **［○×クイズ 2/9］** 所有権に基づく返還請求権を行使するには、相手方が目的物の占有を取得したことについて、相手方に故意又は過失があることを要する。
  - 正解：×（誤り）
  - 理由：物権的請求権は物権の円満な支配状態の回復を目的とする権利で、相手方の帰責事由（故意・過失）を要件としない。要件は①請求者の所有権と②相手方の占有だけ。損害賠償（709条）と違い過失は不要、という区別が問われやすい。
- **［○×クイズ 3/9］** 代理行為の効果が本人に帰属するか否か（有権代理か無権代理か）は、その後に本人・相手方間で生じる不当利得の「利益」の有無を判断するための前提問題となる。
  - 正解：○（正しい）
  - 理由：不当利得は当事者間の給付の巻き戻し。効果が本人に帰属しなければ本人は取引の当事者でなく、給付の受領も観念できないから「利益」は立たない。代理の有効性という前提が、後続の不当利得の成否を規定する。だから連動設問は前から順に、結論を一貫させて解く。
- **［○×クイズ 4/9］** 民法826条の利益相反行為に当たるか否かは、親権者が子を代理してした行為自体を外形的・客観的に考察して判定すべきであり、その行為をするに至った親権者の動機・意図を考慮して判定すべきではない。
  - 正解：○（正しい）
  - 理由：判例（最判昭42.4.18ほか）は外形説を採る。取引の相手方は親権者の内心を知り得ないから、取引安全・相手方の予測可能性を確保するため、行為の外形だけで画一的に判断する。動機の不当性は切り捨てられるが、それは代理権濫用（107条）で別途拾う。
- **［○×クイズ 5/9］** 親権者が子を代理してした法律行為が、客観的にみて子に不利益な結果をもたらすものであれば、そのことだけで直ちに代理権の濫用に当たり、その効果は子に帰属しない。
  - 正解：×（誤り）
  - 理由：親権者の代理権は子をめぐる諸般の事情を考慮する広範な裁量にゆだねられている。単に子に不利益というだけでは足りず、「子の利益を無視して自己・第三者の利益を図ることのみを目的とする」など、法の趣旨に著しく反する特段の事情があって初めて濫用となる。濫用を無限定に肯定すると子の財産管理機能を害する。
- **［○×クイズ 6/9］** 無権代理として売買契約の効果が本人に帰属しない場合、本人との関係では代理人による代金の受領はなかったものとして扱われ、本人に不当利得法上の「利益」は認められない。
  - 正解：○（正しい）
  - 理由：不当利得は当事者間の給付の巻き戻し。効果が本人に帰属しなければ本人は取引の当事者でなく、その関係で給付の受領を観念できないから「利益」は立たない。効果不帰属を認めた以上、受益もないと一貫させる。効果帰属を肯定する立場なら逆に受益が立ち、現存利益（703条）の有無が次の問題になる。
- **［○×クイズ 7/9］** 不当利得の要件である「利益」は、受益者が現実に金銭その他の財産を受領したという事実さえあれば、その受領の基礎となった契約の効果が受益者に帰属するか否かにかかわらず認められる。
  - 正解：×（誤り）
  - 理由：「利益」は当事者間の給付関係を前提に判断する。契約の効果が本人に帰属しない（無権代理）なら、本人は給付の当事者でなく、代理人が事実上金銭を握っていても本人に受益は立たない。受領の「事実」だけで機械的に受益を認めると、前小問の効果不帰属と矛盾する。
- **［○×クイズ 8/9］** 他人に帰属すべき金銭による弁済につき、受領者が悪意又は重大な過失で金銭を受領した場合には、その金銭の取得は被害者との関係で法律上の原因を欠き、不当利得となる。
  - 正解：○（正しい）
  - 理由：騙取金弁済の判例（最判昭49.9.26）は、金銭が動産の即時取得（192条）以上に流通を保護されるべきことを前提に、受領者が善意かつ無重過失なら保護し、悪意・重過失のときのみ法律上の原因を欠くとした。悪意者を保護する立場はどこにもない。本問のDは悪意だから、判例の射程の議論を問わず法律上の原因を欠く。
- **［○×クイズ 9/9］** 不当利得における損失と利益の因果関係が認められるためには、損失者から受益者への直接の財貨の移転が必要であり、その間に中間者が介在して金銭が流れた場合には因果関係は認められない。
  - 正解：×（誤り）
  - 理由：判例・通説は社会通念上、ある人の金銭で他人の利益を図ったと認められるだけの連結があれば因果関係を認める（直接の財貨移転は不要）。金銭の混和・両替や中間者の介在があっても因果関係は切れない。直接因果関係説では中間者介在で救済できず妥当でない。
