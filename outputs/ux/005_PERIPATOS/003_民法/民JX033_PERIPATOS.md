## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

家具商を営む甲は、乙とタンス一さお（以下「本件タンス」という。）を乙に売る契約を締結した。甲乙間の契約では、代金の支払は、本件タンスの引渡しと同時履行となっていた。甲が履行期に乙方に届けたところ、置き場所が片付いていないことを理由として、乙から受け取ることを拒まれた。そこで、甲は、運送業者丙に運送賃を支払ってその運送を依頼し、これを持ち帰って甲の店舗に保管していたところ、地震により右店舗が倒壊したため、本件タンスがき滅した。甲・乙間の法律関係について、本件タンスが特定物の場合と不特定物の場合に分けて、論じなさい。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 甲乙、本件タンス売買契約（代金と引渡しは同時履行）
- 甲、履行期に乙方へ届ける＝現実の提供
- 乙「置き場所が片付いていない」と受領拒絶＝受領遅滞
- 甲、丙に運送賃を払い持ち帰り、自己の店舗に保管
- 地震で店舗倒壊→本件タンスき滅（双方無過失）

### 参考（読み上げない。入口の問いの答えを含むので判定にだけ使う）

登場人物：
- 甲｜家具商・売主（→提供したが受領拒絶され持ち帰る）
- 乙｜買主（→受領拒絶＝受領遅滞・代金を拒みたい）
- 丙｜運送業者・運送賃を受領＝直接の当事者外
- 本件タンス｜目的物・地震で滅失

一行要約：甲が本件タンスを提供→乙が受領拒絶（受領遅滞）→甲が運送賃を払い持ち帰り保管中、地震で滅失。

### 骨子（3項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　特定物の場合 ― 甲の乙に対する請求

1. 甲→乙 代金支払請求（555条）／乙の抗弁：双方無過失滅失で危険負担（536条1項）で拒む
2. 【論点】受領遅滞後の危険の移転（規範：567条2項→1項後段）
   - あてはめ：現実の提供＋受領拒絶＋提供後の双方無過失滅失 → 危険は乙に移転 → 乙は代金を拒めない
3. 甲→乙 運送賃＝受領遅滞の増加費用（413条2項） → 乙負担
4. 乙→甲 引渡し → 履行不能（412条の2）・追完/解除も封じる（567②→1項前段）
- 結論：甲の代金・運送賃請求 認容／乙の請求 否定 ＝ 甲勝ち

#### 第2　不特定物の場合 ― 特定を上乗せ

1. 567条2項は特定したものに限る（1項かっこ書）→ まず特定を検討
2. 【論点】種類債権の特定（「必要な行為の完了」の意義）（規範：401条2項・大判大8.12.15）
   - あてはめ：別段の意思表示なし＝持参債務（484条1項）、持参債務では現実の提供で特定
3. 甲が乙方へ届け受領を求めた＝現実の提供 → 特定成立
- 結論：以後は特定物と同様 → 第1と同じ（甲勝ち）

#### 第3　結論

   特定物・不特定物いずれでも 甲は代金・運送賃を請求でき、乙は何も請求できない

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「履行期に乙方に届けた」 → 現実の提供(493条本文)の認定材料
- 【拾う事実】『「置き場所が片付いていない」ことを理由に受取拒否』 → 正当な理由のない受領拒絶＝受領遅滞
- 【拾う事実】『「地震により」店舗倒壊』 → 双方無過失（不可抗力）による滅失
- 【拾う事実】『運送賃を支払って持ち帰り』 → 受領遅滞による増加費用(413②)
- 【拾う事実】「特定物の場合と不特定物の場合に分けて」 → 場合分けの指定＝特定(401②)の要否
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 契約成立・同時履行・現実の提供（493条）・受領拒絶・「地震により」＝双方無過失 はほぼ争いなしで一言。引っかかるのは「受領遅滞で危険が移るか」（567条2項）と「不特定物で特定したか」（401条2項）の2点だけ。
- 【効く事実】「危険の移転（567条2項）」のあてはめで使う事実
  - 現実の提供 → 「甲が履行期に乙方に届けた」／受領拒絶（受領遅滞）→ 「置き場所が片付いていない」ことを理由に受取拒否（正当な理由なし）／双方無過失 → 「地震により」（不可抗力・甲の保管に落ち度なし）。事実は必ず要件と結合させる。
- 【規範の要点】「種類債権の特定（401条2項）」の規範
  - 種類債権は、債務者が給付に必要な行為を完了したときに特定する（401条2項）。「必要な行為の完了」は履行態様で異なり、持参債務では現実の提供（大判大正8年12月15日）。別段の意思表示がなければ債権者の住所地で履行＝持参債務（484条1項）。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 不特定物では特定と提供が同時に生じ「特定した目的物を提供」の枠に乗りにくい疑義がある → 特定物性を要件としない別解（413条の2第2項で受領遅滞中の不能を債権者帰責に擬制し536条2項へ）で同じ結論に。運送賃＝受領遅滞の増加費用（413②）、引渡し＝履行不能（412の2）で各一言。
- 【まぎらわしい選択肢・論点】同時履行の抗弁権の存否／危険負担の債権者主義の可否
- 【まぎらわしい選択肢・結論】乙の代金債務は消滅する／甲の請求はいずれも認められない
- 【まぎらわしい選択肢・規範】旧534条（契約時に危険移転）／536条2項
- 【まぎらわしい選択肢・事実】契約成立時に危険移転／口頭の提供で足りる

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

代金＝乙は536①で拒めそうだが、受領遅滞ゆえ567②で危険移転→拒めない。運送賃＝413②で乙負担。引渡し＝412の2で不能・567②で解除等も封じる。不特定物＝484①で持参債務、現実の提供で401②特定→以後特定物と同様。結論＝いずれも甲勝ち。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 双方無過失で目的物が滅失しても買主が代金支払を拒めなくなるのはどのような場合か。根拠条文と要件を挙げよ（売買の危険移転の特則）。
  - 模範解答：567条2項（→1項後段）。①売主が契約に適合する目的物で引渡債務の履行を提供 ②買主が受領を拒み又は受けられない ③その提供時以後に当事者双方の責めに帰することができない事由で滅失。受領遅滞により危険が買主へ移転するから、買主は代金支払を拒めない。
- **［規範クイズ 2/3］** 危険負担の原則を定める536条1項の内容（帰責事由と反対給付の扱い）を述べよ。
  - 模範解答：当事者双方の責めに帰することができない事由により債務の履行が不能となったときは、債権者は反対給付の履行を拒むことができる（債務者主義・履行拒絶権構成）。反対給付債務は当然には消滅せず、解消するには解除を要する（542条）。
- **［規範クイズ 3/3］** 種類債権の特定（401条2項）における「必要な行為の完了」の意義を、持参債務・取立債務で分けて述べよ。
  - 模範解答：持参債務＝目的物を債権者の住所に持参して受領を求めること、すなわち現実の提供（大判大正8年12月15日）／取立債務＝目的物の分離・準備＋受領の通知（口頭の提供に相当）。特定の効果として調達義務から解放され、以後は善管注意義務（400条）を負う。

（規範クイズはここまで＝全3問。最後の3問目まで出したら「規範クイズ、全3問クリア！」と言って次へ）

## 4. ○×クイズ（全12問・1問目から最後まで全部出す）

- **［○×クイズ 1/12］** 双務契約において、一方の債務が当事者双方の責めに帰することができない事由により履行不能となっても、他方の債務（反対給付）は当然には消滅せず、相手方はその履行を拒むことができるにとどまる。
  - 正解：○（正しい）
  - 理由：現行536条1項は履行拒絶権構成をとり、反対給付債務は当然消滅せず債権者は履行を拒めるにとどまる（契約の解消は解除による）。旧536条1項の「反対給付債務が消滅する」構成は改正で改められた。「消滅」と書くと現行法上は不正確。
- **［○×クイズ 2/12］** 売主が契約の内容に適合する目的物をもって引渡債務の履行を提供したにもかかわらず買主が受領を拒み、その提供の時以後に当事者双方の責めに帰することができない事由により目的物が滅失したときは、買主は、その滅失を理由として代金の支払を拒むことができない。
  - 正解：○（正しい）
  - 理由：567条2項（→同条1項後段）。受領遅滞により危険が買主に移転するため、買主は代金支払を拒めない。売買の危険負担の特則で、原則（536条1項の債務者主義）を破る条文。
- **［○×クイズ 3/12］** 種類債権について、危険移転を定める567条2項を適用するには、その目的物が特定したものであることを要する。
  - 正解：○（正しい）
  - 理由：567条の「目的物」は特定したものに限る（同条1項かっこ書）。ゆえに不特定物では、567条2項を使う前に401条2項による特定の有無を先に検討しなければならない。これが不特定物パート唯一の追加論点。
- **［○×クイズ 4/12］** 特定物の売買において、目的物が受領遅滞の後に当事者双方の責めに帰することができない事由により滅失した場合でも、買主は、その滅失を理由として代金の支払を全額拒むことができる。
  - 正解：×（誤り）
  - 理由：受領遅滞後の双方無過失滅失では、567条2項により危険が買主へ移転し、買主は代金支払を拒めない。原則（536条1項の債務者主義）で拒めるのは受領遅滞がない場合であって、本問類型では特則が原則を破る。
- **［○×クイズ 5/12］** 令和2年4月施行の現行民法では、特定物の売買において、目的物の滅失についての危険は、原則として売買契約の成立の時に買主へ移転する（債権者主義）。
  - 正解：×（誤り）
  - 理由：契約成立時に危険が買主へ移る「債権者主義」は旧534条1項で、引渡し前の買主に酷であるとして改正で廃止された。現行567条1項は危険移転の基準を目的物の引渡し時とし、受領遅滞があれば提供時（2項）に前倒しする。
- **［○×クイズ 6/12］** 567条2項により危険が買主に移転した場合、買主が拒めなくなるのは代金の支払だけであり、履行の追完請求・代金減額請求・損害賠償請求・契約の解除は、なお買主のためにこれを行使することができる。
  - 正解：×（誤り）
  - 理由：567条2項は「前項と同様とする」とし1項を全面的に準用する。したがって代金拒絶が封じられる（1項後段）だけでなく、追完請求・代金減額請求・損害賠償請求・契約解除も封じられる（1項前段）。効果が代金債務だけに及ぶと考えるのは誤り。
- **［○×クイズ 7/12］** 地震のような不可抗力によって目的物が滅失した場合は、当事者双方の責めに帰することができない事由による滅失に当たる。
  - 正解：○（正しい）
  - 理由：不可抗力（天災）による滅失は、通常、当事者いずれの帰責事由にもよらない。もっとも、目的物を保管する債務者に善良な管理者の注意義務（400条）違反があれば債務者の帰責事由となりうる。本問は保管に落ち度をうかがわせる事情がなく、双方無過失と評価できる。
- **［○×クイズ 8/12］** 危険負担の債務者主義（536条1項）の下では、当事者双方の責めに帰することができない事由により目的物が滅失すると、買主の代金債務は当然に消滅する。
  - 正解：×（誤り）
  - 理由：現行536条1項は履行拒絶権構成をとり、反対給付たる代金債務は当然には消滅せず、買主は履行を拒めるにとどまる。「当然消滅」は旧536条1項（消滅構成）の理解で、改正で改められた。
- **［○×クイズ 9/12］** 弁済をすべき場所について別段の意思表示がないとき、特定物の引渡し以外の弁済は、債権者の現在の住所においてしなければならない（持参債務の原則）。
  - 正解：○（正しい）
  - 理由：484条1項。特定物の引渡しは債権発生時の所在地、それ以外は債権者の現在の住所で弁済する＝種類物の引渡しは原則持参債務。本問は特約がなく、甲が乙方へ届けた事実とも整合するから持参債務と解する。
- **［○×クイズ 10/12］** 種類債権は、債務者が目的物を同種の物から分離して給付の準備を整えれば、債権者に対する提供がなくても、常にその時点で特定する。
  - 正解：×（誤り）
  - 理由：持参債務では、目的物を債権者の住所へ持参して受領を求める現実の提供が「必要な行為の完了」であり（大判大正8年12月15日）、単なる分離・準備では特定しない。特定に必要な行為は履行態様（持参／取立）で異なる。
- **［○×クイズ 11/12］** 債権者が債務の履行を受けることを拒み、又は受けることができないことによって、その履行の費用が増加したときは、その増加額は債権者の負担となる。
  - 正解：○（正しい）
  - 理由：413条2項（受領遅滞の効果）。弁済費用は原則債務者負担（485条本文）だが、受領遅滞による増加分は債権者負担。本問の運送賃は乙の受領拒絶で生じた増加費用だから、甲は乙に請求できる。
- **［○×クイズ 12/12］** 契約に基づく債務について、その履行が契約その他の債務の発生原因及び取引上の社会通念に照らして不能であるときは、債権者はその債務の履行を請求することができない。
  - 正解：○（正しい）
  - 理由：412条の2第1項（履行不能）。本件タンスは滅失して引渡しは不能だから、乙は甲に引渡しを請求できない。加えて567条2項で危険が移転している以上、代替物引渡し・解除・損害賠償も封じられる（1項前段）。
