### 骨子（3項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　小問(1)　相続欠格

- 見出しの補足（結論を含む。項目の終わりに読む）：891条5号
1. Cは本件遺言書を押入れに隠匿 → 形式的に「遺言書を…隠匿」（891条5号）該当
2. もっとも隠匿の故意で足りるか → 【論点】5号の主観的要件（二重の故意）（規範：不当利益目的必要説）
   - あてはめ：趣旨＝著しく不当な干渉行為への民事上の制裁 → 制裁重大ゆえ限定
3. あてはめ：「Dがかわいそう」＝不当利益目的なし → 5号非該当（欠格否定・C/D各1条・2条・900条4号）
- 結論：Dの全部取得の主張 ＝ 認められない

#### 第2　小問(2)　預貯金債権の帰属

- 見出しの補足（結論を含む。項目の終わりに読む）：898条・264ただし書・427条・909の2条
1. 普通預金1000万は896条本文で遺産 → 898条で遺産共有
2. 【論点】898条の共有は249条以下の共有か（規範：同義（昭30.5.31））→ 債権は準共有（264本文）→ 264ただし書で427条
3. 原則＝可分債権は当然分割 → もっとも 【論点】普通預金は可分債権か
   - あてはめ：継続的取引で1個の債権として同一性・残高変動＋実質的公平 → 可分債権に当たらず（最大決平28.12.19）
4. 帰結：遺産分割を経ない払戻し不可（ただし909条の2の限度で単独行使可）
- 結論：E銀行の主張 ＝ 正当（909の2の限度で払戻し義務）

#### 第3　小問(3)　遺産分割協議の解除

- 見出しの補足（結論を含む。項目の終わりに読む）：541条・909本文
1. Cの主張＝Dの同居・扶養義務不履行を理由に541条で法定解除
2. 【論点】協議に541条（法定解除）が及ぶか（規範：法定解除否定説）
   - あてはめ：分割は協議成立で終了・債権債務関係が残るのみ／909本文の遡及効で再分割＝法的安定性侵害
3. 対比：【論点】合意解除の可否 → 新たな合意で可（平2.9.27）
- 結論：前段＝Cは単独で法定解除できない／後段＝CD全員合意なら合意解除可

- 【拾う事実】「自分ばかりが得をしてしまい、Dがかわいそうだ」 → Cの隠匿の動機（不当利益目的の有無を分ける）

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 遺言書の破棄・隠匿型の相続欠格（891条5号）につき、判例が要求する主観的要件を、その理由（趣旨）とともに述べよ。
  - 模範解答：隠匿等の故意に加え「相続に関して不当な利益を得る目的」を要する（二重の故意必要説）。理由＝5号の趣旨は遺言に関し著しく不当な干渉行為をした者への民事上の制裁であり、相続資格の剥奪は重大なので趣旨に沿う範囲に限定すべきだから（最判平9.1.28）。
- **［規範クイズ 2/3］** 普通預金債権が相続開始と同時に当然分割されず遺産分割の対象となる理由を2点挙げよ。
  - 模範解答：①遺産分割における共同相続人間の実質的公平を確保するため、調整に資する財産を分割対象とする要請がある。②普通預金契約は継続的取引契約で、入金の都度既存残高と合算されて1個の預金債権として扱われ、同一性を保ちつつ残高が変動する＝性質上可分な債権に当たらない（最大決平28.12.19）。
- **［規範クイズ 3/3］** 遺産分割協議の法定解除が否定される理由を2点、その根拠条文とともに述べよ。
  - 模範解答：①遺産分割はその性質上協議の成立とともに終了し、後は債務を負担した相続人と債権を取得した相続人との債権債務関係が残るだけ。②解除を認めれば909条本文の遡及効を有する遺産の再分割を余儀なくされ、法的安定性が著しく害される。ゆえに541条による法定解除はできない（最判平元.2.9）。

## 4. ○×クイズ（全7問・1問目から最後まで全部出す）

- **［○×クイズ 1/7］** 相続欠格（891条）は、被相続人の意思表示や家庭裁判所の審判を要することなく、法律上当然に相続資格を失わせる制度である。
  - 正解：○（正しい）
  - 理由：相続欠格は891条各号の非行があれば当然に失権する（形成手続不要）。被相続人の意思＋家裁の審判を要する廃除（892条以下）と対をなす。両者の区別は棚卸し段階で確定しておくと、以後の検討がぶれない。
- **［○×クイズ 2/7］** 相続欠格事由のうち遺言書の破棄・隠匿（891条5号）は、隠匿等の事実と故意があれば足り、それ以上の主観的要件は不要である（判例）。
  - 正解：×（誤り）
  - 理由：判例（最判平9.1.28）は、5号の趣旨（遺言に関し著しく不当な干渉行為への民事上の制裁）から、隠匿等の故意に加えて「相続に関して不当な利益を得る目的」を要するとする（二重の故意必要説）。目的のない隠匿は制裁に値しないという価値判断が核心。
- **［○×クイズ 3/7］** 共同相続された普通預金債権は、相続開始と同時に当然に相続分に応じて分割されることはなく、遺産分割の対象となる（判例）。
  - 正解：○（正しい）
  - 理由：最大決平28.12.19は、普通預金・通常貯金・定期貯金債権につき、当然分割を否定し遺産分割の対象とした。可分債権当然分割の一般法理は維持しつつ、預貯金を「性質上可分な債権」から外した点が要（旧判例=最判平16.4.20を変更）。本問の山場=小問(2)の結論部分。
- **［○×クイズ 4/7］** 相続財産中に金銭債権その他の可分債権があるときは、その債権は相続開始と同時に当然に相続分に応じて分割されるのが原則である（判例）。
  - 正解：○（正しい）
  - 理由：可分債権当然分割の原則（大判大9.12.22・最判昭29.4.8等）。この一般法理自体は現在も維持されている。最大決平28.12.19が変えたのは「預貯金債権は性質上可分な債権に当たらない」という一点だけ。「判例変更で当然分割が消えた」と書くと誤り。
