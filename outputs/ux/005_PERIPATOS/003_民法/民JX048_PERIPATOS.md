### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「事業は基本的に変わっておらず、従業員等にも変更はない」 → 使用主体の実質的同一性（背信性の否定）
- 【拾う事実】『甲の引渡しを受けている／所有権移転登記を経た』 → 借家31の対抗力・605の2Ⅲの対抗要件
- 【拾う事実】『「Xの承諾を得た上で」賃借権を譲渡』 → 「適法に賃借権を譲り渡した」（622の2Ⅰ②）
- 【拾う事実】『敷金の担保・引継ぎをめぐるXの主張』 → 承継の可否＝特段の事情の有無
- 【拾う事実】「充当されるべき債務は一切ない」 → 控除額ゼロ＝返還は満額50万円
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 小問2の明渡＝Yが引渡しを受け対抗力あり（借家31）で即断／賃料＝地位移転（605の2Ⅰ）＋登記（Ⅲ）／敷金＝承継（Ⅳ）。解釈が残るのは小問1の「解除できるか」と小問3の「承継されるか」だけ。
- 【効く事実】「敷金の帰趨」のあてはめで使う事実
  - 背信性否定 → 「事業は基本的に変わっておらず、従業員等にも変更はない」を直接引用。敷金承継 → 賃貸人交替（605の2Ⅳ）は承継／賃借人交替（622の2Ⅰ②）は原則不承継。返還額 → 「充当されるべき債務は一切ない」＝満額50万円。
- 【規範の要点】「法人成りの背信性」の規範
  - 無断転貸でも、背信的行為と認めるに足りない特段の事情があれば612条2項の解除権は発生しない。法人成りで使用主体が実質的に同一・使用形態に変更がなければ背信性は否定される（最判昭39.11.19＝本問と同型）→ Xは解除できない。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 同じ「敷金の承継」でも、賃貸人が代われば承継（605の2Ⅳ）／賃借人が代われば原則不承継（622の2Ⅰ②）。差は敷金が旧賃借人の債務を担保する目的で差し入れられたという一点から統一的に説明できる。この対比を書けると理解の深さが伝わる。
- 【まぎらわしい選択肢・論点】用法遵守義務違反による解除の可否／造作買取請求権の行使
- 【まぎらわしい選択肢・結論】Xは賃貸借契約を解除できる／YはZに敷金の返還を求めえない
- 【まぎらわしい選択肢・規範】同時履行の抗弁／背信性が認められる
- 【まぎらわしい選択肢・事実】賃料の不払い／Xの承諾なし

## 3. 規範クイズ（3問）

- **Q05［規範］** 無断転貸・無断譲渡があっても賃貸人が解除できない場合の規範（信頼関係破壊の法理）を述べよ。
  - 模範解答：賃借人の行為が賃貸人に対する背信的行為と認めるに足りない特段の事情があるときは、612条2項の解除権は発生しない（最判昭28.9.25）。背信性は使用主体の同一性・使用目的や使用形態の変更の有無等を総合考慮して判断する。
- **Q06［規範］** 不動産が譲渡された場合に賃貸人たる地位が譲受人に移転する要件と、これを賃借人に対抗する要件を述べよ。
  - 模範解答：賃借人が賃貸借の対抗要件を備えた不動産が譲渡されると、賃貸人たる地位は賃借人の承諾なく譲受人に当然移転する（605条の2第1項）。ただし移転を賃借人に対抗するには、その不動産の所有権移転登記を要する（同第3項）。地位移転に伴い敷金返還債務も譲受人が承継する（同第4項）。
- **Q07［規範］** 賃借人が適法に賃借権を譲渡した場合における、敷金関係の承継の原則と例外を述べよ。
  - 模範解答：原則：敷金関係は新賃借人に承継されず、賃貸人は旧賃借人に返還する（622条の2第1項2号）。例外：敷金交付者が賃貸人との間で敷金をもって新賃借人の債務不履行の担保とすることを約し、又は新賃借人に敷金返還請求権を譲渡するなど特段の事情があれば承継される（最判昭53.12.22）。

## 4. ○×クイズ（9問）

- **Q08［○×］** 賃借人は、賃貸借の終了前であっても、賃貸人に対し、差し入れた敷金をその未払賃料の弁済に充てるよう請求することができる。
  - 正解：×（誤り）
  - 理由：敷金の充当は賃貸人の権利であり、賃借人の側から充当を請求することはできない（622条の2第2項後段）。敷金返還請求権が現実化するのは、原則として賃貸借が終了し目的物を返還した時（同条1項1号）である。
- **Q09［○×］** 賃借人が賃貸人の承諾を得ずに賃借物を第三者に使用・収益させたとき、賃貸人は契約を解除することができるのが条文上の原則である（612条）。
  - 正解：○（正しい）
  - 理由：612条1項が無断譲渡・無断転貸を禁じ、同条2項が違反時の解除権を定める。まず「原則として解除可」を条文で示すのが出発点。もっとも、この解除権は信頼関係破壊の法理で制限されうる（次のドリル）。
- **Q10［○×］** 無断転貸があった以上、賃借人の行為が賃貸人に対する背信的行為に当たるかを問わず、賃貸人は常に612条2項により契約を解除することができる。
  - 正解：×（誤り）
  - 理由：賃貸借は当事者の信頼関係を基礎とする継続的契約であり、612条の趣旨は賃貸人の信頼保護にある。そこで背信的行為と認めるに足りない特段の事情があれば解除権は発生しない（信頼関係破壊の法理・最判昭28.9.25）。「常に解除できる」は誤り。
- **Q11［○×］** 賃貸不動産が譲渡され賃貸人たる地位が譲受人に移転した場合、譲受人が賃借人に賃料を請求するには、その不動産について所有権移転登記を備えることを要する（605条の2第3項）。
  - 正解：○（正しい）
  - 理由：地位の移転自体は当然に生じる（605条の2第1項）が、これを賃借人に対抗するには所有権移転登記が必要（同第3項）。賃借人が旧賃貸人・新賃貸人から二重に請求される危険を防ぐ趣旨。移転（Ⅰ）と対抗（Ⅲ）は別要件で、両方を落とさない。
- **Q12［○×］** 建物の賃貸借は、その登記がなくても、建物の引渡しがあれば、その後その建物について物権を取得した者に対して対抗することができる（借地借家法31条）。
  - 正解：○（正しい）
  - 理由：賃借権登記は賃貸人の協力を要し実際上得にくいため、現実の占有（建物の引渡し）に対抗力を認め借家人を保護する。引渡しを受けた賃借人は、新所有者からの明渡請求を拒める。この対抗要件具備は、605条の2第1項の地位当然移転の前提でもある。
- **Q13［○×］** 賃貸人たる地位が譲受人に移転したときは、敷金の返還に係る債務は譲受人が承継し、承継される額は旧賃貸人に対して生じた未払債務を控除した残額である（605条の2第4項）。
  - 正解：○（正しい）
  - 理由：賃貸人が交替しても賃借人（敷金差入人）は同一で担保の必要が続くから、敷金関係は当然に新賃貸人へ承継される（最判昭44.7.17を明文化）。控除後の残額が承継されるので、未払債務がなければ満額が承継される。
- **Q14［○×］** 賃借人が賃貸人の承諾を得て賃借権を第三者に譲渡した場合、旧賃借人が差し入れた敷金に関する権利義務関係は、特段の事情がなくても当然に新賃借人へ承継される。
  - 正解：×（誤り）
  - 理由：敷金は旧賃借人が自己の債務を担保するために差し入れたものだから、賃借人交替時は原則として新賃借人に承継されない（最判昭53.12.22・622条の2第1項2号）。承継されるのは、敷金で新賃借人の債務を担保する旨の合意や敷金返還請求権の譲渡など特段の事情がある場合に限る。
- **Q15［○×］** 賃借人が個人で営む事業を会社組織に改め、その会社に賃借物を使用させた場合でも、使用の主体が実質的に同一で使用形態にも変更がないときは、背信的行為と認めるに足りない特段の事情があるとして、賃貸人は無断転貸を理由とする解除をすることができない。
  - 正解：○（正しい）
  - 理由：いわゆる法人成りの事案で、形式的には賃借人（個人）と会社（法人）が別人格でも、使用主体の実質的同一性・使用形態の不変更があれば背信性は否定される（最判昭39.11.19）。零細事業の法人化が一般的な経済実態であることを踏まえた帰結。
- **Q16［○×］** 敷金に関する権利義務関係は、賃貸人が交替した場合には新賃貸人に承継されるが、賃借人が交替した場合には特段の事情のない限り新賃借人に承継されない。
  - 正解：○（正しい）
  - 理由：賃貸人交替（605条の2第4項・最判昭44.7.17）は当然承継、賃借人交替（622条の2第1項2号・最判昭53.12.22）は原則不承継。方向が逆になる根拠は、敷金が旧賃借人自身の債務を担保する目的のものである点にある。
