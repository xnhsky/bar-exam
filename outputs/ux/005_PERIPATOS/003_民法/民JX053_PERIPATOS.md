## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

Xは、Yに国際見本市の会場の一つとなる乙建物の建築を注文した。Zは、見本市の期間中、乙建物を出展用に使用するため、Xと賃貸借契約を締結した。この契約には、乙建物を使用させられないときはXがZに1000万円を支払う旨の損害賠償額の予定条項が含まれていた。ところが、乙建物は、完成後引渡前に地震により全壊して使用不能となり、見本市の期間中には再築も間に合わなくなった。Xは、Zに予定どおり乙建物を使用させていれば、2000万円の収益を得られるはずであった。右の事例において、(1)地震の震度が極めて大きく、Yが耐震基準に適合した設計・施工をしていたにもかかわらず、乙建物が全壊した場合と、(2)地震の震度は、標準的な建物であれば十分耐え得る程度のもので、Yの施工上の手抜き工事が原因で乙建物が全壊した場合とに分けて、XY間及びXZ間の法律関係について論ぜよ（なお、XY間の請負契約には民法の規定と異なる特約はなかったものとする。）。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- XY請負契約締結（乙建物の建築を注文）
- XZ賃貸借締結（乙完成前・予定条項1000万）
- 乙完成 → 引渡前に地震で全壊・使用不能
- 見本市期間中の再築も不能（履行不能が確定）
- (1)Y無帰責／(2)Y手抜き＝有帰責に分岐
- Xは予定どおり使用させれば2000万の収益

### 骨子（3項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　XY間（請負）の法律関係

1. 乙は完成後引渡前に全壊＋再築不能 → 【論点】引渡債務の履行不能（規範：社会通念上の不能・412条の2）→ 履行不能
2. 536条＝危険負担（双方無帰責）でXは報酬拒絶／542条1項1号・543条＝解除（帰責事由不要）→ 報酬債務を消せる（(1)(2)共通）
3. 【論点】損害賠償の可否と帰責事由 → 規範：415条1項ただし書（契約・社会通念に照らした帰責事由）
   - あてはめ：(1)耐震適合＋極大地震＝責めに帰し得ない事由→賠償義務なし／(2)手抜き工事＝帰責→賠償義務あり
- 結論：(1)は報酬拒絶・解除のみで賠償なし／(2)は解除＋Yに損害賠償

#### 第2　XZ間（賃貸借）の法律関係

1. 乙全部滅失 → 賃貸借は当然終了（616条の2） → 残る火種＝予定条項1000万
2. 【論点】損害賠償額の予定と帰責事由の要否 → 規範：立証軽減が主眼で免責を否定する趣旨でない（420条1項） → Xの帰責事由で決まる
3. 【論点】履行補助者Yの過失＝Xの帰責事由か → 規範：免責可否は個別契約の解釈／賃貸借は乙完成前締結でYの建築は履行過程
   - あてはめ：716条の独立性は反対事情として受け止め乗り越える
- 結論：(1)Xも無帰責で予定額請求不可／(2)Xに帰責事由あり・Zは1000万請求可

#### 第3　(2)の損害賠償の範囲

- 見出しの補足（結論を含む。項目の終わりに読む）：416条
1. 【論点】通常損害と特別損害の仕分け → 規範：通常損害は当然・特別損害は債務者が予見すべきとき（416）
2. 乙の時価相当額＝通常損害／1000万・2000万＝特別損害（見本市会場用ゆえ予見可能）
   - あてはめ：解除で報酬を免れた限度は時価から調整（545条4項の趣旨）
- 結論：(2)XYでXは乙時価＋1000万＋2000万を賠償請求しうる

- 【拾う事実】『(1)「耐震基準に適合した設計・施工」＋「震度が極めて大きい」』 → 責めに帰し得ない事由＝Y免責（415ただし書）
- 【拾う事実】『(2)「施工上の手抜き工事が原因」』 → 請負人に帰属すべき瑕疵＝帰責事由
- 【拾う事実】「賃貸借契約は……乙完成前に締結」 → Yの建築を履行過程へ組み込む決め手
- 【拾う事実】「1000万円の損害賠償額の予定」「2000万円の収益」 → 予定条項の趣旨・特別損害の予見可能性（416②）
- 【事案の整理】マス目の勘所
  - 四つのマスのうち(1)と(2)で結論が変わるのは「損害賠償」のマスだけ。引渡不能・危険負担・解除・賃貸借の当然終了は帰責事由と無関係なので(1)(2)共通。まず共通を淡々と、損害賠償で対比、と決めると迷わない。
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 「完成後引渡前に全壊＋再築不能」→社会通念上の履行不能（412条の2）を一言。「全部滅失」→当然終了（616条の2）を一言。立ち止まるのは帰責事由・予定条項・履行補助者の三つだけ。
- 【ポイント】帰責事由の中身
  - 改正法の帰責事由は過失の有無ではなく、契約の趣旨・社会通念に照らし当該不履行のリスクを誰が引き受けたか（契約リスク配分説）。(1)極大地震で耐震適合建物が全壊する事態は請負人の引き受けたリスク外＝免責、(2)手抜き工事は請負人のリスク＝帰責、と読む。
- 【効く事実】XY間で効く事実
  - 履行不能 → 「完成後引渡前に地震により全壊」＋「再築も間に合わない」／(1)免責 → 「耐震基準に適合した設計・施工」＋「震度が極めて大きい」＝リスク外／(2)帰責 → 「施工上の手抜き工事が原因」＝請負人に帰属すべき瑕疵。
- 【規範の要点】「予定条項の趣旨と履行補助者の二段」の規範
  - 予定条項は損害の発生・額の立証困難を回避するのが主眼で、帰責事由という責任成立の要件まで排除する趣旨とは通常いえない（合理的意思）→Xに帰責事由がなければZは予定額を請求できない。そのXの帰責事由は、賃貸借が乙完成前に締結された＝Yの建築はXのZに対する債務履行の過程だから、Yの手抜きのリスクをXが負う、と読む。
- 【ポイント】独立性の受け止め方
  - 請負人には注文者からの独立性がある（716条参照）。でもそれは対第三者の不法行為の規律で、Xが別途Zに負う契約上の債務の履行過程にYを組み込めるかは契約の趣旨で別に決まる。「確かに独立性がある。しかし…」と一度受け止めてから乗り越えると説得力が出る。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - ①建物が壊れれば当然生じる時価相当額＝通常損害（1項）。②③は「国際見本市の会場」という特殊用途から生じる特別損害（2項）で、予見の主体は債務者Y・基準時は不履行時。問題文が用途を明示している以上、賃貸・予定条項は予見すべきであったと評価できる。①は解除で報酬を免れる限度で調整（545条4項の趣旨）。
- 【まぎらわしい選択肢・論点】危険負担における債権者主義の当否／第三者のためにする契約の成否
- 【まぎらわしい選択肢・結論】Xは報酬全額を支払わなければならない／賃貸借は解除の意思表示により終了する
- 【まぎらわしい選択肢・規範】履行補助者の過失は常に債務者の過失と同視される／予定条項があれば帰責事由は一切不要となる
- 【まぎらわしい選択肢・事実】乙は引渡後に滅失した／損害はすべて通常損害である

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

共通＝引渡不能(412の2)・報酬拒絶(536)・解除(542条・543条)・賃貸借当然終了(616の2)は(1)(2)共通で一気に。(1)＝耐震適合＋極大地震で415ただし書免責＝XYもXZ(予定額)も賠償なし。(2)＝手抜きでYに帰責＝XはY解除＋損害賠償(416で乙時価＝通常・1000万/2000万＝特別損害)、XZは乙完成前締結でYの建築は履行過程＝Xに帰責＝Zは予定額1000万請求可（716は受け止めて乗り越え）。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 特定物の引渡債務が双方無帰責で履行不能となった場合の、①反対給付（報酬）債務の帰趨と②契約解消の可否を、根拠条文とともに述べよ。
  - 模範解答：①反対給付＝536条1項により債権者は報酬支払を拒める（履行拒絶権。旧534条の債権者主義は改正で廃止）。②解消＝全部履行不能につき542条1項1号で催告なく解除でき、解除に債務者の帰責事由は不要（不能が債権者の責めによるときのみ解除不可＝543条）。危険負担は債務を残したまま拒む・解除は債務を消す、の違いを添える。
- **［規範クイズ 2/3］** 改正民法の「責めに帰することができない事由」（415条1項ただし書）の意義について、旧通説（過失責任説）と改正が採用した理解を対比して述べよ。
  - 模範解答：旧通説＝過失責任説：帰責事由とは債務者の故意・過失＋信義則上これと同視すべき事由。改正が採用＝契約リスク配分説：過失の有無ではなく、契約の趣旨・取引上の社会通念に照らし当該不履行のリスクをいずれの当事者が引き受けたか、で判断（「契約その他の債務の発生原因及び取引上の社会通念に照らして」の文言に忠実）。いずれでも、耐震適合＋極大地震＝免責、手抜き＝帰責という結論は一致するが、条文適示として後者で書く。
- **［規範クイズ 3/3］** 債務不履行による損害賠償の範囲（416条）の枠組みを、通常損害・特別損害・予見の主体と基準時に触れて述べよ。
  - 模範解答：①通常損害（416条1項）＝債務不履行から通常生ずべき損害は当然に賠償範囲。②特別損害（2項）＝特別の事情から生じた損害は、当事者が予見すべきであったときに賠償範囲。③予見の主体は債務者、基準時は債務不履行時（富喜丸事件・大連判大正15年5月22日が損害額算定の基準時をめぐり示した枠組み）。乙時価＝通常損害、1000万・2000万＝見本市会場用ゆえ予見可能な特別損害、と仕分ける。

## 4. ○×クイズ（全9問・1問目から最後まで全部出す）

- **［○×クイズ 1/9］** 特定物の引渡債務が当事者双方の責めに帰することができない事由で履行不能となった場合、債権者は、なお反対給付を履行しなければならない。
  - 正解：×（誤り）
  - 理由：これは旧534条の債権者主義の発想で、改正で廃止された。現行法は536条1項で、双方無帰責の履行不能では債権者は反対給付の履行を拒める（履行拒絶権構成）。だから特定物（建物）でも、引渡前の滅失について注文者Xが報酬を支払わされることはない。反対給付債務が残る点で解除と区別するのがコツ。
- **［○×クイズ 2/9］** 賃借物の全部が滅失して使用収益ができなくなっても、賃貸借は当事者の解除の意思表示があって初めて終了する。
  - 正解：×（誤り）
  - 理由：全部滅失は616条の2により当然終了で、解除の意思表示を待たない（帰責事由も問わない）。だから賃貸借では「使用させろ」「賃料を払え」の話は消え、残る火種は損害賠償額の予定条項だけになる。一部滅失（611条＝賃料減額・解除）とは効果が違う点も対で押さえる。
- **［○×クイズ 3/9］** 全部履行不能を理由とする契約の解除は、債務者に責めに帰すべき事由があることを要件とする。
  - 正解：×（誤り）
  - 理由：改正民法は解除を「債務者への責任追及」から「債権者を契約の拘束力から解放する制度」へ再構成し、債務者の帰責事由を解除要件から外した（542条1項1号）。だから請負人Yが無帰責の(1)でも、注文者Xは全部履行不能を理由に催告なく解除できる。もっとも不能が債権者Xの責めによるときは解除不可（543条）＝帰責の向きに注意。
- **［○×クイズ 4/9］** 履行不能は物理的な不能に限られず、契約の目的に照らして履行が期待できない社会通念上の不能を含む。
  - 正解：○（正しい）
  - 理由：412条の2第1項は「契約その他の債務の発生原因及び取引上の社会通念に照らして不能」と定め、社会通念上の不能を含む判例法理を明文化した。建物が全壊し「見本市の期間中には再築も間に合わない」以上、契約目的（会場としての使用）に照らして履行不能。物理的に再築が観念できても、期間内という契約目的で不能と評価するのがコツ。
- **［○×クイズ 5/9］** 債務不履行が、契約その他の債務の発生原因及び取引上の社会通念に照らして債務者の責めに帰することができない事由によるときは、債務者は損害賠償義務を負わない。
  - 正解：○（正しい）
  - 理由：415条1項ただし書の免責事由。改正で「債務者の過失」という過失責任的表現を改め、契約・社会通念に照らした帰責事由の有無で判断する枠組みへ転換した（免責事由の立証責任は債務者）。危険負担・解除は帰責事由と無関係なので、この免責が効くのは損害賠償のマスだけ。だから(1)(2)の差はここに集約する。
- **［○×クイズ 6/9］** 損害賠償額の予定がある場合、債権者は、債務者に帰責事由がなくても、当然に予定額の賠償を請求することができる。
  - 正解：×（誤り）
  - 理由：損害賠償額の予定（420条1項）は、損害の発生・額の立証の困難を回避するために置かれるのが通常で、帰責事由という責任成立の要件まで排除する趣旨とは、当事者の合理的意思に照らして通常いえない（免責否定せず説）。だから債務者に帰責事由がなければ予定額の請求もできない。もし帰責事由不要と読むと(1)(2)いずれも1000万請求可となり場合分けの意味が消える＝出題趣旨に反する。
- **［○×クイズ 7/9］** 債務者が債務の履行に用いた者（履行補助者）の過失を債務者自身の帰責事由と評価できるかは、当該契約の趣旨に照らして個別具体的に決すべきである。
  - 正解：○（正しい）
  - 理由：改正民法は「履行補助者の過失＝債務者の過失」という旧法の等式（大判昭和4年3月30日）をそのまま条文化せず、415条1項ただし書の「契約その他の債務の発生原因及び取引上の社会通念」に照らした帰責事由の有無の判断へ解消した。もっとも実質は維持され、債務者が他人を用いて履行領域を拡張した以上その過失リスクは原則債務者が負う。個別契約の解釈による、と枠を立てるのが正しい。
- **［○×クイズ 8/9］** 特別の事情によって生じた損害であっても、当事者がその事情を予見すべきであったときは、債権者はその賠償を請求することができる。
  - 正解：○（正しい）
  - 理由：416条2項。特別損害は「特別の事情＋当事者（債務者）が予見すべきであった」ときに賠償範囲に入る。改正で「予見し、又は予見することができた」が「予見すべきであった」に改められ、予見可能性が規範的判断であることが明確化された。見本市会場用の建物なら賃貸・収益・予定条項は通常想定できるから、1000万・2000万は特別損害として賠償範囲に含まれる。
- **［○×クイズ 9/9］** 解除権の行使は、損害賠償の請求を妨げない。
  - 正解：○（正しい）
  - 理由：545条4項。解除しても損害賠償は併存する。だから(2)でXは請負契約を解除した上で、なおYに履行不能に基づく損害賠償を請求できる。もっとも解除で報酬債務を免れた限度で、乙時価相当額の損害からその分が差し引かれる（二重取りの防止）。「解除したら賠償できない」と誤解しないのが一点。
