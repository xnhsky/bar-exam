## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

Aは、Bとの間で、自己が所有する高級腕時計（以下「本件時計」という。）を100万円で売却する契約を締結し、Bから手付金10万円を受領すると同時に、本件時計を占有改定により引き渡した。なお、AB間では、手付は違約手付である旨の確認はされたが、特に解約手付であることを排除することの取決めはされていない。しかし、その後、CがAに対して本件時計を150万円で買うと申し出たため、Aは、Bが履行日に現金90万円を持ってA宅を訪れ、残代金の支払を申し出た際、Bに20万円を提供して「あの時計はCに売ることにした。この話はなかったことにしてくれ。」と言い、契約の解除を主張した。解除は不当であると考えたBは20万円の受領を拒んだ。一方、上記A及びBのやりとりについて何らの事情も知らず、Aが所有権者であると信じていたCは、Aとの間で、本件時計を150万円で購入する旨の売買契約を締結した（以下「本件契約」という。）。設問1　Bは、Aに対して、本件時計の引渡しを求めることができるか。設問2　Cは、本件契約に基づき、本件時計の引渡しを受けた後、上記一連のやりとりについて悪意のDに対して、本件時計を売却し、引き渡した。Bは、Dに対して、本件時計の引渡しを求めることができるか。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- A・B売買100万・手付10万（違約手付確認・解約排除なし）・占有改定で引渡し
- CがAに150万で買うと申出（Aは高値のCへ売りたくなる）
- 履行日：Bが残代金90万を現実に持参・提供／Aは20万提供し解除主張
- Bは20万の受領を拒絶（＝持ち帰り・提供の不継続）
- 善意無過失のCがA・C売買150万・現実の引渡し（即時取得）
- CがA・B間の事情に悪意のDへ転売・引渡し

登場人物：

### 入口の問い（3問）

- **Q01［事案の整理］** 当事者と「誰が誰に何を請求するか」を挙げて
  - 答え：請求の向きは設問で変わる。設問1＝B → A（売買に基づく引渡請求）、設問2＝B → D（所有権に基づく引渡請求）。
  - 答え：同じ時計が A→B（占有改定）と A→C（現実の引渡し）→C→D と流れる二重売買。設問1は契約法（手付・同時履行）、設問2は物権法（対抗要件・即時取得）と土俵が分かれる。ここで切るのが第一歩。
- **Q02［見当づけ］** 各請求で使えそうな「制度」 ― 見当をつけて
  - 答え：設問1：B→Aの引渡請求（売買555条）に対し、Aは①手付解除（557条1項）②同時履行の抗弁（533条）で反論。設問2：Bの所有権取得（176条）＋占有改定で対抗要件（178条）→ Cの即時取得（192条）→ Dの承継取得。
- **Q03［論点］** 設問1・2で問題になる論点を挙げて（4つ）
  - 答え：CP①：手付は「違約手付である旨の確認」あり → 解約手付と違約手付は兼併するか。（＝排除特約がなければ両立し、解約手付性は死なない）
  - 答え：CP②：Bが残代金90万円を持参・提供 → 「履行の着手」（557条1項ただし書）の該当性。（＝解除者Aの相手方Bが着手すれば解除は封じられる）
  - 答え：CP③：Bは一度提供したが受領拒絶で持ち帰った → 弁済提供後もAは同時履行の抗弁を言えるか（存在効果と本来的効果の区別）。
  - 答え：CP④：Bは占有改定で引渡し／Cは現実の引渡し → 占有改定は178条には足りるが192条には足りない（占有改定の二面性）。

### 骨子（2項目。第1から【論点】ごとに、何が問題→規範→使う事実→結論 の順で組み立てる）

#### 第1　設問1　BのAに対する引渡請求

1. Bは売買（555条）に基づき引渡請求 → Aの反論①②を検討
2. 手付解除（557条1項）：違約手付の確認あり → 【論点】解約手付と違約手付の兼併（規範：排除特約なき限り兼併・解約手付と推定）→ 解約手付性肯定
   - あてはめ：Bが残代金90万を現実に持参・提供 → 【論点】「履行の着手」の該当性（規範：客観的に外部から認識しうる履行行為の一部）＝相手方Bの着手で解除封じ
3. 手付解除＝不可（着手後）／倍返しの当否は論じる実益なし
4. 同時履行の抗弁（533）：牽連性あり → 【論点】弁済提供後も抗弁を主張できるか（規範：本来的効果は提供の継続を要す（昭34.5.14））
   - あてはめ：Bは受領拒絶で20万を持ち帰り＝提供の不継続 → Aの抗弁は生き残る
- 結論：Bは引渡請求可・残代金90万と引換給付

#### 第2　設問2　BのDに対する引渡請求

1. A→B売買でB所有権取得（176）／占有改定で対抗要件具備（178・183） → Bが確定的所有者・Aは無権利
2. Cは無権利者Aから譲受＝承継取得できず → 【論点】即時取得（192）の成否
3. 【論点】即時取得の占有取得に占有改定で足りるか（規範：外観変更を要す・占有改定は不可（昭35.2.11））
   - あてはめ：Cは現実の引渡し＋善意無過失 → 即時取得成立＝C確定的所有者
4. 【論点】悪意のDが承継取得できるか → 前主Cが権利者＝善悪不問で承継取得
- 結論：所有権はDに帰属 ＝ BはDに引渡しを請求できない

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「解約手付であることを排除する取決めはされていない」 → 解約手付性が生きるか（兼併）
- 【拾う事実】『Bが履行日に残代金90万円を現実に持参・支払を申し出た』 → 「履行の着手」に当たるか
- 【拾う事実】『Bは20万円の受領を拒んだ（持ち帰り）』 → 弁済提供が継続されているか
- 【拾う事実】『Aは本件時計を占有改定により引き渡した』 → 対抗要件と即時取得で逆に働く事実
- 【拾う事実】『Cは事情を知らずAを所有者と信じ・現実の引渡しを受けた』 → 即時取得の善意無過失・占有取得
- 【拾う事実】『悪意のDへ売却・引渡し』 → 承継取得で善悪が結論を左右するか
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 手付の交付＝あり／牽連性＝同一売買から生じる引渡債務↔代金債務＝あり／取引行為・平穏公然＝あり。詰まる所＝①違約手付でも解約手付か ②残代金持参が「履行の着手」か ③弁済提供後も同時履行を言えるか ④占有改定で即時取得できるか。
- 【効く事実】あてはめで使う事実
  - 解約手付性 → 「解約手付を排除する取決めはされていない」を直接引用／履行の着手 → Bが履行日に残代金90万円を現実に持参・支払を申し出た／同時履行 → Bは受領を拒まれ20万円を持ち帰り、提供を継続していない。事実は必ず評価語（客観的に外部から認識しうる履行行為の一部／提供の不継続）と結合させる。
- 【規範の要点】最判昭35.2.11の規範
  - 178条の対抗要件たる「引渡し」には占有改定も含まれる（Bは占有改定で対抗要件を具備し確定的に所有者）。他方、192条の即時取得の「占有を始めた」は一般外観上従来の占有状態に変更を生ずる占有取得を要し、占有改定では足りない。本問のCは現実の引渡しを受けているからこの要件を充たす。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 「Dは悪意だから保護されない」と早とちりしない。即時取得（善悪を問う制度）が問題になるのは無権利者から買った局面だけ。Cが確定的所有者になった後は、Dは権利者Cからの承継取得で、192条を持ち出すまでもなく善悪を問わず所有権を得る。前主が権利者かどうかが分水嶺。
- 【まぎらわしい選択肢・論点】他人物売買の担保責任（561条）／177条の登記による対抗／94条2項類推適用／危険負担（536条）
- 【まぎらわしい選択肢・結論】手付解除により契約消滅／請求棄却（引渡し拒否）／Cは即時取得できず所有権はBのまま／悪意のDは所有権を取得できない
- 【まぎらわしい選択肢・規範】一回消滅説／違約手付優先説／占有改定説（即時取得肯定）
- 【まぎらわしい選択肢・事実】提供の継続あり／Cは悪意／本件時計は盗品

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

設問1＝違約手付でも解約手付は死なない、でも相手方Bが残代金持参＝着手で手付解除不可。同時履行は、Bが一度提供しても継続していないからAは主張でき、引換給付。設問2＝Bは占有改定で対抗要件具備＝所有者、Aは無権利。Cは現実の引渡し＋善意無過失で即時取得（占有改定なら不可）。DはCから承継取得、悪意でも所有権取得＝BはDに請求不可。

## 3. 規範クイズ（3問）

- **Q04［規範］** 「契約の履行に着手」（557条1項ただし書）の意義と、着手による手付解除の遮断が誰の着手で生じるかを述べよ。
  - 模範解答：「履行の着手」とは、客観的に外部から認識し得るような形で履行行為の一部をなし、又は履行の提供をするために欠くことのできない前提行為をした場合をいう（最大判昭40.11.24）。ただし書は着手した当事者の不測の損害を防ぐ趣旨だから、解除を主張する者の相手方が着手したときにのみ解除が封じられる（着手した当事者自身からの解除は妨げられない）。
- **Q05［規範］** 弁済の提供が相手方の同時履行の抗弁権に及ぼす効果について、一度の提供で確定的に生じる効果と、提供の継続を要する効果を区別して述べよ（533条）。
  - 模範解答：弁済提供の効果は二層に分かれる。①存在効果（提供者が遅滞責任を免れ、相手方を受領遅滞に陥らせる効果）は一回の提供で確定的に発生し、過去の遅滞責任は復活しない。②本来的効果（相手方の同時履行の抗弁権そのものを消滅させ履行を請求できる状態にする効果）は提供を継続しない限り生じない・維持されない（最判昭34.5.14）。ゆえに一度提供しても受領拒絶で持ち帰れば、相手方の抗弁権は復活する。
- **Q06［規範］** 即時取得（192条）の成立に必要な占有の取得について、占有改定で足りるかを判例の立場とその理由から述べよ。
  - 模範解答：即時取得の成立には、一般外観上従来の占有状態に変更を生ずるような占有の取得を要し、占有改定はこれに当たらない（最判昭35.2.11＝現実の引渡し必要説・否定説）。理由：即時取得は動産の占有に対する信頼を保護し取引安全を図る制度だが、占有改定では譲渡人が現実の所持を続け外観上の変更がないため、真の権利者から権利を奪う根拠となる占有信頼が生じていないから。現実の引渡し・簡易の引渡し・指図による占有移転（外観変更あり）なら足りる。

## 4. ○×クイズ（7問）

- **Q07［○×］** 同一の動産が二重に売却された場合、後の買主が確定的に所有権を取得すれば、先の買主はもはやその動産の所有権に基づく引渡しを、後の買主やその転得者に対して請求することができない。
  - 正解：○（正しい）
  - 理由：所有権に基づく物権的請求は、請求者が所有権を保持していることが前提。後の取得者が対抗要件具備や即時取得で確定的に所有者になれば、先の買主は所有権を失い（喪失させられ）、物権的請求の基礎を欠く。「誰が今の所有者か」を先に決めるのが物権の攻防の出発点。
- **Q08［○×］** 売買契約に基づく買主の目的物引渡請求に対し、売主が同時履行の抗弁権（533条）を行使して認められた場合、買主の請求は棄却される。
  - 正解：×（誤り）
  - 理由：同時履行の抗弁権は履行を全面的に拒める抗弁ではなく、引換給付を導く抗弁。裁判所は「被告は原告から反対給付を受けるのと引換えに給付せよ」との引換給付判決をする。請求棄却ではない点が要注意。手付解除（契約を消す）との効果の違いを意識する。
- **Q09［○×］** 契約の解除（形成権の行使）は契約そのものを消滅させる主張であるのに対し、同時履行の抗弁権は相手方の請求を引換給付にとどめる抗弁にすぎず、契約の存続を前提とする。
  - 正解：○（正しい）
  - 理由：解除が認められれば契約は遡及的に消え、引渡義務も消滅する（結論は請求棄却）。同時履行の抗弁は契約が生きていることを前提に、対価の同時履行を求める抗弁で、認められても契約は存続し引換給付になる。効果が全く違うので、契約の存否に関わる解除から先に処理するのが論理的。
- **Q10［○×］** 売買契約に際して交付された手付について「違約手付とする」旨の合意がある場合には、その手付はもっぱら違約手付となり、解約手付（557条1項）としての性質を有する余地はない。
  - 正解：×（誤り）
  - 理由：違約手付の定めがあるだけでは、解約手付性を排除する反対の意思表示とはいえず、両者は兼併しうる（最判昭24.10.4）。手付は特約なき限り解約手付と推定されるから、解約手付を排除する特約がない限り解約手付として機能する。「違約手付だから解約手付ではない」は典型的な誤り。
- **Q11［○×］** 双務契約において、一方当事者が自己の債務につき一度現実の提供をすれば、その後に提供を継続しなくても、相手方は同時履行の抗弁権を確定的に失う。
  - 正解：×（誤り）
  - 理由：抗弁権を消滅させる本来的効果は、提供が継続されない限り生じない（最判昭34.5.14）。一度の提供で確定的に生じるのは遅滞責任を免れる存在効果だけ。相手方が受領を拒み提供者がこれを持ち帰れば、相手方は再び同時履行の抗弁を主張できる。一度提供したことと抗弁権の消滅を短絡させないのが要。
- **Q12［○×］** 動産の対抗要件たる「引渡し」（178条）には占有改定は含まれず、占有改定を受けたにすぎない譲受人は、その物権取得を第三者に対抗することができない。
  - 正解：×（誤り）
  - 理由：178条の「引渡し」には現実の引渡し・簡易の引渡し・占有改定・指図による占有移転がすべて含まれる（判例）。占有改定を受けた譲受人も対抗要件を具備し、物権取得を第三者に対抗できる。対抗要件では足りる占有改定が、即時取得（192条）の占有取得としては足りない ── この非対称が本問の核心。両制度の趣旨（公示か公信か）の違いから生じる。
- **Q13［○×］** 前主が完全な権利者である場合、その者から目的物を譲り受けた者は、たとえ前主・自己の取得の経緯について悪意であっても、承継取得により所有権を取得する。
  - 正解：○（正しい）
  - 理由：承継取得は前主の権利をそのまま承継するから、前主が完全な権利者でありさえすれば、承継人の善悪は結論を左右しない。即時取得のように善意無過失を要するのは、無権利者から取得する原始取得の場面。前主が権利者になった後の転得者に、改めて即時取得の要件を求める必要はない。
