## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

Bは家屋を所有する目的でA所有の甲土地を賃借し、Cから建築資金の融資を受け、甲土地上に乙建物を建築した。その上で、Bは自己名義で乙建物を保存登記して、Cからの貸金債権の担保のために、乙建物に抵当権を設定した。さらに、その後、Bは地主Aに乙建物を譲渡して移転登記を了した。他方で、Bから貸金の弁済を受けられなかったCは、抵当権を実行して、Dが乙建物の買受人となった。以上の場合の、DとAの関係について説明しなさい。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- BがA所有甲土地を賃借（借地権）・乙建物を建築
- Bが乙建物を自己名義で保存登記（＝借地権の対抗要件）
- Bが乙建物にCの貸金債権の担保として抵当権設定（設定時＝別人所有）
- Bが乙建物をAへ譲渡・移転登記（甲土地・乙建物が同一人Aに帰属）
- C抵当権実行 → Dが乙建物を競落（甲=A・乙=D）

### 参考（読み上げない。入口の問いの答えを含むので判定にだけ使う）

登場人物：
- A｜地主・甲土地所有者（→Dへ建物収去土地明渡請求）
- B｜賃借人・建築者（→乙建物をAへ譲渡）
- C｜融資者・抵当権者（→抵当権を実行）
- D｜競落人・乙建物の買受人（→賃借権で対抗）

一行要約：Aが土地所有権でDへ建物収去土地明渡を請求、Dは土地利用権で対抗。

### 入口の問い（3問）

- **Q01［事案の整理］** 当事者・目的物・権利の動きを挙げて
  - 答え：対立するのはA（甲土地所有者）とD（乙建物競落人）。Bは既に退場（乙建物をAへ譲渡）、Cは抵当権を実行し終えた。焦点はDがAの土地を使える権原を持つか。
  - 答え：抵当権設定時＝甲土地A・乙建物B（別人所有）／その後＝乙建物もAへ（同一人）／競落後＝乙建物D・甲土地A。この3時点の所有関係が全論点の入口。
- **Q02［見当づけ］** Aの請求と Dの抗弁候補 ― 見当をつけて
  - 答え：A：甲土地所有者→乙建物所有者Dへ所有権に基づく建物収去土地明渡請求。D：土地利用権で反論＝候補は2つ①法定地上権（388条前段）②賃借権。この2つは表裏一体（賃借権が生きていれば法定地上権は不要）。
- **Q03［論点］** 問題になる論点を挙げて（3つ）
  - 答え：CP①：抵当権実行時は土地・建物が同一人A → 一見法定地上権？だが基準時は抵当権設定時 → 設定時は別人所有ゆえ不成立。（設定時に別人所有だと同一人所有要件を欠く）
  - 答え：CP②：賃借権はまだ生きているか → 乙建物のA譲渡で所有権と賃借権が同一人Aに集中 → 混同で消えないか。（混同＝両立させる意味のない権利が同一人に帰属して消える）
  - 答え：CP③：賃借権をDが引き継げるか → 抵当権の効力が敷地賃借権に及ぶか＋無断譲渡（612条）と20条。

### 骨子（3項目。第1から【論点】ごとに、何が問題→規範→使う事実→結論 の順で組み立てる）

#### 第1　AのDに対する請求

1. A＝甲土地所有者／D＝乙建物所有により甲土地を占有
2. 所有権に基づき 建物収去土地明渡請求（Dに占有権原あれば認められない）
- 以下、Dの占有権原（法定地上権・賃借権）を検討

#### 第2　法定地上権（388前段）の成否

1. 抵当権実行時は甲土地・乙建物ともA → 法定地上権を主張
2. 【論点】法定地上権の成否 → 規範：成否は抵当権設定時の所有関係で判断
   - あてはめ：設定時は甲A・乙B の別人所有（事後の同一人帰属は考慮せず・最判昭44.2.14）
3. 実質：建物所有者Bは賃借権を有し、これで足りる＝法定地上権不要
- 結論：法定地上権 不成立

#### 第3　賃借権の抗弁

1. Dは甲土地の賃借権を主張／乙建物のA譲渡で所有権と賃借権が同一人Aへ
2. 【論点】賃借権の混同消滅 → 規範：179条1項ただし書準用
   - あてはめ：対抗要件（乙建物の保存登記・借地借家法10条1項）＋抵当権の目的 → 消えない（最判昭46.10.14）
3. 【論点】抵当権の効力が敷地賃借権に及ぶか → 規範：370条類推（従たる権利・一体の財産的価値）
   - あてはめ：最判昭40.5.4 → Dは競落で 賃借権を取得
4. 【論点】無断譲渡と承諾に代わる許可 → 612条の無断譲渡だが借地借家法20条1項で許可
- 結論：賃借権は消滅せず／Aの建物収去土地明渡請求は認められない

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】『「乙建物に抵当権を設定」＋設定時は甲A・乙B』 → 法定地上権の基準時＝設定時別人所有
- 【拾う事実】「自己名義で乙建物を保存登記」 → 借地権の対抗要件（借地借家法10条1項）
- 【拾う事実】「Bは地主Aに乙建物を譲渡」 → 所有権と賃借権が同一人Aへ＝混同の契機
- 【拾う事実】『乙建物に抵当権が付いている』 → 賃借権が第三者の権利の目的＝混同の例外
- 【拾う事実】『「Dが乙建物の買受人」＝競落・Aの承諾なし』 → 抵当権の効力の波及＋無断譲渡・20条
- 【争いのない要件】論点にならず、あっさり認定する要件
  - A所有・D占有は争いなし＝一言。焦点はDの占有権原だけ。争いの薄い前提（対抗要件＝乙建物の保存登記）は一度認定すれば足りる。
- 【効く事実】効く事実（混同）
  - 同一人帰属 → Bが乙建物をAへ譲渡し、甲土地の所有権と賃借権がAに集中／対抗要件 → 乙建物の自己名義保存登記（借地借家法10条1項）／第三者の権利の目的 → 乙建物に抵当権が設定。事実は必ず規範の要件と結合させる。
- 【規範の要点】混同の例外の規範
  - 対抗要件を備えた賃借権が抵当権の目的となっているときは、179条1項ただし書の準用により、混同によっても消滅しない（最判昭46.10.14）。→ 本問は対抗要件○＋抵当権の目的○ ＝ 消えない。
- 【規範の要点】「抵当権の効力＋無断譲渡」の規範
  - ①建物所有に必要な敷地賃借権は建物所有権に付随し一体の財産的価値を形成するから、建物の抵当権の効力は敷地賃借権に及ぶ（370条類推・最判昭40.5.4）→ Dは競落で賃借権も取得。②その移転にAの承諾がなければ無断譲渡だが、Aに不利がなければ裁判所が承諾に代わる許可を与える（借地借家法20条1項）→ Dは対抗できる。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 各論点を「結論だけ」でつなぐと論理が飛ぶ。「法定地上権は不要（∵賃借権があるから）→ その賃借権は生きているか→引き継げるか→対抗できるか」と一段ずつ受けると、答案が一本の線になる。共通の前提（乙建物の保存登記＝対抗要件）は一度認定して使い回す。
- 【まぎらわしい選択肢・論点】自己借地権の可否／即時取得の成否／背信的悪意者からの譲受け
- 【まぎらわしい選択肢・結論】法定地上権 成立／賃借権 混同で消滅／建物収去土地明渡請求 認容
- 【まぎらわしい選択肢・規範】競売時基準説／94条2項類推／対抗要件不要説
- 【まぎらわしい選択肢・事実】設定時同一人所有／Aの承諾あり／抵当権は甲土地に設定

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

請求＝Aは所有権で建物収去土地明渡。法定地上権＝基準時は設定時、設定時別人所有ゆえ不成立（賃借権で足りる）。賃借権＝同一人帰属でも対抗要件＋抵当権の目的ゆえ179条1項ただし書準用で消えない → 抵当権の効力が敷地賃借権に及び（370条類推）Dが取得 → 無断譲渡でも20条で承諾に代わる許可。結論＝Aの請求は認められない。

## 3. 規範クイズ（3問）

- **Q04［規範］** 抵当権設定時に土地・建物が別人所有だった場合、その後に同一人へ帰属し競売で分離しても法定地上権が成立しないことの規範と理由を述べよ。
  - 模範解答：法定地上権の成否は抵当権設定時の所有関係を基準に判断する。設定時に別人所有なら「土地及び建物が同一の所有者に属する場合」（388条前段）を欠き、事後の同一人帰属は考慮しない（最判昭44.2.14）。加えて、建物所有者は既に土地の賃借権を有していれば、これを存続させれば足り、法定地上権を認める必要もない。
- **Q05［規範］** 土地の所有権と賃借権が同一人に帰属したのに、その賃借権が混同によって消滅しないための要件と根拠条文を述べよ。
  - 模範解答：①賃借権が対抗要件を具備し、②その賃借権が抵当権など第三者の権利の目的となっているとき。対抗要件を備えた不動産賃借権は物権類似の性質を有するから、179条1項ただし書を準用して混同消滅を否定する（最判昭46.10.14）。賃借権は債権ゆえ厳密には520条ただし書だが、答案は判例に従い179条で書く。
- **Q06［規範］** 建物に設定された抵当権が実行されたとき、競落人が敷地賃借権も取得できることの規範と、その理由・根拠構成を述べよ。
  - 模範解答：建物を所有するために必要な敷地の賃借権は、建物所有権に付随し、これと一体となって一の財産的価値を形成する。よって建物に抵当権が設定されると、敷地賃借権も原則としてその効力の及ぶ目的物に包含される（最判昭40.5.4）。根拠構成は370条類推（付加一体物）または87条2項類推（従たる権利）のいずれでもよい。競落人は建物とともに敷地賃借権を取得する。

## 4. ○×クイズ（7問）

- **Q07［○×］** 日本法は土地と建物を別個独立の不動産として扱い、建物を所有するには、土地についての利用権（地上権・賃借権等）が別途必要である。
  - 正解：○（正しい）
  - 理由：土地・建物を別個の不動産とするのが日本法の建前。だから建物所有者は敷地の利用権原（賃借権・地上権・法定地上権）を必ず要し、それが無ければ建物収去土地明渡しを迫られる。本問でDに何の土地利用権があるかが攻防の核心になる。
- **Q08［○×］** 土地所有者が、正当な土地利用権原なくその土地上に建物を所有して土地を占有する者に対しては、所有権に基づく妨害排除請求として、建物を収去して土地を明け渡すよう請求できる。
  - 正解：○（正しい）
  - 理由：建物所有は敷地の占有を伴うから、土地所有者は所有権に基づき建物収去土地明渡しを請求できる。これに対し占有者が土地利用権原（地上権・賃借権・法定地上権等）を主張・立証できれば請求は認められない。攻防は「利用権原の有無」に収れんする。
- **Q09［○×］** 法定地上権（388条）と約定の賃借権（借地権）は、いずれも建物のための土地利用権であり、一つの事案で両者が同時に成立して重畳的に建物を保護するのが原則である。
  - 正解：×（誤り）
  - 理由：法定地上権は、約定の土地利用権を設定できない場合に建物の存立を守るため法が地上権を擬制する制度。建物所有者が既に賃借権（借地権）を持つなら、その利用権を存続させれば足り、法定地上権を認める必要はない（両者は表裏一体で、一方が生きれば他方は出番を失う）。だから「賃借権があるから法定地上権は不要」と流れるのが正しい。
- **Q10［○×］** 法定地上権（388条前段）の成立要件である「土地及び建物が同一の所有者に属すること」の充足は、抵当権設定時を基準に判断され、その後に同一人へ帰属しても要件は満たされない。
  - 正解：○（正しい）
  - 理由：388条は抵当権設定時の所有関係で法定地上権の成否を決める。設定時に別人所有なら、抵当権者は法定地上権の負担がない担保価値を把握しているから、事後の同一人帰属で成立に転じさせると担保価値を害する。本問も乙建物への抵当権設定時は甲土地A・乙建物Bの別人所有ゆえ不成立（最判昭44.2.14）。競売時に同一人だからと成立させるのが典型ミス。
- **Q11［○×］** 同一物について所有権と他の物権が同一人に帰属したときは、その他の物権は常に混同により消滅し、当該物権が第三者の権利の目的である場合も例外ではない。
  - 正解：×（誤り）
  - 理由：179条1項は本文で混同消滅を定めるが、ただし書で「その物又は当該他の物権が第三者の権利の目的であるとき」は消滅しないと定める。第三者（抵当権者等）の権利が乗っている以上、消してしまうとその第三者を害するからである。本問の賃借権も抵当権の目的だから、混同では消えない。
- **Q12［○×］** 借地上の建物が競売された場合、建物の取得者（競落人）が賃貸人の承諾を得られないときでも、その賃借権譲渡が賃貸人に不利となるおそれがないのに承諾しないときは、裁判所は建物取得者の申立てにより賃貸人の承諾に代わる許可を与えることができる（借地借家法20条1項）。
  - 正解：○（正しい）
  - 理由：競売・公売で借地上建物を取得した第三者は借地借家法20条1項で救済される（借地権者自身の任意譲渡＝19条とは別条文）。承諾に代わる許可を得れば、無断譲渡（612条）による解除を避け、賃借権を賃貸人に対抗できる。「賃借権は生きている」で止めず、無断譲渡→20条まで書き切るのが上位答案。
- **Q13［○×］** 建物のための敷地賃借権について借地借家法上の対抗要件を備えるには、賃借権の登記が不可欠であり、借地上に借地権者名義で登記した建物を所有していても対抗力は生じない。
  - 正解：×（誤り）
  - 理由：借地権は、その登記がなくても、土地上に借地権者名義で登記した建物を所有すれば第三者に対抗できる（借地借家法10条1項）。本問はBが乙建物を自己名義で保存登記しているから、これ一つで①混同の例外の前提（対抗要件を備えた賃借権）と②Dの賃借権の対抗要件の双方を満たす。共通前提として一度認定すれば足りる。
