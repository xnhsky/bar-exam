Aは、甲自動車（A名義の登録済み）、乙自動車及び丙自動車（いずれも未登録）の3台の自動車を購入した。Aは、ガレージを設置する間、自動車の販売を業とするBに保管を依頼し、これらを引き渡した。ところが、Bは事業資金が必要となり、甲自動車について名義変更に必要な書類を偽造して自己名義に登録を変更した上で、自己所有と称してCに売却し、引き渡した。また、Bは、乙自動車が未登録であることに気付き、これを自己所有と称してDに売却した上で、Dが駐車場を見つけるまでの間、自ら保管しておくことにした。さらに、Bは、丙自動車についても、Aの承諾を得た上で、いったんその保管を友人のEに依頼して引き渡した上で、改めてこれをFに売却した。その際、Bは、F承諾のもと、Eに対して以後Fのために丙自動車を保管するよう指示した。本件自動車の所有権を巡る法律関係について論ぜよ。なお、商法の適用については考慮する必要がない。

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】『甲は「A名義で登録済み」』 → 動産性の判断（Bの名義変更は偽造＝不実の登録にすぎない）
- 【拾う事実】『乙はBが「自ら保管を継続」』 → 占有改定・現実の占有はBに残り外観に変更なし
- 【拾う事実】『丙はEが直接占有・Aの間接占有が失われる』 → 支配領域を離れて流通したかの判断
- 【拾う事実】『Bは保管を受けた受寄者』 → 処分権なし＝無権利者（承継取得不可の前提）
- 【拾う事実】「商法の適用は考慮不要」 → 商人間の特則を論じず民法の枠内で処理する誘導
- 【事案の整理】まず「無権利者からの取得」を確認
  - 本問はすべて「A所有の車を、保管を受けた無権利者Bが無断で第三者へ売った」構図。共通の入口は承継取得は不可 → 即時取得（192条）で救われるか。
- 【争いのない要件】論点にならず、あっさり認定する要件
  - ②取引行為＝各車とも売買あり・Bは受寄者で処分権なし＝無権利／③善意無過失＝186条1項（平穏・公然・善意）＋188条（無過失）で推定＝一言で素通り。争いは①（甲）と④（乙・丙）に集中する。
- 【効く事実】「乙＝占有改定」のあてはめで使う事実
  - 甲＝A名義で登録済（Bの名義変更は偽造＝不実の登録にすぎない）→ 動産性なし。乙＝BがDに売った後も自ら保管を継続（現実の占有はBに残り外観に変更なし）→ 占有改定。
- 【規範の要点】支配領域離脱基準の規範
  - 指図による占有移転でも、占有代理人が譲受人のために占有する旨を承諾し、従来の権利者が当該動産に対する一切の占有（間接占有を含む）を失ったときは、外観に変更を生じたものとして即時取得を肯定する（最判昭57.9.7）。所有者の支配が残る類型は否定（大判昭8.2.13等）。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 乙・丙は「所有者が間接占有を含む一切の占有を失い、支配領域を離れて流通したか」の同一基準で説明できる。占有改定（乙）＝支配領域内にとどまる→否定／指図（丙）＝権利者の間接占有が失われる→肯定。
- 【まぎらわしい選択肢・論点】即時取得と盗品・遺失物の回復（193条）／94条2項の類推適用／対抗要件としての引渡し（178条）
- 【まぎらわしい選択肢・結論】即時取得○＝甲はC所有／即時取得✕＝丙はA所有のまま
- 【まぎらわしい選択肢・規範】占有改定肯定説／折衷説（限定肯定説）
- 【まぎらわしい選択肢・事実】現実の引渡し／簡易の引渡し

## 3. 規範クイズ（3問）

- **Q04［規範］** 登録済自動車が即時取得の対象とならない理由を、即時取得制度の趣旨から説明せよ。
  - 模範解答：即時取得は、動産の占有という公示方法の不完全さを公信の原則で補い、占有への信頼を保護する制度。登録という公示方法が完備された登録済自動車には、占有に公信力を認める前提がなく、これを即時取得で保護する必要もないから、「動産」に当たらないと解される（最判昭62.4.24）。
- **Q05［規範］** 192条「占有を始めた」の解釈規範（占有改定を否定する基準）を述べ、否定の理由づけを挙げよ。
  - 模範解答：規範＝一般外観上従来の占有状態に変更を生ずるような占有の取得を要する。占有改定は外観に変更がなくこれを欠く。理由づけ＝①支配領域を離れて流通したといえない、②帰責性のない真の所有者に酷、③法律関係の早期確定の要請（最判昭35.2.11）。
- **Q06［規範］** 占有改定（乙）は否定され、指図による占有移転（丙）は肯定されうる ― この差を統一的に説明する基準を述べよ。
  - 模範解答：基準＝従来の権利者が間接占有を含む一切の占有を失い、一般外観上従来の占有状態に変更を生じたか（支配領域離脱基準）。占有改定は所有者側の占有状態に変更が生じないため否定、指図は占有代理人が譲受人のため占有する旨承諾し所有者の間接占有が失われる場合に肯定。名目的態様でなく支配喪失の実質で判断する。

## 4. ○×クイズ（12問）

- **Q07［○×］** 無権利者から動産を譲り受けた者は、承継取得によっては所有権を取得できないのが原則であり、保護される余地があるとすれば即時取得（192条）による。
  - 正解：○（正しい）
  - 理由：権利は前主から承継するのが原則だから、無権利者からは承継取得できない。例外的に取得を認めるのが即時取得（原始取得）であり、これは占有への信頼を保護する制度。だから検討の入口は常に「承継取得不可 → 即時取得の成否」に絞る。
- **Q08［○×］** 即時取得（192条）は、動産の占有に公信力を認め、前主が無権利者であっても占有を信頼して取引に入った者に所有権の原始取得を認める制度である。
  - 正解：○（正しい）
  - 理由：動産取引では占有が権利の外観を作る。この外観への信頼を保護しないと取引ごとに前主の権利を調査せねばならず動的安全が害される。そこで占有に公信力を与え、真の権利者の静的安全を犠牲にしてでも取引の安全を守るのが192条の趣旨（公信の原則）。
- **Q09［○×］** 即時取得が成立するためには、「動産」を「取引行為によって」取得したことを要し、相続などの包括承継や、原始取得によって占有を得た場合には適用されない。
  - 正解：○（正しい）
  - 理由：即時取得は「取引の安全」を守る制度だから、保護に値する取引行為（売買・贈与等）による取得でなければならない。相続のような包括承継や、取引によらない占有取得は前主の占有への信頼を語れず、192条の適用外。本問はいずれも売買＝取引行為なのでこの要件は充たす。
- **Q10［○×］** 登記・登録という占有とは別個の公示制度が完備された財産は、占有に公信力を認める前提を欠くため、192条にいう「動産」に当たらない。
  - 正解：○（正しい）
  - 理由：即時取得は「占有＝唯一の権利外観」であることを前提に、その外観への信頼を保護する制度。登記・登録という別の公示があれば権利関係はそちらで分かるから、占有に公信力を認める必要も前提もない。だから登録済自動車・船舶・航空機等は「動産」から外れる。
- **Q11［○×］** 登録済自動車について即時取得が否定されるのは、自動車が高価な財産であって、取引の安全よりも真の所有者の保護を優先すべきだからである。
  - 正解：×（誤り）
  - 理由：理由は「高価だから」ではなく、登録という別個の公示制度が完備され占有の公信力を語る前提を欠くからである。価格の高低は基準にならない（高価でも未登録の動産は即時取得の対象になる）。理由づけを取り違えると甲の論述が的を外す。
- **Q12［○×］** 道路運送車両法により登録を受けている自動車は、登録によって所有権の得喪が公示されるため、192条にいう「動産」に当たらず、即時取得の規定の適用がない（最判昭62.4.24）。
  - 正解：○（正しい）
  - 理由：登録済自動車は登録簿で権利関係が公示され、占有が唯一の外観ではない。即時取得は占有の公信力を基礎とする制度だから、登録という別の公示が働く車には適用がない（最判昭62.4.24）。甲はこれで即時取得＝A所有のまま。
- **Q13［○×］** 無権利者が書類を偽造して登録済自動車を自己名義に変更した場合、その自動車は不実の登録がされたことによって192条の「動産」に当たることになり、即時取得の対象となる。
  - 正解：×（誤り）
  - 理由：名義変更が偽造であっても、それは不実の登録がされたにすぎず、当該自動車が「登録済自動車」であるという性質自体は変わらない。したがって依然「動産」に当たらないから、Cの即時取得は成立しない。本問の甲はまさにこの型（Bの偽造名義変更）。
- **Q14［○×］** 占有改定（183条）による占有取得は、一般外観上従来の占有状態に変更を生じないため、192条の「占有を始めた」に当たらず、即時取得は成立しない（最判昭35.2.11）。
  - 正解：○（正しい）
  - 理由：「占有を始めた」というには、一般外観上従来の占有状態に変更を生ずるような占有取得を要する。占有改定では現物が前主の下に留まり外観が変わらないから、これに当たらない（最判昭35.2.11・民法判例百選I-64）。乙はこれで即時取得＝A所有のまま。
- **Q15［○×］** 占有改定も引渡し（178条）に当たり対抗要件としては足りる以上、192条の「占有を始めた」にも当然に当たり、占有改定による即時取得が成立する。
  - 正解：×（誤り）
  - 理由：これは肯定説の論法だが判例は採らない。178条は有効な権利移転を前提にした対抗要件、192条は無権利者からの権利取得原因で制度目的が異なる。占有改定は178条の引渡しには当たっても、外観の変更がなく192条の「占有を始めた」には足りない。役割の違いを示すのが差のつく一手。
- **Q16［○×］** 指図による占有移転（184条）による占有取得は、現物の現実の所持が移らない以上、いかなる場合も一般外観上の変更を欠くから、即時取得は一切成立しない。
  - 正解：×（誤り）
  - 理由：占有改定と違い、指図では占有代理人が譲受人のために占有する旨を承諾し、従来の権利者が一切の占有を失う場合があり、そのときは外観に変更が生じたといえ即時取得が肯定される（最判昭57.9.7）。「一切成立しない」と言い切るのは誤り。成否は支配領域を離れたか否かで決まる。
- **Q17［○×］** 指図による占有移転でも、占有代理人が譲受人のために占有する旨を承諾し、従来の権利者が間接占有を含む一切の占有を失った場合には、「占有を始めた」といえ即時取得が成立しうる（最判昭57.9.7）。
  - 正解：○（正しい）
  - 理由：従来の権利者が間接占有まで含めて一切の占有を失えば、一般外観上従来の占有状態に変更が生じたといえる。本問の丙は、EがFのため占有する旨の承諾によりBの間接占有が消え、それに依拠したAの間接占有も完全に失われる型＝即時取得○（Fが善意無過失なら）。
- **Q18［○×］** 即時取得の主観的要件のうち「平穏」「公然」「善意」は186条1項により推定され、「無過失」は前主の占有に基づき188条により推定される。
  - 正解：○（正しい）
  - 理由：186条1項は平穏・公然・善意を推定するが無過失は推定しない。そこで判例は、前主が占有していれば188条により前主の権利適法性が推定され、これを信頼した譲受人の無過失も推定されるとする（最判昭41.6.9）。結果、主観的要件はすべて推定され、悪意・有過失は真の権利者側が立証する。
