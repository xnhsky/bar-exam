## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

Aは、Bに対し、自己の所有する中古のステレオ・セットを贈与することを約し、Bへの送付をCに委託した。ところが、Cによる輸送の途中、Dがこのステレオ・セットを盗み、Eに売り渡した。1　この場合に、A、B及びCは、Eに対し、ステレオ・セットの引渡しの請求をすることができるか。2　A、B、Cのいずれもがステレオ・セットを取り戻すことができなかった場合に、BがAに対してすることができる請求及びAがその請求を拒むことができる根拠について説明せよ。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- AがBへ中古ステレオ（特定物）を口頭で贈与 → 契約時にBへ所有権移転（176）
- AがCに送付を委託（準委任656）→ Cが直接占有・Aは間接占有
- 輸送中にDが盗取（占有の侵奪・「盗品」に）
- DがEへ売却（Eは即時取得192の可能性・侵奪者の特定承継人200Ⅱ）
- 小問1：A・B・CがEへ引渡請求できるか
- 小問2：ABC取り戻せず（＝履行不能）→ BがAへ損害賠償・Aの抗弁

登場人物：
- A｜贈与者・元所有者（→契約時に所有権はBへ）
- B｜受贈者・新所有者
- C｜送付の受託者・直接占有者
- D｜窃盗犯（侵奪者）＝請求主体でない
- E｜転得者（買主）＝請求の相手方

一行要約：Aが特定物（中古ステレオ）をBへ贈与し送付をCに委託、輸送中にDが盗みEへ売却。

### 入口の問い（3問）

- **Q01［事案の整理］** 登場人物と「動いた物・権利」を挙げて
  - 答え：請求できる可能性があるのは A（贈与者）・B（受贈者）・C（受託者） の3人。相手方は転得者 E。D＝窃盗犯は請求主体ではなく、追及の起点。
  - 答え：物の流れ：A所有 →（贈与でB所有）→ Cが輸送（直接占有）→ Dが盗む → Eへ売却。「所有」と「占有」を分けて書くのが第一歩。
- **Q02［見当づけ］** 各主体が立てうる「請求権」 ― 見当をつけて
  - 答え：「所有権があるか」「盗まれた物か」「占有を奪われたか」で振り分ける。所有権＝物権的請求／盗品＝193条の特則／占有喪失＝占有の訴え。1つの物に3本の権利が重なりうると気づくのがコツ。
- **Q03［論点］** 本問の問題になる論点を挙げて（3つ）
  - 答え：CP①：193条の 「被害者」に直接占有者を含むか。（含めばB・Cは可、間接占有者Aは不可）
  - 答え：CP②：占有の訴えの 主体（197条前段＝間接／後段＝直接）と 相手方（200条2項但書＝善意の特定承継人）。
  - 答え：CP③：Eの 即時取得（192条）と期間（2年・1年）で全体を絞る。

#### 前提　所有権の所在

- 見出しの補足（結論を含む。項目の終わりに読む）：特定物贈与
1. 中古ステレオ＝特定物 → 【論点】特定物贈与の所有権移転時期（意思主義・176条＝契約時説）
- 結論：所有権は契約時に Bへ移転（所有権請求はBのみ）

#### 第1　小問1・A/B/CのEへの引渡請求

1. A（贈与者・間接占有者）：所有権／盗品回復（【論点】「被害者」に間接占有者を含むか→含まず）／占有回収○（197条前段）

2. B（受贈者・所有者）：所有権○（Eが即時取得192しない限り）／盗品回復○（193条・盗難から2年）／占有改定あれば占有回収も
3. C（受託者・直接占有者）：占有回収○（197条後段）／Eが即時取得しても盗品回復○（【論点】「被害者」に直接占有者を含むか→含む）

#### 第2　小問2・BのAへの請求とAの抗弁

1. ABC取り戻せず＝特定物の引渡債務が履行不能 → Bの請求＝履行不能の損害賠償（415条1項・2項1号）

- 【拾う事実】『「中古の」ステレオ・セット』 → 特定物 → 176条で契約時にBへ所有権移転

- 【拾う事実】「書面によらない（口頭の）贈与」 → 550条の解除・「履行の終わった」の検討へ
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 所有権＝Bのみ／即時取得＝盗品なので193条で2年間留保／占有の侵奪＝Cの占有が奪われた＝あり。争いのない要件は一言で通し、「被害者」の範囲と占有の訴えの主体に紙幅を割く。
- 【効く事実】あてはめで使う事実

- 【ポイント】抗弁の急所を一文で

- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり

- 【まぎらわしい選択肢・事実】代価の弁償（194条）／書面による贈与

## 3. 規範クイズ（4問）

- **Q04［規範］** 占有の訴えの主体を定める民法197条の前段と後段の使い分けを述べよ。
  - 模範解答：前段「占有者」＝間接占有者を含む占有者一般（本問のA＝委託者）。後段「他人のために占有をする者」＝占有代理人＝直接占有者（本問のC＝受託運送人）。前段でAを、後段でCを占有回収の主体として振り分ける。
- **Q05［規範］** 占有回収の訴えの相手方に関する制約（民法200条2項）を、善意の意味まで含めて述べよ。
  - 模範解答：占有回収の訴えは、侵奪者の特定承継人が侵奪の事実につき善意であるときは、これに対して提起できない（200条2項但書）。この善意は過失の有無を問わない。本問のEがDから買い受けた際に侵奪を知らなければ、占有回収は遮断される。
- **Q06［規範］** 盗品が即時取得された場合、回復期間中の所有権は誰に帰属するか（判例の立場）と、その帰結を述べよ。
  - 模範解答：原所有者帰属説（判例）＝即時取得された後も、193条の回復期間（2年）内は所有権が原所有者に帰属したままである。帰結として、193条の回復請求は所有権に基づく返還請求と別個の訴訟物にはならず、回復により所有権は確定的に原所有者へ落ち着く。
- **Q07［規範］** 履行補助者（独立の運送人）を用いた場合の帰責事由の判断枠組みと、無償契約たる贈与での処理を述べよ。
  - 模範解答：帰責事由の有無は契約その他の債務の発生原因および取引上の社会通念に照らして判断（415条1項ただし書）。運送を第三者に委ねた債務者は通常そのリスクを引き受けたと評価され、独立の運送人を用いた一事では免責されない。無償契約でも551条1項により契約内容適合物の給付が前提であり、無償ゆえの酷さは賠償額の調整で処理する（免責の範囲を広げない）。

## 4. ○×クイズ（7問）

- **Q08［○×］** 特定物の贈与では、特約がない限り、目的物の所有権は贈与契約の成立時に受贈者へ移転する（意思主義）。
  - 正解：○（正しい）
  - 理由：物権の設定・移転は当事者の意思表示のみで効力を生じる（176条・意思主義）。中古品のように物の個性に着目した特定物は、特約なき限り契約時に所有権が移転する。これが「所有権に基づく請求ができるのは誰か」を決める起点になる。
- **Q09［○×］** 占有回収の訴え（200条1項）は、占有そのものを基礎とする請求であり、請求者が目的物の所有権を有することを要件としない。
  - 正解：○（正しい）
  - 理由：占有の訴えは事実状態たる占有を保護する制度で、本権（所有権）の有無を問わない。だから所有者でないC（受託者）や間接占有者A（委託者）も、占有を奪われた者として占有回収を検討できる。「所有していないから請求できない」で切らないこと。
- **Q10［○×］** 盗品が第三者に即時取得された場合、被害者は民法193条により、盗難の時から1年間に限り、占有者に対して盗品の回復を請求することができる。
  - 正解：×（誤り）
  - 理由：盗品回復請求（193条）の期間は盗難の時から2年間。1年は占有回収の訴えの出訴期間（201条3項）で、両者は別制度。2年（本権寄りの盗品回復）と1年（占有の訴え）の取り違えは頻出の失点。
- **Q11［○×］** 民法193条にいう「被害者」には、目的物の所有者のみならず、盗難の時に目的物を直接占有していた者（賃借人・受託者など）も含まれる。
  - 正解：○（正しい）
  - 理由：193条は直接には占有の回復を主眼とし、文言も「被害者」を所有者に限定していない（判例・通説＝占有者包含説）。ゆえに直接占有者たる受託者Cも回復請求できる。もっとも、Cを介した間接占有者にすぎない者は「被害者」に含まれない。
- **Q12［○×］** 占有回収の訴えは、占有を侵奪した者から目的物を買い受けた特定承継人に対しては、その承継人が侵奪の事実について善意かつ無過失であるときに限り、提起することができない。
  - 正解：×（誤り）
  - 理由：200条2項但書の善意は過失の有無を問わない（無過失は不要）。承継人が侵奪の事実を知らなければ、過失があっても占有回収の訴えは提起できない。即時取得（192条）が無過失を要求するのと混同しないこと＝ここが引っかけの定番。
- **Q13［○×］** 書面によらない贈与であっても、動産が現実に引き渡されず占有改定による引渡しにとどまる場合には、「履行の終わった」（550条ただし書）とはいえず、贈与者はなお解除することができる。
  - 正解：×（誤り）
  - 理由：「履行の終わった」とは厳格な履行完了ではなく債務の主要部分の履行を意味し、動産では引渡しで足り、その引渡しには占有改定（183条）も含まれる（判例・通説）。履行により贈与意思が外部的に明確化した以上、翻意による解除を認める必要がないからである。占有改定があれば解除できない。
- **Q14［○×］** 占有回収の訴えは侵奪の時から1年の出訴期間（201条3項）や善意の特定承継人への提起制限（200条2項）を受ける点で、消滅時効にかからない所有権に基づく返還請求に比べ、権利として弱い。
  - 正解：○（正しい）
  - 理由：占有の訴えは事実状態の暫定的保護にすぎず、相手方（善意の特定承継人には不可）・期間（1年）の制約が大きい。他方、所有権に基づく返還請求は所有権自体が消滅時効にかからないため制約が小さい。占有回収は「弱い権利」と割り切り、深追いしないのがコツ。
