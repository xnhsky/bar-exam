#### 第1　設問1(1)　錯誤取消しの可否

- 見出しの補足（結論を含む。項目の終わりに読む）：B側
1. 表示「300万で売る」／内心「500万」のズレ → 【論点】1号錯誤（表示錯誤）・重要性（代金200万円差）○
2. Bは定価に戻すのを失念 → 【論点】3項の重過失と例外（規範：重過失で原則取消不可・例外＝相手方の悪意重過失／共通錯誤）
   - あてはめ：「キャンペーン価格」の表示 → Aの悪意・重過失なし（例外不成立）
- 結論：取消しできない（契約は300万で有効）

#### 第1　設問1(2)　錯誤取消しの可否

- 見出しの補足（結論を含む。項目の終わりに読む）：A側
1. 希少価値の動機の齟齬 → 【論点】2号錯誤（基礎事情錯誤）
2. 【論点】2項「基礎事情の表示」の意義（規範：内容化説＝相手方に了解され契約内容となっていたことを要す）
   - あてはめ：Aが希少性をBに伝えた事情も了解の事情もなし
- 結論：取消しできない

#### 第2　設問2　XのY代金請求の可否

1. Zに買受けの代理権なし＝無権代理 → 原則不帰属（113条1項）・追認なし → 表見代理のみ
2. (1) 消滅した抵当権設定の代理権＋越権(売買) → 【論点】112条2項（消滅後＋権限外）の適用

- 結論：正当な理由が認められる限りで代金請求可

- 【拾う事実】『Bが「定価に戻すのを失念」』 → 表意者Bの重過失（3項）の認定根拠
- 【拾う事実】『Aが「希少価値が高いことから購入」』 → 動機＝2号錯誤・2項の表示要件が争点
- 【拾う事実】『Zに「甲土地買受けの代理権なし」』 → 無権代理＝原則不帰属（113条1項）
- 【拾う事実】『与えた／表示した代理権は「抵当権設定」』 → 売買はその範囲を超える＝112条2項・109条2項（2項型）
- 【ポイント】型に載せると関門が浮かぶ
  - (1)＝表示300万／内心500万＝1号。因果・重要（200万円差）はOK → 関門は3項の重過失（Bの失念）。(2)＝希少価値の動機の齟齬＝2号 → 関門は2項の表示要件。1号か2号かを取り違えると以降の要件が総崩れになる。
- 【効く事実】「関門」のあてはめで使う事実
  - (1) 重過失 → 「価格を定価に戻すのを失念」＋価格管理を業とする販売業者／例外の否定 → 「キャンペーン価格」の記載でAは安値を疑えず（Aの悪意・重過失なし）。(2) 表示要件の否定 → Aが希少性をBに伝えた事情も、Bが了解した事情もない。
- 【規範の要点】112条2項・109条2項の規範
  - 基本権限（消滅前の代理権／代理権授与表示）はいずれも「抵当権設定」に限られ、今回の「売買」はその範囲を超える。1項本文では越権部分を捕捉できないため、110条の趣旨を取り込んだ2項（消滅後＋権限外＝112条2項／授与表示＋権限外＝109条2項）による。要件は正当な理由（＝越権部分につき代理権ありと信じ、そう信じることに過失がない＝善意無過失）。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 設問1(2)：Aの誤信がBの説明で生じたなら詐欺（96条）・消費者契約法も。しかし本問はAの一方的誤信で、Bが希少性を述べた事情はない＝95条2号の枠内で足りる。設問2：表見代理が不成立なら、XはZに117条（履行又は損害賠償）を追及しうる（Y請求とは別ルート）。
- 【まぎらわしい選択肢・論点】93条心裡留保の成否／詐欺取消し（96条）の成否／110条単独適用の可否
- 【まぎらわしい選択肢・結論】取消しできる／有権代理として有効
- 【まぎらわしい選択肢・規範】単純表示説／一元論
- 【まぎらわしい選択肢・事実】動機の表示があった／正当な理由あり

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

設問1(1)＝表示300／内心500で1号錯誤、重要（200万差）、でもBの失念＝3項重過失、キャンペーン価格でAの悪意・重過失なし＝取消不可。(2)＝希少価値の動機で2号錯誤、2項は内容化説、表示・了解なし＝取消不可。設問2＝無権代理で不帰属（113条1項）、追認なし→表見代理、(1)消滅後＋越権＝112条2項／(2)授与表示＋越権＝109条2項、正当理由（善意無過失）が認められる限りで代金請求可。

## 3. 規範クイズ（全4問・1問目から最後まで全部出す）

- **［規範クイズ 1/4］** 錯誤による意思表示の取消し（95条）の要件を、1号（表示錯誤）と2号（基礎事情錯誤）に分けて挙げよ。
  - 模範解答：共通：①その錯誤に基づく意思表示（因果性）②法律行為の目的・取引上の社会通念に照らして重要（1項柱書）。1号＝意思表示に対応する意思を欠く錯誤（表示錯誤）。2号＝表意者が法律行為の基礎とした事情の認識が真実に反する錯誤（基礎事情錯誤）＋その事情が法律行為の基礎とされていることが表示されていたこと（2項）。さらに重過失による制限（3項）とその例外を検討。
- **［規範クイズ 2/4］** 表意者に重大な過失があっても、なお錯誤取消しができる例外（95条3項各号）を挙げよ。
  - 模範解答：①相手方が表意者に錯誤があることを知り、又は重大な過失によって知らなかったとき（3項1号＝相手方の悪意・重過失）。②相手方が表意者と同一の錯誤に陥っていたとき（3項2号＝共通錯誤）。重過失で切って終わらせず、例外の不成立まで一言触れるのが丁寧な答案。
- **［規範クイズ 3/4］** 基礎事情の錯誤（95条1項2号）における2項「表示されていた」の意義について、有力な内容化説の規範を述べよ。
  - 模範解答：単に基礎事情が相手方に表示されただけでは足りず、当該事情が相手方に了解され、法律行為の内容となっていたことを要すると解する。取引の安全を図りつつ、相手方の予測可能性を確保するため。改正後の最高裁判例は未確立なので、旧法下の判例法理（動機の表示による要素性）と学説を踏まえて根拠づける。
- **［規範クイズ 4/4］** 代理権消滅後に、その代理権の範囲を超えてされた行為につき本人が責任を負う要件（112条2項）を挙げよ。
  - 模範解答：①かつて他人に代理権を与えたこと、②その代理権の消滅後に、③その範囲を超えて代理行為がされたこと、④相手方が代理権の消滅の事実を知らず、かつ知らなかったことに過失がないこと（112条1項の善意無過失）、⑤越権部分につき代理権があると信ずべき正当な理由（＝善意無過失）。正当な理由は110条の正当理由と同義。

## 4. ○×クイズ（全7問・1問目から最後まで全部出す）

- **［○×クイズ 1/7］** 錯誤による意思表示の取消し（民法95条）は、原則として錯誤に陥った表意者（及びその代理人・承継人）のみが主張でき、相手方の側から取消しを主張することはできない。
  - 正解：○（正しい）
  - 理由：錯誤取消しは表意者を保護する制度だから、取消権者は表意者側（120条2項参照）に限られる。誰が取消しを主張しうるかを最初に確定すると、設問1(1)は表意者B、(2)は表意者Aと、検討の主体がぶれない。
- **［○×クイズ 2/7］** 錯誤による意思表示の効果は、平成29年改正後も「無効」であり、「取消し」ではない。
  - 正解：×（誤り）
  - 理由：平成29年改正で錯誤の効果は「無効」から「取消し」に改められた（95条1項）。取消しは表意者側のみが主張でき、追認・第三者保護（4項）とも整合する。
- **［○×クイズ 3/7］** 無権代理行為は、本人が追認しない限り本人に対して効力を生じない（113条1項）。無権代理行為の相手方が本人に履行を求めるには、本人の追認があるか、又は表見代理が成立することを要する。
  - 正解：○（正しい）
  - 理由：無権代理の効果は本人に不帰属が原則（113条1項）。相手方が本人へ履行（本問ならX→Yの代金請求）を求める道は、①追認（116条で遡及有効）②表見代理の成立の2つだけ。本問は追認がないから、検討対象は表見代理に絞られる。
- **［○×クイズ 4/7］** 錯誤が「法律行為の目的及び取引上の社会通念に照らして重要」（95条1項柱書）と認められれば、その錯誤が表意者の重大な過失によるものであっても、表意者は当然に意思表示を取り消すことができる。
  - 正解：×（誤り）
  - 理由：重要性を満たしても、錯誤が表意者の重大な過失によるときは取消しが制限される（95条3項柱書）。重要性だけ認定して取消しを認めるのは典型的失点。もっとも相手方の悪意・重過失（3項1号）や共通錯誤（3項2号）があれば、なお取消しができる。
- **［○×クイズ 5/7］** 基礎事情の錯誤（95条1項2号）による取消しは、表意者がその基礎事情を相手方に一方的に告げてさえいれば、相手方がこれを了解し契約内容となっていなくても、常に認められる。
  - 正解：×（誤り）
  - 理由：内容化説によれば、単に表示されただけでは足りず、当該事情が相手方に了解され法律行為の内容となっていたことを要する（取引安全・予測可能性）。設問1(2)は、Aが希少性をBに伝えた事情も了解の事情もないから、いずれの説でも2項の要件を欠き取消不可。
- **［○×クイズ 6/7］** 本人が与えた基本代理権（又は代理権授与表示）が「抵当権設定」に限られている場合でも、代理人がその範囲を超えて「売買」をしたときは、110条を単独で適用すれば足り、109条2項・112条2項による必要はない。
  - 正解：×（誤り）
  - 理由：110条単独は基本代理権が現存する越権型の規律。本問(1)は代理権が既に消滅した後の越権だから112条2項、(2)は代理権を与えず授与表示したにとどまる越権だから109条2項による（いずれも110条の趣旨を取り込んだ重畳型を条文化したもの）。
- **［○×クイズ 7/7］** 表見代理が成立する場合であっても、無権代理行為の相手方は、表見代理の成立を主張せず、無権代理人に対して民法117条の責任（履行又は損害賠償）を追及することを選択できる（判例）。
  - 正解：○（正しい）
  - 理由：判例（最判昭62.7.7）は、相手方は表見代理の主張と117条の無権代理人責任の追及を選択できるとする。表見代理は相手方保護の制度だから、相手方に不利益に働かせない趣旨。本問はX→Y請求に絞られるため117条は結論に直結しないが、体系的位置づけとして押さえる。
