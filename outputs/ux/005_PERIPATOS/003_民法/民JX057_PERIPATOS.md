## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

甲と乙は隣人同士であったが、ある日、乙は甲宅よりガスの臭いが漂ってくることから、甲宅をのぞいてみたところ、ガス中毒により甲が倒れているのを発見した。乙は、甲を助けようと思い、甲宅のドアや窓を調べたが、全て施錠されていたことから、甲宅の窓ガラスを割って甲宅内に立ち入り、甲を丙病院に連れて行き治療を受けさせたところ、甲は一命を取り留めた。なお、いまだ治療費は支払われていない。乙は、甲宅に立ち入った際、甲宅内にあった絵画（Aの作品、時価100万円、以下「本件絵画」という。）を持ち出し、これを乙が経営している画廊に出品したところ、Aの作品の収集家であり事情を知らない丁が画廊に訪れ、本件絵画を大変気に入ったため、時価を大幅に上回る300万円で買い受けた。丁は、本件絵画が乙の物であると信じており、このことについて過失はなかった。この場合の甲乙間、甲丙間、及び甲丁間の法律関係について論じなさい。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 甲がガス中毒で自宅で倒れる／隣人乙が発見
- 乙、施錠のため窓ガラスを割り立入り・甲を丙病院へ搬送
- 甲は一命をとりとめる（治療費は未払い）
- 乙、立入りの際に本件絵画（時価100万）を持ち出す
- 乙、画廊に出品→善意無過失の丁が300万で買受け

- 丁｜善意無過失の買主（→画廊で300万円で購入）

### 入口の問い（3問）

- **［入口 1/3・事案の整理］** 当事者ごとに「考えられる請求」を挙げて
  - 答え：甲乙間は請求が3本。①甲→乙の窓ガラス損壊の賠償 ②乙→甲の治療費（費用償還・代弁済）③甲→乙の売却益300万円の返還。
  - 答え：甲丙間は丙→甲の治療費請求が立つか。甲丁間は甲→丁の絵画返還請求。「誰が請求する側か」を取り違えないのが第一歩。
- **［入口 2/3・見当づけ］** 各請求は「どの条文が根拠か」 ― 見当をつけて
  - 答え：窓ガラス＝不法行為（709条）を緊急事務管理（698条）が軽減。治療費＝費用償還・代弁済（702条）。売却益＝不当利得（703条）／準事務管理。丙の請求＝治療契約が甲に帰属するか（無権代理・113条）。絵画返還＝即時取得（192条）と盗品回復（193条・194条）。 管理者が本人の身体・名誉・財産に対する急迫の危害を免れさせるために事務管理をしたときは、悪意又は重大な過失がなければ、これによって生じた損害を賠償する責任を負わない。
- **［入口 3/3・論点］** 甲乙間で問題になる論点を挙げて（2つ）
  - 答え：CP①：時価超過分の200万円 → 準事務管理の肯否。（他人の事務を自己のために処理した者にも事務管理規定を準用し儲け分を吐き出させるか）

### 骨子（3項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　甲乙間の法律関係

1. 窓ガラス損壊 → 【論点】緊急事務管理（698条） → 悪意・重過失なし → 賠償責任なし
2. 治療費（未払い）→ 代弁済（702条2項・650条2項）／支払済みなら費用償還（702条1項）
3. 売却益300万 → 【論点】準事務管理の肯否 → 否定説（利他的行為の前提）
   - あてはめ：時価100万は損失に対応／200万は乙の才覚＝損失に対応せず
4. 【論点】不当利得の返還範囲 → 損失対応で100万に限定（704条・悪意の受益者）
- 結論：甲は乙に 時価100万円の限度で請求可

#### 第2　甲丙間の法律関係

1. 丙→甲の治療費請求＝甲丙間に治療契約が要る
2. 乙が自己のため契約 → 乙丙間に成立 → 丙は甲に請求不可
3. 乙が甲を代理 → 【論点】事務管理は代理権を生むか → 対内的関係説（最判昭36.11.30）
   - あてはめ：追認なし → 効果不帰属（113条1項）
- 結論：丙は甲に治療費を請求できない（丙は乙に117条責任）

#### 第3　甲丁間の法律関係

1. 甲→丁の所有権に基づく返還請求
2. 丁は取引・平穏公然・善意無過失で占有取得 → 【論点】即時取得（192条）成立 → 甲は所有権喪失
3. 本件絵画は盗品 → 回復請求（193条）／同種商人からの善意買受け → 【論点】代価弁償（194条）
- 結論：甲は 300万円を弁償しなければ回復できない

- 【事案の整理】箱を先に作る
  - 「◯◯間の法律関係」型は、当事者ペアの箱を先に用意すると請求の漏れが出ない。甲乙間＝窓ガラス・治療費・絵画の売却益／甲丙間＝治療費／甲丁間＝絵画の返還。1つの箱に複数の請求が入ることに注意（甲乙間は3つ）。
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 窓ガラス＝698条で軽減＝賠償なし／治療費＝702条で処理／絵画の時価100万円は甲の損失に対応するので不当利得・不法行為で回収可＝一言。止まるのは「時価を超える200万円まで返還させられるか」の一点。
- 【効く事実】あてはめで使う事実
  - 準事務管理否定 → 事務管理は「他人のためにする意思」＝利他性を前提／返還範囲 → 甲の損失＝客観的価値100万円・時価超過200万円は乙の画商としての才覚による利得／均衡 → 絵画自体を取り戻せても甲が把握するのは100万円。
- 【規範の要点】対内的関係説の規範
  - 事務管理は本人・管理者間の対内的な法律関係を規律するにとどまり、管理者に代理権を発生させない（最判昭36.11.30）。代理権は本人の授権か法律の規定で発生する。→ 乙が甲を代理しても、甲の追認（116条）なき限り効果不帰属（113条1項）。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 「盗品＋即時取得」ときたら193・194はセット。乙は画廊経営＝「その物と同種の物を販売する商人」なので194条が働き、甲は丁が支払った300万円を弁償しなければ回復できない。締めに治療費の循環（丙は甲に請求不可 → 丙は乙に117条責任 → 乙は甲に費用償還・代弁済）を一文添えると事案全体の理解が伝わる。
- 【まぎらわしい選択肢・論点】表見代理の成否／転用物訴権の可否／占有改定による即時取得
- 【まぎらわしい選択肢・結論】300万円全額の返還を請求できる／丙は甲に治療費を請求できる
- 【まぎらわしい選択肢・規範】準事務管理肯定説／対外的効果肯定説
- 【まぎらわしい選択肢・事実】悪意・重過失あり／占有改定による取得

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

甲乙間＝窓ガラスは緊急事務管理で賠償なし、治療費は費用償還・代弁済、売却益は準事務管理否定＋不当利得は損失対応で100万円だけ。甲丙間＝事務管理は代理権を生まない（最判昭36.11.30）、追認なければ効果不帰属、丙は乙に117条責任。甲丁間＝即時取得で所有権喪失、盗品だが同種商人からの善意買受けで194条、300万円弁償しないと回復不可。

## 3. 規範クイズ（全4問・1問目から最後まで全部出す）

- **［規範クイズ 1/4］** 他人の事務を自己のために処理して利益を得た者に事務管理規定を準用する「準事務管理」を否定する理由と、否定した場合の売却益の処理の仕方を述べよ。
  - 模範解答：事務管理は相互扶助の精神に基づく利他的行為を前提とする制度であり、他人の事務を自己のために処理する利己的行為に事務管理規定（701条→646条）を準用するのは制度趣旨に反し無理がある＝準事務管理否定（通説）。否定した以上、利得の処理は不当利得（侵害利得）・不法行為の一般法理に委ね、返還範囲は損失に対応する限度（客観的価値100万円）にとどまる。
- **［規範クイズ 2/4］** 不当利得で時価超過分（本問の200万円）の返還を否定する論拠を、「損失対応」に加えてもう一つ（物権的返還請求との均衡）挙げて述べよ。
  - 模範解答：①損失対応＝甲の損失は目的物の客観的価値100万円にとどまるため、超過分は損失に対応せず返還の対象外となる。②物権的返還請求との均衡＝仮に甲が目的物自体を取り戻せても把握しえた価値は100万円であり、取り戻せない場合にかえって300万円を得られるのは物権的返還請求とのバランスを失するので、この均衡からも返還範囲は100万円に画される（結論）。この均衡論を一言添えると不当利得の本質理解を示せる。
- **［規範クイズ 3/4］** 事務管理者が本人の名で第三者と契約しても効果が本人に当然には帰属しない理由と、相手方（本問の丙）の救済手段を挙げよ。
  - 模範解答：理由＝事務管理は本人・管理者間の対内的関係を規律するにとどまり、代理権を発生させない。代理権は本人の授権か法律の規定によって生じるものであって、事務管理はそのいずれでもない（最判昭36.11.30・対内的関係説）。救済＝相手方は①本人の追認（116条）を得るか、②無権代理人の責任（117条1項）を追及して履行又は損害賠償を求めうる。
- **［規範クイズ 4/4］** 即時取得が成立した動産が盗品であった場合について、被害者による回復請求の可否と、代価弁償が必要となる場合を場合分けして述べよ。
  - 模範解答：盗品・遺失物は、被害者・遺失者が盗難・遺失の時から2年間、占有者に回復を請求できる（193条）。もっとも占有者が競売・公の市場・同種の物を販売する商人から善意で買い受けた場合は、被害者は占有者が支払った代価を弁償しなければ回復できない（194条）。194条の「善意」は192条の特則として無過失まで要求するのが一般。弁償まで占有者は使用収益権を有し使用利益の返還義務を負わない（最判平12.6.27）。

（規範クイズはここまで＝全4問。最後の4問目まで出したら「規範クイズ、全4問クリア！」と言って次へ）

## 4. ○×クイズ（全8問・1問目から最後まで全部出す）

- **［○×クイズ 1/8］** 法律上の義務がないのに他人のためにその事務の管理を始めた者は、原則としてその事務の性質に従い最も本人の利益に適合する方法で管理する義務を負い、有益費を支出したときは本人に償還を請求できる。
  - 正解：○（正しい）
  - 理由：事務管理（697条）の基本。義務なく他人の事務を管理する者は本人の利益に適合する管理義務を負う一方、支出した有益費は費用償還請求権（702条1項）で回収できる。この骨格を押さえると、救助・治療をめぐる甲乙間の処理が一気に見通せる。
- **［○×クイズ 2/8］** 管理者が本人の身体・名誉・財産に対する急迫の危害を免れさせるために事務管理をしたときは、悪意又は重大な過失がなければ、これによって生じた損害を賠償する責任を負わない。
  - 正解：○（正しい）
  - 理由：緊急事務管理（698条）の効果そのもの。救助行為を萎縮させないための政策的軽減で、責任は悪意・重過失に限定される。窓ガラスを割った点は709条の不法行為が問題になるが、698条により悪意・重過失なき乙は賠償責任を負わない。
- **［○×クイズ 3/8］** 事務管理者が本人のために有益な費用を現実に支出した場合は費用の償還を請求でき、いまだ弁済せず有益な債務を負担したにとどまる場合は、本人に対し自己に代わって弁済することを請求できる。
  - 正解：○（正しい）
  - 理由：費用償還（702条1項）＝現実に支出した場合、代弁済（702条2項が準用する650条2項）＝まだ債務を負担しただけの場合、と支払の有無で分かれる。本問は「いまだ治療費は支払われていない」ので代弁済が主役。両者の混同は典型的な失点。
- **［○×クイズ 4/8］** 不当利得の返還範囲は、受益と損失とが表裏一体の関係に立つことから、損失者が被った損失（目的物の客観的価値）に対応する限度で画される。
  - 正解：○（正しい）
  - 理由：不当利得は損失の填補を目的とする制度なので、返還範囲は損失に対応する限度で画される（損失対応説）。本問で甲が失った価値は絵画の客観的価値100万円であり、時価を超える200万円は乙の画商としての才覚による利得＝甲の損失に対応しない。
- **［○×クイズ 5/8］** 他人の物を法律上の原因なく処分した悪意の受益者は、その受けた利益に利息を付して返還すればよく、損失者になお損害があってもその賠償の責任までは負わない。
  - 正解：×（誤り）
  - 理由：悪意の受益者は、受けた利益に利息を付して返還し、なお損害があるときはその賠償の責任も負う（704条後段）。もっとも返還範囲自体は損失に対応する限度（本問では客観的価値100万円）で画される点は動かない。利息付返還と返還範囲の画定は別の話。
- **［○×クイズ 6/8］** ある者の給付が第三者に利益をもたらした場合、受益と損失の間に因果関係がありさえすれば、当該第三者に対する不当利得返還請求は当然に認められる。
  - 正解：×（誤り）
  - 理由：受益と損失に因果関係があるだけで機械的に不当利得を認めることはできず、第三者が対価関係で負担をしたか等を考慮し、法律上の原因の有無・受益と損失の実質的対応を判断する（転用物訴権に関する最判平7.9.19の枠組み）。本問でも「因果関係あり」で300万円全部を吐き出させるのは誤りで、損失に対応する100万円に画される。
- **［○×クイズ 7/8］** 事務管理が成立している場合、管理者が本人の名で第三者との間でした法律行為の効果は、本人の授権や追認がなくても、事務管理の成立を根拠として当然に本人に帰属する。
  - 正解：×（誤り）
  - 理由：事務管理は本人・管理者間の対内的関係を規律するにとどまり、対外的な効果帰属（代理権）を生じない（最判昭36.11.30）。効果を本人に帰属させるには別に授権・追認等が必要。
- **［○×クイズ 8/8］** 占有者が盗品を、競売若しくは公の市場において、又はその物と同種の物を販売する商人から善意で買い受けたときは、被害者は、占有者が支払った代価を弁償しなければ、その物を回復することができない。
  - 正解：○（正しい）
  - 理由：194条の代価弁償の要件そのもの。193条で回復請求できても、取得ルートが競売・公の市場・同種商人であれば取引安全に配慮して代価弁償が回復の条件になる。本問の丁は画廊経営の乙（同種商人）から善意無過失で購入したので、甲は300万円を弁償しないと絵画を回復できない。

（○×クイズはここまで＝全8問。最後の8問目まで出したら「○×クイズ、全8問クリア！」と言って復習へ）
