### 問題文（最初にゆっくり読み上げる）

【小問1】Aは、その所有する一筆の土地を甲土地と乙土地に分筆した上、甲土地をBに売却したが、分筆により甲土地は公道に一切接しない袋地となった。そこでAB間で、乙土地の一部（本件土地）について、甲土地を要役地とする無償かつ無期限の通行地役権が設定されたが、通行地役権設定登記はされなかった。以降Bは、本件土地をコンクリート舗装するなどして甲土地のための通路として継続的に使用していた。その後、AがCに乙土地を売却して所有権移転登記も済ませたところ、CはBの通行を認めないと主張した。そこでBはCに対し通行地役権を有することの確認を求めた。なおCは、乙土地から約100メートルの距離に自宅があったが、乙土地購入当時、通行地役権の設定もBの使用も知らなかった。Bの請求は認められるか。【小問2】材木加工業を営むDは、2020年4月1日から、E所有の丙土地を平穏・公然と材木置場として利用し、現在も利用している。2041年4月1日、Dのライバル業者Fは、Dの事業を妨害する目的でEから丙土地を買い受け、所有権移転登記を経た。これを知ったDはFに対し丙土地の所有権確認及び所有権移転登記手続を求めた。なおFは、丙土地購入当時、Dの利用開始時期を正確には把握していなかったが、少なくとも10年以上利用していることは知っていた。Dの請求は認められるか。

### 入口の問い（3問）

- **Q01［事案の整理］** 「誰が・誰に・何を」求めているかを挙げて
  - 答え：検討の的は「登記なくして物権を主張する者（B・D）」と「それを拒む登記名義人（C・F）」の対立。A・Eは物権変動の当事者で、対抗問題の相手方ではない。
  - 答え：二つの小問は独立だが、勝負所は同じ一点＝「相手（C・F）は177条の『第三者』か」に収束する。ここを見抜くのが第一歩。
- **Q02［見当づけ］** 各請求の「法的根拠」と対抗の枠組み ― 見当をつけて
  - 答え：両小問とも「登記なき物権 vs 登記ある譲受人」＝177条の対抗問題。そこで「第三者」を制限説で定義し、相手を第三者から外せないか探す。小問1は平10（通行地役権）、小問2は平18（背信的悪意者）という別ルートで外すのが狙い。
- **Q03［論点］** 各小問で「詰まる所（論点）」を挙げて（1つ）
  - 答え：小問1のCP：Cは第三者か → 通行地役権の承役地譲受人の第三者性（平10の二要件＋特段の事情）。（＝継続的通路使用が物理的状況から客観的に明らか＋譲受人が認識可能）

#### 第1　小問1

#### 第2　小問2

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】『袋地・コンクリート舗装・継続的に通路使用』 → 平10要件①＝物理的状況から客観的に明らか
- 【拾う事実】『Cの自宅は乙土地から約100m』 → 平10要件②＝認識可能性
- 【拾う事実】『Cは地役権設定もBの使用も「知らなかった」』 → 善意（＝結論を左右しない引っかけ）
- 【拾う事実】『Fの取得は2041年＝時効完成後』 → 完成後の第三者→原則登記必要
- 【拾う事実】『Fは「事業妨害目的」＋10年超の利用を認識』 → 背信性＋悪意性＝背信的悪意者
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 小問1＝地役権設定（物権変動）・設定登記なし・要役地便益 vs 承役地所有権（対抗関係）は一言で通す。小問2＝Dの時効取得（162条・186条1項で自主占有推定）もほぼ争いなし。詰まるのは相手（C・F）が第三者かの一点だけ。
- 【効く事実】「Cは第三者か（平10の二要件）」のあてはめで使う事実
  - 要件①客観的明白性 → 甲土地は袋地／本件土地はコンクリート舗装・継続的通路使用＝物理的状況から客観的に明らか。要件②認識可能性 → Cの自宅は乙土地から約100mの至近＝容易に認識し得た。Cが「知らなかった」（善意）は結論を左右しない（認識可能性で足りる）。特段の事情なし。
- 【規範の要点】背信的悪意者・平18の規範
  - 登記の欠缺を主張することが信義則に反する背信的悪意者は「第三者」に当たらない。時効事案では、取得時効の成立要件を具体的にすべて認識していなくても、占有者による多年にわたる占有継続の事実を認識し、登記の欠缺を主張することが信義に反する事情があれば背信的悪意者に当たる。Fは10年超の利用を認識（悪意性）＋妨害目的（背信性）→ 背信的悪意者。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 違いの理由＝通行地役権は無償・無期限で人的信頼に基づき設定され、設定登記が省略されがち。譲受人が背信的悪意者に当たる場面は稀なので、客観的状況（物理的状況＋認識可能性）で直接第三者性を否定する枠組みを別途用意した（平10）。一方、時効事案は悪意性＋背信性で除外する（平18）。「同じ制限説の二つの運用で矛盾しない」の一言が理解を示す。
- 【まぎらわしい選択肢・論点】囲繞地通行権の成否／通行地役権の時効取得／即時取得の成否
- 【まぎらわしい選択肢・結論】Bの請求は認められない／Dの請求は認められない
- 【まぎらわしい選択肢・規範】無制限説／占有尊重説
- 【まぎらわしい選択肢・事実】登記の先後で決する／Fは善意の第三者

## 3. 規範クイズ（3問）

- **Q04［規範］** 取得時効と登記について、時効完成前の第三者と完成後の第三者で処理がどう分かれるか、その根拠とともに述べよ。
  - 模範解答：時効完成前の第三者に対しては、時効取得者は当事者類似の地位にあり登記なくして対抗できる。時効完成後の第三者に対しては、原所有者を起点とする二重譲渡類似の関係に立つため登記が必要（昭33.8.28）。そして起算点は現実の占有開始時に固定され逆算は許されない（昭35.7.27）から、完成前後は動かせない。
- **Q05［規範］** 通行地役権の承役地が譲渡された場合に、譲受人が登記の欠缺を主張する正当な利益を有する「第三者」に当たらないとされるための要件を述べよ（最判平10.2.13）。
  - 模範解答：①譲渡の時に、承役地が要役地所有者によって継続的に通路として使用されていることが、その位置・形状・構造等の物理的状況から客観的に明らかであり、②譲受人がそのことを認識していたか又は認識することが可能であったとき。この場合、譲受人は地役権設定を知らなかったとしても、特段の事情がない限り第三者に当たらない。②が「認識可能性」で足りる点（善意でも否定されうる）が急所。
- **Q06［規範］** 時効取得の事案で、第三者が背信的悪意者に当たるための要件を述べよ。とくに悪意性（認識の対象）がどこまで緩和されるかに触れよ（最判平18.1.17）。
  - 模範解答：①悪意性＝取得時効の成立要件をすべて具体的に認識している必要はなく、少なくとも占有者による多年にわたる占有継続の事実を認識していれば足りる（時効の成否は外部から判断しにくいための緩和）。②背信性＝登記の欠缺を主張することが信義に反すると認められる事情の存在。両者を満たせば「第三者」から除外され、時効取得者は登記なくして対抗できる。

## 4. ○×クイズ（7問）

- **Q07［○×］** 地役権は物権であり、その設定・変更は、登記をしなければ第三者に対抗することができない（280条・177条）。
  - 正解：○（正しい）
  - 理由：地役権は用益物権（280条）だから、その得喪変更は177条の対抗要件主義に服する。本問の通行地役権は設定登記がないので、Bは原則としてCに対抗できない――ここが小問1の出発点。まず「地役権＝物権→177条」を一言据えるのが土台。
- **Q08［○×］** 177条の「第三者」とは、当事者及びその包括承継人以外のすべての者を指し、登記の欠缺を主張する正当な利益の有無を問わない。
  - 正解：×（誤り）
  - 理由：これは無制限説で、判例・通説は採らない。判例（大連判明41.12.15）は制限説を採り、「第三者」を登記の欠缺を主張するについて正当な利益を有する者に限定する。無権利者・不法占拠者・背信的悪意者はここから除外される。本問の崩し方はすべてこの制限説から出発する。
- **Q09［○×］** 取得時効の起算点は占有を現実に開始した時点に固定され、時効取得者がこれを任意に選択・繰り下げて主張することは許されない。
  - 正解：○（正しい）
  - 理由：最判昭35.7.27。起算点を動かせるとすると、完成後の第三者を「完成前の第三者」に転換して登記不要にでき、判例準則を潜脱できてしまう。これを封じるため起算点は現実の占有開始時に固定する。本問のFは、Dの占有開始（2020年）を起点とすれば、取得（2041年）は時効完成後の第三者に確定する。
- **Q10［○×］** 時効による不動産所有権の取得も物権変動であり、時効取得者は、登記を経なければ時効完成後に原所有者から当該不動産を譲り受け登記を備えた第三者に、時効取得を対抗することができない。
  - 正解：○（正しい）
  - 理由：最判昭33.8.28。177条は意思表示によらない物権変動（時効取得）にも適用され（全物権変動説）、時効完成「後」の第三者と時効取得者は、原所有者を起点とする二重譲渡類似の対抗関係に立つ。ゆえに登記を備えたFに対し、Dは原則として時効取得を対抗できない。ここが小問2の原則＝一度負ける段。
- **Q11［○×］** 通行地役権の承役地譲受人は、地役権が設定されていることを現に知らなかった（善意）以上、承役地の継続的通路使用が物理的状況から客観的に明らかであっても、常に登記の欠缺を主張する正当な利益を有する「第三者」に当たる。
  - 正解：×（誤り）
  - 理由：平10法理は譲受人の「認識可能性」で足りるとするから、地役権設定を現に知らなかった（善意）としても、客観的利用状況から認識が可能であった以上、第三者性は否定されうる。「善意だから保護される」と書くと判例法理を取り違える＝本問最大の引っかけ。問題文の「知らなかった」はあてはめの罠で、結論を左右しない。
- **Q12［○×］** 背信的悪意者として「第三者」から除外されるには、物権変動があったことを知っている（悪意）だけでは足りず、登記の欠缺を主張することが信義則に反すると認められる事情（背信性）が必要である。
  - 正解：○（正しい）
  - 理由：単なる悪意者は「第三者」として保護される（自由競争の範囲）。第三者から除外されるのは、悪意に加えて背信性（登記の欠缺を主張することが信義則に反する事情）を備える背信的悪意者に限られる。本問のFは、妨害目的での取得という背信性が備わる点が決め手。
- **Q13［○×］** 通行地役権の承役地譲受人の第三者性を否定するには、譲受人が背信的悪意者に当たることを認定しなければならず、承役地の客観的な物理的状況と認識可能性のみによって直接に第三者性を否定することはできない。
  - 正解：×（誤り）
  - 理由：平10は、通行地役権については背信的悪意者論を経由せず、物理的状況からの客観的明白性＋譲受人の認識可能性という客観的基準で直接に第三者性を否定する枠組みを示した。通行地役権では背信的悪意者に当たる場面が稀で救済に欠けるためである。制限説には「直接否定（平10）」と「背信的悪意者除外（平18）」の二つの運用があり、事案で使い分ける。
