- 【拾う事実】「早急に前記保険金の給付を受けるため」 → 早急・少額満足という別損害説の要件
- 【拾う事実】「12週間分の損害額にも満たなかった」 → 少額の賠償金で満足したことの徴表
- 【拾う事実】「予測ができなかった再手術・後遺症」 → 予想外の損害＝別損害（放棄の対象外）
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 和解の成立＝問題文が前提とするので一言／確定効＝696条を一言で確認。山は③の切り分け。①代金額＝争いの対象そのもの＝内／②ハム品質＝前提にすぎず＝外、と評価語で割る。
- 【効く事実】「95条の要件」のあてはめで使う事実
  - 基礎事情錯誤（2号）→ 「100万円相当の特選丸太ハム」との認識が真実（粗悪品）に反する／表示（2項）→ 「特選丸太ハム1000本・100万円相当」が和解条項に明記／重要性 → 錯誤がなければ和解に至らなかった／重過失なし → 粗悪品と気付かなかったことに重過失なし。効く事実は必ず条文文言と結合させる。
- 【規範の要点】別損害説・最判昭43.3.15の規範
  - 全損害を正確に把握し難い状況で早急に少額の賠償金で満足する旨の示談では、放棄した損害賠償請求権は示談当時予想していた損害に限られ、予想できなかった不測の後遺症・再手術の損害は別損害として確定効が及ばない。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 和解・示談の問題は必ず「何について争い、何を確定したのか」を切り分ける。確定効の外にある事項は、①錯誤（95条）でも②契約の限定解釈（別損害説）でも救済されうる。「和解したから全部終わり」という即断が最大の落とし穴。
- 【まぎらわしい選択肢・論点】詐欺取消しの可否／契約不適合責任の成否／事情変更の原則
- 【まぎらわしい選択肢・結論】①も錯誤取消し可／全部放棄で請求不可
- 【まぎらわしい選択肢・規範】全部放棄説／狭義説
- 【まぎらわしい選択肢・事実】重過失あり／清算条項あり

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

小問(1)①＝代金額は争いの対象そのもの→確定効で遮断→Y取消し不可。小問(1)②＝ハム品質は前提外→確定効及ばず→95条（2号・2項・重要性・重過失なし）で取消し可・100万円請求可。小問(2)＝示談は互譲で和解→別損害説で放棄条項を限定解釈→予想外の後遺症は別損害→Z請求可。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 和解の確定効が及ぶ範囲を画する規範（どこまでが遮断され、どこからが錯誤取消しの余地があるか）を述べよ。
  - 模範解答：和解契約の直接の目的となった法律関係（＝当事者が争いの対象とし互譲によって決定した事項）は、和解によって終結した争いそのものだから錯誤取消しを主張できない。それ以外の事項（前提・基礎として争わず疑わなかった事項を含む）には確定効が及ばず、錯誤取消しの余地がある。
- **［規範クイズ 2/3］** 基礎事情（動機）の錯誤（95条1項2号）を理由に意思表示を取り消すために必要な要件を、条文の順に挙げよ。
  - 模範解答：①法律行為の基礎とした事情についての認識が真実に反する錯誤（1項2号）②その事情が法律行為の基礎とされていることの表示（2項）③錯誤が法律行為の目的・取引通念に照らし重要であること（1項柱書）④表意者に重大な過失がないこと（3項柱書。例外＝各号）。②の表示要件が動機錯誤特有の関門。
- **［規範クイズ 3/3］** 別損害説（示談後の後遺症損害の救済）の規範と、放棄条項を限定解釈する根拠を述べよ。
  - 模範解答：規範＝全損害把握困難な状況で早急に少額で満足する示談における放棄の対象は、示談当時予想していた損害に限られ、予想外の後遺症・再手術の損害は別損害として和解の対象外（確定効及ばず）。根拠＝予想もしなかった損害まで放棄する意思はないのが通常であり、放棄条項を当事者の合理的意思に照らして限定解釈するのが相当だから。示談自体は有効に維持しつつ放棄範囲だけを絞る点で錯誤構成より穏当。

（規範クイズはここまで＝全3問。最後の3問目まで出したら「規範クイズ、全3問クリア！」と言って次へ）

## 4. ○×クイズ（全8問・1問目から最後まで全部出す）

- **［○×クイズ 1/8］** 和解契約が成立するには、当事者間に争いがあり、かつ当事者双方が互いに譲歩（互譲）していることを要する。一方のみが譲歩する場合は和解に当たらない。
  - 正解：○（正しい）
  - 理由：和解（695条）は「当事者が互いに譲歩してその間に存する争いをやめることを約する」契約で、①争いの存在②互譲③争いをやめる合意を要する。一方だけが譲る場合は単なる債務の承認・免除であって和解ではない。示談の性質決定でこの互譲の有無を最初に確かめる。
- **［○×クイズ 2/8］** 和解が成立すると、和解の目的とした争いの対象そのものはもちろん、その前提として当事者双方が争わず疑わなかった事実に錯誤があった場合でも、確定効（696条）により一切錯誤取消しを主張できなくなる。
  - 正解：×（誤り）
  - 理由：確定効が及ぶのは「争いの対象となった事項」に限られる。前提として双方が争わず疑わなかった事項の錯誤には確定効は及ばず、錯誤取消しの余地がある（最判昭33.6.14＝特選金菊印苺ジャム事件）。「和解したから全部ダメ」で切ると大失点。
- **［○×クイズ 3/8］** 和解の目的である「争いの対象そのもの」（当事者が互譲によって決めた事項）について錯誤があった場合には、和解の確定効が及び、原則として錯誤取消しを主張できない。
  - 正解：○（正しい）
  - 理由：和解契約の直接の目的となった法律関係（争いの対象・互譲で決定した事項）は和解によって終結した争いそのものだから、後に異なる確証が出ても696条により確定し、これと矛盾する主張（＝錯誤取消し）はできない。小問(1)①の未払代金額がこれに当たる。
- **［○×クイズ 4/8］** 当事者が和解の前提として争わずかつ疑わなかった事項（目的物の品質等）に錯誤があった場合には、和解の確定効は及ばず、錯誤取消しを主張しうる（最判昭33.6.14）。
  - 正解：○（正しい）
  - 理由：特選金菊印苺ジャム事件（最判昭33.6.14）は、和解の目的たる事項ではなく、その前提ないし基礎として当事者双方が争わず疑わなかった品質の錯誤には確定効が及ばず、和解の効力を否定できるとした。本問②の「特選丸太ハムが粗悪品」は同判例と構造が完全に一致する。
- **［○×クイズ 5/8］** 基礎事情（動機）の錯誤による取消しは、表意者に重大な過失があった場合であっても、常に認められる。
  - 正解：×（誤り）
  - 理由：錯誤が表意者の重大な過失によるものであった場合には、原則として取消しをすることができない（95条3項柱書）。例外は、相手方が悪意・重過失で知らなかったとき、又は相手方が同一の錯誤に陥っていたとき（各号）。本問②はXに重過失を基礎づける事情がないから取消し可。
- **［○×クイズ 6/8］** 全損害を正確に把握し難い状況の下で、早急に少額の賠償金で満足する旨の示談がされた場合、放棄された損害賠償請求権は示談当時予想していた損害に限られ、当時予想できなかった不測の後遺症等の損害には及ばない（最判昭43.3.15）。
  - 正解：○（正しい）
  - 理由：別損害説（最判昭43.3.15）は、放棄条項を当事者の合理的意思に照らして限定解釈し、放棄の対象を「示談当時予想していた損害」に限る。予想外の損害は放棄されておらず別損害として請求できる。錯誤（95条）によらず契約解釈で被害者を救済する点に特色がある。
- **［○×クイズ 7/8］** 交通事故の被害者が加害者の負う損害賠償義務の一部を放棄する示談は、被害者の一方的な放棄によって成立し、加害者側の譲歩がなくても和解契約（695条）としての性質を有する。
  - 正解：×（誤り）
  - 理由：和解契約性には互譲が必要（695条）。一方が放棄するだけでは和解ではない。本問では、Zが超過分請求権を放棄し、Xが早期に保険金相当額の支払に応じる点で相互の譲歩があるから和解契約と性質決定できる。互譲の有無を必ず確認する。
- **［○×クイズ 8/8］** 損害賠償をめぐる争いを、当事者が互いに譲歩してやめる合意である示談は、和解契約（695条）としての性質を有し、その損害賠償義務の範囲には和解の確定効（696条）が及びうる。
  - 正解：○（正しい）
  - 理由：示談は多義的だが、互譲により損害賠償の争いをやめる合意であれば和解契約（695条）に当たり、損害賠償義務の範囲は和解の直接の目的となった法律関係として確定効の対象となる。だからこそ、予想外の後遺症損害を救うには別損害説による限定解釈という一手が要る。

（○×クイズはここまで＝全8問。最後の8問目まで出したら「○×クイズ、全8問クリア！」と言って復習へ）
