- 体内アルコール濃度は時間とともに急速に低下・消失の危険

### 入口の問い（5問）

- **Q01［事案の整理］** 捜査機関が行った「処分」を棚卸しする
  - 答え：検討対象は「捜査機関が行った処分」＝呼気採取・血液採取の2つ。被処分者の承諾は失神ゆえ得られていないので、両者とも「承諾なき身体からの証拠採取」として出発する。
- **Q02［見当づけ］** 各処分が「強制っぽい？任意っぽい？」 ― 見当をつけて
  - 答え：呼気＝自然の呼吸で体外に出る空気を採るだけ → 侵害軽微 → 任意処分の方向。血液＝注射針を刺入して身体を損傷 → 強制処分の方向（令状必要）。侵害の質が対極なので結論も割れる、と当たりを付ける。
- **Q03［論点］** 問題になる論点を挙げて（4つ）
  - 答え：CP①：呼気＝有形力・健康侵害なし → 強制処分該当性で任意と認定。（強制処分＝意思に反し重要な権利利益に実質的侵害を加える処分）
  - 答え：CP②：任意でも無制約でない → 任意捜査の限界（比例原則）。（必要性・緊急性と侵害を衡量し相当な限度で許容）
  - 答え：CP③：血液＝身体損傷 → 強制処分（争いなし）＋令状の要否。（法律の根拠があるか＝法定主義／令状を得たか＝令状主義）
  - 答え：CP④：呼気の補助 → 憲法38条1項（供述に当たらない）。
- **Q04［論点］** 呼気の結論と骨を言って（3つ）
  - 答え：①強制処分該当性 → 有形力・健康侵害なし → 任意処分。②任意捜査の限界（比例原則）→ 緊急性高・侵害軽微 → 相当＝適法。③憲法38条1項 → 供述でない → 反しない。→ 呼気は適法。
- **Q05［論点］** 血液の結論と骨を言って（3つ）
  - 答え：①強制処分該当性 → 身体損傷 → 強制（争いなし）。②法定主義／令状主義 → 鑑定処分で根拠あり＝法定主義OK／令状なし＝令状主義違反。③令状の種類 → 鑑定処分許可状＋身体検査令状（実務）／条件付捜索差押許可状説に一言。→ 血液は違法。

### 骨子（3項目。第1から【論点】ごとに、何が問題→規範→使う事実→結論 の順で組み立てる）

#### 第1　呼気の採取の適法性

1. 承諾なき呼気採取は「強制の処分」か → 【論点】強制処分該当性（規範：意思の制圧＋重要な権利利益の実質的侵害）
   - あてはめ：呼気＝自然の呼吸で排出・有形力/健康侵害なし → 任意処分
2. 【論点】任意捜査の限界 → 比例原則（必要性・緊急性と相当性）
   - あてはめ：アルコール濃度の急速な消失＝緊急性高／侵害軽微 → 相当
3. 【論点】呼気検査と憲法38条1項 → 身体状態の把握で「供述」でない → 反しない
- 結論：呼気の採取は適法

#### 第2　血液の採取の適法性

1. 採血＝注射針の刺入・身体の損傷 → 強制処分（争いなし）
2. 【論点】法定主義と令状主義の区別 → 鑑定処分（168）で法律の根拠あり＝法定主義OK／令状なし＝令状主義（憲法35）違反
3. 【論点】令状の種類 → 鑑定処分許可状＋身体検査令状（実務）／条件付捜索差押許可状説（いずれも令状必要）
- 結論：血液の採取は違法

#### 第3　結論の対比

   侵害の質・程度の差（呼気＝軽微・任意／血液＝身体侵襲・強制） → 呼気は適法・血液は違法

## 3. 規範クイズ（3問）

- **Q06［規範］** 捜査における強制処分と任意処分の区別基準（強制処分の定義）を述べよ。
  - 模範解答：強制処分とは、相手方の明示又は黙示の意思に反し、その重要な権利・利益に対して実質的な侵害・制約を加える処分をいう（最決昭51.3.16前段）。これに当たらない処分は任意処分で、比例原則による統制に服する。有形力の有無は基準ではない。
- **Q07［規範］** 任意処分であっても無制約ではない。任意捜査の限界（許容範囲）を画する規範を述べよ。
  - 模範解答：任意処分も、捜査の必要性・緊急性を考慮し、具体的状況の下で相当と認められる限度においてのみ許される（最決昭51.3.16後段＝比例原則）。必要性・緊急性と被処分者の被る不利益とを衡量する。呼気採取は緊急性が高く侵害が軽微ゆえ相当。
- **Q08［規範］** 強制採血に必要な令状の種類を、実務の立場と別説を挙げて述べよ。
  - 模範解答：採血＝鑑定処分と性質決定し、鑑定処分許可状（168条）に、直接強制を可能とする身体検査令状（218条）を併用するのが実務・通説。ほかに、強制採尿（最決昭55.10.23）に準じ条件付捜索差押許可状によるべきとの説もある。いずれによっても令状は必要。

- **Q09［○×］** 強制処分とは有形力（物理的な実力）の行使を伴う処分に限られ、有形力を伴わない処分は常に任意処分である。
  - 正解：×（誤り）
  - 理由：判例（最決昭51.3.16）・通説は有形力を要件から外し、相手方の意思に反して重要な権利・利益に実質的な侵害・制約を加える処分を強制処分とする（実質説）。有形力なきプライバシー侵害（写真撮影・GPS等）も強制処分たりうる。有形力の有無は強制/任意を分ける決め手ではない。
- **Q10［○×］** 憲法38条1項にいう「供述」とは思想・観念の表出をいい、体内アルコール濃度など身体の物理的状態を客観的に把握する行為はこれに含まれない。
  - 正解：○（正しい）
  - 理由：最判平9.1.30（呼気検査）が明示。「供述」＝思想・観念の表出であり、身体の物理的状態の客観的把握（呼気中のアルコール濃度の測定等）は供述に当たらないから、呼気の採取・検査は不利益供述強要の禁止に反しない（供述でない以上、憲法38条1項の射程外）。
- **Q11［○×］** 体内のアルコール濃度が時間の経過とともに急速に低下・消失することは、証拠保全の必要性・緊急性を基礎づけ、任意捜査としての相当性の判断でプラスに働く事情である。
  - 正解：○（正しい）
  - 理由：アルコール濃度は時間経過で消えるため、証拠保全の緊急性が高い。任意捜査の限界（比例原則）では、この必要性・緊急性と被処分者の被る不利益とを衡量して相当性を判断する。緊急性が高く侵害が軽微なら相当＝適法に傾く。
- **Q12［○×］** 注射針を体内に刺入して行う採血は、身体への損傷を伴い健康状態に障害を及ぼす危険があるから、被処分者の真意に基づく同意がない限り強制処分に当たる。
  - 正解：○（正しい）
  - 理由：採血は身体の完全性という重要な権利・利益に実質的な侵害・制約を加える処分であり、真意に基づく同意がなければ強制処分に当たる（争いなし）。ゆえに法律の根拠と令状が必要となる。
- **Q13［○×］** 呼気の採取は被疑者の身体から証拠を得る処分であるから、承諾がない以上つねに強制処分に当たり、令状がなければ許されない。
  - 正解：×（誤り）
  - 理由：呼気は自然の呼吸に伴って体外に排出される空気にすぎず、採取に有形力を要さず健康侵害もない。重要な権利・利益への実質的侵害がないから任意処分であり、令状は不要。承諾の有無だけで強制処分になるのではなく、侵害の実質で判断する。
- **Q14［○×］** 呼気検査を拒否した者を処罰する規定は、被検査者に自己に不利益な供述を強要するものであり、憲法38条1項に違反する。
  - 正解：×（誤り）
  - 理由：最判平9.1.30は、呼気検査は体内アルコールの程度という身体の物理的状態を調べるもので供述を得るものではないから、憲法38条1項の供述の強要に当たらないとした。呼気検査拒否罪も同項に反しない（合憲）。
- **Q15［○×］** 承諾なき強制採血は、法律上の根拠を欠くため、強制処分法定主義（刑訴197条1項但書）に反して違法となる。
  - 正解：×（誤り）
  - 理由：ここが本問最大の罠。強制採血は鑑定に必要な処分（168条1項）として法律の根拠を有するから、強制処分法定主義には反しない。違法の理由は「法律の根拠がない」ではなく、令状を取得していない＝令状主義（憲法35条）違反に求める。
- **Q16［○×］** 強制処分法定主義は立法段階で強制処分の類型が法律に定められているかの統制であり、令状主義は執行段階で裁判官の事前審査（令状）を経たかの統制であって、両者は別レイヤーの規律である。
  - 正解：○（正しい）
  - 理由：法定主義＝立法段階で強制処分の類型を法律が定めているか。令状主義＝執行段階で裁判官の事前審査を経ているか。二つは別レイヤーの統制で、両方を満たして初めて適法。採血は法定はクリアするが令状を欠くから違法、という筋になる。
- **Q17［○×］** 同一の被疑者から同一目的で証拠を採取しても、身体への侵害の質・程度が異なれば、一方は任意処分として適法、他方は令状を欠く強制処分として違法、と結論が分かれうる。
  - 正解：○（正しい）
  - 理由：適法性は処分ごとに侵害の実質で判断する。呼気＝侵害軽微で任意・適法／採血＝身体侵襲で強制・令状なく違法。結論の差は侵害の質・程度の違いに基づく。
- **Q18［○×］** 判例（最決昭55.10.23）は、強制採尿を許すために必要な令状を身体検査令状であるとした。
  - 正解：×（誤り）
  - 理由：最決昭55.10.23は、強制採尿に適する令状は捜索差押許可状であり、採取に関する条件（医師が医学的に相当な方法で行う等）の記載を要する（条件付捜索差押許可状）とした。身体検査令状ではない。なお強制採血は実務上、鑑定処分許可状＋身体検査令状の併用による。
