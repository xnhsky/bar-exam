- 【拾う事実】『科警研勤務・検査歴10年のQ』 → 検査技術の信頼性（適格者による実施）
- 【拾う事実】『「規格化されている」機器』 → 検査方法・器具の標準性・信頼性
- 【拾う事実】『医師Rが心身の正常を確認』 → 被検査者の状態の適格性
- 【拾う事実】『Qが結果回答書を作成』 → 結果の忠実な記載／鑑定受託者の鑑定書
- 【拾う事実】『Pの嘱託を受けたQ』 → 「鑑定人（165条）」でなく鑑定受託者（223条）
- 【拾う事実】『Xが検査に同意・公判で不同意』 → 任意性の担保／326条同意は不成立
- 【事案の整理】翻訳の型
  - 証拠調べ決定（規則190条・317条）の前提は証拠能力。だから「決定できるか」＝「証拠能力があるか」。ここを翻訳し損ねると論点が見えない。
- 【争いのない要件】論点にならず、あっさり認定する要件
  - ①科学的原理＝ポリグラフに一定の科学的基礎あり／不同意だから326条同意による付与はなし＝一文で確定。素直な所は流し、引っかかる所（三要件・準用・供述証拠性）に筆を集める。
- 【効く事実】効く事実（三要件に対応）
  - ①原理＝ポリグラフは生理反応の測定で一定の科学的基礎あり／②実施の信頼性＝Qは科警研勤務・検査歴10年の適格者・規格化機器・医師Rが心身の正常を確認／③記載の忠実性＝Qが結果に基づき回答書を作成。
- 【ポイント】準用の理由づけ（この一手間が差を生む）
  - 鑑定人の鑑定書と鑑定受託者の鑑定書は、いずれも専門的知識経験に基づく判断の報告で性質を同じくし、信頼性は選任主体で左右されない → 321条4項を準用（最判昭28.10.15）。効果は「Qの真正作成証言」を条件に証拠能力（無条件ではない）。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 結論は無条件にしない＝②の準用の効果を受け「Qの真正作成証言を条件として」証拠調べ決定ができる、と条件を明示して締める。
- 【まぎらわしい選択肢・論点】違法収集証拠排除法則の適用／再伝聞の処理／非伝聞（精神状態の供述）該当性
- 【まぎらわしい選択肢・結論】証拠能力は認められない／無条件で証拠調べ決定できる
- 【まぎらわしい選択肢・規範】321条4項を直接適用／狭義の関連性で否定
- 【まぎらわしい選択肢・事実】Xの不同意で当然に排除／令状なく違法

## 3. 規範クイズ（3問）

- **Q04［規範］** 科学的証拠方法に必要最小限度の証明力（自然的関連性）を認めるための判断枠組み（三要件）を挙げよ。
  - 模範解答：自然的関連性を肯定する三要件＝①基礎にある科学的原理が理論的正確性を有すること ②具体的な検査の技術・方法が信頼性を有し、適格者によって正確に実施されたこと ③その結果が忠実に記載されていること。この三要件を満たすから必要最小限度の証明力が認められる（規範の根拠＝最決昭43.2.8）。
- **Q05［規範］** 捜査機関の嘱託を受けた鑑定受託者の鑑定書の証拠能力について、条文の欠缺→処理→条件を一続きで述べよ。
  - 模範解答：321条4項の「鑑定人」は裁判所選任者（165条）で鑑定受託者（223条1項）を含まない＝直接適用なし。もっとも両者は専門的知識経験に基づく判断の報告という点で性質を同じくするから、321条4項を準用する（最判昭28.10.15）。効果は作成者の真正作成証言を条件に証拠能力を肯定。
- **Q06［規範］** ポリグラフ検査結果が黙秘権・自白法則に反しないといえる理由を、「供述証拠」の定義から述べよ。
  - 模範解答：供述証拠とは言語その他の表現手段によって思想内容を表出したものをいう。ポリグラフが記録するのは呼吸・脈拍等の生理的・身体的反応であり、言語による思想の表出ではないから非供述証拠。黙秘権（憲38条1項・198条2項）・自白法則（319条1項）はいずれも供述証拠を保護対象とするから、非供述証拠には及ばない。

## 4. ○×クイズ（12問）

- **Q07［○×］** 裁判所が証拠調べ決定をするには、その前提として、当該証拠に証拠能力が認められることが必要である。
  - 正解：○（正しい）
  - 理由：証拠能力とは、その証拠を事実認定の資料として用いうる資格。証拠能力のない証拠は取り調べても事実認定に使えないから、証拠調べ決定の前提として証拠能力が要求される。「決定できるか」の問いは実質「証拠能力があるか」の問いに翻訳する。
- **Q08［○×］** 証拠能力と証明力は同じ概念であり、証拠の証明力が高ければ当然に証拠能力も認められる。
  - 正解：×（誤り）
  - 理由：証拠能力（証拠となりうる資格）と証明力（心証形成への寄与度）は別概念。証明力の評価は自由心証（318条）に委ねられるが、その前に証拠能力の有無を関門として判断する。証明力があっても伝聞や違法収集で証拠能力を欠けば取り調べられない。
- **Q09［○×］** 証拠能力は、①自然的関連性（必要最小限度の証明力）、②法律的関連性（伝聞法則等による政策的排除の有無）、③証拠禁止（違法・人権侵害による排除の有無）の三つの観点から判断される。
  - 正解：○（正しい）
  - 理由：この三観点は要件ではなく「検討の窓口」。普段は問題になる窓口だけをピックアップして書けばよいが、性質決定の段階で証拠がどの窓口に触れるかを先読みすると、論点の取りこぼしを防げる。
- **Q10［○×］** 科学的な機器を用いて得られた証拠は、その科学的外観ゆえに信用性が高いから、自然的関連性は当然に認められ、証明力の最低限を吟味する必要はない。
  - 正解：×（誤り）
  - 理由：逆である。科学的証拠は科学的外観ゆえに、原理や技術に問題があると裁判官に誤った心証を与える危険が大きい。だからこそ自然的関連性（必要最小限度の証明力）を、原理の正確性・実施の信頼性・記載の忠実性という要件で厳しく吟味する必要がある。
- **Q11［○×］** 証拠に証拠能力が認められるためには、自然的関連性・法律的関連性・証拠禁止のいずれの観点からも排除されないことが必要であり、一つでも欠ければ証拠能力は否定される。
  - 正解：○（正しい）
  - 理由：三観点はいずれも証拠能力を否定しうる関門。すべてをクリアして初めて証拠能力が認められる。本問は3つ全部が問題になるので、どれか一つを落とすと（特に自然的関連性）大幅減点になる。
- **Q12［○×］** 当事者が証拠とすることに同意した書面は、作成状況の相当性が認められる限り、個別の伝聞例外の要件を問わず証拠能力が付与される（326条1項）。
  - 正解：○（正しい）
  - 理由：326条1項は当事者の同意による伝聞例外。相手方の反対尋問権の放棄とみて、伝聞法則にかかわらず証拠能力を付与する。もっとも本問はXが不同意だから326条は機能せず、321条4項準用による伝聞例外を検討する必要が生じる。
- **Q13［○×］** ポリグラフ検査の結果を記載した書面は、検査が信頼性を保障する適格者により必要な条件を備えて実施され、その経過及び結果が忠実に記載されているときは、証拠能力を認めうる（最決昭43.2.8）。
  - 正解：○（正しい）
  - 理由：判例（最決昭43.2.8）は、検査結果を供述の信用性判断の資料に供することは慎重な考慮を要するとしつつ、適格者による信頼性ある実施＋忠実な記載を条件に証拠能力を肯定した。本問のQ（10年・科警研）・規格化機器・医師Rの確認・回答書作成という事実が、この「適格者・条件」に対応する。
- **Q14［○×］** ポリグラフ検査結果に自然的関連性が認められ証拠能力が肯定される以上、その証明力も高いものとして扱わなければならず、裁判官が証明力を低く評価することは許されない。
  - 正解：×（誤り）
  - 理由：証拠能力（証拠となりうる資格）と証明力（心証への寄与度）は別。証拠能力が肯定されても、証明力の評価は自由心証（318条）に委ねられる。判例もポリグラフ結果を供述の信用性判断に供するには慎重な考慮を要するとしており、過大評価は戒められる。
- **Q15［○×］** 捜査機関の嘱託を受けた鑑定受託者が作成した鑑定書には、刑訴法321条4項が直接適用され、そのまま同項により証拠能力が認められる。
  - 正解：×（誤り）
  - 理由：321条4項の「鑑定人」は裁判所・裁判官が命じた者（165条）を指し、捜査機関の嘱託を受けた鑑定受託者（223条1項）は含まれない。よって直接適用はなく「準用」で処理する（最判昭28.10.15）。
- **Q16［○×］** 鑑定受託者の鑑定書に321条4項を準用する場合でも、作成者が公判準備又は公判期日で証人として真正に作成した旨を供述すること（真正作成証言）が証拠能力の条件となる。
  - 正解：○（正しい）
  - 理由：321条4項は3項を準用し、作成者の真正作成証言を条件とする。準用の実質的根拠は、真正作成証言により作成者への反対尋問の機会が担保され、鑑定書の成立の真正と内容の信頼性を吟味しうる点にある。
- **Q17［○×］** 憲法38条1項・刑訴法198条2項・319条1項はいずれも供述証拠を保護対象とするところ、ポリグラフ検査が記録する呼吸・脈拍等の生理的反応は言語による思想の表出ではないから、これらの規定に反しない。
  - 正解：○（正しい）
  - 理由：供述証拠とは言語その他の表現手段によって思想内容を表出したもの。ポリグラフが記録するのは生理的・身体的反応（生体反応）であって供述ではない＝非供述証拠だから、黙秘権・自白法則は働かない（東京高決昭41.6.30参照）。三規定を「供述証拠を保護対象」で束ねて一括処理する。
- **Q18［○×］** 自白法則（319条1項）は任意にされたものでない疑いのある供述証拠を排除する規定であるから、被検査者が任意に検査に同意していれば非供述証拠であっても同項の適用が問題となる。
  - 正解：×（誤り）
  - 理由：319条1項は「自白」＝供述証拠を対象とする。ポリグラフ検査結果は生理反応の記録＝非供述証拠であり、そもそも「自白」に当たらず同項の適用場面ではない。本問はさらにX同意があり強制の要素も欠く（二重に否定できる）。
