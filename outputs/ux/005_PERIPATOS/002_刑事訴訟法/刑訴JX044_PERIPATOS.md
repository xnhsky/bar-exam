- 【拾う事実】『送還のおそれを事前に弁護人へ通知／弁護人は証拠保全せず』 → 手続的正義の観点から公正さを欠かない方向
- 【拾う事実】『Aは私人／消防士15年・火災調査約20年』 → 3項の主体（捜査機関）でない＝準用否定・4項の特別の学識経験＝準用肯定
- 【拾う事実】『立証趣旨＝燃え移る認識がなかったこと』 → 被告人に有利な事実＝厳格な証明の対象か（横断）
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 伝聞該当性＝要証事実との関係で内容の真実性が問題＝両書面とも該当を一文で認定。あとは各書面固有の例外要件（W＝321条1項2号前段／A＝321条3項・4項）が論点。該当性で立ち止まらない。
- 【効く事実】「国外にいる＋手続的正義」のあてはめで使う事実
  - 「国外にいる」→ 不法滞在発覚 → 強制送還 → 既に日本にいない（形式的に充足）／手続的正義（限定が働かない方向）→ 検察官が送還のおそれを事前に弁護人へ通知・弁護人が証拠保全請求をしなかった／署名押印 → 「Wの署名・押印がある」を直接引用。
- 【効く事実】「3項準用は主体で切る／4項準用が」のあてはめで使う事実
  - 3項準用の否定 → Aは私人であり捜査機関（検察官・検察事務官・司法警察職員）でない／4項準用の肯定 → Aは消防士15年・火災調査約20年＝特別の学識経験／報告書 → その学識経験に基づく燃焼実験の考察結果。結論はAの真正作成証言があれば証拠能力あり。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 法は「犯罪事実の存否」と規定し、存在・不存在を区別しない（314条3項・321条1項3号）→ 有利・不利を問わず犯罪事実は厳格な証明の対象（317条）→ A報告書も伝聞法則の規律に服する。
- 【まぎらわしい選択肢・論点】違法収集証拠排除法則の適用／自白法則（319条1項）／再伝聞の可否（324条）
- 【まぎらわしい選択肢・結論】321条1項3号により証拠能力あり／伝聞例外に当たらず証拠能力なし
- 【まぎらわしい選択肢・規範】後段の相対的特信情況／自由な証明で足りる
- 【まぎらわしい選択肢・事実】検察官が退去を殊更利用／証人尋問決定後の強制送還

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

W＝要証事実は犯人性で伝聞、検面調書は321条1項2号前段、国外にいるは充足、事前通知＋証拠保全懈怠で手続的正義に反せず、前段は特信不要＋署名押印あり＝証拠能力あり。A＝故意不存在の証明で伝聞（有利事実も厳格な証明）、3項は主体が捜査機関限定で私人準用否定、4項は正確性の担保の趣旨から特別の学識経験ある者に準用、消防士15年・火災調査約20年＝真正作成証言があれば証拠能力あり。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 伝聞証拠とは何か（定義）、及び伝聞証拠が原則として証拠能力を否定される理由（趣旨）を述べよ。
  - 模範解答：公判期日における供述に代わる書面、又は公判外の他者の供述を内容とする供述で、要証事実との関係で供述内容の真実性が問題となるもの（320条1項）。供述証拠は知覚・記憶・叙述の各過程に誤りが介在しやすく、反対尋問等による吟味を経なければ信用性を担保できないため、原則として証拠能力が否定される（憲法37条2項の証人審問権の実質化）。
- **［規範クイズ 2/3］** 強制送還で証人が国外にいる検面調書につき、証拠能力を否定しうる場合を画した最判平7.6.20の規範を述べよ。
  - 模範解答：「国外にいる」（321条1項2号前段）の要件充足を前提に、検察官が退去強制で供述できなくなる事態を殊更利用しようとした場合や、証人尋問決定後に強制送還された場合など、検面調書の証拠請求が手続的正義の観点から公正さを欠くと認められるときは、これを事実認定の証拠とすることが許容されないこともあり得る。証拠能力否定の場面をかなり限定的に解している。
- **［規範クイズ 3/3］** 私人作成の燃焼実験報告書に321条4項の準用を認めた規範（最決平20.8.27）を述べよ。
  - 模範解答：321条4項は、訴訟に利害関係を有しない鑑定人が特別な知識経験をもって作成し性質上正確性が保障される点に緩やかな証拠能力付与の根拠がある。そうだとすれば、特別の学識経験を有する者が、その学識経験に基づいて実験等を行い考察結果を報告した書面であれば、「鑑定人」が作成したものでなくとも4項の準用を認めてよい。作成者の真正作成証言があれば証拠能力を肯定する。

## 4. ○×クイズ（全7問・1問目から最後まで全部出す）

- **［○×クイズ 1/7］** ある書面が伝聞証拠に当たるか否かは、その書面を何の証明に用いるか（要証事実）との関係で、記載された供述内容の真実性が問題となるかどうかによって相対的に決まる。
  - 正解：○（正しい）
  - 理由：伝聞・非伝聞は書面それ自体で決まるのではなく、要証事実との関係で内容の真実性が問題になるかで相対的に決まる（320条1項）。だからまず要証事実を確定するのが証拠能力検討の第一歩。同じ書面でも、発言の存在自体が要証事実なら非伝聞になりうる。
- **［○×クイズ 2/7］** 被告人以外の者の供述を録取した書面が321条1項各号により証拠能力を認められるためには、各号所定の要件に加えて、原則として供述者の署名又は押印（同項柱書）が必要である。
  - 正解：○（正しい）
  - 理由：供述録取書面は「原供述 → 録取者の聴取・記載」という二重の伝聞過程を含む。署名・押印は録取の正確性を原供述者が確認したことを担保し、録取過程の伝聞性を解消する共通要件（柱書）。だから各号の要件だけでなく柱書の署名押印も確認する。
- **［○×クイズ 3/7］** 検察官及び被告人が証拠とすることに同意した書面は、その作成された情況を考慮し相当と認めるときは、321条以下の伝聞例外の個別要件を満たさなくても証拠とすることができる（326条1項）。
  - 正解：○（正しい）
  - 理由：同意は反対尋問権の放棄と評価でき、相当性を条件に個別要件を要しない（326条1項）。本問は両書面とも相手方が不同意だから326条で拾えず、321条の個別要件を検討する道に入る。まず同意の有無を確認するのが証拠能力検討の入口。
- **［○×クイズ 4/7］** 321条1項2号前段の「供述することができないとき」（供述不能）に当たる事由には、供述者の死亡・精神若しくは身体の故障・所在不明のほか、供述者が国外にいることが含まれる。
  - 正解：○（正しい）
  - 理由：2号前段の供述不能事由は「死亡、精神若しくは身体の故障、所在不明若しくは国外にいるため」と条文に列挙されている。これらは反対尋問に代わる公判外供述の必要性を基礎づける。強制送還で当面帰国の見込みがない場合は「国外にいる」に当たる。
- **［○×クイズ 5/7］** 検察官面前調書を321条1項2号前段（供述不能）により証拠とするには、同号後段の場合と同様に、公判準備・公判期日における供述より前の供述を信用すべき特別の情況（特信情況）が存することが必要である。
  - 正解：×（誤り）
  - 理由：特信情況を明文で要求するのは後段（相反供述の場合）だけで、前段（供述不能）には特信情況の要件はない（条文の素直な読み方・通説）。学説には前段にも特信性を求める見解もあるが、答案では前段は不要で処理し、一言触れれば丁寧。
- **［○×クイズ 6/7］** 321条3項（検証調書）の作成主体は「検察官、検察事務官又は司法警察職員」に限定されているから、その文言及び趣旨に照らし、私人が作成した実況見分書面に同項を準用することはできない。
  - 正解：○（正しい）
  - 理由：3項の主体限定の趣旨は、捜査機関が法律上検証の職務・権限を有する公務員であり検証結果を信用し得る資質上・制度上の保証を備える点にある。私人にはこの保証がないから、私人作成の書面に3項の準用はない（最決平20.8.27）。だからいきなり4項に飛ばず、まず3項を主体で切る二段階処理を示す。
- **［○×クイズ 7/7］** 被告人に有利な犯罪事実の不存在（故意の不存在等）を証明する証拠は、被告人に不利益を及ぼさないから、厳格な証明を要せず自由な証明で足り、伝聞法則の規律は及ばない。
  - 正解：×（誤り）
  - 理由：法は「犯罪事実の存否」と規定し、「存否」（存在・不存在）を区別していない（314条3項・321条1項3号参照）。よって被告人に有利な事実の証明も厳格な証明の対象となり（317条）、伝聞法則の規律に服する。だからA報告書も伝聞例外の要件を満たさなければ証拠にできない。
