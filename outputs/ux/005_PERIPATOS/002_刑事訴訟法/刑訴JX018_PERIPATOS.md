#### 第2　差押え②の適法性

- 見出しの補足（結論を含む。項目の終わりに読む）：関連性・別件
1. 【論点】「メモ、手紙、日記等」への該当性 → 被疑事実との関連で特定される限度で概括的記載を許容（昭36.6.7） → 脅迫文は「等」に該当（通す）
2. 【論点】被疑事実関連性 → 記載物件でも被疑事実関連物に限る（222条1項・99条1項） → 脅迫文は恐喝の証拠・収賄と無関連

3. 【論点】別件捜索・差押え → 諸事情の総合考慮（真の目的等） → 時計押収済み・メモ無し認識・恐喝令状困難・両嫌疑無関連＝収賄に仮託

- 【効く事実】あてはめで使う事実
  - 任意提出の不存在 → 「新たに令状をもってこい」と抗議／逮捕の不存在 → 現行犯逮捕をしていない／即時性 → 反対を押し切って差し押さえた。事実を必ず「だから領置も逮捕に伴う差押えも使えない」と評価に結合する。
- 【ポイント】落とし穴
  - 「メモ、手紙、日記等」の概括的記載は広く許容されるので、脅迫文は物件に当たる → ここで適法と早合点しない。記載物件でも被疑事実に関連しなければ差し押さえられないのが二段目。切るのは関連性。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 別件性の徴表＝時計は押収済み・Bの供述でメモ無しと認識・恐喝令状は取れない・両嫌疑に関連性なし。これらから「収賄に仮託した恐喝の証拠収集」＝真の目的を推認。別件と評価すると違法の重大性が増し、後の証拠排除にも効く。
- 【まぎらわしい選択肢・論点】違法収集証拠排除法則の適用可否／捜索の場所的範囲の逸脱／所持品検査の限界
- 【まぎらわしい選択肢・結論】差押え① 適法／差押え② 適法
- 【まぎらわしい選択肢・規範】相当説／重大違法説
- 【まぎらわしい選択肢・事実】令状の呈示／被疑者の同意

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

①＝覚せい剤は記載外で原則違法、緊急捜索差押えは明文なく否定、領置・再令状・逮捕に伴う差押えのいずれも不履践で違法。②＝脅迫文は「等」に該当するが収賄と無関連で関連性を欠き違法、加えて時計押収済み・メモ無し認識・恐喝令状困難・無関連から別件捜索・差押えで違法。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 令状執行中に令状記載外の証拠物を発見した場合、捜査機関がとりうる適法な3つの手段を条文とともに挙げよ。
  - 模範解答：①所持者の任意提出を求めて領置（221条）／②現場への出入りを禁止して現状を保全し（222条1項・112条1項）改めて令状を得る／③法禁物の所持を現認して現行犯逮捕（213条・212条1項）し逮捕に伴う差押え（220条1項2号）。いずれも履践しなければ差押えは違法。
- **［規範クイズ 2/3］** 令状記載物件に該当する物を適法に差し押さえるために、物件該当性のほかに必要な要件は何か（根拠条文も）。
  - 模範解答：被疑事実との関連性（222条1項・99条1項）。差押えの対象は令状記載物件であっても被疑事実に関連する物に限られる。関連性の判断は「被疑事実に関係する蓋然性」で足りる（最決平10.5.1）が、蓋然性すら無ければ差し押さえられない。
- **［規範クイズ 3/3］** 別件捜索・差押えの違法性を判断する総合考慮の考慮要素を挙げよ。
  - 模範解答：①捜索の真の目的／②別件と本件の関連性／③別件についての令状取得の難易・必要性／④実際の捜索・差押えの態様 等。本問では時計押収済み・メモ無し認識・恐喝令状困難・両嫌疑無関連から、収賄に仮託した恐喝の証拠収集という真の目的を推認できる。

## 4. ○×クイズ（全11問・1問目から最後まで全部出す）

- **［○×クイズ 1/11］** 差押えの効力は令状に記載された差押物件に限られ、記載のない物にはその効力が及ばない。
  - 正解：○（正しい）
  - 理由：219条1項が差押物件を令状に記載させるのは、一般的・探索的差押えを禁じ、差押えの対象を令状記載物件に限定する趣旨。したがって令状の効力は記載物件にのみ及び、記載外の物を差し押さえれば無令状の差押えとして原則違法となる。差押えの適否は、この「記載物件との照合」から出発する。
- **［○×クイズ 2/11］** 差し押さえた物が令状記載の差押物件に当たりさえすれば、令状の被疑事実との関連性を問わず、これを適法に差し押さえることができる。
  - 正解：×（誤り）
  - 理由：令状記載物件に該当することは必要条件にすぎない。差押えの対象は、令状記載物件であっても被疑事実に関連する物に限られる（222条1項・99条1項）。物件該当性と被疑事実関連性は別の関門で、記載物件に入っても関連性を欠けば差し押さえられない。差押え②で脅迫文を「等」に含めて満足すると、この二段目を落とす。
- **［○×クイズ 3/11］** 捜索差押許可状の効力は、令状記載の「捜索すべき場所」の記載によって場所的にも限定され、記載された場所以外を捜索することは許されない。
  - 正解：○（正しい）
  - 理由：令状主義（憲法35条・刑訴219条1項）は「捜索すべき場所」の明示も要求し、令状の効力は記載場所に限定される。物件のみならず場所・被疑事実の各記載が令状の効力範囲を画する。差押えの適否は、物件・場所・被疑事実の各枠に照らして判断する。
- **［○×クイズ 4/11］** 覚せい剤の所持のように、その所持自体が犯罪となる物（法禁物）は、令状に記載がなくとも、発見した以上当然に差し押さえることができる。
  - 正解：×（誤り）
  - 理由：典型的な誤答。法禁物であっても、令状記載外である以上、令状の効力は及ばない。適法に押収するには、任意提出→領置（221条）、現場保全＋再令状（222条1項・112条1項）、又は現行犯逮捕して逮捕に伴う差押え（213条・220条1項2号）といった手続を経る必要がある。「法禁物＝無条件で押収可」は令状主義の理解を欠くものと評価される。
- **［○×クイズ 5/11］** 現行犯人を逮捕する場合において必要があるときは、逮捕の現場で令状なくして差押え・捜索・検証をすることができる（220条1項2号）。
  - 正解：○（正しい）
  - 理由：逮捕に伴う差押え・捜索（220条1項2号）は、逮捕の現場における無令状の差押えを認める。覚せい剤の所持は現行犯（212条1項）だから、Pは現行犯逮捕（213条）したうえで逮捕に伴う差押えによれば適法に押収できた。これが本問の本命ルートで、Pはこれを踏まなかった。
- **［○×クイズ 6/11］** 現行法上、緊急逮捕に相当する「緊急捜索・差押え」を認める明文はなく、強制処分法定主義（197条1項但書）・令状主義の下では、これを認めることはできない。
  - 正解：○（正しい）
  - 理由：逮捕には緊急逮捕（210条）という無令状類型の明文があるが、捜索・差押えには対応する明文がない。強制処分は法律の特別の定めによらなければならない（197条1項但書）以上、明文なき緊急捜索・差押えは令状主義を潜脱するものとして認められない（通説）。
- **［○×クイズ 7/11］** 捜索又は差押えの許可状の執行中であっても、現場に出入りする者に対してその出入りを禁止・制限することはできない。
  - 正解：×（誤り）
  - 理由：112条1項（222条1項により捜査に準用）は、執行中、何人に対しても許可を得ない出入りを禁止できると定める。これは現場を保全して改めて令状を得るまでの現状維持の根拠となる。差押え①でPはこの手続もとらなかった。
- **［○×クイズ 8/11］** 差押物件の記載は個別具体的に列挙しなければならず、「メモ、手紙、日記等」のように例示に『等』を付す概括的記載は一切許されない。
  - 正解：×（誤り）
  - 理由：被疑事実の性質上、差押物件を個別に列挙し難い場合があるから、被疑事実との関連で特定される限度では例示＋「等」型の概括的記載も許される（最大判昭36.6.7）。ただしこれは物件該当性の話にとどまり、被疑事実関連性（99条1項）の欠如までは治癒しない。
- **［○×クイズ 9/11］** 令状記載の差押物件に該当する物であっても、令状の被疑事実と関連しない物は差し押さえることができない（222条1項・99条1項）。
  - 正解：○（正しい）
  - 理由：99条1項（222条1項により捜査に準用）の「証拠物…と思料するもの」は、被疑事実に関連する物を意味する。物件該当性と被疑事実関連性は別個の要件で、記載物件に入っても被疑事実と無関連なら差押えは許されない。差押え②の脅迫文は恐喝の証拠で収賄と無関連ゆえ違法。
- **［○×クイズ 10/11］** 専ら別罪（本件）の証拠を収集する目的で、証拠の揃った別件の令状を利用して捜索・差押えを行うこと（別件捜索・差押え）は、令状審査を潜脱するものとして令状主義に反し違法となりうる。
  - 正解：○（正しい）
  - 理由：別件捜索・差押えは、令状審査という事前抑制を潜脱する点で、別件逮捕・勾留の潜脱論と同型に違法評価を受ける。専ら本件の証拠収集の目的で別件令状を用いれば、令状主義に反し違法となりうる。
- **［○×クイズ 11/11］** 別件捜索・差押えに当たるか否かは、捜索の真の目的、別件と本件の関連性、別件についての令状取得の難易・必要性、実際の捜索・差押えの態様等を総合的に考慮して判断する。
  - 正解：○（正しい）
  - 理由：別件性は一義的な基準ではなく、真の目的・両事件の関連性・別件令状取得の難易や必要性・捜索差押えの態様等の諸事情の総合考慮で判断する（別件逮捕・勾留と同型）。単一の外形だけで決めない点に注意。
