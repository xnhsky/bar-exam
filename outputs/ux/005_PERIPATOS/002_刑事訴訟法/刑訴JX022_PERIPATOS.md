## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

A市の公安条例は、集団行進等を行うときは事前許可を要し、第4条第3号で「交通秩序を維持すること」を許可条件の1つとし、第5条で条件違反の行進の主催者・指導者・扇動者を処罰する旨を定めている。A市在住の甲は、許可を得た反戦デモ行進に参加し、先頭集団の最先端に立って行進していた。ところが、甲を含む先頭集団が蛇行進をするに至ったため、行進状況を監督していた巡査乙は、違反行進ありと判断し、この先頭集団の行進状況をカメラで撮影した。甲は「どこのカメラマンか」と抗議したが、乙がことさらこれを無視する態度に出たことに憤慨し、乙の手からカメラを奪いとり、地面に叩きつけて壊した。乙の撮影した写真を刑事訴訟で証拠として用いる場合に、何が問題になるか。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 許可を得た反戦デモ行進（当初は適法）
- 先頭集団が蛇行進 → 条例4条3号の条件違反へ
- 監督の巡査乙が「違反行進あり」と判断し撮影
- 甲が抗議 → 乙が無視 → 甲がカメラを奪い破壊
- 乙の撮影した写真を刑事訴訟で証拠利用

### 入口の問い（3問）

  - 答え：証拠能力は 自然的関連性 → 法律的関連性 → 証拠禁止 の三段で切る。まずこの三段の物差しを頭に置くのが第一歩。
- **［入口 2/3・見当づけ］** 「どの関門で引っかかるか」 ― 見当をつけて

### 骨子（3項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　本件写真の関連性

- 見出しの補足（結論を含む。項目の終わりに読む）：自然的関連性・法律的関連性
1. 自然的関連性 → 条例5条違反の被疑事実との結びつき ＝ あり
2. 【論点】現場写真は非供述証拠か（規範：伝聞法則の適否・320条1項）
   - あてはめ：写真は機械的記録＝供述過程なし → 非供述証拠 → 伝聞なし（昭59.12.21）
- 結論：法律的関連性 あり

#### 第2　写真撮影の適法性

- 見出しの補足（結論を含む。項目の終わりに読む）：証拠禁止の前提・本丸
1. 【論点】強制処分該当性（規範：「強制の処分」＝重要な権利利益の制約）
   - あてはめ：公道＝容ぼう等を観察されるのを受忍せざるを得ない → 重要な権利利益の制約なし → 任意処分
2. 【論点】任意捜査の限界（規範：京都府学連①現行犯性②必要性緊急性③相当性）
   - あてはめ：①違反行進を現認 ②集団行動で証拠保全困難＝必要性・緊急性 ③無視の態度あるも撮影方法は相当
- 結論：撮影は適法

#### 第3　証拠禁止の帰結

   撮影が適法 → 令状主義没却の重大な違法なし → 排除に至らない
- 結論：写真は証拠として用いることができる

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】『「公道上・デモ行進の現場」で撮影』 → 重要な権利利益の制約の有無（強制処分該当性の分水嶺）
- 【拾う事実】『「違反行進ありと判断し」撮影』 → 現に犯罪が行われている（現行犯性）の認定根拠
- 【拾う事実】『集団行進・多数参加・状況が刻々変化』 → 証拠保全の必要性・緊急性の基礎づけ
- 【拾う事実】「ことさら無視する態度」 → 撮影の相当性（許容限度）の評価事情
- 【拾う事実】『「行進状況を撮影」した写真』 → 現場写真＝非供述証拠（伝聞の適否）
- 【事案の整理】証拠の棚卸し
  - 本件写真＝巡査乙が公道でデモの行進状況を撮影した「現場写真」。撮影者は捜査機関（乙）。この2点（何の証拠か／捜査機関が撮ったか）が、後の全論点の起点になる。
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 自然的関連性＝条例違反の現場写真だから最小限の証明力あり＝あり／法律的関連性＝現場写真は非供述証拠＝伝聞なし／証拠禁止＝撮影が適法かをこれから割る。3段は必ず通すが、問題が無ければ一文でよい。
- 【効く事実】あてはめで使う事実
  - 意思に反する撮影 → みだりに容ぼう・姿態を撮影されない自由（憲法13条）の制約に触れる。しかし撮影場所は公道で、他人から容ぼう等を観察されるのを受忍せざるを得ない場所 → 重要な権利利益の制約とはいえない → 強制処分に当たらず任意処分。
- 【ポイント】判例の使い分け
  - 現行犯的事案（デモ違反の撮影）＝京都府学連の①現行犯性②必要性・緊急性③相当性。継続的・計画的な撮影の最決平20.4.15（百選8）は現行犯性を必須とせず別基準。本問は事案がほぼ同型の昭44基準を使う。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 収集手続に違法があれば、①令状主義の精神を没却する重大な違法＋②排除相当性で証拠能力を否定（最判昭53.9.7）。本問は撮影が適法だから、この枠組みに乗せず「排除に至らない」で完結。適法なのに違法重大性・排除相当性を長々論じない（時間ロス＋減点）。
- 【まぎらわしい選択肢・論点】公安条例の合憲性／写真の同一性・作成過程の立証／令状主義の趣旨
- 【まぎらわしい選択肢・結論】証拠能力は否定される／検証令状が必要で違法
- 【まぎらわしい選択肢・規範】有形力基準説／比較衡量説
- 【まぎらわしい選択肢・事実】被撮影者の同意／令状の呈示

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

関連性＝条例違反の現場写真で自然的関連性○、現場写真は非供述証拠で伝聞なし（昭59.12.21）。適法性＝強制処分の意義（重要権利利益の制約）→公道だから任意処分、任意捜査の限界は京都府学連①現行犯②必要性緊急性③相当性で全部充足（昭44）。証拠禁止＝適法だから排除に至らず、写真は証拠として使える。

## 3. 規範クイズ（全4問・1問目から最後まで全部出す）

- **［規範クイズ 1/4］** 現場写真について、伝聞法則の適用がないとする理由（規範のコア）を述べよ。
  - 模範解答：写真は光学的・化学的過程により機械的に作成され、人の知覚・記憶・叙述という供述過程を経ない。伝聞法則の趣旨は供述過程の誤りを反対尋問等で吟味する点にあるから、供述過程のない現場写真は非供述証拠に当たり、伝聞法則の適用はない（最決昭59.12.21）。偽造・修正のおそれは証明力の問題。
- **［規範クイズ 2/4］** 「強制の処分」（197条1項ただし書）の意義を述べよ（強制処分と任意処分を分ける規範）。
  - 模範解答：個人の意思を制圧し、身体・住居・財産等の重要な権利利益に制約を加えて強制的に捜査目的を実現する行為をいう。有形力の行使を伴うか否かは問わない（最決昭51.3.16）。「重要な権利利益への制約」の有無が処分性を分ける（GPS捜査＝最大判平29.3.15とも通底）。
- **［規範クイズ 3/4］** 京都府学連事件（最大判昭44.12.24）が定立した、令状によらない写真撮影が許容される3要件を挙げよ。
  - 模範解答：①現に犯罪が行われ又は行われた後間がないと認められる場合であること（現行犯性）、②証拠保全の必要性・緊急性があること、③一般的に許容される限度を超えない相当な方法によること。以上の3要件を満たすときは、現行犯的事案として被撮影者の同意も裁判官の令状も要しないから、令状によらない撮影が適法となる（最大判昭44.12.24）。
- **［規範クイズ 4/4］** 違法収集証拠排除法則の下で証拠物の証拠能力が否定される2要件（最判昭53.9.7）を挙げよ。
  - 模範解答：①証拠物の収集手続に令状主義の精神を没却するような重大な違法があること、②これを証拠として許容することが将来における違法な捜査の抑制の見地から相当でないと認められること。両者を満たす場合に証拠能力が否定される（最判昭53.9.7）。

## 4. ○×クイズ（全7問・1問目から最後まで全部出す）

- **［○×クイズ 1/7］** 伝聞法則（320条1項）が適用されるのは、人の知覚・記憶・叙述という供述過程を経た供述証拠であり、機械的に記録される非供述証拠には及ばない。
  - 正解：○（正しい）
  - 理由：伝聞法則の趣旨は、供述過程（知覚・記憶・叙述）の誤りを反対尋問等で吟味する点にあるから、供述過程を経ない非供述証拠にはこの危険がなく、伝聞法則の適用がない、伝聞法則は及ばない。現場写真はこの非供述証拠に当たる（最決昭59.12.21）。
- **［○×クイズ 2/7］** 違法収集証拠排除法則（証拠禁止）は、証拠の収集手続（集め方）の違法を理由に証拠能力を否定する枠組みであり、証拠自体の性質（関連性・伝聞該当性）とは別の段階の問題である。
  - 正解：○（正しい）
  - 理由：関連性・伝聞は「その証拠が事実認定に使えるか（証拠の性質）」の問題、証拠禁止は「集め方が違法でないか（手続の適法性）」の問題で、判断の層が異なる。だから写真そのものが非供述証拠で伝聞にかからなくても、なお撮影の適法性を別途検討する必要がある。
- **［○×クイズ 3/7］** 犯行の状況等を撮影したいわゆる現場写真は非供述証拠に属し、写真自体又は他の証拠により事件との関連性を認めうる限り証拠能力を有し、伝聞法則の問題は生じない。
  - 正解：○（正しい）
  - 理由：最決昭59.12.21の判示。現場写真は機械的記録＝非供述証拠だから伝聞法則は及ばず、撮影者に作成過程・関連性を証言させる必要もない。偽造・修正のおそれは証明力（証拠価値）の問題として処理すれば足りる。
- **［○×クイズ 4/7］** 写真が非供述証拠として伝聞法則の適用を受けない場合、その写真の証拠能力は当然に肯定され、撮影手続の適法性を別途検討する必要はない。
  - 正解：×（誤り）
  - 理由：伝聞法則（法律的関連性）をクリアしても、なお証拠禁止（違法収集証拠排除）の段階が残る。証拠の集め方＝写真撮影が違法であれば証拠能力が否定されうるから、撮影の適法性を必ず別途検討する。本問はここが主戦場。
- **［○×クイズ 5/7］** 捜査機関による写真撮影は、対象者の意思に反して行われる以上、常に「強制の処分」に当たり、検証令状がなければ違法となる。
  - 正解：×（誤り）
  - 理由：強制処分か否かは「重要な権利利益への制約」の有無で決まり、意思に反するだけでは強制処分にならない。公道でデモをしている姿の撮影は、容ぼう等を観察されるのを受忍せざるを得ない場所での撮影で重要な権利利益の制約とはいえず、任意処分と解される。
- **［○×クイズ 6/7］** 現行犯的事案における捜査機関の写真撮影は、①現に犯罪が行われ又は行われた後間がなく、②証拠保全の必要性・緊急性があり、③一般的に許容される限度を超えない相当な方法によるときは、本人の同意も裁判官の令状もなく許容される。
  - 正解：○（正しい）
  - 理由：京都府学連事件（最大判昭44.12.24）の定立した3要件。憲法13条から導かれるみだりに容ぼう等を撮影されない自由も、公共の福祉のため必要な場合には相当の制限を受ける、という枠組みから許容される。本問はこの射程がまさに及ぶ。
- **［○×クイズ 7/7］** 違法収集証拠排除法則により証拠物の証拠能力が否定されるのは、①収集手続に令状主義の精神を没却するような重大な違法があり、かつ②これを証拠とすることが将来の違法捜査抑制の見地から相当でないと認められる場合である。
  - 正解：○（正しい）
  - 理由：最判昭53.9.7の定立した2要件（①重大な違法＋②排除相当性）。適正手続（憲法31条）・将来の違法捜査抑止・司法の廉潔性を根拠とする判例法理。単なる違法では足りず「重大な」違法と排除相当性の両方を要する。
