### 問題文（最初にゆっくり読み上げる）

甲は、乙と共謀の上、甲の姉である丙宅へ赴き丙から金銭を脅し取った。さらに、その帰り際に、丙が、甲及び乙を罵倒したので、甲及び乙は、腹いせに丙宅の棚を蹴り飛ばし、棚の上にあった丙所有の花瓶及び丙の夫丁所有の壺を壊した。小問1　丙及び丁が、甲及び乙を器物損壊罪で告訴するべきか迷っていた場合、捜査機関は、当該器物損壊事実について捜査することができるか。小問2　丙だけが、乙のみを恐喝罪及び器物損壊罪で告訴した。これを受けた検察官は、捜査を進めた上で、甲及び乙を、丙に対する恐喝罪と丙及び丁に対する器物損壊罪の容疑で起訴しようとしている。この場合に、甲に対する起訴は許されるか。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 甲乙が共謀 → 丙宅で丙を恐喝（甲は丙の弟）
- 帰り際、棚を蹴る一個の行為で丙花瓶・丁壺を損壊（観念的競合）
- 小問1：丙・丁は告訴を迷う（＝未告訴）
- 小問2：丙が「乙のみ」を恐喝罪・器物損壊罪で告訴
- 検察官が甲・乙を恐喝・器物損壊で起訴しようとする

### 骨子（3項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　小問1

- 見出しの補足（結論を含む。項目の終わりに読む）：告訴を欠く親告罪の捜査
1. 器物損壊は親告罪（264条）・現時点で告訴なし → 【論点】告訴を欠く親告罪の捜査の可否（規範：訴訟条件≠捜査の条件）
2. 原則＝将来公訴提起の可能性ある限り捜査可（189条2項・証拠保全／告訴期間6か月＝235本文）
   - あてはめ：例外＝可能性皆無なら捜査の必要性を欠き不可（親告罪の趣旨）
3. 「迷っている」＝見込み皆無とはいえない
- 結論：捜査できる

#### 第2　小問2・恐喝罪

- 見出しの補足（結論を含む。項目の終わりに読む）：甲への起訴
1. 丙は乙のみ告訴 → 原則 共犯者甲に及ぶ（【論点】主観的不可分・規範：238条1項）
2. 恐喝は【論点】相対的親告罪（251→244条2項・甲は丙の弟）→ 例外で親族甲に及ばず
   - あてはめ：人的関係への配慮の趣旨が没却されるため
- 結論：恐喝で甲は起訴不可

#### 第3　小問2・器物損壊罪

- 見出しの補足（結論を含む。項目の終わりに読む）：甲への起訴
1. 相対的親告罪でない → 丙の告訴は甲に及ぶ（丙花瓶）→ 丙花瓶は起訴可
2. 丙花瓶・丁壺は観念的競合（54条1項前段）→ 【論点】客観的不可分（規範：一罪の一部の告訴は全部に及ぶ）
3. もっとも【論点】被害者を異にする（丙≠丁）→ 例外（230条趣旨）で丁は未告訴の壺に及ばず
- 結論：丁壺は起訴不可 ＝ 甲は丙花瓶の器物損壊罪のみ起訴可

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「共謀の上」 → 共同正犯・共犯者間の告訴（主観的不可分）
- 【拾う事実】『「甲の姉」（甲＝丙の弟）』 → 親族＝相対的親告罪（251→244Ⅱ）
- 【拾う事実】「一個の行為で花瓶と壺」 → 観念的競合・客観的不可分の前提
- 【拾う事実】「丙所有の花瓶／丁所有の壺」 → 被害者を異にする（丙≠丁）
- 【拾う事実】「迷っていた」 → 告訴を得る見込み（捜査の限定）
- 【拾う事実】「乙のみを告訴」 → 甲は未告訴（効力が及ぶか）
- 【事案の整理】告訴状況の棚卸し
  - 小問1＝丙も丁も未告訴（迷っている）。小問2＝丙が「乙のみ」を告訴（甲は未告訴／丁も未告訴）。この「誰の告訴が抜けているか」が全論点の起点。
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 恐喝＝主観的不可分で原則及ぶ（238Ⅰ）→相対的親告罪で切る。丙花瓶＝相対的でない＝及ぶ（一言）。丁壺＝客観的不可分で及ぶ→被害者別で切る。
- 【効く事実】あてはめで使う事実
  - 相対的親告罪 → 甲は丙の弟（姉弟＝親族）／被害者を異にする → 花瓶は丙・壺は丁の所有／捜査の限定 → 丙丁は「迷っている」＝見込み皆無でない。
- 【規範の要点】「丁壺」の規範
  - 一罪の一部の告訴は全部に及ぶ（客観的不可分・明文なし）。もっとも、科刑上一罪がともに親告罪で被害者を異にする場合は、被害者意思を尊重する230条の趣旨から、告訴していない被害者の被った犯罪事実には及ばない。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 相対的親告罪の非対称性（乙にとっては非親告罪／甲にとってのみ親告罪）と、被害者の複数性（丙と丁）が、それぞれ例外を導く理由。二つの例外は「不可分を貫くと保護されるべき人（親族甲・未告訴の丁）に不意打ちになる」という同じ発想でつながる。
- 【まぎらわしい選択肢・論点】訴因変更の要否／一事不再理効の範囲／告訴の追完の可否
- 【まぎらわしい選択肢・結論】恐喝罪でも甲を起訴できる／甲は全事実で起訴不可
- 【まぎらわしい選択肢・規範】告訴期間の徒過／公訴時効の完成
- 【まぎらわしい選択肢・事実】乙は甲の親族／丁も乙を告訴済み

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

小問1＝告訴は訴訟条件で捜査の条件でない→見込み皆無でなければ捜査可（迷っている＝可）。恐喝＝主観的不可分だが相対的親告罪で甲に及ばず→起訴不可。丙花瓶＝相対的でない→及ぶ→起訴可。丁壺＝客観的不可分だが被害者別で及ばず→起訴不可。結論＝甲は丙花瓶のみ。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 告訴の主観的不可分の原則（238条1項）の内容と、その趣旨を書け。
  - 模範解答：内容＝親告罪について共犯の一人に対してした告訴・その取消しは、他の共犯にも効力を生ずる（238条1項）。趣旨＝告訴は特定の犯人を識別するものではなく犯罪事実の訴追を求める意思表示であり、被害者に通常は犯人を特定する能力がないから。
- **［規範クイズ 2/3］** 告訴を欠く親告罪について捜査ができるか、その規範（原則と限定）を書け。
  - 模範解答：訴訟条件は公訴の提起・追行の条件であって捜査の条件ではないから、将来公訴提起の可能性がある限り捜査できる（証拠の収集・保全の必要）。もっとも、公訴提起の可能性が皆無と認められる場合は、捜査の必要性を欠き、親告罪の趣旨からも許されない。
- **［規範クイズ 3/3］** 告訴の客観的不可分の原則（明文なし）の内容と、被害者を異にする科刑上一罪での例外を書け。
  - 模範解答：原則＝一罪の一部についての告訴の効力は全部に及ぶ（告訴人が訴追範囲を一部に限定する意思はないのが通常）。例外＝科刑上一罪がともに親告罪で被害者を異にする場合、被害者自らが告訴しうると定めた230条の趣旨から、告訴していない者の被った犯罪事実には及ばない。

## 4. ○×クイズ（全6問・1問目から最後まで全部出す）

- **［○×クイズ 1/6］** 親告罪において告訴は、公訴の提起・追行に必要とされる訴訟条件であって、捜査を開始・遂行するための条件そのものではない。
  - 正解：○（正しい）
  - 理由：告訴は訴訟条件＝公訴の提起・追行の条件であって、捜査それ自体の適法要件ではない。だから「告訴がまだ無い」段階でも、捜査ができるかは別問題として検討する余地が生まれる。ここを分けるのが小問1の出発点。
- **［○×クイズ 2/6］** 恐喝罪は本来は非親告罪であるが、犯人と被害者との間に一定の親族関係があるときは、刑法251条が準用する244条2項により、告訴がなければ公訴を提起できない親告罪（相対的親告罪）となる。
  - 正解：○（正しい）
  - 理由：相対的親告罪＝犯人と被害者の人的関係によって親告罪性が決まる罪。恐喝は251条が244条を準用し、親族間では2項で相対的親告罪になる（244条1項の刑の免除とは別）。「誰にとって親告罪か」が人ごとに変わる点がミソ。
- **［○×クイズ 3/6］** 一個の行為で数個の物を損壊し観念的競合（科刑上一罪）となる場合、被害者が複数でも、そのうち一人が告訴すれば、当然に全被害事実について告訴の効力が及ぶ。
  - 正解：×（誤り）
  - 理由：原則（客観的不可分）では全部に及ぶが、科刑上一罪がともに親告罪で被害者を異にする場合は例外で、告訴していない被害者の被害事実には及ばない。被害者自らが告訴しうると定めた230条の趣旨からである。「当然に全部」と言い切るのが典型的な誤りで、まず被害者ごとに三事実へ割る発想が要る。
- **［○×クイズ 4/6］** 告訴は特定の犯人を指定してその処罰を求める意思表示であるから、共犯者の一人を名指しして告訴した場合、その効力は名指しされた者にのみ及び、他の共犯者には及ばないのが原則である。
  - 正解：×（誤り）
  - 理由：告訴は犯人の指定ではなく犯罪事実の訴追を求める意思表示であり、犯人を名指ししても効力は左右されない。だから原則として共犯者全員に及ぶ（主観的不可分・238条1項）。名指しで効力が限定されるという理解が誤り。
- **［○×クイズ 5/6］** 一罪の一部について告訴があれば、その効力は原則として一罪の全部に及ぶ（告訴の客観的不可分の原則）が、科刑上一罪がともに親告罪で被害者を異にする場合には、告訴していない被害者の被った犯罪事実には及ばない。
  - 正解：○（正しい）
  - 理由：原則＝客観的不可分（一罪の一部の告訴は全部に及ぶ・明文なし）。例外＝ともに親告罪で被害者を異にする科刑上一罪では、230条の趣旨（被害者自らが告訴しうる）から他方の被害者の事実に及ばない。原則と例外を一組で覚える。
- **［○×クイズ 6/6］** 相対的親告罪では、親族でない共犯者（乙）に対する告訴の効力も、親族である共犯者（甲）に対する告訴が別途なされない限り、乙に対しても生じない。
  - 正解：×（誤り）
  - 理由：乙は非親族＝乙にとって恐喝は非親告罪なので、そもそも告訴を要せず訴追できる。例外で「及ばない」とされるのは親族甲への効力だけ。乙への効力は甲の告訴の有無と無関係。相対的親告罪の非対称性（人ごとに親告罪性が違う）を取り違えた誤り。

（○×クイズはここまで＝全6問。最後の6問目まで出したら「○×クイズ、全6問クリア！」と言って復習へ）
