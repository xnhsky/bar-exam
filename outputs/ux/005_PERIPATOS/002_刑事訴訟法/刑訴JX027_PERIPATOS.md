## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

甲は、任意で提出した尿から覚せい剤が検出されたため、覚せい剤自己使用罪で起訴された。起訴状の公訴事実には、「被告人は、平成26年6月1日から7日までの間に、A町内又はその周辺において、覚せい剤を自己の身体に注射又は服用して施用し、もって覚せい剤を使用した」と記載されている。この起訴状の適法性について、論じなさい。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 甲が平成26年6月1日〜7日のいずれかで覚せい剤を自己使用（幅あり）
- 甲が尿を任意提出
- 鑑定で覚せい剤検出（＝使用の唯一の客観証拠）
- 検察官が幅のある公訴事実を記載して起訴
- この起訴状の適法性が問われている

### 参考（読み上げない。入口の問いの答えを含むので判定にだけ使う）

登場人物：
- 甲｜被告人（尿から覚せい剤検出→起訴された者）
- 検察官｜訴因設定権者（幅のある公訴事実を記載）
- 裁判所｜審判対象の受け手＝主体ではない

一行要約：甲は尿から覚せい剤が検出され起訴。公訴事実は日時7日間・場所概括・方法択一と幅がある。結論は適法。

### 入口の問い（3問）

- **［入口 1/3・事案の整理］** 公訴事実を分解し「幅・不明確」を挙げて（3つ）
  - 答え：拾うのは日時（7日間）・場所（概括）・方法（択一＋量なし）の3か所。いずれも一点に確定されていない。
  - 答え：この3か所が256条3項「できる限り……特定」に反しないかという一本の争点に集約される。まずここで幹を1本に束ねる。
- **［入口 2/3・見当づけ］** 狙う条文と文言を1点に定める ― 見当をつけて
  - 答え：「できる限り」は、絶対的な一点特定ではなく可能な限りの特定で足りることを示す鍵語。だから「幅がある＝直ちに違法」ではなく、論点は「特定の程度が足りるか」に絞れる。ここで幹を1本にできる。
- **［入口 3/3・論点］** 識別説の規範を言って（1つ）
  - 答え：規範＝他の犯罪事実と識別できる程度に特定されていれば、訴因の特定に欠けない（識別説・判例通説）。
  - 答え：補正規範＝特殊事情で概括せざるを得なくても、①構成要件該当性を認識でき ②他の犯罪事実と区別でき ③起訴当時の証拠に基づきできる限り特定していれば足りる。この3点セットが各論の物差し。

### 組み立ての順序（入口の問いのあと、骨子に入る前に読み上げる）

- 順番：第1　訴因の特定の判断基準 → 第2　覚せい剤自己使用罪への当てはめ → 第3　不特定の効果
- 第1　訴因の特定の判断基準
  - 論点1：256条3項「できる限り特定」に反しないか
  - 論点2：特殊事情による概括的記載の許容
- 第2　覚せい剤自己使用罪への当てはめ
  - 論点：複数回使用が疑われるかで場合分け
- 第3　不特定の効果
  - 論点：なし（結論の確認だけ）

この順番の理由（参考。結論・配点には触れず、一言で言い直す）：訴因特定は総論（判断基準を立てる）→ 各論（当該罪へ当てはめる）の順で書く。まず一般的な物差しを作り、その後で覚せい剤自己使用罪に適用する。逆順にすると規範なきあてはめになる。

3. 【論点】特殊事情による概括的記載の許容

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「平成26年6月1日から7日までの間」 → 日時に7日間の幅（一点特定でない）
- 【拾う事実】「A町内又はその周辺」 → 場所が概括的（広がりがある）
- 【拾う事実】「注射又は服用」 → 方法が択一的・使用量の記載なし
- 【拾う事実】『任意で提出した尿から覚せい剤が検出』 → 立証は尿の鑑定のみ・目撃者なし
- 【拾う事実】『複数回使用をうかがわせる証拠は現れない』 → 複数回が顕在化していない事案
- 【事案の整理】幅の三点セット
  - 日時＝「6月1日から7日まで」＝7日間の幅／場所＝「A町内又はその周辺」＝概括／方法＝「注射又は服用」＝択一・使用量の記載なし。どこが緩いかを先に可視化すると、あとで「どの緩みが問題か」を絞れる。
- 【規範の要点】この論点の規範
  - 「防御は釈明・訴因変更という起訴後の手続で柔軟に補える」──この理由づけを噛ませると、なぜ幅のある記載でも足りるのかが一本で通る。趣旨の序列 → 規範の橋を必ず架ける。
- 【効く事実】効く事実（特殊事情）
  - 目撃者が通常いない／尿の鑑定でしか立証できない（遡れる時期は幅をもってしか特定できない）／短期に反復可能で各回が併合罪／使用量・方法は被告人の供述に頼らざるを得ない。これらは白山丸事件のいう「証拠上明らかにし得る事実に限界がある」場合に当たる。
- 【ポイント】特殊事情の書き方
  - 抽象的に「特殊事情がある」と書かず、目撃者なし・尿でしか立証不能という罪の性質を具体的事実として認定するのがコツ。ここを書くと、概括的記載が正当化される素地が示せて説得力が段違いになる。
- 【規範の要点】「で二分する」の規範
  - (1) 疑われない場合＝複数回の可能性が顕在化せず、殊更他の犯罪事実との識別を問題にする必要はない → 構成要件該当性を認識でき、できる限り特定した以上、適法。(2) 疑われる場合＝正面から識別が問題 → 最終一行為説により、検察官が「幅のある日時のうち最終の1回を起訴した趣旨」と釈明して特定を補充 → 適法。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 「特定を欠けば公訴棄却」という出口を一言添えると、なぜ特定の程度をこれほど厳密に論じるのかという実益が示せて答案が締まる。訴因変更（312条）による事後補完可能性も、識別説の理由づけとして一言で橋を架けられる。
- 【まぎらわしい選択肢・論点】採尿手続の違法収集証拠／訴因変更の要否
- 【まぎらわしい選択肢・結論】起訴状は違法（公訴棄却）／訴因不特定で無効
- 【まぎらわしい選択肢・規範】防御権説／最低一行為説
- 【まぎらわしい選択肢・事実】目撃者の供述で特定／自白で日時を確定

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

幹＝幅ある記載→256条3項「できる限り特定」に反しないか。総論＝審判対象画定が第一次→識別説（他の犯罪事実と識別できる程度で足りる）＋補正規範（特殊事情でも構成要件該当性認識可＋識別可＋できる限り特定なら欠けない）。各論＝覚せい剤は目撃者なし・尿でしか立証不能＝特殊事情、複数回疑いで場合分け（不疑=殊更不要／疑い=最終一行為説＋釈明）。結論＝本問は不疑＝適法。効果＝欠ければ338条4号で公訴棄却。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 訴因の特定が要求される趣旨（2つの機能とその序列）を挙げ、そこからなぜ識別説が導かれるかを述べよ。
  - 模範解答：①審判対象画定機能（第一次的・裁判所に審判対象を示す）②防御権告知機能（第二次的・被告人に防御範囲を示す）。防御は釈明・訴因変更で事後補完できるから、他の犯罪事実と識別できる程度の特定で足りる（識別説）。
- **［規範クイズ 2/3］** 特殊事情のため概括的記載にとどめざるを得ない場合の補正規範（訴因特定を肯定する3要素）を挙げよ。
  - 模範解答：①被告人の行為が当該犯罪の構成要件に該当すると認識でき、②他の犯罪事実と区別される程度に特定され、③検察官において起訴当時の証拠に基づきできる限り特定した──この3点を満たせば訴因の特定に欠けない。白山丸事件の特殊事情論を規範化したもの。
- **［規範クイズ 3/3］** 覚せい剤自己使用罪の訴因特定を、証拠上複数回使用が疑われない場合／疑われる場合に分けてそれぞれ結論と理由を述べよ。
  - 模範解答：(1)疑われない場合＝複数回使用の可能性が顕在化せず、殊更識別を問題にする必要がなく、構成要件該当性を認識でき、起訴当時の証拠に基づきできる限り特定した以上、訴因特定に欠けない。(2)疑われる場合＝正面から識別が問題となるが、検察官が最終の1回を起訴した趣旨と釈明して特定を補充すれば足りる。いずれも適法。

## 4. ○×クイズ（全9問・1問目から最後まで全部出す）

- **［○×クイズ 1/9］** 起訴状の公訴事実は、訴因を明示してこれを記載しなければならない（刑事訴訟法256条3項前段）。
  - 正解：○（正しい）
  - 理由：256条3項前段は「公訴事実は、訴因を明示してこれを記載しなければならない」と定める。訴因＝検察官が審判を求める具体的犯罪事実の主張で、当事者主義の下、審判対象を画定する枠。これを明示するのが起訴状の役割で、後段の「できる限り……特定」がその程度を画する。
- **［○×クイズ 2/9］** 刑事訴訟法256条3項の「できる限り」との文言は、検察官に対し、犯罪の日時・場所・方法を常に一点に確定して記載することを義務づけたものである。
  - 正解：×（誤り）
  - 理由：「できる限り」は絶対的・一点の特定を要求する趣旨ではなく、相対的・可能な限りの特定で足りることを示す文言。犯罪の性質上、証拠によって詳らかにできない事情があれば、幅のある記載も直ちには違法とならない。ここが識別説・特殊事情論の出発点になる。
- **［○×クイズ 3/9］** 訴因の特定が要求される第一次的な趣旨は、裁判所に対して審判の対象を明確にする点（審判対象画定機能）にある。
  - 正解：○（正しい）
  - 理由：訴因特定の趣旨は、第一次的には裁判所に審判対象を画定する機能にあり、被告人に防御範囲を示す防御権告知機能は第二次的にとどまるからである。防御は釈明・訴因変更で事後補完できるため、この機能の序列から「他の犯罪事実と識別できる程度で足りる」という識別説の規範が導かれ、それが本問の結論を支える土台になる。
- **［○×クイズ 4/9］** 識別説によれば、訴因は他の犯罪事実と識別することができる程度に特定されていれば、訴因の特定に欠けるところはない。
  - 正解：○（正しい）
  - 理由：これが判例・通説である識別説の規範。訴因の第一次的機能は審判対象の画定にあり、被告人の防御は釈明・訴因変更等の事後手続で補えるから、識別が可能な程度の特定で足りる。防御権説（防御に支障のない具体性を要する）と対立するが、立証困難犯罪への配慮からも識別説が妥当とされる。
- **［○×クイズ 5/9］** 覚せい剤の各使用行為は、原則としてそれぞれ独立の犯罪であり、相互に併合罪の関係に立つ。
  - 正解：○（正しい）
  - 理由：覚せい剤の使用は短期間に反復可能で、各回が別個の犯罪＝併合罪（刑法45条前段）となる。だからこそ幅のある期間に複数回が紛れると「どの1回か」の識別が要求され、訴因特定が構造的に問題化する。この罪数の理解が次のステップの場合分けの前提になる。
- **［○×クイズ 6/9］** 犯罪の性質上、証拠によって日時等を詳らかにできない特殊事情がある場合であっても、日時・場所・方法をすべて一点に特定して記載しない限り、訴因の特定に欠ける。
  - 正解：×（誤り）
  - 理由：白山丸事件（最大判昭37.11.28）は、犯罪の種類・性質等により詳らかにできない特殊事情がある場合には、法の目的を害さない限度で幅のある記載をしても、その一事で直ちに訴因特定を欠くものではないとした。特殊事情があれば概括的記載が許容されるのが判例であり、常に一点特定を要するわけではない。
- **［○×クイズ 7/9］** 覚せい剤自己使用について複数回の使用が疑われる場合、検察官が幅のある日時のうち最終の1回を起訴した趣旨である旨を釈明することにより、他の犯罪事実との識別を可能にして訴因の特定を補充しうる。
  - 正解：○（正しい）
  - 理由：最終一行為説＋釈明による補充の処理。尿から検出されるのは直近（最終）の使用であり証拠と整合し、他の犯罪事実との識別も明確化しやすい。釈明によって審判対象が画定され一事不再理効の範囲も明確になる。なお「少なくとも1回」とする最低一行為説はどの1回か不分明で一事不再理の範囲が曖昧になる難点がある。
- **［○×クイズ 8/9］** 公訴提起の手続がその規定に違反したため無効であるときは、裁判所は判決で公訴を棄却しなければならない（刑事訴訟法338条4号）。
  - 正解：○（正しい）
  - 理由：338条4号は「公訴提起の手続がその規定に違反したため無効であるとき」を公訴棄却判決の事由とする。訴因が特定されていなければ256条3項違反として公訴提起が無効となり、本号により判決で公訴が棄却される。訴因特定を論ずる実益はこの効果にある。
- **［○×クイズ 9/9］** 起訴状における訴因の特定（256条3項）には、有罪判決で「罪となるべき事実」を示す場合（335条1項）と全く同一の、構成要件該当事実を具体的に特定する水準が要求される。
  - 正解：×（誤り）
  - 理由：両者は局面が異なるため区別を要する。訴因の特定（入口＝起訴）は「他の犯罪事実と識別できる程度」で足りるのに対し、罪となるべき事実の判示（出口＝有罪判決）は構成要件該当事実を具体的に特定する必要があるからである。入口と出口で要求水準は同一でなく、幅のある訴因でも起訴段階では特定に欠けないと解される。
