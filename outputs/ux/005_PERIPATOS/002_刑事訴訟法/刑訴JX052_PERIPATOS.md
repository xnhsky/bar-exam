### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】『「令状なく」「Aに無断で」立入り・室内捜索・持ち去り』 → 実質的無令状捜索＝令状主義没却の重大違法
- 【拾う事実】『張り込みの上で意図的に敢行』 → 違法の重大性・排除相当性・著しく不正義を基礎づける
- 【拾う事実】『本件バッグに「異議がない」旨の証拠意見』 → 同意＝責問権放棄（証拠能力付与説）
- 【拾う事実】『Wの腹部を執拗に殴打・脅迫で供述強要』 → 基本原則を無視する重大違法（319Ⅰ参照）
- 【拾う事実】『暴行を受けたのはWでありAではない』 → 自白法則の直接適用なし＋申立適格の起点
- 【拾う事実】『Aの「被害品と知らなかった」』 → 犯罪の成否＝別問題（証拠能力論に混ぜない）
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 本件バッグは強盗の被害品で自然的関連性あり／法律的関連性の障害もなし。詰まるのは③証拠禁止＝令状なく無断でA宅に立ち入る捜索は令状主義（憲法35条・218条1項）を真正面から破る違法。
- 【効く事実】効く事実（本件バッグ）
  - 違法の重大性 → 「令状なく」「Aに無断で」立入り・室内捜索・持ち去り＋張り込みの上で意図的に敢行／排除相当性 → 意図的な令状主義潜脱＝抑止の必要が高い／同意 → Aの「異議がない」旨の証拠意見／例外 → 手続的瑕疵が処分を許さないほど著しく不正義。
- 【規範の要点】供述証拠への適用の規範
  - 取調べには捜索差押えと違い令状主義が直接妥当しないため、「令状主義の精神を没却」ではなく「憲法や刑事訴訟法が所期する基本原則を無視する重大な違法」と文言を読み替え、これ＋排除相当性で排除する。共通規範はバッグで立てたものを受ける。
- 【効く事実】効く事実（本件供述調書）
  - 重大な違法 → Wの腹部を執拗に殴打し脅迫文言で供述を強要（「強制」「脅迫」＝319条1項参照）／排除相当性 → 許容すれば将来の暴行取調べを助長／自白法則の切り分け → 暴行を受けたのは第三者WでありAではない＝Aの「自白」ではない。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 排除の根拠を適正手続の保障のみに求めれば、権利侵害を受けていない第三者Aの申立ては否定されそう。しかし根拠には司法の廉潔性維持・将来の違法捜査抑止もあり、これらは被侵害者が誰かを問わない。よって権利侵害の有無を問わず第三者Aにも申立適格を肯定（非限定説）→ 証拠能力否定。バッグで立てた根拠論をここで回収すると一貫する。
- 【まぎらわしい選択肢・論点】違法性の承継の有無／伝聞例外(321条1項)の要件／自白法則(319条1項)の直接適用
- 【まぎらわしい選択肢・結論】本件バッグは証拠能力あり／本件供述調書は証拠能力あり
- 【まぎらわしい選択肢・規範】絶対的排除説／毒樹の果実の総合判断
- 【まぎらわしい選択肢・事実】令状の事前呈示なし／Aが暴行を受けた

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

本件バッグ＝令状なく無断でA宅捜索＝実質的無令状捜索で令状主義没却の重大違法＋抑止相当。もっとも「異議なし」＝同意（責問権放棄・326準用で原則証拠能力付与）。しかし意図的無令状＝著しく不正義ゆえ例外的に排除＝証拠能力否定。本件供述調書＝Wへの暴行で違法収集（取調べは令状主義直接妥当せず「基本原則を無視する重大違法」に読み替え）。暴行の相手は第三者W＝自白法則直接適用なし。被侵害者はWだが排除根拠＝廉潔性・抑止から第三者Aにも申立適格肯定＝証拠能力否定。いずれも取調べ不可。

## 3. 規範クイズ（5問）

- **Q04［規範］** 違法収集証拠排除法則の二要件と、その根拠となる三つの価値を挙げよ。
  - 模範解答：①令状主義の精神を没却するような重大な違法があること（違法の重大性）②これを証拠として許容することが将来の違法捜査抑制の見地から相当でないこと（排除相当性）。両方そろって初めて排除。根拠は適正手続・司法の廉潔性・違法捜査抑止。
- **Q05［規範］** 違法収集証拠につき当事者の同意があってもなお証拠能力が否定される例外の基準を挙げよ（証拠能力付与説を前提に）。
  - 模範解答：同意は責問権の放棄（処分行為）として原則証拠能力を付与する（326条準用）が、手続的瑕疵が当事者の処分を許さないほど著しく不正義な場合には、司法の廉潔性・違法捜査抑止の見地から例外的になお証拠能力が失われる。本問の意図的な無令状捜索はこの例外に当たる。
- **Q06［規範］** 証拠能力付与説が「同意は証拠能力を付与する」と説明する理論的根拠と、この構成に対する批判を一言で述べよ。
  - 模範解答：根拠＝当事者主義の下、同意は証拠能力の欠如に対する責問権の放棄（処分行為）であり、当事者の処分により証拠能力が付与される（326条準用）。批判＝326条は本来伝聞例外の規定であり、これを違法収集証拠に準用する明文上の根拠は必ずしもない（座りの悪さ）。
- **Q07［規範］** 第三者への暴行で得た供述調書を、自白法則（319条1項）ではなく違法収集証拠排除法則で処理すべき理由を述べよ。
  - 模範解答：自白法則（319条1項）の「自白」は被告人自身の供述をいう。本件で暴行を受け供述したのは第三者WであってAではないから、Wの供述録取書はAの「自白」に当たらず、自白法則は直接適用されない。そこで違法収集証拠排除法則で処理する。「暴行＝自白法則で一発排除」と即断すると相手が第三者である点を見落として大幅減点。
- **Q08［規範］** 権利侵害を受けていない第三者に違法収集証拠排除の申立適格を認める根拠を述べよ。
  - 模範解答：排除法則の根拠は適正手続の保障に尽きず、司法の廉潔性の維持・将来の違法捜査の抑止にもある。これらの根拠は違法捜査を裁判所が是認しないという客観的要請で、被侵害者が誰であるかを問わない。したがって権利侵害の有無を問わず第三者による排除の申立てを肯定し、当該証拠の証拠能力を否定できる。反対＝適正手続説（限定説）にも一言触れると厚い。

## 4. ○×クイズ（7問）

- **Q09［○×］** 証拠を「取り調べることができるか」という問いは、当該証拠に証拠能力が認められるか（刑訴法317条の証拠裁判主義を前提とする証拠能力の有無）を問うものである。
  - 正解：○（正しい）
  - 理由：「取調べの可否」＝公判で証拠として用いてよいかの資格＝証拠能力の問題。事実の認定は証拠による（317条・証拠裁判主義）から、証拠能力を欠く証拠は取り調べられない。取り調べた後の信用性＝証明力とは別次元で、違法収集証拠排除は証拠能力の段階で証拠を締め出す法則。ここを出発点に据える。
- **Q10［○×］** 違法収集証拠排除法則は刑訴法に明文の規定を欠くが、適正手続の保障（憲法31条）・司法の廉潔性・将来の違法捜査の抑止を根拠として、判例上、証拠能力を否定しうる解釈準則として承認されている。
  - 正解：○（正しい）
  - 理由：排除法則は明文なき解釈上の準則。証拠物自体の価値は違法によって変わらないから直ちには排除できないが、真相究明も適正手続（憲法31条）の下でなされるべきで、司法の廉潔性・将来の違法捜査抑止の見地から、一定の場合に証拠能力を否定する（最判昭53.9.7）。要件は条文ではなく趣旨から導くので、答案では根拠を示して規範を立てる。
- **Q11［○×］** 証拠とすることの同意（刑訴法326条1項）の法的性質については、当事者主義の下で証拠能力の欠如に対する責問権の放棄という処分行為とみて、同意により証拠能力が付与されると解する見解（証拠能力付与説）がある。
  - 正解：○（正しい）
  - 理由：本件バッグでAは「異議なし」＝同意を述べている。同意の性質を、当事者主義の観点から反対尋問権等の欠如に対する責問権の放棄＝処分行為と捉え、これにより証拠能力が付与されると解するのが証拠能力付与説（326条準用）。もっとも同条は本来伝聞例外の規定で、違法収集証拠への準用には理論的違和感があるとの批判もある。
- **Q12［○×］** 捜査機関が、令状によらず居住者に無断でその住居に立ち入って室内を捜索し証拠物を持ち去る行為は、実質的に無令状の捜索差押えであって、令状主義（憲法35条・刑訴法218条1項）の精神を没却する重大な違法にあたりうる。
  - 正解：○（正しい）
  - 理由：令状なく無断で住居に立ち入り室内を捜索して物を持ち去る行為は実質的な無令状の捜索差押えで、刑法上は住居侵入に等しく、令状主義を正面から破る。しかも本問のPは張り込みの上、施錠されていないのを奇貨として意図的に敢行しており、違法の重大性・排除相当性はほぼ明らか。ここはあっさり認定してよい。
- **Q13［○×］** 被告人が違法収集証拠につき「異議がない」旨の証拠意見（同意）を述べた以上、その証拠は常に証拠能力を取得し、もはや排除される余地はない。
  - 正解：×（誤り）
  - 理由：本問前半最大の罠。証拠能力付与説でも同意は原則として証拠能力を付与するにとどまり、手続的瑕疵が当事者の処分を許さないほど著しく不正義な場合には例外的になお証拠能力は失われる。本問の意図的な無令状捜索はまさにその例外で、同意があっても証拠能力は否定。
- **Q14［○×］** 取調べにおける暴行によって得られた供述証拠の違法性を評価する場合も、捜索差押えと同様に「令状主義の精神を没却するような重大な違法」という文言をそのまま用いるべきである。
  - 正解：×（誤り）
  - 理由：令状主義（憲法35条）は捜索・押収の場面の原則で、取調べには直接妥当しない。だから供述証拠の違法評価では「令状主義の精神を没却」を無自覚に流用せず、「憲法や刑事訴訟法が所期する基本原則を無視する重大な違法」と文言を読み替える。排除の枠組み（重大違法＋排除相当性）自体はバッグと共通。
- **Q15［○×］** 違法収集証拠排除法則の根拠を、適正手続の保障のみならず司法の廉潔性の維持・将来の違法捜査の抑止にも求める立場からは、自己の権利を侵害されていない第三者による証拠排除の申立ても認められる。
  - 正解：○（正しい）
  - 理由：排除の根拠を適正手続の保障だけに求めると、権利を侵害された本人（W）しか排除を申し立てられない（限定説）。しかし根拠には司法の廉潔性・違法捜査抑止もあり、これらは違法捜査を裁判所が是認しないという客観的要請だから、被侵害者が誰かを問わない。よって権利侵害を受けていない第三者Aにも申立適格を肯定できる（非限定説）。本問はこの立場でAの申立てを認め、供述調書の証拠能力を否定する。
