### 骨子（3項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　前提　設備なき庁舎での接見拒否の可否

- 見出しの補足（結論を含む。項目の終わりに読む）：39条1項・2項
1. 【論点】接見設備を欠く庁舎内での接見拒否の可否 → 規範：逃亡・罪証隠滅・戒護支障を防げる設備の部屋の存在が秘密接見の物的前提（39条2項・規則30条）
2. 本件庁舎に接見設備の部屋なし → 秘密接見（39条1項）を認める余地なし
- 結論：拒否自体は 違法でない（→もっとも、で本丸へ橋渡し）

#### 第2　本丸　面会接見の配慮義務〔前段〕

- 見出しの補足（結論を含む。項目の終わりに読む）：39条の趣旨
1. 【論点】なお即時接見を求める弁護人への面会接見の配慮義務 → 規範：39条の趣旨（接見交通権と捜査の必要の合理的調整）→ 配慮義務の4要件
2. なお即時接見を要求／「立会人可」＝面会接見でも可の意向
3. 必要性 ＝ 少年・一貫否認・鑑別所移送 → 肯定
   - あてはめ：取調べは1時間40分後＝現に取調べ中でも直近の確実な予定でもない → 顕著な支障なし
4. Pは意向確認も措置もせず → 不作為
- 結論：配慮義務違反 ＝ Pの不作為は違法

#### 第3　後段の比較

- 見出しの補足（結論を含む。項目の終わりに読む）：成人・自白済み
1. 同一規範のまま必要性のあてはめだけ変える → 成人・自白済み＝黙秘権教示の切迫性低い
2. 即時接見の必要性 否定 → 配慮義務 発生せず
- 結論：Pの不作為は 違法ではない（適法）

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「接見設備がある部屋が存在しない」 → 秘密接見を認める余地の有無（前提）を基礎づける
- 【拾う事実】「立会人がいてもかまわない」 → 面会接見でも可の意向表明＝配慮義務の決定的事実
- 【拾う事実】『少年／一貫して否認／鑑別所へ移送』 → 即時接見の必要性の三本柱（前段）
- 【拾う事実】「1時間40分後にAの取調べ」 → 顕著な支障の有無（現に取調べ中でも直近の確実な予定でもない）
- 【拾う事実】『（後段）成人・自白済み』 → 必要性が減退＝比較で結論が分かれる軸
- 【事案の整理】対象の絞り方
  - 問われるのはPが「Lの即時接見の申出に応じなかったこと」の適法性。主体＝検察官P、相手＝弁護人L。設備の部屋が存在しないことは動かせない前提事実として受け止め、そこで終わらせないのがコツ。
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 設備の部屋が存在しない＝逃亡・罪証隠滅・戒護上の支障を防げる物的前提を欠く＝立会人なしの秘密接見を認める余地なし＝拒否自体は違法でない。ただし「もっとも」で必ず面会接見の配慮義務へ橋を架ける（設備なしで打ち切ると大幅減点）。
- 【効く事実】前段で効く事実（必要性を高める三本柱）
  - 即時接見の必要性 → 少年（状況把握能力が未成熟）／一貫して否認（黙秘権の教示が急務）／鑑別所へ移送（動揺・励ましの必要）／面会接見でも可の意向 → 「立会人がいてもかまわない」を直接引用／顕著な支障なし → 取調べは1時間40分後（現に取調べ中でも直近の確実な予定でもない）。
- 【ポイント】比較の型（一文）
  - 後段は「Aが成人で状況把握能力があり、既に自白していて黙秘権教示の必要も乏しい」→ 即時接見の必要性が否定される → 配慮義務は発生しない → Pの不作為は適法。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 面会接見の配慮義務違反＝不作為の違法／接見指定の違法＝指定権行使という作為の違法、と対で押さえる。判断基準も、前者＝即時接見の必要性＋顕著な支障の不存在、後者＝捜査の中断による支障が顕著か（杉山事件）で異なる。
- 【まぎらわしい選択肢・論点】接見指定の適法性(39条3項)／秘密交通権侵害の有無／余罪捜査と接見指定の可否
- 【まぎらわしい選択肢・結論】拒否は違法／Pの措置は適法(前段)
- 【まぎらわしい選択肢・規範】顕著な支障説／比例原則
- 【まぎらわしい選択肢・事実】罪証隠滅のおそれ／余罪の存在

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

前提＝設備なし→秘密接見の余地なし→拒否は違法でない。本丸＝もっとも39条の趣旨から配慮義務、なお即時接見・必要性（少年・否認・鑑別所）・立会人可・顕著な支障なし（1時間40分後）→Pの不作為は違法。後段＝成人・自白済みで必要性否定→配慮義務発生せず→適法。

## 3. 規範クイズ（全2問・1問目から最後まで全部出す）

- **［規範クイズ 1/2］** 接見設備のある部屋を欠く庁舎内で、検察官が接見の申出を拒否できるかの規範（拒否が違法でないといえる根拠）を述べよ。
  - 模範解答：被疑者と弁護人等との接見には、被疑者の逃亡・罪証の隠滅・戒護上の支障の発生の防止の観点からの制約がある（39条2項・規則30条参照）。そこで、立会人なしの接見を認めても逃亡・罪証隠滅を防止でき戒護上の支障が生じない設備のある部屋等が存在しない場合には、接見の申出を拒否しても違法とはいえない（最判平17.4.19第1段）。
- **［規範クイズ 2/2］** 設備を欠く庁舎で接見を拒否された後、検察官に面会接見の配慮義務が発生する要件と、その不履行の効果を述べよ。
  - 模範解答：39条の趣旨（接見交通権の行使と捜査の必要の合理的調整）から、①検察官が設備不存在を理由に拒否したにもかかわらず、②弁護人等がなお庁舎内での即時接見を求め、③即時に接見をする必要性があり、④弁護人等が面会接見でも差し支えないとの意向を示したときは、⑤捜査に顕著な支障が生ずる場合は格別、検察官は面会接見ができるよう特別の配慮をすべき義務を負う。これを怠り何らの措置も執らない不作為は違法となる（最判平17.4.19第2段）。

## 4. ○×クイズ（全7問・1問目から最後まで全部出す）

- **［○×クイズ 1/7］** 接見交通権（刑訴法39条1項）は、身体拘束を受けた被疑者が弁護人の援助を受ける機会を保障するもので、憲法34条前段の弁護人依頼権に由来する重要な権利である。
  - 正解：○（正しい）
  - 理由：接見交通権は弁護人依頼権を実質化する中核的権能で、憲法34条前段に由来する重要な権利である（最大判平11.3.24）。だから捜査機関は原則としてその行使を保障すべきで、制約には慎重さが要求される。この憲法的重みが、設備を欠く場合でも「拒否して終わり」にせず配慮義務を導く価値判断の背後にある。
- **［○×クイズ 2/7］** 接見設備のある部屋が存在しないのに接見を拒否した措置は、接見指定（39条3項）の適否として処理するのが正しい。
  - 正解：×（誤り）
  - 理由：39条3項の接見指定は設備がある前提で「いつ・どこで」を調整する制度。設備自体が存在しない本問とは局面が異なり、混同してはならない。設備不存在の場面は、①秘密接見を認める余地の有無（1項・2項）と、②面会接見の配慮義務（39条の趣旨）の問題として処理する。
- **［○×クイズ 3/7］** 39条1項の接見（秘密交通）も、被疑者の逃亡・罪証の隠滅・戒護上の支障の発生の防止の観点からの制約に服し（同2項・刑訴規則30条参照）、これらを防げる設備のある部屋の存在がその物的前提となる。
  - 正解：○（正しい）
  - 理由：秘密接見といえど無制約ではなく、逃亡・罪証隠滅・戒護上の支障を防ぐための措置に服する（39条2項）。立会人なしの接見を認めてもこれらの支障が生じない設備のある部屋が物的前提であり、これを欠く場合には秘密接見を認める余地がなく、拒否しても違法とはいえない（最判平17.4.19第1段）。
- **［○×クイズ 4/7］** 検察庁の庁舎内に接見設備のある部屋が存在しない場合、検察官は弁護人の即時接見の申出に対し、何らの措置も講じないまま一切拒否しても違法となる余地はない。
  - 正解：×（誤り）
  - 理由：設備を欠くため秘密接見（39条1項）を認める余地がなく、その拒否自体は違法でない。しかしそこで終わりではない。なお即時接見を求め、必要性が認められ、面会接見でも可の意向があるのに、検察官が特別の配慮を怠り何らの措置も執らなければ、その不作為が違法となりうる（最判平17.4.19第2段）。設備なしを理由に接見交通権を空洞化させてはならない。
- **［○×クイズ 5/7］** 面会接見とは、立会人なしの秘密交通が保障された接見をいい、39条1項所定の接見そのものである。
  - 正解：×（誤り）
  - 理由：面会接見は立会人の居る部屋での短時間の接見など、秘密交通権が十分に保障されない態様の接見であり、39条1項所定の秘密接見そのものではない。設備を欠き秘密接見を認める余地がない場合に、39条全体の趣旨から導かれる代替的な配慮として位置づけられる。両者を混同すると規範の理解が崩れる。
- **［○×クイズ 6/7］** 「即時に接見をする必要性」は、被疑者の判断能力・防御上の緊急性・心理的状況等を総合して判断され、成人で既に自白しており黙秘権教示の切迫性が低い場合には、その必要性は否定されうる。
  - 正解：○（正しい）
  - 理由：必要性は被疑者の判断能力・防御上の緊急性・心理的状況を総合考慮する。少年・否認・環境変化があれば必要性は高く（前段）、成人・自白済みで教示の切迫性が低ければ必要性は否定されうる（後段）。必要性が否定されれば配慮義務は発生せず、拒否の不作為も適法となる。同じ規範であてはめの差だけで結論が分かれるのが本問の型。
- **［○×クイズ 7/7］** 面会接見の配慮義務違反は、検察官が特別の配慮をすべきなのに何らの措置も執らなかったという不作為の違法として構成され、接見指定権の行使という作為の違法とは違法の型が異なる。
  - 正解：○（正しい）
  - 理由：配慮義務違反は「特別の配慮を怠り何らの措置も執らなかった」不作為を違法と評価する（最判平17.4.19）。他方、接見指定（39条3項）の違法は日時等を指定する作為の違法。両者は問題状況（設備の有無）も違法の型（不作為／作為）も異なる。
