### 骨子（3項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　前提　設備なき庁舎での接見拒否の可否

- 見出しの補足（結論を含む。項目の終わりに読む）：39条1項・2項
1. 【論点】接見設備を欠く庁舎内での接見拒否の可否 → 規範：逃亡・罪証隠滅・戒護支障を防げる設備の部屋の存在が秘密接見の物的前提（39条2項・規則30条）
2. 本件庁舎に接見設備の部屋なし → 秘密接見（39条1項）を認める余地なし
- 結論：拒否自体は 違法でない（→もっとも、で本丸へ橋渡し）

#### 第2　本丸　面会接見の配慮義務〔前段〕

- 見出しの補足（結論を含む。項目の終わりに読む）：39条の趣旨
1. 【論点】なお即時接見を求める弁護人への面会接見の配慮義務 → 規範：39条の趣旨（接見交通権と捜査の必要の合理的調整）→ 配慮義務の4要件
2. なお即時接見を要求／「立会人可」＝面会接見でも可の意向
3. 必要性 ＝ 少年・一貫否認・鑑別所移送 → 肯定
   - あてはめ：取調べは1時間40分後＝現に取調べ中でも直近の確実な予定でもない → 顕著な支障なし
4. Pは意向確認も措置もせず → 不作為
- 結論：配慮義務違反 ＝ Pの不作為は違法

#### 第3　後段の比較

- 見出しの補足（結論を含む。項目の終わりに読む）：成人・自白済み
1. 同一規範のまま必要性のあてはめだけ変える → 成人・自白済み＝黙秘権教示の切迫性低い
2. 即時接見の必要性 否定 → 配慮義務 発生せず
- 結論：Pの不作為は 違法ではない（適法）

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「接見設備がある部屋が存在しない」 → 秘密接見を認める余地の有無（前提）を基礎づける
- 【拾う事実】「立会人がいてもかまわない」 → 面会接見でも可の意向表明＝配慮義務の決定的事実
- 【拾う事実】『少年／一貫して否認／鑑別所へ移送』 → 即時接見の必要性の三本柱（前段）

- 【拾う事実】『（後段）成人・自白済み』 → 必要性が減退＝比較で結論が分かれる軸
- 【事案の整理】対象の絞り方
  - 問われるのはPが「Lの即時接見の申出に応じなかったこと」の適法性。主体＝検察官P、相手＝弁護人L。設備の部屋が存在しないことは動かせない前提事実として受け止め、そこで終わらせないのがコツ。
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 設備の部屋が存在しない＝逃亡・罪証隠滅・戒護上の支障を防げる物的前提を欠く＝立会人なしの秘密接見を認める余地なし＝拒否自体は違法でない。ただし「もっとも」で必ず面会接見の配慮義務へ橋を架ける（設備なしで打ち切ると大幅減点）。
- 【効く事実】前段で効く事実（必要性を高める三本柱）
  - 即時接見の必要性 → 少年（状況把握能力が未成熟）／一貫して否認（黙秘権の教示が急務）／鑑別所へ移送（動揺・励ましの必要）／面会接見でも可の意向 → 「立会人がいてもかまわない」を直接引用／顕著な支障なし → 取調べは1時間40分後（現に取調べ中でも直近の確実な予定でもない）。
- 【ポイント】比較の型（一文）

- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 面会接見の配慮義務違反＝不作為の違法／接見指定の違法＝指定権行使という作為の違法、と対で押さえる。判断基準も、前者＝即時接見の必要性＋顕著な支障の不存在、後者＝捜査の中断による支障が顕著か（杉山事件）で異なる。

- 【まぎらわしい選択肢・規範】顕著な支障説／比例原則
- 【まぎらわしい選択肢・事実】罪証隠滅のおそれ／余罪の存在

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

前提＝設備なし→秘密接見の余地なし→拒否は違法でない。本丸＝もっとも39条の趣旨から配慮義務、なお即時接見・必要性（少年・否認・鑑別所）・立会人可・顕著な支障なし（1時間40分後）→Pの不作為は違法。後段＝成人・自白済みで必要性否定→配慮義務発生せず→適法。
