- 【拾う事実】『一罪 → 併合罪／併合罪 → 包括一罪』 → 罪数評価の変動（専権＝補正の要否）

- 【拾う事実】『後段は事実に変化なし』 → 訴因変更不要（前段の裏返し）
- 【事案の整理】2タグで拾う
  - ズレは必ず(ⅰ)審判対象たる事実（日時・場所・回数）と(ⅱ)罪数評価（一罪⇔数罪）の二層に分けて記録する。この二層の切り分けが前段・後段を貫く軸になる。

  - 要否 → 「10時ころ」→「10時ころ＋翌日0時ころ」の日時変動・一個の行為が二個に／可否 → 暴行の総数10発・加療4週間の結果は共通／罪数 → 一罪→併合罪＝法的評価／訴追意思 → 翌日0時の暴行は「別事件」。
- 【規範の要点】要否の裏側適用の規範
  - 訴因変更を要するのは審判対象画定に不可欠な事実に変動が生ずる場合 → 後段は事実に変動がない → 訴因変更不要。数罪⇔一罪は法的評価＝裁判所の専権 → 補正も不要 → そのまま包括一罪で認定。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 裁判所は自ら訴因を変更できない（審判対象設定権＝検察官）→ 釈明で促す。命令（312条2項）は形成力なし。翌日0時の「別事件」は訴追意思を釈明で確認（不告不理）。ここまで書いて措置が確定する。
- 【まぎらわしい選択肢・論点】一事不再理の効力／公訴時効の完成／訴訟条件の追完
- 【まぎらわしい選択肢・結論】公訴を棄却すべき／訴因変更命令を要する
- 【まぎらわしい選択肢・規範】縮小認定の法理／防御説
- 【まぎらわしい選択肢・事実】罰条の変更あり／被告人の同意

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

前段＝日時・回数が動く＝画定に不可欠な事実の変動で訴因変更が要る、総数・結果が共通で公訴事実の同一性あり＝可能、一罪→数罪は法的評価＝専権で補正不要、自ら変更できず釈明で促す＋別事件の訴追意思を確認。後段＝事実不変で訴因変更不要、罪数は専権で補正不要＝そのまま包括一罪で認定。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 訴因変更の要否の判断基準（最決平成13年）を述べよ。
  - 模範解答：審判対象の画定に不可欠な事実に変動があれば、防御に不利益がなく罰条に変更がなくとも原則として訴因変更を要する（第一次基準）。加えて、訴因に明示され被告人の防御にとって重要な事実の変動も、争点明確化のため原則として要する（第二次基準）。
- **［規範クイズ 2/3］** 一罪として起訴された訴因が実は数罪と判明した場合、罪数固有の「訴因の補正」を要するか。結論と理由を述べよ。
  - 模範解答：不要。一罪か数罪かは犯罪事実そのものではなく、これに対する法的評価であって裁判所の専権に属する。事実の変動を訴因変更手続で処理すれば罪数の齟齬も包摂されて解消されるから、罪数固有の補正手続を別途要しない。
- **［規範クイズ 3/3］** 訴因の日時・回数が動く事案で、なぜ「公訴事実の同一性」が認められ訴因変更が可能となるのか、その認定枠組みと効く事実を述べよ。
  - 模範解答：公訴事実の同一性は基本的事実関係の社会的同一性で判断する。日時・回数が動いても、被害者に加えられた暴行の総数（10発）と生じた結果（加療4週間の傷害）に変化がなければ、基本的事実関係は同一と評価でき、同一性が認められて訴因変更は可能となる。

## 4. ○×クイズ（全7問・1問目から最後まで全部出す）

- **［○×クイズ 1/7］** 訴因は、検察官が主張する具体的犯罪事実であり、審判の対象を画定するとともに、被告人の防御の範囲を示す機能を有する。
  - 正解：○（正しい）
  - 理由：当事者主義的訴訟構造（刑訴256条3項参照）の下、訴因は審判対象を画定し（識別機能）、被告人の防御の範囲を示す（防御機能）。この二機能こそ「訴因変更の要否」を論ずる出発点。訴因と心証がズレたら、まずこの機能に立ち返る。
- **［○×クイズ 2/7］** 訴因変更の要否は、審判対象の画定に不可欠な事実に変動が生じたか否かを基準として判断される。
  - 正解：○（正しい）
  - 理由：最決平成13年4月11日は、審判対象の画定に不可欠な事項の変動があれば、被告人の防御に不利益がなく罰条に変更がなくとも、原則として訴因変更を要するとした。これが要否の第一次基準。防御上重要な事実の変動は第二次基準として補充的に働く。
- **［○×クイズ 3/7］** 訴因変更が許されるのは「公訴事実の同一性を害しない限度」に限られる（刑訴312条1項）。
  - 正解：○（正しい）
  - 理由：312条1項は、検察官の請求により「公訴事実の同一性を害しない限度において」訴因の追加・撤回・変更を許すと定める。これが訴因変更の可否（外枠）を画する。要否（変更が必要か）とは別の関門であり、両者を切り分けて論ずる。
- **［○×クイズ 4/7］** 訴因変更の可否を画する「公訴事実の同一性」は、両訴因の基本的事実関係が社会的に同一といえるかによって判断される。
  - 正解：○（正しい）
  - 理由：公訴事実の同一性は、基本的事実同一説により、変更前後の訴因が社会的事実として基本的に同一といえるかで判断する（両訴因の非両立性を補助基準とする見解もある）。暴行の総数・結果が共通なら基本的事実は同一で、同一性が認められ変更は可能となる。
- **［○×クイズ 5/7］** 訴因と異なる事実を認定するため訴因変更が必要な場合、裁判所は、検察官の請求を待たず、職権で訴因を変更したうえで有罪を認定することができる。
  - 正解：×（誤り）
  - 理由：審判対象の設定は検察官の権限に属する（国家訴追主義・247条）。裁判所は自ら訴因を変更できず、検察官に釈明を求めて訴因変更を促すにとどまる。訴因変更命令（312条2項）を発しても形成力はなく（最大判昭40年）、命令だけで訴因は変更されない。「裁判所が職権で変更できる」は典型的な誤り。
- **［○×クイズ 6/7］** 数罪（併合罪）として起訴された訴因を裁判所が包括一罪と評価する場合において、審判対象たる事実に変動がないときは、裁判所は訴因変更を経ずにそのまま有罪を認定することができる。
  - 正解：○（正しい）
  - 理由：訴因変更の要否は審判対象画定に不可欠な事実の変動を基準とする。事実に変動がなければ訴因変更は不要。併合罪か包括一罪かは犯罪事実に対する法的評価であり裁判所の専権に属するから、訴因の補正も不要で、そのまま一罪として有罪認定できる。
- **［○×クイズ 7/7］** 裁判所は、検察官の訴追意思が及ばない事件について、これを審判の対象として有罪を認定することはできない（不告不理の原則）。
  - 正解：○（正しい）
  - 理由：不告不理の原則により、裁判所は訴えのない事項を審判できない。国家訴追主義（247条）の下、審判対象の外縁は検察官の訴追意思で画される。訴追意思の及ばない「別事件」を裁判所が取り込めば不告不理に反するから、裁判所は釈明でその有無を確認すべきことになる。
