#### 第1　欺罔的入室

- 見出しの補足（結論を含む。項目の終わりに読む）：必要な処分
1. Pらは令状呈示前にガス点検を装い甲に開扉させ入室 → 【論点】呈示前の入室措置が「必要な処分」（222条1項・111条1項）として許されるか
2. 規範：「執行について」＝前提行為を含む／必要かつ社会通念上相当な態様
   - あてはめ：覚せい剤＝水に流し罪証隠滅容易→必要性／甲自ら開扉＝平和裡・第三者PV侵害想定なし→相当性
- 結論：必要な処分として許容 ＝ 欺罔的入室は適法

#### 第2　本件バッグの捜索

- 見出しの補足（結論を含む。項目の終わりに読む）：場所令状と物
1. 令状は「場所」（甲方・219条1項）、本件バッグは令状に載らない「物」 → 【論点】場所令状で物を捜索できるか
2. 規範：場所内で住居権者が管理する物は「場所」に包摂→効力及ぶ／携帯は偶然／身体は別令状
   - あてはめ：バッグはリビングのテーブル上＝甲乙の管理を推認／甲が抱え込んでも携帯は偶然
- 結論：効力が及ぶ ＝ 本件バッグの捜索は適法

#### 第3　令状呈示・差押え

1. 呈示（222条1項・110）は着手前が原則 → 入室（着手）前に呈示済み → 事後提示の問題なし
2. 差押え（222条1項・99条1項）＝覚せい剤・メモは記載物件かつ被疑事実と関連
- 結論：呈示・差押えも適法＝下線部の行為はいずれも適法

- 【拾う事実】『捜索場所＝「甲方」（場所）／バッグは令状に載らない「物」』 → 場所令状で物を捜索できるか
- 【拾う事実】『バッグは「リビングのテーブル上」／甲が「抱え込んだ」』 → 住居権者の管理の推認・携帯は偶然
- 【拾う事実】『差押物＝小分けの覚せい剤・甲の手書きメモ』 → 記載物件性・被疑事実との関連性
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 令状は正規発付・場所「甲方」・差押物「覚せい剤・メモ」＝争いなしを一言で通す。詰まる所だけ彫る ── ①呈示前の入室（受け皿＝必要な処分）／③令状に載らないバッグの捜索（受け皿＝場所への包摂）。
- 【効く事実】「必要性＋相当性」のあてはめで使う事実
  - 必要性 → 覚せい剤は「水に流す」等で短時間の罪証隠滅が容易／来意を告げれば証拠隠滅のおそれ。相当性 → 甲が自ら錠を外し開扉＝平和裡・穏当（錠破壊より軽微）／捜索場所＝甲方で第三者のプライバシー侵害は想定されず。事実は必ず評価語（実効性確保に必要・社会通念上相当）と結合させる。
- 【規範の要点】包摂の規範
  - 法は「場所」と「物」を区別する（219Ⅰ）が、物ごとに令状を要するのは煩瑣で、場所の記載の趣旨（その場所のプライバシー保護）からすれば当該場所内で住居権者が管理する物は「場所」に包摂される。よって場所令状の効力が及び、居合わせた者が携帯していても携帯は偶然の事情にすぎず結論を左右しない（最決平6.9.8）。ただし身体そのものの捜索には及ばない。
- 【まぎらわしい選択肢・論点】別件捜索・差押えの可否／所持品検査の限界
- 【まぎらわしい選択肢・結論】欺罔的入室は令状主義違反で違法／場所令状で物は捜索できず違法
- 【まぎらわしい選択肢・規範】令状呈示時点限定説／管理権拡張説（第三者持込物にも及ぶ）
- 【まぎらわしい選択肢・事実】錠を破壊して強制的に入室／甲の身体そのものを捜索

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

第1＝呈示前入室は「執行について」に含む→必要（覚せい剤＝罪証隠滅容易）かつ相当（自ら開扉＝穏当）→必要な処分で適法。第2＝場所と物は区別（219条1項）だが場所内で管理する物は包摂→効力及ぶ、携帯は偶然（バッグ抱え込みも同じ）、身体は別→バッグ捜索は適法。第3＝入室前に呈示済み＝着手前呈示OK、覚せい剤・メモは記載物件かつ関連性→差押え適法。よって下線部の行為はいずれも適法。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 令状呈示前の欺罔的な立入りが「必要な処分」（222条1項・111条1項）として許される規範（呈示前でも可の理由＋必要性・相当性の枠組み）を述べよ。
  - 模範解答：「執行について」（111Ⅰ）は執行それ自体に限らず前提となる不可欠な行為を含むから、令状呈示前でも「必要な処分」をなしうる。もっとも無制限ではなく、捜査比例の原則から①捜索差押えの執行目的の達成に必要であり、かつ②社会通念上相当な態様であることを要する（最決平14.10.4）。この必要性＋相当性の枠組みに事実をあてはめる。
- **［規範クイズ 2/3］** 「場所」に対する捜索差押許可状の効力が、その場所内で住居権者が管理する「物」（居合わせた者の携帯品を含む）に及ぶことを基礎づける規範（趣旨＋理由）を述べよ。
  - 模範解答：①差押対象物が存在しうる物に1つずつ令状をとることは煩瑣で捜査機関に不可能を強いる。②219条1項が場所を特定した趣旨は当該場所のプライバシー等の保護にあり、その場所内で管理される物のプライバシーは場所のそれに包摂される。よって当該場所の住居権者が管理する物には場所令状の効力が及ぶ。この理は物を居合わせた者が携帯していても変わらない（携帯は偶然の事情）。ただし身体そのものの捜索には別途令状を要する（最決平6.9.8）。
- **［規範クイズ 3/3］** 令状呈示の時期の原則（着手前呈示）とその趣旨、及び差押えが適法となる要件（記載物件性・関連性）を述べよ。
  - 模範解答：令状呈示（222Ⅰ・110）は、手続の公正を担保し被処分者の人権に配慮する趣旨だから、執行の着手前に呈示するのが原則（もっとも実効性確保のためやむを得ない場合は着手直後の呈示も可＝最決平14.10.4）。差押えは、差押目的物が令状記載の物件であり、かつ被疑事実との関連性が認められれば適法（222Ⅰ・99Ⅰ）。本問は入室前に呈示済み・覚せい剤とメモは記載物件かつ関連性ありで適法。

## 4. ○×クイズ（全11問・1問目から最後まで全部出す）

- **［○×クイズ 1/11］** 捜索差押許可状の執行に必要な「必要な処分」（222条1項・111条1項）には、執行それ自体だけでなく、その前提として不可欠な行為も含まれ、令状呈示や捜索の着手前に行うことも許される。
  - 正解：○（正しい）
  - 理由：111条1項の「執行について」は、執行自体に限らず、執行のため不可欠な前提行為を含む趣旨だから、令状呈示や捜索差押えの着手前の措置も「必要な処分」として行いうる。だから呈示前の入室措置も、この受け皿でまず検討する。
- **［○×クイズ 2/11］** 令状呈示前に欺罔的な手段で被処分者に扉を開けさせ入室した措置が「必要な処分」として許されるかは、捜索差押えの実効性を確保する必要性と、その手段が社会通念上相当な態様かを比較衡量して判断する。
  - 正解：○（正しい）
  - 理由：「必要な処分」の限界は捜査比例の原則から画される。すなわち捜索差押えの執行目的の達成に必要であり、かつ社会通念上相当な態様であることを要する（最決平14.10.4の枠組み）。
- **［○×クイズ 3/11］** 捜索差押えに際し、捜査官が来意を秘し欺罔的な手段で被処分者に扉を開けさせて立ち入る行為は、被処分者を欺くものである以上、およそ「必要な処分」として許容される余地はなく、常に違法である。

  - 理由：欺罔的手段でも当然に違法となるわけではない。実効性確保の必要性があり、社会通念上相当な態様であれば「必要な処分」として許容される（最決平14.10.4はマスターキーによる呈示前入室を許容）。「欺いた＝即違法」と短絡しないのが要点。
- **［○×クイズ 4/11］** 刑訴法111条1項にいう「執行について」とは、令状執行それ自体に限らず、その前提となる執行のため不可欠な行為をも含む趣旨である。
  - 正解：○（正しい）

- **［○×クイズ 5/11］** 令状呈示前の立入りが「必要な処分」として許される場合でも、その手段は捜索差押えの目的達成に必要な範囲にとどまり、かつ社会通念上相当な態様でなければならない。
  - 正解：○（正しい）
  - 理由：「必要な処分」は必要ならどのような処分でもよいわけではなく、捜査比例の原則から必要性＋相当性の限界に服する。必要性だけを論じて相当性（態様の穏当さ・侵害の程度）を落とすと大きく減点される。両輪で書く。
- **［○×クイズ 6/11］** 捜索差押えの執行に際し、被処分者が自ら錠を外して扉を開けた場合の立入りは、施錠を破壊して立ち入る場合と比べて権利侵害の程度がより重いといえる。

- **［○×クイズ 7/11］** 捜索すべき「場所」を特定した捜索差押許可状では、その場所内にある「物」を捜索することはできず、物ごとに別個の令状を要する。
