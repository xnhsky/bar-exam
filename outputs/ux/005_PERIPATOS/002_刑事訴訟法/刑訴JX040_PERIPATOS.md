### 骨子（3項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　悪性格の立証

- 見出しの補足（結論を含む。項目の終わりに読む）：証拠の関連性
1. 立証命題＝Xの犯人性（被告人と犯人の同一性）／関連性は解釈上の要件（317条）
2. 同種前科 → 自然的関連性は肯定（争いなし）
3. 【論点】悪性格立証と法律的関連性 → 原則否定
   - あてはめ：理由＝誤判のおそれ＋争点拡散のおそれ
   - あてはめ：例外＝実証的根拠の乏しい人格評価による誤判のおそれなし（最判平24.9.7）
4. 同一性立証の具体化 → ①顕著な特徴＋②相当程度類似
   - あてはめ：㋐昼間・高齢空き巣＝顕著でない／㋑X自作の特殊工具で3cm円穴＝顕著な特徴
   - あてはめ：起訴事実も窓に3cm円穴 → 相当程度類似
- 結論：おそれなし ＝ 法律的関連性は否定されない

#### 第2　伝聞法則

- 見出しの補足（結論を含む。項目の終わりに読む）：323条1号
1. 前科調書＝書面・記載内容（前科の存在）の真実性が問題 → 【論点】伝聞証拠該当（320条1項）
2. 公務員が職務上証明できる事実についてその公務員が作成した書面 → 323条1号該当
- 結論：伝聞例外に当たり証拠能力あり

#### 第3　総合結論

   両関門（関連性・伝聞）を通過 → 裁判官は前科調書を証拠とすることができる

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「X自身が作成した特殊な工具」 → 模倣困難＝顕著な特徴の基礎
- 【拾う事実】『「半径3cm程度の円形の小さな穴」（前科・本件とも）』 → 前科と起訴事実の相当程度類似
- 【拾う事実】「昼間・高齢の一人暮らし・窓から侵入」 → 一般的な空き巣＝顕著でない側
- 【拾う事実】「同種前科・有罪確定」 → 自然的関連性を肯定する事実
- 【拾う事実】「前科調書＝公務員が職務上作成した書面」 → 323条1号該当（伝聞例外）
- 【事案の整理】立証命題を先に固定
  - 証拠法の問題は「何を・どの証拠で・どう立証するか」の三点セットで整理する。立証命題を犯人性と特定しないと、後の「悪性格立証」の危険性の議論がぶれる。動機・故意の立証と取り違えると規範がずれる。
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 自然的関連性＝同種前科ゆえ肯定（一言）／証拠禁止＝違法収集等なし（触れず）／伝聞該当性＝書面で記載の真実性が問題＝一言。
- 【効く事実】あてはめで使う事実
  - 顕著性を割る2要素 → ㋐昼間・高齢一人暮らし・空き巣＝一般的で顕著でない／㋑X自作の特殊工具で半径3cmの円穴を開け解錠侵入＝模倣困難＝顕著な特徴。類似 → 起訴事実も窓に半径3cmの円穴。
- 【規範の要点】伝聞例外の規範
  - 前科調書は「公判期日における供述に代えて書面を証拠とする」もの（320Ⅰ）で、記載内容の真実性が問題＝伝聞証拠。もっとも「公務員が職務上証明できる事実についてその公務員が作成した書面」（323条1号）に当たり、類型的に高度の信用性があるから伝聞例外＝証拠能力あり。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 証拠能力は関連性と伝聞例外の双方を満たして初めて肯定される。答案の締めで「本件前科調書は、法律的関連性・伝聞法則のいずれの観点からも証拠能力が否定されない」と両関門を明示して結論する。なお顕著な特徴の評価次第で否定結論もありうる点を意識。
- 【まぎらわしい選択肢・論点】違法収集証拠排除法則の適用／自白の任意性
- 【まぎらわしい選択肢・結論】証拠能力は認められない／自然的関連性を欠き証拠にできない
- 【まぎらわしい選択肢・規範】狭義の関連性説／特信情況説
- 【まぎらわしい選択肢・事実】殺意あり／自白の存在

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

関連性＝立証命題は犯人性、同種前科で自然的関連性○、悪性格立証は原則否定（誤判＋争点拡散）、例外＝おそれなし、同一性は顕著な特徴＋相当程度類似、㋑特殊工具で顕著・窓の3cm穴で類似○。伝聞＝書面で伝聞、公務員作成で323条1号、証拠能力○。統合＝両関門クリアで証拠にできる。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 同種前科を「被告人と犯人の同一性」の立証に用いる場合に、判例（最判平24.9.7）が要求する2つの要件を挙げよ。
  - 模範解答：①前科に係る犯罪事実が顕著な特徴を有すること ②それが起訴に係る犯罪事実と相当程度類似すること。この二つから、それ自体で両者の犯人が同一であることを合理的に推認させるものであることを要する。
- **［規範クイズ 2/3］** 前科証拠による犯人性の立証が、法律的関連性の段階で原則として排除される2つの理由を述べよ。
  - 模範解答：①被告人の犯罪性向という実証的根拠の乏しい人格評価につながり、事実認定を誤らせるおそれ（誤判のおそれ）／②前科の内容に立ち入った攻撃防御が必要となり、取調べに付随して争点が拡散するおそれ。この2つの危険を回避するため原則排除する。
- **［規範クイズ 3/3］** 前科調書が伝聞例外として証拠能力を認められる根拠条文と、その条文が定める書面の類型を述べよ。
  - 模範解答：323条1号。「戸籍謄本、公正証書謄本その他公務員（外国の公務員を含む）がその職務上証明することができる事実についてその公務員の作成した書面」。前科調書はこれに当たる（2号＝業務文書、3号＝その他特信情況ある書面と区別）。

## 4. ○×クイズ（全8問・1問目から最後まで全部出す）

- **［○×クイズ 1/8］** ある証拠に証拠能力が認められるには、一般に、自然的関連性・法律的関連性があり、かつ証拠禁止に当たらないことの3つを満たす必要がある。
  - 正解：○（正しい）
  - 理由：証拠能力は、①自然的関連性（要証事実に対する必要最小限の証明力）、②法律的関連性（証明力の評価を誤らせる類型的危険がないこと）、③証拠禁止に当たらないこと、の3要件で判断する。関連性を要求する明文はないが解釈上の要件として承認されている（317条の証拠裁判主義が出発点）。
- **［○×クイズ 2/8］** 証拠に自然的関連性（要証事実に対する必要最小限の証明力）が認められれば、それだけでその証拠を事実認定に用いることができる。
  - 正解：×（誤り）
  - 理由：自然的関連性は証拠能力の入口にすぎない。証明力の評価を誤らせる類型的危険（不当な予断・偏見）がないこと＝法律的関連性も必要で、悪性格立証はまさにこの段階で原則排除される。自然的関連性の肯定＝証拠能力肯定、ではない。
- **［○×クイズ 3/8］** 証拠の関連性と伝聞法則は別個の要件であり、書面の証拠については両方の関門を満たして初めて証拠能力が認められる。
  - 正解：○（正しい）
  - 理由：関連性（自然的・法律的）と伝聞法則は独立の要件。書面はまず関連性をクリアし、さらに伝聞法則（320Ⅰ）の例外に当たる必要がある。一方を満たしても他方を欠けば証拠にできない。両者を混同するのは典型的な失点。
- **［○×クイズ 4/8］** 書面の証拠については、伝聞例外（323条各号など）に当たりさえすれば、証拠の関連性を別途検討する必要はない。
  - 正解：×（誤り）
  - 理由：伝聞例外への該当は「伝聞の関門」を通すだけで、証拠の関連性（自然的・法律的関連性）は別に必要。前科調書は323条1号に当たっても、悪性格立証としての法律的関連性が否定されれば証拠にできない。関連性と伝聞は独立の要件で、どちらも欠かせない。
- **［○×クイズ 5/8］** 前科証拠は自然的関連性があるだけでは証拠能力が認められず、証明しようとする事実について、実証的根拠の乏しい人格評価によって誤った事実認定に至るおそれがないと認められるときに初めて証拠とすることが許される。
  - 正解：○（正しい）
  - 理由：最判平24.9.7の一般的判断枠組み。前科証拠は自然的関連性のみで証拠能力が決まるのではなく、誤判・争点拡散のおそれがないと認められる場合に限り許される。
- **［○×クイズ 6/8］** 同種前科を被告人と犯人の同一性の立証に用いる場合、前科の犯罪事実が起訴事実と相当程度類似していれば、その手口が特に顕著な特徴を有していなくても、証拠として用いることができる。
  - 正解：×（誤り）
  - 理由：同一性立証には①顕著な特徴と②相当程度類似の両方が必要。ありふれた手口が偶然似ているだけでは、人格評価を介さずに同一性を合理的に推認したとはいえず、誤判のおそれを払拭できない。顕著な特徴を欠けば、類似していても証拠にできない。
- **［○×クイズ 7/8］** 戸籍謄本や前科調書のように、公務員がその職務上証明することができる事実についてその公務員が作成した書面は、供述不能等の要件を要することなく当然に証拠能力が認められる（323条1号）。
  - 正解：○（正しい）
  - 理由：323条1号書面は、作成者が公務員でその職務権限に基づき客観的事実を証明する書面ゆえ、内容の正確性が制度的に担保され類型的信用性が高い。321条1項の供述録取書と違い、供述不能・特信情況等の要件なしに当然に証拠能力が認められる。前科調書は1号の典型例。
- **［○×クイズ 8/8］** 証拠能力は、証拠の関連性（悪性格立証の関門）と伝聞例外の双方を満たして初めて認められ、いずれか一方でも欠ければその証拠を事実認定に用いることはできない。
  - 正解：○（正しい）
  - 理由：関連性と伝聞は独立の要件で、両方をくぐって初めて証拠能力が肯定される。前科調書は、悪性格立証としての法律的関連性が否定されない、かつ323条1号の伝聞例外に当たる、の双方が揃って初めて犯人性の認定に用いうる。
