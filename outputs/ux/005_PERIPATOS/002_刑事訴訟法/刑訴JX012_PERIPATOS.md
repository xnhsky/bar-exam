警察官Aは、覚せい剤の密売ルートについて内偵を進めていたが、甲が自宅に覚せい剤を隠し持っているとの情報を得た。そこで甲の身辺調査をしたところ、甲は自宅付近の食堂で、1か月前に無銭飲食をしたことが判明した。10月2日、Aは詐欺罪の被疑事実で逮捕令状を得て、警察官Bとともに甲宅に赴き甲を逮捕するとともに、甲宅内部を捜索した。その結果、覚せい剤は発見されなかったものの、甲の手提げ金庫の中から覚せい剤取引を記帳した手帳が発見されたので、これを差し押さえた。この手帳の記載によって、10月14日午後6時に、P駐車場において覚せい剤20グラムの取引が行われること、取引の相手方の車両番号を知ることができた。Aは、甲になりすまして取引相手を逮捕しようと考え、約束の時間にP駐車場に行き、甲の手帳にあった車両番号に一致するワゴン車を発見した。Aは帽子を目深にかぶり運転席の乙に「約束のものは持ってきましたか」と話しかけた。乙はAを甲と誤信して覚せい剤の入った紙袋をAに手渡したので、Aは待機していた警察官B、Cとともに覚せい剤所持の嫌疑で乙を現行犯逮捕した。以上の警察官Aの行為は適法か。

### 骨子（3項目。第1から【論点】ごとに、何が問題→規範→使う事実→結論 の順で組み立てる）

#### 第1　甲の逮捕の適法性

- 見出しの補足（結論を含む。項目の終わりに読む）：別件逮捕・199条
1. 覚せい剤（本件）取調べ目的で詐欺（別件）の逮捕状 → 【論点】別件逮捕の規制基準（規範：別件基準説）
   - あてはめ：主観的意図は令状審査になじまず、逮捕の要件は被疑事実について判断
2. 詐欺に逮捕の理由（相当な理由）・必要性（246条・法定刑重い）あり
- 結論：別件たる詐欺の要件充足 ＝ 甲の逮捕は適法

#### 第2　手帳の捜索・差押えの適法性

- 見出しの補足（結論を含む。項目の終わりに読む）：220条1項2号
1. 逮捕に伴う無令状の捜索差押え → 【論点】220条1項2号の物的限界（規範：被疑事実関連物件に限る（相当説・222条1項・99条1項））
2. 差押物＝覚せい剤取引の手帳／被疑事実＝詐欺 ＝ 無関係
- 結論：被疑事実関連性なし ＝ 本件差押えは違法

#### 第3　乙の現行犯逮捕の適法性

- 見出しの補足（結論を含む。項目の終わりに読む）：212条1項
1. 乙は現に覚せい剤を所持 → 現行犯逮捕の要件は充足
2. なりすまし取引 → 【論点】おとり捜査の適法性（規範：意思制圧なし＝強制処分でない／相当性で限界）
   - あてはめ：必要性・緊急性＋既に犯意ある乙への機会提供・働きかけ軽微 → おとりは適法
3. 端緒が違法差押えの手帳 → 【論点】違法性の承継（規範：違法の程度＋関連性で遮断の有無を判断）
   - あてはめ：違法重大（令状潜脱）＋手帳が唯一の端緒＝関連性強 → 遮断されず承継
- 結論：差押えの違法が承継 ＝ 現行犯逮捕は違法

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】『「覚せい剤の密売ルートを内偵」＋詐欺で逮捕状』 → 逮捕の実質目的は覚せい剤の取調べか（別件逮捕の徴表）

- 【拾う事実】『手帳の記載で日時・場所・相手の車両番号を取得』 → 手帳が取引情報の唯一の端緒（承継の関連性の強さ）
- 【拾う事実】『乙は現に覚せい剤を所持し手渡した』 → 現行犯逮捕の要件（現に罪を行う者）は充足
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 逮捕の理由（詐欺の相当な理由）＝あり／現行犯逮捕の要件（現に罪を行う者）＝あり／おとりの強制処分性＝意思制圧なし＝任意、は一言で素通り。詰まるのは「基準の選択」と「範囲・限界」の所だけ。
- 【効く事実】あてはめで使う事実
  - 別件逮捕 → 詐欺は法定刑が重く（刑法246条・10年以下）逮捕の理由・必要性あり／物的限界 → 差押えた手帳は「覚せい剤取引の記帳」＝詐欺の被疑事実と無関係。
- 【規範の要点】2段の規範
  - おとり捜査は相手が自らの意思で行動し意思制圧を欠くから「強制の処分」に当たらない → もっとも法益侵害の結果を招くおそれがあるから、必要性・緊急性等を考慮し、具体的状況の下で相当と認められる範囲でのみ許容（最決平16.7.12）。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 承継の相手を間違えない。おとり捜査は適法なので、承継されるのは②差押えの違法であって「おとり捜査の違法」ではない。判断は違法の程度＋関連性を勘案し、違法が遮断されたかで決する（最判平15.2.14の枠組みを応用）。
- 【まぎらわしい選択肢・論点】余罪取調べの限界／訴因変更の要否／接見交通権の侵害
- 【まぎらわしい選択肢・結論】差押えは適法／現行犯逮捕は適法
- 【まぎらわしい選択肢・規範】本件基準説／緊急処分説で範囲拡大
- 【まぎらわしい選択肢・事実】被疑事実と関連する／意思を制圧している

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

①逮捕＝別件基準説、詐欺に理由・必要性ありで適法。②差押え＝220条1項2号の物的限界、覚せい剤の手帳は詐欺と無関係で違法。③おとり＝意思制圧なしで強制処分でない、必要性・緊急性・軽微でおとりは適法。④承継＝差押えの違法が重大＋手帳が唯一の端緒で遮断されず、現行犯逮捕は違法。

## 3. 規範クイズ（4問）

- **Q04［規範］** 本件取調べ目的で別件の逮捕状を用いた逮捕（別件逮捕）の適否について、別件基準説の判断基準とその論拠を述べよ。
  - 模範解答：逮捕の適否は別件（現に令状の被疑事実）を基準に判断し、別件に逮捕の理由・必要性が備わる限り逮捕は適法。論拠＝①捜査官の主観的意図を令状裁判官が見抜くことは困難、②逮捕の要件は被疑事実について客観的に判断すべきこと。取調べ目的による違法主張は余罪取調べの限界の問題として処理する。
- **Q05［規範］** 逮捕に伴う無令状の捜索・差押え（220条1項2号）で差し押さえうる物の範囲（物的限界）の規範と、その根拠条文を述べよ。
  - 模範解答：差押対象は逮捕の理由となった被疑事実に関連する証拠物に限られる（222条1項本文・99条1項参照）。根拠＝逮捕現場には被疑事実の証拠が存在する蓋然性が高く、通常令状発付の要件を満たすため無令状でも人権侵害のおそれが低い（相当説）から、その趣旨が及ぶ範囲＝被疑事実関連物件に限定される。
- **Q06［規範］** おとり捜査が「強制の処分」に当たらない理由と、任意捜査として許容される限界の判断枠組みを述べよ。
  - 模範解答：不当たり＝おとり捜査は詐術的であっても相手方が自らの意思で犯罪を実行しており、個人の意思を制圧する側面を欠くから「強制の処分」に当たらない。限界＝法益侵害の結果を惹起するおそれがあるため、必要性・緊急性等を考慮し、具体的状況の下で相当と認められる範囲でのみ許容される（比例原則。最決平16.7.12）。
- **Q07［規範］** 先行手続に違法がある場合に、その違法が後行手続に承継されるか（後行手続を違法とすべきか）を判断する枠組みを述べよ。
  - 模範解答：証拠収集手続の違法の程度と、これと後行手続・当該証拠との関連性など諸般の事情を勘案し、先行手続の違法が遮断されたか否かによって決する（最判平15.2.14の枠組みを応用）。違法が重大かつ両手続が密接に関連する場合は遮断されず承継を認める。

## 4. ○×クイズ（7問）

- **Q08［○×］** 逮捕に伴う捜索・差押え（刑訴法220条1項2号）は、裁判官の発する捜索差押許可状を得ることなく行うことができる。
  - 正解：○（正しい）
  - 理由：220条1項2号は逮捕に伴う場合の無令状の捜索・差押えを認める。逮捕現場には被疑事実の証拠が存在する蓋然性が高く、通常は令状発付の要件も満たすため、改めて令状を経なくても人権侵害のおそれが低いことに根拠がある。もっとも無令状で許されるからこそ、対象物の範囲（物的限界）が別途問題になる。
- **Q09［○×］** 現行犯人は、「現に罪を行い、又は現に罪を行い終わった者」（212条1項）であり、逮捕状によらずに逮捕することができる。
  - 正解：○（正しい）
  - 理由：現行犯逮捕は令状主義（憲法33条）の例外で、犯罪と犯人の明白性から誤認逮捕のおそれが低く、令状なしで許される（212条・213条）。乙は覚せい剤を現に所持・授受した直後で「現に罪を行い……」った者に当たり、逮捕自体の要件は満たす。もっとも要件を満たしても、端緒となった先行手続の違法が承継されないかは別問題として残る。
- **Q10［○×］** 複数の捜査行為が連鎖する事案では、先行手続の違法が後行手続へ影響しうるため、原則として行為の時系列順に各行為の適法性を検討する。
  - 正解：○（正しい）
  - 理由：先行行為の違法が後行行為に承継されるかを論じるには、先行行為の適否を先に確定しておく必要がある。時系列順に並べれば、違法の縦の連鎖を自然に拾える。逆に思いついた順に書くと、承継の前提（先行の違法）が未確定のまま結論に飛びやすい。
- **Q11［○×］** 強制処分とは有形力（物理的な力）の行使を伴う手段をいい、有形力の行使を伴わない詐術的な働きかけは、それだけで当然に任意処分に分類される。
  - 正解：×（誤り）
  - 理由：強制処分とは、有形力の有無ではなく、個人の意思を制圧し、身体・住居・財産等の重要な権利利益に制約を加えて強制的に捜査目的を実現する行為をいう（最決昭51.3.16）。有形力を伴わなくても意思制圧があれば強制処分になりうるし、逆におとり捜査は詐術的でも相手が自らの意思で行動するため意思制圧を欠き任意処分となる。区別基準は「有形力の有無」ではなく「重要な権利利益への実質的制約と意思制圧の有無」。
- **Q12［○×］** 220条1項2号による差押えの限界を緊急処分説（逮捕者の安全確保・証拠破壊防止に根拠を求める説）で説いた場合、相当説（証拠存在の蓋然性に根拠を求める説）よりも差押えの許容範囲は広くなる。
  - 正解：×（誤り）
  - 理由：逆である。緊急処分説は差押対象を被疑事実に関連しかつ被逮捕者の支配下にある物に絞るため、相当説より範囲が狭い。もっとも本問では、覚せい剤取引の手帳は詐欺の被疑事実と無関係で、いずれの説でも差押えは許されず結論は一致する。説の対立が結論に影響しない場面では、対立の紹介は簡潔にしてあてはめに紙幅を割く。
- **Q13［○×］** 最決平16.7.12は、直接の被害者がいない薬物犯罪等で通常の捜査方法のみでは摘発が困難な場合に、機会があれば犯罪を行う意思があると疑われる者を対象とするおとり捜査を、任意捜査として許容されるとした。
  - 正解：○（正しい）
  - 理由：同決定は、①直接の被害者がいない薬物犯罪等で②通常の捜査方法のみでは摘発困難な場合に③機会があれば犯罪を行う意思があると疑われる者を対象とするおとり捜査を、197条1項に基づく任意捜査として許容されるとした。「少なくとも」との限定から事例判断と解され、本問では既に犯意ある乙に機会を提供したにすぎず、働きかけも「約束のものは持ってきましたか」と軽微で相当と評価できる。
- **Q14［○×］** 後行の逮捕・処分それ自体が独立の要件を満たしていれば、たとえ先行する違法な手続と密接に関連していても、先行手続の違法が後行手続の適法性に影響することはない。
  - 正解：×（誤り）
  - 理由：後行手続がそれ自体の要件を満たしても、先行手続の違法が重大でかつ両手続の関連性が強い場合には、違法が遮断されず後行手続に承継されて違法となりうる。本問の現行犯逮捕は212条の要件を満たすが、違法差押えの手帳が取引情報の唯一の端緒であり関連性が強く、令状潜脱で違法の程度も高いため、違法が承継されて現行犯逮捕も違法と評価される。「後行が要件を満たすから当然適法」で切ると致命傷。
