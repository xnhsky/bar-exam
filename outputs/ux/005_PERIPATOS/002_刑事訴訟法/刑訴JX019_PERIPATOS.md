### 骨子（3項目。第1から【論点】ごとに、何が問題→規範→使う事実→結論 の順で組み立てる）

#### 第1　強制採尿の可否

- 見出しの補足（結論を含む。項目の終わりに読む）：197条1項ただし書
1. カテーテル採尿＝身体侵襲＋精神的打撃 → 【論点】「強制の処分」該当性（規範：重要権利利益の実質的侵害）＝一文で通過
2. 【論点】強制採尿はおよそ許されないか → 医師が適切に行えば危険乏しい → 絶対的禁止ではない
3. 【論点】許容の実体要件 → 重大性・嫌疑・証拠の重要性・代替手段の不存在 → 真にやむを得ない・最終的手段
   - あてはめ：頑なな拒否＋一度出した尿を廃棄 → 代替手段なし（効く事実）／担当医実施＝身体・人格に配慮
- 結論：強制採尿は許容される

#### 第2　必要な令状の種類

- 見出しの補足（結論を含む。項目の終わりに読む）：218条・219条
1. 体内の尿という「物」を探索・取得 → 捜索・差押の性質 → 捜索差押許可状（218条1項前段・219）
2. 人権侵害のおそれ＝身体検査と共通 → 【論点】令状の種類 → 218条9項を準用
   - あてはめ：「医師をして医学的に相当と認められる方法により行わせる」旨の条件記載が不可欠
3. 反対＝鑑定処分許可状説 → 直接強制の担保なし → 採らない（一言）
- 結論：必要な令状は 条件付捜索差押許可状

#### 第3　強制採尿令状に基づく強制連行の可否

1. 採尿令状は対物的令状 → 【論点】その効力で「人」を連行できるか（物と人の区別）
2. 任意同行が事実上不可能 → 令状の効力で採尿に適する最寄りの場所まで連行＋必要最小限度の有形力
   - あてはめ：有形力が必要最小限か不明 → 仮定的認定にとどめる
- 結論：令状が条件付捜索差押許可状で連行が限度内なら 下線部の捜査は適法

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「意味不明な言動・瞳孔が定まらない・両腕の注射痕様のもの」 → 覚せい剤使用の嫌疑を基礎づける
- 【拾う事実】「頑なに拒否＋一度出した尿を洗面所に廃棄」 → 任意の採取は不可能＝代替手段の不存在
- 【拾う事実】「最寄りの病院まで連行」 → 採尿に適する最寄りの場所＝場所的限定
- 【拾う事実】「担当医がカテーテルで実施」 → 医学的に相当な方法という条件を充足
- 【拾う事実】「強制採尿に必要な令状を取得」 → 令状の種類（条件付捜索差押許可状か）が問題
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 該当性＝身体侵襲＋精神的打撃で「強制の処分」＝ほぼ争いなし・一文で通過。止まるのは「そもそも許されるか」と「実体要件を満たすか」の2点。ここに紙幅を集める。
- 【効く事実】あてはめで使う事実
  - 重大性 → 覚せい剤自己使用罪＝密行性が高い／嫌疑 → 意味不明な言動・瞳孔・注射痕様のもの／証拠の重要性 → 尿が決定的証拠／代替手段の不存在 → 頑なな拒否＋一度出した尿を洗面所に廃棄を直接引用。
- 【規範の要点】判例の規範
  - 体内の尿を証拠物として強制取得する行為は捜索・差押の性質を有する → 捜索差押許可状（218条1項前段・219条）。ただし人権侵害のおそれがある点で身体検査と共通するから、218条9項を準用し「医師をして医学的に相当と認められる方法により行わせる」旨の条件記載を要する ＝ 条件付捜索差押許可状。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり

- 【まぎらわしい選択肢・結論】強制採尿は違法／鑑定処分許可状が必要
- 【まぎらわしい選択肢・規範】鑑定処分許可状説／令状主義違反
- 【まぎらわしい選択肢・事実】逮捕の現場／緊急性の存在

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

可否＝強制処分該当は一文、絶対的禁止でない、実体要件（拒否・尿の廃棄で真にやむを得ない・最終的手段）で許容。令状＝捜索差押の性質＋218条9項準用の条件記載＝条件付捜索差押許可状。連行＝任意同行が事実上不可能なら令状の効力で採尿に適する最寄りの場所まで＋必要最小限度の有形力。

## 3. 規範クイズ（3問）

- **Q06［規範］** 強制採尿が捜査として許容されるための実体要件を、判例の枠組みで挙げよ。
  - 模範解答：①被疑事件の重大性 ②嫌疑の存在 ③当該証拠の重要性とその取得の必要性 ④適当な代替手段の不存在。これらの要件に照らし、犯罪の捜査上真にやむを得ないと認められる場合に限り、最終的手段として許容されるとの結論に至る（最決昭55）。実施にあたっては身体の安全と人格の保護に十分な配慮を要する。
- **Q07［規範］** 強制採尿に必要な令状の種類と、その令状に不可欠な記載を、性質論とともに述べよ。
  - 模範解答：尿の強制採取は捜索・差押の性質を有するから捜索差押許可状を要する。もっとも人権侵害のおそれがある点で身体検査と共通するので、身体検査に関する218条9項を準用し、「強制採尿は医師をして医学的に相当と認められる方法により行わせなければならない」旨の条件の記載が不可欠＝条件付捜索差押許可状。
- **Q08［規範］** 対物的な強制採尿令状の効力として被疑者を採尿場所へ連行できるかにつき、判例の規範（要件と限界）を述べよ。
  - 模範解答：身柄を拘束されていない被疑者を採尿場所へ任意に同行することが事実上不可能であると認められる場合には、強制採尿令状の効力として、採尿に適する最寄りの場所まで連行でき、その際必要最小限度の有形力を行使できる。理由は、そう解さないと令状の目的を達せず、裁判官も連行の当否を含めて審査したとみられるから。

## 4. ○×クイズ（7問）

- **Q09［○×］** 「強制の処分」とは、相手方の明示又は黙示の意思に反し、その重要な権利・利益に実質的な侵害・制約を加える処分をいう。
  - 正解：○（正しい）
  - 理由：最決昭和51年3月16日が示した「強制の処分」（197条1項ただし書）の定式。有形力の行使の有無ではなく、意思に反する重要な権利・利益の実質的侵害・制約か否かで判定する。これが捜査手法の適法性を論ずる出発点。
- **Q10［○×］** カテーテルを尿道に挿入して尿を採取する行為は身体への侵襲を伴うから、被採取者本人がその実施に同意していても、なお「強制の処分」に当たる。
  - 正解：×（誤り）
  - 理由：「強制の処分」該当性は相手方の意思に反することを要件とする。本人が真意で同意していれば意思に反しないから、身体侵襲があっても強制処分ではなく任意処分の問題となる。侵襲の重さだけで強制処分と決めつけない。
- **Q11［○×］** 強制の処分は、この法律に特別の定めがある場合でなければすることができない（強制処分法定主義）。カテーテルによる強制採尿は、この「強制の処分」に当たる。
  - 正解：○（正しい）
  - 理由：197条1項ただし書が強制処分法定主義を定める。強制採尿は身体への侵入行為であり重要な権利・利益への実質的制約だから「強制の処分」に当たる。ゆえに法律の根拠と令状という手続的統制の下でのみ許され、まず可否・許容性から論ずることになる。
- **Q12［○×］** カテーテルによる強制採尿は身体への侵入行為であり屈辱感等の精神的打撃を与えるから、たとえ法律の根拠と令状があっても、捜査手続上の強制処分としておよそ許されない。
  - 正解：×（誤り）
  - 理由：判例（最決昭和55年10月23日）は絶対的禁止説を否定する。医師等これに習熟した技能者によって適切に行われる限り、身体上・健康上格別の障害をもたらす危険性は比較的乏しく、精神的打撃も身体検査と同程度でありうるから、絶対に許されないとすべき理由はない、とする。侵襲の重さだけで違法と即断しない。
- **Q13［○×］** 強制採尿は、被疑事件の重大性、嫌疑の存在、当該証拠の重要性とその取得の必要性、適当な代替手段の不存在等の事情に照らし、犯罪の捜査上真にやむを得ないと認められる場合に、最終的手段として許容される。
  - 正解：○（正しい）
  - 理由：最決昭和55年10月23日の実体要件（歯止め）部分。絶対的禁止を否定して許容する一方、これらの事情から「真にやむを得ない・最終的手段」に限り許すという厳格な限定を課す。あてはめでは拒否・廃棄といった事実を拾ってこの要件を基礎づける。
- **Q14［○×］** 鑑定処分許可状（168条）は身体検査を拒む者に対する直接強制の担保を備えているから、頑なに任意提出を拒む被疑者からの強制採尿も、鑑定処分許可状のみによって実施することができる。
  - 正解：×（誤り）
  - 理由：鑑定処分許可状には直接強制の担保がない（身体検査の直接強制規定を準用していない）。そのため拒否する被疑者からは実力で採尿できず実効性を欠く。これが判例が鑑定処分許可状説を採らず、直接強制の担保がある捜索差押許可状（条件付）による理由。両令状の「直接強制の有無」が判別基準。
- **Q15［○×］** 身柄を拘束されていない被疑者を採尿場所へ任意に同行することが事実上不可能であると認められる場合には、強制採尿令状の効力として、採尿に適する最寄りの場所まで被疑者を連行することができ、その際、必要最小限度の有形力を行使することができる。
  - 正解：○（正しい）
  - 理由：最決平成6年9月16日の規範。そう解さないと強制採尿令状の目的を達せず、令状を発付する裁判官も連行の当否を含めて審査したとみられる、というのが理由。歯止めは①任意同行が事実上不可能・②採尿に適する最寄りの場所・③必要最小限度の有形力の3点。
