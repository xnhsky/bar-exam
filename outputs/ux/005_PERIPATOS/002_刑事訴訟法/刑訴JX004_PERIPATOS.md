#### 第2　小問(2)　本件覚せい剤の証拠能力

1. 覚せい剤＝第二次証拠（毒樹の果実）と位置づけ
2. 【論点】違法収集証拠排除法則の一般基準 → 規範：違法重大性＋排除相当性

  - 刑訴の事例は「捜査の適法性」と「証拠能力」の2枚看板。明文のない捜査手法（X線検査・GPS・写真撮影）を見たら、反射的に「これは強制か任意か」を疑うのが第一歩。
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 捜査に任意・強制の別があること（197条1項本文・ただし書）／強制なら法定主義＋令状主義が及ぶこと／任意なら比例原則の限界に服すること――ここは各一文で素通りし、筆は「強制か任意か」の一点に集める。
- 【効く事実】あてはめで使う事実
  - 権利利益 → 内容物に対する荷送人・荷受人のプライバシー（憲法13条）／制約の実質性 → 射影で品目まで特定＝開披して見分するに等しい／意思 → 荷送人・荷受人の承諾なし（Bの承諾は占有者のもの）／性質 → 検証／令状 → 検証令状なし。
- 【規範の要点】排除法則の規範
  - ①令状主義の精神を没却する重大な違法があり、②これを許容することが将来の違法捜査抑制の見地から相当でないときに証拠能力を否定（最判昭53.9.7）。派生証拠は、第一次証拠収集の違法の程度・第二次証拠の重要性・両者の関連性の程度を総合判断する（最判昭58.7.12 伊藤補足意見）。本問は両要件とも否定＝証拠能力あり。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 覚せい剤に直接排除法則を当てると、間の司法審査（令状発付）や「写真以外の疎明資料」といった介在事情を評価できずあてはめが雑になる。
- 【まぎらわしい選択肢・論点】接見交通権の侵害／訴因変更の要否／伝聞法則の適用
- 【まぎらわしい選択肢・結論】証拠能力なし（排除）／適法（証拠能力あり）
- 【まぎらわしい選択肢・規範】比例原則（必要性・緊急性・相当性）／令状主義の例外
- 【まぎらわしい選択肢・事実】被処分者の明示の承諾／令状主義の潜脱意図あり

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

(1)＝明文なし→強制処分の意義（意思に反し重要権利利益に実質的制約・昭51）→内容物のプライバシー（13条）を開披同然に侵害＋承諾なし→検証（218条1項）→検証令状なし→218条1項違反で違法。(2)＝覚せい剤は第二次証拠→排除は違法重大性＋排除相当性、派生は違法の程度・重要性・関連性の総合→令状潜脱意図なし・司法審査介在・関連性弱・証拠価値大→両否定→証拠能力あり。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 判例・通説がいう「強制の処分」（197条1項ただし書）の意義（定義）を述べよ。
  - 模範解答：個人の明示又は黙示の意思に反し、重要な権利・利益に実質的な制約を加える処分。昭51決定の「特別の根拠規定がなければ許容することが相当でない手段」を、意思の点は「意思に反する」で足り、重要な権利利益への実質的制約を中核と読む。
- **［規範クイズ 2/3］** 本件X線検査が強制処分に当たるとする平21決定の思考過程（3段）を述べよ。
  - 模範解答：①射影で内容物の形状・材質を知り品目まで特定できる＝内容物のプライバシーを大きく侵害（重要権利利益への実質的制約）②荷送人・荷受人の承諾なし（意思に反する）③よって検証としての性質を有する強制処分。
- **［規範クイズ 3/3］** 検証と性質決定した場合、令状なき本件検査の違法の根拠条文は何条何項か、なぜそちらになるかも述べよ。
  - 模範解答：218条1項（令状主義違反）。検証と性質決定した以上、法律の根拠（検証）はあるから、欠けているのは検証令状。ゆえに197条1項ただし書（強制処分法定主義違反）ではなく218条1項で締めるのが正確（採点実感で重視）。「法定主義違反で違法」と書くと、検証と認定したことと矛盾する。

## 4. ○×クイズ（全7問・1問目から最後まで全部出す）

- **［○×クイズ 1/7］** 「強制の処分」は、刑訴法197条1項ただし書により、法律に特別の定めがある場合でなければすることができない（強制処分法定主義）。
  - 正解：○（正しい）
  - 理由：197条1項は本文で任意捜査を原則とし、ただし書で「強制の処分は、この法律に特別の定めのある場合でなければ、これをすることができない」と定める（強制処分法定主義）。だから明文なき手法が「強制」なら、それだけで原則違法となる。任意なら比例原則の枠で許される余地がある。
- **［○×クイズ 2/7］** 判例（最決昭51.3.16）によれば、「強制手段」とは有形力の行使を伴う手段を意味し、有形力を伴わない捜査手法が強制処分に当たることはない。
  - 正解：×（誤り）
  - 理由：昭51決定は「強制手段とは、有形力の行使を伴う手段を意味するものではなく、個人の意思を制圧し、身体、住居、財産等に制約を加えて……特別の根拠規定がなければ許容することが相当でない手段」とする。有形力を切り離したからこそ、X線検査・写真撮影・GPS等の有形力を伴わない手法にも強制処分該当性の議論が及ぶ。
- **［○×クイズ 3/7］** 違法収集証拠排除法則は、証拠収集の手続に違法があることを前提として、その証拠の証拠能力を否定しうるかを問う法理である。
  - 正解：○（正しい）
  - 理由：排除法則は「収集手続の違法」を出発点に、なお証拠として許容できるかを判断する。したがって先に収集手続（本問ではX線検査）の適法性を確定しなければ、証拠能力の議論は始まらない。適法な収集なら排除の問題自体が生じない。
- **［○×クイズ 4/7］** 捜査機関が物の内容の存在・状態を五官の作用によって把握する処分は「検証」に当たり、令状によってこれを行うには検証許可状（218条1項）を要する。
  - 正解：○（正しい）
  - 理由：検証とは、場所・物・人の存在・状態を五官の作用で認識する強制処分。捜査機関が令状によって行う場合は218条1項の検証許可状（検証令状）を要する。本件X線検査は「不審な荷物の内容物の存在・状態を把握する」から検証としての性質を有し、検証令状なき実施は218条1項違反となる。
- **［○×クイズ 5/7］** 荷物を現実に占有・管理する運送業者の営業所長が承諾していれば、荷送人・荷受人の承諾がなくても、内容物に対するプライバシーの主体の意思に反しないといえる。
  - 正解：×（誤り）
  - 理由：占有者（営業所長B）の承諾は、荷物を事実上管理する者の承諾にすぎず、内容物に対するプライバシーの主体である荷送人・荷受人の承諾ではない。よってBの承諾があっても被処分者の意思に反することは否定されない。もっともBの承諾は、小問(2)で違法重大性を否定する方向（潜脱意図なし）の事情としては働く＝同一事実の場面ごとの使い分けが差を生む。
- **［○×クイズ 6/7］** 最判昭53.9.7は、令状主義の精神を没却するような重大な違法があり、かつ、これを証拠として許容することが将来における違法な捜査の抑制の見地から相当でないと認められる場合に、証拠能力が否定されるとする。
  - 正解：○（正しい）
  - 理由：昭53決定（大阪覚せい剤事件）は、①違法の重大性と②排除相当性の二要件で証拠排除を定式化した。根拠は適正手続の保障（憲法31条）・司法の廉潔性・違法捜査の抑止。①は主に捜査官の態度・逸脱の程度、②は事案の重大性・証拠価値・関連性で判断する（配分はある程度任意）。
- **［○×クイズ 7/7］** 違法な処分から直接得られた第一次的証拠には違法収集証拠排除法則が直接適用されうるのに対し、これを介して間接的に得られた第二次的証拠（派生証拠）は、いわゆる毒樹の果実として別途総合判断による。
  - 正解：○（正しい）
  - 理由：第一次証拠（本問の射影写真）は違法な検査から直接得られるので排除法則を直接適用しうる。第二次証拠（本問の覚せい剤）は、写真→令状→捜索という介在事情を経た派生証拠だから、第一次証拠の違法の程度・第二次証拠の重要性・両者の関連性を総合して排除の可否を決める（伊藤補足意見）。介在した司法審査は違法を希釈する方向に働く。
