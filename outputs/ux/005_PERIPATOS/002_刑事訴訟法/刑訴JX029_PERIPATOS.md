### 骨子（3項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　訴因変更の要否

- 見出しの補足（結論を含む。項目の終わりに読む）：312条1項
1. 訴因⇔認定で共謀相手方・実行行為者が変動 → 【論点】訴因変更を要するか（378③・379参照）
2. 審判対象＝訴因（当事者主義）→ 規範：三段階基準（(a)不可欠事項/(b)防御上重要な明示事項/(c)不意打ち・不利益なし）
3. 第一段階(a)：【論点】共謀者・実行行為者が誰かは審判対象画定に不可欠か → 共謀共同正犯理論（数人共謀＋一人の実行で全員正犯）で不可欠でない → (a)不該当
   - あてはめ：平13決定は実行行為者の変動が射程・共犯者変動は射程外だが同理論で架橋
4. 第二段階(b)：共謀相手・実行行為者は防御上重要な明示事項 → (b)該当
5. 第三段階(c)：甲が現場を認め共謀を争う＝不意打ちなし／弁解一部容れた択一＝不利益なし → (c)該当
- 結論：例外的に 訴因変更は不要（有罪判決は適法）

#### 第2　択一的認定

- 見出しの補足（結論を含む。項目の終わりに読む）：罪となるべき事実・335条1項／333条1項
1. 実行行為者を「甲又は氏名不詳者あるいは両名」と択一認定 → 【論点】「罪となるべき事実」として十分か
2. 択一はいずれも殺人の共同正犯という同一構成要件内 → 概括的認定（狭義の択一的認定でない・利益原則は不問）
3. 規範：構成要件該当が合理的疑いを超えて証明＋識別可能な程度に具体的なら十分
4. あてはめ：共謀共同正犯理論でいずれが実行者でも殺人の共同正犯＝合理的疑いを超える証明あり
- 結論：記載として十分・有罪判決は適法

#### 貫く筋

   両論点とも 共謀共同正犯理論＝共謀者・実行行為者が具体的に誰かは審判対象画定にも罪となるべき事実の特定にも決定的でない → 一本の理屈で通す

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「乙と共謀」→「氏名不詳者と共謀」 → 共犯者の変動（要否の対象①）
- 【拾う事実】「被告人において」→「被告人又は氏名不詳者あるいは両名」 → 実行行為者の変動・択一（要否①＋択一②）
- 【拾う事実】「その場にいたが犯行に関与せず」 → 共謀・実行が主要争点として顕在化＝不意打ちなし
- 【拾う事実】『弁解を一部受け入れた択一認定』 → 認定が訴因より不利益でない
- 【拾う事実】『訴因変更手続を経ていない』 → 要否を問う起点（378③・379の受け皿）
- 【ポイント】三段階の勘所

- 【効く事実】「第一〜第三段階」のあてはめで使う事実
  - 不意打ちなし → 甲は「その場にいた」ことを認め、乙とは別の男との共謀を争っている＝争点が主要争点として顕在化／不利益なし → 甲の弁解を一部受け入れて択一的に認定・対等型共謀で犯情に影響なし。事実は必ず「不意打ちにならない／不利益でない」の評価語と結合させる。
- 【ポイント】平13決定の射程に注意
  - 平13決定は実行行為者の変動の事案。本問はさらに共犯者（共謀の相手方）の変動を含み、厳密には射程外。ここを共謀共同正犯理論で補い「共犯者の変動も同様に(a)不該当」と架橋できると上位答案。
- 【規範の要点】「概括的認定」の規範
  - 特定の構成要件該当が合理的な疑いを超えて証明され、他の犯罪事実と識別できる程度に具体的なら「罪となるべき事実」の記載として十分。本問はいずれが実行者でも殺人の共同正犯という同一構成要件に収まる＝概括的認定として許容。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 共謀者・実行行為者が具体的に誰かは、審判対象の画定にとっても（論点1）、罪となるべき事実の特定にとっても（論点2）決定的でない。
- 【まぎらわしい選択肢・論点】訴因の同一性の有無／公訴時効の完成／自白の補強法則
- 【まぎらわしい選択肢・結論】訴因変更が必要／記載として不十分・破棄すべき
- 【まぎらわしい選択肢・規範】識別説のみで判断／狭義の択一的認定
- 【まぎらわしい選択肢・事実】乙以外考えられないとの立証を続けた／利益原則に反する

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

要否＝審判対象は訴因、三段階基準、(a)共謀共同正犯理論で不可欠でない・(b)防御上重要で該当・(c)甲が現場を認め共謀を争う＝不意打ちなし＋弁解一部容れた択一＝不利益なしでクリア、訴因変更不要。択一＝同一構成要件内の概括的認定、合理的疑い超え証明＋識別可能なら十分、記載として十分。貫く筋＝共謀共同正犯理論。

## 3. 規範クイズ（全2問・1問目から最後まで全部出す）

- **［規範クイズ 1/2］** 訴因変更の要否を判断する三段階基準（最決平13.4.11）を(a)(b)(c)の順で述べよ。
  - 模範解答：(a)審判対象の画定に不可欠な事項の変動＝訴因変更が必要／(b)これに当たらなくとも、一般的に被告人の防御にとって重要で訴因に明示された事項の変動＝原則として訴因変更が必要／(c)(b)の場合でも、具体的審理経過に照らし被告人に不意打ちを与えず、かつ認定が訴因より不利益でないとき＝例外的に訴因変更を要しない。以上が要否判断の規範であり、結論は多く(c)で決まる。
- **［規範クイズ 2/2］** 実行行為者を択一的（概括的）に認定した判決が「罪となるべき事実」として十分といえるための規範と、狭義の択一的認定との区別を述べよ。
  - 模範解答：規範＝①特定の構成要件該当が合理的な疑いを超えて証明され、②他の犯罪事実と識別可能な程度に具体的なら記載として十分。区別＝択一が同一構成要件内にとどまれば概括的認定として許容、異なる構成要件間にまたがる狭義の択一的認定は、いずれの構成要件該当も合理的疑いを超えて証明されておらず利益原則（336条）に照らし原則不許容。

## 4. ○×クイズ（全11問・1問目から最後まで全部出す）

- **［○×クイズ 1/11］** 当事者主義的訴訟構造の下では、裁判所が審判できる対象は、検察官が起訴状に掲げて主張する具体的事実たる「訴因」に限られる。
  - 正解：○（正しい）
  - 理由：訴因対象説（通説・判例）。検察官の主張する訴因が審判対象を画するから、訴因と認定事実を突き合わせて「ズレ」を探すことが手続の問題点を拾う出発点になる。だからこそ両者の対比が第一歩。
- **［○×クイズ 2/11］** 訴因には、裁判所の審判の範囲を画する審判対象画定機能（第一次的機能）と、被告人に防御の範囲を告知する防御権告知機能（第二次的・派生的機能）とがある。
  - 正解：○（正しい）
  - 理由：訴因の二機能。第一次的機能は審判対象の画定にあり、防御権告知はその裏返し。この序列が、後で立てる要否の判断枠組み（三段階基準）を根拠づける土台になる。
- **［○×クイズ 3/11］** 訴因に記載された事実と少しでも異なる事実を認定するには、その大小を問わず、常に訴因変更手続（312条1項）を経なければならない。
  - 正解：×（誤り）
  - 理由：些細な食い違いのたびに訴因変更を要するとすれば訴訟不経済だから、常に必要とはいえない。そこで「どの程度の変動があれば訴因変更を要するか」を限界づける必要が生じ、これに答えた判例が最決平13.4.11で、その規範が三段階基準である。
- **［○×クイズ 4/11］** 判例（最決平13.4.11）によれば、訴因変更の要否は、まず審判対象の画定に不可欠な事項の変動か否かを問い、これに当たる場合には訴因変更が必要となる。
  - 正解：○（正しい）
  - 理由：三段階基準の第一段階（審判対象画定説を基礎とする識別の視点）。審判対象の画定に不可欠な事項の変動だから、防御の議論を待たず当然に訴因変更を要する、という判例の規範の起点。
- **［○×クイズ 5/11］** 実行行為者が誰であるかは被告人の防御にとって重要な事項であるから、訴因に実行行為者が明示された以上、これと異なる認定をするには、審理経過を問わず常に訴因変更を要する。
  - 正解：×（誤り）
  - 理由：実行行為者の明示は防御上重要だが訴因の記載として不可欠な事項ではない（平13決定）。防御上重要な明示事項でも、具体的審理経過に照らし不意打ちがなく認定が不利益でなければ、例外的に訴因変更を要しない（第三段階）。「常に必要」ではない。
- **［○×クイズ 6/11］** 共謀共同正犯（刑法60条）では、数人が共謀し、そのうち少なくとも一人が実行行為を行ったことが立証されれば、実行を分担しなかった者も含め全員が共同正犯として責任を負う。
  - 正解：○（正しい）
  - 理由：共謀共同正犯の帰責構造。だからこそ「共謀者・実行行為者が具体的に誰か」は審判対象の画定に不可欠でない（第一段階不該当）と言える。本問の両論点を貫く隠れた主役。
- **［○×クイズ 7/11］** 防御にとって一般的に重要で訴因に明示された事項が変動しても、具体的な審理経過に照らし、被告人に不意打ちを与えず、かつ認定が訴因より不利益でないときは、例外的に訴因変更を要しない。
  - 正解：○（正しい）
  - 理由：三段階基準の第三段階。防御上重要な明示事項でも、不意打ち・不利益の両方がなければ訴訟経済の見地から例外的に訴因変更は不要。本問は甲が現場を認め共謀を争う（争点顕在化＝不意打ちなし）・弁解を一部容れた択一認定（不利益なし）で、この例外に乗る。
- **［○×クイズ 8/11］** 同一の構成要件に該当する事実の細部（実行行為者が誰か等）を確定できないままこれを概括的に認定することは、利益原則（疑わしきは被告人の利益に）に反し、原則として許されない。
  - 正解：×（誤り）
  - 理由：同一構成要件内の概括的認定は、構成要件該当性自体は合理的疑いを超えて証明されており、細部の不確定は特定の問題にすぎないから許容される。利益原則が問題化するのは、異なる構成要件のいずれかに当たるが特定できない狭義の択一的認定の場面。本問は前者。
- **［○×クイズ 9/11］** 「罪となるべき事実」（335条1項）は、特定の構成要件に該当することが合理的な疑いを超えて証明され、かつ他の犯罪事実と識別できる程度に具体的であれば、その記載として十分である。
  - 正解：○（正しい）
  - 理由：罪となるべき事実の特定の程度に関する規範。犯罪の日時・場所・方法等は構成要件要素でない限りその特定手段にすぎない。本問は共謀共同正犯理論により、いずれが実行者でも殺人の共同正犯該当が合理的疑いを超えて証明され、記載として十分。
- **［○×クイズ 10/11］** 異なる構成要件のいずれかに該当することは確実だが、どちらか特定できない狭義の択一的認定は、いずれの構成要件該当も合理的な疑いを超えて証明されておらず、利益原則に照らし原則として許されない。
  - 正解：○（正しい）
  - 理由：狭義の択一的認定（例：窃盗か盗品等譲受けか）は、いずれの構成要件についても単独では合理的疑いを超える証明がないから、「疑わしきは被告人の利益に」に反し原則不許容。本問はこれと異なり同一構成要件内なので許容される（区別が要）。
- **［○×クイズ 11/11］** 訴因変更を経ずに訴因と異なる事実を認定した違法は、審判の請求を受けない事件について判決をした場合に当たり、常に絶対的控訴理由（378条3号）となる。
  - 正解：×（誤り）
  - 理由：訴因の同一性の範囲内で訴因変更を怠った違法は、審判対象自体を逸脱したわけではないから、通常は訴訟手続の法令違反（相対的控訴理由・379条）として扱われる（東京高判平10.7.1参照）。378条3号（審判の請求を受けない事件への判決＝不告不理違反）となるのは訴因の同一性を超えた場合。受け皿条文の区別に注意。
