#### 第3　設問2・A供述録取書

- 【拾う事実】『A証言「一度も見失っていない」／A供述書「一度見失った」』 → 自己矛盾供述の一致点
- 【拾う事実】『A供述書はA証言の「後」に作成』 → 作成時期の論点を起動
- 【拾う事実】『B供述書＝「BがAの発言を伝える」内容』 → 存在の立証に厳格な証明
- 【拾う事実】『B供述書は「Bの供述書」（Bが自ら作成）』 → 署名押印でなく321条1項3号へ
- 【拾う事実】『A・Bに供述不能等の事情なし』 → 321条1項3号の要件不充足
- 【拾う事実】『A供述録取書＝A証言と一致・署名押印あり』 → 回復証拠・存在は厳格な証明済み
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 実質証拠＝どの書面も伝聞（320条1項）・供述不能なし＝一言で切る。作成時期の疑問（証言後に作られた書面でよいか）も最判昭43.10.25で不要と一言。
- 【効く事実】あてはめで使う事実
  - 自己矛盾 → A証言「一度も見失っていない」×A供述書「一度見失った」を直接対置。作成時期 → A供述書はA証言の後に作成（→ 判例で不要と一言）。事実は必ず評価語（＝矛盾する＝自己矛盾供述に当たる）と結合させる。
- 【ポイント】平18判例の「直輸入」禁止
  - 平18判例は書面が供述録取書で、供述者の署名・押印がないから不可とした。本問のB供述書はB自身が書いた「Bの供述書」。だから「厳格な証明」は署名押印ではなく 321条1項3号の要件を意味する → Bに供述不能等なし → 要件不充足で取れない。判例をそのまま貼ると事故る。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 回復証拠は再弾劾にすぎず、一致供述の存在自体を示す非伝聞的利用だから伝聞法則を骨抜きにしない → 「証明力を争う」に含む（多数説・東京高判昭54.2.7）。限定は「弾劾の場面」の話で、回復の場面とは層が違う、と一言添えれば体系的理解を示せる。署名押印あり＝存在は厳格な証明で立証済み。
- 【まぎらわしい選択肢・論点】伝聞例外（321条1項2号）の要件／違法収集証拠排除法則の適用／自白法則（319条1項）の適用
- 【まぎらわしい選択肢・結論】B供述書 取調べ可／A供述録取書 取調べ不可
- 【まぎらわしい選択肢・規範】非限定説／増強証拠肯定説
- 【まぎらわしい選択肢・事実】供述不能（所在不明）／特信情況あり

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

A供述書＝実質証拠は伝聞で切る、限定説でも自己矛盾供述に当たる、作成時期は昭43判例で不問＝弾劾で取れる。B供述書＝矛盾供述の存在に厳格な証明、でもBの供述書だから署名押印でなく321条1項3号、供述不能なしで取れない。A供述録取書＝回復証拠は再弾劾で非伝聞、多数説で328条に含む、署名押印あり＝取れる。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 刑訴法328条の「証拠」を自己矛盾供述に限る限定説の理由づけを述べよ。
  - 模範解答：328条は、証言と矛盾する供述をしたこと自体の立証によって証言の信用性を減殺することを許す趣旨。自己矛盾供述の利用は供述内容の真偽を問わない非伝聞的用法だから許される。これに限らないと、反対尋問を経ない供述内容が実質的に法廷へ流入し、反対尋問権の保障（憲法37条2項）・直接主義など伝聞法則の趣旨が没却される。
- **［規範クイズ 2/3］** 自己矛盾供述を弾劾証拠として用いることが伝聞法則に反しない理由（非伝聞的利用である理由）を述べよ。
  - 模範解答：弾劾で示すのは「証言と食い違う供述をした事実そのもの」であり、その供述内容が真実かどうかは問わない。要証事実は「矛盾供述の存在」であって供述内容の真実性ではないから、内容の真実性を要証事実とする伝聞（320条1項）には当たらない＝非伝聞的利用。だから反対尋問を経ていなくても許される。
- **［規範クイズ 3/3］** 回復証拠を328条に含めてよい理由と、初めから証明力を高める増強証拠との違いを述べよ。
  - 模範解答：回復証拠は、弾劾で減殺された証明力を戻す再弾劾であり、一致供述の存在自体を示す非伝聞的利用だから伝聞法則を骨抜きにしない→「証明力を争う」に含む。増強証拠は減殺される前から証明力を高めようとするもので、328条の「争う」に当たらず含まれない。回復は「いったん下がったものを戻す」、増強は「初めから上げる」で場面が違う。

（規範クイズはここまで＝全3問。最後の3問目まで出したら「規範クイズ、全3問クリア！」と言って次へ）

## 4. ○×クイズ（全8問・1問目から最後まで全部出す）

- **［○×クイズ 1/8］** 公判廷における証人の供述と矛盾する、別の機会にした同一人の供述を記載した書面を、その証言の証明力を減殺する目的で用いる証拠を弾劾証拠という。
  - 正解：○（正しい）
  - 理由：弾劾証拠とは、公判供述の証明力を減殺（弾劾）する目的で用いる証拠で、その典型が自己矛盾供述（証言と食い違う別の機会の供述）。実質証拠（犯罪事実の証明）とは目的が違うから、証拠能力の判断枠組みも変わる。まずこの「用途の仕分け」が出発点。
- **［○×クイズ 2/8］** 刑訴法328条により証明力を争う弾劾証拠として許容される書面は、その内容を犯罪事実の存否を証明する実質証拠としても当然に用いることができる。
  - 正解：×（誤り）
  - 理由：328条が許容するのは証明力を争う（弾劾・回復）目的での利用に限る。犯罪事実そのものを証明する実質証拠として使うには、別途320条1項の伝聞法則をクリアし321条以下の例外要件を満たす必要がある。用途を混同して「弾劾で取れる＝実質証拠でも取れる」とするのは誤り。
- **［○×クイズ 3/8］** 刑訴法328条の「証拠」の範囲について、判例（最判平成18年11月7日）は、証明力を争うために用いうる証拠を、その供述者自身の自己矛盾供述に限るとする限定説を採用している。
  - 正解：○（正しい）
  - 理由：最判平18.11.7は限定説を採り、328条の「証拠」を公判供述者本人の自己矛盾供述に限る。他人の供述や自己一致供述まで許すと、反対尋問を経ない供述内容が法廷に流入し伝聞法則が骨抜きになるからである。この限定説を幹に据えると3書面すべてが処理できる。
- **［○×クイズ 4/8］** 刑訴法328条により弾劾証拠として用いうる自己矛盾供述は、弾劾の対象となる公判証言よりも前に作成され、又は存在していたものでなければならない。
  - 正解：×（誤り）
  - 理由：作成・存在の先後は問わない。自己矛盾供述による証言の証明力の低下は供述が証言に先行するか否かで変わらず、条文上も限定がないからである。判例（最判昭43.10.25）も、証人尋問終了後に作成された検察官調書を弾劾証拠とすることは328条に違反しないとした。本問のA供述書はA証言の後に作られているが、この一言で処理できる。
- **［○×クイズ 5/8］** 自己矛盾供述を弾劾証拠として用いる場合、その供述の要証事実は「供述内容が真実であること」ではなく「証言と矛盾する供述をした事実が存在すること」であるから、供述内容の真実性は問題とならない。
  - 正解：○（正しい）
  - 理由：弾劾の要証事実は矛盾供述の存在そのもの。内容の真偽は問わないから、内容の真実性を要証事実とする伝聞法則の埒外の利用（非伝聞的利用）となる。この理解が、限定説（自己矛盾供述に限る）と設問2の回復証拠の議論を貫く一本の筋になる。
- **［○×クイズ 6/8］** 供述者本人が自らその供述内容を記載した供述書については、伝聞例外の要件として、供述者の署名又は押印は要求されない。
  - 正解：○（正しい）
  - 理由：署名・押印は、他人が録取した供述録取書について、録取の正確性を担保するために要求される（321条1項柱書）。供述書は本人が自ら書いているため録取の過程がなく、署名押印は不要。だから「Bの供述書」では署名押印は問題にならず、判断は321条1項3号の要件に移る。
- **［○×クイズ 7/8］** 他人（録取者）が供述を聴取して記載した供述録取書を刑訴法328条の弾劾証拠として用いる場合、その録取の正確性を担保する供述者の署名・押印は不要である。
  - 正解：×（誤り）
  - 理由：供述録取書は録取者の聴取・記載という伝聞過程を含むため、その正確性を担保する供述者の署名・押印が必要（最判平18.11.7はこれを欠く書面を328条の証拠に当たらないとした）。供述書（本人作成）と供述録取書（他人録取）で要件が違う点が、本問B供述書の性質決定の急所。
- **［○×クイズ 8/8］** いったん弾劾によって減殺された公判供述の証明力を回復するために用いる自己一致供述（回復証拠）も、多数説・裁判例は刑訴法328条の「証明力を争う……証拠」に含まれると解する。
  - 正解：○（正しい）
  - 理由：回復証拠は再弾劾にすぎず、一致供述の存在自体を示す非伝聞的利用だから、「証明力を争う」に回復も含める（多数説・東京高判昭54.2.7）。一方、初めから証明力を高める増強証拠は含まれない（自己矛盾供述に限る限定説の埒外）。「争う＝減殺＋回復／増強は別」の線引きが要。

（○×クイズはここまで＝全8問。最後の8問目まで出したら「○×クイズ、全8問クリア！」と言って復習へ）
