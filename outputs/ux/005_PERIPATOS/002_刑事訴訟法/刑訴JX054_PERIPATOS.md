## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

甲と乙は、共謀のうえ丙を射殺したとして殺人罪で起訴され、共同被告人として審理を受けている。甲は終始一貫して犯行を否認しており、甲を有罪と認定しうる証拠としては、乙の「甲に頼まれて丙を射殺した。」という検察官面前調書（以下「本件検面調書」という。）があるのみである。もっとも、乙は公判廷では甲の関与についてあいまいな供述をするにとどまっている。裁判所が本件検面調書のみを用いて甲を有罪とすることができるか。証拠能力および証明力（補強法則）の観点から論ぜよ。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 甲乙が共同被告人として審理中
- 乙が検面で甲の関与を供述（詳細）
- 乙が公判ではあいまいな供述（供述はある）
- 関門①＝伝聞例外（321条1項2号後段）の充足
- 関門②＝唯一証拠→補強法則（319条2項）が及ぶか

### 参考（読み上げない。入口の問いの答えを含むので判定にだけ使う）

登場人物：
- 甲｜被告人・否認（→有罪認定の対象）
- 乙｜共同被告人・検面で甲の関与を供述／公判ではあいまい
- 丙｜被害者（射殺された）＝対象外
- 検察官｜本件検面調書の作成者

一行要約：甲は否認、有罪証拠は乙の検面調書1本のみ（乙は公判ではあいまい）。

### 入口の問い（3問）

- **［入口 1/3・事案の整理］** 「甲を有罪にできる証拠」を棚卸しする
  - 答え：甲を有罪にできる証拠は本件検面調書ただ1つ。中身は「乙が、甲に頼まれて丙を射殺した」という乙の供述を録取した書面。
  - 答え：タグは①供述証拠（内容の真実性が問題）②書面（調書）③供述主体＝乙（甲にとっては他人）。この3タグが「伝聞か」「どの条文か」を決める。
- **［入口 2/3・見当づけ］** その証拠に立ちはだかる「関門」 ― 見当をつけて
  - 答え：本件検面調書は公判外供述を内容とする書面 → 関門①＝伝聞法則（320条1項）・伝聞例外。しかも甲を有罪にできる証拠はこれ1本だけ → 関門②＝補強法則（319条2項）。証拠能力の関門を越えても、証明力の関門が待っている。
- **［入口 3/3・論点］** 本件検面調書で問題になる論点を挙げて（2つ）
  - 答え：CP①：乙は共同被告人。その調書に321条（被告人以外の者）と322条（被告人）のどちらを使うか → 共同被告人の供述調書と適用条文の選択。（乙は「被告人」でもあり甲から見れば「他人」でもある二面性）
  - 答え：CP②：乙は公判で供述している（あいまいだが供述はある） → 321条1項2号後段（相反・実質的不一致）の意義。（供述不能の前段ではなく後段のルート）

### 組み立ての順序（入口の問いのあと、骨子に入る前に読み上げる）

- 順番：第1　乙の検面調書の証拠能力 → 第2　補強法則と共犯者の自白
- 第1　乙の検面調書の証拠能力
  - 論点1：共同被告人の供述調書と適用条文の選択
  - 論点2：相反・実質的不一致の意義
- 第2　補強法則と共犯者の自白

この順番の理由（参考。結論・配点には触れず、一言で言い直す）：2つの関門は論理的な前後関係で並ぶ。まず①証拠能力（伝聞例外の要件を満たすか）を固め、それが通ってはじめて②証明力（補強法則）の検討に進む。逆順にしない。

### 骨子（2項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　乙の検面調書の証拠能力

- 見出しの補足（結論を含む。項目の終わりに読む）：伝聞例外・321条1項2号後段
1. 供述内容の真実性が要証事実 → 伝聞証拠（320条1項）＝原則証拠能力なし
2. 乙は共同被告人 → 【論点】共同被告人の供述調書と適用条文の選択
   - あてはめ：甲との関係で乙は「被告人以外の者」 → 321条説（反対尋問権保障）→ 検面ゆえ2号
3. 乙は公判で供述あり（あいまい）→ 前段でなく後段 → 【論点】相反・実質的不一致の意義
   - あてはめ：規範：両供述を対比して異なる認定を導く場合（詳細供述も含む）→ 検面「甲に頼まれ射殺」⇔ 公判「あいまい」＝相反該当
4. 署名押印（柱書）・特信情況（ただし書）は記載なし → 仮定的処理
- 結論：これらを前提に 証拠能力あり

#### 第2　補強法則と共犯者の自白

- 見出しの補足（結論を含む。項目の終わりに読む）：319条2項・憲38条3項
1. 甲は否認・証拠は検面1本 → 「自己に不利益な唯一の証拠」＝補強法則の場面
2. 【論点】共犯者の自白は「本人の自白」に含まれ補強を要するか
   - あてはめ：甲との関係で乙は第三者 → 「本人の自白／その自白」に含まれず → 不要説（文理・自由心証318の例外の不拡張・危険は証明力）
3. → 補強不要＝理論上は検面1本で有罪可能
4. もっとも 責任転嫁・引っ張り込みの危険は証明力（318）の問題 → 実際の有罪認定は困難

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】『「甲に頼まれて丙を射殺した」（検面）』 → 詳細な前の供述（後段の一方）
- 【拾う事実】『公判では「あいまい」』 → 相反・実質的不一致の他方
- 【拾う事実】『乙は「共同被告人」』 → 321条説／322条説の条文選択を分ける
- 【拾う事実】『甲は終始否認・他に証拠なし』 → 検面が「唯一の証拠」＝補強法則の起動
- 【拾う事実】『署名押印・特信情況の記載なし』 → 仮定的処理の対象
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 伝聞該当性＝供述内容の真実性が要証事実だから伝聞に当たる（一文）。署名押印・特信情況＝問題文に記載がなければ「仮定的処理」で一言。要件は必ず全部通すが、争いが無い所は一文でよい。
- 【効く事実】「後段の意義」のあてはめで使う事実
  - 条文選択 → 乙は甲との関係で「被告人以外の者」（第三者）／後段該当 → 検面「甲に頼まれて射殺」⇔ 公判「あいまい」の落差／仮定的処理 → 署名押印・特信情況は問題文に記載なし。
- 【規範の要点】不要説の規範
  - 甲との関係で乙は「被告人以外の者」＝第三者にすぎず、共犯者の自白を「本人の自白」（憲法38条3項）・「その自白」（319条2項）と同一視できない → 補強証拠は不要（不要説・最大判昭33.5.28）。理論上は検面調書1本で甲を有罪としうる。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 321条説（論点①）も補強不要説（論点②）も、乙を第三者と見る一本の軸で結べる。論点①で322条説（被告人性重視）を採ると論点②で補強不要と言いにくくなる ── 条文選択と補強法則の理由を揃えるのが一貫性のコツ。締めは「理論上は有罪可能／実際には困難」の二段で。
- 【まぎらわしい選択肢・論点】自白法則（任意性）の有無／違法収集証拠排除法則／前段（供述不能）の該当性
- 【まぎらわしい選択肢・結論】証拠能力なし（伝聞排除）／補強証拠が必要で有罪不可
- 【まぎらわしい選択肢・規範】322条説／必要説
- 【まぎらわしい選択肢・事実】供述不能／正面から矛盾する供述

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

証拠能力＝乙の検面は伝聞、共同被告人でも甲から見れば「被告人以外の者」で321条説、検面ゆえ2号、公判で供述ありで後段、詳細な検面⇔あいまい公判で相反、署名押印・特信は仮定で証拠能力あり。補強法則＝証拠は1本、共犯者は第三者で「本人の自白」でない＝補強不要（不要説）、理論上は有罪可能だが責任転嫁の危険は証明力の問題で実際は困難。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 共同被告人乙の供述調書を、他の被告人甲を有罪とする証拠に用いる場合、どの条文で証拠能力を判断すべきか（判例）。理由も一言。
  - 模範解答：甲との関係では乙も「被告人以外の者」にあたるから、322条（被告人の供述）ではなく321条で判断する（321条説・判例＝最判昭27.12.11）。理由＝甲の反対尋問権保障の必要が高く、緩やかな322条で甲に不利益な証拠を入れるべきでない。検面ゆえ321条1項2号。
- **［規範クイズ 2/3］** 321条1項2号後段にいう「前の供述と相反するか若しくは実質的に異なった供述をしたとき」の意義を述べよ（判例の規範）。
  - 模範解答：両供述を対比して、それにより異なった認定を導くようになる場合をいい、正面から矛盾する場合に限らず、公判供述より前の供述の方がより詳細である（公判供述がより詳細でない）場合も含む（最決昭32.9.30）。詳細な検面 ⇔ あいまいな公判、という落差がこれに当たる。
- **［規範クイズ 3/3］** 共犯者の自白に補強証拠を要しないとする不要説（判例）の理由を挙げよ（3点程度）。
  - 模範解答：①甲との関係で共犯者は「被告人以外の者」＝第三者であり、反対尋問でその信用性を争える。②「本人の自白／その自白」に共犯者の自白を読み込むのは文理上無理。③補強法則は自由心証主義（318条）の例外であり、明文なく拡張すべきでない。責任転嫁の危険は証明力の問題として処理すれば足りる。

## 4. ○×クイズ（全8問・1問目から最後まで全部出す）

- **［○×クイズ 1/8］** 証拠の「証拠能力」と「証明力」は同じ概念であり、証拠能力が認められれば当然にその証拠だけで有罪認定ができる。
  - 正解：×（誤り）
  - 理由：証拠能力は「法廷に証拠として提出できる資格」（入口）、証明力は「事実を推認させる力の強さ」（出口）で別概念。証拠能力があっても、補強法則（319条2項）等により、その証拠だけでは有罪にできない場面がある。だから証拠能力→証明力の二段で検討する。
- **［○×クイズ 2/8］** 公判期日における供述に代えて書面を証拠とし、その書面に記載された供述内容の真実性を立証しようとする場合、その書面は伝聞証拠に当たり、原則として証拠能力が否定される（320条1項）。
  - 正解：○（正しい）
  - 理由：供述証拠は知覚・記憶・表現・叙述の各過程に誤りが入りやすく、反対尋問等で吟味できない伝聞証拠は原則排除される（320条1項）。要証事実との関係で供述内容の真実性が問題になるかどうかが伝聞・非伝聞の分水嶺。本件検面調書は乙の供述内容の真実性が問題だから伝聞に当たる。
- **［○×クイズ 3/8］** 補強法則（319条2項）は証拠能力に関するルールであり、伝聞例外の要件を満たすか否かを判断する前に、まず補強法則の適用を検討すべきである。
  - 正解：×（誤り）
  - 理由：補強法則は証明力（自由心証）の制限に関するルールで、証拠能力の問題ではない。証拠能力（伝聞例外）を先に固め、証拠として使えることを前提に、その証拠だけで有罪にできるかを補強法則で検討する。入口→出口の順を崩さないのがコツ。
- **［○×クイズ 4/8］** 検察官面前調書（321条1項2号）は、供述者が供述不能である場合（前段）のほか、公判準備・公判期日で前の供述と相反するか実質的に異なった供述をしたとき（後段）にも、伝聞例外として証拠能力が認められうる。
  - 正解：○（正しい）
  - 理由：321条1項2号は、前段（死亡・所在不明・国外・精神身体の故障による供述不能）と後段（相反・実質的不一致供述）の2ルートを定める。本件の乙は公判で供述している（あいまいだが供述はある）から、供述不能の前段ではなく、後段の相反・実質的不一致で処理する。前段／後段の振り分けは「供述しているか否か」で決まる。
- **［○×クイズ 5/8］** 検察官面前調書につき321条1項2号後段を適用するには、公判供述が前の供述と正面から矛盾・対立している必要があり、前の供述の方が単に詳細であるにとどまる場合には後段に当たらない。
  - 正解：×（誤り）
  - 理由：判例（最決昭32.9.30）は「相反・実質的不一致」を両供述を対比して異なる認定を導く場合と広くとらえ、前の供述の方がより詳細であるにとどまる場合も含むとする。正面衝突まで要求しない。本件の「詳細な検面 ⇔ あいまいな公判」も後段に当たる。
- **［○×クイズ 6/8］** 供述録取書について、321条1項柱書の要求する供述者の署名・押印や、2号ただし書の相対的特信情況の有無が問題文から明らかでない場合、これらが備わることを前提とした「仮定的処理」をするのが穏当である。
  - 正解：○（正しい）
  - 理由：署名押印（柱書）・特信情況（ただし書）は伝聞例外の要件だが、問題文に事実の記載がなければ存否を断定できない。「これらが認められることを前提とすれば証拠能力が認められる」と仮定的に処理するのが答案作法。
- **［○×クイズ 7/8］** 共犯者（共同被告人）の自白は319条2項・憲法38条3項にいう「本人の自白」に含まれ、被告人本人を有罪とするには常に別途の補強証拠を要する（判例）。
  - 正解：×（誤り）
  - 理由：判例（最大判昭33.5.28〔百選A43〕）は不要説。共犯者は被告人本人との関係では「被告人以外の者」であり、純然たる証人と本質を異にしないから、その自白を「本人の自白」と同一視できず、補強証拠がなくても有罪認定できる（憲法38条3項に違反しない）。必要説（責任転嫁の危険を重視）と混同しないこと。
- **［○×クイズ 8/8］** 共犯者の自白に類型的に伴う責任転嫁・引っ張り込みの危険は、証拠能力（補強法則）の問題としてではなく、証明力の問題として自由心証主義（318条）の枠内で慎重に評価すれば足りる。
  - 正解：○（正しい）
  - 理由：不要説の眼目。責任転嫁の危険は確かに存在するが、それを補強法則（証拠能力・証明力制限のルール）に取り込むのではなく、証明力＝自由心証（318条）の問題として処理する。だから「理論上は検面調書1本で有罪可能／もっとも実際の認定は慎重を要する」と二段で締めるのが判例の射程を踏まえた書き方。
