## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

甲は、酒税法上の販売業免許を受けることなく、自己の店舗内において酒類を販売したとして起訴された。甲は捜査段階において事実を認めたため、検察官によって自白調書が作成されていた。公判期日において、検察官が証拠調べ請求をした証拠は、自白調書以外では、甲が嫌疑を受ける前から酒類以外の商品についても併せて記入していた売上帳（以下「本件売上帳」という。）しかなかった。甲は、公判では否認に転じ、甲の弁護人は自白調書及び本件売上帳に対する証拠意見として、不同意との意見を述べた。裁判所は、自白調書及び本件売上帳を証拠として採用し、証拠調べをした結果、本件売上帳のみでは犯罪事実を認定することはできないが、甲の自白調書をも勘案すれば、甲が無免許で酒類販売をした事実が認定できるとして、甲に有罪判決を下した。以上の事案における、裁判所の措置のうち問題となる点を挙げ、その適法性について、論じなさい。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 嫌疑前：甲、売上帳に酒類以外も機械的・継続的に記入
- 甲、無免許酒類販売で起訴
- 捜査段階：甲が自認 → 自白調書作成
- 公判：甲は否認・弁護人が両証拠に不同意／請求証拠は自白調書と売上帳のみ
- 裁判所：両証拠を採用・証拠調べ、勘案して有罪

### 骨子（3項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　証拠採用の適法性

- 見出しの補足（結論を含む。項目の終わりに読む）：伝聞例外・証拠能力
1. 両証拠は公判外書面＝伝聞証拠（320①）／弁護人不同意 → 326不可・個別例外を検討
2. 自白調書＝「不利益な事実の承認」＋任意性 → 規範：322条1項 → 証拠能力○
3. 本件売上帳 → 【論点】「商業帳簿」該当性 → 規範：323条2号（機械的・継続的作成） → 該当
   - あてはめ：嫌疑前から業務の通常の過程で継続記帳（大阪高判昭25.9.9）
- 結論：両証拠に証拠能力あり ＝ 採用・証拠調べの措置は適法

#### 第2　補強証拠適格

- 見出しの補足（結論を含む。項目の終わりに読む）：自白からの独立性・319条2項
1. 証拠は自白調書＋売上帳のみ → 自白のみでは有罪不可（319②）＝売上帳を補強に使用
2. 売上帳も甲自身の供述 → 【論点】被告人自身の供述で補強できるか
   - あてはめ：規範：補強証拠は自白から独立を要す（趣旨＝自白偏重の誤判防止）／原則は被告人供述での補強不可
3. 例外：嫌疑前・捜査と無関係・機械的継続的作成 → 独立性あり（最決昭32.11.2）
- 結論：補強証拠適格を肯定 ＝ 補強に用いた措置は適法

#### 第3　補強証拠の証明力

- 見出しの補足（結論を含む。項目の終わりに読む）：相対説・333条1項
1. 売上帳のみでは犯罪事実を認定不可 → 【論点】補強証拠に単独の証明力が必要か
2. 規範：相対説（自白と相まって認定できれば足りる／絶対説なら無罪）
3. あてはめ：自白調書と売上帳を勘案 → 合理的疑いを超えて認定＝「犯罪の証明」（333①）
- 結論：いずれの措置も適法

- 【拾う事実】「売上帳のみでは認定不可・自白をも勘案すれば認定」 → 相対説／絶対説の分岐点
- 【事案の整理】措置を動詞で分解
  - 「措置の適法性」型は、まず措置を〈採用した〉〈補強に使った〉〈有罪にした〉と動詞で割る。採用＝証拠能力、補強に使った＝補強法則、と措置ごとに条文が対応する。人物より証拠と手続を棚卸しするのが刑訴の第一歩。
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 自白調書＝不利益事実の承認＋任意性を疑う事情なし＝322条1項で一言。売上帳＝嫌疑前から機械的・継続的＝「商業帳簿」＝323条2号。紙幅は補強法則（手5以降）に残す。
- 【ポイント】独立性の一点で決まる
  - 補強証拠は自白から独立していることを要する（趣旨＝自白偏重による誤判の防止）。被告人自身の供述は原則ダメ。もっとも嫌疑前・捜査と無関係・機械的継続的に作成された記録は例外的に独立性あり。ここが本問最大の差がつく一点。
- 【効く事実】「補強証拠適格をで割る」のあてはめで使う事実
  - 独立性 → 「嫌疑を受ける前から」「機械的・継続的に」「捜査と無関係に」記入＝自白の単なる繰り返しではない。「甲自身が作成した書面」という所在の指摘も落とさない。
- 【ポイント】相対説で締める
  - 補強証拠単独で犯罪事実を認定できる証明力まで要求するのが絶対説、自白と相まって認定できれば足りるのが相対説（判例）。本問は差が出るように作られた教室事例で、判例＝相対説に立てば「犯罪の証明」（333条1項）ありとして有罪＝措置は適法。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 総合問題は最後に「以上より、①②③いずれの措置も適法」と束ねて締める。三段の入れ子（証拠能力→適格→証明力）を全部通したことを、設問の言葉（措置の適法性）で受け直すのが答案の作法。個別結論の羅列で終えない。
- 【まぎらわしい選択肢・論点】自白の任意性（319条1項）の有無／共同被告人の供述の証拠能力
- 【まぎらわしい選択肢・結論】補強証拠適格を欠き無罪／証拠能力を欠き証拠排除
- 【まぎらわしい選択肢・規範】絶対説／自白法則
- 【まぎらわしい選択肢・事実】捜査開始後に作成された帳簿／公判廷の自白のみ

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

証拠能力＝両証拠は伝聞、不同意で326不可、自白調書は322①・売上帳は323②の商業帳簿で証拠能力あり。補強適格＝自白だけでは有罪不可（319②）、補強証拠は自白から独立を要す、売上帳も甲の供述だが嫌疑前・機械的作成で独立性あり＝適格肯定。証明力＝相対説で自白と相まって認定できれば足り、犯罪の証明あり＝措置は適法。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 伝聞証拠が原則として排除される（320条1項）趣旨を述べよ。
  - 模範解答：供述証拠は知覚・記憶・叙述の各過程に誤りが介在しうるのに、公判廷外の供述は反対尋問・宣誓・供述態度の観察による吟味を経ておらず、類型的に信用性が担保されないから（反対尋問権＝憲法37条2項の保障の現れ）。ゆえに321条以下の例外に当たる場合に限り例外的に証拠能力を認める。
- **［規範クイズ 2/3］** 補強法則（319条2項）の趣旨と、そこから導かれる補強証拠の要件を述べよ。
  - 模範解答：趣旨＝自白偏重による誤判の防止（自白は「証拠の女王」として過大評価されやすく、虚偽自白の危険もある）。∴補強証拠は自白から独立した証拠であることを要し、被告人自身の供述での補強は原則不可。ただし嫌疑前に捜査と無関係に機械的・継続的に作成された記録は例外的に独立性を肯定できる。
- **［規範クイズ 3/3］** 補強証拠の証明力に関する相対説・絶対説の区別と、判例の立場を述べよ。
  - 模範解答：相対説＝補強証拠は自白と相まって犯罪事実を認定できれば足りる／絶対説＝補強証拠単独で（自白を除いて）犯罪事実を認定できる程度の証明力を要する。判例は相対説。本問では相対説なら有罪（適法）、絶対説なら無罪となり、結論が分かれる。

## 4. ○×クイズ（全12問・1問目から最後まで全部出す）

- **［○×クイズ 1/12］** 公判廷外で作成された書面を、その記載内容が真実であることの立証に用いる場合、それは伝聞証拠に当たり、原則として証拠能力が否定される。
  - 正解：○（正しい）
  - 理由：供述証拠は知覚・記憶・叙述の各過程に誤りが入りうるのに、反対尋問・宣誓・供述態度の観察による吟味を経ないため、類型的に信用性が担保されない。ゆえに伝聞証拠は原則排除される（320条1項）。書面が「内容の真実性」の立証に使われているかがまず入口の判断。
- **［○×クイズ 2/12］** 弁護人が書面に「不同意」との証拠意見を述べても、裁判所は当事者の同意（326条）があったものとして、伝聞例外の個別要件を検討せずに証拠能力を認めることができる。
  - 正解：×（誤り）
  - 理由：326条の同意は当事者双方の同意を要する。一方が「不同意」なら同意ルートは使えず、321条以下の個別の伝聞例外の要件を満たさない限り証拠能力は認められない。不同意＝反対尋問権を放棄しないという意思表示だから、個別要件審査に進むのが筋。
- **［○×クイズ 3/12］** 被告人の供述を録取した書面で被告人の署名・押印のあるものは、その内容が不利益な事実の承認を内容とするものであれば、特信情況がなくても、任意性が認められる限り証拠能力を有する（322条1項）。
  - 正解：○（正しい）
  - 理由：322条1項は、被告人自身の供述で反対尋問権の問題が生じにくく、不利益事実の承認は虚偽の危険が類型的に低いことから、任意性さえあれば証拠能力を認める（特信情況は利益供述の場合に要求される）。自白調書はこの筋で拾う。
- **［○×クイズ 4/12］** 証拠能力（証拠として取り調べる資格）と証明力（心証形成に働く力）は別次元の問題であり、証拠能力が認められても、直ちに有罪認定に足りる証明力が備わるわけではない。
  - 正解：○（正しい）
  - 理由：証拠能力は「取り調べてよいか」の入口の資格、証明力は「どれだけ事実を認定できるか」の中身の力。両者は次元が異なり、証拠能力ありでも証明力が足りなければ有罪にできない。補強法則（319条2項）は証明力の側の規律で、証拠能力の話と混同しないことが要。
- **［○×クイズ 5/12］** 商業帳簿その他、業務の通常の過程において機械的・継続的に作成された書面は、作成者を証人尋問しなくても、伝聞例外として証拠能力が認められうる（323条2号）。
  - 正解：○（正しい）
  - 理由：323条の特信文書は、作成過程の定型性・機械性・反復性ゆえに意図的な虚偽記載の危険が低く、反対尋問による吟味を要しないほどの高度の類型的信用性が認められる。だから供述不能等の要件も要らない。売上帳・航海日誌等が典型例。
- **［○×クイズ 6/12］** 被告人側が不同意とした供述書面は、322条・323条の伝聞例外の要件をすべて満たしても、当事者の同意がない以上、証拠能力は認められない。
  - 正解：×（誤り）
  - 理由：326条の同意は伝聞例外を認める複数ある根拠の一つにすぎない。同意がなくても、321条以下の個別の伝聞例外（322条1項・323条2号等）の要件を満たせば証拠能力は認められる。不同意は「個別要件審査に進め」という合図であって、証拠能力の全否定ではない。
- **［○×クイズ 7/12］** 被告人は、公判廷における自白であるか否かを問わず、その自白が自己に不利益な唯一の証拠である場合には、有罪とされない（319条2項・補強法則）。
  - 正解：○（正しい）
  - 理由：319条2項は自白偏重による誤判を防ぐため、自白のみによる有罪認定を禁じ、独立の補強証拠を要求する（憲法38条3項を受けた規定）。公判廷の自白か否かを問わない点が条文の明文。だから本問でも自白調書だけでは足りず、売上帳が補強証拠たりうるかが問われる。
- **［○×クイズ 8/12］** 補強法則における補強証拠は自白から独立した証拠でなければならず、被告人自身の供述をもって自白を補強することは、原則として許されない。
  - 正解：○（正しい）
  - 理由：補強法則の趣旨（自白偏重の誤判防止）は、自白から独立した資料による裏付けを要求する。被告人自身の供述で補強を認めれば「自白を自白で補強」する結果になり趣旨を没却するから、原則として許されない。この「原則」を立てて初めて、次の「例外」（嫌疑前の機械的記録）が生きる。
- **［○×クイズ 9/12］** 被告人が嫌疑を受ける前に、捜査と無関係に備忘のため機械的・継続的に作成した帳簿であっても、被告人自身が作成した書面である以上、およそ補強証拠として用いることはできない。
  - 正解：×（誤り）
  - 理由：嫌疑前に捜査と無関係に機械的・継続的に作成された記録は、自白の単なる繰り返しではなく自白からの独立性を例外的に肯定でき、補強証拠適格を有する（最決昭32.11.2は同種帳簿を「被告人の自白と目すべきものではない」とした）。「被告人作成＝一律に不可」ではない。原則で止めず例外まで書き切るのが差を分ける。
- **［○×クイズ 10/12］** 補強証拠は自白と相まって犯罪事実を認定できれば足り、補強証拠それ自体で犯罪事実を認定できる程度の証明力までは要しないとするのが判例（相対説）である。
  - 正解：○（正しい）
  - 理由：心証形成は本来裁判所の専権で、各証拠を総合して合理的疑いを超える証明の有無を判断するのが自然。補強法則の趣旨（誤判防止）も自白と補強証拠の総合で満たされる。ゆえに補強証拠に単独の証明力までは要求しない（相対説）のが判例。実務上、絶対説との差はほとんど出ないとされるが、本問は差が出る作りになっている。
- **［○×クイズ 11/12］** 判例は、補強証拠が、自白を除いてそれ自体で犯罪事実を認定できるだけの証明力を有することを要求している（絶対説）。
  - 正解：×（誤り）
  - 理由：それは絶対説の立場で、判例ではない。絶対説は補強証拠に過度の証明力を要求して有罪認定を不当に困難にし、心証形成の総合判断という性質にそぐわないと批判される。判例は相対説（自白と相まって認定できれば足りる）。本問で絶対説を採ると売上帳単独では認定できず無罪になってしまい、裁判所の措置は違法という帰結になる。
- **［○×クイズ 12/12］** 補強法則の下でも、自白と補強証拠を総合して合理的な疑いを超える程度に達すれば、「犯罪の証明」（333条1項）があったといえ、有罪判決をすることができる。
  - 正解：○（正しい）
  - 理由：「犯罪の証明」とは合理的な疑いを超える程度の証明（高度の蓋然性）をいう。相対説の下では、補強証拠単独で認定できなくても、自白と相まって合理的疑いを超えれば「犯罪の証明」ありとして有罪にできる（333条1項）。本問の裁判所の措置はこの筋で適法と評価される。
