3. 同一事故／過失の切り取り方の差＝非両立 → 同一性あり

#### 第2　措置②　無罪判決に至る過程

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「一時停止義務違反」→「安全確認義務違反」 → 過失の切り取り方の差（公訴事実の同一性の材料）
- 【拾う事実】『同一の交差点・同一運転・被害者A・傷害結果』 → 基本的事実関係の同一性を基礎づける
- 【拾う事実】「裁判所も同様の心証を得た」 → 原訴因なら有罪＝訴因維持義務の前提
- 【拾う事実】『「直ちに無罪判決」（勧告・命令なし）』 → 後見的措置の不作為＝審理不尽の起点
- 【拾う事実】『Aの傷害の程度は不明』 → 「重大性」のあてはめが微妙になる要素
- 【事案の整理】措置の数え方
  - 「〜の措置の適法性」型は、裁判所の判断・処分を一つずつ箱に分けるのが第一歩。本問は許可（処分）と無罪判決（裁判）の別個の措置。同一の裁判所でも、措置ごとに適法／違法の評価は変わりうる。
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 「検察官の請求」＝あり／「効果」＝許さなければならない（裁量なし）。ここは一言で通過し、公訴事実の同一性のあてはめと訴因維持義務の根拠づけに筆を集める。
- 【効く事実】「公訴事実の同一性」のあてはめで使う事実
  - 同一性 → 同一の交差点・同一の自動二輪車運転・被害者A・傷害結果が共通／差異 → 過失を「一時停止義務違反」と捉えるか「安全確認義務違反」と捉えるかだけ。事実は必ず「同一機会の一個の過失運転行為の択一的評価＝非両立」という評価語と結合させる。
- 【規範の要点】後見的義務の要件の規範
  - ①原訴因のまま有罪であることが証拠上明白であり、かつ②事件が重大であるときは、裁判所は原訴因の維持又は訴因の再変更を勧告・命令すべき義務を負い、これを怠って直ちに無罪判決を下せば審理不尽の違法（379条）がある。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 「命令できる」＝権限だが形成力なし → 裁判所ができるのは主に勧告・示唆。だから答案は「命令」より「原訴因維持の勧告・釈明」を軸に構成すると整合的。訴因変更命令義務との表裏の対比を一文添えると理解の深さが伝わる。
- 【まぎらわしい選択肢・論点】訴因変更の要否（審判対象逸脱・防御）／一事不再理効の客観的範囲
- 【まぎらわしい選択肢・結論】許可は違法／措置②も適法で確定
- 【まぎらわしい選択肢・規範】罪質同一説／訴因共通説
- 【まぎらわしい選択肢・事実】訴因変更命令に形成力あり／検察官の同意が必要

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

## 3. 規範クイズ（3問）

- **Q04［規範］** 過失犯で、同一の事故（日時・場所・被害者・結果が同一）について過失（注意義務違反）の態様のみを差し替える訴因変更が、公訴事実の同一性の枠内に収まる理由を述べよ。
  - 模範解答：同一機会の一個の過失運転行為を、どの注意義務違反として切り取るかを変えたにすぎず、両訴因は同一の社会的事実を択一的に評価したもの＝非両立の関係にある。日時・場所・被害者・結果が共通で基本的事実関係の同一性があるから、公訴事実の同一性の枠内。日時・場所・被害者まで異なれば別個の事故＝別の公訴事実となる点が分水嶺。
- **Q05［規範］** 公訴事実の同一性の判断基準（規範）と、その徴表を述べよ。
  - 模範解答：公訴事実の同一性は、両訴因の基礎となる社会的事実が基本的に同一といえるか否か（基本的事実関係の同一性）で判断する。その徴表として、両訴因が同一事実を異なる法律的観点から捉えたにすぎず相互に両立しない関係（非両立性）にあることを用いる。趣旨は、訴因が審判対象と防御範囲を画する（256条3項）ことから、変更の許容限界と一事不再理効の範囲を画することにある。
- **Q06［規範］** 訴因維持義務（無罪となる訴因への変更後の後見的義務）の根拠と発生要件を述べよ。
  - 模範解答：訴因設定は当事者たる検察官の権限に属するのが原則だが、真実発見（刑訴1条）の要請から、裁判所の後見的介入権限である312条2項を手がかりに、権限が例外的に義務へ転化すると構成する。発生要件は、訴因変更命令義務の議論を参照し、①原訴因のまま有罪であることが証拠上明白であり、かつ②事件が重大であること。明文も最高裁判例もない弱点を、要件で限定して補う。

## 4. ○×クイズ（8問）

- **Q07［○×］** 訴因変更を許可するか否かの判断において、裁判所が判断するのは訴因変更の当否（妥当性）ではなく、両訴因に公訴事実の同一性があるか否かである。
  - 正解：○（正しい）
  - 理由：刑訴312条1項が裁判所に判断させるのは「公訴事実の同一性を害しない限度」か否かのみ。訴因変更が妥当か・望ましいかは判断対象ではない。ここを取り違えて「無罪になる変更を認めたのは不当だから許可が違法」と論じるのが本問最大の誤り筋。
- **Q08［○×］** 公訴事実の同一性が認められる場合でも、裁判所は検察官の訴因変更請求を許可するかどうかを裁量で決めることができる。
  - 正解：×（誤り）
  - 理由：312条1項は「許さなければならない」と規定し、同一性を害しない限り許可は義務。裁判所に許否の裁量はない。だからこそ、無罪となる訴因への変更でも許可自体は適法となり、問題は「許可後に直ちに無罪としてよいか」へ移る。
- **Q09［○×］** 「公訴事実の同一性」は、両訴因の基礎となる社会的事実が基本的に同一か否か（基本的事実関係の同一性）で判断し、両訴因が相互に両立しない関係（非両立性）にあることをその徴表とする。
  - 正解：○（正しい）
  - 理由：判例（最判昭29.5.14）の確立した基準。基本的事実関係が同一かを基準とし、両訴因が同一事実の異なる法律的構成で一方が立てば他方は成り立たない（非両立）ことを徴表とする。罪質同一説・訴因共通説はいずれも通説の座を占めない。
- **Q10［○×］** 起訴状記載の原訴因について有罪判決を得られる場合には、裁判所は、検察官からの訴因変更請求を許可してはならない。
  - 正解：×（誤り）
  - 理由：最判昭42.8.31は、起訴便宜主義（248条）・公訴取消（257条）を根拠に、有罪判決が得られる場合であっても、公訴事実の同一性を害しない限り訴因変更を許可しなければならないとする。有罪を得られることは許可を拒む理由にならない。
- **Q11［○×］** 無罪となるべき訴因への変更を裁判所が許可することは、それ自体が違法であり、許可の時点で訴訟手続の法令違反となる。
  - 正解：×（誤り）
  - 理由：許可自体は適法（最判昭42.8.31）。同一性を害しない限り許可は義務だからである。違法が問題となるのは「許可後、後見的措置をとらずに直ちに無罪判決を下したこと」＝出口の過程であって、許可という入口ではない。
- **Q12［○×］** 無罪となる訴因への変更を許可した後、原訴因の維持や訴因の再変更を勧告・命令することなく直ちに無罪判決を下したことの違法は、審理不尽（訴訟手続の法令違反・刑訴379条）として控訴理由となりうる。
  - 正解：○（正しい）
  - 理由：大阪高判昭56.11.24は、無罪となる訴因への変更を許可した以上、再変更の勧告・命令等の後見的措置をとるべき義務があり、これを怠り直ちに無罪判決を下せば審理不尽の違法があるとした。審理不尽は379条の訴訟手続の法令違反の一態様。
- **Q13［○×］** 裁判所の訴因変更命令（刑訴312条2項）には形成力があり、裁判所が命令すれば、検察官が現実に変更しなくても訴因は当然に変更される。
  - 正解：×（誤り）
  - 理由：最決昭43.11.26は、訴因変更命令に形成力はないとした ── 命令しても、検察官が変更しない限り訴因は変わらない。訴因設定はあくまで検察官の権限に属する（当事者主義）。ゆえに、後見的措置も勧告・釈明が中心となるとするのが判例の結論である。
- **Q14［○×］** 訴因維持義務（無罪となる訴因への変更後、原訴因維持・再変更を促すべき義務）は、原訴因では無罪だが心証事実では有罪という場合に問題となる「訴因変更命令義務」を、裏返した関係にある。
  - 正解：○（正しい）
  - 理由：訴因変更命令義務＝「今の訴因では無罪だが変更すれば有罪」の場面で変更を促す義務。訴因維持義務＝「今の訴因では有罪だが変更すれば無罪」の場面で維持・再変更を促す義務。ともに312条2項の後見的権限が例外的に義務化する構造で、方向が逆なだけの表裏の関係。
