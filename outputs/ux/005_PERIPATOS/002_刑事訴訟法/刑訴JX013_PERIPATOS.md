## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

警察官P及びQは、甲に対する覚せい剤所持事件において、甲の自宅を捜索場所、差し押さえるべき物を「覚せい剤、注射器、計量器、その他本件に関係ありとされる一切の資料及び物件」とする捜索差押許可状を得た。P及びQは、上記令状を用いて甲を立会人とする甲宅の捜索を開始したところ、執行中に、甲宛ての宅配物が配達され、甲がこれを受領した。Pは、甲に宅配物の中を見せるよう求めたが甲が拒んだため、甲から宅配物を取り上げて中を捜索したところ、注射器を発見し、これを差し押さえた。一方、Qは、甲の寝室を捜索していたところ高価な腕時計十数点が出てきたため、これらを床に並べて写真撮影をした。その後、甲は、P及びQの行為は違法であると主張し、注射器の返還及びQが写真撮影をしたことによって得られたネガの廃棄又は返還を求めるとして、準抗告を申し立てた。甲の準抗告は認められるかについて、論じなさい。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 覚せい剤所持事件で甲宅の捜索差押許可状が発付
- P・Qが令状を用い甲立会いで甲宅の捜索開始
- 執行中に甲宛て宅配物が配達され、甲が受領
- Pが甲の拒否を排し宅配物を取り上げ捜索・注射器を差押え
- Qが寝室の腕時計十数点を床に並べ写真撮影（差押えはせず）
- 甲が準抗告（注射器返還・ネガ廃棄／返還を請求）

### 入口の問い（3問）

- **［入口 1/3・事案の整理］** 争われている「処分」を棚卸しする
  - 答え：審査するのは「甲が違法と主張する処分」＝Pの宅配物の捜索・注射器の差押えと、Qの腕時計の写真撮影の2つ。
  - 答え：申立ての中身は「注射器の返還」（P分）と「ネガの廃棄・返還」（Q分）。処分ごとに分けて審査するのが第一歩。
- **［入口 2/3・見当づけ］** 各処分の「法的性質」 ― 見当をつけて
  - 答え：P：宅配物を捜索し注射器の占有を取得 → 差押え＝「押収」。Q：腕時計を動かさず床に並べて撮影しただけ → 写真撮影＝「検証」。この性質の違いが、後で準抗告の対象性を分ける。
- **［入口 3/3・論点］** 各処分の問題になる論点を挙げて（3つ）
  - 答え：CP①（P・①違法か）：宅配物は令状呈示時に捜索場所に無く執行中に搬入 → 令状の効力が及ぶ物的範囲。（呈示時点で範囲が固定されるか）
  - 答え：CP②（Q・①違法か）：室内の写真撮影＝検証。無令状で許されるか → 無令状検証の許容範囲（必要な処分の2類型）。（証拠価値保全／執行状況記録に当たるか）

### 骨子（3項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　準抗告の法的根拠

- 見出しの補足（結論を含む。項目の終わりに読む）：総論
1. P・Qは警察官＝司法警察職員 → 根拠は430条2項（検察官・検察事務官は1項）
2. 審査は二段 → ①その処分が違法か ②準抗告の対象たる処分（39条3項の処分・押収・押収物の還付等）か
   - あてはめ：以下、P・Qを時間軸で順に検討

#### 第2　Pの注射器差押え

- 見出しの補足（結論を含む。項目の終わりに読む）：令状効力
1. 宅配物は呈示時点で捜索場所に無く執行中搬入 → 【論点】捜索差押許可状の効力が及ぶ物的範囲
2. 規範：効力肯定説（場所記載の趣旨＝住居の不可侵／執行時点の幅／呈示は限定機能なし）
   - あてはめ：執行中に甲が受領＝被処分者の管理下 → 新たな住居権侵害なし → 効力及ぶ
3. 注射器は令状記載物／取り上げは「必要な処分」（222条1項・111条1項）で相当 → 差押え適法
- 結論：適法 ＝ 準抗告は認められない（注射器の返還請求不可）

#### 第3　Qの写真撮影

- 見出しの補足（結論を含む。項目の終わりに読む）：検証・準抗告対象性
1. 室内撮影＝五官で感知＝検証（218条1項）→ 原則検証令状要
2. 【論点】無令状撮影の許容範囲 → 証拠価値保全・執行状況記録の2類型のみ
   - あてはめ：腕時計は被疑事実と無関係 → いずれにも当たらず → 無令状検証で違法
3. 【論点】検証は「押収に関する処分」か → 文言説（限定列挙） → 該当せず
   - あてはめ：補足意見（実質的差押え）も腕時計の外形撮影ゆえ射程外
- 結論：違法だが対象外 ＝ 準抗告は認められない（ネガの廃棄・返還請求不可）

- 【争いのない要件】論点にならず、あっさり認定する要件
  - P：令状発付・場所の記載・注射器は令状記載物＝争いなしを一言で通す。詰まる所だけ論点として彫る。
- 【効く事実】「令状効力」のあてはめで使う事実
  - 効力肯定 → 「執行中に」配達／「甲がこれを受領」＝被処分者の管理下／差押対象物 → 令状に「注射器」明記／実力行使 → 甲が開披を「拒んだ」のを排した取り上げ＝必要な処分。
- 【規範の要点】2類型の規範
  - 無令状の写真撮影が許されるのは ①証拠価値の保全 と ②執行状況の記録 の2類型のみ（222Ⅰ・111Ⅰの必要な処分）。腕時計は被疑事実と無関係でどちらにも当たらず違法。もっとも撮影＝検証で「押収に関する処分」でないから、準抗告の対象にはならない。
- 【まぎらわしい選択肢・論点】別件捜索・差押えの可否／所持品検査の限界
- 【まぎらわしい選択肢・結論】注射器の差押えは違法 準抗告認容／写真撮影は準抗告の対象
- 【まぎらわしい選択肢・規範】呈示時点限定説／実質説（実質的差押え）
- 【まぎらわしい選択肢・事実】捜査機関が代わって受領／文書内容の逐一撮影

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

総論＝警察官だから430条2項、①違法か②対象たる処分か。P＝執行中に配達され甲が受領＝管理下で令状効力及ぶ→適法→準抗告不可（返還請求不可）。Q＝室内撮影は検証、2類型外で違法、でも検証は「押収に関する処分」でない→対象外→準抗告不可（ネガ廃棄・返還請求不可）。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 室内の写真撮影が「検証」＝強制処分に当たり、原則として検証令状を要すると解される理由を述べよ。
  - 模範解答：室内等の撮影は、高度の要保護性が認められるプライバシー（憲13参照）を侵害し、相手方に反対意思形成の機会を与えないから強制処分に当たる。そして五官の作用で対象の性質・形状を感知・記録するものだから、法的性質は「検証」であり検証令状（218Ⅰ）を要する（京都府学連事件＝みだりに撮影されない自由の延長）。
- **［規範クイズ 2/3］** 捜索差押許可状の効力が「執行中に搬入され被処分者が管理するに至った物」にも及ぶことを基礎づける規範（趣旨＋理由）を述べよ。
  - 模範解答：219条1項が「捜索すべき場所」の記載を要求した趣旨は住居の不可侵（憲35Ⅰ）の保障にある。とすれば、執行中に捜索場所へ搬入され被処分者が管理するに至った物を捜索しても新たな住居権侵害を生じない。加えて執行の時点には幅があり、令状呈示に効力を時点で限定する機能はない。よって当該物にも令状の効力が及ぶ。
- **［規範クイズ 3/3］** 準抗告（430条）の対象たる処分を列挙し、検証がこれに含まれないことを述べよ。
  - 模範解答：①39条3項の処分（接見交通の日時等の指定）②押収（差押え・領置等）③押収物の還付に関する処分。これに加えて、令和7年法律第39号（2026年5月21日施行）により④電磁的記録提供命令⑤218条3項の命令（秘密保持命令）⑥複写に関する処分が明記された。対象はこれらに限定列挙され、検証は含まれない。だから検証たる写真撮影は準抗告の対象外となる。

## 4. ○×クイズ（全9問・1問目から最後まで全部出す）

- **［○×クイズ 1/9］** 準抗告の対象となる処分は刑訴法430条に列挙されており、捜査機関のあらゆる違法な処分が当然に準抗告の対象となるわけではない。
  - 正解：○（正しい）
  - 理由：430条は対象を「39条3項の処分・押収・押収物の還付・電磁的記録提供命令等に関する処分」に限定列挙する。だから処分を棚卸ししたら、各処分が①違法かだけでなく、②そもそも対象に当たるかも必ず確かめる。この二段構えが本問の骨格。
- **［○×クイズ 2/9］** 写真撮影のように五官の作用で対象の性質・形状を感知・記録する処分は、物の占有を強制的に取得する差押えと同じく「押収」に分類される。
  - 正解：×（誤り）
  - 理由：五官の作用で対象を感知・記録する処分は「検証」であり、物の占有を取得する「差押え（押収）」とは別類型。写真撮影は検証にあたる。両者の区別は準抗告の対象性（押収＝対象／検証＝対象外）に直結するので、性質決定を飛ばさない。
- **［○×クイズ 3/9］** 司法警察職員のした押収に関する処分に対して準抗告を申し立てる場合の根拠条文は、刑訴法430条1項である。
  - 正解：×（誤り）
  - 理由：司法警察職員の処分は430条2項が根拠。1項は検察官・検察事務官の処分。本問のP・Qは警察官（司法警察職員）だから2項。冒頭で根拠を2項と特定できるかが出だしの分かれ目。
- **［○×クイズ 4/9］** 捜索差押許可状の効力は、令状呈示の時点で捜索場所に存在した物に限られ、執行中に配達され被処分者が受領した物には及ばない。
  - 正解：×（誤り）
  - 理由：令状の効力は呈示時点で固定されない。執行中に捜索場所へ搬入され被処分者が管理するに至った物にも効力が及ぶ（最決平19.2.8）。場所の記載の趣旨は住居の不可侵の保障であり、被処分者の管理下に入った物の捜索は新たな住居権侵害を生じないからである。
- **［○×クイズ 5/9］** 捜索差押えの執行に際し、被処分者が開披を拒む物を実力で取り上げて開ける行為は、捜索の実効性確保に必要かつ相当な限度で「必要な処分」（222条1項・111条1項）として許容される。
  - 正解：○（正しい）
  - 理由：111条1項は「錠を外し、封を開き、その他必要な処分」を認め、222条1項が捜査に準用する。実力による開披・取り上げも、捜索の実効性確保に必要かつ相当な範囲であれば許容される。本問でPが甲の拒否を排して取り上げた点も、この必要な処分で正当化できる。
- **［○×クイズ 6/9］** 捜索差押えに際した無令状の写真撮影が許されるのは、差押物の証拠価値を保全する場合と、手続の適法性担保のためその執行状況を記録する場合に限られる。
  - 正解：○（正しい）
  - 理由：無令状撮影が付随処分（必要な処分）として許されるのは、証拠価値保全と執行状況記録の2類型に限られる。これを超えて差押対象物でない物件を撮影すれば無令状検証として違法。本問の腕時計は被疑事実と無関係でどちらにも当たらない。
- **［○×クイズ 7/9］** 検証としての性質を有する写真撮影は、刑訴法430条の準抗告の対象となる「押収に関する処分」に当たる。
  - 正解：×（誤り）
  - 理由：写真撮影は検証としての性質を有するから、「押収に関する処分」には当たらない（最決平2.6.27）。したがってネガ・写真の廃棄・返還を求める準抗告は不適法。違法かどうかとは別に、そもそも準抗告の土俵に乗らない。
- **［○×クイズ 8/9］** 捜査機関の処分が違法であっても、それが準抗告の対象たる処分に当たらない場合には、準抗告によってその是正を求めることはできない。
  - 正解：○（正しい）
  - 理由：準抗告が認められるには①処分が違法であること＋②対象たる処分に当たることの双方が必要。検証たる違法な写真撮影のように、②を欠けば違法でも準抗告は認められず、救済は証拠排除・国家賠償など別ルートによる。
- **［○×クイズ 9/9］** 差押対象物以外の文書の内容を逐一撮影し、実質的にみて当該文書を差し押さえたのと同視できる場合には、その写真撮影を「押収に関する処分」として準抗告の対象とする余地がある。
  - 正解：○（正しい）
  - 理由：最決平2.6.27の補足意見が示す考え方。文書内容を逐一撮影する行為は、実質的に差押えと同視でき「押収に関する処分」として対象になる余地がある。もっとも本問は腕時計の外形撮影にとどまり射程外で、補足意見によっても準抗告は認められない。
