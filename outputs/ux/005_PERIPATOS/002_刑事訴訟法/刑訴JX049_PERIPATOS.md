- 【争いのない要件】論点にならず、あっさり認定する要件
  - 調書①の「自白」該当・署名押印・伝聞例外の外形などは争いが薄ければ一言で通す。争点は任意性の判断枠組み・派生証拠の処理・特信情況の3点に集中する。
- 【効く事実】「自白法則」のあてはめで使う事実
  - 虚偽排除 → 実在しないEの供述をでっち上げ「間違いない」と告知（偽計）＋「自供すれば内通を表沙汰にしない」（約束）＝迎合して虚偽自白のおそれ。人権擁護 → 「組長甲が知ったら黙っていない」（脅迫）＝身の危険を感じ供述せざるを得ない＝供述の自由の制約。
- 【規範の要点】人権擁護の規範
  - 証拠物には虚偽のおそれがない（物は嘘をつかない）ので虚偽排除では排除できない。もっとも人権擁護の観点からは、派生証拠まで排除しなければ自白強要の防止・黙秘権保障を全うできないから、319条1項の趣旨が及ぶ限度で証拠能力を否定できる → 本件拳銃も否定。前段の趣旨と論理一貫させるのが命。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 証拠能力の要件だから外部的付随的事情から判断する。本問は調書①から1日・接見なし＝先行自白の心理的影響が残存 → 検面供述をより信用すべき特別の事情なし＝特信情況を否定。札幌高判平18.8.31と整合。
- 【まぎらわしい選択肢・論点】違法収集証拠排除法則の適用／補強法則（319条2項）の要否／共謀共同正犯の成否
- 【まぎらわしい選択肢・結論】証拠能力肯定／違法だが証拠能力は認められる
- 【まぎらわしい選択肢・規範】違法排除説一本／絶対的特信情況
- 【まぎらわしい選択肢・事実】黙秘権告知あり／署名押印なし

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

調書①＝趣旨は虚偽排除＋人権擁護、偽計・約束で虚偽自白のおそれ、脅迫で供述の自由制約、319条1項で否定。拳銃＝物は嘘つかない→虚偽排除は無理、人権擁護で派生証拠も否定。調書②＝乙との関係で321条1項2号後段、①署名押印②相反○、③特信情況＝1日・接見なしで影響残存→否定。

## 3. 規範クイズ（全5問・1問目から最後まで全部出す）

- **［規範クイズ 1/5］** 自白法則（319条1項）の趣旨と、それに応じた任意性の判断基準を述べよ（任意性説）。
  - 模範解答：趣旨＝①虚偽自白排除（誤判の防止）②人権擁護（黙秘権を中心とする供述の自由の保障）。基準＝①虚偽自白誘発の類型的危険の高い状況下でなされたか、②供述の自由に対する制約のある状況下でなされたか、で任意性を判断する。
- **［規範クイズ 2/5］** 偽計による自白について任意性を否定した判例（最大判昭45.11.25）の規範のコアを述べよ。
  - 模範解答：「偽計によって被疑者が心理的強制を受け、その結果虚偽の自白が誘発されるおそれのある場合には、その自白は任意性に疑いがあるものとして証拠能力を否定すべきである」。本問の実在しないEの供述の告知に直接及ぶ。
- **［規範クイズ 3/5］** 捜査官が「起訴猶予にする」等の利益を約束して得た自白の証拠能力について、判例（最判昭41.7.1）はどう扱ったか、規範を述べよ。
  - 模範解答：利益供与の約束（利益誘導）による自白は、被疑者が迎合して虚偽の自白をする心理状況を生むため、任意性に疑いがあるとして証拠能力を否定した。本問の「内通を表沙汰にしない」との約束に射程が及ぶ。
- **［規範クイズ 4/5］** 不任意自白に基づいて発見された派生証拠（物証）を排除するための、①人権擁護説 ②違法排除説 ③関連性構成 の各筋道を述べよ。
  - 模範解答：①人権擁護＝派生証拠まで排除しなければ自白強要防止・黙秘権保障を全うできないから319条1項の趣旨が及ぶ限度で否定。②違法排除＝端的に毒樹の果実として排除（最もすっきり・ただし判例＝虚偽排除ベースと目され弱み）。③関連性構成＝自白の内容を前提としてのみ要証事実との関連性が生じる場合、自白排除に連動して自然的関連性を否定。
- **［規範クイズ 5/5］** 先行する不任意自白の影響下でなされた反復自白（後の検面調書）につき、相対的特信情況（321条1項2号後段）をどう判断するか、外部的事情に即して述べよ。
  - 模範解答：先行自白から時間的に近接し（本問は1日）、弁護人との接見等の遮断措置がないときは、先行自白の心理的影響（虚偽自白誘発・供述の自由侵害のおそれ）が残存した状況でなされたといえる。このような外部的事情の下では、検面供述の方をより信用すべき特別の事情は認められず、相対的特信情況を否定する（札幌高判平18.8.31と整合）。

## 4. ○×クイズ（全8問・1問目から最後まで全部出す）

- **［○×クイズ 1/8］** 同一人の供述録取書でも、その供述者自身に対する関係で用いるなら刑訴322条が、共同被告人など他の被告人に対する関係で用いるなら321条が適用される。
  - 正解：○（正しい）
  - 理由：供述証拠は「誰の供述を・誰に対する関係で」使うかで根拠条文が変わる。自分自身に対して使えば322条（不利益事実の承認・特信情況）、相被告人など「被告人以外の者」に対して使えば321条（伝聞例外）。本問の調書②は乙との関係だから321条で処理する。まずこの仕分けが出発点。
- **［○×クイズ 2/8］** 自白法則（319条1項）は、自白の内容が客観的事実に反して虚偽であることが証明された場合に限り、その自白を証拠から排除する法則である。
  - 正解：×（誤り）
  - 理由：自白法則は任意性（採取の過程）を問う法則で、内容が真実か否かは要件ではない。「任意にされたものでない疑いのある自白」を、自白の真偽を確かめるまでもなく類型的に排除する（誤判防止＝虚偽排除、供述の自由＝人権擁護）。内容の真実性が証明されれば排除しない、というのは誤り。
- **［○×クイズ 3/8］** 不任意自白に基づいて発見された派生証拠や、その後に反復された自白の証拠能力は、先行する自白の任意性の欠如がどこまで波及するかという観点から判断される。
  - 正解：○（正しい）
  - 理由：先行自白の不任意性は、それを前提に得られた物証（派生証拠）や、影響下でなされた後続自白（反復自白）へと波及しうる。だからこそ採る自白法則の趣旨を一つ決め、派生証拠・反復自白まで同じ趣旨で一貫させることが要になる。趣旨がぶれると連鎖の処理が矛盾する。
- **［○×クイズ 4/8］** 被疑者に黙秘権（供述拒否権）が告知されていれば、その後に取調官が偽計や脅迫を用いて自白を得たとしても、告知があった以上その自白の任意性に疑いは生じない。
  - 正解：×（誤り）
  - 理由：黙秘権告知（198条2項）は任意性を担保する一事情にすぎず、告知後でも偽計・約束・脅迫があれば任意性は否定されうる。本問も告知後にKが偽計等を用いており、告知の存在は結論を左右しない。「告知さえあれば任意」は誤り。
- **［○×クイズ 5/8］** 取調官が、実際には存在しない者の供述であるかのように装って虚偽の情報を告げ、被疑者を錯誤に陥らせて自白させた場合、その自白は任意性に疑いがあるものとして証拠能力を否定されうる。
  - 正解：○（正しい）
  - 理由：これが偽計による自白で、最大判昭45.11.25の射程内。虚偽の内容の告知で被疑者が錯誤に陥り、虚偽自白へ誘導される類型的危険が高いから、虚偽排除の観点から任意性に疑いが生じる。本問のKの「実在しないEの供述」の告知がまさにこれ。
- **［○×クイズ 6/8］** 自白法則の趣旨を虚偽排除説（虚偽自白による誤判の防止）のみに求める立場からは、不任意自白に基づいて発見された証拠物（物証）も、当然にその証拠能力が否定される。
  - 正解：×（誤り）
  - 理由：物証には虚偽のおそれがない（物は嘘をつかない）から、虚偽排除説の論理では派生証拠を排除できない。排除するには人権擁護（黙秘権保障の徹底）や違法排除（毒樹の果実）、あるいは自白の内容を前提としてのみ関連性が生じる場合に自然的関連性を否定する関連性構成を用いる。虚偽排除「だけ」で当然否定は誤り。
- **［○×クイズ 7/8］** 共同被告人であっても、他の被告人にとっては「被告人以外の者」に当たるから、その者の供述録取書には刑訴321条1項が適用される。
  - 正解：○（正しい）
  - 理由：共同被告人（相被告人）は、当該被告人自身ではない以上「被告人以外の者」であり、その供述録取書は321条1項の伝聞例外で処理する（最決昭27.12.11）。本問の調書②を乙との関係で使う場面がこれ。自分（丙）との関係なら322条だから、取り違えないこと。
- **［○×クイズ 8/8］** 刑訴321条1項2号後段の相対的特信情況の有無は、検面供述と公判供述の内容自体を比較し、どちらが真実らしいかを直接判断して決めるのが原則である。
  - 正解：×（誤り）
  - 理由：特信情況は証拠能力の要件だから、供述がなされた外部的付随的事情（供述時の状況・取調べの態様・時間的近接・接見の有無等）から判断するのが原則。供述内容そのものの真偽比較で決めるのではない（ただし外部的事情を判断する資料として内容を斟酌することは許される）。本問は「調書①から1日・接見なし＝影響残存」という外部的事情で特信情況を否定する。
