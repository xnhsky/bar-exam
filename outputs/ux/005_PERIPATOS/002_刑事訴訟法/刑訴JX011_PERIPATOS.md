### 骨子（3項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　総論 ― 一罪一逮捕一勾留の原則と「一罪」

- 見出しの補足（結論を含む。項目の終わりに読む）：論点1
1. 保釈＝執行停止 → 勾留は観念的に継続／α・βは起訴された一罪の一部
2. 明文なし → 【論点】原則の根拠づけ（規範：逮捕・勾留一回性＋203〜208条の潜脱防止）
3. 【論点】「一罪」の判断基準 → 実体法上一罪（刑罰権は実体法上一罪に一個）
   - あてはめ：常習特殊窃盗＝包括一罪 → 本件・α・βは同一の一罪の一部＝原則の射程内
- 結論：一見、α・βでの重複逮捕・勾留は 原則に反する（例外は論点2）

#### 第2　例外 ― 同時処理の可能性

- 見出しの補足（結論を含む。項目の終わりに読む）：論点2
1. 原則を読み換え：捜査機関に一罪の同時処理を義務づけるもの
2. 【論点】例外の定立 → 同時処理が現実的・物理的に不能なら例外的に一部の逮捕・勾留可（法は不可能を強いない）
   - あてはめ：潜在的可能型は 不当な蒸し返しに当たらない限度で例外（多数説）
- 結論：同時処理不能なら例外肯定

#### 第3　あてはめ ― α・βの対比

1. α → 保釈後＝起訴時に不存在＝およそ同時処理不能 → 逮捕・勾留できる
2. β → 起訴前に発生＝潜在的に同時処理可能／同一県内・同種 → 逮捕・勾留できない（＝両論可）
   - あてはめ：「同一県内・同種というだけで同時処理可能と断ずるのは相当でない」→ 逆の結論（β許容）も可

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】『常習特殊窃盗（盗犯等防止法2条）で一括起訴』 → 実体法上一罪＝包括一罪（原則の射程）
- 【拾う事実】『保釈を許可された』 → 勾留は執行停止で継続（重複の前提）
- 【拾う事実】『α＝保釈後の犯行』 → 起訴時に不存在＝同時処理不能
- 【拾う事実】『β＝令和2年12月19日発生』 → 起訴前＝潜在的に同時処理可能
- 【拾う事実】『β＝同一K県内・同種手口』 → 現実の同時処理可能性の評価材料
- 【事案の整理】保釈≠釈放
  - 保釈は勾留の執行を停止する裁判・執行にすぎず、勾留自体は観念的に継続している（89条）。だからα・βで重ねて逮捕・勾留すれば、同一の一罪について「重複」した身柄拘束が生じる、という前提に立てる。
- 【ポイント】理由づけの筋
  - 「一罪」基準の理由づけは〈手続は刑罰権の存否を明らかにするため → 刑罰権は実体法上一罪に一個 → 手続も一個〉が一番きれい。常習性という一個の人格態度に基づく包括一罪だという理解が、論点2の「例外」の必要性へ自然につながる。
- 【効く事実】「例外を同時処理の可能性で割る（＋α＝不能型）」のあてはめで使う事実
  - α → 保釈後（起訴後）の犯行・起訴時に存在せず＝およそ同時処理不能／β → 起訴前（R2/12/19）に発生済み＝潜在的には同時処理可能／β → 同一K県内・同種手口。
- 【規範の要点】多数説の規範
  - 物理的に不可能でなくても、捜査機関がどれほど尽力しても発覚しえなかったような場合は、不当な蒸し返しに当たらない限度でなお例外を認めてよい（多数説）。他方、同時処理の機会があった以上は分割を認めない有力説もある。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 両者は同じ逮捕・勾留一回性・203〜208条の潜脱防止に由来するが、同時か異時かで規律が違う。本問で「再逮捕・再勾留」を持ち出すと場面を取り違える。先行拘束が継続中なら一罪一逮捕一勾留、終了・釈放後なら再逮捕・再勾留と切り分ける。
- 【まぎらわしい選択肢・論点】再逮捕・再勾留の禁止の可否／別件逮捕・勾留の適法性／公訴事実の同一性
- 【まぎらわしい選択肢・結論】α・βとも逮捕・勾留できる／α・βとも逮捕・勾留できない
- 【まぎらわしい選択肢・規範】訴因基準説／実体喪失説
- 【まぎらわしい選択肢・事実】別罪（数罪）／勾留は消滅している

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

総論＝明文なし→一回性＋203〜208潜脱防止で原則、「一罪」＝実体法上一罪（刑罰権一個）、常習特殊窃盗＝包括一罪。例外＝原則は同時処理義務、不能なら例外。α＝保釈後で不能＝可。β＝起訴前で潜在的可能、同一県内・同種を評価して不可（両論可）。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 明文なき一罪一逮捕一勾留の原則の根拠を、答案の規範として述べよ。
  - 模範解答：刑訴法は逮捕・勾留につき厳格な時間的制限（203条〜208条）を設け、身柄拘束を必要最小限にとどめる趣旨である。同一被疑事実について逮捕・勾留を反覆すればこの趣旨が潜脱されるから、同一被疑事実については逮捕・勾留を原則1回に限る（逮捕・勾留一回性の原則）。ここから一罪一逮捕一勾留の原則が導かれる。
- **［規範クイズ 2/3］** 一罪一逮捕一勾留の原則の例外を基礎づける規範（同時処理の可能性）を述べよ。
  - 模範解答：一罪一逮捕一勾留の原則は、捜査機関に一罪の関係にある事実を同時に処理させる義務を負わせるものである。しかし同時処理が現実的・物理的に不可能な場合にまで重ねての逮捕・勾留を否定すると、後に判明した事実の罪証隠滅・逃亡を防止する手段を欠く。法は不可能を強いないから、同時処理が不可能な場合には、例外的に一罪の一部について逮捕・勾留が認められる。
- **［規範クイズ 3/3］** 潜在的には同時処理が可能だった事実（β型）について、多数説がなお例外を認める枠組みを述べよ。
  - 模範解答：物理的には同時処理が不可能でなかった場合でも、捜査機関が尽力しても発覚しえなかったような事実については、不当な身柄拘束の蒸し返しに当たらない限度で、なお例外を認めてよい（多数説）。これは、捜査を尽くしても発覚しえなかった事実にまで原則を貫くのは酷だからである。同時処理の機会があった以上は分割を認めるべきでないとする有力説（厳格説）と対立し、βのあてはめは現実の同時処理の可能性の評価により結論が分かれる。

（規範クイズはここまで＝全3問。最後の3問目まで出したら「規範クイズ、全3問クリア！」と言って次へ）

## 4. ○×クイズ（全7問・1問目から最後まで全部出す）

- **［○×クイズ 1/7］** 一罪一逮捕一勾留の原則とは、同一の被疑事実について、時を同じくして2個以上の逮捕・勾留をすることを禁じる原則（重複逮捕・重複勾留の禁止）である。
  - 正解：○（正しい）
  - 理由：同原則は、同一被疑事実について同時に二重の身柄拘束を行うことを禁じる（重複逮捕・重複勾留の禁止）。厳格な身柄拘束期間の潜脱を防ぐためであり、時をおいて反覆する場面（釈放後の再逮捕等）を規律する再逮捕・再勾留の禁止とは、同時か異時かで場面を区別する。
- **［○×クイズ 2/7］** 一罪一逮捕一勾留の原則は、刑事訴訟法上に明文の根拠規定が置かれており、その要件も条文上明示されている。
  - 正解：×（誤り）
  - 理由：同原則には明文の根拠規定はなく、解釈上の原則である。だからこそ、逮捕・勾留一回性の原則や厳格な身柄拘束期間（203条〜208条）の潜脱防止という実質的根拠から基礎づける作業が答案で必須になる。
- **［○×クイズ 3/7］** 一罪一逮捕一勾留の原則の適用単位である「一罪」を実体法上の罪数で判断するのは、手続は刑罰権の存否を明らかにするためのものであり、刑罰権が実体法上一罪に対して一個発生することを理由とする。
  - 正解：○（正しい）
  - 理由：実体法上一罪説（通説）の理由づけ。〈手続は刑罰権を明らかにする → 刑罰権は実体法上一罪に一個発生 → だから手続（逮捕・勾留）も一個であるべき〉という連鎖で導く。基準としての明確性からも妥当。
- **［○×クイズ 4/7］** 常習特殊窃盗罪（盗犯等防止法2条）は、常習性という行為者の属性に基づく包括一罪であり、これを構成する複数の窃盗は、全体として実体法上一罪として扱われる。
  - 正解：○（正しい）
  - 理由：常習特殊窃盗は常習性という一個の人格態度に基づく包括一罪で、個々の窃盗はバラバラに見えても一個の刑罰権に服する。だから本件・α・βは全部「同じ一罪」であり、原則の射程内に入る。
- **［○×クイズ 5/7］** 一罪の関係にある数個の事実について同時に処理することが客観的に不可能であった場合であっても、既に一部で身柄拘束がされている以上、他の事実について重ねて逮捕・勾留することは、一罪一逮捕一勾留の原則に反し、常に許されない。
  - 正解：×（誤り）
  - 理由：同時処理が客観的に不可能だった場合は、原則の例外が認められ、重ねての逮捕・勾留が許される（富山地決昭54.7.26）。原則は同時処理義務であり、不能な場合にまで貫けば後発事実の証拠隠滅・逃亡を防げなくなるからである。
- **［○×クイズ 6/7］** 起訴前に既に発生していた事実（潜在的可能型）については、物理的には同時処理が可能だった以上、およそ例外は認められず、常に重ねての逮捕・勾留は許されない。
  - 正解：×（誤り）
  - 理由：潜在的可能型は争いのある領域で、「常に否定」ではない。多数説は、捜査を尽くしても発覚しえなかった場合には不当な蒸し返しに当たらない限度で例外を認める。結論は事実評価次第で両様ありうる（＝断定は誤り）。
- **［○×クイズ 7/7］** 同一被疑事実について、先行の逮捕・勾留が終了し釈放された後に再び逮捕・勾留する場面を規律するのは、一罪一逮捕一勾留の原則ではなく、再逮捕・再勾留の禁止の法理である。
  - 正解：○（正しい）
  - 理由：一罪一逮捕一勾留の原則は同時に2個の身柄拘束を行う場面（重複）を、再逮捕・再勾留の禁止は時をおいて反覆する場面（蒸し返し）を規律する。本問は勾留が継続中の同時的重複なので前者。両者は根拠（一回性・潜脱防止）を共有する。

（○×クイズはここまで＝全7問。最後の7問目まで出したら「○×クイズ、全7問クリア！」と言って復習へ）
