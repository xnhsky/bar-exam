### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「任意にされたものでない疑のある自白」 → 立証対象＝自白の任意性（319条1項の文言）
- 【拾う事実】『Pが「Xは正直なやつで、素直に犯行を自白した…」』 → 備忘録の中身＝P自身の発言（再伝聞）
- 【拾う事実】「心覚えの手帳（備忘録）」／「メモ」 → 323条3号の正確性の類型的保障がない
- 【拾う事実】『事件時Yと居酒屋で飲酒＝アリバイ』 → 犯人性の不存在を推認する間接事実
- 【拾う事実】『Q・Yとも公判で証言に支障なし』 → 供述不能（321条1項3号）を充たさない
- 【拾う事実】『Q備忘録・Yメモとも不同意』 → 326条の同意による救済もない
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 供述不能＝Q・Yとも証言可能で不充足＝一言で否定／同意＝両者とも不同意で326条は使えない＝一言で締める。要件は必ず通すが、争いが無ければ一文でよい。
- 【効く事実】あてはめで使う事実
  - 任意性＝「任意にされたものでない疑のある自白」（319条1項の文言）を立証する重大事項／備忘録＝「心覚えのため書き留めた手帳」で正確性の類型的保障なし／供述不能＝Q・Yとも公判で証言に支障なし／再伝聞＝記載内容はP自身の発言。
- 【規範の要点】通説の規範
  - アリバイは犯人性の不存在を推認させる間接事実であり、犯罪事実の認定を左右するから、犯罪事実と同様に厳格な証明を要する。被告人に有利な事実でも、317条は有利・不利で様式を使い分けていないから結論は変わらない。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり

- 【まぎらわしい選択肢・論点】違法収集証拠排除法則の適用／自白の補強法則の要否／自然的関連性の有無
- 【まぎらわしい選択肢・結論】取り調べることができる／証拠能力あり → 取調べ可
- 【まぎらわしい選択肢・規範】狭義説／精密司法の原則
- 【まぎらわしい選択肢・事実】絶対的特信情況あり／供述不能

## 3. 規範クイズ（3問）

- **Q04［規範］** 自白の任意性の証明の様式について、判例と有力説の結論をそれぞれ述べよ。
  - 模範解答：判例＝任意性は訴訟法上の事実だから自由な証明で足りる（最判昭28.2.12）。有力説＝自白は犯罪事実認定に決定的で、その任意性は誤判防止の要だから犯罪事実に準じ厳格な証明を要する。自由な証明なら伝聞法則の適用が無く取調べ可、厳格な証明なら伝聞法則が適用され例外の検討へ。
- **Q05［規範］** 備忘録・メモが323条3号の「特に信用すべき情況の下に作成された書面」に当たらないとされる理由を、規範とあてはめで述べよ。
  - 模範解答：規範＝323条3号の「書面」は、1号・2号の戸籍謄本・商業帳簿に準じ、作成及び内容の正確性が類型的に信頼できる書面をいう（最判昭31.3.27）。あてはめ＝備忘録・メモは単に心覚えのため書き留めた手帳にすぎず、その正確性の類型的保障を欠くから3号の書面に当たらない。
- **Q06［規範］** アリバイ（現場不在）が厳格な証明を要する理由と、「被告人に有利な事実だから自由な証明でよい」との反対説をどう斥けるかを述べよ。
  - 模範解答：理由＝アリバイは犯人性の不存在を推認させる間接事実で、犯罪事実そのものの認定を左右するから犯罪事実と同様に厳格な証明を要する。反対説の排斥＝317条は証明の様式を事実の有利・不利で使い分けておらず、有利な事実だから自由な証明でよいとする見解は条文上の根拠を欠く。

## 4. ○×クイズ（9問）

- **Q07［○×］** 証拠を取り調べられるかを検討するには、まずその書面が「何を立証するための証拠か」（立証対象＝要証事実）を確定する必要がある。
  - 正解：○（正しい）
  - 理由：立証対象（要証事実）が「犯罪事実」か「訴訟法上の事実」かで要求される証明の様式（厳格な証明／自由な証明）が変わるから、立証対象の特定が出発点となる。伝聞法則の適用の有無という証拠能力の要件判断も、この立証対象の確定を前提に決まる。
- **Q08［○×］** 訴訟条件の存否や自白の任意性のように、犯罪事実そのものではなく手続の適否にかかわる事実を「訴訟法上の事実」といい、原則として自由な証明で足りる。
  - 正解：○（正しい）
  - 理由：訴訟法上の事実は犯罪事実そのものではなく、その認定は裁判所の合理的裁量に委ねてよいから、原則として自由な証明で足りるとされる。もっとも自白の任意性はこの原則の例外として厳格な証明を要しないかが本問の争点になる。
- **Q09［○×］** 立証対象の性質が異なる複数の証拠でも、「証明の様式 → 伝聞法則の適用 → 伝聞例外の可否」という共通の思考枠組みで順に処理できる。
  - 正解：○（正しい）
  - 理由：まず厳格な証明を要するかを決め、要するなら伝聞法則（320条1項）が適用され、伝聞例外（323条・321条1項3号等）の充足を検討する。この共通枠組みを持てば、立証対象が違っても同じ手順で流せる。
- **Q10［○×］** ある事実について自由な証明で足りるとされる場合、その証明にはそもそも伝聞法則（320条1項）の適用がない。
  - 正解：○（正しい）
  - 理由：伝聞法則は証拠能力の制約であり、厳格な証明（証拠能力＋適法な証拠調べ）を要する事実の認定にのみ働く。自由な証明で足りるなら証拠能力の制約が及ばず、伝聞例外を論ずるまでもなく取調べが許される。だからこそ「厳格か自由か」を先に決める意味がある。
- **Q11［○×］** 書面自体の伝聞性を伝聞例外で除去できれば、その書面に記載された内容が更に他人の供述であっても、その真実性を問題とする限り、もはや伝聞の問題は残らない。
  - 正解：×（誤り）
  - 理由：書面に記載された供述内容が更に他人の供述である場合、その内容の真実性を要証事実とするときは、いわゆる再伝聞として供述部分についてなお伝聞性が残る。よって備忘録の伝聞性を仮に除去できても、記載されたP発言部分について別途伝聞例外の要件を充足しなければ証拠とできないから、再伝聞の処理を落とすと結論を誤る。
- **Q12［○×］** 単に心覚えのために書き留めた手帳・メモも、作成者の職務に関して継続的に記載されたものであれば、当然に323条3号の書面に当たる。
  - 正解：×（誤り）
  - 理由：323条3号は1号（戸籍謄本等）・2号（商業帳簿等）に準じ、作成・内容の正確性が類型的に信頼できる書面に限られる。心覚えの手帳は個人的な覚え書きにすぎず、たとえ職務に関連していても類型的な正確性保障を欠くから3号に当たらない（最判昭31.3.27）。
- **Q13［○×］** 犯罪事実の存否を推認させる間接事実は、犯罪事実そのものではないから、常に自由な証明で足りる。
  - 正解：×（誤り）
  - 理由：間接事実は犯罪事実そのものではないが、その積み重ねで犯罪事実（主要事実）を推認する以上、認定を左右する。よって犯罪事実と同様に厳格な証明を要する（通説）。アリバイもこの間接事実であり、自由な証明では足りない。
- **Q14［○×］** 相手方が証拠とすることに不同意の書面であっても、裁判所が相当と認めれば、326条1項により証拠能力が付与される。
  - 正解：×（誤り）
  - 理由：326条1項の同意は当事者の同意があることを要件とし、その上で情況の相当性が認められる場合に証拠能力を付与する。相手方が不同意である以上、相当性を問うまでもなく同条は適用されない。本問はQ備忘録＝弁護人不同意、Yメモ＝検察官不同意で、いずれも同意による救済はない。
- **Q15［○×］** 321条1項3号により被告人以外の者の供述書面を証拠とするには、供述者が死亡・所在不明等で公判において供述できないこと（供述不能）が必要である。
  - 正解：○（正しい）
  - 理由：321条1項3号は、供述不能（死亡・精神身体の故障・所在不明・国外）に加え、犯罪事実の証明に不可欠であること・絶対的特信情況を要件とする。本問はQ・Yとも公判で証言に支障がないから、供述不能の要件を欠き、この段階で3号は否定される。
