### 問題文（最初にゆっくり読み上げる）

甲は、器物損壊罪の現行犯人として警察官に逮捕された。器物損壊罪の被害者が告訴しない意向が固いため、同罪では勾留請求をしないことにしたが、甲に殺人の余罪が判明した。検察官は、この殺人罪を被疑事実として勾留請求できるか。被害者の告訴が得られ、器物損壊罪と併せて勾留請求する場合はどうか。なお、現行犯逮捕は適法であることを前提としなさい。また、器物損壊と殺人は別の機会に犯されていたこととする。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 甲、器物損壊罪の現行犯人として逮捕（適法）
- 器物損壊は親告罪・告訴なし → 同罪では勾留請求しない
- 甲に殺人の余罪が判明（器物損壊とは別の機会）
- 〔前段〕殺人罪を被疑事実として勾留請求できるか
- 〔後段〕告訴が得られ、器物損壊＋殺人を併せて勾留請求できるか

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】『器物損壊で逮捕・殺人で勾留請求』 → 逮捕の罪と勾留の罪がズレる＝逮捕前置主義の起点
- 【拾う事実】「別の機会に犯されていた」 → 事実の共通性なし＝別事件（殺人に前置なし）の決定打
- 【拾う事実】『「現行犯逮捕は適法」（前提固定）』 → 違法逮捕後の勾留・逮捕の違法の承継を出題者が遮断
- 【拾う事実】『告訴取得後に器物損壊＋殺人を併合請求』 → 後段＝付加してされた勾留請求の起点
- 【拾う事実】『器物損壊は親告罪・告訴なし』 → 当初は器物損壊で勾留請求しない事案設定の根拠
- 【事案の整理】逮捕と勾留の関係を掴む
  - 勾留請求は逮捕の先行を前提とする（207条1項「前三条の規定による」＝逮捕前置主義）。本問は逮捕された罪（器物損壊）と勾留請求する罪（殺人）がズレているのが論点の芽。ここに気付けば半分勝ち。
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 勾留の理由・必要性（実体的要件）は充足を前提と一言で宣言し脇に置く。根拠は「明文なし。もっとも207条1項が『前三条の規定による』と定める」で立ち上げる。
- 【規範の要点】この論点の規範
  - ①前置の判断単位＝事件単位（法構造との整合）。②同一「事件」＝二重の司法的抑制が及んでいると評価できる限度での、事実の共通性が認められる範囲（趣旨からの実質判断）。
- 【効く事実】効く事実（別事件の決定打）
  - 器物損壊と殺人は「別の機会」に犯された＝事実の共通性なし＝別事件 → 殺人には逮捕が前置されていない。人単位説の言い分（無用な逮捕反復の回避）は一度受けて法構造との不整合で排斥。
- 【規範の要点】この論点の規範
  - 原則＝殺人に前置なく違法。例外＝殺人で逮捕を先行させるとかえって長期の身柄拘束を招き被疑者に不利益。そこで逮捕前置主義を一部修正し、勾留事実の一部（器物損壊）に逮捕が前置されていれば前置主義の要請は満たされると解する。
- 【効く事実】効く事実（許容↑）
  - 器物損壊で勾留を受ける甲に殺人で逮捕を先行させるとかえって長期拘束／短期の逮捕期間内に殺人の嫌疑が消えても器物損壊で拘束継続＝早期釈放の途もない → 逮捕先行はかえって不利益。留保＝各被疑事実に勾留の理由（60条）・必要性（87条）。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 前段で「不必要な身柄拘束の回避」を違法の根拠に、後段で同じ趣旨を許容の根拠に使い分ける（趣旨の一貫運用）。横断すると、逮捕前置主義は違法逮捕に基づく勾留請求の可否とも地続きで、いずれも「不必要・不当な身柄拘束を司法審査で抑える」思想に立つと見える。
- 【まぎらわしい選択肢・論点】違法逮捕に基づく勾留請求の可否／別件逮捕・勾留の可否／逮捕の違法の承継
- 【まぎらわしい選択肢・結論】勾留請求を認容すべき／再逮捕・再勾留は許されない
- 【まぎらわしい選択肢・規範】人単位説／公訴事実の同一性説
- 【まぎらわしい選択肢・事実】逮捕の違法が重大／準現行犯の確保要件

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

前段＝明文なしだが207条1項＋不必要な身柄拘束回避で前置主義、判断単位は事件単位（法構造）、別の機会＝別事件＝殺人に前置なし＝違法・却下。後段＝殺人で逮捕先行はかえって長期拘束、一部（器物損壊）に前置あれば要請充足＝一部修正で許容、ただし各罪の勾留の理由・必要性が要る。

## 3. 規範クイズ（3問）

- **Q05［規範］** 明文がない中で逮捕前置主義を基礎づける根拠を、条文の文理と実質的根拠の二本立てで述べよ。
  - 模範解答：①条文の文理＝207条1項が「前三条の規定による勾留の請求」と定め、204〜206条が逮捕された被疑者の手続であることから、法は勾留に先立つ逮捕を要請していると解される。②実質的根拠＝身柄拘束の必要性が流動的な捜査初期に、比較的短期の逮捕を勾留に先行させ、再び裁判官の判断を経させることで、不必要な身柄拘束を回避する。
- **Q06［規範］** 前置の判断単位について事件単位説を採る論拠と、同一「事件」の判断基準を述べよ。
  - 模範解答：論拠＝逮捕・勾留の各規定（199・200・210・60・61・64条）が「犯罪事実」「被疑事実」等の文言で事件を単位に身柄拘束を規律する法構造に整合する。基準＝逮捕前置主義の趣旨に鑑み、二重の司法的抑制が及ぶ限度での、事実の共通性が認められる範囲を「事件」とする（趣旨実質判断説）。公訴事実の同一性説は公判段階の概念を捜査段階へ借用する点で当否に議論がある。
- **Q07［規範］** 付加してされた勾留請求が許容される根拠と、その留保（必要な要件）を述べよ。
  - 模範解答：根拠＝①付加される罪で逮捕を先行させるとかえって長期の身柄拘束を招き被疑者に不利益（短期の逮捕期間内に嫌疑が消えても他罪で拘束継続＝早期釈放の途もない）②逮捕前置主義の趣旨（不必要な身柄拘束の回避）に反しない③勾留事実の一部に逮捕が前置されていれば要請充足。留保＝各被疑事実について勾留の理由（60条）・必要性（87条）が認められること。

## 4. ○×クイズ（10問）

- **Q08［○×］** 被疑者を勾留するには、原則としてその被疑者が逮捕手続を経ていることを要する（逮捕前置主義）。
  - 正解：○（正しい）
  - 理由：被疑者勾留は逮捕を先行させることを前提とする。207条1項が「前三条の規定による勾留の請求」と定め、204〜206条が逮捕されている被疑者の手続であることから、法は勾留に先立つ逮捕を要請している（逮捕前置主義）。逮捕を経ない勾留は原則許されない。
- **Q09［○×］** 逮捕前置主義は、刑訴法に「勾留請求には逮捕を前置しなければならない」旨の直接の明文があり、207条1項がこれを正面から規定している。
  - 正解：×（誤り）
  - 理由：逮捕前置主義を正面から定めた明文は存在しない。207条1項が「前三条の規定による勾留の請求」と定め、204〜206条が逮捕を前提とすることが唯一の間接的な条文上の手がかりにとどまる。明文があると誤解すると論述が浅くなる。
- **Q10［○×］** 逮捕前置主義の実質的根拠は、身柄拘束の必要性が流動的な捜査の初期に、比較的短期の逮捕を勾留に先行させ、再び裁判官の判断を経させることで、不必要な身柄拘束を回避する点にある。
  - 正解：○（正しい）
  - 理由：逮捕（短期）と勾留（長期）を段階化し、各段階で裁判官の審査（令状審査・勾留質問）を二重に及ぼすことで、不必要な身柄拘束を早期に解消できる。この「不必要な身柄拘束の回避」という趣旨は、前段の違法の根拠にも、後段の許容の根拠にも一貫して効く物差しになる。
- **Q11［○×］** 逮捕・勾留に関する諸規定が「犯罪事実」「被疑事実」「公訴事実」等の文言を用いて事件を単位に身柄拘束を規律していることは、逮捕の前置の有無を事件を基準として判断すべきとする（事件単位説）論拠となる。
  - 正解：○（正しい）
  - 理由：199条・200条・210条・60条・61条・64条等は、いずれも「被疑事実」等を単位に身柄拘束を規律している。この法構造からすれば、逮捕の前置も人ではなく事件（被疑事実）を単位に判断すべきである（事件単位説）。人単位説はこの法構造と整合しない。
- **Q12［○×］** 逮捕の前置の有無を人を基準に判断する見解（人単位説）は、逮捕・勾留の各規定が事件を単位に身柄拘束を規律する法構造と整合的であり、実務・通説もこれを採用している。
  - 正解：×（誤り）
  - 理由：逆である。実務・通説は事件単位説であり、人単位説は法構造と整合しない点が批判される。人単位説の言い分（器物損壊で逮捕中の者に殺人で改めて逮捕手続を要求するのは無用な負担・直ちに勾留する方が留置期間分だけ拘束が短い）は一度受け止めたうえで、法構造との不整合を理由に排斥する二段構えが加点になる。
- **Q13［○×］** 別の機会に犯された二つの犯罪は、事実の共通性がなく同一「事件」とはいえないから、一方の罪で逮捕されていても、他方の罪については逮捕が前置されていないと評価される。
  - 正解：○（正しい）
  - 理由：事件単位説＋事実の共通性基準によれば、別の機会の犯罪は別事件であり、逮捕は事件ごとに前置を要する。本問の器物損壊（逮捕あり）と殺人（別の機会）は別事件だから、殺人には前置がなく、殺人単独の勾留請求は逮捕前置主義に反し違法となる。
- **Q14［○×］** 事件単位説によれば、器物損壊罪で逮捕中の甲について、殺人罪で改めて逮捕手続をとることなく、直ちに殺人罪を被疑事実として勾留請求することができる。
  - 正解：×（誤り）
  - 理由：それは人単位説の帰結である。事件単位説では、別の機会の殺人は器物損壊と別事件であり、殺人には逮捕が前置されていないから、殺人単独での勾留請求は逮捕前置主義に反し違法（却下）となる。判断単位で結論が真逆になる点が本問の急所。
- **Q15［○×］** 付加してされた勾留請求は、勾留請求の被疑事実の一部について逮捕が前置されていれば、被疑者に格別の不利益を生じない限り、逮捕前置主義を一部修正して許容される。
  - 正解：○（正しい）
  - 理由：一部の被疑事実に逮捕が前置されていれば、そこに他の被疑事実を付加しても身柄拘束の不利益は増えない。むしろ付加された罪で逮捕を先行させる方がかえって長期拘束を招く。逮捕前置主義の趣旨（不必要な身柄拘束の回避）に反しないから、一部修正して許容する。
- **Q16［○×］** 付加してされた勾留請求が許容される場合、逮捕が前置された被疑事実についてのみ勾留の理由・必要性があれば足り、付加された被疑事実についての勾留の理由・必要性は不要である。
  - 正解：×（誤り）
  - 理由：付加勾留を許容する場合でも、各被疑事実（器物損壊・殺人）それぞれについて勾留の理由（60条）・必要性（87条）が認められることを要する。付加される殺人について勾留の理由・必要性がなければ、その罪で身柄を拘束する正当化を欠く。
- **Q17［○×］** 逮捕前置主義の趣旨（不必要な身柄拘束の回避）は、前段では殺人単独の勾留請求を違法とする根拠に、後段では付加してされた勾留請求を許容する根拠に、いずれにも用いることができる。
  - 正解：○（正しい）
  - 理由：同一の趣旨を、前段では「殺人に逮捕を前置しないと不必要な身柄拘束を招く」→違法、後段では「殺人で逮捕を先行させる方がかえって長期拘束を招く」→許容、と使い分ける。趣旨を暗記でなく一貫して運用できていることを示せると、上位答案に評価される。
