- 【拾う事実】『恐喝未遂・嫌疑明白』 → (イ)逮捕の必要性・罪質の評価
- 【事案の整理】連鎖で見る
  - 手続問題は「先行処分が適法か → その違法が後行処分にどこまで波及するか」のドミノ。まずいちばん川上（現行犯逮捕）の適法性を先決問題として置くと、（ア）（イ）が枝分かれで見える。
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 現行犯逮捕は時間的接着性と明白性を各1〜2文で切り、準現行犯は各号不充足を一文で落とす。ここを厚く書きすぎない ── メインは（ア）の勾留請求の可否だから、前提は手早く「違法」に着地させる。
- 【規範の要点】この論点の規範
  - ①違法逮捕に引き続く勾留請求は原則却下（前置主義・違法捜査抑止／憲31・司法の信頼・429条1項2号反対解釈）。②もっとも軽微な違法は却下しない＝重大な違法がある場合に限り却下（京都地決昭44.11.5／富山地決昭54.7.26）。
- 【効く事実】効く事実（重大性の決定打）
  - 緊急逮捕（210条）の要件充足すら微妙／かつ逮捕状の請求すらしていない → 「軽微」とはいえず重大な違法。
- 【規範の要点】この論点の規範
  - 原則＝期間制限（203条以下）潜脱防止・人権保障から同一被疑事実の再逮捕・再勾留は禁止。例外＝違法逮捕が先行する以上要件を厳格に判断し、先行逮捕の違法の程度・逮捕の必要性・犯罪の重大性を勘案してやむを得ない事由があれば認めうる。
- 【効く事実】効く事実（やむを得ない事由↑）
  - 違法は緊急逮捕すべきを現行犯逮捕した形式的瑕疵にとどまる／一旦釈放して手続をやり直した（法無視の態度なし）／嫌疑は明白で逮捕の必要性も高い／恐喝未遂で罪質も悪くない → やむを得ない事由あり。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - （ア）で「重大な違法＝却下」と書いた同じ事案を、（イ）では「やり直し＝やむを得ない事由あり＝可」で締める。両小問で結論が分かれることを恐れない。横断すると、（ア）の原則却下は違法収集証拠排除法則と同じ「将来の違法捜査抑止・司法の廉潔性」の政策に立つと見える。
- 【まぎらわしい選択肢・論点】強制処分該当性／別件逮捕・勾留の可否／任意同行の限界
- 【まぎらわしい選択肢・結論】勾留請求を認容／再逮捕・再勾留は許されない
- 【まぎらわしい選択肢・規範】全部却下説／勾留可能説（違法は波及しない）
- 【まぎらわしい選択肢・事実】逮捕状の発付を受けている／準抗告が可能

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

前提＝約50分後・現認なし＝時間的接着性も明白性もなし＝逮捕違法。(ア)＝違法逮捕に引き続く勾留請求は原則却下＋重大な違法に限る、逮捕状すら請求なし＝重大＝却下。(イ)＝再逮捕は199条3項が予定、違法前置ゆえ厳格判断、一旦釈放しやり直し・嫌疑明白・罪質悪くない＝やむを得ない事由あり＝再逮捕再勾留可。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 現行犯逮捕（212条1項）が無令状で許される根拠と、そこから導かれる要件を述べよ。
  - 模範解答：根拠＝逮捕者にとって犯罪・犯人が明白で誤認逮捕のおそれが低く、かつ逮捕の緊急性が高いこと。要件＝①現行犯性又は時間的接着性 ②逮捕者において犯罪及び犯人が明白であること。「明白性を供述だけで基礎づけない」が本問の急所。
- **［規範クイズ 2/3］** 違法逮捕に引き続く勾留請求を原則却下と解する実質的根拠を3つ挙げよ。
  - 模範解答：①逮捕前置主義の趣旨（その「逮捕」は適法なものを想定）②将来の違法捜査抑止・適正手続（憲31）・司法に対する国民の信頼（違法収集証拠排除法則と同型の発想）③429条1項2号の反対解釈（逮捕に準抗告を認めない代わりに勾留審査で逮捕の違法を判断する前提）。最低1つ示せば足りるが、3点言えると論拠が厚い。
- **［規範クイズ 3/3］** 違法逮捕が先行する場合に例外的に再逮捕・再勾留を認める「やむを得ない事由」の判断要素を挙げよ。
  - 模範解答：①先行逮捕の違法の程度（形式的瑕疵か重大か・手続をやり直したか）②逮捕の必要性の程度（嫌疑の明白性等）③犯罪の重大性（罪質）。これらを総合し、やむを得ない事由があれば再逮捕・再勾留を認める。ごく軽微な犯罪では認めない場合もありうる。

（規範クイズはここまで＝全3問。最後の3問目まで出したら「規範クイズ、全3問クリア！」と言って次へ）

## 4. ○×クイズ（全10問・1問目から最後まで全部出す）

- **［○×クイズ 1/10］** 現行犯逮捕は、令状主義（憲法33条）の例外として、逮捕状によらず無令状で行うことが許される（刑訴法213条）。
  - 正解：○（正しい）
  - 理由：憲法33条は「現行犯として逮捕される場合を除いては」令状によると定め、現行犯逮捕を令状主義の明文の例外とする。刑訴法213条は「現行犯人は、何人でも、逮捕状なくしてこれを逮捕することができる」と規定する。無令状が許される以上、その要件（時間的接着性・明白性）を厳格に絞るのが出発点。
- **［○×クイズ 2/10］** 逮捕前置主義にいう「逮捕」は、適法な逮捕であると違法な逮捕であるとを問わず、およそ逮捕手続が現に先行してさえいれば足りる。
  - 正解：×（誤り）
  - 理由：逮捕前置主義は、短期の逮捕を勾留に先行させ裁判官の審査を経させて不必要な身柄拘束を避ける制度であり、その「逮捕」は適法なものを想定している。だからこそ違法逮捕に引き続く勾留請求の可否が問題になる。「逮捕が形式的に先行しさえすればよい」と読むと論点が消えてしまう。
- **［○×クイズ 3/10］** 勾留の理由及び必要性（207条1項・60条）が認められる以上、先行する逮捕手続が適法か否かを問わず、勾留請求は当然に認められる。
  - 正解：×（誤り）
  - 理由：勾留には実体的要件（理由・必要性）だけでなく手続的要件＝適法な逮捕の前置が必要。実体的要件を満たしても、先行逮捕に重大な違法があれば勾留請求は却下されうる。実体面の充足と手続面の適法性は別問題で、本問の争点は後者にある。
- **［○×クイズ 4/10］** 現行犯逮捕の要件である「犯罪及び犯人の明白性」は、逮捕者自身の現認によらず、被害者や目撃者の供述のみによっても常に充たされる。
  - 正解：×（誤り）
  - 理由：無令状逮捕が許されるのは誤認逮捕のおそれが低いからで、明白性は原則として逮捕者自身が現認しうる程度に外部的・客観的でなければならない。後から呼んだ被害者の対面供述のみでは明白性を認め難い。他人の供述だけで足りると解すると、令状主義の例外が無限定に広がる。
- **［○×クイズ 5/10］** 準現行犯逮捕（212条2項）が認められるには、同項各号所定の事由のいずれかに当たり、かつ「罪を行い終わってから間がないと明らかに認められるとき」であることを要する。
  - 正解：○（正しい）
  - 理由：212条2項は、各号（贓物・凶器等の所持、身体・被服に犯罪の証跡、誰何されて逃走等）のいずれかに当たる者が「罪を行い終わってから間がないと明らかに認められるとき」に現行犯人とみなす。本問は各号のいずれにも当たらず、準現行犯逮捕もできない。
- **［○×クイズ 6/10］** 裁判例・実務は、違法な逮捕に引き続く勾留請求について、逮捕手続に重大な違法がある場合に限りこれを却下すべきとする。
  - 正解：○（正しい）
  - 理由：京都地決昭44.11.5・富山地決昭54.7.26に代表されるように、原則却下を前提としつつ、違法が実質的にみて逮捕を無効ならしめる程度に重大でない限り却下しない、と限定する（重大違法説）。「重大」を分水嶺に、あてはめで違法の程度を評価するのが答案の山場。
- **［○×クイズ 7/10］** 逮捕手続に違法がある以上、その違法が軽微であっても、これに引き続く勾留請求は一律に却下しなければならない。
  - 正解：×（誤り）
  - 理由：勾留の理由・必要性がある場合にまで軽微な違法で一律に釈放すると、かえって適正な刑事司法に対する国民の信頼を損なう。そこで重大な違法に限り却下する（限定説＝有力）。「違法があれば全て却下」の全部却下説は少数で、本問の自説ではない。
- **［○×クイズ 8/10］** 同一被疑事実についての再度の逮捕（再逮捕）は、法がおよそ想定しておらず、いかなる場合にも一切許されない。
  - 正解：×（誤り）
  - 理由：199条3項は「同一の犯罪事実……について、その者に対し前に逮捕状の請求……があつたときは、その旨を裁判所に通知しなければならない」と定め、再逮捕を許容することを前提とする規定を置く。ゆえに再逮捕は明文上まったく不可能ではなく、期間制限潜脱防止の観点から要件を絞って例外的に認める問題となる。
- **［○×クイズ 9/10］** 先行する逮捕が違法である場合の再逮捕は、適法な逮捕が先行する通常の再逮捕よりも、その要件を厳格に判断すべきである。
  - 正解：○（正しい）
  - 理由：違法捜査抑止の観点から、捜査機関に手落ちがあった以上、二度目の身柄拘束を安易に認めるべきでない（学説には一切認めない見解すらある）。もっとも一旦釈放し手続をやり直した等の事情があれば、やむを得ない事由を肯定して例外的に再逮捕・再勾留を認めうる。「通常の再逮捕論をそのまま貼る」と評価が落ちる。
- **［○×クイズ 10/10］** 違法な逮捕に引き続く勾留請求を却下すべきとする考え方は、将来の違法捜査抑止・司法の廉潔性という点で、違法収集証拠排除法則と共通の政策的根拠に立つ。
  - 正解：○（正しい）
  - 理由：いずれも「捜査機関の違法を放置すれば将来の違法捜査を助長し、司法に対する信頼を損なう」という同型の発想に立つ。もっとも排除法則は証拠能力の問題、本論点は身柄拘束の可否の問題で、効果の場面は異なる。共通の政策根拠と、効く場面の違いをセットで押さえる。

（○×クイズはここまで＝全10問。最後の10問目まで出したら「○×クイズ、全10問クリア！」と言って復習へ）
