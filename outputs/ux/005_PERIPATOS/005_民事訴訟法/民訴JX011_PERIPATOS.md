## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

XとYは、亡父から相続した甲土地を共有していた（持分はそれぞれ2分の1）が、Yは、Xに無断で、甲土地を第三者に賃貸し、甲土地の賃料収益の全部を収受していた。そこで、Xは、甲土地の賃貸による収益のうちYの持分割合を超える部分は不当利得に当たると主張して、Yに対して、Xの持分割合に相当する賃料持分額の支払を求める訴訟を提起した。これに対してYは、Xの提起した訴訟のうち、口頭弁論の終結日の翌日以降の分について求める部分は不適法であると反論した。甲土地は、X及びYの共有であるとの心証を抱いた裁判所は、口頭弁論の終結日の翌日以降の分について、どのような判決をすべきか、論じなさい。なお、甲土地は、最大50台程度を収容することのできる月極駐車場として利用されているところ、月極駐車場は、一般に常時全部埋まる可能性が高くなく、また、その性質上、短期間で更新のないまま期間が終了したり、期間途中でも解約となることも珍しくない。さらに、より低額の賃料で利用できる駐車場が近隣に現れた場合には賃借人は随時そちらに移る等の事態も予想される。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- X・Yが甲土地を相続し各持分1/2で共有
- YがXに無断で第三者に賃貸し賃料全額を収受
- Xが持分超過分の不当利得返還を提訴（過去分＋将来分）
- Yが「将来分は不適法」と本案前に反論
- 口頭弁論終結（＝基準時）・裁判所はX・Y共有の心証

### 参考（読み上げない。入口の問いの答えを含むので判定にだけ使う）

登場人物：
- X｜共有者・原告（持分1/2・将来分も併せて請求）
- Y｜共有者・被告（無断賃貸し賃料を独占／将来分は不適法と反論）
- 第三者｜甲土地（月極駐車場）の賃借人＝対象外
- 裁判所｜「X・Y共有」の心証 → どの判決をすべきか

一行要約：将来分（基準時後の賃料相当額の不当利得）は135条の将来給付。月極駐車場は賃料が不安定で請求適格の②③を欠く → 請求適格なし → 将来分は訴え却下。

### 入口の問い（3問）

- **［入口 1/3・事案の整理］** 判決基準時でハサミを入れ、「将来分」を挙げて
  - 答え：基準時までの賃料相当額＝現在給付（別途そのまま本案審理）。基準時の翌日以降＝将来給付で、ここに将来の給付の訴えの適否がかかる。（＝まだ履行期が来ていない分を前倒しで請求してよいか）
- **［入口 2/3・見当づけ］** 将来分は「何条の問題か」 ― 見当をつけて
  - 答え：将来分＝基準時後の賃料相当額の不当利得返還（実体は民法703条）→ 将来の給付の訴え（135条）。関所の文言「あらかじめ…必要」は実は二枚扉＝①請求適格（対象として適格か）＋②事前請求の必要性（今訴える必要があるか）。本問の勝負は一枚目。
- **［入口 3/3・論点］** 問題になる論点を挙げて（3つ）
  - 答え：CP①：基準時後の賃料相当額 → 将来の給付の訴え（135条）該当性。（＝まだ発生も履行期も来ていない分の請求）

### 組み立ての順序（入口の問いのあと、骨子に入る前に読み上げる）

- 順番：第1　将来の給付の訴えへの該当性 → 第2　請求適格 → 第3　判決の種類
- 第1　将来の給付の訴えへの該当性
  - 論点：将来の給付の訴え該当性
- 第2　請求適格
  - 論点1：「あらかじめその請求をする必要がある場合」 ― 請求適格＋事前請求の必要性の二段構造
  - 論点2：請求適格の判断基準
- 第3　判決の種類

この順番の理由（参考。結論・配点には触れず、一言で言い直す）：本問は論点1＝請求適格と論点2＝判決の種類の二論点。請求適格なしという結論が出て初めて「では却下か棄却か」が立ち上がる連結構造を押さえる。

#### 第1　将来の給付の訴えへの該当性

- 見出しの補足（結論を含む。項目の終わりに読む）：135条
1. 口頭弁論終結日の翌日以降の賃料相当額の不当利得返還 → 基準時に未履行 → 【論点】将来の給付の訴え該当性（135条）
- 結論：将来の給付を求める訴えに当たる

#### 第2　請求適格

- 見出しの補足（結論を含む。項目の終わりに読む）：論点1・主戦場
1. 「あらかじめその請求をする必要がある場合」 → 【論点】請求適格＋事前請求の必要性の二段構造（本問の争点は請求適格）
2. 将来発生すべき債権の 【論点】請求適格の判断基準 → 規範：3要件（①継続予測②明確な予測可能性③負担転嫁の衡平）
   - あてはめ：②③は債務者視点（将来債権不発生時にYが請求異議の負担・立証責任転嫁）
3. ①継続予測 → Yが現に賃貸・賃料収受中／賃貸借の継続性 → 一応充足
4. ②明確な予測可能性 → 月極駐車場＝満車保証なし・短期解約・近隣移転 → 否定
5. ③負担の衡平 → 賃借人の都合で賃料が左右・Yが左右し得ず請求異議は酷 → 否定
- 結論：②③不充足 ＝ 請求適格なし（あらかじめ請求する必要に当たらない）

#### 第3　判決の種類

- 見出しの補足（結論を含む。項目の終わりに読む）：論点2
1. 請求適格 → 【論点】訴訟要件か本案の問題か → 訴えの利益＝訴訟要件
2. 訴訟要件欠缺 → 本案判決不可（棄却説は既判力・再訴で不都合）
- 結論：将来分につき 訴え却下判決（既発生分は別途本案審理）

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「口頭弁論の終結日の翌日以降の分」 → 将来給付の対象を画す基準時
- 【拾う事実】「最大50台程度の月極駐車場」 → 賃料債権の内容・性質
- 【拾う事実】「常時全部埋まる可能性が高くない」 → 収入発生の不確実性
- 【拾う事実】「短期間で更新切れ・期間途中でも解約」 → 賃料消滅事由
- 【拾う事実】「近隣に低額の駐車場が現れれば随時移る」 → 賃借人の都合で左右
- 【拾う事実】「不適法であると反論」 → 本案前の主張＝適否が争点
- 【事案の整理】ハサミの入れ方
  - 給付の訴えは、履行期が基準時までに来ている＝現在給付／基準時後に来る＝将来給付で二分される。本問は「口頭弁論終結日の翌日以降の分」と名指しされているので、そこが将来給付（135条）の対象だと最初に固定する。
- 【争いのない要件】論点にならず、あっさり認定する要件
  - ①将来給付該当性＝基準時後の賃料相当額の不当利得＝争いなく該当／②必要の意義＝二段構造を一言／③請求適格の3要件＝ここが本丸／④判決の種類＝論点1の結論を受けて一言。流れは必ず通すが、争いのない所は一文でよい。
- 【ポイント】視点の反転に注意
  - ①は事実の継続（客観）。②③は「債務者に有利な事情変動の予測可能性」「請求異議の負担の衡平」＝債務者Yの立場で見る。将来給付を認めると将来賃料が入らなかったときYが請求異議の訴え（民執35条）で執行を止めねばならず、立証責任がYに転嫁されるからだ。
- 【効く事実】「請求適格を3要件＋あてはめで割る」のあてはめで使う事実
  - ①継続予測 → Yが現に賃貸し賃料を収受中・賃貸借の継続性＝一応肯定／②明確な予測可能性 → 月極駐車場は常時満車とは限らず・短期更新切れ・途中解約も珍しくない＝否定／③負担の衡平 → 近隣の低額駐車場へ賃借人が随時移る＝Yが左右し得ない＝否定。
- 【ポイント】訴訟要件 → 却下
  - 請求適格＝訴えの利益＝訴訟要件。訴訟要件を欠く訴えは本案に入れないから、裁判所は中身を判断せず訴え却下（訴訟判決）。却下の対象は将来分だけ（既発生分は本案審理が残る）。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 「請求適格を欠く → だから訴訟要件を欠く → だから却下」と結論が次の前提になる鎖を明示。さらに却下は請求権の当否に既判力が及ばない（114条1項）から、将来事情が具体化すれば再訴できる＝棄却より原告に優しい、と一言添えると上位。
- 【まぎらわしい選択肢・論点】確認の利益の有無／二重起訴の禁止（142条）／既判力の客観的範囲
- 【まぎらわしい選択肢・結論】請求棄却判決 を下す／将来給付の訴えは適法（本案審理へ）
- 【まぎらわしい選択肢・規範】緩和説（紛争の一回的解決）／必要性一要件に一元化
- 【まぎらわしい選択肢・事実】満車が継続し収入は確実／賃借人の移転は想定されない

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

将来分＝基準時後の賃料相当額だから135条。請求適格＝①継続予測は一応○、②③は債務者視点で、月極駐車場は満車保証なし・短期解約・近隣移転だから予測し得ず酷＝×。よって請求適格なし。判決＝訴えの利益＝訴訟要件を欠くから将来分は訴え却下（棄却だと再訴できず酷）。

## 3. 規範クイズ（全2問・1問目から最後まで全部出す）

- **［規範クイズ 1/2］** 将来発生すべき債権に基づく将来の給付請求の「請求適格」が認められるための3要件を挙げよ。
  - 模範解答：①その基礎となるべき事実関係・法律関係が既に存在し、その継続が予測されること。②債権の発生・消滅及びその内容につき債務者に有利な将来の事情変動が、あらかじめ明確に予測し得る事由に限られること。③請求異議の訴えによりその発生を証明してのみ強制執行を阻止し得る負担を債務者に課しても、当事者間の衡平を害さず格別不当といえないこと（最大判昭56.12.16）。
- **［規範クイズ 2/2］** 請求適格を欠く将来給付部分について裁判所がすべき判決を挙げ、請求棄却ではなく訴え却下とすべき理由を述べよ。
  - 模範解答：訴え却下判決（訴訟判決）。請求適格は訴えの利益＝訴訟要件であり、欠ければ本案判決はできない。請求棄却（本案判決）とすると請求権の不存在に既判力が生じ、将来事情が具体化した後の再訴が遮断されて原告に酷となるため、再訴の余地を残す訴え却下が相当である。

## 4. ○×クイズ（全8問・1問目から最後まで全部出す）

- **［○×クイズ 1/8］** 給付の訴えにおける現在の給付と将来の給付は、判決の基準時である事実審の口頭弁論終結時を境に、その時までに履行期が到来しているか否かで区別される。
  - 正解：○（正しい）
  - 理由：判決の基準時（事実審の口頭弁論終結時）までに履行期が到来している請求権が現在の給付、基準時後に履行期が到来するものが将来の給付。将来の給付を求める部分は、135条の「あらかじめその請求をする必要がある場合」の枠を通る必要がある。
- **［○×クイズ 2/8］** 将来の給付の訴えは、「あらかじめその請求をする必要がある場合」であれば、その請求がそもそも将来給付の対象として適格か否かを問わず、常に適法に提起することができる。
  - 正解：×（誤り）
  - 理由：「あらかじめその請求をする必要がある場合」は、将来給付の対象として適格な請求であること（請求適格）と、事前に給付判決を得ておく必要（事前請求の必要性）の二段で捉えるのが一般的整理。将来発生すべき債権では、まず請求適格の有無が問われるのであって、必要性だけで適法になるわけではない。
- **［○×クイズ 3/8］** 将来の給付の訴えにおける「あらかじめその請求をする必要」（請求適格）は、本案判決を求める正当な利益すなわち訴えの利益（権利保護の利益）の問題として位置づけられる。
  - 正解：○（正しい）
  - 理由：請求適格は訴えの利益（権利保護の利益）の一内容であり、その有無は本案に入る資格の問題＝訴訟要件の問題。だからこそ、請求適格を欠けば本案判断をせず訴えを却下するという論点2が立ち上がる。
- **［○×クイズ 4/8］** 判決の基準時までに既に履行期が到来している賃料相当額の不当利得返還請求も、将来の給付の訴え（135条）に当たり、請求適格の有無が問題となる。
  - 正解：×（誤り）
  - 理由：基準時までに履行期が到来している分は現在の給付であり、将来の給付の訴え（135条）の問題ではない。135条の請求適格が問われるのは、基準時後に履行期が到来する将来分に限られる。本問で却下の対象となるのも将来分だけで、既発生分は通常どおり本案審理される。
- **［○×クイズ 5/8］** 将来発生すべき債権の請求適格の要件②③は、債権者に有利な事情ではなく、債務者に有利な将来の事情変動の明確な予測可能性と、債務者に課される請求異議の負担の衡平という、債務者の立場から判断される。
  - 正解：○（正しい）
  - 理由：将来給付を認めると、将来債権が発生しなかった場合に債務者が請求異議の訴えで執行を阻止せねばならず、立証責任が債務者へ転嫁される。そこで②③は「債務者に有利な事情変動が明確に予測でき、負担を課しても衡平を害さないか」という債務者視点で判断する。債権者視点で書くと論旨が逆転する。
- **［○×クイズ 6/8］** 請求適格の要件①（基礎となる事実関係・法律関係の存在と継続の予測）が認められれば、要件②③を検討するまでもなく請求適格が肯定される。
  - 正解：×（誤り）
  - 理由：①②③は累積要件で、いずれかを欠けば請求適格は否定される。本問はまさに①を一応肯定しつつ②③で落とす構造（最判昭63.3.31）。
- **［○×クイズ 7/8］** 将来の給付の訴えにおける請求適格は訴えの利益すなわち訴訟要件であるから、これを欠く将来給付部分について、裁判所は本案判断をすることなく訴えを却下する訴訟判決をすべきである。
  - 正解：○（正しい）
  - 理由：請求適格は訴訟要件なので、欠ければ本案判決（認容・棄却）の対象とならず、裁判所は訴えを却下する（訴訟判決）。判例も請求適格を欠く将来分を不適法として却下している（最判昭63.3.31）。
- **［○×クイズ 8/8］** 請求適格を欠くとして将来給付部分の訴えを却下した場合、請求権の存否には既判力が生じないため、将来事情が具体化した後に改めて給付の訴えを提起することができる。
  - 正解：○（正しい）
  - 理由：訴え却下（訴訟判決）の既判力は訴訟要件を欠くことに生じるにとどまり、請求権の当否には及ばない（114条1項参照）。したがって将来事情が具体化すれば再訴できる。これが、請求棄却ではなく訴え却下を採るべき実質的理由である。

- 【学説】緩和説 ― 将来給付を広く認める ― 【内容】紛争の一回的解決・原告の二重出訴の負担軽減を重視し、請求適格を緩やかに認める。
- 【学説】訴え却下説（通説・判例）＜本問採用＞ ― 【内容】請求適格は訴えの利益＝訴訟要件であり、欠ければ本案に入れないから訴え却下（訴訟判決）。
- 【学説】請求棄却説 ― 【内容】将来の給付義務がなお発生しておらず理由がない以上、本案で請求を棄却すべきとする。
- 【用語】将来の給付の訴え ― 判決の基準時（事実審の口頭弁論終結時）後に履行期が到来する給付請求権についての給付の訴え。
- 【用語】請求適格 ― 将来発生すべき債権が将来の給付の訴えの対象として適格であること。
- 【用語】事前請求の必要性 ― 将来給付判決をあらかじめ得ておく必要。
- 【用語】訴えの利益（権利保護の利益） ― 本案判決を求める正当な利益。
- 【用語】訴訟要件 ― 本案判決をするための前提要件（管轄・当事者能力・訴えの利益等）。
- 【用語】訴訟判決（訴え却下判決） ― 訴訟要件の欠缺を理由に本案に立ち入らず訴えを不適法として却下する判決。
- 【用語】本案判決（請求認容・請求棄却） ― 請求の当否について判断する判決。
- 【用語】既判力 ― 確定判決の判断に認められる後訴での通用力・拘束力。
- 【用語】請求異議の訴え ― 債務名義成立後の事由により強制執行の不許を求める訴え（民執35条）。
- 【用語】基準時（標準時） ― 判決が権利関係を確定する時点＝事実審の口頭弁論終結時。

## 6. 間違えたところの復習
