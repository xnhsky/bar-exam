## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

別荘地で知られる甲町の住民たちは組合契約を締結し、土地（山林）・資金などを出し合って、ある山林（乙）を管理し、自分たちのレジャー施設として利用していた（この組合をAという）。Aには、代表者（組合財産につき包括的な代理権を有する）・書記・会計・監査などの役員の選任や、財産の管理に関する規約が存在し、運営は組合員の多数決で行われ、各住民の転出・転入のたびに組合員の地位は売買で引き継がれ、新たに甲町へ転居してきた住民の大部分も一定額の資金を拠出してAに加入していた。ある日、リゾートマンション開発業者Yが、Aに対し乙の一部を買い受けたとして、分筆のうえ所有権移転登記手続をするよう要求してきた。YはA代表者B名義の記名・押印のある売買契約書を示したが、Bは身に覚えがないという。そこでAは、乙がA側に帰属することの確認を求めて訴えを提起することにした。この場合、原告を誰にするのかにつき、どのような法律構成が成り立ち得るか、検討しなさい。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 甲町住民が組合契約→A組合結成（役員・規約・多数決・存続性）
- Yが乙の一部の所有権移転登記をAに要求（B名義の契約書提示）
- Bは契約に身に覚えなし＝売買の存在を争う
- Aは乙がA側に帰属することの確認を求めて提訴を決意
- 設問：原告を誰にするか・どの構成が成り立つか

### 参考（読み上げない。入口の問いの答えを含むので判定にだけ使う）

登場人物：
- A｜民法上の組合（団体の実態あり・乙を管理）
- B｜A代表者（組合財産に包括的代理権）
- 組合員全員｜乙を総有（合有）
- Y｜開発業者・相手方＝対象外

一行要約：乙は組合員の総有・団体Aに権利なし。原告の立て方は ①A組合（当事者能力29条）→②組合員全員（固有必要的共同訴訟）→③代表者B（任意的訴訟担当）。三つとも成り立つ。

### 入口の問い（3問）

- **［入口 1/3・事案の整理］** 登場人物と「係争物が誰に・どう帰属するか」を挙げて
  - 答え：原告の候補は ①A（団体そのもの）／②組合員全員／③代表者B の3つ。相手方Yは被告側＝検討の中心ではない。
  - 答え：鍵は「乙は組合員に総有的に帰属し、団体Aに権利能力はない」という実体法上の帰属。ここが当事者能力・当事者適格・共同訴訟すべての分岐点。
- **［入口 2/3・見当づけ］** 立てうる「原告の候補」 ― 見当をつけて
  - 答え：①団体Aを原告＝法人でない社団等の当事者能力（29条）系。②組合員全員を原告＝総有ゆえ固有必要的共同訴訟（40条）系。③代表者Bを原告＝選定当事者（30条）→ダメなら任意的訴訟担当系。
- **［入口 3/3・論点］** ①A組合で問題になる論点を挙げて（3つ）
  - 答え：CP①：原則（28条）は権利能力に従う＝組合は当事者能力なし → 組合は29条の「社団」か。（29条＝法人でない社団・財団で代表者等の定めあるものに当事者能力を認める特則）
  - 答え：CP②：社団の実態があるか → 団体性4要件のあてはめ。（組織・多数決・構成員が変わっても存続・主要な点の確定）
  - 答え：CP③：当事者能力を認めても権利は総有 → 当事者適格をどう架橋するか。（権利は構成員のまま団体を訴訟担当者と解するのが穏当）

- 順番：第1　①A組合を原告とする構成 → 第2　②組合員全員を原告とする構成 → 第3　③代表者Bを原告とする構成 → 第4　結論
- 第1　①A組合を原告とする構成

  - 論点2：当事者適格（乙は総有で団体に権利なし）
- 第2　②組合員全員を原告とする構成
  - 論点：固有必要的共同訴訟か
- 第3　③代表者Bを原告とする構成
  - 論点：明文なき任意的訴訟担当
- 第4　結論
  - 論点：なし（結論の確認だけ）

この順番の理由（参考。結論・配点には触れず、一言で言い直す）：本問は ①A組合 → ②組合員全員 → ③代表者B の順。①で29条該当（当事者能力）を決めると、③の選定当事者（30条）の可否が自動的に定まるから。

### 骨子（4項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　①A組合を原告とする構成

- 見出しの補足（結論を含む。項目の終わりに読む）：当事者能力・当事者適格
1. 原則（28条）＝権利能力に従う → 組合に当事者能力なし
2. 【論点】組合は29条の「社団」か（規範：団体性4要件＋代表者の定め）
   - あてはめ：役員選任・規約・多数決・地位の売買承継＝構成員変更にかかわらず存続＋代表者B → 社団該当・当事者能力○
3. 【論点】当事者適格（乙は総有で団体に権利なし） → 訴訟担当構成で架橋
   - あてはめ：実体法を修正せず、団体を訴訟担当者と解する（権利能力付与説は非推奨）
- 結論：A組合を原告とする構成は成り立つ

#### 第2　②組合員全員を原告とする構成

- 見出しの補足（結論を含む。項目の終わりに読む）：固有必要的共同訴訟
1. 乙は総有（合有）＝管理処分権は全員に帰属（40条1項・合一確定）
2. 【論点】固有必要的共同訴訟か → 区別基準＝管理処分権の帰属＋手続保障 → 該当
- 結論：全員を原告とする構成も成り立つ（ただし全員を揃える負担大）

#### 第3　③代表者Bを原告とする構成

- 見出しの補足（結論を含む。項目の終わりに読む）：選定当事者→任意的訴訟担当
1. 選定当事者（30条）→ 29条該当ゆえ「前条に該当しないもの」を欠き不可（一言）
2. 【論点】明文なき任意的訴訟担当（規範：潜脱のおそれなし＋合理的必要）
   - あてはめ：Bは代表者で授権あり＝潜脱なし／全員を揃える困難＝合理的必要 → ○
3. 組合の当事者能力と両立
- 結論：代表者Bを原告とする構成も成り立つ

#### 第4　結論

   ①②③いずれも成り立つ。②は全員を揃える負担が大きく、実務は①又は③が穏当

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 権利能力なき社団が成立する（29条の「社団」に当たる）ための団体性4要件を挙げよ。
  - 模範解答：①団体としての組織を備え ②多数決の原理が行われ ③構成員の変更にかかわらず団体そのものが存続し ④その組織において代表の方法・総会の運営・財産の管理等、団体としての主要な点が確定していること（最判昭42.10.19）。この4要件が、29条の「社団」該当性を判断する規範（要件）であり、充足すれば当事者能力が肯定される。
- **［規範クイズ 2/3］** 団体に当事者能力（29条）を認めても、なお当事者適格が別途問題となるのはなぜか、組合財産の帰属形態に即して説明せよ。
  - 模範解答：当事者能力は「およそ当事者になりうる一般的資格」にすぎず、特定の訴訟物を追行する正当な資格（当事者適格）とは別。係争物は総組合員の総有（合有）に属し団体自体に権利が帰属しないから、団体が確認の訴えを追行する正当な地位があるか（訴訟担当構成で架橋できるか）が別個に問題となる。
- **［規範クイズ 3/3］** 明文なき任意的訴訟担当が許容されるための要件を、なぜ制限されるのか（趣旨）とともに述べよ。
  - 模範解答：民訴法が訴訟信託を禁止し、弁護士でない者が訴訟代理人となることを原則として許さない趣旨（弁護士代理の原則＝54条・訴訟信託の禁止）に照らし、無制限には許されない。もっとも、これらの制限を回避・潜脱するおそれがなく、かつこれを認める合理的必要がある場合には許容される（最大判昭45.11.11）。

## 4. ○×クイズ（全7問・1問目から最後まで全部出す）

- **［○×クイズ 1/7］** 民法上の組合の財産は、総組合員の共有（合有）に属し、組合という団体それ自体は権利能力（権利義務の帰属主体となる資格）を有しない。
  - 正解：○（正しい）
  - 理由：組合財産は総組合員の共有に属し（民法668条）、団体としての組合に実体法上の権利能力はない。この「権利は構成員に帰属し、団体には帰属しない」というズレが、当事者能力を認めても当事者適格が別途問題になる理由になる。
- **［○×クイズ 2/7］** 当事者能力（訴訟の当事者となりうる一般的資格）が認められれば、その者には当然に、当該訴訟物について訴訟を追行する正当な資格（当事者適格）も認められる。
  - 正解：×（誤り）
  - 理由：当事者能力は「およそ当事者になりうるか」の一般的資格、当事者適格は「この訴訟物についてこの人が追行してよいか」の個別的資格で、別個の訴訟要件。団体に当事者能力を認めても、権利が構成員に帰属する場合は当事者適格が別途問題になる。
- **［○×クイズ 3/7］** 選定当事者（30条）の制度は、共同の利益を有する多数の者のうち「法人でない社団等（29条）の規定に該当しないもの」を対象として、その中から訴訟を追行する者を選ぶ制度である。
  - 正解：○（正しい）
  - 理由：30条1項は「共同の利益を有する多数の者で前条の規定に該当しないもの」に選定当事者を認める。「前条」＝29条だから、団体を29条に当たると認めた場合、その構成員は「29条に該当しないもの」とはいえず、選定当事者を使いにくくなる（条文連動）。
- **［○×クイズ 4/7］** 法人でない社団が当事者能力を有するには、民訴法29条により、団体としての実体に加えて代表者又は管理人の定めがあることを要する。
  - 正解：○（正しい）
  - 理由：29条は「法人でない社団又は財団で代表者又は管理人の定めがあるもの」に当事者能力を認める。代表者等の定めは条文上の明文要件。
- **［○×クイズ 5/7］** 団体に当事者能力が認められた以上、その団体の当事者適格は、実体法上の権利能力を当該団体に付与する構成（権利能力付与説）によらなければ説明できない。
  - 正解：×（誤り）
  - 理由：訴訟法上の便宜のために実体法上の権利帰属を修正するのは相当でないから、権利は構成員に総有的に帰属したまま団体を訴訟担当者と解する訴訟担当構成でも当事者適格を肯定できる。むしろ実体法を修正しない訴訟担当構成のほうが穏当とされる。
- **［○×クイズ 6/7］** 数人の総有（合有）に属する権利の確認を求める訴えは、権利者全員が共同して原告とならなければ当事者適格を欠く固有必要的共同訴訟となる。
  - 正解：○（正しい）
  - 理由：総有権の管理処分権は構成員全員に合有的に帰属し、確認判決は全員につき合一にのみ確定すべきである（40条1項）。よって全員が共同してはじめて当事者適格を有する固有必要的共同訴訟となり、一人でも欠ければ訴えは不適法となる。
- **［○×クイズ 7/7］** 団体に当事者能力（29条）が認められる場合には、その団体の代表者を原告とする任意的訴訟担当を重ねて認める余地はない。
  - 正解：×（誤り）
  - 理由：組合の当事者能力と代表者による任意的訴訟担当は二者択一ではなく両立する。両立するのは、当事者能力の付与（29条）と訴訟追行権の授権（任意的訴訟担当）とが別個の制度だからである。団体を原告にできることは、代表者に任意的訴訟担当を認めることを妨げず、本問でも①A組合・③代表者Bのいずれの構成も肯定される。
