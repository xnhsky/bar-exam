## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

甲は、株式会社乙の商業登記簿上の代表取締役丙を乙の代表者として、乙に対し、売買代金の支払を求める訴えを提起した。丙は、乙の代表者としてこの訴訟の訴状の送達を受け、口頭弁論期日に出頭して、甲の請求を争った。丙は、訴訟の審理がかなり進んだ段階で、自分は乙の代表取締役に選任されたことはなく、乙の真実の代表取締役は丁である旨を口頭弁論期日において陳述した。右の場合における訴訟法上の問題点及び裁判所が採るべき措置について論ぜよ。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 甲、登記簿上の代表者丙を乙代表者として提訴
- 丙が訴状送達を受け、口頭弁論に出頭し請求を争う
- 丙を代表者とする前提で審理がかなり進む
- 丙「自分は選任されていない・真実の代表者は丁」と陳述
- 丙の訴訟行為の効力・裁判所の措置が問題に

- 丙｜登記簿上の代表者（→無権代表者と判明）

### 入口の問い（3問）

- **［入口 1/3・事案の整理］** 当事者と「手続上の引っかかり」を挙げて

  - 答え：引っかかりは登記（丙）と実体（丁）の食い違い。審理がかなり進んだ段階で表面化した点をタグ付けしておく。
- **［入口 2/3・見当づけ］** 「何が問題か」 ― 見当をつけて
  - 答え：丙＝無権代表者 → 訴訟行為は原則として乙に及ばない（法定代理の準用・37条）。そこから救済を2方向でGUESS ── ①実体法の表見法理（会社法908Ⅱ等）の類推で救えるか、②追認（34条2項）・信義則で救えるか。最後に設問後段の裁判所の措置（補正）。
- **［入口 3/3・論点］** 問題になる論点を挙げて（3つ）
  - 答え：CP①：丙＝無権代表者なら、その訴訟行為は原則として乙に効力を生じない（37条・法定代理準用）。（＝代表権を欠く者の行為は本人に帰属しないのが出発点）
  - 答え：CP②：表見法理（会社法908Ⅱ・354・民109）を訴訟行為に類推できるか → 表見法理の訴訟行為への類推適用の可否（判例は否定）。（表見法理＝外観を信じた相手方を保護する取引安全の制度）
  - 答え：CP③：否定すると相手方（甲）が害される → 追認（34Ⅱ）・信義則による追認拒絶の制限で救済。CP④：裁判所の措置＝補正（34Ⅰ・37）で代表者を丁へ。

1. 丙＝無権代表者 → 【論点】無権代表者の訴訟行為の効力（規範：37条準用で原則として本人に効力を生じない）
   - あてはめ：もっとも真実の代表者丁の追認（34条2項・37条）で行為時にさかのぼり治癒
2. 追認なき場合の救済 → 【論点】表見法理（会社法908条2項等）の訴訟行為への類推の可否
   - あてはめ：規範：表見法理は取引安全の制度で訴訟手続になじまない＝類推否定（判例）
   - あてはめ：論拠：手続の安定・明確性／真の代表者の裁判を受ける権利／会社法13条但書が裁判上の行為を除外
- 結論：表見法理の類推は否定

#### 第2　訴訟法上の問題点② ― 信義則による相手方保護

1. 否定すると相手方甲が害される → 【論点】信義則による追認拒絶の制限
2. 規範：真の代表者が実質的に訴訟へ関与していた場合は信義則（2条）上、追認を拒絶できない
   - あてはめ：本問は丙個人へ送達・丁の関与の程度が不明 → 条件付きの結論に
- 結論：否定説でも信義則で相手方を保護できる

- 見出しの補足（結論を含む。項目の終わりに読む）：補正
   代表権の欠缺＝治癒可能な瑕疵 → 却下の前に補正を命じる（34条1項・37条） → 代表者を丙から丁に改め、以後丁が訴訟追行

原則＝代表権なき者の訴訟行為は本人に及ばず（37条）、追認で遡及的治癒（34条2項）。表見法理＝取引安全の制度で訴訟になじまない・13条但書も裏付け＝類推否定（最判昭45.12.15）。救済＝否定でも信義則（2条）で追認拒絶を制限。措置＝補正（34条1項・37）で代表者を丁へ。

- **［規範クイズ 3/5］** 表見法理を訴訟行為に類推適用できない理由を3つ以上挙げよ（判例・否定説の論拠）。

## 4. ○×クイズ（全7問・1問目から最後まで全部出す）

- **［○×クイズ 1/7］** 法人が当事者となる訴訟では、代表者の代表権の有無は訴訟要件ないし個々の訴訟行為の適法性に関わる事項であり、裁判所は当事者の主張がなくても職権で調査しなければならない。
  - 正解：○（正しい）
  - 理由：法人は代表者を通じてしか訴訟行為ができず、代表権の有無は手続全体の適法性を左右するため、自白に拘束されず裁判所が職権で調査する（職権調査事項）。だから「丙が真実の代表者か」をまず職権で確定するのが検討の出発点になる。
- **［○×クイズ 2/7］** 代表権を有しない者が法人のためにした訴訟行為は、法定代理権を欠く者の訴訟行為と同様、真実の代表者の追認がなくても原則として本人である法人に効力を生ずる。
  - 正解：×（誤り）
  - 理由：法人の代表者には法定代理の規定が準用され（37条）、代表権を欠く者の訴訟行為は原則として本人に効力を生じないのが出発点。効力を及ぼすには真実の代表者の追認（34条2項・37条）を要する。「当然に効力が生じる」は原則を取り違えた誤り。
- **［○×クイズ 3/7］** 無権代表者がした訴訟行為は、真実の代表者が追認しても、追認の時点から将来に向かってのみ効力を生じ、既にされた訴訟行為に遡って効力が及ぶことはない。
  - 正解：×（誤り）
  - 理由：訴訟行為の追認（34条2項・37条）は、無権代理行為の追認と同様、行為の時にさかのぼって効力を生じさせる（遡及的治癒）。だから審理のやり直しを避けられる。「将来効のみ」は遡及効を落とした誤り。
- **［○×クイズ 4/7］** 会社法908条2項（不実の登記）や354条（表見代表取締役）などの表見法理の規定は、不実の登記を信頼した相手方を保護するためのものであるから、誰が会社を代表して訴訟を追行する権限を有するかを定めるにあたっても当然に類推適用される。
  - 正解：×（誤り）
  - 理由：判例（最判昭45.12.15）は、表見法理の諸規定は取引の相手方保護・取引安全のための規定だから、取引行為と異なる訴訟手続で代表権者を定めるには適用されないとして類推を否定した。手続の安定・明確性、真の代表者の裁判を受ける権利が理由。「当然に類推適用」は判例の結論に反する。
- **［○×クイズ 5/7］** 会社法13条（表見支配人）が、その但書で表見支配人のした裁判上の行為について本文の適用を除外していることは、表見法理が訴訟行為には及ばないという立法者の価値判断の現れとして、表見法理の訴訟行為への類推を否定する論拠になる。
  - 正解：○（正しい）
  - 理由：会社法13条は表見支配人の権限を「裁判外の行為」に限り裁判上の行為を除外する。取引安全のための表見法理ですら訴訟行為には及ばせないという立法者の判断であり、判例もこれを援用して類推を否定した。これを引けると判旨の論理を正確に再現できる（発展加点）。
- **［○×クイズ 6/7］** 表見法理の類推適用を否定する立場でも、真実の代表者が実質的に訴訟手続に関与していた場合には、信義則（2条）上、その者が追認を拒絶して審理のやり直しを求めることが許されないことがある。
  - 正解：○（正しい）
  - 理由：否定説でも「相手方が泣き寝入り」にはならない。真の代表者が実質的に関与しておきながら追認を拒絶して手続をやり直させるのは信義に反するため、信義則（2条）上、追認拒絶を制限して相手方を保護できる。表見法理の類推を否定しつつ結論の妥当性を確保する筋。
- **［○×クイズ 7/7］** 法人の代表権に欠缺がある場合、裁判所は直ちに訴えを却下するのではなく、期間を定めてその補正を命じるのが原則である（34条1項・37条）。
  - 正解：○（正しい）
  - 理由：代表権の欠缺は治癒可能な瑕疵であり、34条1項（37条で法人代表者に準用）は裁判所が期間を定めて補正を命じると定める。できる限り本案判決に導く趣旨（訴訟経済・紛争の一回的解決）から、却下の前にまず補正を命じるのが確立した取扱い。

- 【条文】会社法908条2項（不実の登記） ― 2項故意又は過失によって不実の事項を登記した者は、その事項が不実であることをもって善意の第三者に対抗することができない。

- 【条文】会社法13条（表見支配人） ― 会社の本店又は支店の事業の主任者であることを示す名称を付した使用人は、当該本店又は支店の事業に関し、一切の裁判外の行為をする権限を有するものとみなす。
