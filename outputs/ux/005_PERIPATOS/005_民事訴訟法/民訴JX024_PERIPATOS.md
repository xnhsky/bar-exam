## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

Xら4名とYは、兄弟であったが、Xら4名は、Yに対して、Y名義の本件土地につき、共有持分権に基づく各持分5分の1の所有権移転登記手続を求め、訴訟を提起した。この訴訟において、Xらは、「その土地は、AからXらの先代Bが買い受け、Bからその子である、Xら4名及びYが相続した」と主張した。これに対して、Yは、本件土地は「AからYが買い取ったものである」と主張した。裁判所は、証拠調べの結果、本件土地は「AからBが買い取ったが、Bがその跡取りとしての地歩を占めていたYに死因贈与したものである」との心証を形成した。裁判所は、これを認定して、Xの請求を棄却できるか。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 実体①　AからBへ本件土地が売買により移転（Xらの主張と心証が一致）
- 実体②　BがYに本件土地を死因贈与（心証のみ・誰も主張していない）
- 実体③　Bが死亡し、子であるXら4名とYの5名が相続人となる
- 手続①　Xら4名が各持分5分の1の移転登記手続を求めて提訴
- 手続②　Xら＝A→B売買＋相続／Y＝A→Y売買（Bの取得自体を争う）
- 手続③　証拠調べ → 裁判所が「A→B売買→Yへ死因贈与」の心証を形成
- 手続④　この心証どおり認定して請求を棄却できるかが問われる時点

### 入口の問い（7問）

- **［入口 1/7・事案の整理］** 当事者の主張と裁判所の心証を並べ、差分だけ取り出す（1つ）
  - 答え：Xら＝「A→B（売買）→Xら4名およびY（相続）」／Y＝「A→Y（売買）」／裁判所＝「A→B（売買）→Y（死因贈与）」。
  - 答え：重なり＝A→Bの売買（Xらの主張と一致）。残り＝B→Yの死因贈与。これが誰も主張していない事実。（＝訴訟資料として弁論に現れていない事実）
  - 答え：Yの「AからYが買い取った」は、Xらの主張を打ち消す陳述であって、死因贈与を持ち出すものではない。相手方の主張の中に紛れていないかまで確かめて初めて差分が確定する。
- **［入口 2/7・見当づけ］** 「どの審理原則の問題か」 ― 見当をつけて
  - 答え：「申立てを超えた判決」＝処分権主義（246条）／「主張のない事実を認定」＝弁論主義の第1テーゼ（明文なし）／「証拠の評価の仕方」＝自由心証主義（247条）。本問は申立ての範囲は動いていない（持分5分の1の移転登記のまま）のに事実が増えている。よって弁論主義。
- **［入口 3/7・見当づけ］** 「どの審理原則の問題か」 ― 見当をつけて（1つ）
  - 答え：処分権主義は審判の対象と範囲（何について・どこまで裁くか）を当事者に委ねる原則。本問の判決は「請求棄却」で、申立ての範囲を超えていない。処分権主義の問題ではない。
  - 答え：自由心証主義は主張された事実の存否をどう認定するかの原則。「証拠から心証を得たのだから認定してよい」は作用局面の取り違えで、大幅減点の典型。
  - 答え：残るのが弁論主義の第1テーゼ（主張責任）。（＝当事者の主張しない事実を判決の基礎にできないという審理原則）
- **［入口 4/7・論点］** 問題になる論点を挙げて（3つ）
  - 答え：CP①：条文がない → 弁論主義の定義と趣旨を自分で立てる。（＝訴訟資料の収集・提出を当事者の権能と責任に委ねる建前）
  - 答え：CP②：適用されるのは「事実」だが、どこまでか → 主要事実への限定。理由は自由心証主義（247条）との調和＝間接事実・補助事実は主要事実との関係で証拠と同じ機能を営むから、主張に縛ると不自然な事実認定を強いる。
  - 答え：CP③：では主要事実とは何か → 定義を提示してから手5のあてはめへ。（＝権利の発生・変更・消滅を定める規範の要件に直接該当する具体的事実）
- **［入口 5/7・論点］** 規範からあてはめまで組んで（4つ）

- **［○×クイズ 4/12］** 弁論主義の第1テーゼは、「裁判所において当事者が自白した事実は証明することを要しない」と定める民事訴訟法179条を直接の根拠条文とする原則である。
  - 正解：×（誤り）
  - 理由：弁論主義には直接の明文規定がない。179条・159条1項は第2テーゼ（自白の拘束力）を前提とする規定、247条は適用対象を限定する対抗原理、149条は不都合を調整する装置にすぎない。したがって答案では「〇条より」と書き出せず、民事訴訟の目的（私権に関する紛争の解決）から説き起こす必要がある。
- **［○×クイズ 5/12］** 主要事実の定義にいう「規範の要件に該当する具体的事実」には、その要件の存否を経験則により推認させる事実も含まれる。
  - 正解：×（誤り）
  - 理由：主要事実とは、権利の発生・変更・消滅を定める規範の要件に「直接」該当する具体的事実をいう。推認させるにとどまる事実は間接事実であって、弁論主義の適用はない。この「直接」という限定語が主要事実と間接事実の境界を引く役割を担うので、定義から落としてはならない。
- **［○×クイズ 6/12］** 所有権の帰属が争われる訴訟では、「現在その物の所有権が原告に帰属していること」自体が主要事実であり、売買や相続といった取得原因を構成する事実は、これを推認させる間接事実にとどまる（判例・通説）。
  - 正解：×（誤り）
  - 理由：向きが逆。判例・通説は所有権そのものは法的評価であって主要事実ではなく、それを基礎づける取得原因事実（来歴経過）こそが主要事実と整理する。所有権は観念的権利であり、その帰属は取得原因を離れて認定できないからである。この整理は、所有権の帰属という法的評価の自認（権利自白）に裁判所拘束力を認めない立場とも対応している。答案で「所有権が主要事実である」と書くと、権利と事実の区別がついていないと読まれる。
- **［○×クイズ 7/12］** 死因贈与は贈与者の死亡によって効力を生ずるから、その目的物は被相続人の死亡時に相続財産の範囲から逸出し、相続人は当該財産について相続による持分を取得しない。
  - 正解：○（正しい）
  - 理由：民法554条は、贈与者の死亡によって効力を生ずる贈与について、その性質に反しない限り遺贈に関する規定を準用する。被相続人の処分行為により財産が相続財産を構成しなくなる以上、896条の包括承継の対象から外れ、共同相続人は持分を取得しない。効果を「持分権の不発生（喪失）」として特定できるかが、主要事実性の論証の足場になる。
- **［○×クイズ 8/12］** 相続による特定財産の取得を主張する者は、被相続人が生前その財産の所有権を取得した事実および自己が相続した事実の2つを主張立証すれば足り、被相続人の特段の処分行為により当該財産が相続財産の範囲から逸出した事実がなかったことまで主張立証する責任を負わない（判例）。
  - 正解：○（正しい）
  - 理由：最判昭和55年2月7日（民事訴訟法判例百選［第6版］42事件）の規範。取得主張者の負担を(1)被相続人の生前の所有権取得と(2)相続の開始に限り、①死亡時までに所有権喪失原因がなかったこと、②特段の処分行為による相続財産からの逸出がなかったこと、という2つの消極的事実は、承継取得を争う者が抗弁として主張立証すべきものとした。消極的事実の立証の困難と当事者間の公平が根拠である。
- **［○×クイズ 9/12］** 原告が「目的物は前所有者から自分の先代が買い受け、自分が相続した」と主張したのに対し、被告が「目的物は前所有者から自分が直接買い受けた」と述べた。この被告の陳述は、原告の主張する事実と両立しつつその法律効果を消滅させる抗弁の主張である。
  - 正解：×（誤り）
  - 理由：これは否認である。「前所有者から被告が直接買い受けた」という陳述は、「前所有者から先代が買い受けた」という請求原因事実と両立しないから、新たな事実の主張を含む抗弁ではなく、相手方の主張事実を打ち消す陳述にとどまる。したがって、被告がこう述べたからといって、被相続人の処分行為（生前贈与・死因贈与等）という両立する別の事実が主張されたことにはならない。
- **［○×クイズ 10/12］** ある事実が主要事実に当たる場合において、主張責任を負う当事者がこれを主張しないときは、その事実を要件とする法律効果が認められないという不利益は、その当事者が負う。
  - 正解：○（正しい）
  - 理由：これが主張責任である。その分配は原則として立証責任の分配に従う（法律要件分類説＝権利根拠規定・障害規定・消滅規定・阻止規定による）。存否不明の場合の不利益が立証責任、主張がない場合の不利益が主張責任で、局面が違うだけで負担者は一致するのが原則。裁判所がこの不利益を肩代わりして事実を補うことは、弁論主義が禁じるところである。
- **［○×クイズ 11/12］** 弁論主義は裁判所が当事者の主張しない事実を判決の基礎とすることを禁じるものであるから、裁判所が当事者に対して抗弁となりうる事実の主張を促すこともまた許されない。
  - 正解：×（誤り）
  - 理由：弁論主義が禁じるのは、裁判所が主張のない事実を勝手に取り込むことであって、当事者に主張の機会を与えることまでは禁じていない。裁判長は訴訟関係を明瞭にするため、事実上および法律上の事項に関し問いを発し、または立証を促すことができる（149条1項）。当事者が応じて主張すれば、その事実は訴訟資料となり判決の基礎にできる。これが弁論主義の形式的適用から生じる不都合を調整する経路である。
- **［○×クイズ 12/12］** 弁論主義に違反して主張のない主要事実を認定した判決は違法であるが、その違法は絶対的上告理由（312条2項各号）には当たらない。
  - 正解：○（正しい）
  - 理由：312条2項各号は、判決裁判所の構成の違法、専属管轄違背、代理権の欠缺、口頭弁論の公開違反、理由不備・理由齟齬などを限定列挙する。弁論主義違反はこれに含まれないため、上告審で争うには判決に影響を及ぼすことが明らかな法令違反として上告受理の申立て（318条1項）によることになる。控訴審では事実認定・法令適用の当否が審理の対象となるから、そこで是正されうる。

（○×クイズはここまで＝全12問。最後の12問目まで出したら「○×クイズ、全12問クリア！」と言って復習へ）
