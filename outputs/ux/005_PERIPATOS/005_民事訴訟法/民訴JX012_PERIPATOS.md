## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

Aが死亡し、その共同相続人はX、Y及びZである。1　Xは、Y及びZを被告として甲土地がAの遺産に属することの確認を求める訴えを提起した。この訴訟において、YはXの主張を争ったが、ZはXの主張を争わなかった。裁判所は、Zに対する関係で口頭弁論を分離して終結し、判決することができるか。2　Xは、甲土地の単独所有を主張するYを被告として、共同相続に基づき、甲土地の共有持分権を有することの確認を求める訴えを提起した。この訴訟においてX勝訴の判決が確定した場合、この判決は、どのような効力を有するか。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- A死亡 → X・Y・Zが共同相続・甲土地は遺産共有（分割未了）
- 小問1：XがY・Zを被告に遺産確認の訴え
- 小問1：Yは争う／Zは争わない
- 小問1の問い：Zだけ分離・終結して判決できるか
- 小問2：XがYのみを被告に持分権確認の訴え → X勝訴確定
- 小問2の問い：確定判決はどんな効力を持つか

### 参考（読み上げない。入口の問いの答えを含むので判定にだけ使う）

登場人物：
- X｜共同相続人・原告（両小問で提訴）
- Y｜共同相続人・被告（遺産性／単独所有を争う）
- Z｜共同相続人（小問1は被告で争わず／小問2は非当事者）
- A｜被相続人（死亡）＝検討の起点

一行要約：小問1＝X対Y・Zの遺産確認（Zは争わず）→ 分離判決できるか。小問2＝X対Yの持分権確認でX勝訴確定 → 効力は？

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「甲土地がAの遺産に属することの確認」 → 遺産確認の訴え＝訴えの対象が遺産帰属性
- 【拾う事実】「Y及びZを被告として」 → 共同相続人全員を当事者に＝固有必要的共同訴訟の形
- 【拾う事実】「ZはXの主張を争わなかった」 → 分離できそうに見える罠（合一確定は動かない）
- 【拾う事実】「共有持分権を有することの確認」 → 訴訟物＝持分権の存在（遺産帰属性は取得原因）
- 【拾う事実】『「Yを被告として」（Zはいない）』 → 当事者はXYのみ＝既判力の主観的範囲
- 【事案の整理】民訴は「当事者＝誰が手続に関与したか」が全部を決める
  - 既判力の及ぶ範囲も訴訟形態も、当事者の顔ぶれで決まる。小問ごとに当事者を確定する ── 小問1＝X対Y・Z（3人全員）／小問2＝X対Y（Zは非当事者）。この「小問2でZが外れる」ことが後で効く。
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 対象選択＝現在の権利関係で○／即時確定＝Yが争っている＝○／小問2の適法性＝持分権は各自の管理処分権＝通常共同訴訟で単独提訴可。
- 【効く事実】あてはめで使う事実
  - 方法選択 → 持分権確認では遺産帰属性が確定されない（小問2と架橋）／固有必要的共同訴訟 → 甲土地は全員の遺産共有（898条）＝管理処分権の全員帰属／分離不可 → Zが争わなくても合一確定の要請は動かない。
- 【ポイント】既判力は「主文だけ・当事者だけ」
  - 既判力は主文に包含するもの（＝訴訟物）に限り生じ（114条1項）、理由中の判断（取得原因＝遺産帰属性）には及ばない。また当事者間にのみ生じ（115条1項1号）、非当事者Zには及ばない。この2点を正確に当てる。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 同じ相続財産の確認でも確認の対象の選び方で既判力の射程が変わる。遺産確認は遺産帰属性まで確定＝紛争の抜本解決＝全員関与（固有必要的共同訴訟）。持分権確認は当事者間で持分のみ確定＝遺産帰属性は未確定＝単独提訴可（通常共同訴訟）。
- 【まぎらわしい選択肢・論点】二重起訴の禁止／訴訟承継の要否
- 【まぎらわしい選択肢・結論】通常共同訴訟ゆえ分離して判決できる／遺産帰属性にも既判力が及ぶ
- 【まぎらわしい選択肢・規範】争点効肯定説／類似必要的共同訴訟
- 【まぎらわしい選択肢・事実】基準時後の新事由／反射効
