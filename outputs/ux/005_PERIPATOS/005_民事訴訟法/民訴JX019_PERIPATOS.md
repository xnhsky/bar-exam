## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

原告の法律上及び事実上の主張に対して被告がする陳述の態様とその効果について説明せよ。（具体的事案を伴わない一行問題）

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 問いを「主張の種類×態様／効果」の2×2に分解
- 第1＝事実上の主張＝認否の4類型（態様→効果）
- 自白の効果（証明不要効・拘束力）を厚く
- 第2＝法律上の主張＝権利自白（事実の自白と対比）
- どこまで書くかを配点で判断して締める

### 参考（読み上げない。入口の問いの答えを含むので判定にだけ使う）

登場人物：
- 原告｜事実上・法律上の主張をする側
- 被告｜その主張に認否・陳述で応答する側
- 具体的事案なし＝問いの文言を分解して埋める

一行要約：主張は事実上／法律上の2種、陳述の態様／効果を問う2×2。重心は自白の効果。

### 入口の問い（3問）

- **［入口 1/3・事案の整理］** 問いの文言を「2×2」に棚卸し
  - 答え：主張は2種類。事実上の主張（事実の存否）＝応答は認否（否認・自白・不知・沈黙の4類型）。法律上の主張（具体的権利関係）＝応答は争う／認める。
  - 答え：各セルで問われるのは態様（どう応答するか）と効果（応答で何が起きるか）。この4象限を埋めれば骨格が完成する。
- **［入口 2/3・見当づけ］** 各象限で「どこに論点が潜むか」の見当 ― 見当をつけて
  - 答え：効果が一言で終わるセル（否認＝証明が必要になる）と、効果が割れるセル（自白＝証明不要効＋拘束力の根拠・範囲／不知＝推定の及ぶ範囲／沈黙＝擬制自白の限界／権利自白＝拘束力の有無）を仕分ける。
- **［入口 3/3・論点］** 「どこが論点か」を挙げて（3つ）
  - 答え：CP①：自白の効果＝証明不要効・裁判所拘束力・当事者拘束力の根拠と及ぶ範囲。（3効果それぞれ根拠が違う）
  - 答え：CP②：不知の否認推定の及ぶ範囲＝被告に不利な事実に限る。（有利な事実は争わない扱い＝沈黙と同じ）
  - 答え：CP③：擬制自白と通常の自白の効果差＝当事者拘束力の有無。

### 組み立ての順序（入口の問いのあと、骨子に入る前に読み上げる）

- 順番：第1　事実上の主張に対する陳述 → 第2　法律上の主張に対する陳述
- 第1　事実上の主張に対する陳述
  - 論点1：自白の効果と及ぶ範囲
  - 論点2：否認推定の及ぶ範囲
  - 論点3：擬制自白に当事者拘束力なし
- 第2　法律上の主張に対する陳述
  - 論点：権利自白の効果

この順番の理由（参考。結論・配点には触れず、一言で言い直す）：問いは「法律上及び事実上」の順だが、答案は事実上の主張（認否4類型）を先に厚く、法律上の主張（権利自白）を後に置くと流れが明快。基礎概念を体系化してから発展へ展開する。

### 骨子（2項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　事実上の主張に対する陳述

- 見出しの補足（結論を含む。項目の終わりに読む）：認否の4類型
1. ①否認 → 争いある事実 → 原告に証明責任（単純否認／積極否認＝理由付否認・規則79条3項）
2. ②自白 → 【論点】自白の効果と及ぶ範囲（規範：証明不要効179＋裁判所拘束力＝弁論主義＋当事者拘束力＝信義則2）
   - あてはめ：範囲は主要事実に限る（間接・補助事実は自由心証247で及ばず）
3. ③不知 → 【論点】否認推定の及ぶ範囲 → 159条2項・被告に不利な事実に限る
4. ④沈黙 → 159条1項擬制自白 → 【論点】擬制自白に当事者拘束力なし（訴訟行為の不存在）
- 結論：態様ごとに効果が決まる（自白＝証明不要効＋拘束力・主要事実限定）

#### 第2　法律上の主張に対する陳述

- 見出しの補足（結論を含む。項目の終わりに読む）：権利自白
1. 争う → 原告が権利発生を基礎づける主要事実を証明
2. 認める＝【論点】権利自白の効果 → 証明不要効○／裁判所・当事者拘束力は原則×
   - あてはめ：理由：法の解釈適用は裁判所の専権・弁論主義は事実にのみ妥当
3. 例外：所有権等の日常的法律概念は事実の自白に準じうる（有力説）
- 結論：権利自白は原則として証明不要効のみ

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「法律上及び事実上の主張」 → 主張を2種類に仕分ける起点
- 【拾う事実】「態様」 → どう応答するか＝認否4類型・争う／認める
- 【拾う事実】「効果」 → 応答で何が起きるか＝証明不要・拘束力
- 【拾う事実】「被告がする陳述」 → 視点は被告の応答側に固定
- 【拾う事実】『具体的事案なし（一行問題）』 → 観点なし＝文言分解で網羅
- 【ポイント】4類型の効果を一息で
  - ①否認＝争いある事実→原告に証明責任（単純否認／積極否認＝理由付否認・規則79Ⅲ）／②自白＝証明不要効（179）＋拘束力／③不知＝159Ⅱ否認推定／④沈黙＝159Ⅰ擬制自白。効果の分岐点を押さえれば流せる。
- 【ポイント】3効果の根拠と範囲
  - 証明不要効＝179条。裁判所拘束力＝弁論主義（争いなき事実は基礎とする）。当事者拘束力（撤回制限効）＝信義則2条（証明を免れた相手方の地位保護）。範囲＝主要事実のみ（間接・補助事実は自由心証247の領分だから及ばない）。根拠ごとに書き分けると厚みが出る。
- 【ポイント】限界の一文
  - 不知（159Ⅱ）＝否認推定だが、推定が働くのは被告に不利な事実のとき。有利な事実は争わない扱い（沈黙同様）。沈黙（159Ⅰ）＝擬制自白だが当事者拘束力なし。「推定の範囲」「擬制の限界」をそれぞれ一文添えると差がつく。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 争う→原告が権利発生の主要事実を証明。認める＝権利自白→証明不要効○／裁判所・当事者拘束力は原則×（法の解釈適用は裁判所の専権で弁論主義は事実にしか妥当しない）。ただし所有権等の日常的で明確な法律概念は事実の自白に準じて拘束力を認める余地あり、と一言添えると学説の深さを示せる。
- 【まぎらわしい選択肢・論点】訴訟物の特定／既判力の客観的範囲／弁論主義の第3テーゼ
- 【まぎらわしい選択肢・結論】当事者拘束力も当然に生じる／証明不要効も生じない
- 【まぎらわしい選択肢・規範】自由心証主義／処分権主義
- 【まぎらわしい選択肢・事実】間接事実にも及ぶ／補助事実の自白

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

事実上＝否認は証明必要、自白は証明不要効179＋裁判所拘束力（弁論主義）＋当事者拘束力（信義則）で主要事実限定、不知は159条2項否認推定（被告に不利な事実）、沈黙は159条1項擬制自白で当事者拘束力なし。法律上＝争うは主要事実を証明、認めるは権利自白で証明不要効のみ・拘束力は原則なし（所有権等は例外）。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 裁判上の自白（事実の自白）に生じる3つの効果を、根拠条文・根拠原理とともに挙げよ。
  - 模範解答：①証明不要効（179条）②裁判所拘束力（根拠＝弁論主義）③当事者拘束力＝撤回制限効（根拠＝信義則・2条）。いずれも主要事実に限って生じる。
- **［規範クイズ 2/3］** 自白の当事者拘束力（撤回制限効）の根拠と、例外的に自白の撤回が認められる場合を挙げよ。
  - 模範解答：根拠＝信義則（2条）。証明を免れた相手方の有利な地位を任意に奪えないため撤回が制限される。撤回が許されるのは、①相手方の同意がある場合、②刑事上罰すべき他人の行為により自白した場合、③自白内容が真実に反し、かつ錯誤に基づくことを立証した場合（大判大4.9.29ほか）。
- **［規範クイズ 3/3］** 権利自白に裁判所拘束力・当事者拘束力が原則として生じない理由と、拘束力を認める例外を述べよ。
  - 模範解答：理由＝法規の解釈・適用は裁判所の専権（「裁判所は法を知る」）であり、弁論主義は事実に妥当する原則で法律判断には及ばない。加えて私人の法的判断には誤解が伴いやすい。例外＝所有権など日常生活でも意味内容が明確で誤解のおそれが小さい法律概念については、事実の自白に準じて拘束力を認める余地がある（有力説）。

## 4. ○×クイズ（全7問・1問目から最後まで全部出す）

- **［○×クイズ 1/7］** 原告の事実上の主張に対する被告の陳述（認否）には、否認・自白・不知・沈黙の4類型がある。
  - 正解：○（正しい）
  - 理由：相手方の主張事実への応答態様は、否認（否定する）・自白（認める）・不知（知らない）・沈黙（争うと明らかにしない）の4つに整理される。
- **［○×クイズ 2/7］** 裁判上の自白が成立すると、その事実は証明不要となるだけでなく、裁判所も自白に反する事実認定ができなくなる。この裁判所拘束力は、主要事実のみならず間接事実についても生じる。
  - 正解：×（誤り）
  - 理由：自白の裁判所拘束力が及ぶのは主要事実に限られる。間接事実・補助事実は主要事実の存否を推認させるもので機能は証拠と変わらず、これに拘束力を認めると自由心証主義（247条）に反するからである（最判昭41.9.22）。
- **［○×クイズ 3/7］** 相手方の主張した事実を知らない旨の陳述（不知）をした者は、その事実を争ったものと推定される（159条2項）。
  - 正解：○（正しい）
  - 理由：不知は159条2項により否認と推定される（否認推定）。沈黙を擬制自白とする同条1項と向きが逆なので、1項＝沈黙＝擬制自白／2項＝不知＝否認推定と固定して覚える。
- **［○×クイズ 4/7］** 相手方の主張した事実を争うことを明らかにしない場合（沈黙）は、弁論の全趣旨によりその事実を争ったものと認めるべきときを除き、自白したものとみなされる（159条1項）。
  - 正解：○（正しい）
  - 理由：沈黙は159条1項により擬制自白とみなされる。ただし「弁論の全趣旨により争ったと認めるべきとき」は除かれる。擬制自白は証明不要効を生じるが、当事者の訴訟行為が存在しない点で通常の自白と効果が異なる。
- **［○×クイズ 5/7］** 沈黙による擬制自白（159条1項）にも、通常の自白と同じく、自白した当事者が後に撤回できなくなる当事者拘束力（撤回制限効）が生じる。
  - 正解：×（誤り）
  - 理由：擬制自白には当事者の訴訟行為（自白の陳述）が存在しない。撤回を制限すべき訴訟行為がそもそもないから、当事者拘束力（撤回制限効）は生じない。証明不要効は生じる点と区別する。
- **［○×クイズ 6/7］** 不知の陳述による否認推定（159条2項）が働くのは、相手方の主張事実が陳述者（被告）にとって不利な場合であり、被告に有利な事実については争わないものとして扱われる。
  - 正解：○（正しい）
  - 理由：不知を否認と推定する趣旨は、不利な事実を知らないと述べる被告を争ったものと扱って争点化する点にある。被告に有利な事実をあえて「知らない」と述べても争う意味がないから、沈黙と同様に争わない扱いとなる。
- **［○×クイズ 7/7］** 被告が原告の法律上の主張（具体的権利関係）を認める権利自白が成立すると、証明不要効が生じるだけでなく、裁判所拘束力・当事者拘束力も当然に生じる。
  - 正解：×（誤り）
  - 理由：権利自白は証明不要効は生じるが、裁判所拘束力・当事者拘束力は原則として生じない（一般的見解）。法規の解釈適用は裁判所の職責であり弁論主義は事実に妥当する原則だからである。

（○×クイズはここまで＝全7問。最後の7問目まで出したら「○×クイズ、全7問クリア！」と言って復習へ）

## 5. 関連・比較の材料（読み上げない。横断を話すときの正しい名前と一行要旨）

条文番号・判例名・年月日は、ここに書かれているものだけを言う。ここに無い知識は「シート外の補足ですが」と前置きする。

- 【条文】民事訴訟法179条（証明することを要しない事実） ― 裁判所において当事者が自白した事実及び顕著な事実は、証明することを要しない。
- 【条文】民事訴訟法159条（自白の擬制） ― 1項当事者が口頭弁論において相手方の主張した事実を争うことを明らかにしない場合には、その事実を自白したものとみなす。
- 【条文】民事訴訟法247条（自由心証主義） ― 裁判所は、判決をするに当たり、口頭弁論の全趣旨及び証拠調べの結果をしん酌して、自由な心証により、事実についての主張を真実と認めるべきか否かを判断する。
- 【条文】民事訴訟法2条（裁判所及び当事者の責務） ― 裁判所は、民事訴訟が公正かつ迅速に行われるように努め、当事者は、信義に従い誠実に民事訴訟を追行しなければならない。
- 【条文】民事訴訟規則79条3項（準備書面・理由付否認） ― 3項準備書面において相手方の主張する事実を否認する場合には、その理由を記載しなければならない。
- 【判例】最判昭和41年9月22日（間接事実の自白） ― 間接事実についての自白は、裁判所を拘束しないのみならず、自白した当事者を拘束するものでもない。
- 【判例】大判大正4年9月29日／最判昭和25年7月11日（自白の撤回） ― 自白の撤回は原則として許されないが、自白内容が真実に反し、かつ錯誤に基づくことを自白した当事者が立証した場合には許される（反真実の証明により錯誤が事実上推定される）。
- 【用語】認否（にんぴ） ― 相手方（原告）の主張事実に対する当事者（被告）の応答。
- 【用語】裁判上の自白（さいばんじょうのじはく） ― 当事者が口頭弁論または弁論準備手続において、相手方の主張と一致する自己に不利益な事実を陳述すること効果証明不要効（179条）・裁判所拘束力・当事者拘束力。
