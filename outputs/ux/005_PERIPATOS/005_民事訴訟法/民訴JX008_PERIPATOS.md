## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

Xが交差点を横断しようとしていたところ、Yが運転するトラックにはねられ、それぞれが重傷を負った。そこで、Xは、Yに対して不法行為に基づく損害賠償請求の訴えを提起した。Xは、入院治療費150万円、休業損害200万円、慰謝料50万円、介護費用200万円を合計した600万円の損害を被ったと考えているが、訴えで請求したのは介護費用200万円を除外した400万円であった。裁判所は、入院治療費を150万円、休業損害を100万円、慰謝料を50万円と認定して、Yに300万円の支払いを命じる判決（＝100万円は棄却）をした。この判決の確定後、Xは、介護費用200万円の支払いを求める訴えを新たに提起した。この第2の訴えは、どのように処理されるべきか。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 交通事故（不法行為）→ Xに損害賠償債権（Xの考える総額600万）発生
- 第1の訴え：介護費用を除外した400万円を請求（＝一部を明示）
- 判決：治療150・休業100・慰謝50＝300万認容／100万棄却（一部認容＝一部敗訴）
- 第1の訴えの判決が確定（既判力が生じる）
- 第2の訴え：介護費用200万円を新たに請求（残部請求）

### 参考（読み上げない。入口の問いの答えを含むので判定にだけ使う）

登場人物：
- X｜原告・交通事故の被害者（→400万円で前訴・敗訴部分あり → 介護費用200万円で後訴）
- Y｜被告・加害者（→前訴で一部認容判決を受け確定）

### 入口の問い（3問）

- **［入口 1/3・事案の整理］** 前訴・後訴を分け、時系列で棚卸し
  - 答え：前訴＝400万円請求（介護費用200万円を除外）→ 入院治療費150・休業損害100・慰謝料50＝300万円認容／100万円棄却（＝一部敗訴）→ 確定。
  - 答え：後訴＝介護費用200万円。同じ交通事故（一個の損害賠償債権）の別の費目部分。だから「前訴の既判力・信義則で後訴が止まるか」が問いになる。
- **［入口 2/3・見当づけ］** 後訴を阻む「障害」を2つ ― 見当をつけて
  - 答え：一個の債権を小分けにして何度も訴えると紛争の蒸し返しになる。民訴が後訴を止める道具は大きく既判力（遮断効）と信義則（一般条項）の2つ。この両方を順に当てにいく、と予測しておく。
- **［入口 3/3・論点］** 問題になる論点を挙げて（3つ）
  - 答え：CP①：一個の債権の一部だけを訴求できるか → 一部請求の可否（処分権主義・246条）。（当事者が審判の対象と範囲を決められる原則）
  - 答え：CP②：一部請求の訴訟物は債権全体か、明示部分か → 明示の要否（明示説）。（一部と明示したときだけ訴訟物がその一部に縮む）
  - 答え：CP③：残部（介護費用）に既判力が及ぶか → 既判力の客観的範囲（114Ⅰ）。

### 組み立ての順序（入口の問いのあと、骨子に入る前に読み上げる）

- 順番：第1　第2の訴えと前訴判決の既判力 → 第2　一部認容判決後の残部請求と信義則 → 第3　結論
- 第1　第2の訴えと前訴判決の既判力
  - 論点：一部請求の訴訟物の範囲
- 第2　一部認容判決後の残部請求と信義則
  - 論点1：一部請求敗訴後の残部請求と信義則
  - 論点2：「特段の事情」の意義
- 第3　結論
  - 論点：なし（結論の確認だけ）

この順番の理由（参考。結論・配点には触れず、一言で言い直す）：2つの関門は既判力 → 信義則の順で調べる。まず既判力で遮断されるか（されれば入口＝棄却で終わる）を確定し、遮断されないことを示してから信義則に進む。順序は論理の前提関係で決まる。

- 見出しの補足（結論を含む。項目の終わりに読む）：論点1・前提
1. 訴訟物を債権全体と捉えると既判力（114条1項）で後訴は棄却 → 【論点】一部請求の訴訟物の範囲
2. 規範：明示的一部請求肯定説（明示説） → 一部と明示すれば訴訟物はその一部に限定（最判昭37.8.10）
   - あてはめ：根拠：処分権主義（246条）＋明示を要求して被告の防御上の不利益を防ぐ
3. あてはめ：介護費用200万を除外し400万を請求＝費目限定の明示 → 訴訟物は400万部分に限定
4. 介護費用200万は訴訟物の外 → 残部に既判力なし
- 結論：第2の訴えは既判力に抵触しない

#### 第2　一部認容判決後の残部請求と信義則

- 見出しの補足（結論を含む。項目の終わりに読む）：論点2・本問の山
1. 契機：400万中100万棄却＝一部敗訴が確定 → 【論点】一部請求敗訴後の残部請求と信義則
2. 原則：特段の事情なき限り信義則（2条）違反で却下（最判平10.6.12）
   - あてはめ：理由：債権全部を審理→一部にすら棄却部分→残部不存在と判断済み→蒸し返し・被告の合理的期待・二重応訴
3. 【論点】「特段の事情」の意義 → 審理の範囲が債権全部に及ばなかった事情
4. あてはめ：介護費用は前訴で主張されず審理外 → 特段の事情あり
- 結論：信義則違反なし＝第2の訴えは適法

#### 第3　結論

   既判力にも信義則にも反しない → 第2の訴えは適法・本案で介護費用の存否を審理

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「介護費用200万円を除外した400万円」 → 請求の範囲をどう区切ったか
- 【拾う事実】「300万円の支払いを命じる＝100万円は棄却」 → 前訴の勝ち負け（棄却部分の有無）
- 【拾う事実】『介護費用は前訴で費目として主張されていない』 → 前訴で何が審理されたか
- 【拾う事実】『「この判決の確定後」に新たに提起』 → 前訴がもう確定しているか
- 【拾う事実】『一個の交通事故による損害』 → 同じ債権の別部分か
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 既判力は訴訟物の存否判断にしか生じない。だから訴訟物を「債権全体」と捉えるか「明示された一部」に限るかで、残部への既判力の有無が自動的に決まる。訴訟物の範囲さえ決めれば既判力の射程は出る。
- 【効く事実】あてはめで使う事実
  - 明示あり → 費目を特定して介護費用200万円を除外し400万円を訴求＝費目限定型の明示（最判昭37.8.10）。だから訴訟物は400万円部分に限定され、介護費用200万円は訴訟物の外。114Ⅰの既判力は訴訟物の存否判断にしか生じないから残部に既判力なし＝既判力では遮断されない。
- 【規範の要点】平10判例の規範
  - 一部請求の当否判断には債権全部の審理が必要 → 一部にすら棄却部分があれば残部も不存在と判断されたに等しい → 残部請求は蒸し返しで、被告の合理的期待に反し二重応訴を強いる → 特段の事情なき限り信義則（2条）違反で却下。本問は介護費用が前訴で主張されず審理外＝特段の事情あり → 適法。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 二重フィルターのどちらも通過したら「適法」。最後は却下（訴訟要件の欠缺）でも棄却（既判力抵触）でもなく、本案へと行き先を明示する。処理の問いは「訴え却下／請求棄却／本案審理のどれか」を答えて初めて完結する。
- 【まぎらわしい選択肢・論点】訴えの利益の有無／二重起訴の禁止（142条）／相殺の抗弁と既判力（114Ⅱ）
- 【まぎらわしい選択肢・結論】第2の訴えは既判力に抵触し棄却／第2の訴えは信義則違反で却下
- 【まぎらわしい選択肢・規範】非明示説（訴訟物＝債権全体）／被告帰責性考慮説
- 【まぎらわしい選択肢・事実】前訴で介護費用も審理された／前訴は全部勝訴だった

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

既判力＝明示的一部請求だから訴訟物は400万に限定、残部（介護費用）に既判力及ばず＝遮断されない。信義則＝一部敗訴後の残部請求は特段の事情なき限り信義則違反で却下、だが介護費用は前訴で審理外＝特段の事情あり。結論＝既判力も信義則も通過＝適法、本案で審理。

## 3. 規範クイズ（全2問・1問目から最後まで全部出す）

- **［規範クイズ 1/2］** 数量的一部請求の訴訟物の範囲に関する判例（明示説）の規範を述べよ。
  - 模範解答：一個の債権の数量的な一部についてのみ判決を求める旨を明示して訴えが提起された場合は、訴訟物となるのはその一部の存否のみであって全部の存否ではなく、確定判決の既判力は残部の請求に及ばない（最判昭37.8.10）。この規範の理由は、処分権主義（246条）から当事者が審判対象を切り分けられ、かつ明示を要求すれば被告の防御上の不利益も防げるからである。明示がなければ訴訟物は債権全体に及び、残部は既判力で遮断される。
- **［規範クイズ 2/2］** 平成10年判例が留保する「特段の事情」とは、どのような事情をいうと解されているか述べよ。
  - 模範解答：前訴（一部請求訴訟）における審理の範囲が必ずしも債権全部には及ばなかったような事情をいう。原則で残部請求を封じる根拠が「債権全部が審理された」ことにある以上、その前提が妥当しない場面では信義則違反とはならない、という裏返しの論理。本問の介護費用は前訴で費目として主張されず審理外だから、これに当たる。

## 4. ○×クイズ（全7問・1問目から最後まで全部出す）

- **［○×クイズ 1/7］** 確定判決の既判力は、その客観的範囲に含まれない事項には及ばない。
  - 正解：○（正しい）
  - 理由：既判力は、原則として判決主文に包含される訴訟物たる権利関係の存否の判断にのみ生じる（114条1項）。だから後訴を止めうるかは、まず「前訴の訴訟物が何であったか」を確定することから始まる。これが棚卸しで前訴・後訴を分ける理由。
- **［○×クイズ 2/7］** 前訴判決の既判力によって遮断されない残部請求は、それだけで常に適法であり、信義則（2条）によって制限される余地はない。
  - 正解：×（誤り）
  - 理由：既判力が及ばない場合でも、訴訟追行が信義に反するときは訴えが不適法として退けられうる。既判力（遮断効）と信義則（一般条項）は別個の制限原理で、重畳的に後訴を制限しうる。「既判力で切れないから当然に適法」と即断するのが最大の落とし穴。
- **［○×クイズ 3/7］** 既判力による遮断の効果は請求の棄却（本案判決）であるのに対し、信義則違反による制限の効果は訴えの却下（訴訟要件の欠缺）であり、両者は区別される。
  - 正解：○（正しい）
  - 理由：既判力に抵触する後訴は本案判決として棄却、信義則に反する後訴は訴訟要件を欠く不適法な訴えとして却下される。入口（訴訟要件＝却下）と中身（本案＝棄却）で処理が違うので、どの関門で止めるかによって結論の形が変わる。
- **［○×クイズ 4/7］** 既判力の客観的範囲は、原則として判決主文に包含される訴訟物たる権利関係の存否についての判断に限られる（114条1項）。
  - 正解：○（正しい）
  - 理由：114条1項は「主文に包含するもの」に限り既判力を認める。「主文に包含するもの」＝訴訟物たる権利関係の存否の判断だから、既判力の範囲は訴訟物の範囲と一致する。ゆえに訴訟物に含まれない部分（本問の介護費用）には既判力が及ばない。理由中の判断には原則として既判力は生じない（例外＝相殺の抗弁・114条2項）。
- **［○×クイズ 5/7］** 一個の債権のうち一部であることを明示せずにその一部を請求した場合であっても、訴訟物は現に請求した一部に限定され、残部に既判力は及ばない。
  - 正解：×（誤り）
  - 理由：訴訟物が一部に縮むのは一部であることを明示した場合に限る。明示がなければ訴訟物は債権全体に及び、前訴判決の既判力が債権全体に生じるから、残部請求は既判力で遮断されて棄却される（最判昭32.6.7）。本問は介護費用を除外する費目限定の明示があるから訴訟物は400万円に限定され、この結論にはならない。
- **［○×クイズ 6/7］** 金銭債権の数量的一部請求の訴訟で敗訴した原告が残部請求の訴えを提起することは、特段の事情がない限り、信義則（2条）に反して許されない。
  - 正解：○（正しい）
  - 理由：最判平10.6.12（民訴百選75）の規範。明示的一部請求では既判力は残部に及ばない（論点1）が、一部請求の当否判断には債権全部の審理が必要で、一部にすら棄却部分があれば残部も不存在と判断されたに等しい。ゆえに残部請求は蒸し返しとなり、既判力とは別個に信義則で原則として封じられる。「全部勝訴」ならこの理由は妥当せず原則違反とはならない。
- **［○×クイズ 7/7］** 信義則（2条）に反するとして退けられる残部請求は、前訴判決の既判力に抵触するものとして、本案において請求が棄却される。
  - 正解：×（誤り）
  - 理由：信義則違反は既判力の抵触とは別個の訴訟上の制限であり、効果は本案判決としての棄却ではなく、訴訟要件を欠く不適法な訴えとしての却下である。明示的一部請求では既判力は残部に及ばないから、そもそも「既判力に抵触」はしない。却下（信義則）と棄却（既判力）を混同しないのが本問の要。
