## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

XがYに対して貸金返還請求訴訟を提起した事例を前提に、以下の問いに答えよ。第1問　Xが訴状を裁判所に提出し受理されたが、この時点ですでにYは死亡していた。しかし、訴状および第一回口頭弁論期日呼出状は、Yの唯一の相続人であるZが受領したうえ、口頭弁論にもZがそのまま出席して訴訟行為を行った。ところが、被告の当事者尋問をしようとしたところ、Y本人でないことが判明した。この場合、裁判所はこの訴えをどのように処理すべきか。第2問　前問とは異なり、訴状等の送達を受けたYは、甲弁護士に事件の処理を委任して応訴した。ところが、Yは第三回口頭弁論期日の直後に死亡した。(1)　第四回期日で甲弁護士がY死亡の事実を述べ、裁判所にもこの事実が明らかとなった。本件訴訟手続の進行はどのようになるか。また、当事者は訴訟上どのような手続をとる必要があるか。(2)　甲弁護士がY死亡後もその事実を裁判所およびXに知らせなかったため、裁判所はY死亡を知らないまま、被告をYとしたままX請求を全部認容する判決をした。確定後、相続人ZがXに対し、亡YのXに対する貸金返還債務が不存在であると主張して債務不存在確認の訴えを提起した。この場合、裁判所はこの訴えをどのように処理すべきか。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 第1問＝Xが訴状提出・受理（この時点でY死亡）→ Zが受領・出席・訴訟行為 → 尋問でY本人でないと判明
- 第2問＝Yが送達を受け甲弁護士に委任・応訴 → 審理進行（〜第三回期日）
- 小問(1)＝第三回期日直後にY死亡 → 第四回期日で甲がY死亡を陳述
- 小問(2)＝甲が死亡を秘す → Y表示のまま全部認容判決・確定 → Zが債務不存在確認の訴え提起

登場人物：

- **［入口 2/3・見当づけ］** 各設問が「何を問うているか」 ― 見当をつけて

- **［入口 3/3・論点］** 第1問で問題になる論点を挙げて（3つ）

  - 論点2：訴訟行為の追完（97条）

この順番の理由（参考。結論・配点には触れず、一言で言い直す）：連問は設問の順に。そのうえで各設問内では、必ず原則（死者を被告とする訴え＝却下／係属後死亡＝中断／確定判決＝Zに及ぶ）を先に立て、そこから修正（任意的当事者変更／受継不要・届出／追完の可否）へ進む。

### 骨子（3項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　第1問

- 見出しの補足（結論を含む。項目の終わりに読む）：死者を当事者とする訴えの処理
1. 訴状の被告欄は「Y」→ 【論点】当事者の確定（規範：表示説）→ 被告＝Y

3. 却下は訴訟経済に反する → 【論点】任意的当事者変更（規範：新訴提起＋旧訴取下げの複合）→ 訴状流用・信義則上の追認
4. 当事者の行為を要する → 裁判所は原告Xに変更を促す釈明（149条）

#### 第2　小問(1)

2. 訴訟代理人甲あり → 【論点】中断の例外（規範：124条2項）→ 代理権不消滅（58条1項1号）→ 中断せず続行
3. 死亡時にZが訴訟上の地位を当然承継 → 受継不要

#### 第3　小問(2)

1. 当然承継でZが当事者 → 全部認容判決の効力はZに及ぶ（114条1項・115条1項1号）

2. 前訴で貸金返還請求権の存在が既判力確定 → 【論点】矛盾する後訴の遮断 → 基準時後の新事由なし
3. 【論点】訴訟行為の追完（97条） → 代理人ある以上、手続保障欠如は制度上織り込み済み → 原則否定（特段の事情あれば別論）
- 結論：Zの請求を棄却すべき

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 提訴前に被告が死亡していた訴え（死者を当事者とする訴え）について、裁判所がとるべき処理の流れを順に述べよ。
  - 模範解答：①表示説で被告を確定（本問は被告＝Y）→ ②係属前死亡ゆえ当事者能力なし・訴訟承継なし → ③被告不存在の不適法な訴えとして却下が原則 → ④それでは訴訟経済に反するから任意的当事者変更（新訴提起＋旧訴取下げの複合形態・訴状流用・信義則上の追認）で相続人を当事者に → ⑤当事者の行為を要するから裁判所は原告に変更を促す釈明（149条）にとどまる。
- **［規範クイズ 2/3］** 訴訟係属後・訴訟代理人がある間に当事者が死亡した場合の、①手続の進行 ②当事者がとるべき手続を述べよ。
  - 模範解答：①死亡は中断事由だが、訴訟代理人があるため中断せずそのまま進行する（124条2項・代理権は死亡で消滅しない＝58条1項1号）。相続人は死亡時に訴訟上の地位を当然承継する。②中断していないから受継は不要。もっとも訴訟代理人が中断事由の発生を書面で届け出（民訴規則52条）、当事者の表示を相続人に改める。
- **［規範クイズ 3/3］** 当事者の死亡を看過してされた確定判決につき、①その効力が相続人に及ぶ根拠 ②相続人による訴訟行為の追完（97条）が原則として認められない理由を述べよ。
  - 模範解答：①訴訟代理人があるため中断せず、死亡時に相続人が当然承継して当事者となっている以上、確定判決の効力は当事者である相続人に及ぶ（115条1項1号）。旧当事者の表示は誤記で257条更正の対象にとどまる。②法は訴訟代理人がある場合は中断しないとしており、代理人の不適切な訴訟行為により相続人の手続保障が害される事態は制度上ある程度織り込み済みだから、「責めに帰することができない事由」（97条1項）があるとはいえず追完は原則否定（特段の事情があれば別論）。

## 4. ○×クイズ（全7問・1問目から最後まで全部出す）

- **［○×クイズ 1/7］** 訴訟係属は、原告が被告に対する訴えを提起し、その訴状が被告に送達された時に生ずる（138条参照）。
  - 正解：○（正しい）
  - 理由：訴訟係属（特定の請求につき裁判所に審判が求められ、当事者間で現実に審理が始まる状態）は、訴状が被告に送達された時に生じるため、訴状を裁判所に提出・受理しただけでは係属していない。この「送達＝係属」の時点が、被告の死亡が訴訟承継（124条）の対象となるか否かを分ける分水嶺になる。
- **［○×クイズ 2/7］** 当事者が死亡した場合、訴訟手続はいかなる場合も中断し、相続人が受継の手続をとるまで手続は進行しない。
  - 正解：×（誤り）
  - 理由：当事者の死亡は中断事由だが（124条1項1号）、訴訟代理人があるときは中断しない（124条2項）。代理権は当事者の死亡によっても消滅せず（58条1項1号）、追行の空白が生じないからである。「死亡＝常に中断」と即断しないのが本問の核心。
- **［○×クイズ 3/7］** 被告が訴え提起前にすでに死亡していた場合、その被告は実在せず当事者能力（28条）を欠くため、当該訴えは不適法として却下されるのが原則である。
  - 正解：○（正しい）
  - 理由：当事者能力は実在する者にしか認められず、死者を被告とする訴えは被告不存在の不適法な訴えとして却下が原則。係属中の死亡を前提とする訴訟承継（124条1項1号）も、係属前死亡では適用・類推の基礎を欠く。まずこの原則を立ててから救済（任意的当事者変更）へ進む。
- **［○×クイズ 4/7］** 当事者が誰であるかは、送達・管轄・除斥等の基準となり手続の早期に客観的・画一的に定める必要があるため、訴状の記載を合理的に解釈して確定する（表示説）。
  - 正解：○（正しい）
  - 理由：当事者の確定基準は、原告の内心を基準とする意思説や現実の行動を基準とする行動説ではなく、訴状の記載（134条2項）を合理的に解釈する表示説が通説・実務。送達・管轄・二重起訴等の基準となるため客観性・画一性が要請されるからである。訴状の被告欄に「Y」とあれば、現に出席したZではなくYが被告と確定される。
- **［○×クイズ 5/7］** 訴訟代理人がある間に当事者が死亡し、当然承継により相続人が当事者となった場合、相続人は訴訟を続行するために受継（124条1項）の申立てをしなければならない。
  - 正解：×（誤り）
  - 理由：受継は中断した手続を再開するための手続であり、そもそも中断していない場合には不要。訴訟代理人があるときは中断しない（124条2項）以上、当然承継で相続人が当事者となっても受継の申立ては要らない。もっとも訴訟代理人は中断事由の発生を書面で届け出て（民訴規則52条）、当事者の表示を相続人に改めることになる。
- **［○×クイズ 6/7］** 確定判決の既判力は、原則として判決主文に包含される訴訟物たる権利関係の存否について生じ（114条1項）、当事者間で基準時後に生じた新事由がない限り、これと矛盾する後訴の主張は遮断される。
  - 正解：○（正しい）
  - 理由：既判力の客観的範囲は主文の判断（訴訟物＝本問では貸金返還請求権の存在）に生じる（114条1項）。前訴の口頭弁論終結時（基準時）を標準時として確定されるため、基準時後の新事由（弁済等）がない限り、後訴で請求権の不存在を主張することは既判力に矛盾し遮断される。よって後訴は請求棄却となる。
- **［○×クイズ 7/7］** 訴訟係属は、原告が訴状を裁判所に提出し受理された時点で生じるから、その後に被告が死亡した場合は常に訴訟承継（124条1項1号）の問題となる。
  - 正解：×（誤り）
  - 理由：訴訟係属は訴状の裁判所への提出ではなく、被告への送達によって生じる（138条）。訴状提出後・送達前に被告が死亡していれば、係属はいまだ生じておらず承継すべき地位がないから、訴訟承継（124条1項1号）は働かず、死者を被告とする訴えの処理（却下＋任意的当事者変更）の問題になる。提出時点を係属時と取り違えると、第1問と第2問の分水嶺を見誤る。

## 5. 関連・比較の材料（読み上げない。横断を話すときの正しい名前と一行要旨）

条文番号・判例名・年月日は、ここに書かれているものだけを言う。ここに無い知識は「シート外の補足ですが」と前置きする。

- 【条文】民訴28条（当事者能力） ― 本文当事者能力…は、この法律に特別の定めがある場合を除き、民法その他の法令に従う。
- 【条文】民訴138条（訴えの提起の方式・訴状の送達） ― 1項訴状は、被告に送達しなければならない。
- 【条文】民訴124条（訴訟手続の中断及び受継） ― 1項1号次に掲げる事由があるときは、訴訟手続は中断する。
- 【条文】民訴58条（訴訟代理権の不消滅） ― 1項1号訴訟代理権は、当事者の死亡…によっては、消滅しない。
- 【条文】民訴114条（既判力の客観的範囲） ― 1項確定判決は、主文に包含するものに限り、既判力を有する。
- 【条文】民訴115条（既判力の主観的範囲） ― 1項1号確定判決は、当事者に対してその効力を有する。
- 【条文】民訴257条（更正決定） ― 1項判決に計算違い、誤記その他これらに類する明白な誤りがあるときは、裁判所は、申立てにより又は職権で、いつでも更正決定をすることができる。
- 【条文】民訴97条（訴訟行為の追完） ― 1項当事者がその責めに帰することができない事由により不変期間を遵守することができなかった場合には、その事由が消滅した後1週間以内に限り、不変期間内にすべき訴訟行為の追完をすることができる。
- 【条文】民訴149条（釈明権） ― 1項裁判長は、……訴訟関係を明瞭にするため、事実上及び法律上の事項に関し、当事者に対して問いを発し、又は立証を促すことができる。
- 【判例】大判昭和11年3月11日（死者を当事者とする訴訟） ― 事案すでに死亡していた者を当事者として訴訟手続が進められ、死者名義で判決がされた事案。
- 【判例】最判昭和42年8月25日（訴訟代理人がある間の死亡と判決効） ― 事案訴訟代理人がある間に当事者が死亡し、その死亡を看過して旧当事者を表示したまま判決がされた事案。
- 【用語】本問のキーワード ― 当然承継訴訟係属後に当事者の死亡等の承継原因が生じたとき、新主体（相続人）が当事者の訴訟上の地位を法律上当然に引き継ぐこと。
