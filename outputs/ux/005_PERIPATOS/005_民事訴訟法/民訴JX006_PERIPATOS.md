## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

甲土地を所有するXは、隣接する乙土地を所有するYを被告として、境界確定訴訟（以下「本件訴訟」という。）を提起した。Xは、甲土地と乙土地の境界は、Bの線上であると主張したが、Yは、甲土地の一部をYが時効取得したため、現在の境界線は、Aの線上であると主張した。(1)　Yの主張が認められた場合、Xに本件訴訟の当事者適格が認められるか。(2)　裁判所が境界はCの線上であるとの心証を抱いた場合、どのような判決を下すべきか。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- Xが甲土地所有者としてY（乙土地所有者）に境界確定訴訟を提起
- Xの主張＝境界はB線上
- Yの主張＝甲の一部を時効取得（民法162条）、境界はA線上
- 小問(1)＝Yの主張が認められてもXに当事者適格が残るか
- 裁判所の心証＝C線（双方不主張）／小問(2)＝どんな判決を下すべきか

### 参考（読み上げない。入口の問いの答えを含むので判定にだけ使う）

登場人物：
- X｜甲土地の所有者・原告（→境界はB線と主張）
- Y｜乙土地の所有者・被告（→甲の一部を時効取得・境界はA線と主張）
- A線｜Yの主張（甲が狭い）
- B線｜Xの主張
- C線｜裁判所の心証（双方不主張・XにはBより有利）

一行要約：境界確定訴訟＝形式的形成訴訟（確定するのは筆界）。小問(1)＝Yが甲の一部を時効取得しても、動くのは所有権界だけでXは隣接地所有者＝当事者適格を失わない。小問(2)＝筆界は処分不能で246条・弁論主義の不適用→双方不主張のC線を本案判決で確定。

### 入口の問い（3問）

- **［入口 1/3・事案の整理］** 当事者と「問われている2つの小問」を挙げて
  - 答え：X（甲土地所有者・原告）がY（乙土地所有者・被告）に対して境界確定の訴えを提起。訴訟物は甲乙間の公法上の境界（筆界）の確定。
  - 答え：小問(1)＝Yの時効取得が認められてもXに当事者適格が残るか。小問(2)＝双方不主張のC線で裁判所はどんな判決を下すべきか。
- **［入口 2/3・見当づけ］** 訴訟類型の「性質」 ― 形式的形成訴訟 ― 見当をつけて
  - 答え：境界確定の訴えは、裁判所が法定の基準なしに後見的・裁量的に筆界を定める点で通常の形成訴訟と違う → 形式的形成訴訟とGUESS。ここを固めると、①時効取得に左右されない（小問1）②当事者の主張に拘束されない（小問2）が自動的に流れ出る。
- **［入口 3/3・論点］** 小問(1)の問題になる論点を挙げて（2つ）
  - 答え：CP①：当事者適格の判断基準。通常基準（権利帰属主体）が使えない → 機能的基準＝相隣接地の各所有者が最も密接な利害を有する者。
  - 答え：CP②：Yの時効取得は適格を奪うか → 筆界と所有権界の区別。動くのは所有権界だけ・一部なら隣接地所有者の地位は残る。

### 骨子（3項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　共通の前提　境界確定の訴えの性質

1. 【論点】境界確定の訴えの法的性質 → 規範：形式的形成訴訟（法定基準なし・後見的裁量）
2. 確定するのは筆界（公法上の境界）＝所有権界（私法上）と区別・当事者は処分不能
- 結論：以後の2小問はこの性質から演繹

#### 第2　小問(1)　Xの当事者適格

1. 【論点】当事者適格の判断基準 → 規範：機能的基準（訴訟追行・本案判決が必要かつ有意義か） → 相隣接地の各所有者
2. 【論点】一部時効取得と当事者適格 → 時効取得が動かすのは所有権界のみ・筆界は不動
   - あてはめ：甲の「一部」にとどまる → Xはなお甲地の隣接地所有者（全部取得なら適格喪失＝射程の限界）
- 結論：X は 当事者適格を失わない

#### 第3　小問(2)　下すべき判決

- 見出しの補足（結論を含む。項目の終わりに読む）：246条・弁論主義の不適用
1. 【論点】双方不主張のC線と処分権主義（246条） → 規範：筆界は処分不能＝246条の前提を欠き不適用
2. 【論点】弁論主義の適用の有無 → 同じ理由で不適用（C線の基礎事実も双方不主張でよい）
3. 判決の形式 → 請求棄却でなく正当と認める境界を定める本案判決

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「境界確定訴訟」 → 訴訟類型の性質決定（形式的形成訴訟）＝全論点の前提
- 【拾う事実】「甲土地の一部を時効取得」 → 「一部」か「全部」か＝当事者適格の分かれ目／動くのは所有権界だけ
- 【拾う事実】「現在の境界線はA線上」 → 時効取得が筆界まで動かすかという混同（小問1の罠）
- 【拾う事実】「CはX・Y双方が主張していない」 → 申立て・主張への不拘束＝246条・弁論主義の不適用（小問2）
- 【拾う事実】「CはBよりXに有利」 → 原告の主張を超える認定の可否＝処分権主義不適用の帰結
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 通常訴訟なら適格は「訴訟物たる権利の帰属主体」で決まる。だが形式的形成訴訟ではその基準が使えない→ 機能的基準（誰に訴訟追行させ本案判決するのが紛争解決に必要かつ有意義か）に組み替える。ここが最初のチェックポイント。
- 【効く事実】「筆界と所有権界の区別」のあてはめで使う事実
  - 時効取得の対象＝甲土地の「一部」（全部ではない）／ゆえにXはなお甲地の所有者たる地位を保持＝X・Yは依然として相隣接地の各所有者。「一部」を見落として全部喪失と短絡すると大幅失点。事実は必ず評価語（「隣接地所有者の地位に変わりはない」）と結合させる。
- 【規範の要点】246条不適用の規範
  - 246条は処分しうる権利関係を審判対象とすることを前提に、審判範囲の設定を当事者に委ねる規定。境界確定の訴えが確定する筆界は当事者が処分できない公的事項だから前提を欠き、裁判所は当事者の主張に拘束されず自ら正当と認める境界を確定できる（最判昭38.10.15）。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 形式的形成訴訟では、裁判所は請求の当否を判断するのではなく正当と認める境界を確定する本案判決を下す。Xの主張が容れられないことを理由に請求棄却にしないのが肝。余力があれば共有地の場合（固有必要的共同訴訟・最判昭46.12.9）や筆界特定制度（不登法123条以下）へ一言。
- 【まぎらわしい選択肢・論点】訴えの利益の有無／既判力の客観的範囲
- 【まぎらわしい選択肢・結論】当事者適格を失う（訴え却下）／請求棄却判決を下す
- 【まぎらわしい選択肢・規範】確認訴訟説／通常の形成訴訟
- 【まぎらわしい選択肢・事実】甲土地の全部を時効取得／弁論主義の適用あり

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

性質＝境界確定の訴え＝形式的形成訴訟、確定するのは筆界。小問(1)＝適格は機能的基準で相隣接地の各所有者、時効取得が動かすのは所有権界だけ・一部なら隣接地所有者の地位は残り適格を失わない（全部なら失う）。小問(2)＝筆界は処分不能で246条の前提を欠く＝処分権主義も弁論主義も不適用、裁判所は双方不主張のC線を本案判決で確定する（請求棄却にしない）。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 境界確定の訴えにおける当事者適格の判断基準と、適格を有する者を述べよ。
  - 模範解答：訴訟物たる権利の帰属主体という通常の基準によらず、何人に訴訟を追行させ、何人に対し本案判決をすることが紛争解決にとって必要かつ有意義かの観点から定める。そのうえで相隣接する土地の各所有者が、境界を確定するについて最も密接な利害を有する者として当事者適格を有する（最判平7.3.7）。
- **［規範クイズ 2/3］** 境界確定の訴えに処分権主義（246条）の適用があるか。理由（なぜ前提を欠くか）とともに述べよ。
  - 模範解答：適用なし。246条（処分権主義）は、審判対象が当事者の処分しうる権利関係であることを前提に審判範囲の設定を当事者に委ねる規定である。境界確定の訴えが確定する筆界は公法上の事項で当事者が処分できず、処分権主義の前提を欠く。ゆえに裁判所は当事者の主張に拘束されず、自ら正当と認める境界を確定すべきである（最判昭38.10.15。旧民訴法186条）。
- **［規範クイズ 3/3］** 境界確定の訴えに弁論主義の適用はあるか。C線を基礎づける具体的事実も当事者双方が主張していない場合の処理とあわせて述べよ。
  - 模範解答：適用なし。処分権主義の不適用と同じ理由（筆界は裁判所が職権で確定すべき公的事項）から、裁判所は当事者が主張しない事実をも基礎として正当と認める境界を確定できる（最判昭43.2.22）。したがってC線を基礎づける事実が双方不主張でも、職権で資料を斟酌してC線を確定することが妨げられない。
