## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

甲は、乙の自動車に放火しようと考え、乙の居住するマンションの住民専用の駐車場に駐車されていた乙所有の自動車（以下「乙車」という。）に約1.5リットルのガソリンを車体全体にかけた上で、ガスライターで点火した。当時、乙車は、十分な量のガソリンを積載していた。乙車の周辺には、乙以外の者の所有する自動車が2台停められており、また、マンション住民が捨てるゴミ集積場が設置されており、同所には可燃性のゴミ約300キログラムが置かれていた（以下、2台の自動車とゴミ集積場及び集積場内のゴミを合わせて「本件周辺物」という。）。一方、乙の居住するマンションを含め、人が立ち入る建造物等からは少なくとも20メートル以上離れていた。甲は、本件周辺物が乙車から数メートル離れていたことから、乙車に火をつけても本件周辺物に延焼することはないだろうと思っていた。しかし、現実には、給油口内のプラスチック樹脂製の給油キャップ等に引火し、更にガソリンタンク内の気化ガスに引火する等してタンクが爆発するおそれがあり、そうなれば、本件周辺物にも延焼するおそれはあった。甲が点火して立ち去った後、乙車が数か所にわたって炎が上がり、その炎の幅は約10センチメートル、高さは約30センチメートルであったところを管理人が発見し、消防士らの消火活動により鎮火した。甲の罪責について、論じなさい。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 甲、乙車に放火を決意
- 乙車にガソリン1.5Lをかけガスライターで点火
- 甲は「本件周辺物に延焼しない」と予想（現実にはタンク爆発・延焼のおそれ）
- 乙車が数か所で独立燃焼（炎 幅約10cm・高さ約30cm）
- 管理人が発見、消防士の消火活動で鎮火（建造物等への延焼なし）

### 参考（読み上げない。入口の問いの答えを含むので判定にだけ使う）

登場人物：
- 甲｜放火行為者（→乙車に放火・焼損）
- 乙車｜乙＝他人所有の自動車＝110条1項の客体
- 本件周辺物｜他人の自動車2台＋ゴミ300kg＝財産危険の対象
- 建造物等｜20m以上離隔＝危険なし・対象外

### 入口の問い（3問）

- **Q01［事案の整理］** 行為・客体・結果を棚卸しする
  - 答え：行為＝乙車にガソリンをかけ点火。客体＝乙車（他人所有の建造物等以外の物）。結果＝乙車が独立燃焼＋本件周辺物（財産）への延焼のおそれ。
  - 答え：危険の対象を切り分けると、建造物等は20m離隔で危険なし／人の生命身体も危険なし／財産（自動車2台・ゴミ）にのみ危険。ここを最初に握るのが第一歩。
- **Q02［見当づけ］** 「何罪っぽい？」 ― 見当をつけて
  - 答え：客体＝建造物等以外の物（自動車）で、現に人が住む建造物（108条）でも非現住建造物（109条）でもない → 建造物等以外放火罪（110条1項）系。乙＝他人所有なので1項（他人所有）。
- **Q03［論点］** 問題になる論点を挙げて（2つ）
  - 答え：CP①：建造物等への危険なし・財産への危険のみ → 「公共の危険」の意義（財産危険を含むか・不特定・規模）。（不特定＝偶然その場に存在／規模＝財産のみへの危険のとき必要）
  - 答え：CP②：甲は「延焼しない」と認識 → 公共の危険発生の認識の要否（故意）。（不要説＝「よって」＝結果的加重犯類似で認識不要）

### 骨子（3項目。第1から【論点】ごとに、何が問題→規範→使う事実→結論 の順で組み立てる）

#### 第1　放火・客体・焼損

- 見出しの補足（結論を含む。項目の終わりに読む）：前提・一言
1. 乙車に点火＝「放火」／乙車＝他人所有の建造物等以外の物
2. 数か所で独立燃焼 → 独立燃焼説で「焼損」＝一言で通過
- 他人所有建造物等以外放火罪（110条1項）の客観面・前半

#### 第2　「公共の危険」の意義

- 見出しの補足（結論を含む。項目の終わりに読む）：本丸・110条1項
1. 建造物等20m離隔・人も危険なし → 財産への危険のみと特定
2. 【論点】財産への危険で公共の危険を肯定できるか → 非限定説（財産危険も含む）
3. 自動車2台＝多数否定 → 【論点】「不特定」の意義 → 偶然性で肯定（ゴミは財産と言い難い）
4. 財産のみへの危険 → 【論点】「規模」を要するか → 要する（毀棄罪との刑の均衡）
   - あてはめ：タンク爆発のおそれ・ゴミ300kg・炎の幅高さ・住民専用駐車場で一般人基準に肯定
- 結論：公共の危険の発生を肯定

#### 第3　認識の要否

- 見出しの補足（結論を含む。項目の終わりに読む）：故意・38条1項
1. 甲は「延焼しない」＝公共の危険発生の認識なし
2. 【論点】公共の危険発生の認識は故意に必要か → 必要説（責任主義）に一言触れ → 不要説（「よって」＝結果的加重犯類似）
3. 放火・焼損の認識あり → 故意阻却されず
- 結論：他人所有建造物等以外放火罪 成立

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】『建造物等から20m以上離隔』 → 建造物危険を否定＝財産危険に絞る
- 【拾う事実】『他人所有の自動車2台が偶然駐車』 → 多数否定・不特定（偶然性）
- 【拾う事実】『タンク爆発のおそれ・ゴミ約300kg』 → 規模の認定材料
- 【拾う事実】『炎 幅約10cm・高さ約30cm／住民専用駐車場』 → 規模・一般人基準の材料
- 【拾う事実】「延焼することはないだろう」 → 公共の危険発生の認識なし（論点2）
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 放火＝点火／客体＝乙車は建造物等以外の物／焼損＝独立燃焼＝一言で素通り。詰まるのは「よって公共の危険」と「故意」の2か所だけ。ここに筆力を集中する。
- 【効く事実】「タ・フ・キ」のあてはめで使う事実
  - 不特定 → 自動車2台が偶然そこに駐車（多数とは言い難いが偶然性で拾う）／規模 → タンク爆発のおそれ・ゴミ約300kg・炎の幅10cm高さ30cm・住民専用駐車場。
- 【規範の要点】不要説の規範
  - 責任主義から必要説もあるが、110条1項は「よって」の文言を用い結果的加重犯であることが明らかだから、公共の危険発生の認識は不要（最判昭60.3.28）。放火・焼損の認識があれば故意は阻却されない。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 放火罪が成立すれば、乙車の毀棄は放火罪に吸収され、器物損壊罪（261条）を別建てしない。なお規模要件は「110条の刑が毀棄罪より重いこととの均衡」から来る ── 毀棄との比較は罪数ではなく規模要件の根拠として効く。
- 【まぎらわしい選択肢・論点】正当防衛の成否／公共の危険の認識は不要か／効用喪失説か独立燃焼説か
- 【まぎらわしい選択肢・結論】器物損壊罪のみ成立／放火罪不成立（限定説）
- 【まぎらわしい選択肢・規範】限定説／規模不要説
- 【まぎらわしい選択肢・事実】多数の財産への危険／建造物への延焼の危険

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

放火焼損＝独立燃焼で一言。公共の危険＝建物危険なし・財産のみ、多数否定・不特定（偶然）で拾って、財産のみだから規模で締める。認識＝「よって」の結果的加重犯だから不要、故意阻却されず。結論＝110条1項成立。

## 3. 規範クイズ（2問）

- **Q04［規範］** 判例（独立燃焼説）における「焼損」の意義を述べよ。
  - 模範解答：火が媒介物を離れ、目的物が独立して燃焼を継続する状態に達したこと（独立燃焼説）。効用喪失までは不要。本問は数か所で炎を上げ独立燃焼＝焼損あり。
- **Q05［規範］** 危険が財産のみに及ぶ場合に、不特定・多数を満たしてもなお要求される要件と、その理由を述べよ。
  - 模範解答：一定の規模の危険性の発生。理由は、毀棄罪（261条）より重い110条1項の刑との均衡。財産のみへの危険を見たら反射的に「規模」を立てる。これを落とすのが本問最頻出の失点。

## 4. ○×クイズ（5問）

- **Q06［○×］** 放火罪の保護法益は、不特定又は多数の人の生命・身体・財産という公共の安全であり、放火罪は公共危険罪である。
  - 正解：○（正しい）
  - 理由：放火罪は火の伝播性・拡散性ゆえ、個人の財産（毀棄罪）ではなく公共の安全を保護法益とする公共危険罪。この性格が、財産への危険でも「公共の危険」を基礎づけうる出発点となる。
- **Q07［○×］** 建造物等以外放火罪（110条1項）は、108条・109条1項（抽象的危険犯）と異なり、「公共の危険」の発生を要件とする具体的危険犯である。
  - 正解：○（正しい）
  - 理由：108条・109条1項は公共の危険が擬制される抽象的危険犯だが、110条（と109条2項）は「よって公共の危険を生じさせた」ことを要件とする具体的危険犯。だから本問は公共の危険の発生を正面から論じる必要がある。
- **Q08［○×］** 延焼の危険が及ぶ財産が少数（自動車2台）であっても、それが偶然その場に存在したのであれば「多数」の財産への危険として公共の危険を肯定できる。
  - 正解：×（誤り）
  - 理由：自動車2台では「多数」とはいえないから、この偶然性で満たせるのは「多数」ではなく「不特定」の要件である。偶然その場に駐車していたことは客体の不特定性を基礎づける事情にすぎず、多数性とは区別する。本問は不特定（偶然性）で公共の危険を肯定し、用語のすり替えを避ける。
- **Q09［○×］** 判例（不要説）によれば、110条1項の放火罪が成立するには放火・焼損の認識があれば足り、公共の危険を発生させることまでの認識は不要である。
  - 正解：○（正しい）
  - 理由：最判昭60.3.28は不要説。「火を放って所定の物を焼燬する認識」で足り、公共の危険発生の認識は不要とする。甲は公共の危険の認識を欠くが、放火・焼損の認識があるから故意は阻却されない。
- **Q10［○×］** 放火罪が成立する場合、目的物を損壊した点（毀棄）は放火罪に吸収され、別途器物損壊罪を成立させる必要はない。
  - 正解：○（正しい）
  - 理由：放火行為は当然に目的物の毀棄を伴うから、放火罪が成立すれば毀棄の点はこれに吸収される。器物損壊罪を別に立てない。仮に公共の危険が認められず放火罪が不成立なら、器物損壊罪にとどまる。
