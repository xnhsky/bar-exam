### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「相続によりAの財産を得よう」 → → 殺害が財産取得と結合＝重い罪を疑う合図
- 【拾う事実】「1000万円を支払う意思はなかった」 → → 甲とBの財産関係を整理する材料
- 【拾う事実】「Cは…計画を自分で考えた上で」 → → 甲の関与形態の評価に直結
- 【拾う事実】「500万円を払うのも惜しくなった」 → → C殺害の動機＝支払を免れる
- 【拾う事実】「毒薬の入ったお茶を飲ませて」 → → 暴行の認定事実
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 暴行＝包丁での刺殺／毒殺で○／結果＝死亡で○／故意＝計画的・確定的殺意で○。立ち止まるのは「財産上の利益」性（A・C）と関与形態（B）だけ。
- 【規範の要点】限定の規範
  - 「財産上の利益」は無限定に広がりうるため、これを限定しないと財産動機の殺人がすべて強盗殺人化し単純殺人との区別を失う。そこで暴行・脅迫から利益が直接かつ具体的に移転する場合に限り二項強盗を認める。
- 【規範の要点】2つの規範
  - ①処分行為は不要だが、被害者の死亡により債務の追及が事実上不可能・著しく困難になることを要する。②財産犯の保護法益は事実上の財産的秩序であり、民事上保護されない利益でも刑法上の保護を否定しない。
- 【ポイント】ここで効く対比
  - 論点A（相続）は移転の直接性なしで否定したのに、論点C（債務免脱）は追及不能で肯定する。「同じ二項強盗の枠で結論が分かれる理由」を移転の直接性・追及不能の有無で説明できると上位答案。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 各被害者ごとに罪が成立したら最後に罪数処理を一言。被害者（法益主体）を異にする故意犯は原則別個の犯罪＝併合罪（45条前段）。観念的競合となる事情がなければ一文で締める。
- 【まぎらわしい選択肢・論点】因果関係の錯誤／不能犯の成否
- 【まぎらわしい選択肢・規範】処分行為必要説／狭義の従属性説
- 【まぎらわしい選択肢・事実】先行行為による排他的支配／具体的謀議あり
- 【まぎらわしい選択肢・結論】強盗致死罪 不成立／傷害致死罪 成立

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

A＝相続目的の刺殺→二項強盗を疑うが相続利益は直接移転せず否定→殺人罪（199条）。B＝甲は依頼のみ・Cが自律的に実行＝謀議なし→共同正犯不成立、殺人の教唆（199条・61条1項）。C＝報酬支払を免れる毒殺→処分行為不要説＋追及不能、不法原因債権も民刑分離で保護→二項強盗殺人（240条後段・236条2項）。罪数＝被害者を異にする3罪で併合罪（45条前段）。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 二項強盗（236条2項）の「財産上の利益」をめぐる限定規範を、理由とあわせて一文で書け。
  - 模範解答：模範「財産上の利益」は概念上無限定に広がり単純殺人との区別を失うため、暴行・脅迫から利益が直接かつ具体的に移転する場合に限り二項強盗を認める。
- **［規範クイズ 2/3］** 共同正犯（60条）と教唆犯（61条1項）を分ける判断基準を挙げよ。
  - 模範解答：模範共謀（謀議＝具体的計画の共同立案）の有無・正犯意思・役割の重要性で区別する。これらを備えれば共同正犯、犯意を生じさせたにとどまれば教唆犯。
- **［規範クイズ 3/3］** 民事上無効な不法原因債権を、刑法が「財産上の利益」として保護する理由づけを書け。
  - 模範解答：模範財産犯の保護法益は事実上の財産的秩序の維持にあり、民事法上の権利の有無に必ずしも依存しない。よって民事上保護されない利益でも刑法上の保護を否定すべきでない（民刑の保護範囲の分離）。

## 4. ○×クイズ（全12問・1問目から最後まで全部出す）

- **［○×クイズ 1/12］** 生命・身体といった一身専属的な個人的法益に対する罪は、原則として被害者（法益主体）ごとに別個に成立する。
  - 正解：○（正しい）
  - 理由：個人的法益は被害者に専属するため、複数人が死傷すれば原則として法益主体の数だけ罪が成立する。だから複数の死亡結果は被害者ごとに切り分けて構成要件該当性を立てる（混ぜると罪数を誤る）。
- **［○×クイズ 2/12］** 単独行為者の罪責が問われた事案では、被害者や第三者が犯した行為（恐喝・実行行為など）も、その者の罪責として論じなければならない。
  - 正解：×（誤り）
  - 理由：問われた者の罪責だけを論じる。他者の行為は、問われた者の罪名選択・関与形態の評価材料として使うにとどめる。
- **［○×クイズ 3/12］** 強盗殺人罪（240条後段）は強盗罪を前提とする加重類型であり、その成立にはまず前提となる強盗罪（1項・2項）が成立していることを要する。
  - 正解：○（正しい）
  - 理由：240条は「強盗が…死亡させた」と規定する強盗の加重類型。前提の強盗（二項なら236条2項）が成立しなければ240条後段も成立しない。だから財産動機の殺害ではまず二項強盗の成否を検討し、それが落ちれば単純殺人へ落とす。
- **［○×クイズ 4/12］** 財産取得の動機がある殺害は、その動機の存在だけで当然に二項強盗殺人罪が成立する。
  - 正解：×（誤り）
  - 理由：動機があるだけでは足りない。前提の二項強盗（暴行・脅迫＋「財産上の利益」の取得＋利益移転）を満たすかを吟味し、満たさなければ単純殺人に落とす。
- **［○×クイズ 5/12］** 二項強盗罪（236条2項）の成立要件は、①暴行・脅迫、②財産上の利益の取得、③両者の因果（利益移転）である。
  - 正解：○（正しい）
  - 理由：1項強盗の「財物」が「財産上の利益」に置き換わる。利益移転（因果）に直接性・具体性を要求するのが判例・通説。
- **［○×クイズ 6/12］** 二項強盗の「財産上の利益」を限定せず広く認めると、財産取得を動機とする殺人がすべて強盗殺人に転化し、単純殺人罪との区別を失うおそれがある。
  - 正解：○（正しい）
  - 理由：この限定の必要性こそ規範を立てる理由。だから利益移転の直接性・具体性を要求する。
- **［○×クイズ 7/12］** 二項強盗の「財産上の利益」の移転は、暴行・脅迫の結果として利益を取得しうる事実上の可能性や期待が生じれば足り、別途の手続を経て初めて利益が確定する場合でも認められる。
  - 正解：×（誤り）
  - 理由：要求されるのは暴行・脅迫からの直接かつ具体的な利益移転であり、取得の可能性・期待にとどまるものや別途の手続を経て初めて確定する利益では足りない。可能性で足りるとすれば限定の意味が失われる。
- **［○×クイズ 8/12］** 共同正犯（60条）の成立には、関与者間に共同実行の意思（具体的な意思連絡・謀議）が必要であり、実行担当者が単独で計画を立て実行した場合はこれを欠く。
  - 正解：○（正しい）
  - 理由：謀議＝具体的計画の共同立案が共謀の核。これを欠けば共同正犯ではなく、犯意を生じさせた者は教唆犯。
- **［○×クイズ 9/12］** 他人に犯罪の実行を依頼して報酬を約束すれば、それだけで常に共同正犯（60条）が成立する。
  - 正解：×（誤り）
  - 理由：依頼にとどまり実行を支配せず、計画立案にも関与しなければ、正犯意思・役割の重要性を欠き教唆犯にとどまる。
- **［○×クイズ 10/12］** 二項強盗罪が成立するには、つねに被害者による財産的処分行為が必要である。
  - 正解：×（誤り）
  - 理由：1項強盗が処分行為を要しないこととの均衡上、処分行為は不要と解する（処分行為を要求すると殺害事案で観念できず不当な不処罰を招く）。代わりに追及不能等で限定する。
- **［○×クイズ 11/12］** 財産犯の保護法益を事実上の財産的秩序と捉えれば、不法契約に基づき民事上は無効な債権（公序良俗違反・民法90条）であっても、刑法上は「財産上の利益」として保護されうる。
  - 正解：○（正しい）
  - 理由：判例は民事の無効に引きずられず、財産的秩序の維持を重視して保護を肯定（民刑の保護範囲の分離）。なお保護否定の有力説もあり、自説を理由づければ可。
- **［○×クイズ 12/12］** 被害者を異にする複数の故意の殺害（・関与）は、原則として別個の犯罪として併合罪（45条前段）になる。
  - 正解：○（正しい）
  - 理由：法益主体（被害者）ごとに別罪。観念的競合となる事情がなければ併合罪で一文処理。
