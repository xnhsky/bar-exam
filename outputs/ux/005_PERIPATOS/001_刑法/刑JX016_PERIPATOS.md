### 問題文（最初にゆっくり読み上げる）

甲は、Aを殺害しようと考え、景気づけに酒を飲んでから、A宅へ向かった。甲は、飲酒をすれば病的な酩酊状態に陥ることを自覚していた。甲は、A宅に立ち入り、Aに向けて拳銃を発射したところ、Aのみならず、その場にいたBにも当たり、Aを死亡させ、Bには全治約1か月の怪我を負わせた。その後、その場にあったAの財布を手に取り、A宅を出た。甲は、A宅内に立ち入った時点ではいまだ意識があったが、その後、Aを殺害しBに怪我を負わせるまでの間、飲酒による酩酊状態にあり、心神喪失状態であった。甲の罪責を論ぜよ。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 飲酒（殺意あり・責任能力あり・酩酊を自覚）

- 拳銃発射→A死亡・B負傷（心神喪失）

登場人物：
- 甲｜行為者（飲酒→心神喪失下で発射・殺害後に財布奪取）

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「Aを殺害しようと考え」 → ＝原因行為時の殺意
- 【拾う事実】「病的な酩酊に陥ると自覚」 → ＝自招性
- 【拾う事実】「までの間…心神喪失」 → ＝喪失は殺害〜負傷に限定
- 【拾う事実】「その場にあったAの財布」 → ＝死亡後の奪取
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 殺人の客観（発射→A死亡→因果）も故意（「殺害しようと考え」）も問題なし＝一文で通過。違法性も阻却事由なし＝一言。止まるのは責任（心神喪失）の所。
- 【規範の要点】責任モデルの規範
  - 責任の本質＝非難可能性。責任能力ある状態の意思決定が結果行為まで貫かれ、原因行為・結果行為・結果に因果関係があれば、全体を一個の行為として完全責任を問える → 39条1項の適用排除。
- 【効く事実】「原因において自由な行為（）」のあてはめで使う事実
  - 意思の連続 → 「Aを殺害しようと考え」飲酒し、殺意を維持したまま発射／自招性 → 「飲酒すれば病的酩酊に陥ると自覚」／因果 → 飲酒→発射→A死亡の連鎖。
- 【規範の要点】「死者の占有・方法の錯誤」の規範
  - 強盗罪が成立するには、暴行・脅迫が財物奪取に向けられたものでなければならない。殺害時に領得意思がなく、殺害後に初めて奪取意思が生じた場合は、殺害行為を強取手段とは評価できず、強盗殺人罪は成立しない。
- 【規範の要点】「死者の占有・方法の錯誤」の規範
  - 死者に占有はない（占有＝事実的支配＋意思）。もっとも自ら殺害した犯人との関係では、殺害から奪取までの一連の行為を全体的に考察し、被害者の生前占有を侵害したと評価できる → 窃盗罪。第三者の死後奪取は占有離脱物横領にとどまる。
- 【規範の要点】「死者の占有・方法の錯誤」の規範
  - 法定的符合説：認識と結果が「人」という構成要件の範囲内で符合すれば故意あり。故意を構成要件の範囲で抽象化する以上数故意犯説で個数を問わず、A殺人既遂とB殺人未遂が併存。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり

- 【まぎらわしい選択肢・論点】不真正不作為犯の実行行為性／正当防衛の成否／抽象的事実の錯誤／承継的共同正犯
- 【まぎらわしい選択肢・規範】具体的符合説／間接正犯類似説で実行行為性
- 【まぎらわしい選択肢・事実】殺害目的での財物奪取／第三者による死後の持ち去り
- 【まぎらわしい選択肢・結論】強盗殺人罪 成立／占有離脱物横領罪 成立／過失致傷罪にとどまる

- 【学説】数故意犯説（法定的符合説内部） ― 故意の対象を構成要件の範囲で抽象化する以上、故意の個数は問題とならず、認識客体・発生客体の双方に故意犯が成立しうる論拠抽象化の論理的帰結／法益保護の徹底↩ 解法ナビ STEP 5′ へ戻る
