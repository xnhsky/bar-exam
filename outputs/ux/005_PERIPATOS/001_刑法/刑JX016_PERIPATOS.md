### 問題文（最初にゆっくり読み上げる）

甲は、Aを殺害しようと考え、景気づけに酒を飲んでから、A宅へ向かった。甲は、飲酒をすれば病的な酩酊状態に陥ることを自覚していた。甲は、A宅に立ち入り、Aに向けて拳銃を発射したところ、Aのみならず、その場にいたBにも当たり、Aを死亡させ、Bには全治約1か月の怪我を負わせた。その後、その場にあったAの財布を手に取り、A宅を出た。甲は、A宅内に立ち入った時点ではいまだ意識があったが、その後、Aを殺害しBに怪我を負わせるまでの間、飲酒による酩酊状態にあり、心神喪失状態であった。甲の罪責を論ぜよ。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 飲酒（殺意あり・責任能力あり・酩酊を自覚）

- 拳銃発射→A死亡・B負傷（心神喪失）

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「Aを殺害しようと考え」 → ＝原因行為時の殺意
- 【拾う事実】「病的な酩酊に陥ると自覚」 → ＝自招性
- 【拾う事実】「までの間…心神喪失」 → ＝喪失は殺害〜負傷に限定
- 【拾う事実】「その場にあったAの財布」 → ＝死亡後の奪取
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 殺人の客観（発射→A死亡→因果）も故意（「殺害しようと考え」）も問題なし＝一文で通過。違法性も阻却事由なし＝一言。止まるのは責任（心神喪失）の所。
- 【規範の要点】責任モデルの規範
  - 責任の本質＝非難可能性。責任能力ある状態の意思決定が結果行為まで貫かれ、原因行為・結果行為・結果に因果関係があれば、全体を一個の行為として完全責任を問える → 39条1項の適用排除。
- 【効く事実】「原因において自由な行為（）」のあてはめで使う事実
  - 意思の連続 → 「Aを殺害しようと考え」飲酒し、殺意を維持したまま発射／自招性 → 「飲酒すれば病的酩酊に陥ると自覚」／因果 → 飲酒→発射→A死亡の連鎖。
- 【規範の要点】「死者の占有・方法の錯誤」の規範
  - 強盗罪が成立するには、暴行・脅迫が財物奪取に向けられたものでなければならない。殺害時に領得意思がなく、殺害後に初めて奪取意思が生じた場合は、殺害行為を強取手段とは評価できず、強盗殺人罪は成立しない。
- 【規範の要点】「死者の占有・方法の錯誤」の規範
  - 死者に占有はない（占有＝事実的支配＋意思）。もっとも自ら殺害した犯人との関係では、殺害から奪取までの一連の行為を全体的に考察し、被害者の生前占有を侵害したと評価できる → 窃盗罪。第三者の死後奪取は占有離脱物横領にとどまる。
- 【規範の要点】「死者の占有・方法の錯誤」の規範
  - 法定的符合説：認識と結果が「人」という構成要件の範囲内で符合すれば故意あり。故意を構成要件の範囲で抽象化する以上数故意犯説で個数を問わず、A殺人既遂とB殺人未遂が併存。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 複数の罪が成立したら最後に罪数処理を一言。観念的競合（54条前段）／牽連犯（54条後段）／併合罪（45条）のどれかを示す。住居侵入のように複数罪と牽連でつながる前提行為があれば、それが「かすがい」となって全体が科刑上一罪に束ねられる。
- 【まぎらわしい選択肢・論点】不真正不作為犯の実行行為性／正当防衛の成否／抽象的事実の錯誤／承継的共同正犯
- 【まぎらわしい選択肢・規範】具体的符合説／間接正犯類似説で実行行為性
- 【まぎらわしい選択肢・事実】殺害目的での財物奪取／第三者による死後の持ち去り
- 【まぎらわしい選択肢・結論】強盗殺人罪 成立／占有離脱物横領罪 成立／過失致傷罪にとどまる

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

## 3. 規範クイズ（4問）

- **Q04［規範］** 原因において自由な行為で完全責任を基礎づける「責任モデル」の規範を、自分の言葉で書き出してみよう。
  - 模範解答：責任の本質は非難可能性。責任能力ある状態での意思決定が結果行為まで連続し、原因行為・結果行為・結果に因果関係があれば、全体を一個の行為として完全責任を問える（→39条1項の適用排除）。
- **Q05［規範］** 殺害後に初めて領得意思が生じた場合に強盗殺人罪を否定する理由を、「暴行・脅迫の向けられ先」から一文で書けるか。
  - 模範解答：強盗罪の暴行・脅迫は財物奪取に向けられたものである必要があるため、殺害時に領得意思がなく、殺害後に初めて奪取意思が生じたときは、殺害行為を強取手段と評価できず、強盗殺人罪は成立しない。
- **Q06［規範］** 死者の財物を奪った行為を「窃盗」と評価する判例の規範（キーワードを含めて）を書き出してみよう。
  - 模範解答：死者に占有はないが、自ら殺害した犯人との関係では、殺害から財物奪取までの一連の行為を全体的に考察し、被害者の生前の占有を侵害したと評価できる（最判昭41.4.8）。
- **Q07［規範］** Aを狙った弾がBに当たった方法の錯誤で、法定的符合説・数故意犯説から故意をどう処理するか、結論まで書けるか。
  - 模範解答：認識した内容と発生した事実が「人」という構成要件の範囲内で符合する以上、Bに対する殺意も認められる。さらに故意の個数は問わないため、Aに対する殺人既遂とBに対する殺人未遂が併存する。

## 4. ○×クイズ（14問）

- **Q08［○×］** 「甲の罪責を論ぜよ」と問われたとき、甲に撃たれて死傷した被害者も罪責の検討主体に含めるべきだ。
  - 正解：×（誤り）
  - 理由：検討するのは「犯罪になりうる行為をした人」だけ。被害者は対象外。まず行為者の行為を時系列で全部出す。
- **Q09［○×］** 一人の行為者でも、行為の時点ごとに責任能力の有無が変わりうるので、各行為にその有無のタグを付けて整理するとよい。
  - 正解：○（正しい）
  - 理由：責任能力は行為時を基準に判断する。時点で変動するなら各行為ごとに仕分けるのが後の検討（とくに心神喪失）で効く。
- **Q10［○×］** 人を殺害した後に初めて領得意思が生じてその財物を奪った場合は、強盗殺人罪ではなく窃盗罪等の財産犯を疑うのが筋である。
  - 正解：○（正しい）
  - 理由：強盗殺人の「暴行」は財物奪取に向けられたものを要する。殺害が財物目的でないなら強盗殺人を否定し、財産犯を別途検討する。
- **Q11［○×］** 同じ「人を死なせる行為」でも、「殺してやろう」という認識があれば殺人罪系を、無ければ過失犯系を疑うのが出発点である。
  - 正解：○（正しい）
  - 理由：主観の一語（死亡結果の認識・認容＝故意の有無）が罪名を分ける。結果の重さだけで罪名を決めない。
- **Q12［○×］** 一個の行為が複数の罪名に触れる場合は観念的競合（54条1項前段＝科刑上一罪）、別個の行為が数罪を構成する場合は併合罪（45条）となり、行為の個数が罪数処理の出発点になる。
  - 正解：○（正しい）
  - 理由：罪数はまず「行為が一個か数個か」で観念的競合と併合罪を分ける。本問の一発の発射でA殺人・B殺人未遂が生じた部分は一個の行為＝観念的競合。複数論点を束ねて最後に罪数で締めるための土台。
- **Q13［○×］** 責任主義の下では、非難の対象となる実行行為の時点で責任能力が存在していなければならない（行為と責任の同時存在の原則）。
  - 正解：○（正しい）
  - 理由：これが原則。実行行為時に責任能力がない（心神喪失）と原則不可罰となる。これをどう乗り越えるかが原因において自由な行為。
- **Q14［○×］** 自ら飲酒して心神喪失を招き、当初の犯意どおり結果を実現した場合でも、行為時が心神喪失なら常に不可罰となる。
  - 正解：×（誤り）
  - 理由：原因において自由な行為により39条1項の適用を排除し、完全な責任を問いうる。自招の心神喪失を盾に不可罰は許されない。
- **Q15［○×］** 原因において自由な行為で完全責任を問う限定基準は、①責任能力ある意思決定が結果行為まで連続していること、②原因行為と結果の因果関係である。
  - 正解：○（正しい）
  - 理由：無限定だと責任主義が空洞化するため、意思の連続と因果性で処罰範囲を限定する。
- **Q16［○×］** 刑法39条は、心神喪失者の行為を刑の必要的減軽とし、心神耗弱者の行為を不可罰とする。
  - 正解：×（誤り）
  - 理由：効果が逆。責任能力（是非弁別能力・行動制御能力）を欠くのが心神喪失＝不可罰（39条1項）、著しく減退するにとどまるのが心神耗弱＝必要的減軽（39条2項）。取り違えると刑の効果を誤るため、まず喪失か耗弱かを条文で確定してから論じる。自招酩酊なら、さらに原因において自由な行為による39条の適用排除まで検討が伸びる。
- **Q17［○×］** 死者には占有がないから、被害者を殺害した犯人が殺害直後にその財布を奪っても、常に占有離脱物横領罪にとどまる。
  - 正解：×（誤り）
  - 理由：判例は、殺害者との関係に限り殺害から奪取までを全体的に考察し生前占有の侵害＝窃盗を認める。一律に横領ではない。
- **Q18［○×］** 被害者を殺害した犯人以外の第三者が、死亡後にその財物を持ち去った場合は、占有離脱物横領罪にとどまる。
  - 正解：○（正しい）
  - 理由：生前占有の保護は「殺害者との関係」に限られる。第三者には及ばないので占有離脱物横領（254条）。射程の線引きが要点。
- **Q19［○×］** 法定的符合説によれば、Aを狙った弾が別人Bに当たった場合でも、「人」という範囲で符合するためBに対する故意が認められる。
  - 正解：○（正しい）
  - 理由：構成要件は法益主体を「人」として類型化。具体的な人の同一性まで認識は要らない＝符合し故意あり。
- **Q20［○×］** 法定的符合説に数故意犯説を組み合わせると、一個の行為で複数人に対し故意犯（既遂・未遂）が併存しうる。
  - 正解：○（正しい）
  - 理由：故意を構成要件の範囲で抽象化する以上、個数は問わない。意図した相手に既遂、巻き込んだ相手に未遂が成立しうる。
- **Q21［○×］** 牽連犯（54条1項後段）が成立するには、数罪が罪質上、通例手段と結果（目的）の関係に立つことを要し、当該事案でたまたま手段・目的の関係にあるだけでは足りない。
  - 正解：○（正しい）
  - 理由：牽連犯は罪質上・類型的に手段結果の関係にある場合に限る（客観説）。住居侵入と殺人・窃盗等はこの関係に立つため、住居侵入を共通の手段として各罪が牽連でつながる（この連結が「かすがい」として機能する）。
