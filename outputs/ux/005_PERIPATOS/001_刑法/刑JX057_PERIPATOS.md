### 問題文（最初にゆっくり読み上げる）

BはA銀行のCの口座に絵画の売買代金40万円を振り込むつもりであったが、誤って口座番号のよく似たA銀行の甲の口座に振り込んでしまった。なお、当時甲の預金口座の残高は10万円であった。金に困っていた甲は、これを奇貨として、誤振込みの事実を秘してA銀行の支店窓口において払戻請求をし、50万円の払戻しを受けた。その後、甲は払戻金も使い果たしてしまったので、再び金に困り、支払意思なく自己名義のクレジットカードを用いてカード加盟店Dで高級カメラを購入した。その代金相当額は、後日、信販会社E社から加盟店Dに支払われた。甲の罪責を論ぜよ。なお、住居等侵入罪については検討しなくてよい。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- B が甲口座へ40万円を誤振込（残高10万）
- 甲、誤振込みを秘して窓口で50万円払戻
- 払戻金を使い果たし再び困窮
- 支払意思なく自己名義カードでカメラ購入
- 後日 E 社が D へ立替払い（事後）

### 入口の問い（4問）

- **［入口 1/4・事案の整理］** 登場人物と「引っかかる行為」を挙げて
  - 答え：罪責を検討するのは「何か行為をした人」＝甲ひとり。B（誤振込みした人）・C（本来の受取人）・E社（事後の立替払い）は対象外。
  - 答え：甲の行為を時系列で2つに割る：第1場面＝50万円の払戻し（相手＝A銀行）／第2場面＝カメラ購入（相手＝加盟店D）。相手方ごとに別の財産犯になる。
- **［入口 2/4・見当づけ］** 各行為は「何罪っぽい？」 ― 見当をつけて
  - 答え：第1場面：銀行窓口で「誤振込みを秘して」払戻し → 銀行を騙して交付 ＝ 詐欺（246条1項）系。ただし「自分の口座の金＝自分の物では？」という占有離脱物横領（254条）の対抗仮説を先に潰す。第2場面：支払意思なくカード呈示 → 加盟店Dを騙してカメラ交付 ＝ 1項詐欺（246条1項）。
- **［入口 3/4・論点］** 第1場面で「立ち止まる石」を挙げて（4つ）
  - 答え：石①：自分の口座の金＝占有離脱物横領（254条）では？ → 詐欺罪／横領罪の振り分け。（誤振込みでも預金債権は成立するが「正当な払戻権限」はない＝法律上の占有なし）
  - 答え：石②：「誤振込みを秘して」＝黙っていただけ → 不作為の欺罔と告知義務。（挙動では読めない＝信義則上の告知義務違反で構成）
  - 答え：石③：銀行が失うのは調査の機会だけ → 実質的な財産的損害。（誤振込みか否かは支払応否を決する「重要事項」）
  - 答え：石④：50万円のうち自己分10万円は？ → 詐欺の成立範囲（因果関係）。（10万円は正当な払戻権限あり＝告知義務なし＝不成立）
- **［入口 4/4・論点］** 第1場面の論点を4点セットで割って（3つ）
  - 答え：不作為の欺罔：払戻請求それ自体を「誤振込みでない金の請求」とは読めない（挙動の欺罔×）→ 信義則上の告知義務違反で不作為構成。根拠＝継続的預金取引者の地位。
  - 答え：実質的財産損害：銀行の不利益は調査機会の喪失だが、誤振込みか否かは支払応否を決する重要事項だから、その欺罔に基づく交付に損害あり。
  - 答え：成立範囲：自己分10万円には告知義務がなく欺罔と交付の因果がない → 40万円分のみ詐欺成立。

### 骨子（3項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　払戻しを受けた行為

- 見出しの補足（結論を含む。項目の終わりに読む）：詐欺罪・246条1項
1. 自分の口座の金＝横領では？ → 【論点】詐欺罪／占有離脱物横領罪の振り分け
   規範：誤振込みでも預金債権は成立するが正当な払戻権限なし → 横領罪 不成立
2. 「誤振込みを秘して」 → 【論点】不作為の欺罔
   規範：信義則上の告知義務違反／事実：継続的な預金取引を行う者の地位 → 欺罔○
3. 銀行の損害は調査機会の喪失 → 【論点】実質的な財産的損害
   規範：重要事項に関する欺罔に基づく交付／事実：誤振込みか否かは支払応否を決する → 損害○
4. 50万円のうち自己分10万円は？ → 【論点】詐欺の成立範囲（因果関係）
   事実：自己分10万円は正当な払戻権限あり＝告知義務なし
- 結論：誤振込分40万円について A 銀行に対する1項詐欺罪 成立

#### 第2　カメラを購入した行為

- 見出しの補足（結論を含む。項目の終わりに読む）：1項詐欺・加盟店D
   支払意思を装うカード呈示 → 【論点】自己名義クレカ・支払意思なし
   規範：加盟店は確実に立替払いを受けられず支払意思に関心
   事実：支払意思なくカメラの交付を受けた（交付時に既遂・立替払いは無関係）
- 結論：加盟店 D に対する1項詐欺罪 成立

- 【拾う事実】『代金は後日 E 社から D へ支払われた』 → → 事後事情と既遂時期・損害を起動
- 【争いのない要件】論点にならず、あっさり認定する要件
  - ③処分行為＝窓口係員が払戻しに応じた／④移転＝50万円が甲へ／違法性・責任＝阻却事由なし。
- 【効く事実】「第1場面」のあてはめで使う事実
  - 告知義務 → 「継続的な預金取引を行っている者」という契約上の地位／重要事項性 → 誤振込みが疑われれば銀行は調査・照会する＝支払応否を決する重要事項／成立範囲 → 自己分10万円は正当な払戻権限あり＝告知義務なし＝不成立、誤振込分40万円のみ詐欺。
- 【規範の要点】「自己名義の処理」の規範
  - 支払意思を装うカード呈示＝①欺罔。加盟店Dは支払意思なきことを知ればカード呈示に対し物品を引き渡さない（加盟店規約の趣旨）→ ②錯誤に基づく③交付。加盟店は確実に立替払いを受けられるとは限らず会員の支払意思に関心がある＝⑤財産的損害あり。詐欺は交付時に既遂＝後日の立替払いは成否を左右しない。
- 【まぎらわしい選択肢・論点】欺罔行為の不存在／不可罰的事後行為／権利行使と財産犯
- 【まぎらわしい選択肢・結論】占有離脱物横領罪 成立／50万円全額に詐欺成立／観念的競合（54条1項）
- 【まぎらわしい選択肢・規範】挙動による欺罔で足りる／形式的個別財産説
- 【まぎらわしい選択肢・事実】名義の冒用／先行行為に基づく作為義務

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

払戻し＝横領否定・不作為の欺罔（告知義務違反）・実質的財産損害あり・成立は40万限定でA銀行への詐欺。クレカ＝支払意思なしの欺罔・5要件肯定・立替払い無関係で既遂・加盟店Dへの詐欺。罪数＝被害者・行為・時期が別→併合罪。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 1項詐欺罪（246条1項）の構成要件を、欺罔から結果まで順に挙げよ。
  - 模範解答：①欺罔行為 → ②（被欺罔者の）錯誤 → ③錯誤に基づく処分行為 → ④財物の占有移転 → ⑤財産的損害。①〜⑤が因果でつながって既遂。書けたら○。
- **［規範クイズ 2/3］** 誤振込みを秘した払戻請求につき、銀行に対する不作為の欺罔（告知義務）を基礎づける根拠を述べよ。
  - 模範解答：銀行実務では誤振込みの指摘があれば入金確認や振込依頼人への照会措置が講じられる。受取人は銀行と継続的な預金取引を行っている者として、誤振込みを知ったら銀行に告知すべき信義則上の義務を負う。これを秘した払戻請求が不作為の欺罔。書けたら○。
- **［規範クイズ 3/3］** 詐欺罪における「実質的な財産的損害」の判断基準を一文で述べよ。
  - 模範解答：詐欺も財産罪だから、条件関係だけで損害を肯定せず、経済取引上重要な事項に関する欺罔に基づいて財物が交付された場合に限り財産的損害を認める（実質的個別財産説）。この要件を立ててはじめて詐欺罪の成立を論じられる。誤振込みか否かは支払応否を決する重要事項に当たる。書けたら○。

## 4. ○×クイズ（全9問・1問目から最後まで全部出す）

- **［○×クイズ 1/9］** 同一人が時間を異にする複数の財産取得行為をしたときは、まず行為を場面ごとに切り分け、各場面で被害者（相手方）を特定してから犯罪を検討するのがよい。
  - 正解：○（正しい）
  - 理由：場面ごとに「誰を相手に・何を取得したか」を確定すると、罪名・被害者・罪数がぶれない。混ぜて論じると論点が落ちる。
- **［○×クイズ 2/9］** 人を欺いて財物を交付させた疑いがある事案でも、その財物が行為者の占有・支配下にあると見る余地があるときは、横領罪との振り分けを先に意識すべきである。
  - 正解：○（正しい）
  - 理由：交付（詐欺）か領得（横領）かは占有の所在で分かれる。入口で振り分けないと罪名選択を誤る。
- **［○×クイズ 3/9］** 自分名義の預金口座から払戻しを受ける行為は、原資が誤振込金であっても、つねに自己の財物の処分にすぎず横領・詐欺の問題は生じない。
  - 正解：×（誤り）
  - 理由：誤振込みでは預金債権は成立しても正当な払戻権限がない。誤振込みを秘した払戻請求は銀行に対する詐欺になりうる（最決平15.3.12）。
- **［○×クイズ 4/9］** 黙って真実を告げないだけの行為は、つねに「欺罔行為」に当たらず、詐欺罪は成立しえない。
  - 正解：×（誤り）
  - 理由：告知すべき信義則上の義務がある者が真実を秘すれば、不作為による欺罔として欺罔行為に当たる。義務の根拠を示すのが鍵。
- **［○×クイズ 5/9］** 詐欺罪が成立するには、欺罔がなければ交付がなかったというだけでは足りず、実質的にみて財産的損害があると評価できることが必要である。
  - 正解：○（正しい）
  - 理由：詐欺も財産罪。条件関係だけで損害を肯定せず、経済取引上重要な事項に関する欺罔に基づく交付に限り損害を認める（実質的個別財産説）。
- **［○×クイズ 6/9］** 誤振込みを受けた者が、自己の従前からの正当な残高分も含めて全額を払い戻した場合、払い戻した全額について当然に詐欺罪が成立する。
  - 正解：×（誤り）
  - 理由：正当な払戻権限のある自己残高分には告知義務がなく、欺罔と交付の因果関係がない。詐欺が成立するのは誤振込分のみ。
- **［○×クイズ 7/9］** 自己名義のクレジットカードを使った以上、たとえ支払意思がなくても、名義の偽りがないのだから加盟店に対する詐欺罪は成立しえない。
  - 正解：×（誤り）
  - 理由：名義が真実でも、支払意思を装うこと自体が欺罔。加盟店は支払意思の欠如を知れば交付しないから錯誤・交付・損害が認められ、1項詐欺が成立しうる。
- **［○×クイズ 8/9］** 加盟店は信販会社から代金の立替払いを受けられるのだから、会員に支払意思がなくても加盟店に財産的損害は生じず、詐欺は成立しない。
  - 正解：×（誤り）
  - 理由：加盟店は規約違反等で必ずしも立替払いを受けられない。だから加盟店は会員の支払意思に関心があり、財物（カメラ）の交付に財産的損害が認められる。
- **［○×クイズ 9/9］** 同一人が、被害者・行為・時期をいずれも異にする複数の財産犯を犯したときは、原則として併合罪（45条前段）として処理する。
  - 正解：○（正しい）
  - 理由：別個の機会・別の被害者に向けられた数個の犯罪は併合罪。観念的競合（54条1項）や包括一罪と即断しない。
