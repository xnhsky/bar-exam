### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「現物を買い手に見せてからでないと契約・代金は無理」 → Aがなぜ甲に渡したのか＝交付の趣旨を示す
- 【拾う事実】「701・702は手狭なワンルーム・内とびらで連絡」「売却価格は未定」 → Aの占有がどこまで及ぶかの評価材料

- 【拾う事実】『乙はAの頭部を撃ち「即死」』 → 死亡結果の発生（既遂・未遂の分かれ目）
- 【拾う事実】『丙は乗り気でなく「手伝わなかったらどうなるか分かるだろうな」とすごまれた／利益なし』 → 関与の動機・従属性
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 建造物侵入＝犯罪目的の立入りは管理権者の意思に反する＝一文で成立。
- 【規範の要点】「甲の奪取は詐欺か窃盗か」の規範
  - 詐欺罪の成立には相手方の処分行為に基づく占有移転が必要。Aが終局的に占有を移す意思で交付したのでなければ「交付」とはいえず、意思に反する持ち去り＝窃盗。
- 【効く事実】「甲の奪取は詐欺か窃盗か」のあてはめで使う事実
  - 占有移転の意思を否定 → 手狭なワンルーム・内とびらで連絡・「現物を買い手に見せるだけ」・売却価格未定＝Aは自己の管理下にとどめる意思。財物性 → 覚せい剤も没収まで事実上の所持が可能。
- 【ポイント】順次排除のロジック
  - 1項強盗× → 射殺前に甲が占有確保済みで「強取」（占有取得に向けた暴行）なし。事後強盗× → 甲は出発済で窃盗の機会性なし。→ 残るは2項強盗（236②）＋240後段。
- 【規範の要点】「乙の射殺は2項強盗殺人（排除→肯定）」の規範
  - 不法な利益（覚せい剤の返還・代金請求権）も財産法秩序の保護の見地から「財産上の利益」に当たる。同罪は意思を抑圧して利益を強取する類型ゆえ処分行為は不要。240後段は「よって」がなく殺意ある故意の殺害も含む。A即死＝既遂。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 共犯事案は各人が共同正犯か幇助か＝正犯意思で振り分け、最後に罪数を一言。意思連絡だけでなく自己の犯罪として行う正犯意思があれば共同正犯（60条）、なければ幇助（62条1項）。罪数は包括一罪・牽連犯（54条1項後段）等を一文で。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 計画に乗り気でない・乙にすごまれた消極的動機・主体的計画なし・車を出すだけの従属的役割・利益の帰属なし → 正犯意思を欠く → 幇助犯（62条1項）。甲乙は意思連絡＋主体的関与あり＝共同正犯。
- 【まぎらわしい選択肢・論点】不真正不作為犯の実行行為性／正当防衛の成否
- 【まぎらわしい選択肢・結論】詐欺罪 成立／強盗殺人未遂罪 成立／丙＝共同正犯
- 【まぎらわしい選択肢・規範】狭義の暴行説／財物の他人性
- 【まぎらわしい選択肢・事実】先行行為／意思連絡なし

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

第1＝犯罪目的の立入り＝建造物侵入（130条前段）（甲乙＝共同正犯・丙＝幇助）。第2＝「見せるだけ」で終局的占有移転の意思なし→詐欺×、持ち去り＝意思に反する占有移転で窃盗（235条）、覚せい剤も没収まで所持可で財物性○。第3＝甲が占有確保済→1項強盗×・事後強盗×→不法な利益も保護＝2項強盗＋処分行為不要＋殺意ある射殺・A即死→強盗殺人既遂（240条後段）。第4＝丙は乗り気でなく従属的・利益なし→正犯意思なく幇助、窃盗は強盗殺人に包括一罪・侵入とは牽連犯。

## 3. 規範クイズ（3問）

- **Q04［規範］** 詐欺罪と窃盗罪を分ける中心メルクマールを、一言で書けるか。
  - 模範解答：処分行為（相手が占有を終局的に移す意思に基づく交付）の有無。これがあれば詐欺、なければ意思に反する占有移転＝窃盗。
- **Q05［規範］** 2項強盗（強盗利得罪）に被害者の処分行為が不要とされる理由を、一言で書けるか。
  - 模範解答：同罪は被害者の意思を抑圧して財産上の利益を強取する犯罪類型だから、「暴行」が（恐喝のように）処分行為に向けられている必要はない。
- **Q06［規範］** 同一の財物をめぐり連続して成立した窃盗と強盗（殺人）の罪数を、どう処理するか一言で書けるか。
  - 模範解答：法益の密接関連性・時間的場所的近接性・犯意の一個性（同一機会性）から、軽い窃盗は重い強盗殺人に包括して評価（包括一罪）され、目的・手段関係の建造物侵入とは牽連犯（54条1項後段）。

## 4. ○×クイズ（14問）

- **Q07［○×］** 共犯事案では、自ら構成要件に該当する実行行為をした正犯のみが罪責を負い、自分では手を下していない背後の関与者は罪責を問われない。
  - 正解：×（誤り）
  - 理由：正犯＝自ら構成要件該当行為をした者／共犯＝それ以外の関与者。実行行為がなくても教唆・幇助・共謀共同正犯として罪責を負いうるから、背後者も当然に検討対象に入る。
- **Q08［○×］** 同じ「財物を取得する」行為でも、相手の交付（処分行為）によるか、意思に反する占有移転かで、詐欺罪と窃盗罪のどちらを疑うかが分かれる。
  - 正解：○（正しい）
  - 理由：交付（処分行為）に基づく占有移転＝詐欺、意思に反する占有移転＝窃盗。手段の違いが罪名を分ける。
- **Q09［○×］** 財産上の利益（債務の免脱等）を得る目的で人を殺害した場合、強盗利得罪（2項強盗）＋強盗殺人の成否を検討する筋がありうる。
  - 正解：○（正しい）
  - 理由：「殺して支払い・返還を免れる」型は2項強盗（236条2項）＋240条後段が視野に入る。まず1項強盗・事後強盗を排除してから。
- **Q10［○×］** 目的・手段の関係に立つ複数の罪（例：住居・建造物侵入とその目的である窃盗）は、つねに併合罪として各罪の刑を合算して処断される。
  - 正解：×（誤り）
  - 理由：目的・手段（牽連）関係にある数罪は牽連犯（54条1項後段）として科刑上一罪となり、最も重い罪の刑で処断される。付随的に成立するこの種の罪を軽く一文で済ませてよいのはこのためである。
- **Q11［○×］** 強盗利得罪（2項強盗）を検討する前に、まず1項強盗罪・事後強盗罪が成立しないかを順次排除して示すべきである。
  - 正解：○（正しい）
  - 理由：1項強盗（強取の有無）→事後強盗（窃盗の機会性）→2項強盗、と排除の枠組みを示す。
- **Q12［○×］** 犯罪目的を秘してホテル等の建造物に立ち入っても、外見上の挙動が平穏であれば「侵入」には当たらない。
  - 正解：×（誤り）
  - 理由：「侵入」は管理権者の意思に反する立入りをいう。犯罪目的での立入りは意思に反し「侵入」に当たる（一文で成立処理）。
- **Q13［○×］** 覚せい剤のような法禁物は誰も適法に所有できないから、およそ窃盗罪・強盗罪の客体たる「財物」になりえない。
  - 正解：×（誤り）
  - 理由：禁制品でも没収には一定の手続を要し、その限度で事実上の所持が可能だから「財物」性を認めるのが判例・通説。
- **Q14［○×］** 「隣室の買い手に見せるだけ」と告げて手狭な一室内で品物を手渡させた場合、相手は占有を自己の支配下にとどめる意思だったと評価でき、終局的な占有移転（処分行為）はないと見うる。
  - 正解：○（正しい）
  - 理由：処分行為には占有を終局的に移転させる意思（認識）が要件であるため、「見せるだけ」の一時的・限定的な引渡しは処分行為性を欠く。よって占有はなお相手の管理下にとどまり、その後の持ち去りは意思に反する占有移転＝窃盗が成立し、詐欺は不成立。
- **Q15［○×］** 窃盗犯人が財物の占有を確保した後、その確保とは別に被害者を殺害して債務を免れても、占有取得に向けた暴行がない以上1項強盗罪は成立しない。
  - 正解：○（正しい）
  - 理由：1項強盗の「強取」は占有取得に向けられた暴行・脅迫を要件とするため、財物の占有を確保した後に別途行う暴行はこれに向けられておらず「強取」に当たらない。よって1項強盗は不成立となる。
- **Q16［○×］** 事後強盗罪（238条）の成立には、強盗との均衡上、窃盗の機会の継続中に暴行・脅迫が行われたこと（窃盗の機会性）が必要である。
  - 正解：○（正しい）
  - 理由：窃盗の機会性を欠けば事後強盗は不成立。本問は財物を持った甲が既に出発しており機会性なし。
- **Q17［○×］** 民事上は返還請求が認められない不法な利益（例：覚せい剤の返還請求権）は、2項強盗罪の「財産上の利益」に当たる余地はない。
  - 正解：×（誤り）
  - 理由：不法な手段で財産法秩序を乱す行為を容認すべきでないから、民事上保護されない利益でも「財産上の利益」に当たると解する。
- **Q18［○×］** 財産上の利益を得る意思で被害者を殺害した事案では、被害者がたまたま即死していても、強盗殺人は常に「未遂」として処理する。
  - 正解：×（誤り）
  - 理由：死亡結果が生じれば240条後段は既遂。死亡したか否かで既遂・未遂が決まる。
- **Q19［○×］** 共謀共同正犯の成立には、意思連絡（共謀）に加えて、自己の犯罪として行う「正犯意思」が必要である。
  - 正解：○（正しい）
  - 理由：意思連絡だけでは足りず、正犯意思（相互利用補充による犯行の一体性）が要る。これを欠けば幇助にとどまる。
- **Q20［○×］** 計画に乗り気でなく、脅されて従属的に運転役を引き受けたにすぎず、利益の帰属もない関与者は、正犯意思を欠き幇助犯にとどまりうる。
  - 正解：○（正しい）
  - 理由：消極的動機・従属的役割・利益なしを総合すると正犯意思を欠く。
