## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

外国人乙は、Bから一般旅券の不正取得を頼まれ、報酬目的でこれを引き受けた。乙は、知人の甲に名義を借りようと考えて事情を話したところ、甲は「お前が俺に100万円を支払ってくれるのであれば協力してやってもよい」と述べてこれを承諾し、乙に対し戸籍謄本・住民票・健康保険証を交付し、乙は甲に対し（Bから渡された）100万円を支払った。数日後、乙は、旅券窓口において、一般旅券発給申請書の本籍欄・現住所欄に記入し、所持人自署欄・申請者氏名欄・裏面署名欄にそれぞれ甲の氏名を記入し、Bの顔写真を添付して甲名義の本件申請書を作成した。乙は甲の代理人として本件申請書を旅券発給担当職員Cに提出して旅券発給を申請した。所持人自署欄の署名を本人以外の者が行うことは旅券法上原則として禁止され、申請書には「署名は申請者本人が行ってください」との注意書きがあり、甲はその例外に該当しない者であった。Cが代理権授与の事実や本人との間柄等の確認を求めたところ、乙は応答に詰まり、トイレを口実に立ち去り、結局旅券を取得できなかった。甲及び乙の罪責を論じなさい（特別法違反の点を除く。）。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- Bが乙に旅券の不正取得を依頼 → 乙が報酬目的で引受け
- 甲が100万円を要求・承諾 → 戸籍謄本等を交付・乙が甲へ100万円授受
- 乙が甲名義で本件申請書を作成（Bの写真添付・自署欄に甲名）
- 乙が甲の代理人として職員Cに提出・旅券発給を申請
- Cの本人確認で頓挫・乙は立ち去り旅券を取得できず

  - 答え：B＝依頼者・C＝旅券発給職員は問いの対象外（特別法違反も除外）。ここで的を絞るのが第一歩。

### 骨子（3項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　乙の罪責

- 見出しの補足（結論を含む。項目の終わりに読む）：有印私文書偽造・159条1項／同行使・161条1項／旅券不実記載未遂・157条2項Ⅲ
1. 客体＝事実証明文書／有印／行使目的＝いずれも肯定。名義人甲の承諾あり → 原則同一性を偽らず
2. 【論点】自署性が要求される文書と名義人の承諾（規範：人格の同一性偽り説＋自署性例外）
   - あてはめ：本人以外の署名は旅券法上禁止・注意書き・甲は例外非該当 → 承諾無意味 → 偽造○
3. 真正なものとしてCに提出 → 同行使罪 成立
4. 【論点】国家に対する詐欺と財産的価値 → 個別具体的判断説 → 旅券は証明手段の価値のみ＝財産価値なし → 詐欺否定
5. 受け皿：虚偽申立てで不実記載させ未遂 → 旅券不実記載未遂罪 成立

#### 第2　甲の罪責

- 見出しの補足（結論を含む。項目の終わりに読む）：名義人の共謀共同正犯・60条
1. 甲は実行せず・名義人で単独正犯になれない → 【論点】名義人の共謀共同正犯
2. 消極的身分犯否定→65条を介さず60条のみ／意思連絡＋正犯意思で共同正犯
   - あてはめ：100万円を自ら要求・名義使用は不可欠 → 正犯意思○
- 結論：乙の各罪につき共同正犯 成立

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】『「署名は申請者本人が行ってください」／本人以外の署名は旅券法上原則禁止／甲は例外に非該当』 → 偽造の例外（自署性）
- 【拾う事実】「一般旅券」 → 財産的価値なし（詐欺否定）
- 【拾う事実】『「100万円を自ら要求」／名義使用は不可欠』 → 甲の正犯意思
- 【拾う事実】『甲名義で署名・押印（有印）』 → 有印私文書偽造の客体
- 【拾う事実】「旅券を取得できなかった」 → 未遂（旅券不実記載未遂）
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 客体＝申請書は「事実証明に関する文書」／有印＝甲の署名押印あり／目的＝旅券取得＝行使の目的あり（いずれも争いなく肯定）。
- 【効く事実】あてはめで使う事実
  - 偽造の例外 → 「署名は申請者本人が行ってください」の注意書き・本人以外の署名は旅券法上原則禁止・甲は例外に非該当／詐欺否定 → 一般旅券は証明手段の価値しかなく財産的価値を欠く／甲の正犯意思 → 「100万円を自ら要求」・名義使用は不可欠。
- 【規範の要点】受け皿の規範
  - 公務員Cに虚偽の申立てをして旅券に不実の記載をさせようとして遂げなかった → 旅券不実記載未遂罪（157条2項・3項）成立。詐欺（246条）は旅券が財産的価値を欠くため不成立。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 名義人でないこと（消極的身分）を65条1項で処理する説もあるが、判例通説は消極的身分犯を認めない。名義人も乙を通じて文書への社会的信用を害しうるから、65条を介さず60条のみで共同正犯を肯定。意思連絡＋正犯意思があれば成立。
- 【まぎらわしい選択肢・論点】正当防衛の成否／公文書偽造の成否／消極的身分犯と65条1項
- 【まぎらわしい選択肢・結論】有印私文書偽造罪 不成立／詐欺既遂罪 成立
- 【まぎらわしい選択肢・規範】狭義説／作成権限濫用説
- 【まぎらわしい選択肢・事実】殺意あり／財産的損害あり

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

乙＝承諾あっても自署性文書だから偽造、真正に提出で行使、旅券は財産価値なしで詐欺ダメ→旅券不実記載未遂。甲＝単独正犯は不可だが共同正犯は可、意思連絡＋正犯意思で共謀共同正犯。最後＝手段目的で牽連犯。

## 3. 規範クイズ（全2問・1問目から最後まで全部出す）

- **［規範クイズ 1/2］** 名義人の承諾があっても「偽造」となる例外の規範を述べよ。
  - 模範解答：文書の性質上、その名義人自身による作成だけが予定されている文書（自署性が要求される文書）では、作成者と名義人の同一性が厳格に要求されるから、本人による名義使用の許諾は意味をなさず、人格の同一性を偽るものとして「偽造」となる（最決昭56.4.8・東京地判平10.8.19）。「承諾あり→偽造不成立」で止めると致命傷。
- **［規範クイズ 2/2］** 国家的法益に対し詐欺罪が成立しうるかの判断枠組みを述べよ。
  - 模範解答：詐欺罪の保護法益たる財産権は当然国家にも観念しうるから成立しうるが、財物交付の具体的目的・財物の内容性質などを考慮し個別具体的に成否を決する（個別具体的判断説）。旅券は証明手段としての価値しかなく財産的価値を欠くから「欺く」行為を認めがたい（最判昭27.12.25）。

## 4. ○×クイズ（全4問・1問目から最後まで全部出す）

- **［○×クイズ 1/4］** 私文書の無形偽造（権限ある者が内容虚偽の文書を作成すること）は、原則として処罰されない。
  - 正解：○（正しい）
  - 理由：私文書については虚偽診断書作成罪（160条）等の例外を除き無形偽造は不可罰で、文書偽造罪が問題とするのは原則として有形偽造（名義人と作成者の人格の同一性を偽ること）。検討の的を「誰が誰の名義で作ったか」に絞る出発点となる。
- **［○×クイズ 2/4］** 文書偽造罪における「偽造」とは、文書の名義人と作成者との人格の同一性を偽ることをいう。
  - 正解：○（正しい）
  - 理由：判例・通説は、文書に対する社会的信用を保護するため、「偽造」を名義人と作成者との人格の同一性を偽ることと定義する（人格の同一性偽り説）。この定義から、名義人の承諾があれば原則として同一性は偽られないという議論が出発する。
- **［○×クイズ 3/4］** 免状・鑑札・旅券のような証明文書を不正に取得する行為は、財物の交付を受ける以上、常に詐欺罪（246条）で処断すべきである。
  - 正解：×（誤り）
  - 理由：これらは証明手段としての価値しかなく財産的価値を欠くから、不正取得しても交付者が経済的に重要な目的を達成できなくなるとはいえず、判例は246条でなく157条2項だけを適用すべきとする（最判昭27.12.25）。
- **［○×クイズ 4/4］** 実行行為を分担しない者でも、共同実行の意思（意思連絡）と正犯意思が認められれば、共謀共同正犯として共同正犯（60条）が成立しうる。
  - 正解：○（正しい）
  - 理由：60条の一部実行全部責任の趣旨は相互利用補充関係による共同犯行の一体性にある。実行行為に関与しない者も、共同性を基礎づける意思連絡と正犯性を基礎づける正犯意思があれば共謀共同正犯となる。本問の甲は100万円を自ら要求し、名義使用も不可欠で正犯意思が肯定される。
