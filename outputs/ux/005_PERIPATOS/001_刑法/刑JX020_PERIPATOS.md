## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

甲は、A（28歳、男）のことを恨んでおり、殺してやろうと思い、そのことを乙に相談した。乙は、これに対して、「この睡眠薬は、10錠飲めば意識が戻らずに死亡する代物だ。これをAに飲ませて殺すのはどうか。」などと言って、睡眠薬10錠を交付した。この睡眠薬は、過剰に投与されれば身体に重篤な症状を与え、場合によっては死亡する可能性もあるものであったが、健康な成人男性が10錠飲んだだけでは、死亡する確率は皆無であった。乙もそのことを認識しており、甲に渡した睡眠薬10錠では、健康であるAを殺害することはできないと思っていたが、甲がこれをAに飲ませれば少しは恨みも晴れるだろうと考えて、甲に交付したのであった。しかし、甲は、この睡眠薬を10錠飲ませればAが死亡すると信じ、Aに乙から渡された睡眠薬10錠を飲ませた。その結果、Aは、深い眠りにつき、起きた後も、眠気により意識が朦朧とすることがあったが、数日後には回復した。甲及び乙の罪責について、論じなさい。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 甲がAを恨み「殺してやろう」と乙に相談
- 乙が「10錠で死ぬ。飲ませて殺せ」と睡眠薬10錠を甲に交付
- （乙は内心「10錠では殺せない」と認識しつつ交付）
- 甲が「10錠で死ぬ」と信じてAに10錠を飲ませる
- Aは深い眠り・数日意識朦朧 → 数日後に回復（死亡せず）

### 参考（読み上げない。入口の問いの答えを含むので判定にだけ使う）

登場人物：
- 甲｜正犯・殺意あり（→睡眠薬10錠をAに飲ませた）
- 乙｜幇助・交付者（→10錠では殺せないと認識しつつ交付）
- A｜28歳・健康な成人＝被害者・対象外（数日後回復）

一行要約：甲が殺意で睡眠薬10錠をAに飲ませた（が10錠では死なず・A数日で回復）、乙は「殺せない」と分かって10錠を交付。

### 入口の問い（3問）

- **［入口 1/3・事案の整理］** 登場人物と「引っかかる行為」を挙げて
  - 答え：罪責を検討するのは「何か行為をした人」だけ。本問は甲（睡眠薬10錠を実際にAに飲ませた＝正犯）と乙（10錠を交付して手助けした＝幇助＝共犯）の2人。
  - 答え：A＝被害者は対象外（数日後に回復）。ここで切るのが第一歩。
- **［入口 2/3・見当づけ］** 各行為は「何罪っぽい？」 ― 見当をつけて
  - 答え：甲：「殺してやろう」「死亡すると信じて」飲ませた＝殺意あり＋Aは死なず → 殺人未遂（199条・203条）系。乙：薬を渡して手助け → 幇助犯（62条1項）系。ただし両者とも「10錠では死なない」という客観事情・主観が引っかかる＝論点の芽。
- **［入口 3/3・論点］** 甲で問題になる論点を挙げて（3つ）
  - 答え：CP①：10錠では死亡確率が皆無 → およそ殺せない行為に殺人の客観的危険性（実行行為性）を認めてよいか → 不能犯と未遂犯の区別。（不能犯＝結果発生の現実的危険性を欠き不可罰の行為）
  - 答え：CP②：危険性を誰の視点・どの事情で判断するか → 危険性判断の基準（具体的危険説／修正客観的危険説／純客観説）。（具体的危険説＝一般人基準＋一般人が認識しえた事情＋行為者が特に認識した事情）
  - 答え：CP③：仮に不能犯（殺人未遂否定）でも → 予備的に傷害罪（204条）。意識朦朧＝生理的機能の障害。

### 組み立ての順序（入口の問いのあと、骨子に入る前に読み上げる）

- 順番：第1　甲の罪責 → 第2　乙の罪責 → 第3　罪名従属性
- 第1　甲の罪責
  - 論点1：不能犯と未遂犯の区別
  - 論点2：危険性判断の基準
- 第2　乙の罪責
  - 論点：幇助犯の故意（結果発生の認識の要否）
- 第3　罪名従属性
  - 論点：正犯と共犯の罪名相違の許容

この順番の理由（参考。結論・配点には触れず、一言で言い直す）：共犯事案は正犯（手を下した者）から。本問は 甲（殺人未遂＝不能犯）→ 乙（幇助の故意）→ 罪名従属性。共犯の成否は正犯の成否を前提にするから。

### 骨子（3項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　甲の罪責

- 見出しの補足（結論を含む。項目の終わりに読む）：殺人未遂・199条・203条
1. 甲は殺意で睡眠薬10錠をAに飲ませたが、健康な成人は10錠では死亡確率が皆無 → 実行行為性（不能犯か）を検討
2. 【論点】不能犯と未遂犯の区別（規範：結果発生の現実的危険性の有無で区別・危険性を欠けば不能犯として不可罰）
3. 【論点】危険性判断の基準（規範：行為時に一般人が認識しえた事情＋行為者が特に認識した事情を基礎に、一般人を基準に判断＝具体的危険説）
   - あてはめ：10錠は睡眠薬として多量で過剰投与なら死にうる→ 一般人は死の危険を抱きうる ＝ 危険性発生を肯定・不能犯否定
- 結論：確定的殺意もあり 殺人未遂罪 成立（仮に不能犯でも意識障害で傷害罪）

#### 第2　乙の罪責

- 見出しの補足（結論を含む。項目の終わりに読む）：傷害罪の幇助・204条・62条1項
1. 乙の10錠交付は正犯の実行を容易にする幇助行為だが、「殺せない」と認識して交付 → 殺人未遂幇助の故意を認めうるか
2. 【論点】幇助犯の故意（結果発生の認識の要否）（規範：共犯の処罰根拠は正犯を通じた結果の間接的惹起で正犯と同一ゆえ共犯にも結果発生の認識を要する＝因果的共犯論）
   - あてはめ：乙は死亡結果が生じないと認識して交付＝殺人の結果認識を欠くが意識障害程度の認識はある
- 結論：殺人未遂幇助の故意なし ＝ 傷害罪の幇助犯 成立（63条で減軽）

#### 第3　罪名従属性

- 見出しの補足（結論を含む。項目の終わりに読む）：甲乙の罪名相違
1. 【論点】正犯と共犯の罪名相違の許容（規範：共犯従属性は同一罪名まで要求せず、狭義の共犯は自己の故意の限度で罪責を負えば足り罪名相違を許容）
- 結論：正犯甲が殺人未遂でも 乙は傷害幇助として処断

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】『「10錠で死亡すると信じ」飲ませた』 → 甲の心理（殺意の中身・確定的か）
- 【拾う事実】『健康な成人男性が10錠では死亡確率は皆無』 → 客観的に殺せたか（甲の核心事実）
- 【拾う事実】『過剰投与なら重篤・死亡可能性／10錠は多量』 → 一般人がどう受け取るか
- 【拾う事実】『深い眠り・数日間の意識朦朧』 → 現に生じた身体への影響
- 【拾う事実】『乙は「10錠では殺せない」と認識して交付』 → 乙が結果をどう認識していたか
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 故意＝「死亡すると信じて飲ませた」＝確定的殺意あり（一文）／結果＝Aは死亡せず＝未遂／違法性・責任＝阻却事由なし＝一言で素通り。引っかかるのは入口の実行行為性だけ。
- 【効く事実】効く事実（甲・具体的危険説のあてはめ）
  - 一般人が認識しえた事情 → 「10錠という服用数は睡眠薬として多量」「過剰投与なら死にうる」＝死の危険を惹起する可能性は皆無とはいえない（危惧感） → 危険性発生を肯定し不能犯を否定。故意 → 「10錠で死亡すると信じた」＝確定的殺意（未必ではない）。予備的に → 「数日間の意識朦朧」＝生理的機能の障害で傷害罪。
- 【規範の要点】因果的共犯論の規範
  - 共犯の処罰根拠は正犯を通じて間接的に法益侵害結果を惹起する点にあり、正犯と共犯で基本的に同一 → 正犯に結果発生の認識が要る以上、共犯にも結果発生の認識を要する。乙は殺人未遂幇助の故意を欠く → ただし意識障害程度の認識はある → 傷害罪の幇助（204条・62条1項）。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 正犯と共犯の罪名がズレたら、最後に罪名従属性を一言。狭義の共犯では自己の故意の限度で罪責を負えば足り、罪名相違は正面から認められる。罪名論が華やかなのは共同正犯（犯罪共同説／行為共同説）の方で、幇助では実益が薄い＝一段落で完結。
- 【まぎらわしい選択肢・論点】因果関係の錯誤／共謀共同正犯の成否／間接正犯の成否
- 【まぎらわしい選択肢・結論】殺人既遂罪 成立／殺人未遂罪の幇助犯 成立／不可罰（無罪）
- 【まぎらわしい選択肢・規範】抽象的危険説／責任共犯論
- 【まぎらわしい選択肢・事実】未必の故意／意思連絡あり

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

甲＝10錠で死なず不能犯か、具体的危険説で一般人基準＋認識しえた事情、多量・危惧感で危険性肯定、確定的殺意で殺人未遂、不能犯なら意識障害で傷害。乙＝幇助行為あり、因果的共犯論で結果認識を要する、結果認識なしで殺人未遂幇助の故意なし、意識障害は認識で傷害幇助。罪名＝従属性は同一罪名まで要求せず相違許容。

## 3. 規範クイズ（全4問・1問目から最後まで全部出す）

- **［規範クイズ 1/4］** 不能犯と未遂犯はどの一点で区別されるか、その区別基準（規範）を述べよ。
  - 模範解答：未遂犯の処罰根拠は構成要件的結果発生の現実的危険性を生じさせた点にある。よって両者は結果発生の現実的危険性の有無で区別され、これを欠く行為が不能犯として不可罰となる。
- **［規範クイズ 2/4］** 具体的危険説は、危険性を「どの事情を基礎に」「誰を基準に」判断するか（判断基底と判断基準）を述べよ。
  - 模範解答：判断基底＝行為時に一般人が認識しえた事情＋行為者が特に認識していた事情。判断基準＝一般人。構成要件は一般人への行為規範だからである。
- **［規範クイズ 3/4］** 因果的共犯論（惹起説）からは、共犯（教唆・幇助）の故意として何の認識が必要か。その理由とともに述べよ。
  - 模範解答：共犯の処罰根拠は正犯を通じた法益侵害結果の間接的惹起にあり正犯と共犯で同一。よって正犯に結果発生の認識が要る以上、共犯にも結果発生の認識が必要。ゆえに結果発生を認識しない「未遂の教唆・幇助」は故意を欠き不可罰となる。
- **［規範クイズ 4/4］** 共犯の従属性は、共犯者が正犯と「同一の罪名」を負うことまで要求するか。結論と理由を述べよ。
  - 模範解答：要求しない。共犯従属性は正犯の実行行為への従属を意味するにとどまり、狭義の共犯では共犯者自身の故意の限度で罪責を負えば足りるから、罪名の相違は許容される（正犯＝殺人未遂／共犯＝傷害幇助でよい）。

## 4. ○×クイズ（全6問・1問目から最後まで全部出す）

- **［○×クイズ 1/6］** 犯罪を自らの手で実現した者を「正犯」、その犯罪の実行を手助けしたにとどまる者を「幇助犯（従犯）」といい、両者は区別される。
  - 正解：○（正しい）
  - 理由：自ら構成要件該当行為を行う者が正犯、正犯の実行を物理的・心理的に容易にするにとどまる者が幇助犯（62条1項）。本問では実際に飲ませた甲が正犯、薬を渡した乙が幇助犯。誰が正犯かを最初に確定すると、検討の順番（正犯→共犯）が決まる。
- **［○×クイズ 2/6］** 結果が発生しなかった犯罪（未遂）は、各則に未遂処罰規定がある場合にのみ処罰される。殺人罪には未遂処罰規定（203条）があるため、殺人未遂は処罰される。
  - 正解：○（正しい）
  - 理由：未遂は各則に処罰規定がある場合のみ可罰（44条）。殺人は203条が未遂を罰する。死亡結果が出なくても、実行に着手していれば殺人未遂（199条・203条・43条本文）で捉える。本問はAが回復＝死亡せずなので「未遂か、それとも不能犯か」が焦点になる。
- **［○×クイズ 3/6］** 幇助犯（従犯）が成立するには、正犯が少なくとも実行に着手して違法な行為を行ったことを要する（共犯の従属性）。
  - 正解：○（正しい）
  - 理由：狭義の共犯（教唆・幇助）は正犯の実行行為に従属して初めて成立する（共犯従属性・制限従属性説）。正犯が何罪をどこまで実現したかが共犯の前提になるからこそ、答案でも正犯から書く。これが「正犯先行」の理論的な裏付け。
- **［○×クイズ 4/6］** いわゆる「不能犯」と評価される行為は、結果発生の現実的危険性を欠くため、未遂犯としても傷害罪としても一切処罰されない。
  - 正解：×（誤り）
  - 理由：不能犯は当該犯罪（例：殺人）の現実的危険性を欠くためその罪の未遂では不可罰となるにとどまる。現に生じた別の結果（生理的機能の障害＝傷害）があれば、傷害罪等が別途成立しうる。「不能犯＝全部不可罰」と早合点しない。
- **［○×クイズ 5/6］** 幇助犯（従犯）の客観的要件である「幇助」とは、正犯の実行行為を物理的または心理的に容易にすることをいう。
  - 正解：○（正しい）
  - 理由：幇助＝正犯の実行を物理的（道具・薬の提供等）または心理的（助言・激励等）に容易にする行為（62条1項）。乙の睡眠薬10錠交付は物理的幇助にあたる。客観面はクリアし、争点は主観（幇助の故意）に絞られる。
- **［○×クイズ 6/6］** 正犯が成立する罪と共犯が負う罪の罪名は、共犯従属性の原則上、常に一致しなければならない。
  - 正解：×（誤り）
  - 理由：従属性が要求するのは正犯の実行行為の存在であって、同一罪名までは要しない。狭義の共犯は自己の故意の限度で罪責を負うから、正犯（殺人未遂）と共犯（傷害幇助）で罪名がズレてよい。「常に一致」は誤り。

（○×クイズはここまで＝全6問。最後の6問目まで出したら「○×クイズ、全6問クリア！」と言って復習へ）
