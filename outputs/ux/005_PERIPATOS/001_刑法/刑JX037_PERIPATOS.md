## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

甲が自宅付近の夜道を歩いていると、突然、以前から不和であった乙が金属バットを振り上げて襲いかかってきた。甲はとっさに身をかわしたが、乙が執拗に甲を殴打しようとするため、甲は乙の攻撃を避けようとして同人の胸を両手で強く押したところ、乙はそのまま転倒し、後頭部を路上に強く打ち付けて動かなくなった（「第1暴行」）。甲は、乙が動かなくなったことを認識したが、理不尽な攻撃を受けたことへの反感から、「お前、俺をなめているのか」などと怒鳴りながら、乙の頭部を多数回足蹴にし、強く踏みつけた（「第2暴行」）。甲は乙が全く動かなくなったことから死亡したと考えた。乙の上着から財布（現金・キャッシュカード）が飛び出して見えたため、金策に窮していた甲はこれを奪い取り、直ちに逃走した。もっとも、甲が逃走した段階では乙は生存しており、目撃した丙の通報で救急搬送されたが、数時間後、乙は頭部の傷害が原因で死亡した。死因となった傷害は第1暴行から生じ、第2暴行は第1暴行による傷害を悪化させ乙の死期を早める効果を有していた。甲の罪責を論じなさい。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 乙が金属バットで甲に襲いかかる
- 甲が乙の胸を押す→乙転倒・後頭部強打・動かなくなる（第1暴行＝死因）
- 甲が反感から乙の頭部を足蹴・踏みつけ（第2暴行＝死期を早める）
- 甲、乙の死亡を誤信し財布を奪取・逃走（この時 乙は生存）
- 丙の通報で搬送、数時間後 頭部傷害で死亡

### 参考（読み上げない。入口の問いの答えを含むので判定にだけ使う）

登場人物：
- 甲｜防衛者 → 追撃者 → 財布奪取者
- 乙｜侵害者（金属バット）→ 被害者・死亡＝客体
- 丙｜目撃・通報者＝対象外

### 入口の問い（3問）

- **Q01［事案の整理］** 甲の「引っかかる行為」を挙げて
  - 答え：甲の行為は3つ。①第1暴行（胸を押す→転倒・後頭部負傷＝死因）②第2暴行（頭部を足蹴・踏みつけ＝追撃）③財布奪取。
  - 答え：乙＝侵害者→被害者（客体）・丙＝通報しただけは罪責の検討対象外。ここで切るのが第一歩。
- **Q02［見当づけ］** 各行為は「何罪っぽい？」 ― 見当をつけて
  - 答え：暴行：金属バットに対する反撃 → 正当防衛（36条）＋傷害致死（205条）系。追撃：反感から → 傷害（204条）系。財布：暴行後に奪取意思 → 強盗（236条）ではなく窃盗（235条）系を疑う。
- **Q03［論点］** 前半で問題になる論点を挙げて（3つ）
  - 答え：CP①：第1暴行と第2暴行は1個か別個か → 防衛行為の一体性。（＝複数の暴行を一個の防衛行為とみるか別個とみるか）
  - 答え：CP②：第1暴行に正当防衛が成立、でも死期を早めた第2暴行もある → 死をどちらに負わせる？ → 死の結果の帰責。（＝同一人の二行為で死を二重に評価しないための割り振り）
  - 答え：CP③：第2暴行は侵害終了後・防衛意思なし → 過剰防衛すら成立しない（端的に通常の犯罪）。

### 骨子（3項目。第1から【論点】ごとに、何が問題→規範→使う事実→結論 の順で組み立てる）

#### 第1　乙への暴行・死亡

1. 第1暴行（胸を押す）と第2暴行（頭部を足蹴）→ 【論点】防衛行為の一体性
   規範：時間的場所的近接性＋侵害の継続性＋防衛意思の一個性
   - あてはめ：転倒し動かなくなった＝侵害終了／「なめているのか」＝反感 → 別個の行為
2. 第1暴行：傷害致死の構成要件該当（死因）→ 正当防衛（36条1項）
   - あてはめ：金属バット vs 胸を両手で押すにとどまる＝相当性 → 違法性阻却・犯罪不成立
3. 【論点】死の結果の帰責（同一人の二行為）
   規範：双方帰責は二重評価で不当→死因の第1暴行に帰責（熊内事件＝新たな決意ありと区別）
4. 第2暴行：死の結果不帰属＝傷害罪（204）／侵害終了・防衛意思なし → 過剰防衛も不成立・傷害罪成立

#### 第2　財布の奪取

1. 暴行時に奪取意思なし → 強盗（236条1項）不成立
2. 客観面：奪取時 乙は生存＝生者の占有侵害 → 窃盗の客観的構成要件該当
3. 主観面：甲は死亡を誤信 → 【論点】死者の占有
   規範：生前の占有は死亡直後もなお継続保護・全体的考察で窃盗（最判昭41.4.8）
   - あてはめ：不法領得の意思（金策目的）あり → 窃盗罪（235）成立

#### 第3　罪数

   傷害罪と窃盗罪は社会通念上別個 → 併合罪（45条前段）

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「死因となった傷害は甲の第1暴行から生じ」 → 死と第1暴行の因果
- 【拾う事実】「第1暴行による傷害を悪化させ……死期を早める」 → 第2暴行の死への寄与（帰責の悩み）
- 【拾う事実】『乙が「動かなくなった」「なめているのか」「反感から」』 → 侵害終了／防衛意思の消失
- 【拾う事実】「金属バット」 vs 「胸を両手で強く押した」 → 防衛行為の相当性
- 【拾う事実】「甲が逃走した段階では生存しており」 → 奪取時の生死（客観）
- 【拾う事実】「同人が死亡したと考えた」 → 甲の認識（主観）
- 【拾う事実】「金策に窮していた」 → 不法領得の意思
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 急迫不正の侵害＝金属バット○／防衛意思＝攻撃を避けようと○／相当性＝胸を両手で押すにとどまる○／違法性・責任＝阻却事由なし＝一言で素通り。明らかな要件は短く、難所に時間を回す。
- 【効く事実】「前半」のあてはめで使う事実
  - 一体性否定 → 「転倒し動かなくなった」（侵害終了）＋「なめているのか」（反感＝防衛意思消失）／相当性 → 金属バット vs 胸を両手で押すにとどまる／帰責 → 「死因となった傷害は第1暴行から」を直接引用。
- 【規範の要点】「死者の占有」の規範
  - 客観面＝奪取時 乙は生存（「逃走した段階では生存」）→ 生者の占有侵害 → 窃盗の客観的構成要件該当。主観面＝甲は死亡を誤信 → 死亡直後の奪取は生前の占有を侵害（最判昭41.4.8）→ 故意も肯定 → 窃盗罪成立。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 複数の罪が成立したら最後に罪数処理を一言。観念的競合（54条前段）／牽連犯（54条後段）／併合罪（45条）のどれかを一文で示す。社会通念上別個の行為なら原則は併合罪。
- 【まぎらわしい選択肢・論点】量的過剰防衛の成否／因果関係の錯誤
- 【まぎらわしい選択肢・結論】傷害致死罪 成立／過剰防衛 成立／強盗罪 成立／占有離脱物横領罪 成立
- 【まぎらわしい選択肢・規範】侵害の継続性のみで判断／死期を早めた第2暴行に帰責
- 【まぎらわしい選択肢・事実】暴行時に財物奪取意思あり

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

暴行・死亡＝第1暴行と第2暴行は一体か→侵害終了・専ら攻撃の意思→別個の行為。第1暴行＝死因だが金属バットに胸押しで相当→正当防衛で不成立。死は二重評価を避け第1暴行に帰責→第2暴行は傷害罪のみ。財布奪取＝暴行後に奪取意思→強盗不成立。客観は乙生存＝窃盗該当、主観は死者の占有でも継続保護→窃盗成立。罪数＝傷害罪と窃盗罪は併合罪。

## 3. 規範クイズ（3問）

- **Q04［規範］** 複数の暴行を一個の防衛行為とみるかの判断基準（3つの要素）を挙げよ。
  - 模範解答：①時間的・場所的近接性（前提）②侵害の継続性③防衛の意思（動機）の一個性。侵害終了後に専ら攻撃の意思に出た暴行は別個（最決平20.6.25）。
- **Q05［規範］** 同一人の複数行為で、死の結果をどちらの行為に帰責させるかの規範を述べよ。
  - 模範解答：双方に帰責させれば死の二重評価となり不当。そこで死の結果は死因を形成し全体として重要な意味を持つ行為に帰責させる。後行行為が先行行為の追撃で延長線上にあるなら、死因を形成した先行行為に帰責させる。
- **Q06［規範］** 「死者の占有」が問題となる場面で窃盗を肯定する規範（最判昭41.4.8の趣旨）を述べよ。
  - 模範解答：人を死亡させた者がその直後に同一の機会・場所で財物を奪取する場合、被害者が生前有していた財物の所持は死亡直後においてもなお継続して保護される。一連の行為を全体的に考察すれば他人の財物に対する所持を侵害したものといえ、窃盗罪を構成する。

## 4. ○×クイズ（13問）

- **Q07［○×］** 自己の生命・身体を自ら侵害する自損行為は、原則として犯罪を構成しない。
  - 正解：○（正しい）
  - 理由：刑法は原則として自己加害を処罰しない。これが、結果が生じても被害者本人を「罪責を論ぜよ」の検討対象から外せる理論的根拠（手を下した加害者だけを拾う）。
- **Q08［○×］** 同一の機会に行われた数個の暴行は、外形上分けられる以上、つねに各別の罪を構成し、一罪に包括して評価することは許されない。
  - 正解：×（誤り）
  - 理由：同一法益に対し同一機会に反復された暴行は、一個の犯意に基づくものとして包括一罪と評価されうる。逆に犯意・機会が断絶すれば別個の罪となる。行為をどの単位で評価するかは後の罪数・正当防衛の判断を左右する。
- **Q09［○×］** 正当防衛の前提となる「急迫不正の侵害」の「急迫」とは、法益の侵害が現に存在しているか、または間近に押し迫っていることをいう。
  - 正解：○（正しい）
  - 理由：急迫＝侵害が現在または間近に切迫していること。侵害が既に終了した後の反撃は「急迫性」を欠き、正当防衛は問題とならない（過去の侵害への報復は防衛でない）。
- **Q10［○×］** 財物を奪う前に被害者へ暴行を加えていれば、その暴行と奪取が時間的に近いというだけで、常に強盗罪が成立する。
  - 正解：×（誤り）
  - 理由：強盗は暴行・脅迫の時点で財物奪取意思が要る。意思が暴行後に生じたなら強盗ではなく窃盗系を疑う。
- **Q11［○×］** 構成要件に該当する行為であっても、正当防衛その他の違法性阻却事由が認められれば、その行為について犯罪は成立しない。
  - 正解：○（正しい）
  - 理由：犯罪成立は構成要件該当性→違法性→責任の三段階。違法性が阻却されれば犯罪不成立で、後続の責任段階に進むまでもない。
- **Q12［○×］** 過剰防衛（36条2項）が成立すると、行為の違法性が阻却され、犯罪は成立しないことになる。
  - 正解：×（誤り）
  - 理由：過剰防衛は防衛の程度を超えた行為で、違法性は阻却されず犯罪は成立する。ただし情状により刑を減軽・免除できるにとどまる（任意的減免）。違法性阻却（不成立）の正当防衛との違いがここ。
- **Q13［○×］** 侵害者が倒れて動かなくなった後、防衛者が憤激して専ら攻撃の意思で殴打を続けた追撃行為にも、当然に過剰防衛が成立する。
  - 正解：×（誤り）
  - 理由：侵害が終了し防衛の意思も欠ける追撃は、もはや防衛行為でなく、正当防衛も過剰防衛も成立しない（端的に通常の犯罪）。
- **Q14［○×］** 同一人の二つの行為がいずれも死の結果に因果性を持つ場合でも、双方に死の結果を帰責させると死の二重評価となるため、一方に帰責させるべきである。
  - 正解：○（正しい）
  - 理由：第三者が別行為をしたなら双方帰責でも二重評価にならないが、同一人の二行為では一人に死を二重評価することになり不当。一方に割り振る。
- **Q15［○×］** 先行行為が死因を形成し、後行行為がその傷害を悪化させ死期を早めたにとどまる場合、死の結果は常に後行行為にのみ帰責させる。
  - 正解：×（誤り）
  - 理由：後行行為が先行行為の追撃で延長線上にあるなら、死因を形成した先行行為に帰責させるのが筋。後行行為に新たな決意が介在した熊内事件（昭53）とは事案が異なる。
- **Q16［○×］** 正当防衛の相当性（やむを得ずにした行為）は、防衛手段が必要最小限度であれば足り、生じた結果が侵害より大きくても直ちには否定されない。
  - 正解：○（正しい）
  - 理由：正当防衛は不正の侵害に対する正の行為だから、厳格な法益の権衡までは要求されない。金属バットに対し胸を押すにとどまる行為は相当。
- **Q17［○×］** 強盗罪が成立するには、財物奪取の意思が暴行・脅迫の時点で存在していることを要し、奪取意思が暴行後に生じた場合は強盗罪は成立しない。
  - 正解：○（正しい）
  - 理由：強盗は暴行・脅迫を手段として財物を強取する罪。暴行後に奪取意思が生じたなら、それを手段とした強取とはいえず、窃盗系を検討する。
- **Q18［○×］** 人を死亡させた直後の被害者から、その行為者自身が財物を奪う行為は、死者に占有がない以上、常に占有離脱物横領罪にとどまる。
  - 正解：×（誤り）
  - 理由：判例（最判昭41.4.8）は、被害者の生前の占有は死亡直後もなお継続して保護され、一連の行為を全体的に考察して窃盗罪を構成するとした。横領で終えると失点。
- **Q19［○×］** 別個の機会・別個の法益侵害にあたる複数の罪が成立するときは、原則として併合罪（45条前段）となる。
  - 正解：○（正しい）
  - 理由：一個の行為で数罪なら観念的競合だが、社会通念上別個の行為で数罪が成立するなら併合罪。
