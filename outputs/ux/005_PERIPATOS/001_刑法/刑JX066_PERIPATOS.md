### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】『答案用紙に「甲」と記入・提出』 → 名義人甲・作成者乙（人格の同一性）
- 【拾う事実】『乙は甲の承諾を得ている』 → 承諾の効力（自署性で分かれる）
- 【拾う事実】『甲は計画を立てた張本人・会場に行かず』 → 共謀共同正犯／名義人本人
- 【拾う事実】『Bは承諾／Cは拒絶』 → 契約書①②の結論を分ける
- 【拾う事実】『「C代理人丙」と記載』 → 代理名義の名義人は誰か
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 客体＝答案・契約書はいずれも文書性あり／行使の目的・署名＝そろう／違法性・責任＝阻却事由なし＝一言で素通り。引っかかるのは「偽造」該当性だけ。
- 【効く事実】あてはめで使う事実
  - 承諾無効 → 答案は志願者本人の学力を示す資料＝本人作成のみが予定（自署性）／消極的身分 → 甲は名義人本人だが計画の張本人／代理名義 → 「C代理人丙」＝効果が本人Cに帰属する形式／詐欺 → 偽造契約書で銀行を欺き融資取得。
- 【規範の要点】この論点の規範
  - 消極的身分＝「身分」は有することが特殊で有しないのが通常な地位・状態 → 「名義人でない」という消極的事情は身分でない → 65条不適用・端的に60条。代理名義＝名義人は一般人がその文書に誰の意思が記載されていると認識するか → 効果が本人に帰属する形式だから名義人＝本人C。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 同じ「名義人の承諾あり」でも、自署性の程度で結論が分かれる（乙の答案＝承諾無効で偽造／丙の契約書①＝承諾有効で不可罰）。この一本の軸で説明し分けると理解が伝わる。罪数は偽造→同行使→詐欺を牽連犯で締める。
- 【まぎらわしい選択肢・論点】共謀の射程の有無／通称・偽名の使用と偽造／無形偽造の成否
- 【まぎらわしい選択肢・結論】有印私文書偽造罪 不成立／詐欺罪 不成立
- 【まぎらわしい選択肢・規範】承諾有効説／代理人説（無形偽造説）
- 【まぎらわしい選択肢・事実】Cの承諾あり／無印私文書

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

乙＝答案は事実証明文書、自署性で承諾無効だから偽造、行使と牽連犯。甲＝消極的事情は身分じゃないから端的に60条で共同正犯。丙＝契約書①は承諾あり不可罰、契約書②は効果帰属の本人Cで偽造、行使・詐欺・牽連犯。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 「事実証明に関する文書」の意義（規範）を述べよ。
  - 模範解答：実社会生活に交渉を有する事項を証明するに足りる文書。入試の答案は、採点されてその結果が志願者の学力を示す資料となるからこれに当たる（最決平6.11.29）。「それ自体で証明する」と決めつけず採点を介する点を論じる。
- **［規範クイズ 2/3］** 名義人と作成者の意義（定義）をそれぞれ述べよ。
  - 模範解答：名義人＝文書から認識される意思・観念の主体。作成者＝文書に意思・観念を表示させた者。両者の人格の同一性が偽られると「偽造」（有形偽造）となる。承諾論・代理名義論はこの定義を前提に展開する。
- **［規範クイズ 3/3］** 名義人の承諾があってもなお「偽造」が成立する場合の規範を述べよ。
  - 模範解答：文書の性質上、名義人本人による作成のみが予定されている文書（自署性が強く求められる文書）では、名義人の承諾は意味をなさず、なお「偽造」に当たる。

## 4. ○×クイズ（全4問・1問目から最後まで全部出す）

- **［○×クイズ 1/4］** 有形偽造（「偽造」）とは、名義人と作成者の人格の同一性を偽ることをいい、文書の内容が虚偽であること（無形偽造）とは区別される。
  - 正解：○（正しい）
  - 理由：文書偽造罪の「偽造」は名義人と作成者の人格の同一性を偽ること（有形偽造）。文書の作成名義を偽る点に本質がある。内容の真否を偽る無形偽造（虚偽公文書作成等）とは別系統。検討の的は「誰が名義人で誰が作成者か」に絞る。
- **［○×クイズ 2/4］** 他人名義の文書を作成した者がこれを真正な文書として使用した場合、偽造罪のほかに偽造私文書等行使罪（161条）が別途成立しうる。
  - 正解：○（正しい）
  - 理由：偽造行為と行使行為は別個の構成要件。偽造文書を提出・使用すれば同行使罪が成立し、偽造罪とは目的・手段の関係で牽連犯となる。さらに財物を交付させれば詐欺罪が加わる。文書を「作る」段階と「使う」段階を分けて拾うのがGUESSのコツ。
- **［○×クイズ 3/4］** 「一定の身分にない」という消極的事情も65条1項の「身分」に含まれ、消極的身分犯については常に65条1項を適用して共犯の成否を決する。
  - 正解：×（誤り）
  - 理由：「身分」とは有することが特殊で有しないのが通常な犯人の地位・状態をいうから、「○○でない」という消極的事情はこれに含まれない（消極的身分否定説）。65条の解釈問題は生じず、端的に60条で共同正犯の成否を判断すれば足りる。
- **［○×クイズ 4/4］** 偽造罪・偽造文書行使罪・詐欺罪が手段・結果（目的・手段）の関係に立つときは、牽連犯（54条1項後段）として最も重い刑により処断される。
  - 正解：○（正しい）
  - 理由：偽造は行使の手段、行使は詐欺の手段という目的・手段の関係に立つから、これらは牽連犯（54条1項後段）として科刑上一罪となる。
