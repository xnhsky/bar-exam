### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】『「自宅まで送る」と誤信』 → → 移動意思の有無（監禁の成立時期）
- 【拾う事実】『車を疾走させた』 → → 降車困難＝脱出を著しく困難に
- 【拾う事実】『強いて性交する目的で押し倒そうとした』 → → 暴行は性交目的（財物に向かない）／着手
- 【拾う事実】『極度に畏怖して財布を差し出した』 → → 奪取意思は財布提示の後に発生
- 【拾う事実】『取り上げ中身を確認しただけ』 → → 新たな暴行・脅迫の有無
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 誘拐（225）＝欺罔で生活環境から離脱・実力支配＝素直に成立／強制性交等＝押し倒しで着手・逃走で未遂／違法性・責任＝阻却事由なし＝一言で素通り。
- 【規範の要点】可能的自由説の規範
  - 身体活動の自由とは「移動したいときに移動できる自由（可能的自由）」をいい、現実の移動意思は不要 → 移動しようと思えば移動できる状態を奪えば「監禁」。（試験では現実的自由説を立てて批判→可能的自由説へ架橋すると説得力が上がる）
- 【効く事実】「監禁罪の保護法益」のあてはめで使う事実
  - 「自宅まで送る」と誤信＝現実の移動意思なし／疾走する自動車＝降車すれば生命身体に危険＝脱出を著しく困難に → 発進時点で可能的自由を侵害＝監禁成立。
- 【規範の要点】新たな暴行・脅迫必要説の規範
  - 強盗は暴行・脅迫を手段として財物を奪う罪 → 財物奪取に向けられた暴行・脅迫を要する。事後的奪取意思の場合は原則強盗不成立。ただし奪取意思発生後に反抗を抑圧するに足りる新たな暴行・脅迫があれば強盗成立。
- 【効く事実】「事後的奪取意思（強盗か窃盗か）」のあてはめで使う事実
  - 押し倒しは性交目的＝財物奪取の手段でない／財布は取り上げて中身を確認しただけ＝新たな暴行・脅迫なし（既に畏怖した相手から受け取ったにすぎない）→ 強盗不成立 → 241Ⅰも不成立 → 窃盗（235）にとどまる。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 一人に複数の罪が成立したら最後に罪数処理を一言。起点は行為が一個か数個か・手段結果の関係か。一個の行為が複数罪名に触れれば観念的競合（54条1項前段）、手段‐結果の関係なら牽連犯（54条1項後段）、別個の行為で罪質も異なれば併合罪（45条前段）。本問の4罪は一個の行為でも手段結果でもない＝すべて併合罪。
- 【まぎらわしい選択肢・論点】財物奪取の手段性／不可罰的事後行為
- 【まぎらわしい選択肢・結論】強盗罪 成立／恐喝罪 成立／強制性交等既遂
- 【まぎらわしい選択肢・規範】現実的自由説／反抗抑圧状態利用説
- 【まぎらわしい選択肢・事実】奪取に向けた新たな暴行あり／取り上げ時に脅迫を加えた

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

第1＝「送る」と欺き乗車・発進＝わいせつ目的誘拐罪（225条）／監禁罪の保護法益は可能的自由（移動意思不要）＝疾走する車で発進時点から監禁罪（220条）／誘拐は状態犯・監禁は継続犯＝併合罪。第2＝車外へ引き出し押し倒す＝反抗を著しく困難にする有形力で強制性交等の着手／逃走で遂げず＝強制性交等未遂罪（180・177条）。第3＝強盗・強制性交等罪（241条1項）の前提として強盗を検討／事後的奪取意思には奪取に向けた新たな暴行・脅迫が必要／押し倒しは性交目的・取り上げは中身確認のみで新たな暴行脅迫なし＝強盗不成立 → 241条1項不成立 → 窃盗罪（235条）。第4＝4罪すべて併合罪（45条前段）。

## 3. 規範クイズ（3問）

- **Q04［規範］** 強盗罪（236条）を窃盗罪と区別する中核的な要件を、一言で挙げよ。
  - 模範解答：中核は財物奪取に向けられた（＝手段としての）暴行・脅迫があり、それが反抗を抑圧するに足りる程度であること。この要件を満たすため強盗が成立し、これを欠けば窃盗にとどまる。結果ではなく手段性で区別するのが眼目。
- **Q05［規範］** 監禁罪で現実的自由説ではなく可能的自由説を採るべき理由を、一言で挙げよ。
  - 模範解答：被害者がたまたま移動の意思を起こすか否かという偶然によって犯罪の成否が左右されるのは妥当でないから。だから移動意思を要しない可能的自由を保護する。
- **Q06［規範］** 暴行の後に初めて財物奪取意思を生じた事案で、なお強盗罪が成立するための要件を一言で挙げよ。
  - 模範解答：奪取意思の発生後に、被害者の反抗を抑圧するに足りる新たな暴行・脅迫が加えられ、これを手段として財物を奪取したと評価できること。

## 4. ○×クイズ（10問）

- **Q07［○×］** 未成年者拐取罪・わいせつ目的拐取罪などの拐取（誘拐・略取）罪にいう「拐取」とは、被害者を従来の生活環境から離脱させ、自己または第三者の実力支配内に移すことをいう。
  - 正解：○（正しい）
  - 理由：拐取＝生活環境からの離脱＋実力支配への移転。手段が欺罔・誘惑なら「誘拐」、暴行・脅迫なら「略取」と呼び分ける。「自宅まで送る」と欺いて車に乗せ自己の支配下に置けば、わいせつ目的誘拐罪（225条）の「誘拐」に当たる。
- **Q08［○×］** 同じ財物の取得でも、暴行・脅迫を手段として奪えば強盗系を、そうした手段なく取れば窃盗系を、まず疑うのが筋である。
  - 正解：○（正しい）
  - 理由：強盗は暴行・脅迫を「手段」として財物を奪う罪であり、その手段が無ければ窃盗にとどまる。ゆえに罪名は結果（財物が移った）ではなく、財物奪取に向けられた暴行・脅迫の有無で区別する。結果だけで強盗と決めると、手段性という強盗固有の要件を落とし、窃盗との限界を見失うから誤り。まず手段の文言でアタリを付けるのが筋。
- **Q09［○×］** 強盗罪は、暴行・脅迫を手段とする点を除けば窃盗罪と同じく他人の財物を不法に領得する罪であり、窃盗の要素（占有移転・不法領得の意思）をいわば内包する加重類型といえる。
  - 正解：○（正しい）
  - 理由：強盗は窃盗に「反抗抑圧に足りる暴行・脅迫を手段とする」要素が加わった加重類型。重い強盗が成立しなければ、その手段要素を落とした軽い窃盗が残る関係にある。だから財産罪は重い罪（強盗）から検討し、足りなければ軽い罪（窃盗）へ落とすのが筋＝先に軽い罪で確定すると重い罪の検討を落としやすい。
- **Q10［○×］** 結果（性交）が発生しなかった犯罪では、実行の着手時期を検討して未遂の成否を判断する必要がある。
  - 正解：○（正しい）
  - 理由：未遂では「いつ着手したか」が鍵。本問は押し倒そうとした時点で着手＝逃走で目的を遂げず未遂（180・177）。既遂と誤らない。
- **Q11［○×］** 被害者を「無理やり車外へ引き出し押し倒そうとした」段階では、まだ反抗を著しく困難にする有形力の行使がなく、強制性交等罪の実行の着手は認められない。
  - 正解：×（誤り）
  - 理由：引き出して押し倒そうとした時点で、反抗を著しく困難にする程度の有形力（暴行）が開始されており、着手は認められる。目的を遂げなければ未遂。
- **Q12［○×］** 監禁罪の「監禁」は、施錠など物理的方法に限られ、偽計や走行中の自動車を利用する無形的方法では成立しない。
  - 正解：×（誤り）
  - 理由：監禁の手段は問わない。偽計・脅迫・羞恥心の利用や、降車困難な疾走する自動車に乗せる無形的方法でも「脱出を著しく困難に」すれば成立する。
- **Q13［○×］** 監禁罪の保護法益を可能的自由と解すれば、被害者が現実には移動しようと思っていなくても、移動しようと思えば移動できる状態を奪えば監禁が成立する。
  - 正解：○（正しい）
  - 理由：可能的自由説の帰結。客体となるために具体的な移動の意思は不要。だから「送られる」と誤信して乗っている発進時点から監禁が成立しうる。
- **Q14［○×］** 強盗罪は暴行・脅迫を手段として財物を奪う罪だから、その暴行・脅迫は財物奪取に向けられたものでなければならない。
  - 正解：○（正しい）
  - 理由：暴行・脅迫の手段性が強盗の核。別目的（性交目的）の暴行は強盗の「暴行」にならない。手段性を緩めると窃盗との区別を失う。
- **Q15［○×］** 被害者が既に畏怖している状態に乗じ、新たな暴行・脅迫を加えずに、差し出された財物を受け取った場合、強盗罪が成立する。
  - 正解：×（誤り）
  - 理由：既存の畏怖に乗じて受け取るだけでは、財物奪取に向けられた新たな暴行・脅迫という強盗の要件を欠くから、強盗は成立しない。反抗を抑圧するに足りる新たな暴行・脅迫を手段として加えて初めて強盗となり、それがなければ窃盗にとどまる。手段性の有無で区別する。
- **Q16［○×］** 罪質の異なる複数の罪が一人に成立し、一個の行為でもなく手段結果の関係にもないときは、併合罪（45条前段）として処理する。
  - 正解：○（正しい）
  - 理由：「一個の行為」なら観念的競合（54条1項前段）、「手段結果」なら牽連犯。どちらでもなければ併合罪。誘拐は状態犯・監禁は継続犯で重なり合わず併合罪。
