### 問題文（最初にゆっくり読み上げる）

甲は、A国立大学の音楽学部に所属する教授であるが、楽器業者である乙に「A大学の学生に乙のヴァイオリンを買うようあっせんしてくれませんか。お礼はもちろんさせていただきますので。」などと言われ、これを承諾した。甲は、乙との約束に従い、A大学の授業中に、生徒に対して、乙のヴァイオリンが優れており、購入するべきである旨を告げ、その見返りとして、乙から100万円を受け取った。なお、A国立大学の学則上、音楽学部教授が生徒に対して特定の事業者から楽器を購入するよう勧めることを禁止する規定はなく、また、乙のヴァイオリンの販売価格は市場価格と大差ないものであった。丙は、楽器業者であるが、甲と乙のやりとりを知り、A大学に対して苛立ちを覚えたため、ある日の深夜、A大学の校門前に大量の木材を釘などでつなぎ合わせて壁を作り、学生や教授が校門から出入りできないようにした。丙の上記行為には事件性があると判断した警察官Bは、捜査を開始したところ、丁が深夜にA大学前をうろついており、施錠されたA大学の校門をまさに乗り越えようとしていた。警察官Bは、丁に対して「そこで何をしているんだ。」と質問した。丁は、A大学の職員で、職務室に忘れてきた書類を取りにA大学構内に立ち入ろうとしただけであり、実際に立ち入る権限もあったため、警察官に質問されるいわれはないと思ったが、突然の事態に驚き、無言でいたところ、Bは丁に対して「お前が犯人だな。」などと言いながら、同人の身体を拘束しようとした。丁は逮捕される筋合いはないと考え、Bに対して、手拳で殴るなどの暴行を加えた。甲、乙、丙及び丁の罪責について論じなさい。なお、国立大学法人法により、国立大学法人の役員及び職員は、刑法の適用については、法令により公務に従事する職員とみなされている。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 甲、授業中に生徒へ乙のVn購入を勧誘し、見返りに乙から100万円収受

- 【拾う事実】『A大学は国立大学（みなし公務）』 → 妨害された相手の性質
- 【拾う事実】『深夜・施錠校門を乗り越えようと／丁に立入権限あり』 → 行為時の外形と事後の事情の食い違い
- 【拾う事実】『「逮捕される筋合いはない」と考えた』 → 丁の認識
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 甲の「公務員」「請託」「収受」／丙の「威力」（木壁＝意思制圧の勢力）／丁の「公務員」「暴行」（手拳で殴る）はほぼ争いなしで一文素通り。立ち止まる石は甲の「職務に関し」・丙の「業務」・丁の「適法性＋錯誤」だけ。
- 【効く事実】丙で効く事実
  - 95条不成立 → 丙は壁を作っただけで「暴行・脅迫」なし／威力 → 大量の木材を釘でつなぎ壁を構築＝意思を制圧する勢力／非権力的公務 → A大学は教育機関で強制力を行使しない／妨害結果 → 抽象的危険犯で現実の妨害結果は不要。
- 【規範の要点】「職務の適法性 → その錯誤」の規範
  - 適法性＝事後・純客観でなく、行為時の状況を基礎に裁判所の立場から客観的・合理的に判断（やわらかな客観説・最決昭41.4.14）。錯誤＝適法性を基礎づける事実の認識を欠けば事実の錯誤（故意阻却）、事実は認識し評価のみ誤れば法律の錯誤（故意阻却せず）＝二分説。
- 【まぎらわしい選択肢・論点】正当防衛の成否／共同正犯の成否／因果関係の有無
- 【まぎらわしい選択肢・結論】単純収賄罪 成立／加重収賄罪 成立／公務執行妨害罪 不成立
- 【まぎらわしい選択肢・規範】純客観説／事実の錯誤説／消極説（公務は業務でない）
- 【まぎらわしい選択肢・事実】暴行・脅迫あり／不正な行為あり

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

甲＝みなし公務員＋請託＋収受、勧誘は職務密接関連で「職務に関し」、学則違反なし・価格相当で加重収賄なし＝受託収賄。乙＝対向犯で贈賄。丙＝暴行脅迫なしで95条不成立、木壁は威力、A大学は非権力的公務＝業務、抽象的危険犯＝威力業務妨害。丁＝適法性は記述されざる要素で行為時基準＝施錠校門を越える外形で現行犯逮捕は適法、丁は事実を認識し評価のみ誤る＝法律の錯誤で故意阻却せず＝公務執行妨害。

## 3. 規範クイズ（4問）

- **Q04［規範］** 収賄罪の「職務に関し」を広く捉える「職務密接関連行為」の規範を、理由とともに述べよ。
  - 模範解答：本罪の趣旨は職務の公正とこれに対する社会一般の信頼の保護にある。そうだとすれば、法律上有する権限そのものでなくても処罰の必要がある。よって「職務に関し」とは、職務として行いうる一般的・抽象的範囲にあればよく、職務と密接に関連する行為（職務密接関連行為）も含む。
- **Q05［規範］** 公務が業務妨害罪の「業務」に含まれるかにつき、判例・通説（限定積極説）の規範を述べよ。
  - 模範解答：強制力を行使する権力的公務は、妨害を自ら実力で排除でき、威力・偽計から特に保護する必要がないため「業務」に含まれない。これに対し、強制力を行使しない非権力的公務は、私人の業務と区別する必要がないから「業務」に含まれる（最決平12.2.17）。
- **Q06［規範］** 公務執行妨害罪における職務の適法性の判断基準（やわらかな客観説）を述べよ。
  - 模範解答：職務行為の適否は、事後的に純客観的な立場から判断されるべきものではなく、行為当時の状況を基礎に、裁判所の立場から客観的・合理的に判断すべきである。行為時に適法であった公務を保護することで公務の円滑な執行を確保し、客観判断で公務員の独断を排する。
- **Q07［規範］** 職務執行の適法性の錯誤を二分説で処理する基準を述べよ。
  - 模範解答：適法性を基礎づける事実を誤認した場合は、行為者に規範の問題が与えられておらず事実の錯誤として故意を阻却する。他方、その事実を認識しつつ適法か違法かの評価のみを誤った場合は、法律の錯誤にすぎず故意を阻却しない。

## 4. ○×クイズ（6問）

- **Q08［○×］** 私人であっても、特別法が「刑法の適用については法令により公務に従事する職員とみなす」と定めれば、その者は賄賂罪や公務執行妨害罪にいう「公務員」に当たる（みなし公務員）。
  - 正解：○（正しい）
  - 理由：特別法が「法令により公務に従事する職員とみなす」と定めれば、その私人は刑法上「公務員」として扱われるから、賄賂罪（197条）・公務執行妨害罪（95条）の主体要件を充たす。本問では国立大学法人法がこれを定めるため、甲（教授）の「公務員」性が肯定され、A大学の活動が「公務」である前提も基礎づけられる。みなし公務員規定の有無は冒頭で必ず確認する。
- **Q09［○×］** 収賄罪が成立するには、賄賂を受け取る前に必ず「請託」（一定の職務行為の依頼）を受けて承諾していなければならない。
  - 正解：×（誤り）
  - 理由：請託がなくても単純収賄罪（197条1項前段・5年以下）は成立する。請託を受けて承諾した場合に受託収賄罪（同項後段・7年以下）として加重されるにすぎない。請託の有無は前段／後段を分ける指標。
- **Q10［○×］** 収賄罪の「職務に関し」は、当該公務員が現に法律上の権限を有する職務行為に限られ、これと密接に関連する行為は含まない。
  - 正解：×（誤り）
  - 理由：賄賂罪の保護法益は職務の公正と社会一般の信頼。判例・通説は「職務に関し」を広く捉え、職務として行いうる一般的・抽象的範囲にあればよく、職務密接関連行為も含む。本来職務でない勧誘も、地位を利用した密接関連行為として含まれうる。
- **Q11［○×］** 威力業務妨害罪が成立するには、現実に業務が妨害された結果（具体的な業務の停止・遅延）の発生を要する。
  - 正解：×（誤り）
  - 理由：業務妨害罪（233条・234条）は抽象的危険犯であり、業務妨害の危険を生じさせれば足り、現実の妨害結果の発生は不要。校門の封鎖で出入りを妨げる危険を作出した時点で足りる。
- **Q12［○×］** 公務執行妨害罪の職務の適法性は条文に明記されていないが、本罪が保護するのは適法な公務に限られるから、適法性は「記述されざる構成要件要素」と解される。
  - 正解：○（正しい）
  - 理由：本罪の趣旨は公務の適正な執行の保護にある。違法な職務まで暴行・脅迫から保護する必要はないから、95条に明文はなくとも適法性は記述されざる構成要件要素となる。だから違法な職務への暴行は本罪を構成しない。
- **Q13［○×］** 贈賄罪と収賄罪のように、構成要件上当然に複数人の関与を予定する犯罪を「対向犯（必要的共犯）」といい、各関与者には総則の共犯規定（60条等）は原則として適用されない。
  - 正解：○（正しい）
  - 理由：対向犯は、贈賄（198条）と収賄（197条）のように対向する2当事者の関与が予定された必要的共犯。各々に固有の処罰規定があるため、総則の共犯規定は原則適用されない。乙の贈賄は60条でなく198条で一行認定する。
