   これらと窃盗 ＝ 併合罪（45前段）

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】『自己の顔写真を貼付』 → 偽造否定の罠（別人格は明白）
- 【拾う事実】『公安委員会発行／写真コピーのみ』 → コピーの公文書性・名義人
- 【拾う事実】『預金通帳の交付』 → 財物性＋偽名申込みの欺罔
- 【拾う事実】『営業課保管・甲は経理部』 → 占有は甲になし＝窃盗
- 【拾う事実】『約5分で返却／価値は情報』 → 不法領得の意思（二段）
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 「事実証明に関する文書」「行使の目的」「処分行為」「錯誤」など争いのない周辺要件は一言で認定。
- 【効く事実】文書系で効く事実
  - 偽造 → 履歴書は継続的雇用の基礎で氏名・経歴が重要＝一般人は名義人を「前科なきA」と認識／自己の顔写真貼付でも別人格は明白。写真コピー → 原本を加工せず写真コピーのみ作成＝機械的に正確な複写＋証明文書として原本同様の機能／名義人＝公安委員会（甲ではない）。
- 【規範の要点】この論点の規範
  - ③欺罔＝財産的処分の基礎となる重要事項を偽ること。本人確認は犯罪防止だけでなく信用性維持の観点からも行われる → 名義人は重要事項。④不法領得の意思＝①権利者排除意思＋②利用処分意思。5分でも価値消耗を伴う利用態様なら①肯定、情報の化体で②肯定。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 偽造→行使→詐欺は手段・目的の牽連犯。①私文書系（私文書偽造→行使→二項詐欺）で1個、②公文書系（公文書偽造→行使→一項詐欺）で1個、③これらと窃盗は併合罪。
- 【まぎらわしい選択肢・論点】正当防衛の成否／横領罪と背任罪の区別／不能犯の成否
- 【まぎらわしい選択肢・結論】有印私文書偽造罪 不成立／横領罪 成立
- 【まぎらわしい選択肢・規範】狭義説／形式的個別財産説
- 【まぎらわしい選択肢・事実】責任を免れる意思あり／名義人は甲

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

履歴書＝私文書偽造＋二項詐欺、免許証コピー＝公文書偽造、口座＝詐欺、書類＝窃盗、最後に牽連犯と併合罪。これだけ。

## 3. 規範クイズ（全2問・1問目から最後まで全部出す）

- **［規範クイズ 1/2］** 文書偽造罪における「偽造」（有形偽造）の定義を述べよ。
  - 模範解答：「偽造」とは、名義人と作成者の人格の同一性に齟齬を生じさせること。名義人が誰かは、一般人が当該文書に接した場合に誰の意思・観念の表示と認識するか（一般人標準）で判断する。
- **［規範クイズ 2/2］** 不法領得の意思の2要素を、それぞれが担う区別機能とともに挙げよ。
  - 模範解答：①権利者排除意思（権利者を排除し自己の所有物と同様に利用する意思）＝不可罰的使用窃盗との区別。②利用処分意思（経済的用法に従い利用・処分する意思）＝毀棄罪との区別。

（規範クイズはここまで＝全2問。最後の2問目まで出したら「規範クイズ、全2問クリア！」と言って次へ）

## 4. ○×クイズ（全7問・1問目から最後まで全部出す）

- **［○×クイズ 1/7］** 単独犯の多論点型では、登場人物ではなく「犯罪になりそうな行為」を時系列で全部拾い出すのが出発点となる。
  - 正解：○（正しい）
  - 理由：主体が一人でも、行為ごとに別個の犯罪が成立しうる。行為を時系列で漏れなく拾い、各行為に構成要件を当てるのが検討の軸。拾い落とすと論点ごと落とす。
- **［○×クイズ 2/7］** 文書を作成・行使した行為は文書偽造罪系を、財物や財産上の利益を取得した行為は財産犯（詐欺・窃盗等）を、それぞれまず疑うのが筋である。
  - 正解：○（正しい）
  - 理由：客体（文書か財物か）と結果（取得した利益）から罪名の当たりをつけるのが第一歩。本問は文書系（偽造・行使）と財産犯系（詐欺・窃盗）が交互に並ぶので、行為ごとに系統を仕分ける。
- **［○×クイズ 3/7］** 文書に作成者自身の顔写真が貼付されている場合、作成者の身体的同一性が示されているから、文書偽造罪の「偽造」は成立しない。
  - 正解：×（誤り）
  - 理由：表示された名義人が作成者とは別人格であることが明らかであれば、顔写真が貼付され又は責任を免れる意思がなくても「偽造」は妨げられない（最決平11.12.20）。顔写真を理由に偽造を否定するのが最大の罠。
- **［○×クイズ 4/7］** 公文書の写真コピーが偽造罪の客体たる「文書」に当たる場合、その名義人はコピーを作成した者である。
  - 正解：×（誤り）
  - 理由：写真コピーは原本作成名義人の意思内容を直接伝達保有する文書だから、名義人は原本作成名義人（本問では公安委員会）。コピーを作った者を名義人とするのは典型的な誤り（最判昭51.4.30）。
- **［○×クイズ 5/7］** 他人の物を持ち出して短時間（数分）で原物を返還した場合、それは一時使用にすぎないから、当然に権利者排除意思は否定される。
  - 正解：×（誤り）
  - 理由：持出しが短時間でも、価値の消耗を伴う利用態様であって社会通念上許容される一時使用といえない場合は、権利者排除意思が認められる。時間の長短だけでは決まらない。5分だから不可罰、は大事故。
- **［○×クイズ 6/7］** 金融機関の本人確認は犯罪防止という公的目的のみならず信用性維持の観点からも行われるため、口座の名義人が誰かは経済取引上の重要事項であり、偽名での口座開設申込みは「人を欺く」行為に当たる。
  - 正解：○（正しい）
  - 理由：詐欺罪は財産犯ゆえ「人を欺く」行為には限定が必要で、財産的処分の基礎となる重要事項を偽ることを要する。本人確認の信用性維持目的を捉えれば名義人は重要事項。
- **［○×クイズ 7/7］** 文書偽造罪・同行使罪・詐欺罪が手段・目的の関係に立つ場合、これらは牽連犯（54条1項後段）として科刑上一罪となる。
  - 正解：○（正しい）
  - 理由：偽造は行使の手段、行使は詐欺の手段という目的・手段の関係にあるから牽連犯となる。牽連関係に立たない罪どうしは併合罪（45条前段）。

（○×クイズはここまで＝全7問。最後の7問目まで出したら「○×クイズ、全7問クリア！」と言って復習へ）
