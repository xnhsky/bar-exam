## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

A市において補助金の交付事務を担当する公務員である甲は、事業者乙が虚偽の申請により補助金を不正に受給している事実を職務上把握した。甲の妻丙は、甲に対し、「乙から口止め料を要求すべきだ」と述べ、甲にその旨の犯意を生じさせた。そこで甲は、乙に対し、「不正受給の事実を摘発されたくなければ、口止め料として金を支払え」と申し向けて畏怖させ、口止め料として現金200万円の交付を要求した。乙はこれに畏怖し、後日、現金200万円を用意して甲宅に持参してこれを交付した。その際、丙は、乙が持参した現金200万円を受け取る行為を担当した。甲は、上記の見返りとして、乙の補助金不正受給を摘発せず、これを放置した。甲、乙及び丙の罪責を論ぜよ（特別法違反の点は除く）。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 甲が乙の補助金不正受給を職務上把握
- 丙が甲に「口止め料を要求せよ」と唆し犯意を生じさせる
- 甲が乙を「摘発されたくなければ払え」と脅す
- 乙が畏怖して200万円を持参・交付／丙が受領を分担
- 甲が見返りに不正受給を摘発せず放置

### 参考（読み上げない。入口の問いの答えを含むので判定にだけ使う）

登場人物：
- 甲｜A市・補助金担当の公務員（→恐喝＋収賄）
- 丙｜甲の妻・身分なし（→唆し＋受領を分担）
- 乙｜不正受給の事業者（→畏怖して交付＝贈賄側）

一行要約：甲が乙を脅して賄賂200万円を得て摘発せず放置、丙が唆し＋受領を分担、乙が畏怖して交付。

### 入口の問い（3問）

- **［入口 1/3・事案の整理］** 登場人物と「引っかかる行為」を挙げて
  - 答え：中心にいるのは金銭授受のハブ＝甲。甲を先に固めないと、丙が「何罪の共同正犯か」も乙の「賄賂の相手方」も決まらない。
  - 答え：「一つの200万円」を甲＝加重収賄かつ恐喝／丙＝その共同正犯／乙＝贈賄と、立場ごとに色分けするのが第一歩。
- **［入口 2/3・見当づけ］** 各行為は「何罪っぽい？」 ― 見当をつけて
  - 答え：甲＝脅して金を取る→恐喝（249条）／職務の対価で金を得て摘発せず→加重収賄（197条の3）。丙＝唆し＋受領分担→共同正犯（60条）。乙＝賄賂を渡した→贈賄（198条）。
- **［入口 3/3・論点］** 甲で問題になる論点を挙げて（3つ）
  - 答え：CP①：不正受給を摘発せず放置＝「相当の行為をしなかった」（加重収賄）。（すべき職務を対価で行わない＝197条の3で単純収賄より重い）
  - 答え：CP②：賄賂の200万円は不法原因給付でも恐喝罪になるか。（返還請求できない金でも財産犯の客体か）
  - 答え：CP③：1個の200万円が両罪に該当＝加重収賄と恐喝の罪数。

#### 第1　甲の罪責

- 見出しの補足（結論を含む。項目の終わりに読む）：加重収賄・恐喝・観念的競合
1. 摘発せず放置＝相当の行為の不作為 → 【論点】加重収賄罪の成否（規範：一般的職務権限説）
2. 脅して交付させた200万円は賄賂＝不法原因給付 → 【論点】不法原因給付と恐喝罪の成否
   - あてはめ：交付時までは適法・恐喝が財産状態を侵害 → 恐喝罪成立
3. 1個の200万円が両罪に該当 → 【論点】加重収賄と恐喝の罪数（観念的競合）
- 結論：加重収賄罪と恐喝罪 成立・観念的競合

#### 第2　丙の罪責

- 見出しの補足（結論を含む。項目の終わりに読む）：共犯と身分・65条1項
1. 唆し＋受領を分担＝重要な役割 → 共同正犯（60条）
2. 丙は公務員でない → 【論点】共犯と身分（65条）の処理
   - あてはめ：収賄＝真正身分犯 → 65条1項適用（1項の「共犯」に共同正犯を含む）
3. 恐喝は非身分犯 → 65条を経ず60条のみで共同正犯
- 結論：加重収賄罪の共同正犯と恐喝罪の共同正犯 成立

#### 第3　乙の罪責

- 見出しの補足（結論を含む。項目の終わりに読む）：贈賄・任意性
1. 甲の職務に関し賄賂200万円を供与 → 贈賄罪（198条）
2. 畏怖して交付 → 【論点】贈賄の「供与」の任意性（規範：供与の当否を決する自由で足りる）
   - あてはめ：摘発を免れるため交付を選ぶ自由あり
- 結論：贈賄罪 成立

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「摘発されたくなければ払え」 → 害悪の告知（恐喝の脅迫）
- 【拾う事実】『摘発せず放置＝見返り』 → 相当の行為の不作為（加重収賄）
- 【拾う事実】『200万円は賄賂＝不法原因給付』 → 恐喝の客体になるかを起動
- 【拾う事実】『丙は公務員でない・受領を分担』 → 共犯と身分（65条1項）
- 【拾う事実】『乙は畏怖して交付』 → 贈賄の「任意性」の評価
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 甲の脅迫＝「摘発されたくなければ払え」／畏怖に基づく交付＝一項恐喝／違法性・責任＝阻却事由なし＝一言で素通り。
- 【効く事実】「不法原因給付と恐喝」のあてはめで使う事実
  - 不法原因給付でも恐喝成立 → 交付の時までは適法・恐喝行為こそが適法な財産状態を侵害／賄賂性 → 「摘発しないこと」の対価で職務関連性あり。
- 【規範の要点】積極説の規範
  - 収賄罪は真正身分犯だから身分なき者の加功には65条1項が適用され、同項の「共犯」には共同正犯も含まれる。丙は唆し＋受領分担で重要な役割＝加重収賄罪の共同正犯。恐喝罪は非身分犯だから65条を経ず60条だけで共同正犯。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 収賄と贈賄は対向犯（必要的共犯）。相手方の乙も忘れず拾う。罪数は「1個の行為が2罪に触れる」を一文で観念的競合に落として締める。
- 【まぎらわしい選択肢・論点】正当防衛の成否／被害者の同意／不能犯の成否
- 【まぎらわしい選択肢・結論】単純収賄罪 成立／贈賄罪 不成立
- 【まぎらわしい選択肢・規範】65条2項適用／狭義説

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

甲＝摘発せず放置で加重収賄、脅して交付で恐喝、不法原因給付でも成立、1個の行為で観念的競合。丙＝唆し＋受領で共同正犯、収賄は真正身分犯だから65条1項、恐喝は60条だけ。乙＝畏怖しても供与の自由あり贈賄。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 恐喝・詐取した財物が賄賂として不法原因給付（民法708条）に当たり被害者が返還請求できない場合でも、恐喝罪・詐欺罪が成立する理由を述べよ。
  - 模範解答：財産犯の保護法益は被害者が現に有する適法な財産的地位。交付される財物は交付の時までは不法な原因に基づくものではなく、恐喝（欺罔）行為こそが被害者の適法な財産状態を侵害する。ゆえに交付物が不法原因給付でも財産犯の成立は妨げられない（判例・圧倒的多数説）。
- **［規範クイズ 2/3］** 真正身分犯（構成的身分犯）と不真正身分犯（加減的身分犯）とで、身分なき共犯者の扱いが65条1項・2項でどう分かれるかを述べよ。
  - 模範解答：1項＝真正身分犯（構成的身分）：身分がなければおよそ成立しない罪（収賄等）。身分なき者も共犯（共同正犯を含む）として成立する（身分の連帯的作用）。2項＝不真正身分犯（加減的身分）：身分が刑の軽重に影響するだけの罪（業務上横領等）。身分なき者には通常の刑を科す（科刑の個別化）。
- **［規範クイズ 3/3］** 恐喝により畏怖して賄賂を交付した者について、贈賄罪（198条）の「供与」が認められるかの規範を述べよ。
  - 模範解答：贈賄罪の「供与」には完全な自由意思までは不要で、賄賂を供与するか否かを決する意思の自由があれば足りる（通説・判例）。恐喝の被害者でも、摘発を免れるために交付を選ぶ意思の自由があれば「供与」に当たり贈賄罪が成立する。

## 4. ○×クイズ（全8問・1問目から最後まで全部出す）

- **［○×クイズ 1/8］** 収賄罪（197条）は、「公務員」という身分がなければおよそ成立しない真正身分犯（構成的身分犯）である。
  - 正解：○（正しい）
  - 理由：収賄罪は公務員という身分によって初めて成立する真正身分犯。だからこそ、身分なき者が加功したときは65条1項で罪責を基礎づける必要が出てくる。身分の有無を最初に押さえるのが、共犯処理の出発点。
- **［○×クイズ 2/8］** 公務員が相手を恐喝して金銭を交付させた場合、その金銭は任意に供与されたものではないから、収賄罪にいう「賄賂」には当たらず、収賄罪は成立しない。
  - 正解：×（誤り）
  - 理由：賄賂性は職務行為との対価関係で決まり、交付者の任意性が完全であることまでは要しない。脅して得た金でも「職務の対価」である以上は賄賂であり、収賄罪と恐喝罪は同時に成立しうる（保護法益＝職務の公正／財産、が別だから両立する）。
- **［○×クイズ 3/8］** 賄賂罪にいう「職務」とは、公務員が担当する一般的職務権限に属する事務をいい、当該公務員が現に具体的に担当している事務であることまでは要しない。
  - 正解：○（正しい）
  - 理由：判例・通説の一般的職務権限説。地位に伴い公務として取り扱うべき一切の事務が「職務」で、一般的職務権限に属すれば足りる。だから補助金交付事務の担当者にとって、不正受給の摘発・是正はその権限内であり、黙認が職務行為の対価となる。
- **［○×クイズ 4/8］** 公務員が、その職務上なすべき行為をしないことの見返りとして賄賂を収受した場合であっても、成立するのは単純収賄罪（197条）にとどまり、加重収賄罪は成立しない。
  - 正解：×（誤り）
  - 理由：賄賂を得て、よって「不正な行為をし、又は相当の行為をしなかった」ときは加重収賄罪（197条の3第1項）。摘発というすべき職務の不作為が加重事由。
- **［○×クイズ 5/8］** 恐喝によって交付させた財物が、賄賂として不法原因給付に当たり被害者が返還請求できないものである場合には、財産的保護に値しないから、恐喝罪は成立しない。
  - 正解：×（誤り）
  - 理由：交付の時までは不法な原因に基づくものではなく、恐喝行為こそが被害者の適法な財産状態を侵害する。したがって交付物が不法原因給付でも恐喝罪は成立する（判例・圧倒的多数説）。
- **［○×クイズ 6/8］** 収賄罪のような真正身分犯に身分のない者が加功した場合、身分のない者には65条2項により通常の刑を科す。
  - 正解：×（誤り）
  - 理由：65条2項は不真正身分犯（加減的身分犯）の科刑を個別化する規定。収賄罪は真正身分犯（構成的身分犯）だから、適用されるのは1項で、身分なき者も共犯として成立する。
- **［○×クイズ 7/8］** 贈賄罪（198条）の「供与」が成立するには賄賂を供与する完全な自由意思が必要であり、恐喝により畏怖して交付した者には贈賄罪は成立しない。
  - 正解：×（誤り）
  - 理由：「供与」には完全な自由意思までは不要で、供与するか否かを決する意思の自由があれば足りる（通説・判例）。恐喝被害者でも、摘発を免れるため交付を選ぶ自由があれば「供与」に当たり贈賄罪成立。任意性を安易に否定して不成立とすると失点。
- **［○×クイズ 8/8］** 1個の200万円の収受という1個の行為が加重収賄罪と恐喝罪の双方の構成要件に該当する場合、両罪は観念的競合（54条1項前段）となる。
  - 正解：○（正しい）
  - 理由：「一個の行為」（自然的観察のもと社会的見解上1個）が2個以上の罪名に触れる＝観念的競合。保護法益を異にする加重収賄と恐喝が、1個の収受行為で同時に実現されているから54条1項前段で科刑上一罪。

（○×クイズはここまで＝全8問。最後の8問目まで出したら「○×クイズ、全8問クリア！」と言って復習へ）
