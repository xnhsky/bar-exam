## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

甲は、自宅への帰り道で財布を拾い、中に現金2万円とA名義のクレジットカード（本件カード）が入っているのを見つけた。甲は、生活に困窮していたことから、本件カードで高級時計を買おうと思いついたが、自分で店舗に赴くと犯行が発覚するかもしれないと考えた。そこで、弟分である乙であれば世間知らずで自分の真意に気づかれないだろうと考え、乙に「Aから頼まれた」旨の虚言を用い、自分に代わって時計の購入を行わせることとした。乙は、Aという名を聞いたことがなかったが、甲の言葉を信じ、Aから依頼された（名義人の許諾がある）と誤信し、加盟店B店でA本人になりすまして本件カードを使用し、高級腕時計の交付を受けた。腕時計は乙から甲に渡された。なお、会員規約上カードは名義人のみが利用でき、加盟店規約上、加盟店は利用者が会員本人であることを確認する義務を負う。甲および乙の罪責を論ぜよ（財布拾得に関する罪および特別法違反は除く）。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 甲が帰り道で財布を拾得（中にA名義カード）※拾得は除外
- 甲、本件カードで時計購入を発案・発覚回避のため乙に依頼
- 甲が乙に「Aから頼まれた」と虚言・カードを手渡し
- 乙、許諾ありと誤信しB店でA本人になりすましカード使用
- 店員が乙をA本人と誤信し腕時計を交付
- 腕時計は乙から甲に渡される（利得が甲に帰属）

### 参考（読み上げない。入口の問いの答えを含むので判定にだけ使う）

登場人物：
- 乙｜実行者（→A本人になりすましカード使用）
- 甲｜背後者・首謀者（→虚言で乙を誘導・利得帰属）
- A｜カード名義人＝対象外
- B店店員｜被欺罔者・処分行為者（対象者ではない）

一行要約：乙がA本人になりすましB店でカード使用→腕時計交付、甲は虚言で乙を誘導しカードを用意・利得が帰属。乙は許諾ありと誤信。

### 入口の問い（3問）

- **Q01［事案の整理］** 登場人物と「引っかかる行為」を挙げて
  - 答え：罪責を検討するのは「犯罪になりうる行為をした人」だけ。本問は乙（A本人になりすましてカード使用＝実行行為）と甲（虚言で乙を誘導・カードを用意・利得が帰属）の2人。
  - 答え：A＝カード名義人・B店店員＝被欺罔者は罪責検討の対象ではない。財布拾得・特別法違反は問題が除外＝書くと余事記載。ここで切るのが第一歩。
- **Q02［見当づけ］** 各行為は「何罪っぽい？」 ― 見当をつけて
  - 答え：乙：A本人になりすまし店員にカードを使い腕時計の交付を受けた → 人を欺いて財物を交付させた＝1項詐欺（246条1項）系。交付したのが人（店員）であって機械でないことが要注意（機械なら電子計算機使用詐欺）。甲：自ら実行せず背後で乙を動かした → 共同正犯（60条）系。
- **Q03［論点］** 乙で問題になる論点を挙げて（2つ）
  - 答え：CP①：A本人へのなりすまし＝名義の偽りが欺罔行為に当たるか。（欺罔行為＝処分の判断の基礎となる重要事項を偽ること） これが本問の中核。
  - 答え：CP②：乙は「Aの許諾あり」との誤信が故意に影響するか。名義偽りのみで欺罔成立とする以上、許諾の誤信は些細な点で故意に影響しない。

### 骨子（3項目。第1から【論点】ごとに、何が問題→規範→使う事実→結論 の順で組み立てる）

#### 第1　乙の罪責

- 見出しの補足（結論を含む。項目の終わりに読む）：1項詐欺・246条1項
1. 乙がA本人になりすまし本件カードで腕時計の交付を受けた行為 → 1項詐欺罪の客観的構成要件該当性を検討
2. 【論点】名義の偽りが欺罔行為に当たるか（規範：欺罔行為＝判断の基礎となる重要な事項を偽ること）
   - あてはめ：会員規約上 名義人のみ利用可・加盟店に本人確認義務 → 名義人の同一性は重要事項 → 乙のなりすましはこれを偽るもの
   - あてはめ：錯誤・処分行為・財物移転も認められ → 欺罔行為に当たり客観的構成要件に該当
3. 【論点】許諾の誤信が故意に影響するか（規範：名義偽りのみで欺罔成立→許諾・決済の誤信は故意の認定に影響しない／最決平16.2.9）
   - あてはめ：乙は「他人名義のカードを使う」という重要部分を認識 → 許諾ありとの誤信は些細
- 結論：詐欺の故意・不法領得の意思を肯定 → 1項詐欺罪 成立

#### 第2　甲の罪責

- 見出しの補足（結論を含む。項目の終わりに読む）：共謀共同正犯・246条1項・60条
1. 甲は実行行為を担当せず → 「共同して犯罪を実行した者」（60条）として乙の1項詐欺の共同正犯に問えるか
2. 【論点】共謀共同正犯の成否（規範：相互利用補充関係の一体性は実行非分担者にも及ぶ→①意思連絡②正犯意思（重要な役割）／練馬事件）
   - あてはめ：「A名義カードを使う」合意で意思連絡 → 乙の許諾誤信は障害とならない
   - あてはめ：甲は兄貴分として指示・虚言で誘導・カードを用意・利得が帰属＝正犯意思あり
- 結論：甲は乙の1項詐欺につき 共謀共同正犯 成立

#### 第3　間接正犯との整理

1. 【論点】間接正犯か共謀共同正犯か（規範：間接正犯には被利用者への行為支配性を要する）
   - あてはめ：乙の誤信は犯罪の成否に影響しない → 甲に乙への行為支配性は認められない
- 結論：間接正犯ではなく 共謀共同正犯

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】『会員規約＝名義人のみ利用可／加盟店に本人確認義務』 → 名義の同一性が重要事項である根拠
- 【拾う事実】『乙がA本人になりすました』 → 名義の偽り＝欺罔行為
- 【拾う事実】『乙は「Aの許諾あり」と誤信』 → 故意に影響するかの処理対象
- 【拾う事実】『甲が兄貴分・虚言で誘導・カードを用意』 → 甲の正犯意思（重要な役割）
- 【拾う事実】『動機は甲の困窮・腕時計は甲に帰属』 → 利得帰属＝正犯意思
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 錯誤＝店員は乙をA本人と誤信／処分行為＝店員が腕時計を手渡し／財物移転＝交付完了。4要素は必ず通すが、争いの無い所は一文でよい。
- 【効く事実】あてはめで使う事実
  - 重要事項性 → 会員規約（名義人のみ利用可）・加盟店規約（本人確認義務）／欺罔 → 乙がA本人になりすました／誤信の処理 → 乙は「他人名義カードを使う」重要部分を認識（許諾の誤信は些細）。
- 【規範の要点】練馬事件の規範
  - 相互利用補充関係による共同犯行の一体性は実行行為を分担しない者にも及ぶ → ①意思連絡＋②正犯意思があれば実行非分担者も共同正犯（最大判昭33.5.28）。意思連絡は「A名義カードを使う」合意で足り、乙の許諾誤信は障害とならない。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 間接正犯には被利用者への行為支配性が要る。論点1で「名義偽りのみで欺罔成立」とした以上、乙の許諾誤信は犯罪の成否に影響しない些細な点。乙は犯罪の重要部分を認識する故意ある正犯だから甲に行為支配性は認められず → 間接正犯ではなく共謀共同正犯。分量がきつければ省略可。
- 【まぎらわしい選択肢・論点】不真正不作為犯の実行行為性／窃盗罪との区別／承継的共同正犯の成否
- 【まぎらわしい選択肢・結論】電子計算機使用詐欺罪 成立／間接正犯 成立
- 【まぎらわしい選択肢・規範】狭義説／行為共同説
- 【まぎらわしい選択肢・事実】殺意あり／法令上の作為義務

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

乙＝名義の偽りは重要事項を偽る欺罔行為（規約で基礎づけ）、錯誤・処分・移転で客観面、許諾誤信は故意に影響せず1項詐欺。甲＝相互利用補充で実行非分担者も共同正犯、A名義使用の合意＝意思連絡、指示・虚言・カード準備・利得帰属＝正犯意思で共謀共同正犯。整理＝乙は故意ある正犯で行為支配なし→間接正犯でなく共謀共同正犯。

## 3. 規範クイズ（4問）

- **Q04［規範］** 詐欺罪における「欺罔行為（人を欺く行為）」の定義（一般規範）を挙げよ。
  - 模範解答：相手方が財産的処分行為をするための判断の基礎となる重要な事項を偽ること。重要事項性が欺罔行為性の核心であり、これを偽れば挙動・不作為でも欺罔行為となりうる。
- **Q05［規範］** 他人名義クレジットカードの不正使用において、名義の偽りが欺罔行為に当たる理由づけ（なぜ名義人の同一性が重要事項か）を挙げよ。
  - 模範解答：クレジットカード取引は会員に対する個別的信用を基礎とし、会員規約上名義人本人のみが利用でき、加盟店規約上加盟店に本人確認義務がある。よって名義人の同一性はカード利用の極めて重要な要素であり、これを偽れば処分の判断の基礎となる重要事項を偽ったといえる（最決平16.2.9）。
- **Q06［規範］** 実行行為を分担しない者にも共同正犯が成立しうる（共謀共同正犯）とする規範の成立要件を挙げよ。
  - 模範解答：相互利用補充関係による共同犯行の一体性は実行を分担しない者にも及ぶ。要件は①共同正犯者間の意思の連絡と②自己の犯罪を行う意思（正犯意思）ないし重要な役割。両者があれば実行非分担者も共同正犯となる（最大判昭33.5.28練馬事件・最決平15.5.1スワット事件）。
- **Q07［規範］** 背後者が被利用者を利用した事案で、間接正犯と共謀共同正犯を分ける判断基準と、被利用者が「故意ある正犯」のときどちらになるかを述べよ。
  - 模範解答：分岐基準は被利用者に対する行為支配性。被利用者が規範的障害（故意・責任能力）を欠く「道具」と評価できれば間接正犯。被利用者が故意ある正犯であれば行為支配性は否定され、背後者は共謀共同正犯（又は教唆・幇助）として処理される。

## 4. ○×クイズ（5問）

- **Q08［○×］** 無人の自動精算機やATMに虚偽の情報を入力して財産上の利益を得た場合は、機械を相手とする行為であっても1項詐欺罪（246条1項）が成立する。
  - 正解：×（誤り）
  - 理由：詐欺罪は「人を欺いて」錯誤に陥らせ処分させる罪であり、被欺罔者は自然人に限られる。機械は錯誤に陥らないから、機械相手の不正利得は電子計算機使用詐欺罪（246条の2）で捉える。交付者が「人」か「機械」かで適用条文が分かれる。
- **Q09［○×］** 詐欺罪（246条1項）の客観的構成要件は「欺罔行為 → 相手方の錯誤 → 錯誤に基づく処分行為 → 財物の交付・移転」という一連の因果の連鎖として構成される。
  - 正解：○（正しい）
  - 理由：各要素が因果的につながって初めて詐欺が成立する。どこか1つでも欠けると（例：錯誤に基づかない交付）詐欺は未遂・不成立。
- **Q10［○×］** 財物の交付者（処分行為者）が、自分の財産的処分の判断にとって重要でない事項について偽られたにすぎない場合でも、欺罔行為として詐欺罪が成立する。
  - 正解：×（誤り）
  - 理由：欺罔行為は「処分の判断の基礎となる重要な事項」を偽ることをいう。重要でない事項の偽りは欺罔行為に当たらない。だからこそ名義の同一性が「重要事項」であることを規約等で基礎づける必要がある。
- **Q11［○×］** 共同正犯（60条）が成立するには、関与者の全員が実行行為の一部を現実に分担していなければならない。
  - 正解：×（誤り）
  - 理由：判例（練馬事件）は、相互利用補充関係による一体性は実行を分担しない者にも及ぶとして、意思連絡と正犯意思（重要な役割）があれば実行非分担者も共同正犯になるとした（共謀共同正犯）。実行分担は必須要件ではない。
- **Q12［○×］** 背後者を間接正犯と評価するには、被利用者に対する行為支配性が必要であり、被利用者が故意ある正犯と評価される場合には背後者の間接正犯は否定され、共同正犯・教唆・幇助として処理される。
  - 正解：○（正しい）
  - 理由：間接正犯は被利用者を規範的障害のない「道具」として支配する点に正犯性がある。被利用者が故意ある正犯なら「道具」とはいえず、背後者の行為支配性は否定される。本問の乙は犯罪の重要部分を認識する故意ある正犯だから、甲は間接正犯ではなく共謀共同正犯。
