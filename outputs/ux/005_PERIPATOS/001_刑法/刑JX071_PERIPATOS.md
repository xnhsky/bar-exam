## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

甲は、乙と不倫していることが妻であるAに発覚してしまったことから、A及び乙と3人で話し合う機会を設けることとした。甲は、話合いが行われる前に、乙に対し、「Aは、感情的になると何をするのか分からない。Aが暴れそうな素振りをみせたら、思い切った対応が必要になる。」などと、暗にAに暴力を振るうことを提案したところ、乙は甲の意図を察した上で「仕方ないと思うね。」などと了承した。この時、甲は場合によっては、Aを殺してしまっても仕方がないと考えていたが、乙はAを殺すつもりはなかった。Aは、話合いの場において、声を荒らげて乙を罵倒し始めたことから、甲と乙で、Aを取り押さえた上で、テーブルを背にしたAを思い切り突き飛ばした。その結果、Aは、テーブルの角に頭部を負傷し、頭部挫傷により死亡した。なお、後日、Aの死因である頭部挫傷は、乙の暴行から生じたことが判明している。甲は、乙をかばうため、自己が所有する別荘に乙をかくまった。その上で、Aと乙の関係が警察に発覚しないようにするため、甲と乙と不倫発覚後にやりとりをしていたAの携帯電話を処分した。甲及び乙の罪責について、論じなさい。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 不倫がAに発覚 → 3人で話合いの場を設定
- 話合い前、甲が暗に暴力を提案・乙が了承（共謀）。甲＝殺意あり／乙＝殺意なし
- Aが乙を罵倒 → 甲乙でAを突き飛ばす
- Aは頭部挫傷で死亡。死因は乙の暴行から生じたと判明
- 甲が乙を自己所有の別荘にかくまう（蔵匿）
- 甲がAの携帯電話を処分（証拠処分）

### 参考（読み上げない。入口の問いの答えを含むので判定にだけ使う）

登場人物：
- 甲｜夫・殺意あり（→突き飛ばし／乙を蔵匿／携帯処分）
- 乙｜不倫相手・殺意なし（暴行傷害の故意）（→突き飛ばし）
- A｜甲の妻・死亡＝被害者・対象外

一行要約：甲（殺意）と乙（傷害故意）が共謀してAを突き飛ばし、乙の暴行が死因でA死亡。甲は乙を別荘に蔵匿し、Aの携帯を処分。

### 入口の問い（3問）

- **Q01［事案の整理］** 登場人物と「引っかかる行為」を挙げて
  - 答え：罪責を検討するのは「何か行為をした人」だけ。本問は甲（殺意ある共謀＋突き飛ばし＋蔵匿＋携帯処分）と乙（傷害故意の共謀＋突き飛ばし）の2人。
  - 答え：A＝被害者で死亡は罪責の客体だが検討対象ではない。ここで切るのが第一歩。
- **Q02［見当づけ］** 各行為は「何罪っぽい？」 ― 見当をつけて
  - 答え：甲：「殺してしまっても仕方がない」＝殺意 → 殺人（199条）系。乙：「仕方ないと思うね」＝暴行傷害の故意＋死 → 傷害致死（205条）。別荘にかくまう → 犯人蔵匿（103条）。証拠を処分 → 証拠隠滅（104条）／隠避。
- **Q03［論点］** 本問で問題になる論点を挙げて（3つ）
  - 答え：CP①：甲＝殺意・乙＝傷害故意で罪名がズレる → 異なる故意を持つ者の共同正犯の成立範囲。（＝何罪について「共同」が成立するか＝部分的犯罪共同説）
  - 答え：CP②：死因が殺意なき乙の暴行から生じた → 殺意ある甲の殺人単独正犯（既遂・未遂）。（＝共同正犯の限度を超える上乗せ部分）
  - 答え：CP③：犯行後 → 犯人蔵匿・証拠隠滅の可罰性（自己の刑事事件性）。（＝手6で割る）

### 骨子（4項目。第1から【論点】ごとに、何が問題→規範→使う事実→結論 の順で組み立てる）

#### 第1　甲の罪責

- 見出しの補足（結論を含む。項目の終わりに読む）：共同正犯と錯誤・殺人単独正犯
1. 甲乙は意思を通じてAを突き飛ばし死亡（甲＝殺意／乙＝傷害の故意、死因は乙の暴行から）→ 甲に成立する罪と乙との共犯の成立範囲が問題
2. 【論点】異なる故意を持つ者の共同正犯の成立範囲（規範：実質的に重なり合う限度で共同正犯が成立し、重い故意の者には別途その重い罪が成立する＝部分的犯罪共同説）→ 殺人罪と傷害致死罪は傷害致死罪の限度で重なり合い、暗黙の提案＋「仕方ないと思うね」の了承＋共同の突き飛ばしで相互利用補充関係あり → 結論：甲乙は傷害致死罪の限度で共同正犯
3. 【論点】殺意ある甲の殺人単独正犯（既遂・未遂）（規範：甲乙は共謀し相互利用補充関係に立つから、乙の行為も甲の行為と同視でき、甲の行為から死の結果が生じたと評価できる＝既遂説）→ 死因は乙の暴行から生じたが相互利用補充関係により甲の行為から死が生じたと評価（未遂説なら因果関係不明で未遂）→ 結論：甲に殺人既遂罪の単独正犯 成立（乙とは傷害致死罪の限度で共同正犯）

#### 第1の2　別荘に乙をかくまった行為

- 見出しの補足（結論を含む。項目の終わりに読む）：犯人蔵匿
1. 【論点】共犯者の蔵匿と自己の刑事事件性（規範：103条と104条は構成要件を異にし、共犯者という独立の刑罰権の客体の蔵匿は防御として放任される範囲を逸脱する＝自己の刑事事件性を併有しても可罰・可罰説）→ 乙は傷害致死罪という「罰金以上の刑に当たる罪を犯した者」、別荘は隠匿場所の提供＝「蔵匿」→ 結論：甲に犯人蔵匿罪 成立

#### 第1の3　Aの携帯電話を処分した行為

- 見出しの補足（結論を含む。項目の終わりに読む）：証拠隠滅→隠避
1. 【論点】104条「他人の刑事事件」性（規範：専ら共犯者のためにする意思で隠滅した場合に限り「他人の刑事事件に関する証拠」に当たる＝専ら共犯者のため説）→ 携帯には甲自身の不倫の発覚につながるやりとりが残り専ら乙のためとはいえない／隠避は発覚回避の一切の行為 → 結論：証拠隠滅罪は不成立、犯人隠避罪 成立
2. 罪数：殺人罪・犯人蔵匿罪・犯人隠避罪は → 結論：併合罪（45条前段）

#### 第2　乙の罪責

- 見出しの補足（結論を含む。項目の終わりに読む）：傷害致死罪の共同正犯
1. 乙は暴行傷害の故意で意思連絡を形成し共同してAを突き飛ばした＝傷害致死罪の限度で共同正犯（前述）→ 結論：乙に傷害致死罪の共同正犯 成立（殺意なしで殺人は不成立）

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「殺してしまっても仕方がない」 → 甲の殺意（未必の故意）
- 【拾う事実】「仕方ないと思うね」 → 乙の了承＝意思連絡・傷害の故意
- 【拾う事実】『死因の頭部挫傷は乙の暴行から生じた』 → 既遂/未遂の分岐点
- 【拾う事実】『自己が所有する別荘にかくまう』 → 蔵匿（場所提供）
- 【拾う事実】『甲乙のやりとりが残るAの携帯』 → 自己の刑事事件性（他人性）
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 突き飛ばし＝暴行の実行行為／結果＝Aの死亡／因果＝あり／違法性・責任＝阻却事由なし＝一言で素通り。引っかかるのは故意の食い違い。
- 【効く事実】あてはめで使う事実
  - 殺意 → 「Aを殺してしまっても仕方がない」を直接引用／意思連絡 → 「仕方ないと思うね」＝暴行傷害の共謀／死因＝乙の暴行から生じた＝既遂・未遂の分岐点。
- 【ポイント】蔵匿と隠避の振り分け
  - 「蔵匿」＝隠匿場所の提供（別荘にかくまう）。「隠避」＝それ以外で官憲の発見・逮捕を免れさせる一切の行為（証拠の処分も含む）。携帯処分はまず証拠隠滅(104)を検討し、「他人の」性で不成立 → 隠避(103)で拾う、の二段で書くと差がつく。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 共同正犯は「一部実行全部責任」。意思連絡があるので、死因が一方の暴行から生じても双方に帰責でき、同時傷害の特例（207条）の出番はない。乙は帰結として一段落、甲の殺人・蔵匿・隠避は別個の罪なので併合罪で締める。
- 【まぎらわしい選択肢・論点】正当防衛の成否／承継的共同正犯の成否
- 【まぎらわしい選択肢・結論】殺人未遂罪 成立（単独正犯）／証拠隠滅罪 成立
- 【まぎらわしい選択肢・規範】完全犯罪共同説／行為共同説
- 【まぎらわしい選択肢・事実】急迫不正の侵害

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

甲乙＝部分的犯罪共同説で傷害致死の限度で共同正犯、甲は殺意ありで殺人単独正犯（既遂／未遂は理由づけて選択）。甲＝別荘で蔵匿（103）、携帯処分は104が「他人の」性で不成立→隠避（103）、自己の刑事事件性を併有しても可罰。乙＝傷害致死の共同正犯。罪数＝併合罪。

## 3. 規範クイズ（4問）

- **Q04［規範］** 殺意ある者と傷害（暴行）の故意の者が共謀して人を死亡させた場合、判例（部分的犯罪共同説）が共同正犯を認める範囲と、重い故意の者の扱いを述べよ。
  - 模範解答：構成要件が実質的に重なり合う限度（＝傷害致死罪の限度）で共同正犯が成立し、より重い故意を持つ者には別途その重い罪（殺人罪）が成立する。共同正犯の処罰根拠＝相互利用補充関係から理由づける。
- **Q05［規範］** 殺意ある者が、共謀した相手（殺意なし）の暴行から死の結果が生じた場合に、その者の殺人を既遂とする説（既遂説）の理由づけを述べよ。
  - 模範解答：共謀により相互利用補充関係に立つから、共犯者の行為もまた自己の行為と同視でき、自己の行為から死の結果が生じたと評価できる。⇔ 未遂説は「単独正犯である以上、自己の行為と死との因果関係が必要」とし、死因が他方の暴行から生じた本問では因果関係不明として未遂にとどめる。どちらでも合格。
- **Q06［規範］** 共犯者をかくまう行為が、自己の刑事事件の証拠隠滅の側面を併有していても犯人蔵匿罪が成立する（可罰説）理由を述べよ。
  - 模範解答：①103条と104条は構成要件を異にし、104条が「他人の」に限り処罰する（自己の証拠隠滅は不可罰）からといって、103条が当然に不可罰となるわけではない。②共犯者という独立の刑罰権の客体の蔵匿は、その者への捜査・刑の執行を直接阻害し、自己の防御として放任される範囲を逸脱する（旭川地判昭57.9.29）。
- **Q07［規範］** 自己と共犯者の双方にかかわる証拠を処分した場合に「他人の刑事事件に関する証拠」（104条）に当たるための基準（専ら共犯者のため説）を述べよ。
  - 模範解答：104条が「他人の」と限定したのは自己の防御を保障する趣旨。そこで、専ら共犯者のためにする意思で隠滅した場合に限り「他人の刑事事件に関する証拠」に当たる。自己のためにする意思が併存すれば、自己の防御の一環としての性格を否定できず該当しない。

## 4. ○×クイズ（4問）

- **Q08［○×］** 傷害致死罪（205条）が成立するには、行為者が被害者の死亡という結果を認識・認容していること（殺意）が必要である。
  - 正解：×（誤り）
  - 理由：傷害致死罪は結果的加重犯であり、基本犯（暴行・傷害）の故意があれば足り、加重結果（死）についての故意は不要。逆に殺意があれば殺人罪系を疑う。死の認容の有無が殺人と傷害致死を分ける。
- **Q09［○×］** どちらの罪が「重い」かは、原則として各罪の法定刑（刑の上限・下限）を比較して決まる。殺人罪（199条）は傷害致死罪（205条）より法定刑が重い。
  - 正解：○（正しい）
  - 理由：罪の軽重は法定刑で比較する（10条参照）。殺人罪は死刑・無期・5年以上の拘禁刑、傷害致死罪は3年以上の有期拘禁刑で、殺人が重い。共同実行の部分を確定したうえで、重い故意を持つ者の上乗せ部分を論じる。
- **Q10［○×］** 犯人蔵匿等罪（103条）の「隠避」とは、蔵匿（隠匿場所の提供）以外の方法によって、官憲による発見・逮捕を免れさせる一切の行為をいう。
  - 正解：○（正しい）
  - 理由：「蔵匿」＝隠匿場所の提供に限られるのに対し、「隠避」はそれ以外で発覚・逮捕を妨げる一切の行為を広く含む。だからこそ証拠隠滅(104)が「他人の」性で不成立でも、隠避(103)で拾える余地が生まれる。
- **Q11［○×］** 意思連絡のある共同正犯が成立する場面では、因果関係不明の不利益を被告人に転嫁する同時傷害の特例（207条）を持ち出す必要はない。
  - 正解：○（正しい）
  - 理由：207条は意思連絡なき暴行の競合で因果関係が不明な場合の特例。本問は意思連絡があり共同正犯が成立するから、一部実行全部責任で双方に死を帰責でき、207条を論じるのは論点違いとなる。
