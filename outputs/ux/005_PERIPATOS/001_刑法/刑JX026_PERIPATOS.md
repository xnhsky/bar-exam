## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

暴力団組長である甲とVとの間に金銭トラブルがあり、組員乙は甲から「この金で手打ちにしろ。あいつが嫌がるようなら、なめられてはいけないから、多少手荒なことはしてもかまわない」と命じられ、和解金100万円を持参して気が進まないままV方へ向かった。乙が和解金を切り出すとVは激高し、日本刀を引き抜いて振り回し、乙の左腕に切りつけて服を破き血が噴き出した。乙は逃げようとしたが、Vが「貴様逃げるのかぁ」とドアの前で仁王立ちになった。乙は甲の指示も思い出し、側にあった銅製の壺をVの顔面めがけて投げつけた。Vは避けようとしてよろけ、その際刀が自らの首筋に刺さり、多量出血して死亡した。甲及び乙の罪責について論じなさい（特別法違反に言及する必要はない。）。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 甲とVに金銭トラブル／甲が乙に「多少手荒なことも可」と指示・和解金100万円
- 乙、気が進まぬままV方へ・和解金を切り出す
- V激高・日本刀を振り回し乙の左腕に切りつけ出血
- 乙逃げようとするがVがドア前で仁王立ち
- 乙、甲の指示を思い出し銅製の壺をVの顔面に投擲
- Vよろけ、刀が自らの首筋に刺さり多量出血・死亡

  - 答え：引っかかる行為をしたのは 乙（壺を投げてVを死亡させた＝実行行為者）と 甲（「多少手荒なこと」と指示して送り込んだ＝背後者）の2人。
  - 答え：V＝被害者かつ侵害者。死亡しているが罪責検討の対象ではない。ここで切る。
- **Q02［見当づけ］** 各行為は「何罪っぽい？」 ― 見当をつけて
  - 答え：乙：壺投擲でVが死亡 → まず殺人（199条）か傷害致死（205条）か。壺を顔面に投げ、刀が首筋に刺さったのは偶然 → 殺意は弱い → 傷害致死（205条）系。甲：自ら手を下さず指示しただけ → 共同正犯（60条）を疑う。
- **Q03［論点］** 乙で問題になる論点を挙げて（3つ）
  - 答え：CP①：乙はVとのトラブルを予期しうる状況で赴いた → 急迫性（侵害の予期と積極的加害意思）。（予期しただけでは急迫性は消えない・最決平29.4.26）
  - 答え：CP②：乙は「怒りがこみ上げ」て反撃 → 防衛の意思（攻撃意思との併存）。（攻撃意思が併存しても防衛の意思は失われない・最判昭50.11.28）
  - 答え：CP③：日本刀 vs 銅製の壺 → 防衛行為の相当性。（正対不正ゆえ厳格な権衡・退避義務は不要）

### 骨子（2項目。第1から【論点】ごとに、何が問題→規範→使う事実→結論 の順で組み立てる）

#### 第1　乙の罪責

- 見出しの補足（結論を含む。項目の終わりに読む）：傷害致死・205条／正当防衛・36条1項
1. 壺投擲→よろけ→刀が首筋→死亡 ＝ 因果関係あり（危険の現実化）
2. 殺意は偶然性から否定 → 傷害の故意で傷害致死罪の構成要件該当
3. 【論点】急迫性（侵害の予期と積極的加害意思）（最決平29.4.26）
   - あてはめ：積極的加害意思の総合考慮／命令でやむなく訪問・当初やり過ごそうとした → 積極的加害意思なし → 急迫性○
4. 【論点】防衛の意思 → 攻撃意思併存説／怒り併存でも侵害に対応する意思あり（最判昭50.11.28）→ ○
5. 【論点】相当性 → 正対不正・武器対等不要／退路を塞がれ日本刀に壺 → ○（過剰防衛の余地なし）
- 結論：正当防衛成立 → 違法性阻却 → 乙は不可罰

#### 第2　甲の罪責

- 見出しの補足（結論を含む。項目の終わりに読む）：傷害致死の共同正犯・205条/60条
1. 自ら実行せず指示 → 共謀共同正犯（支配従属・指示・和解金交付＝自己の犯罪）
2. 共謀成立時点＝乙が指示を思い出し反撃に出た時点／傷害致死は共謀の射程内
3. 乙に正当防衛成立 → 【論点】違法性阻却の効果は甲に及ぶか
   - あてはめ：制限従属性説：違法は原則連帯／ただし積極的加害意思（主観的違法要素）は個別化（最決平4.6.5）
4. 甲には当初から積極的加害意思（「多少手荒なこと」） → 甲基準で急迫性なし → 正当防衛は甲に及ばない
- 結論：甲に傷害致死罪の共同正犯 成立

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「多少手荒なことはしてもかまわない」「なめられてはいけない」 → 甲の心理
- 【拾う事実】「気が進まないまま」「逃げようとした」 → 乙の心理
- 【拾う事実】『日本刀を振り回し左腕に切りつけ出血／ドア前で仁王立ち』 → Vの攻撃の強さ・退路
- 【拾う事実】『壺を顔面に投擲／刀が自らの首筋に刺さり死亡』 → 死の経過（偶然性）
- 【拾う事実】『甲の指示を思い出して反撃』 → 甲と乙の結びつき
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 乙：構成要件＝壺投擲→よろけ→刀が首筋→死亡で因果関係あり（危険の現実化）／殺意は偶然性から否定し傷害の故意で傷害致死罪。ここまでは一気に通す。止まるのは違法性＝正当防衛の急迫性。
- 【規範の要点】「急迫性」の規範
  - 侵害を予期していても直ちに急迫性は失われない。もっとも、行為全般の状況に照らしその機会を利用して積極的に加害する意思（積極的加害意思）で侵害に臨んだといえる場合は、36条の趣旨に照らし許容されず急迫性を欠く（最決平29.4.26）。
- 【効く事実】効く事実（乙の急迫性 肯定へ）
  - 予期 → 「多少手荒なこと」と言われトラブルを認識／積極的加害意思の否定 → 気が進まず親分の命令でやむなく訪問・当初は「やり過ごそう」とした。これを評価語（受動的・機会利用の加害意思なし）と結合 → 急迫性肯定。
- 【規範の要点】「違法の連帯と個別化」の規範
  - 制限従属性説を前提に、正犯に生じた違法性阻却事由は原則として共同正犯者間で連帯する。もっとも、急迫性を否定する積極的加害意思は行為無価値的・一身的な主観的違法要素であり、共同正犯者各人につき個別に判断される（最決平4.6.5＝防衛の成否は各人ごとに検討）。
- 【効く事実】効く事実（甲は不可罰にならない）
  - 甲は「なめられてはいけない」「多少手荒なこと」と当初からVを痛めつける意図で乙を送り込んだ → 甲には積極的加害意思あり → 甲基準で急迫性なし → 乙の正当防衛は甲に及ばず、甲に傷害致死罪の共同正犯。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 共謀共同正犯では、共謀がいつ成立したかと結果が共謀の射程内かを一言で詰める。射程＝共謀の心理的因果性が及ぶ範囲。抽象的な動機づけにとどまる指示でも、実行者がそれを思い起こして犯行に出た時点で因果性が現実化し共謀が完成しうる。実行者の逸脱が当初の犯意から想定できないものなら射程外、として帰責範囲を画する。
- 【まぎらわしい選択肢・論点】誤想防衛の成否／過剰防衛の成否
- 【まぎらわしい選択肢・結論】殺人罪 既遂 成立／乙に過剰防衛 成立
- 【まぎらわしい選択肢・規範】厳格従属性説
- 【まぎらわしい選択肢・事実】殺意あり

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

乙＝壺投擲→Vよろけ→刀が首筋で死亡＝危険の現実化で因果○、偶然性から殺意否定＝傷害致死罪該当、急迫性は予期だけでは失われず積極的加害意思の総合考慮（命令でやむなく訪問・当初やり過ごそうとした）で否定→急迫性○、怒り併存でも防衛の意思○、退路を塞がれ日本刀に壺＝相当性○→正当防衛成立で不可罰。甲＝自ら実行せず指示も支配従属・和解金交付で共謀共同正犯、傷害致死は共謀の射程内、乙の違法性阻却は制限従属性説で原則連帯も積極的加害意思は主観的違法要素で個別化→甲は当初から積極的加害意思ゆえ急迫性なし→正当防衛は及ばず傷害致死罪の共同正犯成立。

## 3. 規範クイズ（3問）

- **Q04［規範］** 正当防衛（36条1項）の成立要件を順に挙げよ。
  - 模範解答：①急迫不正の侵害 ②防衛の意思（「防衛するため」）③やむを得ずにした行為（相当性）。違法性阻却事由として3要件を順に検討する。本問で割れるのは①の「急迫」性。
- **Q05［規範］** 侵害を予期していた場合に「急迫」性が否定されるのはどのような場合か、規範を述べよ。
  - 模範解答：侵害を予期しても直ちには急迫性を失わない。もっとも、行為全般の状況に照らし、その機会を利用して積極的に加害する意思（積極的加害意思）で侵害に臨んだ等、36条の趣旨に照らし許容されないといえる場合は急迫性を欠く（最決平29.4.26）。予期だけでは消えず、機会利用の積極加害があって初めて急迫性を欠く。
- **Q06［規範］** 正犯に生じた正当防衛（違法性阻却事由）が共同正犯者に及ぶか ―― 連帯と個別化の規範を述べよ。
  - 模範解答：制限従属性説を前提に、正犯に生じた違法性阻却事由は原則として共同正犯者間で連帯する。もっとも、急迫性を否定する積極的加害意思は行為無価値的・一身的な主観的違法要素であり、各人につき個別に判断される（最決平4.6.5）。まず「原則連帯」を立て、そこから個別化の例外を論じる。

## 4. ○×クイズ（12問）

- **Q07［○×］** 人を死なせた行為でも、死の結果の認識・認容（殺意）が認め難ければ、殺人罪ではなく傷害致死罪を疑うのが筋である。
  - 正解：○（正しい）
  - 理由：結果の重さだけで殺人と決めない。殺意（死の認識・認容）の有無で殺人罪と傷害致死罪を切り分ける。
- **Q08［○×］** 自ら実行行為を分担せず、他人に指示してその行為を通じて犯罪を実現した者にも、共同正犯（60条）が成立しうる。
  - 正解：○（正しい）
  - 理由：共謀に基づき他人の行為を通じて「自己の犯罪」を実現したと評価できれば、実行を分担しなくても共謀共同正犯となる。
- **Q09［○×］** 自ら実行行為を分担しなかった背後の指示者は、せいぜい教唆犯・幇助犯にとどまり、共同正犯（正犯）になることはない。
  - 正解：×（誤り）
  - 理由：正犯と共犯の区別は実行行為の分担の有無だけで決まらない。意思連絡のもと自己の犯罪として実現したといえる程度の重要な役割（正犯性）を果たせば、実行を分担しなくても共謀共同正犯（正犯）となる。本問の甲もこれに当たりうる。
- **Q10［○×］** 行為と結果との間に被害者自身の動き（よろけて自らの刀が刺さる等）が介在すると、因果関係はおよそ否定される。
  - 正解：×（誤り）
  - 理由：行為に内在する危険が結果へ現実化したといえれば因果関係は肯定される（危険の現実化）。介在事情があっても直ちには切れない。
- **Q11［○×］** 反撃に出た者が事前に侵害を予期していたという事実があれば、それだけで「急迫」性は失われる。
  - 正解：×（誤り）
  - 理由：法は予期された侵害を避けるべき義務まで課していないから、侵害を予期していても急迫性は直ちには失われない（最決平29.4.26）。
- **Q12［○×］** 防衛の意思は必要だが、憤激・逆上して攻撃の意思が併存していても、それだけで防衛の意思は失われない。
  - 正解：○（正しい）
  - 理由：防衛行為は性質上反射的になされやすい。防衛の意思（侵害の認識＋対応する意思）があれば、攻撃意思の併存では失われない（最判昭50.11.28）。
- **Q13［○×］** 正当防衛が成立するには、防衛行為が侵害手段と「武器対等」でなければならず、相手より危険性の高い手段を用いれば常に過剰防衛になる。
  - 正解：×（誤り）
  - 理由：正当防衛は正対不正の関係に立つから、退避義務や厳格な法益権衡は不要で、武器対等の原則も絶対ではない。相当性は必要最小限度かで判断する。
- **Q14［○×］** 凶器を投げた行為で相手が体勢を崩し、相手自身の凶器で致命傷を負った場合、攻撃方法の偶然性が大きければ殺意（死の認識・認容）は否定されうる。
  - 正解：○（正しい）
  - 理由：結果惹起が偶然性に依存する部分が大きいと、確定的・未必の殺意の認定は慎重を要する。傷害の故意にとどめ傷害致死罪で構成する。
- **Q15［○×］** 共同正犯における正当防衛・過剰防衛の成否は、共同正犯者各人につきそれぞれ要件を満たすかを検討して決すべきである。
  - 正解：○（正しい）
  - 理由：最決平4.6.5は、共同正犯者の一人に過剰防衛が成立しても当然に他の者にも成立するわけではないとした。各人の主観的事情に応じ個別判断される。
- **Q16［○×］** 実行行為者に正当防衛が成立して不可罰となれば、その者に指示した背後の共謀者も当然に不可罰となる。
  - 正解：×（誤り）
  - 理由：急迫性を否定する積極的加害意思は主観的違法要素として個別化される。背後者に積極的加害意思があれば、その者については急迫性を欠き正当防衛は成立しない。
- **Q17［○×］** 共謀に基づき共同正犯が成立する以上、実行担当者が現実に引き起こした結果は、当初の共謀の内容を大きく逸脱したものであっても、すべて背後の共謀者の責任に帰せられる。
  - 正解：×（誤り）
  - 理由：共同正犯の責任は共謀の射程（共謀の心理的因果性が及ぶ範囲）に限られる。実行担当者の行為が当初の共謀から想定できない別の犯意に基づく逸脱なら、その結果は射程外で共謀者は責任を負わない。射程内か否かで帰責範囲を画する。
- **Q18［○×］** 当初の共謀内容（和解＋多少手荒なこと）と現実の結果（傷害致死）に食違いがあっても、その結果が当初から想定可能な範囲内なら共謀の射程内と評価できる。
  - 正解：○（正しい）
  - 理由：共謀の射程は、共謀内容と結果の食違いが当初想定の範囲内かで判断する。実力衝突を当然に想定していたなら傷害致死も射程内。
