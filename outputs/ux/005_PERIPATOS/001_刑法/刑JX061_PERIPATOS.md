## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

甲は、公園付近を歩いていたところ、偶然、見知らぬ女性（A）がベンチに鞄を置いたまま、その場から徒歩で立ち去るのを目撃した。甲は、1分ほどAの様子をうかがっていたが、鞄に気付いて戻る気配がなかったため、鞄に近付き、中をのぞいたところ、有名ブランド製の財布とコインケースを見つけた。そこで、甲は、財布とコインケースを自宅まで持ち去った。そのため、ベンチを離れてから約5分後に、鞄を置き忘れたことに気が付いたAが慌てて戻ったときには、既に鞄から財布とコインケースが抜き取られている状態であった。翌日、甲は、妻である乙に対して事情を伝えた上で、財布の保管を依頼した。乙は、Aという見知らぬ女性にとっては気の毒な話だと思いながらも、警察に届けるわけにもいかないと思い、甲の依頼を承諾することにして、財布を受け取り、自己のタンスにしまった。一方、甲は、友人の丙と会い、昨日の出来事について話をした上で、Aのコインケースを示した。すると、丙は、「Aとは面識がある。このコインケースはAが大事にしていた物だから、うまく言えば、高値で買い取ってくれると思う。」などと述べたため、甲は、丙に対して、コインケースの売却を依頼した。丙は、これに応じて、Aに対して、「今、買い取らないと、二度と手に入らなくなる。」などとほのめかし、コインケースを時価相当額である2万円で売却し、後日、これを甲と折半した。甲、乙及び丙の罪責について、論じなさい。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- A、公園ベンチに鞄を置き徒歩で立ち去る
- 甲、約1分様子見 → 財布・コインケースを持ち去る
- 約5分後、A戻るも財物は既になし
- 翌日、甲が妻乙に事情を伝え財布の保管を依頼／乙承諾・保管
- 甲が友人丙にコインケース売却を依頼／丙が被害者Aに2万円で売却・折半

### 入口の問い（3問）

  - 答え：罪責を検討するのは「何か行為をした人」だけ。本問は甲（財布・コインケースを持ち去り）・乙（盗品の財布を保管）・丙（盗品を被害者A本人に売却）の3人。
  - 答え：A＝被害者・所有者は対象外。甲の行為で「盗品」が生まれ、それが乙・丙へ枝分かれする連鎖構造を最初に掴むのが第一歩。
- **［入口 2/3・見当づけ］** 各行為は「何罪っぽい？」 ― 見当をつけて
  - 答え：甲：他人の財物を持ち去り → 窃盗（235条）系。ただし置き忘れ＝なお占有あるか（無ければ占有離脱物横領254条）。乙：盗品を預かり保管 → 盗品等保管罪（256条2項）系。丙：盗品の売却を仲介 → 盗品等有償処分あっせん罪（256条2項後段）系。

  - 答え：CP甲：置き忘れ財物を持ち去り → 置き忘れ財物の占有の有無（窃盗か占有離脱物横領か）。（占有＝人が物を実力的に支配する関係＝事実＋意思）

### 骨子（3項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　甲の罪責

- 見出しの補足（結論を含む。項目の終わりに読む）：窃盗罪・235条・254条
1. 置き忘れの財布・コインケースを持ち去り → 【論点】置き忘れ財物の占有の有無（窃盗か占有離脱物横領か）
2. 規範：占有＝実力支配（事実＋意思）／公衆自由出入りでは場所的・時間的離隔が第一次的
3. あてはめ：取得まで約1分・Aは徒歩で近接 → 占有なお失われず
   - あてはめ：甲が目撃した事情（主観）は占有判断に取り込まない
4. → 窃取に当たる → 結論：窃盗罪 成立
5. 甲の売却依頼＝不可罰的事後行為（別罪を構成せず）

#### 第2　乙の罪責

- 見出しの補足（結論を含む。項目の終わりに読む）：盗品等保管罪・256条2項
1. 盗品の財布を保管・盗品性の認識あり → 保管罪 成立
2. 【論点】257条1項の親族関係は誰と誰の間か → 規範：本犯者・関与罪犯人間説（期待可能性の減少）
3. あてはめ：甲乙は夫婦（配偶者）
- 結論：刑は必要的免除（罪は成立）

#### 第3　丙の罪責

- 見出しの補足（結論を含む。項目の終わりに読む）：盗品等有償処分あっせん罪・256条2項後段
1. 被害者A本人へ売却 → 【論点】被害者本人への売却でも追求権侵害があるか
2. 規範：追求権侵害＝正常な回復を困難にすること
3. あてはめ：本来無償で返るのに2万円を負担 → 正常な回復が困難
- 結論：盗品等有償処分あっせん罪 成立

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】『「1分ほど」様子見／「約5分後」にA戻る』 → 取得時の時間的離隔
- 【拾う事実】『Aは徒歩で立ち去った』 → 取得時なお近接（場所的離隔）
- 【拾う事実】『公園のベンチ』 → 公衆が自由に出入りできる場所
- 【拾う事実】『妻である乙／事情を伝えた』 → 夫婦関係・盗品の認識
- 【拾う事実】『相手はA本人／時価2万円で売却』 → 被害者への返還・負担
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 素直に通す石（各一文）＝乙の「保管」該当・盗品の認識／丙の「あっせん」の意義。立ち止まる石＝①甲＝占有の有無 ②乙＝257条1項の特例 ③丙＝追求権侵害。
- 【効く事実】「占有の有無」のあてはめで使う事実
  - 離隔が小さい → 取得まで約1分・Aは徒歩で立ち去り近接／占有の意思 → 約5分後に置き忘れを記憶して戻る（補充的）。甲が置き忘れを目撃した事情は「主観」＝占有判断に取り込まず故意で考える。事実は必ず評価語（離隔が極めて小さい／なお失われない）と結合させる。
- 【規範の要点】2つの規範
  - 乙：257条1項は親族間の関与で適法行為の期待可能性が減少することを理由に刑を免除する一身的処罰阻却事由 → 親族関係は本犯者（甲）と関与罪犯人（乙）の間に必要。甲乙は夫婦＝刑の必要的免除（罪は成立）。丙：追求権侵害＝被害者による盗品の正常な回復を困難にすること → 被害者本人への売却でも、Aは本来無償で返るのに2万円を負担＝回復困難＝侵害あり（最決平14.7.1）。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 窃盗の本犯者は、自分の盗品を運搬・保管・処分させても盗品等関与罪に問われない（本犯者の事後関与＝不可罰的事後行為）。だから甲のコインケース売却依頼は別罪にならず一文で処理。乙・丙それぞれの罪責に集中する。
- 【まぎらわしい選択肢・論点】不法領得の意思の有無／共謀共同正犯の成否／不能犯の成否
- 【まぎらわしい選択肢・結論】占有離脱物横領罪 成立／無罪（追求権侵害なし）／盗品等無償譲受け罪 成立
- 【まぎらわしい選択肢・規範】本犯・被害者間説／狭義の占有説
- 【まぎらわしい選択肢・事実】被害者の主観的認識／意思連絡

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

甲＝占有は実力支配＝事実＋意思、公衆場所では場所的・時間的離隔、約1分・近接で占有なお失われず＝窃盗（主観は取り込まない）。乙＝盗品保管罪○、257条1項の親族は本犯者甲と乙の間＝夫婦で刑の必要的免除（罪は成立）。丙＝被害者本人売却でも正常な回復を困難＝追求権侵害あり＝有償処分あっせん罪○。甲の売却依頼＝不可罰的事後行為。

## 3. 規範クイズ（全2問・1問目から最後まで全部出す）

- **［規範クイズ 1/2］** 窃盗罪にいう「占有」の意義と、その有無を判断する2つの要素を述べよ。
  - 模範解答：占有＝人が物を実力的に支配する関係。必ずしも現実の所持・監視を要せず、占有の事実と占有の意思からなり、支配の有無は社会通念で決する（最判昭32.11.8）。
- **［規範クイズ 2/2］** 盗品等関与罪（256条）の保護法益と、処罰根拠とされる2つの性格を挙げよ。
  - 模範解答：保護法益＝被害者の追求権（盗品の正常な回復を求める権利）。処罰根拠は①追求権侵害（違法性の本体）に加え、②本犯を助長・誘発する事後従犯的（犯罪助長的）性格を併有する点にある。

## 4. ○×クイズ（全9問・1問目から最後まで全部出す）

- **［○×クイズ 1/9］** 複数人が登場する事例では、被害者や単に救助しただけの者など「犯罪となりうる行為をしていない者」は、罪責検討の対象から外してよい。
  - 正解：○（正しい）
  - 理由：「罪責を論ぜよ」の検討対象は、犯罪を構成しうる行為をした者に絞る。本問ではA（被害者）を冒頭で切り、甲・乙・丙に絞る。
- **［○×クイズ 2/9］** 他人が占有する財物を奪えば窃盗罪（235条）だが、誰も占有していない物（遺失物等）を領得した場合は、占有離脱物横領罪（254条）にとどまる。
  - 正解：○（正しい）
  - 理由：窃盗罪は「他人の占有」を侵害する罪。占有を離れた物の領得は占有離脱物横領罪（法定刑も大きく軽い）にとどまる。だから「置き忘れ財物になお占有が及ぶか」が、適用罪名を分ける最初の関門になる。
- **［○×クイズ 3/9］** 盗品等関与罪（256条）が成立するには、その前提として本犯（窃盗等の財産犯）が既遂に達し、客体が「財産犯によって領得された物＝盗品」であることが必要である。
  - 正解：○（正しい）
  - 理由：盗品等関与罪は本犯の存在を前提とする犯罪（事後従犯的性格）。客体「盗品等」は財産犯により領得され被害者が追求権を持つ物をいう。
- **［○×クイズ 4/9］** 盗品等関与罪（256条2項）の故意としては、その物が財産犯によって領得された物であること（盗品性）の認識があれば足り、未必的な認識でもよい。
  - 正解：○（正しい）
  - 理由：盗品等関与罪の故意は、客体が盗品等であることの認識で足り、確定的認識まで不要（未必的でも可）。本問の乙は「甲から事情を伝えられ」、丙は「昨日の出来事」を聞いており、いずれも盗品性の認識に欠けない＝故意は一言で通る。
- **［○×クイズ 5/9］** 占有の有無を判断する際、行為者が被害者の置き忘れを認識していた事情は、被害者の占有を基礎づける（占有を肯定する）事情として、占有判断に取り込むべきである。
  - 正解：×（誤り）
  - 理由：占有の有無は客観的に判断すべきで、行為者の主観（置き忘れの認識）は取り込まない。これは故意の段階で考慮する事情。
- **［○×クイズ 6/9］** 公衆が自由に出入りできる場所に財物を置き忘れた事案では、占有の有無は、行為時における被害者と財物との場所的・時間的離隔を第一次的な指標として、社会通念により判断する。
  - 正解：○（正しい）
  - 理由：置き忘れ事案では、画一的な距離・時間ではなく、行為時の被害者と財物の場所的・時間的離隔を中核に社会通念で決する（最決平16.8.25＝ポシェット事件）。離隔が小さければ占有は失われていない。
- **［○×クイズ 7/9］** 盗品等関与罪の親族間の特例（257条1項）は、本犯の被害者と盗品等関与罪の犯人との間に親族関係があるときに、その刑が免除される趣旨である。
  - 正解：×（誤り）
  - 理由：必要なのは本犯者と盗品等関与罪の犯人との間の親族関係（最決昭38.11.8）。被害者との関係ではない。趣旨＝親族間の犯人庇護は期待可能性が乏しい、という一身的処罰阻却に求めるから、本犯者との関係で判断する。
- **［○×クイズ 8/9］** 盗品を被害者本人に有償で売りつける処分のあっせんも、被害者による盗品の正常な回復を困難にするから、盗品等有償処分あっせん罪（256条2項）に当たる。
  - 正解：○（正しい）
  - 理由：被害者を処分の相手方とする場合でも、本来負担なく回復できるはずの被害者に出捐を強いる以上、正常な回復を困難にし、かつ犯罪を助長・誘発する（最決平14.7.1）。
- **［○×クイズ 9/9］** 窃盗の本犯者が、自ら窃取した盗品を運搬・保管・処分したときは、窃盗罪とは別に盗品等関与罪（256条）が成立し、両罪は併合罪となる。
  - 正解：×（誤り）
  - 理由：盗品等関与罪は本犯者以外の者の関与を処罰する罪で、本犯者は主体になりえない。本犯者自身の事後的な運搬・保管・処分は、先行する窃盗の違法評価に包摂される不可罰的事後行為で、別罪を構成しない。盗品罪の検討では、まず「その者は本犯者か」を確認して主体から切る。
