- 結論：窃盗未遂罪（243・235）成立／侵入＋窃盗＝牽連犯、これと窃盗未遂は併合罪

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【争いのない要件】論点にならず、あっさり認定する要件
  - 通帳等の財物性／錯誤・交付／A銀行の処分権限＝阻却なく一言で素通り。
- 【規範の要点】「挙動による欺罔・重要事項性」の規範
  - 欺罔行為＝相手方が財産的処分行為をする判断の基礎となる重要な事項を偽ること。財産罪ゆえ重要事項は経済取引上重要なものに限る。譲渡目的を秘した口座開設の申込みは「自己利用の意思」を表す挙動による欺罔。
- 【効く事実】「挙動による欺罔・重要事項性」のあてはめで使う事実
  - 重要事項性 → 約款で譲渡が一切禁止／反する意図が分かれば銀行は開設を謝絶／謝絶は銀行の信用性維持のため＝経済取引上重要。挙動 → 譲渡目的を秘した自己名義の開設申込み。
- 【規範の要点】「既遂時期／引出窃盗／不能犯／実行の着手」の規範
  - 既遂時期＝振込入金時に同額を自由処分できる状態に置けば既遂（乙と共犯で口座を管理＝障害なし）。引出窃盗＝機械は欺けず、譲渡禁止で正当な払戻権限なし＝意思に反する占有移転。不能犯＝結果発生の危険性で区別（具体的危険説）。着手＝窃取に密接し現実的危険を惹起した時点。
- 【効く事実】「既遂時期／引出窃盗／不能犯／実行の着手」のあてはめで使う事実
  - 不能犯否定 → 暗証番号が別口座とは一般人も丙も認識しえなかった／盗んだ通帳＋暗証番号メモでATM操作には引出しの現実的危険。着手肯定 → 残高照会は引出しの直前準備で一連一体／占有移転の現実的危険を惹起。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 実行行為をしない背後者でも、意思連絡＋正犯意思があれば共謀共同正犯（60条）で正犯になる。締めは罪数を1段落で：被害者・行為が別なら別罪→併合罪（45条前段）、手段目的の関係なら牽連犯（54条1項後段）。包括一罪と誤らない。
- 【まぎらわしい選択肢・論点】2項詐欺（財産上の利益）／不法領得の意思の要否／中止犯の成否
- 【まぎらわしい選択肢・結論】2項詐欺 成立／窃盗 既遂罪 成立／不能犯として不可罰／包括一罪
- 【まぎらわしい選択肢・規範】抽象的危険説／形式的客観説／純主観説
- 【まぎらわしい選択肢・事実】甲自己名義の口座／暗証番号は正しかった／現金を引き出した／意思連絡なし

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

乙＝自己名義でも挙動による欺罔、譲渡禁止＝重要事項、A銀行に1項詐欺（甲と共同正犯）。甲＝共謀共同正犯、振込入金時に既遂、ATM引出しは機械欺けず正当権限なしで窃盗、3罪は併合罪。丙＝侵入＋通帳窃取、暗証番号別口座でも一般人は知り得ず不能犯否定、残高照会は引出しに密接で着手あり、窃盗未遂。

## 4. ○×クイズ（全13問・1問目から最後まで全部出す）

- **［○×クイズ 1/13］** 一連の経済犯罪（口座開設→嘘の電話→現金引出し）でも、行為ごとに財産侵害を切り分け、各行為につき別個に罪を検討するのが基本である。
