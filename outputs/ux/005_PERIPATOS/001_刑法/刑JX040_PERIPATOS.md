## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

Xは、スナックを経営する甲女に好意を抱き、高価な時計、ネックレス等をたびたびプレゼントしていた。しかし甲は、それらの品は受け取っていたものの、Xと交際する気は全くなく、デートの誘いをはぐらかしていた。ある日Xは、スナックで酒を飲み、他の客もいなかったことから、甲に交際を強く迫ったが、甲から、他に交際している男性がいるといわれたため、頭に血が上り、強いて姦淫（注：現行法では「性交」（177条））してしまおうと考え、甲に突然飛びかかり、その顔面を殴打して負傷させた上、さらに頸部を両手で締め上げた。これによって、甲はぐったりして人事不省に陥った。Xはこれを見て、甲を殺害してしまったと思い込み、犯行がばれないように強盗の仕業に見せかけようと考えて、店内を荒らし、甲が身につけていた高価な装飾品などを取り、また、レジスターをこじ開けて金品を持ち出した。以上の事案におけるXの罪責について論じなさい。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 好意・高価な贈与 → 甲は受け取るが交際拒絶
- 交際を強く迫る → 「他に交際相手」と拒絶される
- 姦淫しようと飛びかかり、顔面殴打→負傷、頸部を絞扼
- 甲が人事不省 → Xは「殺害した」と思い込む（客観は生存）
- 強盗偽装目的で店内を荒らし、装飾品・レジ金品を奪取

### 入口の問い（3問）

- **Q01［事案の整理］** 行為者と「引っかかる行為」を挙げて
  - 答え：行為者はXだけ。甲は被害者＝対象外。ここで切るのが第一歩。
  - 答え：Xの行為を時系列で3つに分節：①姦淫目的で殴打・絞扼→負傷（第1行為）／②「殺した」と誤信／③装飾品・レジ金品を奪取（第2行為）。
  - 答え：行為を切り分けると、第1＝性犯罪／第2＝財産犯と別々の罪で検討できる。
- **Q02［見当づけ］** 各行為は「何罪っぽい？」 ― 見当をつけて
  - 答え：第1行為：「強いて姦淫」＋顔面殴打で負傷 → 強制性交等致傷罪（181条2項）系。第2行為：装飾品・金品を奪取 → 窃盗（235条）系。暴行の時点で財物奪取の意思はない（姦淫目的）から、強盗（236条）ではないのがミソ。
- **Q03［論点］** 第2行為（窃盗）で問題になる論点を挙げて（3つ）
  - 答え：CP①：Xは「殺した」と誤信 → 死者の占有＝窃盗の故意。（死者には占有がないのが原則。死んだと誤信した者に"占有侵害の認識"があるかという主観面の問題）
  - 答え：CP②：強盗偽装＝証拠隠滅目的での奪取 → 不法領得の意思（利用処分意思）。（利用処分意思＝物の経済的用法に従い利用・処分する意思。毀棄隠匿目的を窃盗から外すための要件）
  - 答え：CP③：暴行は姦淫目的・奪取意思は誤信後 → 強盗罪の不成立。（暴行・脅迫の時点で奪取意思がなければ手段性を欠く）

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「強いて姦淫しようと…顔面を殴打して負傷させ、頸部を両手で締め上げた」 → （手段の暴行＋ケガ）
- 【拾う事実】「性交には至っていない」 → （基本犯の帰趨）
- 【拾う事実】「甲を殺害してしまったと思い込み」 → （主観と客観のズレ）
- 【拾う事実】「強盗の仕業に見せかけよう」 → （奪取の目的）
- 【拾う事実】「身につけていた高価な装飾品」「レジをこじ開けて金品」 → （客体・占有の態様）
- 【拾う事実】『誤信の後』 → （暴行との前後関係）
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 第1行為：「暴行」＝反抗を著しく困難にする程度→該当／性交は未遂だが致傷あり→181条2項一文。第2行為の客観面：甲は生存→占有侵害は当然に充足。
- 【規範の要点】「死者の占有」の規範
  - 死者そのものに占有はないが、被害者を死亡させた者との関係では、一連の行為を全体として観察し、生前の占有を侵害したと認められる限度で占有侵害（の認識）を肯定できる（最判昭41.4.8・百選Ⅱ29）。
- 【効く事実】「死者の占有」のあてはめで使う事実
  - 先行行為 → 自ら絞扼して人事不省に陥らせた（占有を弛緩させた）／近接性 → 殺害（と誤信）の直後・同一店内＝時間的場所的近接・同一機会／占有の強固さ → 「身につけていた」装飾品。
- 【規範の要点】「不法領得の意思（利用処分意思）」の規範
  - 利用処分意思は領得罪と毀棄隠匿罪を区別するために要求される。そうすると、単純に毀棄・隠匿する目的で奪ったとは認められない場合には、なお経済的用法に従い利用処分する意思を認めうる（東京高判平12.5.15）。効用享受説からは否定もありうる。
- 【効く事実】効く事実／書き分け
  - 肯定（裁判例）→ 破壊・隠匿目的ではない以上、利用処分意思を否定すべき場合に当たらない＝窃盗成立。否定（効用享受説）→ 隠蔽の道具として奪っただけで物自体から効用を得ていない＝窃盗不成立（占有離脱物横領にとどまる）。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 各行為の成否を出したら最後に罪数処理を一言。保護法益を異にする別個の行為なら原則は併合罪（45条）。手段・目的の関係なら牽連犯（54条後段）、一個の行為で数罪なら観念的競合（54条前段）。
- 【まぎらわしい選択肢・論点】死者の占有を客観面で論じる／抽象的事実の錯誤
- 【まぎらわしい選択肢・結論】占有離脱物横領罪 成立／強盗罪 成立／強盗殺人罪 成立
- 【まぎらわしい選択肢・規範】死者にも当然に占有が認められる／効用享受説で利用処分意思を否定
- 【まぎらわしい選択肢・事実】当初から財物奪取目的での殺害／暴行時に奪取意思あり

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

強制性交等致傷＝姦淫目的の暴行は反抗を著しく困難にする程度→該当。性交は未遂だが致傷結果あり→181条2項成立。窃盗＝暴行は姦淫目的・奪取意思は誤信後→強盗不成立。客観は甲生存＝占有侵害充足。死者の占有は主観面で、一連の行為を全体観察し生前占有侵害の認識○→故意肯定。利用処分意思は破壊・隠匿目的でない→○→窃盗成立。罪数＝保護法益が別で併合罪（45前段）。

## 3. 規範クイズ（2問）

- **Q04［規範］** 「死者の占有」で、死んだと誤信した者に窃盗の故意（占有侵害の認識）を認めるための規範を、口頭で言い切れるか挙げよ。
  - 模範解答：「死者そのものに占有はないが、被害者を死亡させた者との関係では、一連の行為を全体として観察し、生前の占有を侵害したと認められる限度で、なお生前の占有を刑法上保護する。本件でXは自ら絞扼した直後・同一店内（同一機会）で奪取したから、その認識を基準としても生前占有侵害と評価でき、占有侵害の認識＝窃盗の故意（38条1項）が認められる」と言えれば合格。
- **Q05［規範］** 不法領得の意思の定義（二要素）と、それぞれが「何と区別するための要件か」を口頭で言い切れるか挙げよ。
  - 模範解答：「①権利者を排除して他人の物を自己の所有物としてその経済的用法に従い、②これを利用し又は処分する意思（大判大4.5.21）。①権利者排除意思は不可罰的な使用窃盗との区別、②利用処分意思は毀棄隠匿罪との区別のために要求される」と言えれば合格。

## 4. ○×クイズ（11問）

- **Q06［○×］** 単独の行為者でも、その者の行為が時系列で複数に分かれるなら、各行為ごとに別々の構成要件該当性を検討するのが基本である。
  - 正解：○（正しい）
  - 理由：「一人＝一罪」ではない。行為を分節し、各行為に対応する罪名を立てる。本問は第1行為（性犯罪）と第2行為（財産犯）に分かれる。
- **Q07［○×］** 暴行・脅迫を加えた後に初めて財物奪取の意思が生じ、その財物を奪った場合、強盗罪ではなく窃盗罪の成否を検討するのが筋である。
  - 正解：○（正しい）
  - 理由：強盗罪は「暴行・脅迫を手段として」財物を強取する罪。暴行時に奪取意思がなければ手段性を欠き、強盗ではなく窃盗を疑う。
- **Q08［○×］** 強制性交等罪の手段である暴行で相手に傷害結果を生じさせたが、性交自体は未遂に終わった。この場合、致傷罪は成立しえない。
  - 正解：×（誤り）
  - 理由：強制性交等致死傷罪（181条2項）は結果的加重犯で、基本犯が未遂でも致死傷結果が生じれば成立する。性交未遂＝致傷罪も不成立、は誤り。
- **Q09［○×］** 死者には占有が認められないから、被害者を死亡させたと誤信した者が物を取った場合、それだけで占有侵害がなく窃盗罪は成立しえない。
  - 正解：×（誤り）
  - 理由：「死者に占有なし→窃盗にならない」で止めるのが最頻出の誤り。被害者を死亡させた者との関係では、一連の行為を全体観察し生前の占有侵害が認められれば窃盗となる。
- **Q10［○×］** 被害者が実際には生存しているのに、行為者が「殺した」と誤信して物を取った場合、客観的には占有侵害があり、いわゆる「死者の占有」は主観面（故意）の問題として現れる。
  - 正解：○（正しい）
  - 理由：被害者が生きていれば客観的占有侵害は当然にある。死者の占有は「死んだと誤信した者に占有侵害の認識（故意）があるか」という主観面でのみ問題になる。
- **Q11［○×］** 窃盗罪の成立には、条文に明文のない主観的超過要素として不法領得の意思（①権利者排除意思＋②利用処分意思）が必要である。
  - 正解：○（正しい）
  - 理由：不法領得の意思は、使用窃盗との区別（①権利者排除意思）と毀棄隠匿罪との区別（②利用処分意思）のために要求される（大判大4.5.21）。
- **Q12［○×］** 財物を奪う際に暴行を加えていれば、その暴行が当初は財物奪取と無関係の目的でなされたものであっても、当然に強盗罪が成立する。
  - 正解：×（誤り）
  - 理由：強盗罪は暴行・脅迫を「手段として」財物を強取する罪。暴行時に財物奪取意思がなければ手段性を欠き、強盗ではなく窃盗にとどまる。
- **Q13［○×］** 被害者を死亡させた者が、その死亡直後に同一機会で被害者の財物を奪った場合、判例は生前の占有侵害として窃盗罪の成立を認める。
  - 正解：○（正しい）
  - 理由：最判昭41.4.8。時間的・場所的近接性のある同一機会の奪取に限り、占有離脱物横領ではなく窃盗とする。第三者が通りすがりに取った場合（占有離脱物横領）とは区別。
- **Q14［○×］** 不法領得の意思のうち利用処分意思は、領得罪（窃盗等）と毀棄・隠匿罪とを区別するために要求される要素である。
  - 正解：○（正しい）
  - 理由：領得罪は毀棄罪より法定刑が重い。利用・処分意思に出た領得の方が違法・有責性が高いため、毀棄隠匿目的にすぎない場合を窃盗から外す機能をもつ。
- **Q15［○×］** 利用処分意思の有無が結論を分けうる論点では、肯定説・否定説のいずれの結論でも、規範の機能に遡って理由を尽くせば高く評価されうる。
  - 正解：○（正しい）
  - 理由：結論の当否ではなく論証の説得力で採点される論点。「何と区別するための要件か」から逆算して説明できるかが鍵。
- **Q16［○×］** 科刑上一罪である牽連犯（54条1項後段）が成立するのは、複数の犯罪が「一個の行為」で実現された場合である。
  - 正解：×（誤り）
  - 理由：「一個の行為」で数罪を実現するのは観念的競合（54条1項前段）。牽連犯は数個の行為が手段・目的の関係に立つ場合。いずれの科刑上一罪にも当たらず別個独立の犯罪なら併合罪（45条前段）。この三分の判別が罪数処理の基本。
