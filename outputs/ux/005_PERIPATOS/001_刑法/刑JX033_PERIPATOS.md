  - ①230条の2＝表現の自由と名誉保護の調和規定＝違法性阻却事由。②真実性の錯誤＝真実と誤信し、確実な資料・根拠に照らし相当の理由があれば犯罪の故意を欠き不成立（最大判昭44.6.25）。

  - 相当の理由 → 「Xの話を真に受けた」＝裏付け取材を欠く伝聞の鵜呑み（自取材を散りばめた程度では足りない）→ 相当の理由なし。第3項 → Aは「代議士」＝公務員・公選候補者。
- 【規範の要点】伝播性の理論の規範
  - 「公然」とは不特定又は多数人が認識し得る状態をいい、直接の相手が特定少数でも、そこから不特定多数へ伝播する可能性があれば公然性を認める（最判昭34.5.7）→ 相手は新聞記者で記事化により拡散 → 公然性肯定。
- 【効く事実】Xで効く事実／230条の2は不適用
  - 伝播可能性 → 相手は「北の国新聞」の記者・現に記事化されて拡散。Xは「有ること無いことを織り交ぜ」＝真実性の証明不可・真実と誤信もなし → 230条の2の違法性阻却も故意阻却もなし。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 複数人が登場したら最後に共犯（60条）を一言。出発点は意思連絡（共同実行の意思）の有無。意思連絡があれば共同正犯を検討、無ければ各自が単独犯。本問は X・Y 間に意思連絡がなく各自が別個に名誉毀損を実現＝共同正犯を論ずる実益は乏しく各自単独犯。
- 【まぎらわしい選択肢・論点】正当防衛の成否／侮辱罪との区別
- 【まぎらわしい選択肢・規範】処罰阻却事由説／厳格責任説／伝播性否定説
- 【まぎらわしい選択肢・結論】名誉毀損罪 不成立／侮辱罪 成立
- 【まぎらわしい選択肢・事実】裏付け取材で真実と確認／公開の記者会見で多数に発表

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

Y＝新聞掲載＝公然・事実摘示＝名誉毀損の構成要件該当（抽象的危険犯）／230条の2は違法性阻却事由・Aは代議士＝3項で真実性の証明のみで足りる／証明不奏功 → 真実性の錯誤＝確実な資料・根拠に照らし相当の理由があれば故意阻却（最大判昭44.6.25）／Xの話を真に受けただけ＝相当の理由なし → 名誉毀損罪（230条1項）成立。X＝相手は記者一人＝特定少数だが伝播性の理論（最判昭34.5.7）で公然性肯定／「有ること無いこと」＝真実性の証明不可・誤信なし → 名誉毀損罪（230条1項）成立。共犯＝XY間に意思連絡なし → 各自単独犯。

## 3. 規範クイズ（全2問・1問目から最後まで全部出す）

- **［規範クイズ 1/2］** 「230条の2と真実性の錯誤」の規範を一文で言うと？
  - 模範解答：①230条の2＝表現の自由と名誉保護の調和規定＝違法性阻却事由。②真実性の錯誤＝真実と誤信し、確実な資料・根拠に照らし相当の理由があれば犯罪の故意を欠き不成立（最大判昭44.6.25）。
- **［規範クイズ 2/2］** 伝播性の理論の規範を一文で言うと？
  - 模範解答：「公然」とは不特定又は多数人が認識し得る状態をいい、直接の相手が特定少数でも、そこから不特定多数へ伝播する可能性があれば公然性を認める（最判昭34.5.7）→ 相手は新聞記者で記事化により拡散 → 公然性肯定。

- **［○×クイズ 4/10］** 名誉毀損罪は、現実に被害者の社会的評価が低下したことが証明されなければ成立しない。
