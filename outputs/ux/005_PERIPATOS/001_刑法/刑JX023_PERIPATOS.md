## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

医者である甲は、甲の妻と不倫しているAが自己の経営する病院に入院してきたことから、これを機にAを殺害しようと考えた。甲は、看護師資格を取ったばかりで甲の病院に勤務し始めて間もない乙に対し「この点滴をAさんに投与してください。」と言って毒薬を手渡した。乙は、過去に一度だけ甲の指示で点滴をしたことがあったため今回も同様だろうと考え、これを受け取りAの病室へ向かった。乙はAの寝ているベッドの脇で点滴の準備をしていたところ、前日にたまたま医学雑誌で見た毒薬と甲から手渡されたものが合致していることに気付き、これが毒薬であると分かった。乙はこれに戸惑ったものの、Aの入院中にセクハラ被害を受けていたことから、この毒薬で殺してしまおうと考え、Aに毒薬を投与しAを死亡させた。その後、乙が、Aの鞄の中を一瞥したところAの財布を発見した。乙は財布からお金を抜き取っても誰も分からないだろうと考え、Aの財布から3万円を抜き取った。甲及び乙の罪責について論じなさい。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 甲がAの殺害を決意
- 甲が乙に毒薬を「点滴」と偽り交付（乙は誤信＝この時点は道具）
- 乙が準備中に毒薬と気付く（道具性が失われる）
- 乙が自らの怨恨で殺意を抱きAに投与・A死亡
- 乙がA死亡後その場で財布から現金3万円を奪取

- **Q01［事案の整理］** 登場人物と「引っかかる行為」を挙げて
  - 答え：乙＝毒薬投与で殺害（作為）＋A死後に財布から3万円奪取（作為）。甲＝乙に毒薬を「点滴」と偽って交付した働きかけ。
  - 答え：A＝被害者は検討対象外。乙→甲の順で組み立てるのが第一歩。
- **Q02［見当づけ］** 各行為は「何罪っぽい？」 ― 見当をつけて
  - 答え：乙：毒薬投与でA死亡＝殺人（199条）／死後に財布から現金＝窃盗（235条）か占有離脱物横領（254条）。甲：乙を道具にしてAを殺そうとした＝殺人の間接正犯。ただし乙が裏切っている点が罠。
- **Q03［論点］** 「立ち止まる石（論点）」を挙げて（4つ）
  - 答え：CP①（乙）：死後に財布から現金 → 死者の占有（窃盗か占有離脱物横領か）。（死者に占有を観念できるか）
  - 答え：CP②（甲）：乙を道具に使うつもりが乙が離反 → 殺人の間接正犯の成否（行為支配性）。（被利用者を一方的に支配して結果へ向けたか）
  - 答え：CP③（甲）：客観は教唆なのに主観は間接正犯 → 間接正犯の故意で教唆を実現した錯誤。（重なり合う限度で軽い故意）
  - 答え：CP④（甲）：実行の着手時期 → 殺人未遂の間接正犯の成否。意思連絡なし → 共犯。

### 骨子（3項目。第1から【論点】ごとに、何が問題→規範→使う事実→結論 の順で組み立てる）

#### 第1　乙の罪責

- 見出しの補足（結論を含む。項目の終わりに読む）：殺人＋死者の占有
1. 乙は毒薬投与でAを死亡させた → 殺人罪（199条）成立（違法性・責任の阻却事由なし＝端的に確定）
2. 【論点】死者の財物奪取は窃盗か占有離脱物横領か（規範：自ら殺害した者との関係で一連の行為を全体的に観察し生前の占有を侵害と評価できれば窃盗・最判昭41.4.8）
   - あてはめ：乙はA殺害の直後にその場で財布から3万円を奪取 → 殺害から奪取が時間的場所的に近接＝生前の占有を侵害
   （当初領得意思なしで強盗は否定・殺人と窃盗は併合罪）
- 結論：窃盗罪 成立

#### 第2　甲の罪責

- 見出しの補足（結論を含む。項目の終わりに読む）：間接正犯と錯誤
1. 【論点】殺人の間接正犯の成否（規範：被利用者への行為支配性と正犯意思）→ 乙が毒薬と気付き自らの意思で殺害を決意した時点で道具性が失われ甲の行為支配性は喪失
   - あてはめ：→ 殺人既遂の間接正犯は不成立（正犯が並び立つ不合理からも支持）
2. 【論点】実行の着手時期と殺人未遂の間接正犯（規範：結果発生の現実的危険が生じた時点・被利用者標準説）→ 毒薬交付時は乙の行為を介して初めて結果に至り現実的危険は未発生
   - あてはめ：→ 殺人未遂の間接正犯も不成立（利用者標準説なら成立の余地）
3. 【論点】間接正犯の故意で教唆を実現した錯誤（規範：故意責任の本質＝反対動機形成から構成要件的に重なり合う限度で故意／間接正犯の故意は教唆の故意を含む）
   - あてはめ：客観的に甲は乙に犯意を生じさせ教唆を実現／間接正犯と教唆は他人利用の点で共通 → 軽い教唆犯の限度で処断
- 結論：甲に殺人既遂罪の教唆犯（61条1項）成立

#### 第3　甲と乙の共犯

1. → 共同正犯不成立（60条）
- 結論：乙＝単独正犯・甲＝教唆犯

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】『「この点滴をAさんに投与してください」と偽り毒薬を交付』 → 甲が乙を道具とみた働きかけ（間接正犯の故意・客観は教唆）
- 【拾う事実】『乙が毒薬であると分かった』 → 道具性の喪失（甲の行為支配が切れる時点）
- 【拾う事実】『乙はこの毒薬で殺してしまおうと考え投与』 → 乙が自らの意思で実行（直接正犯の確定）
- 【拾う事実】『A死亡後に財布から3万円を抜き取った』 → 殺害直後・その場（死者の占有の近接性）
- 【拾う事実】『当初は財物を奪う意思の記載なし』 → 強盗を否定する根拠（領得意思の発生時点）
- 【事案の整理】利用関係はまず直接手を下した者から
  - 背後者（甲）と実行者（乙）がいる事案では、直接実行した乙から確定するのが鉄則。乙が決まらないと、甲が正犯か共犯かを評価できない。
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 乙の殺人＝毒薬投与で死亡・故意あり＝争いなく成立（短く）。
- 【効く事実】あてはめで使う事実
  - 死者の占有 → 殺害直後・その場・財布から3万円（時間的場所的近接）／間接正犯の否定 → 乙が毒薬と気付いた時点で離反＝行為支配の喪失／錯誤 → 甲は道具のつもり（間接正犯の故意）なのに客観は教唆。
- 【規範の要点】行為支配説の規範
  - 正犯とは自らの意思で犯罪を実現し第一次的責任を負う者。被利用者への①行為支配性と②正犯意思があれば間接正犯。乙が毒薬と気付き離反した時点で行為支配性は失われる → 殺人既遂の間接正犯は不成立。客観的には教唆を実現。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 2人以上が関与したら、最後に共犯（60条）を一言だけ。本問は甲を教唆犯と評価済みなので、共同正犯の不成立を確認すれば足り、承継的共犯等へ深入りしない。
- 【まぎらわしい選択肢・論点】正当防衛の成否／共謀共同正犯の成否／因果関係の錯誤
- 【まぎらわしい選択肢・結論】占有離脱物横領罪 成立／強盗殺人罪 成立／殺人未遂罪の間接正犯 成立
- 【まぎらわしい選択肢・規範】占有否定説／利用者標準説
- 【まぎらわしい選択肢・事実】当初からの領得意思／暴行による反抗抑圧

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

乙＝毒薬投与で殺人、財布は強盗否定→殺害者との関係で死者の占有肯定→窃盗、殺人と窃盗は併合罪。甲＝乙の離反で行為支配喪失→間接正犯否定、交付時に危険なしで未遂の間接正犯も否定、客観は教唆→重なり合いで軽い教唆犯。二人＝意思連絡なしで共同正犯なし。

## 3. 規範クイズ（3問）

- **Q04［規範］** 死者の財物を奪った行為につき、窃盗罪を肯定する判例（占有継続説）の規範を挙げよ（誰との関係で・どう評価するか）。
  - 模範解答：被害者が生前有した財物の所持は死亡直後もなお継続して保護するのが法の目的にかなう。そこで自ら被害者を殺害した者との関係では、殺害から奪取に至る一連の行為を全体的に観察し、生前の占有を侵害したと評価できる限度で他人の占有を肯定する（最判昭41.4.8）。第三者の奪取は占有離脱物横領にとどまる。
- **Q05［規範］** 間接正犯の成立要件（2つ）を挙げ、被利用者が事情を知って独自の意思で実行した場合にどうなるかを述べよ。
  - 模範解答：①被利用者に対する行為支配性（因果経過の一方的・実質的支配）②他人の犯罪を自己の犯罪として実現する正犯意思。被利用者が事情を了知して独自の意思で実行した時点で行為支配性は失われ、間接正犯は成立しない（関与形式は教唆へ評価し直される）。
- **Q06［規範］** 間接正犯の故意で客観的に教唆を実現した場合、どの理論でどう処断するか（故意の本質→重なり合い→結論）を述べよ。
  - 模範解答：故意責任の本質は反対動機を形成しえたのにあえて犯罪に及んだ非難。認識事実と実現事実が構成要件的に実質的に重なり合う限度で故意を認める。間接正犯と教唆犯は他人を利用して結果を生じさせる点で共通し、間接正犯の故意は教唆犯の故意を含む。間接正犯は犯情が重いので軽い教唆犯の限度で処断する。

## 4. ○×クイズ（4問）

- **Q07［○×］** 財物奪取の意思を生じたのが被害者を殺害した後であっても、その奪取行為は、暴行・脅迫を手段とする以上、当然に強盗罪（236条）を構成する。
  - 正解：×（誤り）
  - 理由：強盗罪は、財物奪取の手段として反抗を抑圧する暴行・脅迫を加えることを要する。殺害時に領得意思がなく、殺害後に初めて奪取意思を生じた場合、暴行は財物奪取の手段ではないから強盗罪は成立せず、窃盗罪か占有離脱物横領罪の問題となる。
- **Q08［○×］** 抽象的事実の錯誤において、認識した事実より実現した事実の方が軽い場合でも、重い罪の故意犯が成立しうる。
  - 正解：×（誤り）
  - 理由：重なり合いの限度でしか故意は認められず、しかも軽い方の罪の限度で処断する（軽い罪の故意既遂）。認識が重く実現が軽い場合に重い罪の既遂を認めるのは、実現していない結果に故意を認めることになり許されない。
- **Q09［○×］** 他人を道具として利用するつもりだった背後者について、被利用者が途中で事情を了知し自らの意思で犯行に及んだ場合、背後者の行為支配は失われ、殺人既遂の間接正犯は成立しない。
  - 正解：○（正しい）
  - 理由：間接正犯は被利用者を一方的に支配・利用して因果経過を実質的に支配する点に正犯性がある。被利用者が事情を了知し独自の意思で実行すれば、もはや道具ではなく、背後者の行為支配性は失われる。直接正犯が成立する以上、背後者を併せて正犯とすると正犯が並び立ち不合理でもある。
- **Q10［○×］** 複数人が意思の連絡なく、たまたま同一の客体に対し各自の犯罪を実現した場合は「同時犯」と呼ばれ、各人は自己の行為と結果についてのみ単独で責任を負う。
  - 正解：○（正しい）
  - 理由：共同正犯（60条）は共同実行の意思（意思連絡）と共同実行の事実を要する。意思連絡を欠けば共同正犯は成立せず同時犯となり、「一部実行全部責任」も働かず各自が自己の分のみ単独で負う。
