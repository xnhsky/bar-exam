## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

甲は、乙から「強盗に使うのでナイフを貸してくれ」と頼まれ、これに応じてナイフを乙に渡した。甲自身は強盗に加わる意思はなかった。乙は、丙・丁に対し「それぞれがナイフを準備してA宅に強盗に押し入ろう」と持ち掛け、3名で計画を立てた（乙が計画の主導的役割を果たした）。ところが乙は、犯行当日の朝に高熱を発したため、「おれはこの件から手を引く」と丙・丁に電話で告げ、両名の了承を得た。丙・丁は予定どおりA宅に強盗に押し入って現金を奪ったが、各自が準備したナイフを用い、甲が貸したナイフは使用されなかった。甲及び乙の罪責を論ぜよ（丙・丁の罪責及び特別法違反の点は除く）。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 甲が乙にナイフを貸す（甲は加わる意思なし）
- 乙が丙・丁に強盗を持ち掛け、3名で計画（乙が主導）
- 当日朝、乙が高熱→「手を引く」と電話、丙・丁が了承
- 丙・丁がA宅に押し入り現金を奪う（各自のナイフ使用）
- 甲が貸したナイフは使われなかった

### 参考（読み上げない。入口の問いの答えを含むので判定にだけ使う）

登場人物：
- 乙｜計画の主導者（→ナイフ準備・着手前に離脱表明）
- 甲｜ナイフ提供者（→自ら実行意思なし）
- 丙・丁｜実行犯＝対象外（罪責は問わない）
- A｜強盗の被害者＝対象外

### 入口の問い（5問）

- **Q01［事案の整理］** 登場人物と「引っかかる行為」を挙げて
  - 答え：実行犯は丙・丁（A宅に押し入り強盗）。だが設問は甲・乙の罪責に限定。丙・丁＝対象外・A＝被害者で対象外。ここで切る。
  - 答え：時系列：①甲がナイフ貸与 → ②乙が丙・丁と強盗を共謀（主導）→ ③乙が着手前に「手を引く」と離脱表明＋了承 → ④丙・丁が各自のナイフで強盗実行（甲のナイフは不使用）。
  - 答え：引っかかる行為＝乙の共謀・離脱、甲のナイフ提供。この2人を回す。
- **Q02［見当づけ］** 各行為は「何罪っぽい？」 ― 見当をつけて
  - 答え：乙：ナイフ準備＋強盗を共謀 → 強盗予備（237条）＋丙・丁の強盗の共謀共同正犯（236条1項・60条）系。だが着手前に離脱 → 共犯関係からの離脱。甲：強盗用ナイフを提供したが自分は実行しない → 予備の共同正犯（237条・60条・65条1項）か、離脱否定なら強盗の幇助（62条1項）系。
- **Q03［論点］** 乙で問題になる論点を挙げて（2つ）
  - 答え：CP①：乙は謀議しただけで自ら実行していない → 共謀共同正犯の成否。（＝実行行為を分担しなくても、意思連絡＋役割の重要性があれば共同正犯）
  - 答え：CP②：着手前に「手を引く」と表明＋了承 → 共犯関係からの離脱。（＝自分が与えた因果性が除去されれば、その後の他人の行為の責任を負わない）
  - 答え：通過点：離脱を認めても強盗予備罪（237条）は残る（離脱で無罪にしない）。
- **Q04［論点］** 「主導者なのに離脱できる」理由を一手
  - 答え：確かに乙は計画の主導者で心理的因果性が残存するとも見える。しかし統制し得る立場にないので与えた心理的因果性は軽微。表明＋了承で除去が肯定 → 離脱肯定。
  - 答え：対比：松江地判昭51.11.2は指導的地位＋物理的関与ゆえ離脱否定。本問の乙は指導的地位になく因果性が弱い＝離脱を認めやすい、と射程を切る。
- **Q05［論点］** なぜ三段が必要かを一手
  - 答え：いきなり予備の共同正犯を肯定すると、なぜ単独犯ではダメか・なぜ実行意思なき甲が入るかが飛ぶ。単独犯否定（他人予備）→ 共同正犯肯定（実行行為性）→ 65条1項（真正身分）の三段で穴を埋める。
  - 答え：乙の離脱を肯定したので残る正犯結果は強盗予備 → 甲は予備の共同正犯で締める（幇助にしない＝整合性）。最決昭37.11.8が予備の共同正犯を肯定。

### 骨子（3項目。第1から【論点】ごとに、何が問題→規範→使う事実→結論 の順で組み立てる）

#### 第1　乙の罪責

- 見出しの補足（結論を含む。項目の終わりに読む）：強盗予備＋共犯関係からの離脱
1. ナイフ準備＋強盗計画 → 強盗予備罪（237条）成立（離脱でも残る）
2. 丙・丁の住居侵入（130前段）・強盗（236①）の共同正犯か
- 【論点】共謀共同正犯＝意思連絡＋主導的役割（正犯性）→ 成立し得る
3. 着手前に「手を引く」＋了承 → 【論点】共犯関係からの離脱
   ├ 規範：処罰根拠＝因果性（因果的共犯論）→ 因果性除去で離脱／物理・心理の両面
   ├ 物理的因果性：ナイフ各自準備＝寄与なし → 除去
   - あてはめ：心理的因果性：統制力なし＋表明＋了承 → 軽微 → 除去 → 離脱肯定
   （対比：松江地判昭51.11.2＝指導的地位ゆえ離脱否定／本問は逆）
- 結論：強盗の共同正犯 ×、強盗予備罪（237条）のみ成立

#### 第2　甲の罪責

- 見出しの補足（結論を含む。項目の終わりに読む）：予備の共同正犯・他人予備
1. ナイフ提供＝強盗予備（237条）の単独犯？ but 自己実行意思なし
- 【論点】他人予備の否定（予備行為者は自己実行の目的要）→ 単独犯 ×
2. 【論点】予備行為の「実行」性 → 固有の構成要件＝「実行」（43条と60条の実行は別概念）
- 予備の共同正犯を認め得る（最決昭37.11.8）
3. but 甲は実行意思なき非身分者 → 【論点】65条1項
   - あてはめ：「目的」＝真正身分／65条1項の「共犯」に共同正犯を含む → 甲を取り込む
- 結論：乙とともに強盗予備罪（237条）の共同正犯

#### （予備的・択一）離脱を否定したら

   甲＝強盗の幇助犯（236①・62①）／幇助の因果性は容易化で足り、ナイフ未使用でも切れず

- 【拾う事実】「強盗に加わる意思はなかった」 → 甲は自ら実行しない
- 【拾う事実】「乙が計画の主導的役割」 → 乙の関与の重さ

- 【争いのない要件】論点にならず、あっさり認定する要件

- 【規範の要点】因果性除去説の規範
  - 共犯の処罰根拠は自己の行為が結果に与えた因果性にある（因果的共犯論）→ 後の結果との因果性が断ち切られたと評価できれば離脱を認める。除去は物理的因果性・心理的因果性の両面から判断。着手前なら結果防止措置までは不要。
- 【効く事実】「離脱」のあてはめで使う事実
  - 物理的因果性 → ナイフは各自準備・乙は物理的寄与なし＝除去／心理的因果性 → 「手を引く」表明＋丙・丁の了承＋乙は両名を統制し得る立場にない＝軽微・除去。確かに乙は主導的役割で心理的因果性が残るとも見える緊張を処理。
- 【規範の要点】「単独犯否定 → 予備の共同正犯 → 65条1項」の規範
  - ①予備行為者は自己が実行する目的を要する（他人予備否定）→ 実行意思なき甲に予備の単独犯は不成立。②予備行為も固有の構成要件＝「実行」に当たり（43条と60条の「実行」は別概念でよい）予備の共同正犯を認めうる。③「目的」は真正身分とみられ、65条1項の「共犯」に共同正犯を含むから非身分者の甲も取り込む。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 離脱や正犯性のように結論が分かれる論点は、自分の採った立場で本筋を通したうえで、反対の立場に立つとどうなるかを予備的に一言添えると視野の広さが示せる。ただし主従を逆転させない ── 採った立場の帰結（甲・乙＝予備の共同正犯）が本線、択一の幇助構成は一文の補論に留め、深入りしない。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 幇助の因果性は正犯と結果の条件関係までは要せず、正犯の実行を物理的・心理的に容易にした（促進した）といえれば足りる（促進的因果関係）。甲がナイフを渡したからこそ共謀がまとまり丙・丁が実行 → 現実に使われなくても因果性は切れない。
- 【まぎらわしい選択肢・論点】中止犯の成否／教唆犯の成否
- 【まぎらわしい選択肢・結論】強盗未遂罪 成立／離脱により全部無罪
- 【まぎらわしい選択肢・規範】他人予備肯定説
- 【まぎらわしい選択肢・事実】ナイフが現実に使用された

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

乙＝ナイフ準備＋強盗計画で強盗予備罪、丙丁との共謀共同正犯（意思連絡＋主導的役割）成立し得る、着手前に「手を引く」＋了承→因果性除去説で物理（各自準備＝寄与なし）・心理（統制力なし）の両面除去→離脱肯定、但し強盗予備罪は残る。甲＝ナイフ提供も自己実行意思なし→他人予備の否定で単独犯×、予備行為の「実行」性を認め予備の共同正犯、非身分者は65条1項（目的＝真正身分）で取り込む→乙とともに強盗予備罪の共同正犯。択一＝離脱否定なら甲は強盗幇助（因果性は容易化で足り未使用でも切れず）。

## 3. 規範クイズ（3問）

- **Q06［規範］** 自ら実行行為を分担しない者にも共同正犯（共謀共同正犯）が成立するための根拠と要件を挙げよ。
  - 模範解答：根拠＝60条が一部実行全部責任を認めるのは相互利用補充関係による犯行の一体性で、これは実行を分担しない者にも妥当する。要件＝意思連絡＋役割の重要性（正犯性）。両者が認められれば共謀共同正犯が成立する。
- **Q07［規範］** 共犯関係からの離脱の処罰根拠と判断基準（規範）を挙げよ。
  - 模範解答：共犯の処罰根拠は自己の行為が結果に与えた因果性にある（因果的共犯論）。後の結果と自己の行為との因果性が断ち切られたと評価できれば離脱を認める。除去の判断は物理的因果性・心理的因果性の両面から行う（片面だけだと減点）。
- **Q08［規範］** 予備罪の「○○の罪を犯す目的」につき他人予備が否定される理由と帰結を挙げよ。
  - 模範解答：予備は犯罪実行の前段階であるから、予備行為者は自ら実行する目的を要し、条文の「目的」も自己実行の目的と読むのが自然（判例・多数説＝他人予備の否定）。帰結＝実行意思なき者に予備の単独犯は成立しない。

## 4. ○×クイズ（14問）

- **Q09［○×］** 「甲及び乙の罪責を論ぜよ」と問われた共犯事例では、実際に手を下した実行犯の罪責も当然に論じなければならない。
  - 正解：×（誤り）
  - 理由：論じるのは設問が指定した者だけ。実行犯でも設問の対象外なら罪責は書かない（共犯成立の前提として正犯の成立に触れるのは別）。誰を問われているかを最初に確定する。
- **Q10［○×］** 強盗を計画して凶器を準備したが、実行の着手前にとどまる者には、まず強盗予備罪（刑法237条）の成否を検討するのが筋である。
  - 正解：○（正しい）
  - 理由：強盗の罪を犯す目的で予備をした者は237条（強盗予備）。着手があれば強盗未遂（236条・243条）に進む。段階で罪名を当てる。
- **Q11［○×］** 自分は犯罪を実行する気がないのに、他人の犯行のために凶器を提供した者は、提供した犯罪の正犯（共同正犯）になる可能性と、幇助犯になる可能性の両方を検討すべきである。
  - 正解：○（正しい）
  - 理由：関与の重さ（役割の重要性）と正犯結果が何かで、共同正犯か幇助かが分かれる。提供物が使われたか・正犯がどこまで進んだかで結論が動くので、両にらみでGUESSをする。
- **Q12［○×］** 狭義の共犯（教唆・幇助）の成立には、正犯の行為が構成要件に該当し違法であれば足り、正犯が有責であることまでは要しない（制限従属性説）。
  - 正解：○（正しい）
  - 理由：制限従属性説（通説）。共犯は正犯の違法な実行行為に従属して成立するので、正犯の構成要件該当性・違法性を先に固める必要がある＝「正犯結果を左右する者から先に書く」手順の理論的根拠。正犯の責任までは従属しない。
- **Q13［○×］** いったん共謀に加わり共同正犯となり得る者は、その後の共犯者の犯行結果について常に責任を負い、途中で抜けても責任を免れる余地はない。
  - 正解：×（誤り）
  - 理由：共犯の処罰根拠は結果への因果性付与（因果的共犯論）。与えた因果性が除去されたと評価できれば共犯関係からの離脱が認められ、その後の他の共犯者の行為について責任を負わない。
- **Q14［○×］** 共犯関係からの離脱が認められても、離脱者が離脱までに自ら完成させた犯罪（例：強盗予備罪）の罪責はなお残る。
  - 正解：○（正しい）
  - 理由：離脱は「その後の他の共犯者の行為」につき責任を負わせない法理にすぎず、既に成立した自己の予備罪を遡って消すものではない。離脱＝無罪としないこと。
- **Q15［○×］** 共犯者の1人が「自分は抜ける」と表明し他の共犯者の了承を得さえすれば、それだけで常に共犯関係からの離脱が認められる。
  - 正解：×（誤り）
  - 理由：意思表明＋了承だけでは足りない。物理的因果性（提供した凶器等）が残れば、その回収がない限り離脱は認められない。心理的因果性とあわせ両面で除去を判断する。
- **Q16［○×］** 実行の着手前の離脱は、着手後の離脱と異なり、結果防止のための積極的措置までは要せず、離脱の意思表明と他の共犯者の了承により心理的因果性が除去されうる。
  - 正解：○（正しい）
  - 理由：着手後は共謀に基づく実行が始まっているため結果防止措置による因果性の遮断を要する（最決平21.6.30）。着手前はそこまで不要で離脱が認められやすい。区別を明示すると加点。
- **Q17［○×］** 共謀の主導的役割を果たした者は、心理的因果性が常に残存するため、共犯関係からの離脱はおよそ認められない。
  - 正解：×（誤り）
  - 理由：主導的役割でも、他の共犯者を統制し得る立場にない等で与えた心理的因果性が軽微なら、表明＋了承で除去が肯定されうる。「主導者＝離脱不可」と機械的に決めない。
- **Q18［○×］** 予備行為もそれ自体固有の構成要件である以上、60条の「実行」に当たり、予備罪についても共同正犯が成立しうる。43条（着手）の「実行」と60条の「実行」概念は一致を要しない。
  - 正解：○（正しい）
  - 理由：予備の共同正犯を肯定する筋（最決昭37.11.8）。43条は予備と未遂の区別を定めた条文にすぎず、60条の「実行」と概念一致は不要。予備行為の固有構成要件性から実行行為性を認める。
- **Q19［○×］** 「○○の罪を犯す目的」のように、それがなければそもそも犯罪が成立しない要素は真正身分と捉えられ、65条1項により、その目的を欠く非身分者も身分者と共同して共同正犯となりうる（65条1項の「共犯」には共同正犯を含む）。
  - 正解：○（正しい）
  - 理由：65条1項は真正身分犯（身分がなければ犯罪が成立しない場合）の規定で連帯的に作用。「目的」を真正身分と解せば、非身分者も身分者を通じて法益侵害が可能であり、同項の「共犯」に共同正犯を含めて取り込める。
- **Q20［○×］** 65条1項と2項は、いずれも刑の軽重が身分により異なる不真正身分犯について、共犯の科刑を個別的に定めた規定である。
  - 正解：×（誤り）
  - 理由：65条1項は真正身分犯（身分がなければ犯罪が成立しない）の連帯的作用、2項が不真正身分犯（身分が刑の軽重に影響する）の個別的作用。本問の「目的」は真正身分なので1項を適用する。
- **Q21［○×］** 幇助犯が成立するには、提供した道具が現実に正犯の犯行に使用され、提供がなければ結果が生じなかったという条件関係が必要である。
  - 正解：×（誤り）
  - 理由：幇助の因果性は正犯の実行を容易にした（促進した）といえれば足りる（促進的因果関係）。提供物が現実に使われなくても、共謀の形成等を通じて正犯を心理的・物理的に促進していれば因果性は認められる。
- **Q22［○×］** 同一の関与者でも、正犯結果が「予備」にとどまるなら予備の共同正犯、「既遂」まで進むならその幇助犯、というように、正犯がどこまで進んだかで関与者の罪責の構成が変わりうる。
  - 正解：○（正しい）
  - 理由：関与者の罪責は正犯結果に従属する。本問は乙の離脱を肯定すると正犯結果は強盗予備＝甲は予備の共同正犯、離脱を否定すると正犯結果は強盗既遂＝甲は強盗幇助、と択一になる。整合させること。
