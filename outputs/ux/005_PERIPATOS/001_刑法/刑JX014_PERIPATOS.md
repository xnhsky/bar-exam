### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「突然対向車線に押し出された」 → ＝甲の追突が丙の衝突を引き込んだ事情。因果の評価で効く。
- 【拾う事実】「避けきれずにこれに衝突し…乙は死亡」 → ＝重い結果（死亡）の発生と介在事情。
- 【拾う事実】「軽度の傷害を与え…共謀」 → ＝乙の同意の存在。違法性レベルで効く。
- 【拾う事実】「保険金名目下に金員を詐取しよう」 → ＝同意の動機＝違法目的。財産犯の補論も。
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 実行行為＝自動車の追突○／傷害の故意○／結果＝乙の死亡○。本問で立ち止まるのは「因果関係」と「違法性（同意傷害）」の2か所だけ。
- 【効く事実】効く事実（因果）
  - 行為の危険性 → 自動車を追突させる行為は死の危険が高い／介在の評価 → 「乙車が突然対向車線に押し出された」＝甲の追突が丙の衝突を誘発／介在の通常性 → 対向車線に押し出された車に対向車が衝突するのは通常あり得る＝異常でない。だから危険が現実化＝因果関係○。結論は明らかなので端的に。
- 【規範の要点】社会的相当性の規範
  - 被害者の同意があっても違法性阻却は社会的に相当な範囲のみ。承諾の動機・目的・手段・方法・部位・程度など諸般の事情を総合して判断する（最決昭55.11.13）。本問は保険金詐取の違法目的＋自動車追突の危険な手段 → 社会的相当性なし → 違法性は阻却されない。
- 【効く事実】効く事実（同意）
  - 違法目的 → 「保険金名目下に金員を詐取しよう」を直接引用／危険な手段 → 自動車の追突は人の死をも招く危険（現に乙は死亡）。違法目的への言及は必須。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 共謀の目的だった行為が未完でも、触れずに飛ばすと検討漏れに見える。実行の着手（43条本文）の一般基準＝結果発生の現実的危険を生じさせた時点を当てはめ、本問は欺罔の開始前（請求未了）ゆえ着手なし＝未遂不成立と一段落で締める。
- 【まぎらわしい選択肢・論点】正当防衛／被害者の錯誤
- 【まぎらわしい選択肢・規範】相当因果関係説（折衷説）／法益関係的錯誤説
- 【まぎらわしい選択肢・事実】殺意あり／重い結果の予見可能性
- 【まぎらわしい選択肢・結論】殺人罪 成立／詐欺既遂罪 成立／傷害罪のみ成立

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

傷害致死＝追突で軽傷→乙死亡、丙衝突が介在も「対向車線への押出しが誘発・対向車衝突は通常」で危険の現実化→因果○、結果的加重犯で予見可能性不要→構成要件該当。同意傷害＝乙は軽傷に同意も、保険金詐取の違法目的＋自動車追突の危険な手段で社会的相当性なし→承諾無効→傷害致死罪成立。詐欺補論＝請求未了で着手なし→詐欺未遂不成立。
