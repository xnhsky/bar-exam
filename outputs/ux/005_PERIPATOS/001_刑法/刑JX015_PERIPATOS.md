#### 第1　殺人罪の成否

2. 【論点】殺人罪（間接正犯）と自殺関与罪の区別 → 自殺決意の有効性で決まる

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「Aを殺してしまおう」 → ＝確定的殺意（故意の根拠）
- 【拾う事実】『追死は虚偽・甲はサプリを飲む』 → ＝欺罔／甲に追死の意思なし
- 【拾う事実】『「甲を心から愛していたため」同意』 → ＝決意の決定的動機が偽りに基づく
- 【拾う事実】『Aが自ら睡眠薬を飲んだ』 → ＝外形は自殺関与に見える
- 【拾う事実】『間に合わずA死亡』 → ＝既遂（中止犯を切る根拠）
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 結果＝Aの死亡／因果＝甲の欺罔→Aの嚥下→死亡＝あり／故意＝「Aを殺してしまおう」＝確定的殺意／違法性・責任＝阻却事由なし＝一言で素通り。立ち止まるのは実行行為「殺した」だけ。
- 【規範の要点】判例・最判昭33.11.21の規範
  - 被害者の意思決定に重要な影響をもつ錯誤、すなわち真意に添わない重大な瑕疵ある意思に基づく自殺決意は無効。→ 無効なら、被害者を欺いて道具として利用した殺人罪の間接正犯。
- 【効く事実】「核心＝錯誤に基づく自殺決意」のあてはめで使う事実
  - 瑕疵の重大性 → 「甲を心から愛していた」「甲が一緒に死んでくれると信じた」を直接引用／偽り → 甲は無害なサプリを飲み追死の意思なし／決定的影響 → 追死が偽りと知っていれば飲まなかった。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 自ら手を下していなくても、被利用者が規範的障害とならない（意思を抑圧され又は錯誤に陥った）状態を利用し、結果への因果経過を支配したといえれば正犯になる。被害者を「道具」として利用した類型では、まず決意・同意の有効性を潰してから行為支配を一言で示すのが筋。被利用者に自由な意思決定が残れば道具性が否定され、教唆等にとどまる。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - ①間接正犯：決意が無効＝Aは規範的障害なく道具として利用された → 行為支配あり → 被害者を利用した殺人罪の間接正犯（一文）。②反対説：「死そのものへの錯誤はない＝法益関係的錯誤なしとして承諾有効ともいいうるが、本件は追死の誤信が決意の核心をなすから無効」と一言反論できれば差がつく。
- 【まぎらわしい選択肢・論点】不真正不作為犯の実行行為性／被害者の承諾(35条)の有効性
- 【まぎらわしい選択肢・結論】自殺関与罪 成立／殺人未遂罪 成立／中止犯 成立
- 【まぎらわしい選択肢・規範】条件関係説／法益関係的錯誤説
- 【まぎらわしい選択肢・事実】排他的支配／先行行為

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

殺人罪＝Aが自ら飲んだ外形は自殺関与に見えるが、追死は偽り＝「真意に添わない重大な瑕疵ある意思」で自殺決意は無効→規範的障害なく道具利用＝被害者を利用した殺人罪の間接正犯、確定的殺意あり→A死亡で既遂。中止犯＝救急車要請も間に合わずA死亡＝既遂ゆえ成立余地なし（救護は量刑事情）。結論＝殺人罪（間接正犯・199条）成立。

## 3. 規範クイズ（全4問・1問目から最後まで全部出す）

- **［規範クイズ 1/4］** 殺人罪（間接正犯）と自殺関与罪を分ける基準は何か、一言で挙げよ。
  - 模範解答：答被害者の自殺決意（同意）が有効か無効か。有効なら自殺関与罪、無効なら被害者を利用した殺人罪（間接正犯）。
- **［規範クイズ 2/4］** 偽装心中で被害者の自殺決意を無効とする判例（最判昭33.11.21）の規範を、キーフレーズを使って挙げよ。
  - 模範解答：答被害者の意思決定に重要な影響をもつ錯誤、すなわち真意に添わない重大な瑕疵ある意思に基づく自殺決意は無効。→ 被害者を利用した殺人罪の間接正犯。
- **［規範クイズ 3/4・ひっかけ］** この論点のひっかけポイントは？
  - 答え：中止犯は本文「実行に着手してこれを遂げなかった者」を前提とする未遂犯の一種。本問はAが死亡＝既遂に達しているから「遂げなかった」とはいえず、中止犯は成立の余地なし。任意性の検討に入る必要すらない。救護は量刑事情にとどまる。
- **［規範クイズ 4/4］** 中止犯（43条ただし書）が既遂の場合に成立しない理由を、条文の文言を使って一言で挙げよ。
  - 模範解答：答中止犯は「実行に着手してこれを遂げなかった者」＝未遂犯の一種だから。既遂は「遂げなかった」に当たらず、成立の余地がない（救護は量刑事情のみ）。

## 4. ○×クイズ（全12問・1問目から最後まで全部出す）

- **［○×クイズ 1/12］** 「甲の罪責を論じなさい」と単独行為者だけが問われた場合でも、被害者や事件の背景にいる第三者の罪責まで検討すべきだ。
  - 正解：×（誤り）
  - 理由：問われた者の罪責だけを検討する。被害者・背景人物は対象外。まず全員出して対象外を切り、検討すべき行為だけに絞る。
- **［○×クイズ 2/12］** 被害者が自分の手で死の結果を実現した（自ら毒を飲んだ等）事案でも、行為者に確定的殺意があれば、自殺関与罪だけでなく殺人罪の可能性も疑うべきである。
  - 正解：○（正しい）
  - 理由：外形（自ら飲んだ）だけで自殺関与に決めない。殺意があり、被害者を道具のように利用していれば殺人（間接正犯）になりうる。
- **［○×クイズ 3/12］** 被害者が自分の意思で毒を飲んで死亡した以上、関与者にどんな事情があっても、成立しうるのは自殺関与罪に限られる。
  - 正解：×（誤り）
  - 理由：その「自分の意思」が偽りに基づいて作られた（重大な瑕疵ある意思）なら自殺決意は無効となり、被害者を利用した殺人罪となりうる。外形だけで決めない。
- **［○×クイズ 4/12］** 自殺関与・同意殺人罪（202条）が殺人罪（199条）より法定刑が軽いのは、被害者が自らの生命の侵害に同意していることにより違法性（法益侵害の程度）が減少するからである。
  - 正解：○（正しい）
  - 理由：有効な同意があれば法益侵害の違法性が減少するため刑が軽い（202条）。逆に同意が無効なら違法減少の基礎が失われ、被害者を利用した殺人罪（199条）に格上げされる。この軽重の根拠を押さえると罪名の振り分けの重みが分かる。
- **［○×クイズ 5/12］** 殺人罪（間接正犯）と自殺関与罪は、行為者の殺意の有無だけで区別され、被害者の自殺決意が有効かどうかは関係しない。
  - 正解：×（誤り）
  - 理由：両罪の分水嶺は被害者の自殺決意（同意）が有効か無効か。決意が有効なら自殺関与、無効なら被害者を利用した殺人罪となる。
- **［○×クイズ 6/12］** 被害者が「自分が死ぬこと」自体は正しく認識して自ら実行しても、その死の決意が行為者の欺罔によって作られたものであれば、決意が無効となり殺人罪が成立しうる。
  - 正解：○（正しい）
  - 理由：死そのものの認識があっても、決意の動機が偽りに基づき（重大な瑕疵）、それが決定的なら決意は無効。被害者を道具として利用した殺人（間接正犯）になる。
- **［○×クイズ 7/12］** 確定的な殺意をもって被害者を死に至らせた場合、その実行を被害者自身の手に委ねていても、行為が「殺した」に当たれば殺人罪の故意（38条1項）に欠けはない。
  - 正解：○（正しい）
  - 理由：本問の甲は「Aを殺してしまおう」と確定的殺意をもつ。実行行為性（道具利用）さえ認められれば故意は問題なく肯定される。
- **［○×クイズ 8/12］** 承諾・自殺決意の効力を否定する「重大な瑕疵」を基礎づける中心事実は、“決意の決定的動機が偽りであったこと”や“その偽りを知れば決意しなかったといえること”である。
  - 正解：○（正しい）
  - 理由：動機の核心が偽りで、それが決意に決定的影響を与えたことが瑕疵の重大性の柱。本問の「心から愛していた」「追死を信じた」がこれ。
- **［○×クイズ 9/12］** 実行行為の後に行為者が真剣に結果防止に努めれば、たとえ結果（既遂）が発生していても中止犯（43条ただし書）が成立しうる。
  - 正解：×（誤り）
  - 理由：中止犯は未遂犯の一種。結果が発生して既遂に達すれば「遂げなかった」とはいえず、中止犯は成立しない。結果防止の努力は量刑で考慮されうるにとどまる。
- **［○×クイズ 10/12］** 中止犯の成否を検討するときは、まず「既遂に達していないか（未遂か）」を確認し、既遂なら任意性・中止行為に立ち入らず端的に否定してよい。
  - 正解：○（正しい）
  - 理由：未遂であることが中止犯の大前提。既遂なら一刀両断＝時間を核心論点（殺人）に回せる。
- **［○×クイズ 11/12］** 間接正犯において、利用者が自ら手を下していないのに「正犯」とされるのは、被利用者が規範的障害とならない（意思を抑圧され又は錯誤に陥った）状態を利用し、利用者が結果へ至る因果経過を支配していたといえるからである。
  - 正解：○（正しい）
  - 理由：間接正犯の正犯性の根拠＝被利用者を規範的障害のない「道具」として利用し、利用者が行為（因果経過）を支配したこと。被利用者の自由な意思決定が介在すれば道具性が否定され、正犯ではなく教唆等にとどまる。
- **［○×クイズ 12/12］** 法益関係的錯誤説によれば、被害者が「自分が死ぬこと」自体を正しく認識していれば、動機が偽りでも承諾（自殺決意）は常に有効となる。
  - 正解：×（誤り）
  - 理由：法益関係的錯誤説は処罰範囲を絞る立場として死そのものへの錯誤を重視するが、それでも追死の誤信が決意の核心を成す本件では無効と評価する余地がある。「常に有効」は言い過ぎ＝反対説への目配りで差をつける。
