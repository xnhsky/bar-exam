### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「痛めつけてやろう」 → ＝故意は傷害（終始一貫）
- 【拾う事実】「症状はなかった」 → ＝A自身に傷害結果なし
- 【拾う事実】「出産予定日に」 → ＝分娩時期そのまま（第1）
- 【拾う事実】「1か月早く未熟児」 → ＝分娩時期が早まる（第2）
- 【規範の要点】「胎児性傷害」の規範
  - ①胎児は出生まで母体の一部。母体（人）への加害が生まれた子（人）に結果を生じさせれば犯罪が成立しうる（最決昭63.2.29）。②法定的符合説：認識事実と発生事実が同一構成要件（「人」）の範囲で符合すれば故意あり（個数は問題とならない）。
- 【効く事実】第1で効く事実
  - 分娩時期は早まっていない→堕胎を切る／障害は生まれた子（人）の身体に発現→傷害結果／母体への攻撃と「人」への傷害は「人」の範囲で符合。
- 【規範の要点】重なり合いの規範
  - 異なる構成要件にまたがる錯誤でも、両罪に構成要件の実質的な重なり合いがあれば、その重なる軽い罪の限度で故意を認める。標識は①行為態様の共通性 ②保護法益の共通性。
- 【効く事実】第2で効く事実
  - 行為態様＝両罪とも女子の身体への不法な有形力で共通／保護法益＝不同意堕胎罪は妊婦の生命・身体を含み、傷害罪の人の身体の安全と重なる → 不同意堕胎の限度で故意 → 不同意堕胎罪成立。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 複数の罪が成立したら最後に罪数処理を一言。判断の起点は行為が一個か数個か。一個の行為が二個以上の罪名に触れれば観念的競合（54条1項前段）、手段‐結果の関係なら牽連犯（54条1項後段）、別個の行為なら併合罪（45条）。本問は一個の衝突行為から傷害罪と暴行罪が生じる＝観念的競合。
- 【まぎらわしい選択肢・論点】因果関係の錯誤／不真正不作為犯の実行行為性
- 【まぎらわしい選択肢・結論】殺人罪 成立／業務上過失致死罪 成立／傷害致死罪 成立
- 【まぎらわしい選択肢・規範】具体的符合説／抽象的符合説
- 【まぎらわしい選択肢・事実】排他的支配／殺意の認容

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

第1＝分娩時期早まらず堕胎不成立／胎児は母体の一部＝「人」への加害（最決昭63.2.29）→ 生まれた子（人）への結果＝具体的事実の錯誤を法定的符合説で「人」の範囲で符合 → 傷害罪（204条）成立／A無症状＝暴行罪（208条）／一個の行為で2罪＝観念的競合（54条1項前段）。第2＝分娩時期早まる＝不同意堕胎の客観に該当（215条1項）／主観は傷害（重）・客観なし＝38条2項＋抽象的事実の錯誤 → ①身体への有形力②女子の身体の安全で実質的重なり合い → 軽い不同意堕胎の限度で故意 → 不同意堕胎罪（215条1項）成立。

## 3. 規範クイズ（全1問・1問目から最後まで全部出す）

- **［規範クイズ 1/1］** 抽象的事実の錯誤で「実質的な重なり合い」を判断する2つの標識を挙げよ。
  - 模範解答：①行為態様の共通性 ②保護法益（被侵害法益）の共通性。本問では「女子の身体への不法な有形力」（態様）と「女子の身体の安全」（法益）で重なる。

## 4. ○×クイズ（全15問・1問目から最後まで全部出す）

- **［○×クイズ 1/15］** 「甲の罪責を論ぜよ」と問われた場合、結果が被害者や胎児に生じても、罪責検討の主体はあくまで行為をした甲である。
  - 正解：○（正しい）
  - 理由：主体（誰を裁くか）と客体（誰に結果が出たか）は別。まず主体を確定し、客体ごとに結果を仕分ける。
- **［○×クイズ 2/15］** 傷害罪（204条）にいう「傷害」とは、人の生理的機能に障害を与えること（生理的機能障害説）をいい、単なる身体の外形の変更は含まない。
  - 正解：○（正しい）
  - 理由：判例・通説の生理的機能障害説。生理的機能の障害（健康状態の不良な変更）が傷害で、毛髪の切除など外形の変更にとどまるものは暴行罪の限度。だから「無症状＝生理的機能の障害なし」なら傷害結果を欠き暴行罪にとどまる、という仕分けができる。
- **［○×クイズ 3/15］** 暴行を加えたが相手の身体に傷害の結果が生じなかった場合、暴行罪が成立しうる。
  - 正解：○（正しい）
  - 理由：傷害の故意で暴行したが傷害結果が生じなければ、傷害未遂は不可罰なので暴行罪（208条）で捉える。
- **［○×クイズ 4/15］** 「堕胎」とは胎児を母体内で死亡させることだけを指し、胎児を自然の分娩期より早く母体外へ排出させることは堕胎に当たらない。
  - 正解：×（誤り）
  - 理由：堕胎とは自然の分娩期に先立って胎児を母体外に排出させること（胎児の死亡は要件でない）。分娩時期を1か月早めれば堕胎に当たる。
- **［○×クイズ 5/15］** 不同意堕胎罪（215条）の保護法益には、胎児の生命・身体だけでなく、堕胎により危険にさらされる母体（妊婦）の生命・身体も含まれる。
  - 正解：○（正しい）
  - 理由：堕胎罪の保護法益は胎児の生命・身体に加え母体の生命・身体にも及ぶ。母体の身体への侵害という側面が保護法益に含まれるからこそ、傷害罪（人の身体の安全）との間に保護法益の共通性＝構成要件の重なり合いが認められ、抽象的事実の錯誤で軽い堕胎の限度の故意を導ける。
- **［○×クイズ 6/15］** 刑法上の「人」の始期は、一部露出説によれば、胎児が母体から一部露出した時点である。
  - 正解：○（正しい）
  - 理由：一部露出説が判例・通説。出生前は「人」でなく、攻撃時に胎児なら傷害罪は直ちには成立しない（だから母体の一部構成で橋を架ける）。
- **［○×クイズ 7/15］** 攻撃時に客体が「人」でなければ、その後に生まれた子という「人」に結果が生じても、時間差ゆえに常に不可罰となる。
  - 正解：×（誤り）
  - 理由：胎児＝母体の一部とみて母体（人）への加害と構成し、生まれた子（人）への傷害を導きうる（最決昭63.2.29）。
- **［○×クイズ 8/15］** 同じ「客観と主観のズレ」でも、同一構成要件内のズレを具体的事実の錯誤、異なる構成要件にまたがるズレを抽象的事実の錯誤という。
  - 正解：○（正しい）
  - 理由：本問は第1＝具体的（人vs人）、第2＝抽象的（傷害vs堕胎）。どちらの錯誤かで処理の枠組みが変わる。
- **［○×クイズ 9/15］** 法定的符合説では、認識した事実と発生した事実が同一の構成要件（例えば「人」）の範囲で符合していれば、故意が認められる。
  - 正解：○（正しい）
  - 理由：故意責任の本質は反対動機形成可能性。構成要件で類型化された範囲で符合すれば犯罪事実の認識ありとして故意を認める。
- **［○×クイズ 10/15］** 法定的符合説では、同一構成要件内で客体を取り違えた場合、故意の個数を問題にして発生結果への故意を否定しなければならない。
  - 正解：×（誤り）
  - 理由：法定的符合説では「人」の範囲で符合する限り故意を認め、故意の個数は問題とならない。本問でも生まれた子への傷害の故意を肯定できる。
- **［○×クイズ 11/15］** 傷害の故意で妊婦に暴行し、胎児に障害が残ったが分娩時期が早まらなかった場合でも、不同意堕胎罪が成立する。
  - 正解：×（誤り）
  - 理由：堕胎＝分娩時期を早めること。分娩時期が早まらない第1の場合は堕胎に当たらない。
- **［○×クイズ 12/15］** 重い罪の故意で軽い罪の客観的事実を実現した場合、38条2項により、重い罪では処断できない。
  - 正解：○（正しい）
  - 理由：「重い罪に当たるべき行為をしたのに、その重い罪を犯す意思がなかった者は、重い罪で処断できない」（38条2項）。本問は傷害（重）の客観面なし。
- **［○×クイズ 13/15］** 異なる構成要件にまたがる錯誤（抽象的事実の錯誤）でも、両罪に構成要件の実質的な重なり合いがあれば、その重なる軽い罪の限度で故意を認めうる。
  - 正解：○（正しい）
  - 理由：重なり合う限度では反対動機を形成できるから、その軽い罪の故意責任を問える。本問は不同意堕胎の限度で故意。
- **［○×クイズ 14/15］** 抽象的事実の錯誤で「実質的な重なり合い」を判断する標識は、もっぱら両罪の法定刑の軽重のみである。
  - 正解：×（誤り）
  - 理由：標識は①行為態様の共通性 ②保護法益の共通性。法定刑の軽重は「軽い罪の限度で」処断する局面の話で、重なりの有無の判断基準ではない。
- **［○×クイズ 15/15］** 一個の行為が二個以上の罪名に触れる場合は、観念的競合（54条1項前段）として科刑上一罪となる。
  - 正解：○（正しい）
  - 理由：自転車でぶつかる一個の行為からAへの暴行罪と生まれた子への傷害罪が生じる＝観念的競合。
