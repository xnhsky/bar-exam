### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】『甲「強い眠気」「居眠り運転」』 → → 不注意な運転行為の特定
- 【拾う事実】『B「トランク内に監禁」』 → → 被害者の所在が異常
- 【拾う事実】『乙「合図・約20km・左寄り」』 → → 乙の運転態様（適法・相当）
- 【拾う事実】『乙「後方を十分に確認せず」』 → → 乙自身の落ち度
- 【拾う事実】『C「約70km・右はみ出し追い抜き」』 → → 被害者の重大な法規違反
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 死亡結果＝B・Cの死で明白／因果＝甲の追突・乙の衝突がそのまま死を招いた＝危険の現実化で明白／違法性・責任＝阻却事由なし＝一言で素通り。勝負は「過失（注意義務違反）」の有無一点に絞る。
- 【規範の要点】「予見可能性で過失を肯定」の規範
  - 予見可能性は結果回避義務を基礎づける前提だから、一般人を結果回避へと動機づける程度で足り、具体的な被害者や因果経過の細部まで不要、およそ構成要件的結果（人の死傷）の発生が予見できれば足りる（単なる危惧感では足りない）。
- 【効く事実】甲で効く事実
  - 過失行為 → 強い眠気を覚えながら運転を継続→居眠り運転／予見の対象 → Bのトランク所在は予見不能だが、居眠りすればおよそ「人」の死傷を伴う事故を惹起しうることは当然予見しえた／結果回避 → 眠気を覚えた時点で運転を中止すれば回避できた。
- 【規範の要点】「信頼の原則で過失を否定」の規範
  - 被害者ないし第三者が適切な行動をとることを信頼するのが社会的に相当な場合にまで結果回避義務を課すのは妥当でない → かかる場合は結果回避義務を負わない。要件は①現実の信頼の存在 ②その信頼の社会的相当性。行為者側に法規違反があっても適用は否定されない。
- 【効く事実】乙で効く事実
  - ①現実の信頼 → 右折の合図・時速約20kmに減速・センターライン左寄りで適法・相当な運転／②社会的相当性 → あえて法規違反して右側からはみ出し高速で追い抜く車（C）まで予想する義務はない／乙の落ち度は後方不確認に留まる＝適用を妨げない。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 独立した二事例（共犯も牽連もなし）は、それぞれを最後まで通したうえで横断・補論を一言添えるだけ。事例間に帰責の連絡はないので、共通する論点（過失の構造など）を二度書きせず、対照点（肯定／否定の分かれ目）に光を当てて締める。
- 【まぎらわしい選択肢・論点】不真正不作為犯の実行行為性／被害者の承諾
- 【まぎらわしい選択肢・規範】具体的な被害者・因果経過の細部まで予見が必要／行為者に違反があれば信頼の原則は当然に否定される
- 【まぎらわしい選択肢・事実】Bがトランク内にいることを具体的に予見できた
- 【まぎらわしい選択肢・結論】殺人罪 成立

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

甲＝居眠り運転＝注意義務違反、予見可能性は「およそ人の死傷が予見できれば足りる」（Bの所在は予見不要）、眠気を覚えた時点で運転中止すれば回避可能→過失運転致死罪成立。乙＝合図・減速・左寄りで適法走行、信頼の原則（①現実の信頼②社会的相当性）で違反して追い抜くCまで予想する義務なし、乙の後方不確認があっても適用は否定されず→結果回避義務なし→不成立。補論＝甲の追突とBの死は危険の現実化で因果肯定（一文）。

## 3. 規範クイズ（3問）

- **Q04［規範］** 過失犯の構造（新過失論）の規範を、何も見ずに一文で書けるか。
  - 模範解答：「過失とは客観的注意義務違反をいい、具体的には、結果の予見可能性を前提とする予見義務違反と、結果回避可能性を前提とする結果回避義務違反からなる」。書けたら○、詰まったら×で周回に回す。
- **Q05［規範］** 予見可能性の「程度・対象」についての規範を、何も見ずに書けるか。
  - 模範解答：「予見可能性は結果回避義務を基礎づける前提であるから、一般人を結果回避へと動機づける程度で足り、具体的な被害者・因果経過の細部まで不要、およそ構成要件的結果（人の死傷）の発生が予見できれば足りる」。
- **Q06［規範］** 信頼の原則の規範と二要件を、何も見ずに書けるか。
  - 模範解答：「適切な行動への信頼が社会的に相当な場合にまで結果回避義務を課すのは妥当でないから、かかる場合は結果回避義務を負わない。要件は①現実の信頼の存在 ②社会生活上の相当性」。行為者の違反があっても直ちに否定しない点まで言えれば完璧。

## 4. ○×クイズ（14問）

- **Q07［○×］** 過失犯の検討では、まず「結果を招いた不注意な行為（過失行為）」が何かを具体的に特定することが出発点になる。
  - 正解：○（正しい）
  - 理由：過失犯は「どの不注意（注意義務違反）が結果を招いたか」を特定して初めて当てはめができる。漠然と「不注意だった」では足りない。
- **Q08［○×］** 複数人の罪責を問う問題では、各人の罪責は相互に関連づけて一体的に論じなければならず、登場人物ごとに独立して検討することは許されない。
  - 正解：×（誤り）
  - 理由：関連づけの要否は事実次第。共犯関係・牽連性・共謀など各人の罪責を結び付ける事情があれば一体的に論じるが、それが無ければ各人（各事例）を別個に構成要件→違法→責任で完結させてよい。安易な一体処理も無理な分断もしない。
- **Q09［○×］** 自動車（原動機付自転車を含む）の運転上の不注意により人を死亡させた場合、まず自動車運転死傷処罰法5条の過失運転致死罪を検討する。
  - 正解：○（正しい）
  - 理由：運転上の不注意＝「自動車の運転上必要な注意を怠り」に当たり、5条の過失運転致死罪が筋。原付も同法の「自動車」に含まれる。
- **Q10［○×］** 結果として人が死亡している以上、運転による死亡事故でも、まず（業務上）過失致死罪ではなく殺人罪の成否から検討すべきだ。
  - 正解：×（誤り）
  - 理由：殺意（死亡結果の認識・認容）がなければ殺人罪系には乗らない。死亡という結果の重さだけで罪名を決めない。
- **Q11［○×］** 過失犯の枠組みでは、結果回避義務違反の有無を判断する前提として結果の予見可能性が要求され、予見可能性は結果回避義務を基礎づける関係に立つ。
  - 正解：○（正しい）
  - 理由：予見できない結果に回避を求めることはできないから、予見可能性は結果回避義務を基礎づける前提として要求される。両事例に共通するこの土台を先に固めておくと、甲（予見可能性）と乙（結果回避義務＝信頼の原則）のどちらが争点でも同じ枠組みで処理できる。
- **Q12［○×］** 過失行為と結果の間に他の事情が介在しても、実行行為の危険が結果へ現実化したと評価できれば因果関係を肯定してよい（危険の現実化説）。
  - 正解：○（正しい）
  - 理由：因果関係は危険の現実化で判断する。だからこそ本問の因果（甲の追突→B死亡・乙の衝突→C死亡）は争いなく一言で通せ、紙幅を過失（注意義務違反）に集中できる。
- **Q13［○×］** 新過失論によれば、過失とは客観的注意義務違反をいい、その内容は結果の予見可能性を前提とする予見義務違反と、結果回避可能性を前提とする結果回避義務違反からなる。
  - 正解：○（正しい）
  - 理由：過失＝客観的注意義務違反＝予見義務違反＋結果回避義務違反。これが甲・乙双方の規範の土台。旧過失論（過失＝責任要素）と混在させないこと。
- **Q14［○×］** 過失犯では、結果回避義務違反さえあれば足り、結果の予見可能性は不要である。
  - 正解：×（誤り）
  - 理由：予見できない結果について回避を求めることはできない。予見可能性は結果回避義務を基礎づける前提として必要。
- **Q15［○×］** 過失犯の予見可能性は、具体的な被害者や因果経過の細部まで予見できる必要はなく、およそ構成要件的結果（人の死傷）の発生が予見できれば足りる。
  - 正解：○（正しい）
  - 理由：予見可能性の対象を「およそ人の死傷」レベルに設定するのが判例（最決平元.3.14 等）。これにより異常な被害者の所在でも過失を肯定できる。
- **Q16［○×］** 単なる危惧感があれば足りるとして予見可能性を肯定すると、処罰範囲が広がりすぎ責任主義に反するおそれがある。
  - 正解：○（正しい）
  - 理由：危惧感説は責任主義との緊張がある。「結果回避を動機づける程度の予見可能性」を要求して歯止めをかける。
- **Q17［○×］** 被害者がトランク内に監禁されているといった具体的事情を予見できない以上、ただちに予見可能性を否定して過失なし＝不成立と結論してよい。
  - 正解：×（誤り）
  - 理由：本問最大の罠。予見の対象を「具体的なB」ではなく「およそ人の死傷」に設定すれば予見可能性は肯定でき、過失運転致死罪が成立する。
- **Q18［○×］** 信頼の原則とは、他人（被害者・第三者）が適切な行動をとることを信頼するのが社会的に相当な場合には、行為者に結果回避義務を課さないとする考え方である。
  - 正解：○（正しい）
  - 理由：信頼の原則は、新過失論の結果回避義務（違反）を否定する要素として機能する。要件は①現実の信頼②社会的相当性。
- **Q19［○×］** 行為者自身にも交通法規違反（例：後方不確認）がある場合には、信頼の原則は当然に適用が否定される。
  - 正解：×（誤り）
  - 理由：判例（最判昭42.10.13）は、行為者に後方不確認の違反があっても信頼の原則の適用を否定しなかった。
- **Q20［○×］** ある危険な先行状態（例：被害者の監禁）を作った者が別にいる場合、後行の行為者（追突した者）と結果との因果関係は当然に否定される。
  - 正解：×（誤り）
  - 理由：二重帰責の場面でも、各行為の危険がそれぞれ結果へ現実化していれば双方に因果関係を認めうる。甲の追突とBの死の因果は危険の現実化で肯定でき、Aの監禁が介在しても甲の因果は切れない。
