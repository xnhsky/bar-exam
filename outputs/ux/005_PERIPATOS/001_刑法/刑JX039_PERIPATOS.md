### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「Aが盗んできたカメラ」 → 占有者が無権利者。客体「他人の財物」の評価が要る
- 【拾う事実】「一時使用しようと考え」 → 主観：返すつもり（借りる意図）
- 【拾う事実】「留守をねらって…部屋に入った」 → 無断の立入り
- 【拾う事実】『「一泊旅行」に持出し／旅行先で撮影』 → 利用の時間・場所の幅が大きい・現実の使用
- 【拾う事実】「元の場所に返しておいた」 → 事後の返却
- 【拾う事実】『カメラ（自動車より安い物）・顔見知りのAから』 → 軽さ・近さの事情
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 「窃取」＝Aの留守中の無断持出しで占有移転＝争いなし。
- 【規範の要点】占有説の規範
  - 窃盗罪の保護法益は、自力救済を禁じ占有秩序を維持する趣旨から占有（所持）それ自体。占有に法律上の正当な権原は要しない（最判昭35.4.26）。→ だから無権利者の占有を侵害しても「他人の財物」の窃取。
- 【効く事実】「保護法益論（盗品の他人の財物性）」のあてはめで使う事実
  - カメラは少なくとも甲の所有物ではない（＝他人の物）／Aが現に事実上支配している（外形上平穏な占有）。→ 占有説でも所有権の所在からでも「他人の財物」○。本権説だと無権利者Aの保護を説明しにくい、と一言添えれば加点。
- 【規範の要点】最決昭55.10.30の規範
  - 不法領得の意思＝権利者を排除して他人の物を自己の所有物としてその経済的用法に従い利用処分する意思（大判大4.5.21）。後に返還する意思があっても、相当程度の利用可能性を侵害する意思があれば権利者排除意思を肯定する。判断＝利用の時間・場所・態様、目的物の価値、被害者との関係を総合。
- 【ポイント】否定事情 → どう乗り越えるか
  - 否定（−）＝カメラは自動車より低価値・顔見知りのAから・一時使用・返却。肯定（＋）＝一泊旅行に持出し＝場所的・時間的離隔が大きく、その間Aは全く使えない＝相当程度の利用可能性を侵害し、甲もそれを認識。判例の自動車事案と意識的に比較して論じる。返却は事後事情で領得時判断に影響小、と一言添える。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 本丸（不法領得の意思）を抜けたら、付随論点は深追いせず一段落で束ねる。住居侵入は窃盗の手段だから牽連犯（54条1項後段）で科刑上一罪に落とす。手段・目的の関係を一文で示せば足り、住居侵入の細部に紙幅を割かない。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 持出し時の立入り＝管理権者Aの意思に反する「侵入」で成立。返却時の立入りは別罪にせず包括一罪として処理すれば足りる（深追い禁物）。
- 【まぎらわしい選択肢・論点】横領罪との区別／盗品等関与罪（256条）の成否
- 【まぎらわしい選択肢・結論】窃盗未遂罪 成立／不可罰的使用窃盗で不可罰
- 【まぎらわしい選択肢・規範】本権説＝所有権その他の本権を保護／確定的な返還意思があれば権利者排除意思は常に否定
- 【まぎらわしい選択肢・事実】委託に基づく占有の侵害／先行行為による作為義務

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

住居侵入＝管理権者Aの意思に反する無断立入り→住居侵入罪（130前段）。窃盗＝カメラは盗品でもAの平穏占有を占有説で保護→「他人の財物」。利用処分意思は記念撮影で○。権利者排除意思は否定事情（低価値・顔見知り・返却）を摘示しつつ一泊旅行の離隔大で乗り越え○、返却は事後事情→窃盗成立。罪数＝住居侵入は窃盗の手段で牽連犯（54①後段）。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 窃盗罪（235条）の主観的要件として、故意のほかに判例・通説が要求する“明文なき要件”を、その内訳（二要素）まで挙げよ。
  - 模範解答：不法領得の意思。内訳は①権利者排除意思（不可罰的使用窃盗との区別）＋②利用処分意思（毀棄・隠匿罪との区別）の二要素。
- **［規範クイズ 2/3］** 窃盗罪の保護法益について判例が採る立場の名称と、その根拠条文・判例、および盗品の占有を侵害した場合の帰結を述べよ。
  - 模範解答：占有説（所持説）。占有に法律上の正当な権原は不要（最判昭35.4.26）／242条（自己物でも他人占有なら「他人の財物」）。→ 盗品の占有を侵害しても「他人の財物」の窃取＝窃盗罪が成立しうる。
- **［規範クイズ 3/3］** 不法領得の意思の定義（二要素）と、各要素が果たす“区別機能”を述べよ。
  - 模範解答：権利者を排除して他人の物を自己の所有物としてその経済的用法に従い利用処分する意思。①権利者排除意思＝不可罰的使用窃盗との区別／②利用処分意思＝毀棄・隠匿罪との区別。

## 4. ○×クイズ（全11問・1問目から最後まで全部出す）

- **［○×クイズ 1/11］** 単独行為者型（「甲の罪責を論ぜよ」）でも、一人の行為が時系列で複数あるときは、行為ごとに切り分けて犯罪の成否を検討する。
  - 正解：○（正しい）
  - 理由：「立入り」「持出し」「返却」のように行為が分かれるなら、それぞれに成立しうる罪を当て、最後に罪数で束ねる。
- **［○×クイズ 2/11］** 奪った財物が「占有者自身も他人から盗んできた盗品」である場合、誰のどの利益（占有）を侵害したのかをまず確定する必要がある。
  - 正解：○（正しい）
  - 理由：侵害されたのは「無権利の占有者」の占有。その占有も窃盗罪で保護されるかが保護法益論として起動する。
- **［○×クイズ 3/11］** 他人の留守中に無断で部屋に立ち入って物を持ち出した事案では、住居侵入罪と窃盗罪の両方をまず疑うのが筋である。
  - 正解：○（正しい）
  - 理由：無断の立入りは住居侵入罪（130条前段）、財物の持出しは窃盗罪（235条）の成立を検討すべき行為だから、この2罪をまず疑う。両者は手段と目的の関係に立ち、最後は牽連犯（54条1項後段）で束ねる流れになる。
- **［○×クイズ 4/11］** 物を「使ったら返すつもり」で持ち出したというだけで、その行為は当然に不可罰的使用窃盗となり窃盗罪は成立しない。
  - 正解：×（誤り）
  - 理由：返還意思があっても、利用態様によっては権利者排除意思が認められ窃盗になる。「返すつもり」を見た瞬間に不可罰と即断するのが最大の罠。
- **［○×クイズ 5/11］** 窃盗罪は、客観的構成要件（「他人の財物」「窃取」）を検討してから、主観的構成要件（故意・不法領得の意思）に進むのが基本の流れである。
  - 正解：○（正しい）
  - 理由：客観で「他人の財物」「窃取」を固め、主観で故意＋不法領得の意思を検討する。順序を崩すと論点の落としが生じやすい。
- **［○×クイズ 6/11］** 窃盗罪の保護法益を占有それ自体と解する立場（占有説）では、占有者がその物を適法に占有する権原を持つことが、窃盗罪成立の前提となる。
  - 正解：×（誤り）
  - 理由：占有説は占有それ自体を保護する。占有に法律上正当な権原は不要（最判昭35.4.26）だから、盗品＝無権利の占有を侵害しても窃盗が成立しうる。
- **［○×クイズ 7/11］** 自己の所有物であっても、他人がこれを占有している場合に一方的に奪えば、窃盗罪が成立しうる（242条の趣旨）。
  - 正解：○（正しい）
  - 理由：242条は自己物でも他人占有なら「他人の財物」とみなす＝他人の占有それ自体を保護する趣旨。占有説の実定法上の手がかり。
- **［○×クイズ 8/11］** 後で返すつもりがあった（返還意思がある）と認められれば、利用の時間や態様を問わず、権利者排除意思は否定される。
  - 正解：×（誤り）
  - 理由：返還意思があっても、相当程度の利用可能性を侵害する意思があれば権利者排除意思は認められる（最決昭55.10.30）。「返すから無罪」は典型ミス。
- **［○×クイズ 9/11］** 物を使用後に返却した事実は、領得の有無を判断する基準時（領得時）より後の事後事情にすぎず、領得時の意思の有無を直接左右しない。
  - 正解：○（正しい）
  - 理由：返却は領得後の事情。せいぜい権利者排除意思を否定する方向の間接事実にとどまり、「返したから無罪」とはならない。
- **［○×クイズ 10/11］** 住居侵入が窃盗の手段としてなされた場合、住居侵入罪と窃盗罪は牽連犯（54条1項後段）として科刑上一罪となる。
  - 正解：○（正しい）
  - 理由：手段と目的の関係に立つ数罪は牽連犯（54条1項後段）となるから、住居侵入と窃盗は両罪が成立しても科刑上一罪として束ねられ、重い窃盗罪の刑で処断される。
- **［○×クイズ 11/11］** 住居侵入罪の「侵入」が成立するためには、暴行や器物の損壊など物理的に住居を破る行為が必要である。
  - 正解：×（誤り）
  - 理由：「侵入」とは住居等の管理権者の意思に反する立入りをいう。物理的破壊は不要で、留守中に無断で入れば「侵入」に当たる。
