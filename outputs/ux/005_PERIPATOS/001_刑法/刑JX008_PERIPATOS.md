## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

甲は、Aから100万円を渡され、Bへの返済を依頼された。甲は、金額の折り合いがつかず、Bが血気盛んな性格であることから、「けんか沙汰になるかもしれない」と考え気が進まなかったが、日頃の恩義から了承した。甲は、万が一Bに襲われたときに備えて護身用の伸張式の警棒（アルミ製・長さ約21cm）を携帯してB方へ赴いた。甲が「100万円を受け取って欲しい」と伝えると、Bは突如憤慨し、「Aの前にお前を殺してやろうか」と叫び、ガラス製の灰皿をつかんで甲の目の前で頭上まで持ち上げた。甲は、とっさに身の危険を感じこれを避けようとするとともに、無関係の自分に怒号するBに腹を立て、用意していた警棒を取り出してBの顔面を殴打した。Bは倒れこみ頭部を強く打ち、全治約1か月を要する頭頂部打撲挫創の傷害を負った。甲の罪責について、論じなさい（特別法違反の点を除く。）。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- Aの依頼で返済へ（けんか沙汰を予期）
- 護身用警棒を携帯しB方訪問
- Bが激昂→灰皿を頭上まで持ち上げ
- 甲が警棒でBの顔面を殴打
- Bは全治約1か月の傷害

### 参考（読み上げない。入口の問いの答えを含むので判定にだけ使う）

登場人物：
- 甲｜行為者・護身用警棒を携帯（→Bの顔面を殴打）
- B｜債権者・攻撃者（→灰皿を頭上に・甲を脅す）
- A｜委託者・債務者＝行為なし・対象外

一行要約：甲は、けんか沙汰を予期しつつ護身用警棒（アルミ・約21cm）を携帯してB方へ。Bが「殺してやろうか」と叫びガラス灰皿を頭上まで持ち上げたので、甲は身の危険を感じ、かつBに腹を立て、警棒でBの顔面を殴打。Bは全治約1か月の頭頂部打撲挫創。甲の罪責は？

### 入口の問い（3問）

- **［入口 1/3・事案の整理］** 登場人物と「引っかかる行為」を挙げて
  - 答え：行為をしたのは甲（警棒でBの顔面を殴打＝作為）のみ。検討対象はこの1個の行為に絞られる。
  - 答え：B＝攻撃者かつ被害者／A＝返済を頼んだだけは、いずれも甲の罪責検討の対象ではない。ここで切る。
- **［入口 2/3・見当づけ］** 行為は「何罪っぽい？」 ― 見当をつけて
  - 答え：甲は警棒でBの顔面を殴打 → 全治1か月の傷害 → 傷害罪（204条）に当たる。もっともBから先に攻撃されている → 正当防衛（36条1項）で違法性阻却の可能性 → ここが主戦場。
- **［入口 3/3・論点］** 問題になる論点を挙げて（4つ）
  - 答え：CP①：灰皿を頭上に上げただけ＝まだ殴っていない → 侵害の開始時期（急迫性）。（急迫＝侵害が現在し又は間近に押し迫っていること）
  - 答え：CP②：「けんか沙汰になるかも」と予期し警棒を準備 → 侵害の予期と急迫性。（予期して臨んでも急迫性は直ちには失われない＝平29決定）
  - 答え：CP③：「腹を立てて」殴った → 防衛の意思。（攻撃の意思が併存しても防衛の意思は失われないか）
  - 答え：CP④：警棒で顔面・頭部を殴打 → 防衛行為の相当性。（武器対等の原則・過剰防衛との分岐）
