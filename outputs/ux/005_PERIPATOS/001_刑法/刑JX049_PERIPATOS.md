2. あてはめ：記録確認可・住所把握・現に受領 → 実質的減少なし
3. 欺罔も利益に向かわず → 未遂すら×

#### 第2　Bに対する罪責

  - 三場面はバラバラに見えて、すべて「処分行為とその認識」という一本の軸で繋がる。第1＝④客体／第2＝③の主観面（処分意思）／第3＝③そのものの有無。
- 【規範の要点】「財産上の利益」の規範
  - 消極的利得も含むが、「得た」というには支払の一時猶予では足りず、債権の財産的価値が実質的に減少したことを要する（1項＝財物移転との均衡）。判断基準は債権者の事後的追及の容易性。
- 【効く事実】効く事実（不成立方向）
  - Aは事務所で集金記録を確認できた／甲の住所を把握／現に数日後に新聞代を受領 → 追及容易 → 実質的減少なし＝一時猶予にすぎない。さらに利益に向けた欺罔もない→未遂すら不成立。
- 【規範の要点】「処分意思」の規範
  - 処分意思は、処分行為を介する詐欺と、被害者の意思によらない不可罰的利益窃盗とを区別する機能をもつ。よって利益移転を基礎づける外形的事実の認識で足り、内容・価値の正確な認識までは不要（通説）。
- 【効く事実】効く事実（成立方向）
  - Bは代金免脱という正確な認識まではないが、一度店外に出せば回収が著しく困難になりうる外形的事実は認識し得た → 処分意思あり → 退出の承諾＝処分行為。逃走で代金免脱＝2項詐欺成立。
- 【規範の要点】「処分行為の有無＝詐欺と窃盗」の規範
  - 詐欺は被欺罔者が瑕疵ある意思で自ら財産を交付する交付罪。処分行為があるというには、占有移転を基礎づける外形的事実を被欺罔者が認識していることを要する。これを欠けば窃盗。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 場面ごとに罪が成立したら最後に罪数処理を一言。被害者・行為を異にする罪は原則併合罪（45条）、1個の行為で数罪なら観念的競合（54条1項前段）、手段・結果の関係なら牽連犯（同後段）。まず科刑上一罪との振り分けを判断し、別個独立なら併合罪と一文で締める。
- 【まぎらわしい選択肢・論点】不法領得の意思の要否／欺罔行為と財産的損害の因果
- 【まぎらわしい選択肢・結論】詐欺利得罪 成立／1項詐欺罪 成立／遺失物横領罪 成立
- 【まぎらわしい選択肢・規範】一時免脱で足りる（猶予説）／利益の内容・価値の正確な認識が必要
- 【まぎらわしい選択肢・事実】占有移転の確定的な認識あり／暴行・脅迫を用いた

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

A＝嘘で集金を一時免脱→記録確認可・住所把握・現に受領＝実質的減少なし→詐欺利得罪は不成立（未遂も×）。B＝注文時は支払意思ありで1項詐欺×、「友達を迎えに」と偽り店外退出→外形的事実の認識で処分意思○・逃走で代金免脱→2項詐欺（246条2項）。C＝「待つ」認識は占有の弛緩にとどまり処分行為なし→詐欺×、意思に反する占有取得＋「欲しくなった」→窃盗（235条）。罪数＝2項詐欺と窃盗は別被害者・別行為で併合罪（45条）。

## 3. 規範クイズ（全4問・1問目から最後まで全部出す）

- **［規範クイズ 1/4］** 債務の支払を一時免れた利益が「財産上の利益」にあたるための規範（何を要し、何で判断するか）を書いてみよう。
  - 模範解答：規範一時の支払猶予では足りず、債権の財産的価値が実質的に減少したことを要する（1項＝財物移転との均衡）。実質的減少の有無は債権者の事後的な追及の容易性で判断する。
- **［規範クイズ 2/4］** 2項詐欺の「処分意思（交付意思）」について、被欺罔者に要求される認識の程度と、その理由（区別機能）を書いてみよう。
  - 模範解答：規範利益移転を基礎づける外形的事実の認識で足り、内容・価値の正確な認識までは不要。処分意思は、処分行為を介する詐欺と、被害者の意思によらず移転する不可罰的利益窃盗とを区別する機能をもつからである。
- **［規範クイズ 3/4・ひっかけ］** ひっかけ注意「騙した＝即・詐欺ではない」 ― どういうこと？
  - 答え：Cの認識は「工具を取りに行く間、甲が待っている」のみ＝占有移転の認識なし＝占有の弛緩にとどまる。よって処分行為なし→詐欺×。甲はCの意思に反し占有を取得＋「欲しくなった」＝不法領得の意思→窃盗罪（235条）成立。
- **［規範クイズ 4/4］** 詐欺と窃盗を分ける「処分行為」があるといえるための要件（被欺罔者の認識）を書いてみよう。
  - 模範解答：規範詐欺は被欺罔者が自ら財産を交付する交付罪。処分行為があるというには、占有移転を基礎づける外形的事実を被欺罔者が認識していることを要する。認識が占有の弛緩にとどまれば処分行為はなく、隙に取得すれば窃盗となる。

## 4. ○×クイズ（全16問・1問目から最後まで全部出す）

- **［○×クイズ 1/16］** 同一被害者に対し時間的・場所的に近接して反復された同種の侵害行為は、被害者が同じでも常に行為の数だけ別個の犯罪が成立する。
  - 正解：×（誤り）
  - 理由：被害者・法益・機会が同一で密接に連続する場合は、複数行為でも包括一罪として一罪に評価されうる。場面分けは「被害者・法益・機会が替わったか」で行い、機械的に行為数で割らない。
- **［○×クイズ 2/16］** 事案を整理するときは、「誰に・どんな欺罔（嘘）で・何（財物か利益か）を得たか」を場面ごとに書き出すとよい。
  - 正解：○（正しい）
  - 理由：客体が「財物」か「財産上の利益」かで1項詐欺・2項詐欺が分かれる。最初の棚卸しで客体を確定するのが第一歩。
- **［○×クイズ 3/16］** 得たものが「財物」なら1項詐欺（246条1項）、「財産上の利益」なら2項詐欺（246条2項）を疑うのが筋である。
  - 正解：○（正しい）
  - 理由：246条は1項＝財物、2項＝財産上の利益。客体の性質で項を分けるのが詐欺罪検討の出発点。
- **［○×クイズ 4/16］** 相手を騙して財物を手に入れた事案は、相手の処分行為の有無を問わず常に詐欺罪が成立する。
  - 正解：×（誤り）
  - 理由：詐欺は被害者が自ら財産を交付する交付罪。相手の処分行為が無く隙に奪えば窃盗。「騙した＝即・詐欺」は早とちり。
- **［○×クイズ 5/16］** 詐欺罪の成立には、欺く行為と相手方の処分行為との間に「錯誤に基づく」という因果関係が必要であり、相手が錯誤に陥らず処分した場合には（未遂は格別）詐欺既遂は成立しない。
  - 正解：○（正しい）
  - 理由：欺罔→錯誤→処分→移転の各段は因果でつながる必要がある。相手が真実を見抜きつつ憐れみ等で渡したなら錯誤に基づく処分とはいえず既遂にならない（欺罔の段で止まる）。連鎖のどの環が切れたかを特定するのが処理の勘所。
- **［○×クイズ 6/16］** 無銭飲食の事案では、飲食物の交付を受けた点について常に1項詐欺罪が成立する。
  - 正解：×（誤り）
  - 理由：欺く行為・故意は財物交付を生じさせる時点に必要。注文時に支払意思があれば故意（38条1項）を欠き1項詐欺は不成立。逃走による代金免脱を2項詐欺で捉える。
- **［○×クイズ 7/16］** 欺く行為と故意は、財物の交付（または利益の移転）を生じさせる時点に存在することを要する。
  - 正解：○（正しい）
  - 理由：交付の時点を基準に欺罔・故意の有無を判断する。事後に騙す意思が生じても、交付時点に無ければその交付について詐欺は成立しない。
- **［○×クイズ 8/16］** 債務の支払を一時的に免れさえすれば、それだけで2項詐欺罪にいう「財産上の利益」を得たといえる。
  - 正解：×（誤り）
  - 理由：2項詐欺の「財産上の利益」を得たといえる要件は、単なる支払の一時猶予では足りず、債権の財産的価値が実質的に減少したこと。財物移転を要する1項との均衡から利益移転にも具体性・確実性を求めるためであり、減少の有無は債権者の追及の容易性で判断する。追及が容易なら実質的減少は否定され、詐欺利得罪は不成立となる。
- **［○×クイズ 9/16］** 債務の支払を免れた利益が「財産上の利益」にあたるかは、債権者が事後に追及（回収）できるかの容易性を基準に判断する。
  - 正解：○（正しい）
  - 理由：追及が容易なら財産的価値の実質的減少なし＝一時猶予にとどまる。追及困難なら実質的減少を肯定しやすい。
- **［○×クイズ 10/16］** 客体である「財産上の利益」が認められない場合、その取得に向けた欺罔行為も観念できず、詐欺利得未遂罪（250条）も成立しない。
  - 正解：○（正しい）
  - 理由：「およそ成立しない（未遂すら×）」と「既遂に至らない（未遂○）」の区別が上位答案の分かれ目。利益自体が無ければ未遂も立たない。
- **［○×クイズ 11/16］** 2項詐欺の処分意思が認められるには、被欺罔者が移転する利益の内容・価値を正確に認識している必要がある。
  - 正解：×（誤り）
  - 理由：通説の規範では、処分意思は利益移転を基礎づける外形的事実の認識で足り、内容・価値の正確な認識までは不要。処分意思は詐欺と不可罰的利益窃盗とを区別する機能で足りるためであり、正確な認識を要求すると無銭飲食の逃走型の多くで処分意思が否定され不可罰となって不当だから。よって外形的認識があれば2項詐欺は成立する。
- **［○×クイズ 12/16］** 処分意思（交付意思）は、処分行為を介する詐欺罪と、被害者の意思によらず利益が移転する不可罰的な利益窃盗とを区別する機能をもつ。
  - 正解：○（正しい）
  - 理由：この区別機能から、処分意思に求められる認識の程度（外形的事実の認識で足りる）が導かれる。規範の理由づけとして書けると強い。
- **［○×クイズ 13/16］** 詐欺罪は被害者が瑕疵ある意思に基づき自ら財産を交付する「交付罪」であり、処分行為が無ければ詐欺は成立しない。
  - 正解：○（正しい）
  - 理由：処分行為（とその認識）の有無が詐欺と窃盗を分ける。被害者が自ら渡したのではなく隙に奪われたなら窃盗。
- **［○×クイズ 14/16］** 被害者が「その場を少し離れる」と認識しただけで財物のそばを離れた隙に持ち去られた場合、被害者には占有を移転する処分行為がある。
  - 正解：×（誤り）
  - 理由：「少し離れる」は占有の弛緩にすぎず占有移転の認識ではない。処分行為が無いので詐欺ではなく窃盗。
- **［○×クイズ 15/16］** 窃盗罪の成立には、客観的な占有侵奪に加え、主観的要件として不法領得の意思が必要である。
  - 正解：○（正しい）
  - 理由：権利者を排除し自己の物として利用処分する意思。本問は自転車を「欲しくなった」点を拾えば認定できる。
- **［○×クイズ 16/16］** 数個の罪が「一個の行為」によって実現されたか否かにかかわらず、成立した罪が複数あれば常に併合罪（45条）として処理される。
  - 正解：×（誤り）
  - 理由：科刑上一罪との振り分けが先決。一個の行為が数罪に触れれば観念的競合（54条前段）、手段・結果の関係に立てば牽連犯（同後段）で科刑上一罪。これらに当たらず別個独立のときに併合罪となる。「行為が一個か」を基準に判別する。
