## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

連続窃盗で警察に追われていた甲（前科があり執行猶予中）は、父である乙に「身代わりとして警察に出頭してくれないか」と依頼し、乙はこれを了承した。乙は、甲の依頼を受ける前に、警察官の取調べに対し「窃盗をしたのは甲ではなく自分である」と虚偽の供述をし、その内容どおりの警察官面前調書を作成させていた。その後、乙は約束どおり警察署に出向き「実は、私が真犯人である」と身代わりの出頭をした。しかし、乙の供述はあいまいで一貫性を欠いたため、警察はこれを虚偽と判断して乙を逮捕せず、捜査の結果、真犯人は甲であると断定して甲を逮捕した。甲及び乙の罪責について、論じなさい。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 甲が連続窃盗 → 警察に追われる（前科・執行猶予中）
- 乙、依頼を受ける前に「窃盗は自分」と虚偽供述・調書作成
- 甲が乙に「身代わり出頭」を依頼、乙了承
- 乙、警察署に出向き「私が真犯人」と身代わり出頭
- 供述あいまい → 警察は虚偽と判断、乙を逮捕せず
- 捜査の結果、真犯人は甲と断定し甲を逮捕

- 甲｜連続窃盗の犯人本人・執行猶予中（→乙に身代わりを教唆）

#### 第1　乙の罪責

- 見出しの補足（結論を含む。項目の終わりに読む）：犯人隠避罪・103条・105条
1. 虚偽供述＋警察官面前調書 → 【論点】「偽造」（104条）該当性 → 偽証罪の趣旨（169条＝宣誓者限定）→ 宣誓なき虚偽供述は偽造（最決平28）
2. 虚偽供述・身代わり出頭 → 【論点】「隠避」（103条）該当性（規範：蔵匿以外で発見・逮捕を妨げる一切の行為）
   - あてはめ：身柄拘束前・犯人特定前で最決平29の射程外／犯人特定作用も司法作用 → 隠避○（2個）
   - あてはめ：あいまいで逮捕不奏功でも抽象的危険犯 → 成立
3. 乙は甲の父＝親族 → 【論点】105条の刑の任意的免除
- 結論：犯人隠避罪 成立（2個）・105条で任意的免除

#### 第2　甲の罪責

- 見出しの補足（結論を含む。項目の終わりに読む）：犯人隠避罪の教唆犯・61条1項/103
1. 犯人本人の自己隠避は不可罰／甲は乙に身代わりを依頼
2. 【論点】犯人による自己隠避の教唆の可否 → 正犯を介した間接的法益侵害・防御権の濫用で期待可能性否定されず → 他人を巻き込む隠避 → 教唆○（大判昭8）
3. 【論点】甲への105条準用の可否 → 甲は犯人本人で「親族」でない → 準用
- 結論：犯人隠避罪の教唆犯 成立・105条準用なし

#### 第3　罪数

   乙の虚偽供述による隠避と身代わり出頭による隠避の2個 → 別個の機会・態様 → 併合罪（45条前段）（保護法益の単一性を重視し包括一罪も可）

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】『「窃盗をしたのは自分」＋警察官面前調書』 → 偽造該当性（最決平28で否定）
- 【拾う事実】『「私が真犯人」＝身代わり出頭』 → 隠避該当性（成立）
- 【拾う事実】『依頼を受ける前に・身柄拘束前』 → 最決平29の射程外を分ける
- 【拾う事実】『あいまいで逮捕に至らず』 → 抽象的危険犯で成立に影響なし
- 【拾う事実】『乙＝甲の父／甲＝犯人本人』 → 105条・自己隠避の教唆の可否
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 乙が窃盗の真犯人かどうかは検討対象外（甲が真犯人＝「罪を犯した者」）／犯人隠避は抽象的危険犯で逮捕不奏功でも成立／違法性・責任＝阻却事由なし＝一言で素通り。
- 【効く事実】あてはめで使う事実
  - 偽造の否定 → 「窃盗をしたのは自分」＝宣誓なき虚偽供述／隠避 → 「私が真犯人」＝身代わり出頭＋警察官面前調書／隠避は成立 → 「あいまいで逮捕に至らず」でも抽象的危険犯だから成立／105条 → 乙は甲の父（親族）。
- 【規範の要点】教唆肯定説の規範
  - 犯人自身の隠避は不可罰だが、他人を教唆して隠避させる行為は、正犯（乙）を介した間接的な法益侵害の惹起であり、他人を巻き込む点で防御権の濫用にあたり期待可能性も否定されない → 犯人隠避罪の教唆犯（61条1項・103条）が成立（大判昭8.10.18）。甲は犯人本人で「親族」でなく105条準用なし。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 共犯従属性で甲の教唆は乙の正犯に従属（共犯関係を一言確認）。乙の2個の隠避は別個の機会・態様だから併合罪（45条前段）。保護法益の単一性を重視すれば包括一罪も可。
- 【まぎらわしい選択肢・論点】親族による証拠隠滅の特例／共謀共同正犯の成否／偽証罪の成否
- 【まぎらわしい選択肢・結論】証拠偽造罪 成立／犯人隠避罪 不成立
- 【まぎらわしい選択肢・規範】身柄拘束作用説に限定／犯人特定作用説のみ
- 【まぎらわしい選択肢・事実】身柄拘束後／宣誓あり

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

乙＝虚偽供述＋調書は偽証趣旨で偽造（平28）、虚偽供述・身代わり出頭は隠避○（身柄拘束前＝平29射程外）、抽象的危険犯で逮捕不奏功でも成立、父＝親族で105条免除。甲＝犯人本人でも他人教唆は防御権濫用で教唆犯○（昭8）、親族でなく105条準用。罪数＝隠避2個は別機会で併合罪。

## 3. 規範クイズ（全2問・1問目から最後まで全部出す）

- **［規範クイズ 1/2］** 犯人蔵匿等罪（103条）の「隠避」の意義（定義）を書け。
  - 模範解答：「隠避」とは、蔵匿以外の方法により、官憲による犯人の発見・逮捕を妨げる一切の行為をいう（最決平元.5.1）。身代わり出頭・虚偽供述もこれに含まれる。「逮捕を免れさせた」結果は不要（抽象的危険犯）。
- **［規範クイズ 2/2］** 参考人の虚偽供述が証拠偽造罪（104条）にあたらないとされる理由を書け。
  - 模範解答：刑法は虚偽供述を偽証罪（169条）として宣誓した証人に限り処罰する趣旨だから、宣誓に基づかない参考人の虚偽供述は、調書に録取されても、そのことだけで証拠偽造罪にはあたらない（最決平28.3.31）。「供述証拠」と「物理的な証拠の作出」を区別するのがカギ。

（規範クイズはここまで＝全2問。最後の2問目まで出したら「規範クイズ、全2問クリア！」と言って次へ）

## 4. ○×クイズ（全5問・1問目から最後まで全部出す）

- **［○×クイズ 1/5］** 犯人蔵匿・隠避罪（103条）の保護法益は国家の刑事司法作用であり、隠匿された犯人本人ではなく国家が被害者にあたる。
  - 正解：○（正しい）
  - 理由：犯人蔵匿等罪は国家の刑事司法作用（捜査・裁判・刑の執行）を保護法益とする。被害者が私人でないため、検討の的は「司法作用を妨げる行為をした者」に絞られる。
- **［○×クイズ 2/5］** 参考人が捜査機関に対して口頭で虚偽の供述をし、その内容どおりの供述調書が作成された場合、そのことだけで証拠偽造罪（104条）の「証拠を偽造した」にあたる。
  - 正解：×（誤り）
  - 理由：刑法は虚偽供述を偽証罪（169条）として宣誓した証人に限って処罰する趣旨である。宣誓に基づかない参考人の虚偽供述は、調書に録取されても、そのことだけで証拠偽造罪にあたるものではない（最決平28.3.31）。
- **［○×クイズ 3/5］** 犯人隠避罪は抽象的危険犯であるから、隠避行為があれば、現に犯人が逮捕を免れたという結果が生じなくても成立する。
  - 正解：○（正しい）
  - 理由：犯人蔵匿等罪は刑事司法作用を危殆化する抽象的危険犯。隠避行為があれば足り、捜査が現に妨げられた（逮捕を免れた）という結果は不要。身代わりが見破られて逮捕に至らなくても成立する。
- **［○×クイズ 4/5］** 犯人が自ら逃げ隠れする行為（自己隠避）は不可罰だが、犯人が他人を教唆して自己を隠避させた場合には、犯人に犯人隠避罪の教唆犯が成立しうる。
  - 正解：○（正しい）
  - 理由：自己隠避が不可罰なのは防御の自由の範囲だからにすぎない。他人を巻き込んで隠避させる行為は、新たに他人を犯罪に陥れる点で防御権の濫用であり、期待可能性も否定されないから、犯人にも教唆犯が成立する（大判昭8.10.18・証拠隠滅につき最決昭40.9.16も同旨）。
- **［○×クイズ 5/5］** 同一の犯人をかくまう目的で、別個の機会に異なる態様の隠避行為を2回行った場合、保護法益が同一であることから、常に1個の犯人隠避罪（包括一罪）のみが成立する。
  - 正解：×（誤り）
  - 理由：別個の機会・態様による複数の隠避行為は、別個の行為として併合罪（45条前段）と解しうる。保護法益（刑事司法作用）の単一性を重視して包括一罪と解する余地もあるが、「常に包括一罪」とは限らない。罪数は事案に応じて評価する。

（○×クイズはここまで＝全5問。最後の5問目まで出したら「○×クイズ、全5問クリア！」と言って復習へ）
