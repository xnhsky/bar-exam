甲は、先輩Bから借金の返済を迫られ、資産家A宅に侵入したところ、現金5万円と万年筆を発見し、5万円はBへの返済に、万年筆は自己のために持ち出すことにした。甲が両財物を持ったままA宅を出ようとした際、玄関でAと鉢合わせ、甲は「どうせならAを脅してさらに現金等を奪おう」と考え、ナイフを示しながら「金を出せ」と申し向けた。Aは怯んだがA宅を出て大声で助けを求め、甲は奪取を諦め立ち去った。その後、甲は5万円を封筒に入れメンディングテープで封をし、封入部分に「〆」と記載した（本件封筒）。甲は、盗品であることを秘して、友人乙に本件封筒のB宛交付と万年筆の保管を依頼し、乙は同情して預かった。翌日、乙は万年筆の「A」刻印からこれが盗品と気付いたが、なお甲のため保管を継続し、また本件封筒を破って中の5万円を口止め料として自己の財布に入れた。甲及び乙の罪責について、論じなさい。

- 甲：A宅侵入→5万円・万年筆を持出し（占有取得）
- 甲：玄関でAと鉢合せ→ナイフ「金を出せ」→断念

  - 答え：A＝被害者は対象外。B＝封筒をまだ受け取っていない（行為なし）から対象外。ここで切るのが第一歩。
- **［入口 2/4・見当づけ］** 各行為は「何罪っぽい？」 ― 見当をつけて
  - 答え：甲：A宅侵入＝住居侵入(130前段)／持出し＝窃盗(235)／ナイフ脅迫で「さらに奪おう」＝1項強盗(236①)。乙：盗品の保管＝盗品等保管罪(256②)／封筒の中身を抜取り＝窃盗か横領(235/252)。

### 骨子（3項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　甲の罪責

- 見出しの補足（結論を含む。項目の終わりに読む）：住居侵入・窃盗→1項強盗未遂
1. A宅侵入＝住居侵入(130前段)／5万円・万年筆持出し＝窃盗既遂(235)　…素直に通す
2. 鉢合せ→ナイフ「金を出せ」＝反抗抑圧に足る脅迫＝1項強盗の着手(236①)
3. 【論点】居直り強盗 ― 窃盗既遂後の脅迫で既遂か
   規範：強盗の暴行脅迫は財物取得の手段／既取得財物は脅迫との因果性なし
   あてはめ：5万円・万年筆は脅迫前に取得済＝因果性なし／全体強盗既遂説は相当でない
- 結論：新財物の取得なし＝「遂げなかった」(243) → 1項強盗未遂罪 成立
4. 罪数：窃盗既遂は重い強盗未遂に吸収／住居侵入と牽連犯(54①後段)

#### 第2　乙の罪責

- 見出しの補足（結論を含む。項目の終わりに読む）：盗品保管・封緘物の窃盗
1. 万年筆：預かり時は知らず故意なし → 【論点】盗品保管罪の知情時期
   規範：継続犯／知情後も本犯のため保管継続＝その時点から寄蔵
   あてはめ：翌日「A」刻印で知情→保管継続 → 盗品等保管罪(256②) 成立
2. 5万円（本件封筒）：抜取りは窃盗か横領か → 【論点】封緘物の占有
   規範：封緘物全体＝受託者占有／中身＝委託者占有
   あてはめ：「〆」封印で乙は中身を処分不可＝中身は甲占有 → 窃盗罪(235) 成立
   ＋【論点】盗品の占有も保護法益か → 占有説で要保護＝盗品性は障害でない
   ＋5万円は「口止め料」目的＝本犯のため保管意思なし → 保管罪不成立
3. 罪数：盗品保管罪(万年筆)と窃盗罪(5万円)は 併合罪(45前段)

#### 第3　甲乙の共犯

   甲は盗品性を秘す＝意思連絡なし → 共同正犯不成立 → 各自 単独で処断

- 【拾う事実】「さらに現金等を奪おう」 → ＝新たな奪取意思（事後強盗でなく1項強盗）
- 【拾う事実】『「〆」と記載』 → ＝封緘（中身の占有が誰かを分ける）
- 【拾う事実】『「A」刻印で気付いた』 → ＝知情の時期（預かり後）
- 【拾う事実】「口止め料としてもらおう」 → ＝自己領得意思（本犯のため保管でない）
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 甲のA宅侵入＝住居侵入(130前段)／5万円・万年筆の持出し＝占有移転で窃盗既遂(235)。脅迫が反抗抑圧に足ることも明白。立ち止まるのはその先。
- 【規範の要点】「居直り強盗」の規範
  - 強盗罪の暴行・脅迫は、財物取得の手段としてなされることを要する。既に取得済みの財物については、その後の脅迫との間に因果関係を欠く。
- 【効く事実】「居直り強盗」のあてはめで使う事実
  - 5万円・万年筆は脅迫の前に窃取し占有取得済み＝脅迫と因果性なし／甲は新たな財物を取得していない（Aの叫びで断念）＝「これを遂げなかった」(243)。全体を1項強盗既遂とする説は、因果性を欠き相当でない、と一言で否定。
- 【規範の要点】「封緘物・知情時期・保護法益」の規範
  - ①封緘物：包装物全体の占有は受託者／内容物の占有はなお委託者に帰属 → 中身の抜取りは委託者の占有侵害＝窃盗(235)。②盗品保管罪は継続犯＝知情後も本犯のため保管継続すれば、その時点から寄蔵(256②)。③保護法益＝占有説で窃盗犯人の占有も一応保護に値する。
- 【効く事実】「封緘物・知情時期・保護法益」のあてはめで使う事実
  - 封緘 → 「〆」で封印し乙は中身を処分できない＝中身は甲占有／知情 → 翌日「A」刻印で気付き、なお保管継続＝知情後の寄蔵／5万円の二面性 → 「口止め料としてもらおう」＝本犯のため保管意思なし→保管罪不成立・抜取りは窃盗。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 複数の罪が成立したら最後に罪数処理を一言。法益が共通し連続する軽い罪は重い罪に吸収、手段・目的の関係なら牽連犯（54条1項後段）、それ以外で社会通念上別個なら併合罪（45条）。観念的競合は54条前段。
- 【まぎらわしい選択肢・論点】事後強盗罪(238)の成否／横領罪一本で確定
- 【まぎらわしい選択肢・結論】1項強盗既遂罪 成立／横領罪 成立／盗品等保管罪 成立（5万円）
- 【まぎらわしい選択肢・規範】全体強盗既遂説で既遂
- 【まぎらわしい選択肢・事実】逮捕免脱の目的／封筒ごと横領

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

甲＝A宅侵入（130前段）＋5万円・万年筆窃盗既遂（235）。鉢合せ→ナイフ「金を出せ」で1項強盗着手だが既取得財物と脅迫に因果性なし＋新財物取得なし→1項強盗未遂（243）。窃盗は強盗未遂に吸収・住居侵入と牽連犯。乙＝万年筆は知情後の保管継続→盗品等保管罪（256②）。5万円は封緘物で中身は甲占有→封筒を破り抜取り＝窃盗（235）、盗品でも占有説で要保護。両罪は併合罪。共犯＝甲は盗品性を秘す＝意思連絡なし→共同正犯不成立。

## 3. 規範クイズ（全2問・1問目から最後まで全部出す）

- **［規範クイズ 1/2］** 事後強盗罪（238条）の暴行・脅迫が向けられる「3つの目的」を挙げよ。
  - 模範解答：①財物の取り返しを防ぐ目的／②逮捕を免れる目的／③罪跡を隠滅する目的（238条）。この3目的のどれでもなく「新たに別の財物を奪う」なら1項強盗。
- **［規範クイズ 2/2］** 1項強盗（236条1項）が「未遂」（243条＝「これを遂げなかった」）にとどまるのは、どのような場合か。手段と結果の関係から一般化して述べよ。
  - 模範解答：反抗を抑圧するに足る暴行・脅迫を加えた（着手あり）が、それを手段として新たな財物を取得しなかった場合＝強盗未遂。本問は脅迫したが奪取を断念した型。

## 4. ○×クイズ（全12問・1問目から最後まで全部出す）

- **［○×クイズ 1/12］** 犯罪が成立するには刑法上の「行為」（意思に基づく身体の動静）の存在を要するから、何らの作為も不作為もしていない者には、結果との関連があっても犯罪は成立しない。
  - 正解：○（正しい）
  - 理由：行為主義の原則。構成要件該当性の前提として「行為」が要る。これが、まだ何も受け取らず作為も不作為もしていない者を罪責の検討対象から外せる理論的根拠（手を下した者・関与した者だけを拾う）。
- **［○×クイズ 2/12］** 複数の財産犯が連続する事案は、人ごと・行為ごとに切り分け、各行為について構成要件→違法性→責任→罪数を順に回すのが基本である。
  - 正解：○（正しい）
  - 理由：行為の切り出しが甘いと、後の罪数処理や論点抽出が崩れる。長い事案ほど「行為ごとに分ける」が効く。
- **［○×クイズ 3/12］** 事後強盗罪（238条）の主体は「窃盗」を犯した者に限られ（身分犯）、その暴行・脅迫は窃盗の機会の継続中に加えられることを要する。
  - 正解：○（正しい）
  - 理由：事後強盗は窃盗犯人を主体とする身分犯。暴行脅迫は財物取得の手段ではなく、窃盗の機会継続中に取還防止・逮捕免脱・罪跡隠滅の目的でなされる点で、財物取得の手段とする1項強盗(236①)と区別される。
- **［○×クイズ 4/12］** 同じ「物を預かって保管する」行為でも、本犯のために保管するなら盗品等保管罪、自分の物にするため領得するなら領得罪（窃盗・横領）と、目的・意思により罪名が変わる。
  - 正解：○（正しい）
  - 理由：本問の乙は、万年筆は本犯甲のため保管＝盗品保管罪、5万円は自己領得＝窃盗、と1人の中で罪名が分かれる。意思を読み分ける。
- **［○×クイズ 5/12］** 封をして「〆」と記した封筒を預かった者は、封筒全体を占有している以上、中身を抜き取っても常に横領罪にしかならない。
  - 正解：×（誤り）
  - 理由：封緘物は、包装物全体の占有は受託者でも中身の占有はなお委託者に残る。中身の抜取りは委託者の占有侵害＝窃盗罪。
- **［○×クイズ 6/12］** 強盗罪（236条1項）の暴行・脅迫は財物取得の手段としてなされることを要するから、すでに取得済みの財物については、その後に加えた脅迫との間に因果関係を認めることはできない。
  - 正解：○（正しい）
  - 理由：これが居直り強盗を「未遂」とする中核理由。手段としての暴行・脅迫＝財物取得の因果性が要件。
- **［○×クイズ 7/12］** 窃盗が既遂に達した後の脅迫について、窃盗と脅迫を全体として一連の行為とみて1項強盗の既遂と評価する処理は、判例・通説上も全く問題のない確立した立場である。
  - 正解：×（誤り）
  - 理由：全体強盗既遂説（広島高松江支判昭32.5.27）もあるが、新たな財物取得がない以上、既取得財物と脅迫の因果性を欠き相当でない。未遂とするのが筋（大阪高判昭33.11.18等）。
- **［○×クイズ 8/12］** 封緘された委託物について、包装物全体の占有は受託者に、内容物の占有はなお委託者に帰属するから、受託者が中身を抜き取る行為は委託者の占有を侵害し窃盗罪を構成する。
  - 正解：○（正しい）
  - 理由：分離説（最決昭32.4.25等）。封緘により受託者は中身を処分できないから、中身の占有は委託者に残る。抜取り＝窃盗、封筒ごと横領＝横領、と区別する。
- **［○×クイズ 9/12］** 盗品等保管罪は継続犯であり、預かった当初は盗品と知らなくても、後で盗品と知りながらなお本犯のために保管を継続すれば、その知情の時点から同罪が成立する。
  - 正解：○（正しい）
  - 理由：追及権を侵害する継続犯ゆえ、事後的知情＋保管継続で寄蔵に当たる（最決昭50.6.12参照）。預かり当初は故意なく不成立、と時間軸で書き分けるのが要。
- **［○×クイズ 10/12］** 窃取の対象物が「盗品」であった場合、その占有はおよそ保護に値しないから、盗品をさらに奪っても窃盗罪は成立しない。
  - 正解：×（誤り）
  - 理由：占有説では、窃盗犯人の占有も一応保護に値する。盗品であることは窃盗罪の成立の障害とならない（本問の5万円は盗品だが、抜取りは窃盗）。
- **［○×クイズ 11/12］** 同一被害者の財産に対し、窃盗が既遂に達した後さらに強盗（未遂）に及んだ場合、軽い窃盗既遂罪は重い強盗未遂罪に吸収されると処理しうる。
  - 正解：○（正しい）
  - 理由：保護法益が共通し時間的・場所的に近接・連続する場合、軽い罪は重い罪に吸収（包括一罪）。本問の窃盗既遂は強盗未遂に吸収し、住居侵入とは牽連犯。
- **［○×クイズ 12/12］** 共同正犯（60条）の成立には、各関与者が相互に他人の行為を利用し合う意思（共同実行の意思＝意思連絡）と、その意思に基づく共同実行の事実とを要する。
  - 正解：○（正しい）
  - 理由：共同正犯は「共謀（意思連絡）＋共同実行」を要件とし、これがあれば一部実行全部責任を負う。一方が他方を欺いて利用するなど意思連絡を欠くときは共同正犯は成立せず、各自が別個に処断される。
