## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

甲及び乙（以下「甲ら」という。）は、裕福な老人であり一人暮らしをしているAから金員を奪おうと企み、深夜にA宅へ立ち入った。すると、甲らの予想に反して、Aが起きていたため、甲らは、Aに暴行を加え、Aが抵抗しなくなってから金員を奪うことにし、Aを殴り始めた。この時、甲はAが死亡してもかまわないと思っていたが、乙はAが死ぬことはないだろうと思っていた。甲らは、数分後、Aが失神して動かなくなったことから、A宅のタンスをあさったところ、同所から現金を見付けて、これをポケットに入れ、A宅から出た。甲は、現金を山分けし、乙と別れた後で冷静さを取り戻し、大変なことをしたと思い、Aの命だけは助けたいと考え、匿名で病院に電話をして救急車を呼んだが、救急隊員の到着を待つことなく、自宅へ帰った。Aは、翌朝まで放置されていれば、死亡する危険性があったが、甲の電話によって駆けつけた救急隊員の迅速な処置によって一命を取り留めた。甲及び乙の罪責について論じなさい。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 深夜、金員奪取を企て共謀のうえA宅へ侵入
- Aが起きていた→暴行→反抗抑圧後に奪取と決意し殴打（現場共謀）
- 甲＝死亡容認／乙＝死なないと思う（主観が分岐）
- 数分後Aが失神→タンスから現金を奪取しA宅を出る
- 甲が悔悟し匿名で救急車→到着待たず帰宅／Aは一命をとりとめる

### 参考（読み上げない。入口の問いの答えを含むので判定にだけ使う）

登場人物：
- 甲｜共謀の一方・殺意あり（→暴行・奪取／後に救急車を匿名通報し帰宅）
- 乙｜共謀の一方・殺意なし（→暴行・奪取／甲と山分けして別離）
- A｜裕福・一人暮らしの老人＝被害者・対象外

一行要約：甲乙が共謀してA宅侵入→暴行で反抗抑圧→現金奪取。甲は殺意あり・乙は殺意なし。甲は事後に匿名で救急車を呼ぶも到着前に帰宅、Aは死亡せず。

  - 答え：A＝被害者は対象外。共通行為（侵入→暴行→奪取）に、甲だけ「死亡してもかまわない＝殺意あり」、乙は「死なないだろう＝殺意なし」のタグを付けて分けるのが第一歩。
- **［入口 2/3・見当づけ］** 各行為は「何罪っぽい？」 ― 見当をつけて

### 骨子（3項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　甲の罪責

- 見出しの補足（結論を含む。項目の終わりに読む）：強盗殺人未遂・240後段／中止犯・43但書
1. 侵入・強盗を通して加重類型へ → 住居侵入罪（130前段）＋強盗罪（236条1項）を確認 → 甲の殺意ゆえ強盗殺人罪の成否へ
2. 【論点】240条後段に殺意ある場合を含むか（規範：240後段は「よって」を欠く→致死のみならず殺意ある場合（強盗殺人）も含む）→ 甲は「死亡してもかまわない」と未必の殺意で反抗抑圧の暴行→現金奪取 → 強盗殺人罪が問題
3. 【論点】既遂・未遂の区別基準（規範：重い法定刑は生命・身体の保護に由来→人の死の結果を基準）→ 現金は奪取もAは救急処置で一命を取り留め死亡していない → 財物奪取に引きずられず強盗殺人未遂罪 成立（240後段・243）
4. 【論点】中止犯の任意性と中止行為（規範：任意性＝あえてやめたと評価できること／中止行為は因果進行中なら結果防止の積極的措置を要する）→ 悔悟の通報で任意性○も、救急隊員の到着を待たず帰宅・匿名通報で引渡し未了・真摯性に疑い
   - あてはめ：中止行為が不十分
- 結論：中止犯不成立。甲は住居侵入と強盗殺人未遂が牽連犯

#### 第2　乙の罪責

- 見出しの補足（結論を含む。項目の終わりに読む）：強盗致傷・240前段／共犯と錯誤
1. 乙は殺意なし＝致傷へ → 住居侵入・強盗の共同正犯は成立も、殺意なく強盗殺人未遂は不成立 → 強盗致傷罪（240前段）どまり
2. 【論点】罪名の食い違う共同正犯の成否（規範：本質＝相互利用補充関係による一体性→構成要件的に重なり合う限度で「犯罪」の「共同」＝部分的犯罪共同説）→ 甲（強盗殺人未遂）と乙（強盗致傷）は強盗致傷罪の限度で重なり合う
- 結論：その限度で甲乙に強盗致傷罪の共同正犯 成立、甲には別途強盗殺人未遂の単独正犯

- 【拾う事実】「死ぬことはないだろう」 → 乙の心理（殺意なし＝致傷側）
- 【拾う事実】『一人暮らしの老人／2人がかり／失神まで殴打』 → 反抗抑圧の暴行の認定
- 【拾う事実】『タンスから現金をポケットに』 → 財物奪取あり（死亡結果はなし）
- 【拾う事実】『救急隊員の到着を待たず帰宅／匿名で通報』 → 中止行為の不十分・真摯性の疑い
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 住居侵入（130前段）＝争いなく一言／強盗の暴行＝老人・2人がかり・失神まで殴打で反抗抑圧を一気に認定／財物奪取＝現金をポケットに＝あり。争いの薄い前提は厚く書かず、240条後段と中止と共犯の3つの山に時間を割く。
- 【効く事実】効く事実（中止犯）
  - 任意性 → 「大変なことをした」「命だけは助けたい」＝悔悟による自発（どの説でも○）／中止行為 → 「救急隊員の到着を待たず帰宅」＝引渡し未了＋「匿名で通報」＝真摯性に疑い。因果進行中だから積極的措置（引渡しまで）を要する、と評価語で締める。
- 【規範の要点】部分的犯罪共同説の規範
  - 共同正犯（60条）の本質＝相互利用補充関係による一体性 → 成立には共同して特定の構成要件を実現した事実を要するが、構成要件的に重なり合う限度で「犯罪」の「共同」が認められる → 強盗致傷罪の限度で甲乙に共同正犯成立、甲には別途強盗殺人未遂の単独正犯。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 住居侵入は強盗（殺人・致傷）の手段だから牽連犯（科刑上一罪）。甲＝住居侵入＋強盗殺人未遂で牽連犯、乙＝住居侵入＋強盗致傷で牽連犯。共同正犯の成立罪名（強盗致傷）と甲の単独正犯（強盗殺人未遂）は二段で書き分けてから罪数に進む。
- 【まぎらわしい選択肢・論点】正当防衛の成否／完全犯罪共同説の採否／事前暴行が窃盗か強盗か
- 【まぎらわしい選択肢・結論】強盗殺人既遂罪 成立／強盗致死罪 成立／中止犯 成立
- 【まぎらわしい選択肢・規範】財物奪取説／行為共同説
- 【まぎらわしい選択肢・事実】殺意なし／死亡結果あり

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

甲＝侵入＋強盗、殺意あり＝240後段（後段は殺意も含む）、既遂未遂は人の死で測る＝未遂、救急車呼ぶも引渡し未了・匿名＝中止行為不十分で中止犯不成立。乙＝殺意なし＝強盗致傷、甲と罪名食い違い＝部分的犯罪共同説で強盗致傷の限度で共同正犯、甲は別途強盗殺人未遂の単独正犯。各人＝侵入と強盗は牽連犯。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 強盗致死傷罪（240条後段）について、①殺意ある場合を含むか、②既遂・未遂の区別基準、の2つの規範を挙げよ。
  - 模範解答：①240条後段は「よって」の文言を欠くから、結果的加重犯（強盗致死）のみならず殺意ある場合（強盗殺人）をも含む。②重い法定刑が生命・身体の保護に由来することから、既遂未遂は人の死の結果を基準とする（財物奪取の有無は問わない）。
- **［規範クイズ 2/3］** 中止犯（43条但書）の「中止した」（中止行為）について、結果発生に向けた因果が既に進行している場合に要求される行為の程度を、規範として述べよ。
  - 模範解答：結果不発生に向けた因果の流れがいまだ進行を開始していない場合は単なる不作為（中止すること）で足りるが、既に進行を開始している場合は、結果不発生に向けた積極的な措置（自ら被害者を病院へ運ぶ・救急隊員に引き渡す等）を要する。
- **［規範クイズ 3/3］** 共同正犯者間で故意（罪名）が食い違う場合の処理について、判例・通説とされる部分的犯罪共同説の規範を述べよ。
  - 模範解答：相互利用補充関係に基づく共同犯行の一体性という共同正犯の性質から、その成立には共同して特定の構成要件を実現した事実を要する。もっとも、構成要件的に重なり合う範囲については「犯罪」の「共同」が認められるから、その限度で共同正犯が成立する（重い故意の者には、はみ出し分の単独正犯が別途成立する）。

## 4. ○×クイズ（全6問・1問目から最後まで全部出す）

- **［○×クイズ 1/6］** 同一の客体に共同して暴行を加えた共犯者であっても、死亡結果に対する故意（殺意）の有無は各人ごとに別個に判断される。
  - 正解：○（正しい）
  - 理由：故意は各行為者の主観であり、共同実行の事実があっても一方の殺意が他方に当然に帰属するわけではない。だからこそ甲＝殺意あり・乙＝殺意なし、と人物ごとに主観のタグを付けるのが棚卸しの肝。罪名分岐の出発点になる。
- **［○×クイズ 2/6］** 強盗致死傷罪（240条）の前段（致傷）と後段（致死）の振り分けは、もっぱら現実に生じた結果が傷害か死亡かによって決まり、行為者の主観は関係しない。
  - 正解：×（誤り）
  - 理由：240条後段は殺意ある場合（強盗殺人）も含むと解されるから、結果だけでなく主観も振り分けに効く。死の結果が生じなくても殺意があれば強盗殺人未遂を、殺意がなければ生じた傷害につき強盗致傷を疑う。AIMの段では「結果＋主観の文言」を両にらみする。
- **［○×クイズ 3/6］** 反抗を抑圧するに足りる「暴行」（236条1項）の有無は、被害者の年齢・人数・行為態様など事案の具体的事情を社会通念に照らして判断する。
  - 正解：○（正しい）
  - 理由：強盗の暴行は「社会通念上一般に被害者の反抗を抑圧するに足る程度」かで判断され、被害者の属性（一人暮らしの老人）・複数人による犯行・失神まで殴打した態様などの具体的事情を総合する。本問はこれらを拾えば争いなく認定でき、ここを厚くしすぎないのがメリハリ。
- **［○×クイズ 4/6］** 結果発生に向けた因果が既に進行している事案では、行為者が救助の端緒（救急車を呼ぶ等）に着手しさえすれば、それだけで中止犯の「中止した」が認められる。
  - 正解：×（誤り）
  - 理由：因果が進行中の場合、端緒に着手するだけでは足りず、結果不発生に向けた真摯・積極的な措置（被害者を引き渡すなど）まで要する。途中で立ち去れば中止行為として不十分。
- **［○×クイズ 5/6］** 部分的犯罪共同説によれば、殺意のある者と殺意のない者が共同して暴行を加えた場合、殺意のある者も含めて全員に重い罪（殺人系）の共同正犯が成立する。
  - 正解：×（誤り）
  - 理由：部分的犯罪共同説では、共同正犯が成立するのは軽い罪（重なり合う限度）＝致傷・致死系まで。殺意のある者には、それを超える分（殺人系）が単独正犯として別途成立する。「成立する共同正犯の罪名」と「各人の最終罪名」が分離する点が肝で、ここを混同すると減点。
- **［○×クイズ 6/6］** 住居に侵入したうえで強盗を行った場合、住居侵入罪と強盗罪は手段・目的の関係に立ち、牽連犯（54条1項後段）として科刑上一罪となる。
  - 正解：○（正しい）
  - 理由：牽連犯は、ある犯罪の手段または結果である行為が他の罪名に触れる場合の科刑上一罪。住居侵入は強盗（その加重類型を含む）の典型的な手段行為であり、両者は牽連犯となる。

（○×クイズはここまで＝全6問。最後の6問目まで出したら「○×クイズ、全6問クリア！」と言って復習へ）
