### 骨子（3項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　覚せい剤譲受け・所持罪

- 見出しの補足（結論を含む。項目の終わりに読む）：覚せい剤取締法41の2・10年＝重
1. 客観：10万円支払い・受領・隠匿 → 譲受け・所持に該当
2. 麻薬と誤認 → 【論点】重い覚せい剤罪の故意の有無
   規範：故意＝認識・認容／38条2項で重い罪処断不可
   あてはめ：「麻薬と思い」＝覚せい剤の認識なし
- 結論：故意を欠く ＝ 覚せい剤罪 不成立

#### 第2　麻薬譲受け・所持罪

- 見出しの補足（結論を含む。項目の終わりに読む）：麻薬取締法66条1項・7年＝軽
1. 認識（麻薬）≠実現（覚せい剤）＝別構成要件 → 【論点】抽象的事実の錯誤
   規範：実質的重なり合いの限度で軽い罪の故意犯成立（法定的符合説）
   あてはめ：保護法益＝規制薬物からの社会防衛・行為態様＝譲受け所持が共通
- 結論：軽い麻薬罪の限度で符合 ＝ 麻薬譲受け・所持罪 成立

#### 第3　罪数

   譲受け罪と所持罪 → 同一物の継続した占有 → 包括一罪

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「上記麻薬が入っているものと思い」 → ＝実物（覚せい剤）と認識がズレている
- 【拾う事実】『鑑定＝覚せい剤（フェニルメチルアミノプロパン塩酸塩）』 → ＝客観面の確定
- 【拾う事実】『10万円支払い・受領・隠匿して所持』 → ＝譲受け・所持の客観事実
- 【拾う事実】『覚せい剤10年＞麻薬7年』 → ＝法定刑の軽重
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 覚せい剤罪：客観＝10万円支払い・受領・隠匿＝譲受け・所持に該当（一文）。止まるのは故意だけ。
- 【規範の要点】「重い覚せい剤罪の故意阻却」の規範
  - 故意（38条1項）＝構成要件該当事実の認識・認容。軽い罪の認識で重い罪を実現したときは、重い罪では処断できない（38条2項）。
- 【効く事実】「重い覚せい剤罪の故意阻却」のあてはめで使う事実
  - 故意なし → 「茶封筒に上記麻薬が入っているものと思い」＝覚せい剤の認識なしを直接引用／客観 → 10万円支払い・受領・隠匿＝譲受け・所持／軽重 → 麻薬7年＜覚せい剤10年。
- 【規範の要点】法定的符合説の規範
  - 異なる構成要件にまたがる錯誤でも、①保護法益の共通性＋②行為態様の共通性から構成要件が実質的に重なり合う限度で、軽い罪の故意犯が成立する（最決昭61.6.9）。
- 【効く事実】「抽象的事実の錯誤で軽い罪に拾えるか」のあてはめで使う事実
  - ①法益 → 覚せい剤も麻薬も「違法・有害な規制薬物から社会を守る」点で共通／②態様 → 譲受け・所持で同じ → 軽い麻薬罪の限度で重なり合い → 麻薬譲受け・所持罪が成立。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 複数の罪が成立したら最後に罪数処理を一言。観念的競合（54条前段）／牽連犯（54条後段）／併合罪（45条）のどれかを一文で。同一物への継続占有のように一方が他方に随伴するなら包括一罪。
- 【まぎらわしい選択肢・論点】具体的事実の錯誤／因果関係の錯誤
- 【まぎらわしい選択肢・結論】覚せい剤譲受け・所持罪 成立／無罪
- 【まぎらわしい選択肢・規範】抽象的符合説／具体的符合説
- 【まぎらわしい選択肢・事実】殺意の認容／先行行為の有無

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

覚せい剤罪＝客観は譲受け・所持に該当するが、麻薬と誤認＝故意なし、38条2項で重い罪は処断不可→不成立。麻薬罪（錯誤）＝認識と実現が別構成要件＝抽象的事実の錯誤、保護法益（規制薬物からの社会防衛）＋行為態様（譲受け・所持）が共通で実質的に重なり合う→軽い麻薬罪が成立。罪数＝譲受け罪と所持罪は同一物の継続占有で包括一罪。

## 3. 規範クイズ（全2問・1問目から最後まで全部出す）

- **［規範クイズ 1/2］** 「重い覚せい剤罪の故意阻却」の規範を一文で言うと？
  - 模範解答：故意（38条1項）＝構成要件該当事実の認識・認容。軽い罪の認識で重い罪を実現したときは、重い罪では処断できない（38条2項）。
- **［規範クイズ 2/2］** 法定的符合説の規範を一文で言うと？
  - 模範解答：異なる構成要件にまたがる錯誤でも、①保護法益の共通性＋②行為態様の共通性から構成要件が実質的に重なり合う限度で、軽い罪の故意犯が成立する（最決昭61.6.9）。

## 4. ○×クイズ（全14問・1問目から最後まで全部出す）

- **［○×クイズ 1/14］** 「甲の罪責を論ぜよ」と本人だけを問う問題でも、物を売り渡した相手方の罪責まで必ず論じなければならない。
  - 正解：×（誤り）
  - 理由：問われた主体（本人）だけを論じる。問題が指定していない相手方は対象外として切ってよい（書くと時間ロス）。
- **［○×クイズ 2/14］** 認識した事実と実現した事実が食い違う錯誤は、両者が同一の構成要件の範囲内でズレているものを「抽象的事実の錯誤」という。
  - 正解：×（誤り）
  - 理由：逆。同一構成要件内のズレ（人違い等）が具体的事実の錯誤、異なる構成要件にまたがるズレが抽象的事実の錯誤。客観と主観を分けたら、次はこの区別でどちらの錯誤類型かを確定する。
- **［○×クイズ 3/14］** 行為者が認識した罪と客観的に実現した罪とが「別の構成要件」にまたがる食い違いを、抽象的事実の錯誤という。
  - 正解：○（正しい）
  - 理由：同一構成要件内のズレ（人違い等）が具体的事実の錯誤、異なる構成要件にまたがるズレが抽象的事実の錯誤。本問は覚せい剤罪⇔麻薬罪で後者。
- **［○×クイズ 4/14］** 規制薬物Pを買うつもりで受け取った包みが、実は別の規制薬物Qだった。実現したのは客観的にQなので、検討すべきはQの罪だけで足りる。
  - 正解：×（誤り）
  - 理由：客観のQ罪は故意（Qの認識）を欠きうる。認識したP罪も検討対象。両方を立て、錯誤論でどちらが成立するかを処理する。
- **［○×クイズ 5/14］** 刑法38条2項は、重い罪に当たる事実を認識して軽い罪を実現した場合にも、軽い罪の限度でしか処断できないという趣旨の規定である。
  - 正解：×（誤り）
  - 理由：38条2項が直接規律するのは「軽い罪の認識で重い罪を実現」した場合＝重い罪では処断できない、という一方向だけ。逆向き（重い認識で軽い実現）は同項の射程外で、別の処理になる。この一方向性ゆえ、実現した重い罪が先に落ち→軽い罪を拾う流れが論理的に整う。
- **［○×クイズ 6/14］** 故意（38条1項）とは、構成要件に該当する客観的事実の認識・認容をいう。
  - 正解：○（正しい）
  - 理由：故意＝構成要件該当事実の認識・認容。覚せい剤の認識がない以上、覚せい剤罪の故意はこの定義から否定される。
- **［○×クイズ 7/14］** 軽い罪に当たる事実を認識しながら、客観的には重い罪を実現した場合、その重い罪によって処断することはできない（38条2項）。
  - 正解：○（正しい）
  - 理由：38条2項の帰結。麻薬（軽）の認識で覚せい剤（重）を実現したXは、重い覚せい剤罪では処断できない。
- **［○×クイズ 8/14］** 客観的構成要件に該当する事実が存在すれば、行為者がその事実を認識していなくても、その罪の故意犯が成立する。
  - 正解：×（誤り）
  - 理由：故意犯には客観的事実の認識が必要。客観該当だけでは足りず、認識を欠けばその罪の故意犯は成立しない（過失犯の余地は別論）。
- **［○×クイズ 9/14］** 認識した罪と実現した罪が異なる構成要件にまたがる場合、両罪は別物だから、軽い罪の故意犯もおよそ成立しえない。
  - 正解：×（誤り）
  - 理由：構成要件が実質的に重なり合う限度では、軽い罪の故意犯の成立を認めるのが判例・通説（法定的符合説）。一律に否定はしない。
- **［○×クイズ 10/14］** 軽い罪に当たると誤信して客観的に重い罪を実現した者には、重い罪の故意が欠け、38条2項により重い罪では処断できない。
  - 正解：○（正しい）
  - 理由：重い罪の故意阻却＋38条2項の帰結。これが「重い罪を落とす」段階の規範。
- **［○×クイズ 11/14］** 法定的符合説では、異なる構成要件間の錯誤でも、構成要件が実質的に重なり合う限度で軽い罪の故意犯の成立を認める。
  - 正解：○（正しい）
  - 理由：判例・通説の運用。重なり合う限度＝軽い罪の範囲で故意犯が成立する。
- **［○×クイズ 12/14］** 構成要件の「実質的な重なり合い」は、①両罪の保護法益の共通性と②行為態様の共通性を基準に判断する。
  - 正解：○（正しい）
  - 理由：保護法益＋行為態様の共通性が重なり合いの2本柱。本問は「規制薬物からの社会防衛」という法益と「譲受け・所持」という態様が共通。
- **［○×クイズ 13/14］** 実質的に重なり合う場合、認識していた軽い罪ではなく、客観的に実現した重い罪の故意犯が成立する。
  - 正解：×（誤り）
  - 理由：成立するのは軽い罪の故意犯。重い罪は故意を欠くので、重なり合う＝軽い罪の限度でしか故意犯は成立しない。
- **［○×クイズ 14/14］** 複数の犯罪が成立しうる場合でも、保護法益が同一で、一方の行為が他方に通常随伴する関係にあるときは、両者を包括一罪として処断しうる。
  - 正解：○（正しい）
  - 理由：包括一罪の判断軸は①保護法益の同一性＋②行為の随伴性（一方が他方に通常伴う）。譲受けに後続所持が通常随伴し法益も一体だから包括一罪、という結論はこの一般基準の当てはめ。
