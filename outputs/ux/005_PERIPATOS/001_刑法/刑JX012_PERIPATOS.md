### 問題文（最初にゆっくり読み上げる）

甲（50歳、男）は、マンションの2階の一室に居住している者であるが、仕事から帰宅してマンションの通路から自室へ入室しようとしたところ、日ごろから折り合いが悪かったA（56歳、男）に、突然、背後から鉄パイプで頭部を1回殴打された。甲は、続けて鉄パイプを振りかぶったAに対し、それを取り上げようとしてつかみ掛かり、大声で助けを求めたが、誰も現れなかった。Aから鉄パイプを取り上げた甲は、Aが手を前に出して向かってきたため、その頭部を鉄パイプで1回殴打した。これに対して、Aがひるまずに向かってきたため、甲及びAは、もみ合いになって、Aが、甲から鉄パイプを取り戻し、それを振り上げて甲を殴打しようとしたため、甲は、1階に通じる階段の方へ向かって逃げ出した。甲が階段上の踊り場まで至った際、背後を振り返ったところ、Aは、甲を追いかけた挙句、通路末端に設置されていた転落防止用の手すりの外側に勢い余って上半身を前のめりに乗り出し、足を浮かせた姿勢になっていた。しかし、Aがなおも鉄パイプを手に握っているのを見て、甲は、Aの攻撃から逃れるため、Aに近づいてその左足を持ち上げ、Aを手すりの外側に追い落とした。その結果、Aは、手すり上端から約4メートル下のコンクリート道路上に転落した。甲の一連の暴行により、Aは、全治約3か月間を要する頭頂部打撲挫創、第2腰椎圧迫骨折等の傷害を負った。甲の罪責について、論じなさい。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- Aが背後から鉄パイプで甲の頭部を1回殴打（先制）

- Aがなお鉄パイプを握る→甲が左足を持ち上げ追い落とす
- Aは約4m下へ転落／全治約3か月の傷害・死亡なし

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「なおも鉄パイプを手に握っている」 → → 攻撃手段を保持＝再攻撃の徴表
- 【拾う事実】「手すりの外側に…足を浮かせた姿勢」 → → 直ちには攻撃できない外観／態勢回復は可能
- 【拾う事実】「約4メートル下のコンクリート道路上に転落」 → → 危険性の評価（過剰の決め手）
- 【拾う事実】「Aの攻撃から逃れるため」 → → 主観の連続（動機の同一性）
- 【拾う事実】『甲A「いずれも男・同年代」「誰も現れなかった」』 → → 力量対等・他に手段なし（殴打の相当性）
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 殴打＝暴行罪・転落＝傷害罪の構成要件該当性／殺人未遂＝殺意なしで一言否定／責任＝阻却事由なし。本問は違法性（正当防衛）にチェックポイントが集中する。
- 【規範の要点】侵害の終了時期の規範
  - 「急迫」＝侵害が現に存在し又は間近に押し迫っていること。終了時期は、既に侵害を受けている点に鑑み始期より緩やかに判断し、加害の意欲・再度の攻撃の可能性等から「侵害を加えられるおそれが継続するか」で決する。
- 【効く事実】「侵害の継続性（終了時期）」のあてはめで使う事実
  - 継続性 → なお鉄パイプを握っていた（加害意欲おう盛・強固）／態勢を立て直し追い付いて再攻撃が可能（再攻撃の可能性）。「攻撃できない外観」だけで終了と即断しないのが核心。
- 【効く事実】「相当性を行為ごとに評価」のあてはめで使う事実
  - 殴打＝相当 → 甲A同年代・同等の力量／助けを求めたが誰も来ず他に手段なし。転落＝過剰 → Aの攻撃力は減弱／約4m下のコンクリートへ追い落とし＝一歩間違えば死亡しかねない危険。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 相当な行為と過剰な行為が連続したら、別々に評価して終わりにせず「全体で1個の防衛行為と見られないか」を一言で架ける。決め手は時間的・場所的接着性＋侵害の継続性＋防衛の意思の連続性。束ねられれば全体が1個の過剰防衛（36条2項）になる。
- 【まぎらわしい選択肢・論点】誤想過剰防衛／侵害は転落時に終了
- 【まぎらわしい選択肢・結論】正当防衛成立で無罪／傷害致死罪 成立／必要的減免（しなければならない）
- 【まぎらわしい選択肢・規範】厳格な法益の権衡が必要／終了時期も始期と同一基準
- 【まぎらわしい選択肢・事実】甲に積極的加害意思あり／Aは既に武器を手放していた

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

構成要件＝殴打→暴行罪、転落（3か月）→傷害罪、殺意なしで殺人未遂否定。正当防衛＝殴打時は侵害あり／転落時は「なお凶器保持・態勢回復可能」で継続性肯定、防衛の意思○、相当性は殴打＝相当・転落（4m死亡の危険）＝過剰。一体性＝接着・継続・意思連続で全体を1個の過剰防衛。結論＝傷害罪・36条2項で任意的減免。

## 3. 規範クイズ（2問）

- **Q04［規範］** 侵害の「継続性（終了時期）」を判断する際に考慮すべき2つの中心事情を挙げよ。
  - 模範解答：①攻撃者の加害の意欲の強度、②再度の攻撃の可能性。この2点を諸事情と総合して「侵害を加えられるおそれの継続」を判断する（最判平9.6.16）。
- **Q05［規範］** 複数の防衛行為を「1個の過剰防衛」として一体評価するための考慮要素を挙げよ。
  - 模範解答：①各行為の時間的・場所的接着性（前提）、②侵害の継続性、③防衛の意思の連続性。客観面・主観面を踏まえた総合判断。

## 4. ○×クイズ（11問）

- **Q06［○×］** 数個の動作が併存しても、犯罪の個数（罪数）は常に動作の数で決まり、社会通念上一個と評価できるかどうかは問題とならない。
  - 正解：×（誤り）
  - 理由：罪数は動作の物理的個数ではなく、構成要件的評価（保護法益・故意の個数・社会的見解）で決する。だから複数の動作を分節して各々評価したうえで、最後に包括一罪・一個の行為と束ねられるかを別途検討する。
- **Q07［○×］** 人を約4メートルの高さから転落させ重傷を負わせれば、それだけで当然に殺人未遂罪の検討に進むべきだ。
  - 正解：×（誤り）
  - 理由：結果が重大でも、殺意（死亡結果の認識・認容）と殺人の実行行為性が無ければ殺人未遂は成立しない。本問は殺意を認め難く、傷害罪で処理する。
- **Q08［○×］** 暴行を加えたが傷害結果が生じなかった行為は暴行罪、傷害結果が生じた行為は傷害罪、と結果の有無で罪名を振り分けるのが基本である。
  - 正解：○（正しい）
  - 理由：傷害罪は暴行罪の結果的加重類型。生じた結果（傷害の有無）で204条／208条を割り当てるのが出発点。
- **Q09［○×］** 急迫不正の侵害が終了した後もなお反撃を続けた場合に成立しうる過剰防衛を「質的過剰」といい、防衛手段が相当性の程度を超えた場合を「量的過剰」という。
  - 正解：×（誤り）
  - 理由：呼称が逆。侵害終了後も反撃を継続したものが量的過剰、相当性の程度（強度）を超えた防衛行為が質的過剰。複数行為を一体評価して過剰防衛とするのは量的過剰の問題である。
- **Q10［○×］** 過剰防衛（36条2項）の刑が必要的減免ではなく任意的減免にとどまるのは、過剰な反撃に出た行為者の恐怖・驚愕・興奮等による責任の減少を考慮する趣旨に基づく。
  - 正解：○（正しい）
  - 理由：過剰防衛の減免根拠は、急迫の事態での心理的動揺による責任減少（＋違法減少）に求められる。減免はあくまで「できる」＝任意的であり、心理的動揺の程度等を踏まえ裁量で決する点が必要的減免の中止犯（43条但書）と異なる。
- **Q11［○×］** 正当防衛（36条1項）の要件は、①急迫不正の侵害 ②防衛の意思（「防衛するため」）③やむを得ずにした行為（相当性）である。
  - 正解：○（正しい）
  - 理由：この3要件が骨格。本問は①の「継続性（終了時期）」と③の「相当性」に論点が集中する。
- **Q12［○×］** 将来侵害があることを予期していたというだけで、その侵害の「急迫性」は当然に失われる。
  - 正解：×（誤り）
  - 理由：侵害を予期していたとしても、それだけで急迫性は失われない。もっとも、その機会を利用し積極的に相手に加害する意思（積極的加害意思）で侵害に臨んだときは、急迫性を欠く。「急迫」は単なる時間的切迫の有無では決まらない。
- **Q13［○×］** 攻撃者が一時的に攻撃できない外観（体勢を崩した等）になれば、それだけで急迫不正の侵害は終了したと評価してよい。
  - 正解：×（誤り）
  - 理由：外観だけで終了と即断するのが最大の失点。なお凶器を握る・態勢回復が可能等、加害意欲と再攻撃の可能性を総合して継続性を判断する。
- **Q14［○×］** 正当防衛の相当性（「やむを得ずにした行為」）は、その反撃が侵害を避ける唯一の方法であったことを要する。
  - 正解：×（誤り）
  - 理由：正対不正の関係ゆえ、唯一の回避方法であることも厳格な法益権衡も不要。防衛手段として社会的に相当であればよい（緊急避難の「やむを得ず」と区別）。
- **Q15［○×］** 防衛行為の相当性は、武器対等の原則を基本としつつ、当事者の性別・年齢・体格等を考慮し、結果的に過剰な結果が生じても認められうる。
  - 正解：○（正しい）
  - 理由：相当性は「行為」の評価で、結果の過剰とは別。ただし約4m転落のように死亡の危険を伴う行為自体が過剰なら相当性を欠く。
- **Q16［○×］** 時間的・場所的に接着し、同一の侵害に対し防衛の意思が連続している複数の防衛行為は、全体を1個の行為として過剰防衛と評価しうる。
  - 正解：○（正しい）
  - 理由：接着性・侵害の継続性・防衛の意思の連続性を踏まえた総合判断で一体評価できる（量的過剰）。本問はこれを満たす。
