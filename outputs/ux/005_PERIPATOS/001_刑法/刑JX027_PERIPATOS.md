## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

甲、乙及び丙は、同じ建築会社に勤める建築作業員であり、2階建ての家を建築中であった。この建築に当たっては、一番のベテランである甲が現場監督を務め、その指示に従って乙及び丙が作業を進めていた。乙は中堅社員で建築の全般的な作業を担当していたが、丙はまだ建築作業員になって日が浅く、木材を運ぶなどの補助的な作業しかしていなかった。作業も終盤のある日、乙が甲の指示で2階部分に登って瓦を葺き、丙は甲の指示で瓦を2階部分へ運んでいた。乙は、自己の不注意で、丙が運んで積み上げられていた瓦を路上へ落下させ、通行人Aが全治1か月の怪我を負った。なお、瓦は、乙が注意を払って取り扱っていれば落下等の危険のない状態で積み上げられていた。甲、乙及び丙の罪責について、論じなさい。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 甲・乙・丙が同じ建築会社で2階建てを建築中
- 甲が現場監督・その指示で乙が2階で瓦葺き／丙が瓦を運搬
- 乙が自己の不注意で積み上げた瓦を路上へ落下
- 通行人Aが全治1か月の怪我を負う
- （瓦は乙が注意していれば落下の危険のない状態だった）

### 参考（読み上げない。入口の問いの答えを含むので判定にだけ使う）

登場人物：
- 甲｜現場監督・ベテラン（→指示・自ら瓦は落としていない）
- 乙｜中堅・直接行為者（→不注意で瓦を落下）
- 丙｜新人・補助作業（→瓦を運び積上げ）
- A｜通行人・全治1か月＝被害者＝対象外

### 入口の問い（3問）

- **Q01［事案の整理］** 登場人物と「引っかかる行為」を挙げて
  - 答え：行為をしたのは甲（現場監督・指示）・乙（瓦を落とした直接行為者）・丙（瓦の運搬・補助）の3人。A＝被害者は対象外。
  - 答え：地位の差をメモ：甲＝ベテラン現場監督／乙＝中堅・全般作業／丙＝新人・補助作業のみ。この差が「共同の注意義務」の有無を分ける。
- **Q02［見当づけ］** 各行為は「何罪っぽい？」 ― 見当をつけて
  - 答え：乙：「自己の不注意で」瓦を落とし通行人を負傷＝過失＋建築会社の作業員（業務） → 業務上過失致傷罪（211条前段）。甲：自分は落としていないが乙を指示・監督 → 過失の共同正犯（60条）か監督過失の単独犯を疑う。丙：補助作業のみ → 帰責できるか要検討。
- **Q03［論点］** 甲・丙で問題になる論点を挙げて（3つ）
  - 答え：CP①：乙の過失をどう立てるか → 過失犯の構造。（新過失論＝結果の予見可能性を前提とする結果回避義務違反）
  - 答え：CP②：甲は自分で落としていない → 過失犯に共同正犯が成立するか。（成立を認める通説＝共同義務の共同違反説）
  - 答え：CP③：甲は肯定・丙は否定 → 共同の注意義務に共同して違反したか。（地位・役割の共通性で振り分ける）

### 骨子（3項目。第1から【論点】ごとに、何が問題→規範→使う事実→結論 の順で組み立てる）

#### 第1　乙の罪責（業務上過失致傷罪・211前段）＝土台・簡潔に

1. 「業務」＝建築会社の作業員（社会生活上の地位＋反復継続＋危害のおそれ）→ 一行該当
2. 【論点】過失の構造 → 規範：結果回避義務違反（新過失論）
   - あてはめ：予見可能性○／注意すれば落下の危険なし＝結果回避可能性○／不注意で落下＝義務違反○
3. 全治1か月の傷害／落下と負傷に相当因果関係○
- 結論：業務上過失致傷罪 成立（後述・甲と共同正犯）

#### 第2　甲の罪責（業務上過失致傷罪の共同正犯・60条・211前段）＝最厚め・山場

1. 結果は甲自身の行為によらない → 【論点】過失犯に共同正犯が成立するか
   - あてはめ：規範：共同の注意義務に共同して違反すれば「共同して犯罪を実行」（60条）＝成立（最決平28.7.12）
2. 【論点】共同の注意義務に共同して違反したか
   - あてはめ：判断軸＝地位・立場・役割・要求される行為の共通性
   - あてはめ：同じ建築会社・共同して建築・甲の指示・現場監督 → 危険を共同防止すべき関係○ → 共同違反○
3. 補論：現場監督ゆえ監督過失の単独犯構成も可（一言）
- 結論：業務上過失致傷罪の共同正犯 成立

#### 第3　丙の罪責（不可罰）＝甲と逆向き・二段で簡潔に

1. 共同義務の否定 → 日が浅く補助作業のみ＝危険を共同防止すべき関係なし → 共同正犯不成立
2. 単独過失の否定 → 瓦は乙が注意すれば落下の危険なし＝丙の注意義務違反なし → 単独犯不成立
- 結論：丙は罪責を負わない

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】『「自己の不注意で」落下させ』 → 乙の主観（不注意のサイン）
- 【拾う事実】「注意を払っていれば落下等の危険のない状態」 → 落とさずに済んだ状況
- 【拾う事実】『一番のベテラン・現場監督・甲の指示』 → 甲の立場と関与
- 【拾う事実】『同じ建築会社・共同して建築』 → 3人の関係の近さ
- 【拾う事実】『日が浅い・補助的な作業しかしていない』 → 丙だけ立場が違う
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 乙：業務性＝建築作業員で一行／結果＝全治1か月の傷害／因果＝落下と負傷に相当因果関係あり／違法性・責任＝阻却事由なし＝一言で素通り。
- 【規範の要点】「乙の過失・甲の共同正犯」の規範
  - 過失犯の実行行為は結果回避義務（注意義務）違反にあり、複数人が共同の注意義務に共同して違反した場合は「共同して犯罪を実行した」（60条）として過失の共同正犯が成立する。共同義務の有無は地位・立場・分担役割・要求される行為の共通性で判断する（最決平28.7.12）。
- 【効く事実】「乙の過失・甲の共同正犯」のあてはめで使う事実
  - 乙の過失 → 「自己の不注意で」落下＋「注意すれば落下の危険のない状態」（＝結果回避可能性）を直接引用。甲の共同義務 → 同じ建築会社・共同して建築・甲の指示・現場監督＝乙の作業上の危険を共同して防止すべき関係。
- 【効く事実】丙で効く事実（否定の決め手）
  - 共同義務の否定 → 「日が浅く、木材を運ぶなどの補助的な作業しかしていない」＝乙の作業上の危険を共同して防止すべき関係まではない。単独過失の否定 → 「瓦は乙が注意すれば落下の危険のない状態」＝丙が積み上げる際の注意義務違反はない。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 監督的立場の者は、過失の共同正犯のほかに自己の監督義務違反による単独の過失犯（監督過失）でも構成できる。ただし答案では本筋（共同正犯）を厚く書き、監督過失は「単独犯としても構成しうる」と一言添える程度でよい。
- 【まぎらわしい選択肢・論点】共謀共同正犯の成否／因果関係の中断
- 【まぎらわしい選択肢・結論】業務上過失致死罪 成立
- 【まぎらわしい選択肢・規範】危惧感説（新々過失論）
- 【まぎらわしい選択肢・事実】殺意あり／先行行為あり

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

乙＝建築作業員＝「業務」、不注意で瓦落下＝結果回避義務違反で業務上過失致傷（211前段）。甲＝過失犯に共同正犯成立可（共同の注意義務に共同違反説）→ 同一作業・現場監督で共同義務○ → 共同正犯成立（監督過失の単独構成も一言）。丙＝日が浅く補助作業のみ＝共同義務なし、瓦は乙が注意すれば危険なし＝固有過失なし → 不可罰。

## 3. 規範クイズ（3問）

- **Q04［規範］** 業務上過失致傷罪の「業務」の意義を構成する三要素を挙げよ。
  - 模範解答：①社会生活上の地位に基づき ②反復継続して行う行為で ③他人の生命・身体等に危害を加えるおそれのあるもの。営利性・適法性は要件でない（最判昭33.4.18）。
- **Q05［規範］** 過失の共同正犯が成立するための2つの要件（共同義務の共同違反説）を挙げよ。
  - 模範解答：①各人が「共同の注意義務」を負い ②これに「共同して違反した」と認められること。これが過失の共同正犯の核心規範。
- **Q06［規範］** 「共同の注意義務」の有無を判断する際に考慮する要素を挙げよ（最決平28.7.12）。
  - 模範解答：共同行為者の地位・立場、分担する役割、結果回避のために要求され得る行為の共通性。役割・地位の共通性が判断軸。同じ作業を共同遂行し役割が一体的なら肯定しやすい（明石決定はこの共通性を欠くとして否定）。

## 4. ○×クイズ（9問）

- **Q07［○×］** 信頼の原則とは、行為者が他人の適切な行動を信頼するのが相当な場合には、その他人の不適切な行動から生じた結果について過失責任を負わないとする法理である。
  - 正解：○（正しい）
  - 理由：複数人が分担して作業する場面で過失（結果回避義務）の範囲を画する道具概念。各人の地位・役割が異なるほど「相手を信頼してよい範囲」が広がり、結果回避義務＝過失が否定されやすくなる。共同正犯の可否とは別軸の検討。
- **Q08［○×］** 事案に「殺意」「故意」を示す文言がなく、「不注意で」結果を生じさせた場合は、まず過失犯の成否を検討するのが筋である。
  - 正解：○（正しい）
  - 理由：主観の文言（故意の有無）が罪名を分ける。「不注意」は過失のサイン。結果の重さだけで故意犯と決めない。
- **Q09［○×］** 会社の業務として反復継続する作業中に、不注意で他人を負傷させた場合、単純過失傷害ではなく業務上過失致傷罪の成否をまず検討する。
  - 正解：○（正しい）
  - 理由：業務上過失致傷罪（211条前段）は過失傷害罪（209条）の業務性による加重類型。業務該当性を見落とすと条文選択を誤る。
- **Q10［○×］** 過失の共同正犯を肯定する立場（共同義務の共同違反説）でも、各共同者の処罰は、現実に結果を発生させた直接行為者一人の過失行為がそのまま他の者に帰責されるという仕組みで説明される。
  - 正解：×（誤り）
  - 理由：共同義務の共同違反説は、各人が自ら「共同の注意義務」を負い、これに「共同して違反」した点に各人の実行行為性を見いだす。直接行為者一人の過失を借りてくるのではなく、各人固有の義務違反が処罰根拠＝だから補助的役割の者は義務を欠けば共同正犯から外れる。
- **Q11［○×］** 過失犯では、結果が発生しさえすれば、予見可能性や結果回避義務違反を論じなくても過失が認められる。
  - 正解：×（誤り）
  - 理由：新過失論では過失＝結果の予見可能性を前提とする結果回避義務違反。結果発生だけで過失を認めると処罰範囲が広がりすぎる。規範を立ててから当てはめる。
- **Q12［○×］** 過失犯は無意識的犯罪であるから、複数人が過失犯の共同正犯を負うことはおよそ理論上ありえない。
  - 正解：×（誤り）
  - 理由：過失犯の実行行為を結果回避義務（注意義務）違反に求めれば、複数人が共同の注意義務を負いこれに共同して違反することは可能。判例も一定の場合に肯定する（最決平28.7.12）。
- **Q13［○×］** 同じ共同作業者でも、地位・分担役割が補助的にとどまる者には、共同の注意義務を否定して共同正犯を不成立とする余地がある。
  - 正解：○（正しい）
  - 理由：共同義務は地位・役割の共通性で決まる。補助作業のみの者は危険を共同防止すべき関係を欠き、共同正犯にならないことがある。
- **Q14［○×］** 共同正犯が否定された者でも、自己固有の注意義務違反（単独の過失）があれば単独犯として処罰されうるので、その有無も検討する。
  - 正解：○（正しい）
  - 理由：共同義務の否定で終わらせず、単独過失の有無も二段目として検討する。本問の丙は固有過失もなく不可罰。
- **Q15［○×］** 直接行為者を監督する立場の者は、過失の共同正犯のほか、自己の監督義務違反による単独の過失犯（監督過失）として構成できる場合がある。
  - 正解：○（正しい）
  - 理由：現場監督等の管理的地位にある者には監督過失の単独構成もありうる。
