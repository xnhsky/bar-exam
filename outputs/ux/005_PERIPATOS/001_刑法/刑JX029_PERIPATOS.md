(1)　甲は、Aから自殺しようとしていることを打ち明けられ、協力するよう頼まれた。甲は、Aの決意が固いことから、これを承諾し、1錠飲めば苦しむことなく死ねる毒薬を用意し、Aに交付した。Aは、これを受け取った日の夜、自宅で毒薬を飲もうとコップに水を汲んだが、やはり死ぬのは恐いと思い直し、結局、毒薬を飲むことはなかった。(2)　乙は、B宅で2人で飲酒中、Bから「生きていても仕方がない。昨日、自殺しようとしたが自分ではできなかった。」と打ち明けられた。乙は、自分がBを殺すようお願いされていると思い込み、Bが寝たところを包丁で刺殺した。しかしBは、乙に殺害して欲しいとは思っていなかった。(3)　丙は、友人Cと仲たがいし殺してやろうと考え、待ち伏せして予め用意したピストルでCを射殺した。しかしCは会社倒産から死にたいと思い、丙に自分を殺すよう依頼するメールを送っていたが、丙はこのメールに気付いていなかった。甲、乙及び丙の罪責について論じなさい。

4. 【論点】実行の着手時期 → 規範：幇助行為こそ実行行為 → その開始（毒薬交付）に着手

- 【拾う事実】「決意が固い」「飲むことはなかった」 → 甲＝真意の自殺意思／結果不発生

- 【争いのない要件】論点にならず、あっさり認定する要件

- 【効く事実】乙で効く事実・評価

- 【まぎらわしい選択肢・論点】正当防衛の成否／因果関係の有無／共謀共同正犯の成否

- 【まぎらわしい選択肢・事実】先行行為／殺意あり

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

甲(1)＝Aの自殺意思は真意＝自殺幇助／自殺関与罪は独立の犯罪類型・幇助行為こそ実行行為＝毒薬交付で着手／Aは飲まず結果不発生 → 自殺幇助罪の未遂（203条・202条前段）成立。乙(2)＝客観は殺人・主観は嘱託殺人（嘱託を誤信）＝軽い意思で重い結果 → 38条2項で重い殺人は処断不可／法定的符合説で殺人と嘱託殺人は法条関係＝重なり合い → 嘱託殺人罪（202後段）成立。丙(3)＝客観は嘱託殺人（Cの嘱託メール）・主観は殺人（不知）＝重い意思で軽い結果 → 殺人は意思に反する客観的危険なしで実行行為性否定／(2)と同様に重なり合い → 嘱託殺人罪（202後段）成立。

## 3. 規範クイズ（3問）

- **Q04［規範］** 生命に対する罪（自殺関与罪・同意殺人罪・普通殺人罪）を仕分ける2つの軸を挙げよ。
  - 模範解答：①誰が死をもたらすか（本人＝自殺関与／行為者＝同意殺人・普通殺人）／②真意の同意・嘱託の有無（あり＝202条／なし＝199条）。この2軸で罪名を仕分ける。
- **Q05［規範］** 軽い罪を犯す意思で重い罪に当たる事実を実現した場合（乙の型）の、38条2項の帰結と次に検討すべきことを述べよ。
  - 模範解答：重い罪の故意を欠く以上、責任主義から重い罪では処断できない（38条2項）。次に、軽い罪の限度で故意を問えるかを抽象的事実の錯誤（法定的符合説）として検討する。
- **Q06［規範］** 重い意思（殺人）で軽い結果（嘱託殺人）を実現した逆パターン（丙の型）の、処理手順を順に述べよ。
  - 模範解答：①38条2項の場面ではない（軽い結果なので重い罪での処断制限は問題にならない）。②まず重い罪（普通殺人）の客観的危険性の不存在から実行行為性を否定し、殺人はおよそ不成立とする。③次に抽象的事実の錯誤として、法条関係＋重なり合いで軽い嘱託殺人の限度の故意を認める。

## 4. ○×クイズ（15問）

- **Q07［○×］** 被害者の同意（承諾）が違法性阻却ないし減軽の効果を持つには、その同意が被害者の真意に基づく自由かつ有効なものであることを要する。
  - 正解：○（正しい）
  - 理由：同意は被害者の処分しうる利益について、真意・自由・有効でなければ効力を生じない。生命は本来処分できないため、嘱託・承諾があっても違法性は阻却されず、減軽類型（同意殺人罪202条後段）にとどまる。同意の真意性・有効性をまず吟味するのが承諾事案の出発点。
- **Q08［○×］** 生命に対する罪の事案では、各行為につき「行為者が客観的に実現した事実」と「行為者が認識していた事実」を分けて拾うと、錯誤の処理に進みやすい。
  - 正解：○（正しい）
  - 理由：客観（発生事実）と主観（認識事実）を分けて把握することが、錯誤論（38条2項・抽象的事実の錯誤）の出発点になる。
- **Q09［○×］** 被害者の真意による嘱託（殺害の依頼）がある場合でも、行為者が他人を殺害した以上、まず普通殺人罪（199条）だけを検討すれば足りる。
  - 正解：×（誤り）
  - 理由：真意の嘱託があれば客観面は嘱託殺人罪（202条後段）に当たる。199条で済ませると罪名選択を誤る。嘱託・承諾の有無で202条後段か199条かを切り分ける。
- **Q10［○×］** 嘱託・承諾殺人罪（202条後段）が普通殺人罪（199条）より軽く処罰されるのは、被害者の同意により生命侵害という結果無価値そのものが消滅するからである。
  - 正解：×（誤り）
  - 理由：生命は被害者が自由に処分できる利益ではなく、同意があっても生命侵害の結果無価値は消えない。減軽の根拠は、被害者の意思に反しない点で違法性（行為無価値・意思侵害の要素）が減少することにある。だから違法性阻却まではされず、202条後段の独立の減軽類型にとどまる。
- **Q11［○×］** 202条は、前段が同意殺人罪（嘱託殺人・承諾殺人）、後段が自殺関与罪（自殺教唆・自殺幇助）を定めている。
  - 正解：×（誤り）
  - 理由：前段・後段が逆。前段＝自殺関与罪（教唆・幇助＝死をもたらす最終行為を本人が行う型への関与）、後段＝同意殺人罪（嘱託・承諾を得て行為者が直接手を下す型）。
- **Q12［○×］** 自殺は自己の生命に関する自己決定権の表れであり違法性が阻却されるから、自殺関与罪は違法な正犯への加担を処罰する共犯の特別類型ではなく、独立の犯罪類型であると解する立場がある。
  - 正解：○（正しい）
  - 理由：これが独立犯罪類型説の核心。自殺が違法でない以上、共犯の特別類型と捉える前提に難があり、生命への干渉として独自に処罰する独立の犯罪類型と解する。
- **Q13［○×］** 自殺関与罪が成立するには、自殺者の自殺意思が真意かつ自由な意思に基づくことを要する。
  - 正解：○（正しい）
  - 理由：真意・自由な自殺意思があってはじめて自殺関与（202条前段）にとどまる。欺罔等で意思の自由が害されていれば殺人罪の間接正犯となりうる。
- **Q14［○×］** 自殺関与罪を独立の犯罪類型と解する立場からは、幇助行為こそが実行行為であるから、実行の着手は幇助行為の開始時点に認められる。
  - 正解：○（正しい）
  - 理由：性質決定（独立犯罪類型）と着手時期（幇助行為開始）は連動する。これに対し共犯の特別類型説からは正犯たる自殺者の自殺行為の開始に着手を求めることになる。
- **Q15［○×］** 自殺関与罪の未遂は処罰されないから、自殺者が死亡しなかった場合は関与者の罪責を問えない。
  - 正解：×（誤り）
  - 理由：202条の罪の未遂は203条で処罰される。着手が認められれば、自殺者が死ななくても未遂が成立しうる。「未遂は不可罰」とするのは誤り。
- **Q16［○×］** 行為者が「自分も後を追って死ぬ」と偽り、これを信じた相手を欺いて自殺させた偽装心中の場合は、被害者の自殺意思の自由が害されているため、自殺関与罪ではなく殺人罪の間接正犯となりうる。
  - 正解：○（正しい）
  - 理由：最判昭33.11.21の射程。自殺意思が真意・自由でなければ自殺関与にとどまらず殺人の間接正犯となる。だから自殺意思の真意性の確認が前提になる。
- **Q17［○×］** 法定的符合説によれば、認識した事実と発生した事実が異なる構成要件にまたがる場合でも、両罪の構成要件に実質的な重なり合いが認められる限度で、軽い罪の故意責任を問うことができる。
  - 正解：○（正しい）
  - 理由：故意責任の本質（反対動機形成の可能性への道義的非難）から、構成要件の実質的重なり合いの限度で故意を認める＝法定的符合説。重なり合いは①行為態様②被侵害法益の共通性で判断する。
- **Q18［○×］** 殺人罪（199条）と嘱託殺人罪（202条後段）は、いずれも人の生命を断つ行為であり、被害者の真意の同意の有無で法定刑が異なるにすぎない法条関係にあるから、軽い嘱託殺人罪の限度で構成要件の重なり合いが認められる。
  - 正解：○（正しい）
  - 理由：嘱託殺人は殺人の減軽類型であり、行為態様・被侵害法益（生命）が共通する。よって軽い嘱託殺人の限度で重なり合いが認められる（大判明43.4.28参照）。
- **Q19［○×］** 客観的に被害者の真意の嘱託があった場合、被害者の意思に反して生命を奪うという普通殺人の客観的危険性が存在しないから、普通殺人罪の実行行為性は認められない。
  - 正解：○（正しい）
  - 理由：普通殺人は「意思に反して」生命を奪う罪。真意の嘱託があれば意思に反する危険がなく、普通殺人の実行行為性・危険性を欠く（殺人はおよそ成立しない）。残るのは嘱託殺人の限度の故意。
- **Q20［○×］** 承諾（嘱託）の有無についての客観と主観の食い違いには、「軽い意思で重い結果」と「重い意思で軽い結果」の表裏2類型があり、前者は38条2項が正面から、後者はまず重い罪の実行行為性・危険性の検討が必要になる。
  - 正解：○（正しい）
  - 理由：2類型を区別するのが本問の構造。両方で「法条関係→重なり合い→軽い罪の故意」に帰着するが、入口の処理（38条2項か実行行為性否定か）が異なる。
- **Q21［○×］** 客観的危険性の有無を一般人を基準に判断する立場（具体的危険説）からは、逆パターンの事案で「殺人未遂罪が成立する」という結論もありうる。
  - 正解：○（正しい）
  - 理由：危険性判断の基準の取り方次第で、嘱託殺人説と殺人未遂説に分かれる。いずれでも危険性判断の立場と整合させ一貫していれば高評価（採点講評）。
