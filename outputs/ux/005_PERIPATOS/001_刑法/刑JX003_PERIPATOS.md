## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

甲は乙に対して、報酬を支払うことを約束して、Aを殺すように依頼した。そこで、乙は、ある夜Aを殺そうとして待ち伏せしていたが、まわりが暗かったために、BをAだと思い、ピストルを発射してBを殺してしまった。甲及び乙の罪責を論じなさい。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 甲が乙に報酬を約束してA殺害を依頼
- 乙がAを殺す意思で待ち伏せ
- 暗くて乙がBをAと誤信
- 乙が発射しBを殺害（Aは現れず）

### 参考（読み上げない。入口の問いの答えを含むので判定にだけ使う）

登場人物：
- 甲｜依頼者・背後者（→報酬を約してA殺害を依頼）
- 乙｜実行正犯（→BをAと誤認して射殺）
- A｜狙われた標的・現れず＝対象外
- B｜誤認され殺された被害者＝対象外

### 入口の問い（3問）

- **Q01［事案の整理］** 登場人物と「引っかかる行為」を挙げて
  - 答え：罪責を検討するのは「何か行為をした人」だけ。本問は乙（ピストルでBを射殺＝実行行為）と甲（報酬を約してA殺害を依頼＝背後者）の2人。
  - 答え：A＝狙われたが現れなかった標的・B＝誤認され殺された被害者はいずれも対象外。ここで切るのが第一歩。
- **Q02［見当づけ］** 各行為は「何罪っぽい？」 ― 見当をつけて
  - 答え：乙：ピストルでBを射殺 → 殺人（199条）。甲：自ら撃たず「殺せ」と依頼 → 共犯（教唆 61条1項／共同正犯 60条）系。
- **Q03［論点］** 乙で問題になる論点を挙げて（3つ）
  - 答え：CP①：乙はBをAと誤認 → 認識と現実のズレ → 錯誤が故意を阻却するか。（故意＝罪となる事実の認識。ズレがどこまで許されるか）
  - 答え：CP②：ズレの類型を確定。認識Aの死／結果Bの死＝ともに「人」 → 具体的事実の錯誤（同一構成要件内）。（構成要件をまたぐと抽象的事実の錯誤）
  - 答え：CP③：客体の錯誤か方法の錯誤か。狙った客体そのものに命中 → 客体の錯誤。（方法の錯誤＝狙いを外して別客体に当たった場合）

### 骨子（3項目。第1から【論点】ごとに、何が問題→規範→使う事実→結論 の順で組み立てる）

#### 第1　乙の罪責

- 見出しの補足（結論を含む。項目の終わりに読む）：殺人罪・199条
1. ピストル発射でB殺害 → 客観的構成要件該当（実行行為・結果・因果＝一文で通過）
2. BをAと誤認 → 【論点】錯誤は故意（38条1項）を阻却するか
   ・認識Aの死／結果Bの死＝ともに「人」→ 具体的事実の錯誤
   ・狙った客体に命中 → 客体の錯誤（方法の錯誤ではない）
3. 規範：法定的符合説（法定の範囲内で符合すれば故意）
4. あてはめ：「人を殺す意思」で「人を殺した」＝符合（客体の錯誤ゆえ具体的符合説でも同結論）
- 結論：故意阻却されず ＝ 殺人既遂罪 成立

#### 第2　甲の罪責

- 見出しの補足（結論を含む。項目の終わりに読む）：殺人罪の教唆犯・199条・61条1項
1. 報酬約束してA殺害を依頼／自ら実行せず → 教唆犯で構成（共同正犯も可・結論差なし）
2. ①教唆行為 ②被教唆者乙の実行（既遂）→ 充足
3. 甲の認識Aの死／結果Bの死 → 【論点】共犯と錯誤
   - あてはめ：共犯にも同様の錯誤論（法定的符合説）が及ぶ → 規範は再掲せず接続
4. あてはめ：同一構成要件内で符合 → 故意阻却されず
- 結論：殺人既遂罪の教唆犯 成立

#### 第3　関与形式・共犯

   教唆／共同正犯いずれも可だが結論差なし → 教唆構成（共謀共同正犯を回避・一言）

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「報酬を支払うことを約束して……依頼」 → → 甲の関与態様（手を下していない背後者）
- 【拾う事実】『「BをAだと思い」発射』 → → 認識と現実のズレ＝後で性質決定する核心
- 【拾う事実】「ピストルを発射してBを殺してしまった」 → → 客観面（結果＝B死亡・因果）
- 【拾う事実】「Aを殺そうとして待ち伏せ」 → → 乙の認識対象は「目の前の人物」
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 実行行為＝ピストル発射（人の死の現実的危険）／結果＝B死亡／因果＝発射とB死亡に因果あり／違法性・責任＝阻却事由なし＝一言で素通り。客観面は数行で流し、紙幅は故意（錯誤）に割く。
- 【効く事実】あてはめで使う事実
  - 客体の錯誤の認定 → 「BをAだと思い」発射＝狙った人物そのものに命中／符合の認定 → 「人を殺す意思」で「人を殺した」＝同一構成要件内。さらに客体の錯誤ゆえ具体的符合説からも同結論と一言添えると説の射程理解を示せる。
- 【規範の要点】「共犯と錯誤」の規範
  - 共犯についても単独犯と同様の錯誤論が及ぶ → 前述の法定的符合説により、甲は「人（A）を殺せ」と教唆し「人（B）」が死亡＝同一構成要件内で符合 → 甲の教唆の故意も阻却されない。規範を二度書かないのが論述効率の勝負どころ。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 自ら手を下さない背後者は教唆（61条1項）か共同正犯（60条）かを一言で決める。事実が乏しければ立証負担の軽い教唆で構成（共同正犯にすると共謀＋正犯性＝共謀共同正犯の論点が増える）。
- 【まぎらわしい選択肢・論点】正当防衛の成否／抽象的事実の錯誤
- 【まぎらわしい選択肢・結論】殺人未遂罪 成立／不可罰
- 【まぎらわしい選択肢・規範】具体的符合説／抽象的符合説
- 【まぎらわしい選択肢・事実】方法の錯誤／抽象的事実の錯誤

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

乙＝発射でB殺害（客観○）、BをAと誤認＝客体の錯誤、法定的符合説で「人を殺す意思で人を殺した」＝符合→故意阻却されず→殺人既遂。甲＝報酬約束しA殺害を依頼＝教唆、認識Aの死／結果Bの死＝共犯と錯誤、前述の符合説を接続→故意阻却されず→殺人教唆。関与形式＝教唆／共同正犯いずれも可・結論差なし→教唆で構成。

## 3. 規範クイズ（2問）

- **Q04［規範］** 認識した事実と発生した事実が、同一の構成要件の範囲内で食い違っている錯誤を何と呼ぶか挙げよ（構成要件をまたぐ場合の呼称も）。
  - 模範解答：同一構成要件内＝具体的事実の錯誤／構成要件をまたぐ＝抽象的事実の錯誤。まずどちらかを確定する。
- **Q05［規範］** 判例が採る、認識事実と発生事実が「法定の範囲内（同一構成要件内）」で符合すれば故意を認める立場の名称を挙げよ。対立する有力説の名称も。
  - 模範解答：判例・通説＝法定的符合説（同一構成要件内で符合すれば故意）。対立＝具体的符合説（認識した具体的客体との符合を要求）。

## 4. ○×クイズ（10問）

- **Q06［○×］** 教唆犯（61条1項）が成立するには、人を教唆して「犯罪実行の決意を生じさせ」、被教唆者がその犯罪を実行したことが必要である。
  - 正解：○（正しい）
  - 理由：教唆＝まだ決意していない者に犯罪の決意を生じさせる行為。既に決意した者を後押しするのは幇助。背後者の関与形式を捉える第一の候補で、共同正犯との区別は手6で詰める。
- **Q07［○×］** 「人を殺せ」と依頼された者が、別人を誤って殺した。撃った実行者だけ検討すれば足り、依頼した背後者は当然に不可罰である。
  - 正解：×（誤り）
  - 理由：依頼者も共犯（教唆等）として罪責を負いうる。背後者の錯誤処理（共犯と錯誤）まで検討する必要がある。
- **Q08［○×］** 狭義の共犯（教唆・幇助）の成立には、正犯の行為が構成要件に該当し違法であることを要するが、正犯が責任能力を備え有責であることまでは要しない。
  - 正解：○（正しい）
  - 理由：制限従属性説（通説）。共犯は正犯の違法な実行行為に従属して成立するので、正犯が責任無能力でも教唆は成立しうる。この共犯従属性が「正犯から先に書く」手順の理論的根拠。
- **Q09［○×］** 行為者が狙った客体そのものに結果が生じたが、それが人違いだった場合、これは「方法（打撃）の錯誤」である。
  - 正解：×（誤り）
  - 理由：狙った客体そのものに命中＝客体の錯誤（人違い）。方法の錯誤は狙いを外して別客体に当たった場合。ここの取り違えが本問最大の落とし穴。
- **Q10［○×］** 「方法（打撃）の錯誤」とは、行為者が狙いを外し、認識していなかった別の客体に結果が生じた場合をいう。
  - 正解：○（正しい）
  - 理由：方法の錯誤＝因果経過のズレで別客体に命中。客体の錯誤＝狙った客体に命中したが属性（人違い）を誤認。両者で説の結論が分かれうる。
- **Q11［○×］** 具体的事実の錯誤のうち「客体の錯誤」の事案では、法定的符合説からも具体的符合説からも故意は阻却されない。
  - 正解：○（正しい）
  - 理由：客体の錯誤では狙った客体そのものに結果が生じている＝具体的符合説でも符合する。両説が結論を分けるのは方法の錯誤の場面だけ。
- **Q12［○×］** 具体的符合説に立つと、客体の錯誤の事案でも故意が阻却され、発生事実は過失犯・認識事実は未遂として処理される。
  - 正解：×（誤り）
  - 理由：それは具体的符合説が方法の錯誤で出す帰結。客体の錯誤では具体的符合説でも故意は阻却されない。類型の取り違えがこの誤りを生む。
- **Q13［○×］** 単独犯について発展してきた錯誤論（法定的符合説）は、教唆犯など狭義の共犯にも同様に適用される。
  - 正解：○（正しい）
  - 理由：故意の符合範囲を画する理論だから正犯・共犯を問わず妥当する。これが「共犯と錯誤」の処理の出発点。
- **Q14［○×］** 「人（A）を殺せ」と教唆された正犯が、誤って別の人（B）を殺した。法定的符合説によれば、教唆者の故意も同一構成要件内で符合し阻却されない。
  - 正解：○（正しい）
  - 理由：教唆者の認識（人の死）と発生事実（人の死）が殺人罪の構成要件内で符合 → 殺人既遂罪の教唆犯。正犯の錯誤論をそのまま接続する。
- **Q15［○×］** 背後者を共同正犯とするには、単に犯罪を依頼しただけでは足りず、共謀（意思の連絡）と正犯性（自己の犯罪として重要な役割を果たしたこと）が必要である。
  - 正解：○（正しい）
  - 理由：共謀共同正犯はこの2要件を要する。教唆犯は「他人に犯罪実行の決意を生じさせる」だけで足りる点で異なる。だから事実が乏しい事案では立証負担の軽い教唆で簡潔に構成できる。
