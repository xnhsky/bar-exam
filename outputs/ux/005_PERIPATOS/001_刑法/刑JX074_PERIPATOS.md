#### 第1　甲の罪責

4. 【論点】請託と罪名の確定 → 請託＝依頼の承諾。不正行為未了なら加重に至らない

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「警察法に基づき東京都で職権・つなぎ的関与」 → 甲の権限の手がかり
- 【拾う事実】「分かった、何とかしてみよう」 → 甲が依頼を承諾した文言
- 【拾う事実】『50万円／お中元10万円相当』 → 金額（対価性の手がかり）
- 【拾う事実】「必要な調査を行わないまま通常より早く交付」 → 乙の許可の出し方
- 【拾う事実】「W県X署交通課に異動」 → 乙の収受時の所属
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 主体＝警察官で公務員（争いなし）／態様＝現に受領＝収受／甲の50万円は対価性明らか。詰まるのは②「職務に関し」だけ。3要件のうち争点に紙幅を寄せる。
- 【規範の要点】「縦（一般的職務権限）と横（密接関連）」の規範
  - 収賄罪の保護法益は職務の公正及びこれに対する社会一般の信頼。だから「職務に関し」とは、当該公務員の一般的職務権限に属する職務行為及びこれと密接に関連する行為に関する場合をいう（最決平17.3.11）。
- 【効く事実】「縦（一般的職務権限）と横（密接関連）」のあてはめで使う事実
  - 一般的職務権限 → 「警察法に基づき東京都において職権を行使し犯罪捜査等に従事」「つなぎ的存在として関与が予定」を直接引用。情報提供 → 捜査情報を漏らさないのは警察官の職責＝範囲内。働きかけ → 他署の捜査担当者への働きかけ＝本来の職務でないが密接関連。請託 → 「分かった、何とかしてみよう」で承諾。
- 【規範の要点】過去の職務関連の規範
  - 保護法益たる職務の公正への信頼は過去に担当した職務に関する賄賂でも害される。そこで、一般的職務権限を異にする他の職に転じた後でも、前の職務に関し賄賂を収受すれば「職務に関し」を満たす（最決昭58.3.25）。反対の事後収賄説は、197条の3第3項が「公務員であった者」＝退職者を対象とする規定で現職の乙に使えず、間隙が生じる点で批判される。
- 【効く事実】「時間（過去の職務）＋賄賂性＋加重」のあてはめで使う事実
  - 権限を異にする → 「W県X警察署交通課に異動」＝県も部署も異なる。過去の職務関連 → お中元はV署での早期許可の「謝礼」。賄賂性 → 「お中元の名目」だが10万円相当＝社交儀礼超。不正行為 → 「必要な調査を行わないまま通常より早く交付」（不正行為が先・収受が後＝2項）。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 縦＝甲の地域課／刑事課、横＝甲の働きかけ、時間＝乙の異動後。3方向とも「職務の公正と社会の信頼が害される」という一点で説明できる。
- 【まぎらわしい選択肢・論点】正当防衛の成否／事後収賄罪の直接適用／第三者供賄の成否
- 【まぎらわしい選択肢・結論】単純収賄罪 成立／事後収賄罪 成立／加重収賄罪 成立
- 【まぎらわしい選択肢・規範】具体的担当を要する説／狭義の職務限定説
- 【まぎらわしい選択肢・事実】不正行為あり／退職後の収受

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

甲＝地域課でも警察法上の一般的職務権限、情報提供は範囲内・働きかけは密接関連、請託あり・不正未了で受託収賄。乙＝異動で権限が変わっても過去の職務関連で職務に関し、事後収賄罪は退職者規定で使えず、お中元10万は社交儀礼超で賄賂、不正行為先行で加重収賄2項。A・C＝贈賄は設問外。

## 3. 規範クイズ（5問）

- **Q04［規範］** 収賄罪（197条1項前段）の構成要件を順に挙げ、受託収賄・加重収賄への枝分かれも述べよ。
  - 模範解答：①公務員が ②その職務に関し ③賄賂を ④収受・要求・約束。＋請託の承諾＝受託収賄（後段）。＋職務上不正な行為（前か後）＝加重収賄（197条の3第1項／第2項）。退職後＝事後収賄（同3項）。
- **Q05［規範］** 収賄罪の「その職務に関し」の意義（規範）を、保護法益から導いて述べよ。
  - 模範解答：保護法益は職務の公正及びこれに対する社会一般の信頼。そこで「職務に関し」とは、当該公務員の一般的職務権限に属する職務行為、及びこれと密接に関連する行為に関する場合をいう。
- **Q06［規範］** 「職務密接関連行為」とは何か。「職務に関し」との関係を含めて述べよ。
  - 模範解答：賄賂の対価たる行為が、当該公務員の本来の職務権限に属する行為そのものでなくても、これと密接に関連する行為であれば「職務に関し」に含まれる。本問では「捜査の働きかけ」がこれに当たる（情報提供＝範囲内／働きかけ＝密接関連の切り分け）。
- **Q07［規範］** 公務員が一般的職務権限を異にする職に転じた後、前の職務に関し賄賂を収受した場合の処理（規範＋反対説の批判）を述べよ。
  - 模範解答：保護法益（職務の公正＋社会の信頼）は過去の職務に関する賄賂でも害される。よって転職後でも前の職務に関し収受すれば「職務に関し」を満たす（最決昭58.3.25）。事後収賄罪（197条の3第3項）は「公務員であった者」＝退職者の規定で、現職には適用できない（反対説への批判）。
- **Q08［規範］** 「賄賂」の意義と、社交儀礼の範囲内の贈与との区別の基準を述べよ。
  - 模範解答：賄賂＝公務員の職務行為の対価たる不正の報酬としての一切の利益（名目を問わない）。社会通念上の儀礼の範囲にとどまる贈与は対価性を欠き賄賂でないが、その範囲を超え職務との対価関係が認められれば、儀礼の名目でも賄賂に当たる。

## 4. ○×クイズ（6問）

- **Q09［○×］** 収賄罪と贈賄罪は対向犯（必要的共犯）の関係に立ち、賄賂を供与した側は贈賄罪（198条）として別個に処罰される。
  - 正解：○（正しい）
  - 理由：収賄（公務員側）と贈賄（供与側）は表裏の対向犯。本問のA・Cには贈賄罪が成立しうるが、設問は甲・乙の罪責のみを問うので「設問外」と一言で切る。検討対象を公務員側に絞れる根拠。
- **Q10［○×］** 公務員が職務に関し賄賂を収受し、その際に請託（一定の職務行為の依頼）を受けてこれを承諾したときは、単純収賄罪より刑の重い受託収賄罪（197条1項後段）となる。
  - 正解：○（正しい）
  - 理由：請託の承諾で前段（5年以下）が後段（7年以下）に加重される＝受託収賄。請託は正・不正を問わず、「一定の職務行為を行う／行わないことの依頼」で足りる。請託の有無が単純/受託の振り分け。
- **Q11［○×］** 単純収賄罪（197条1項前段）の成立には、公務員がその職務に関し賄賂を収受・要求・約束したことで足り、職務が現実に歪められたこと（不正行為）まではいらない。
  - 正解：○（正しい）
  - 理由：保護法益は職務の公正と社会の信頼で、賄賂の授受それ自体が信頼を害する。現実の職務歪曲は不要。不正行為が加わると加重収賄（197条の3）になる、という段階関係を押さえる。
- **Q12［○×］** 収賄罪の「職務」は、当該公務員が現に具体的に担当している事務に限られず、法令上その地位に伴い一般的に管掌しうる権限（一般的職務権限）の範囲に属すれば足りる。
  - 正解：○（正しい）
  - 理由：具体的職務分担を要しない。配置や転任で具体的担当が変わっても、一般的職務権限の同一性が保たれる限り「職務に関し」は失われない。「担当外だから職務外」と即断するのが最大の罠。
- **Q13［○×］** 利益が「賄賂」に当たるかは、贈与の名目（お中元・餞別など）ではなく、職務行為との対価関係の有無で実質的に判断され、社交儀礼の範囲を超える利益は名目を問わず賄賂となりうる。
  - 正解：○（正しい）
  - 理由：賄賂性は名目でなく対価関係で実質判断する。金額・経緯・職務との関連が判断材料。10万円相当のお中元が不正な早期許可の謝礼なら、社交儀礼の範囲を超え賄賂に当たる。
- **Q14［○×］** 収賄罪の保護法益を「職務の公正及びこれに対する社会一般の信頼」と解する立場（信頼保護説）からは、賄賂の授受それ自体が信頼を害するため、「職務に関し」を一般的職務権限・密接関連行為・過去の職務にまで広く及ぼすことができる。
  - 正解：○（正しい）
  - 理由：信頼保護説（判例・通説）は、職務の現実の歪曲を待たず賄賂授受それ自体を処罰の対象とする。この保護法益理解が、「職務に関し」を縦・横・時間の3方向へ広げる統一的な幹になる。
