### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「必要な書類を全てAに交付」 → もう処理する事務はある？の起点
- 【拾う事実】『Aの登記はまだ未了』 → Aの取得を妨げない義務が残るか
- 【拾う事実】『「Aとの話を秘して」Bに告げた』 → 欺く行為・任務に背く行為の材料
- 【拾う事実】『B銀行が直ちに順位1位の登記』 → 先に対抗要件を備えた＝Bの損害の有無
- 【拾う事実】『Aの登記は2番抵当権』 → 1番予定→2番への転落（価値の差）
- 【拾う事実】『自己の資金繰り／Bから600万』 → 甲が図った利益
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 図利加害目的＝自己・Bの利益を図る目的あり＝一言／任務違背＝Aの登記を妨害してBに設定＝一言／故意＝欠けるところなし＝一言。立ち止まるのは①事務処理者性と④財産上の損害の2点だけ。
- 【効く事実】「背任の2論点」のあてはめで使う事実
  - 事務処理者性 → 書類は全交付済みだが登記は未了（＝妨害しない消極的義務が残る）／財産上の損害 → 1番予定→2番に転落（＝担保価値の著しい差）／図利目的 → B銀行から600万円を得た／自己の資金繰り。
- 【規範の要点】「いずれも不成立」の規範
  - ①B相対＝二重譲渡とパラレル。先に対抗要件（登記）を備えたBに損害なし → 重要事項の偽りといえず原則不成立（特別事情なし）。②A三角＝被欺罔者が被害者の財産を処分し得る権能・地位を要する（最判昭45.3.26） → BにAの財産の処分権能なし → 不成立。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 複数の罪を検討したら、最後に成立した罪を数えて罪数を一言。成立が1つなら「罪数上問題なし」で完結。複数成立して初めて観念的競合（54条1項前段）・牽連犯（同後段）を論じる。成立しない罪との罪数は論じない。
- 【まぎらわしい選択肢・論点】横領罪の成否／不法領得の意思／電子計算機使用詐欺
- 【まぎらわしい選択肢・結論】横領罪 成立／詐欺罪 成立／背任罪 不成立
- 【まぎらわしい選択肢・規範】法律的見地／事実上の近接性説／主観説
- 【まぎらわしい選択肢・事実】書類未交付／登記完了済み／特別事情あり

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

背任＝書類全交付後も登記まで妨害しない消極的義務で事務処理者性○、図利目的・任務違背○、1番→2番転落を経済的見地で損害○、故意○ → Aへ背任成立。詐欺＝B相対は先登記で損害なし・特別事情なしで不成立、A三角は被欺罔者Bに処分権能なしで不成立。罪数＝背任一罪のみ。

## 3. 規範クイズ（全2問・1問目から最後まで全部出す）

- **［規範クイズ 1/2］** 背任罪（247条）の成立要件を全て挙げよ。
  - 模範解答：①他人のためにその事務を処理する者（他人の事務処理者）②任務に背く行為（任務違背行為）③自己若しくは第三者の利益を図り又は本人に損害を加える目的（図利加害目的）④本人に財産上の損害を加えたこと、＋故意。主観（図利加害目的）を落としやすいので注意。
- **［規範クイズ 2/2］** 抵当権設定者が、設定に必要な書類を交付した後もなお「他人のためにその事務を処理する者」にあたるとされる理由を述べよ。
  - 模範解答：登記が完了するまでは、抵当権者の抵当権取得を妨害しないという消極的義務を負い、この任務は主として他人である抵当権者のために負うものだから（最判昭31.12.7）。書類交付後でも事務処理者性は失われない。

## 4. ○×クイズ（全8問・1問目から最後まで全部出す）

- **［○×クイズ 1/8］** 行為者が一人でも、一個の財産的行為が複数の関係者を巻き込むときは、被害者・相手方ごとに別個に犯罪の成否を検討する必要がある。
  - 正解：○（正しい）
  - 理由：犯罪の成否は被害者・相手方ごとに個別に判断する。一個の行為でも、Aとの関係では背任、Bとの関係では詐欺、というように分けて拾うのが財産犯処理の第一歩。検討対象の取りこぼしを防ぐ。
- **［○×クイズ 2/8］** 自己が所有する不動産に二重に抵当権を設定して先順位予定の債権者を害した場合、目的物は「他人の物」にあたるため横領罪が成立する。
  - 正解：×（誤り）
  - 理由：横領罪は「自己の占有する他人の物」を領得する罪。二重抵当の目的物は設定者（甲）の所有物のままで「他人の物」ではないから横領にならず、他人（抵当権者）の事務に背く背任罪が問題となる。なお不動産の二重売買（登記前）は横領になりうる点と対比。
- **［○×クイズ 3/8］** 罪の軽重は法定刑で比較する。詐欺罪（246条1項）の法定刑は背任罪（247条）の法定刑より重い。
  - 正解：○（正しい）
  - 理由：詐欺罪は10年以下の拘禁刑、背任罪は5年以下の拘禁刑又は50万円以下の罰金で、法定刑は詐欺のほうが重い。もっとも本問では詐欺は不成立に終わるため、書く順序は法定刑の重さではなく事案の中核（成立する背任）から決める。重さと書く順序は必ずしも一致しない。
- **［○×クイズ 4/8］** 単に自己の債務を履行しないにすぎない場合は背任罪は成立せず、主として他人のために負う任務に背いた場合に背任罪が成立する。
  - 正解：○（正しい）
  - 理由：「自己の事務」の不履行は民法上の債務不履行にとどまり背任にならない。「主として他人のために負う事務（任務）」への違背だけが背任を構成する。背任と債務不履行を画する基準。
- **［○×クイズ 5/8］** 背任罪の「財産上の損害」は、法律的見地ではなく経済的見地から、本人の財産状態が実質的に悪化したか（価値の減少・増加すべき価値の不増加）で判断する。
  - 正解：○（正しい）
  - 理由：経済的見地で判断する（最決昭58.5.24）。「2番抵当権という権利は得ている」（法律的見地）では担保価値の毀損を捉えられない。1番→2番への転落を担保価値の著しい減少と評価してこそ損害を捕捉できる。
- **［○×クイズ 6/8］** 不動産の二重譲渡・二重抵当で第二の権利者が先に対抗要件（登記）を備えた場合、その者には原則として財産上の損害がなく、その者に対する詐欺罪は原則として成立しない。
  - 正解：○（正しい）
  - 理由：横領・背任とパラレルに、先に対抗要件を備えた者は完全な権利を取得して損害がなく、判断の基礎となる重要事項の偽りともいえないから原則不成立。ただし「契約の存在を知れば取引しなかった」特別事情があれば例外的に成立しうる。
- **［○×クイズ 7/8］** 被欺罔者と財産上の被害者が異なる三角詐欺では、被欺罔者が被害者の財産を処分し得る権能・地位を有しなくても、被害者を欺く意図さえあれば詐欺罪が成立する。
  - 正解：×（誤り）
  - 理由：三角詐欺の成立には、被欺罔者が財産上の被害者の財産を法律上又は事実上処分し得る権能又は地位を有することを要する（最判昭45.3.26）。処分権能のない第三者を欺いても被害者に対する詐欺は成立しない。
- **［○×クイズ 8/8］** 一個の行為が複数の関係者を巻き込んでも、最終的に成立する犯罪が一罪だけであれば、罪数処理で特に問題は生じない。
  - 正解：○（正しい）
  - 理由：罪数論は二罪以上が成立して初めて意味を持つ（観念的競合か牽連犯か等）。成立しない罪（本問の詐欺）との罪数を延々論じるのは失点。

（○×クイズはここまで＝全8問。最後の8問目まで出したら「○×クイズ、全8問クリア！」と言って復習へ）
