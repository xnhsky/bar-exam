## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

甲は、Aと共謀して、乙に対して、傷害を加えたとの公訴事実で起訴され、Aと併合審理に付された。甲は、実際は、乙に対して傷害を加えていたが、何とか無罪を勝ち取ろうと考え、友人の丙に対して、虚偽のアリバイを証言してもらうよう頼んだ。なお、乙を殴ったのは、甲のみであり、Aは、その場で甲が殴っているのを見ていたにすぎなかった。第1回公判期日において、証人として出廷した乙は、宣誓後、「甲とAに取り囲まれて、2人から何度も殴る蹴るの暴行を受けました。」と証言した。一方、目撃者として出廷し、宣誓をした丙は、「甲は乙を殴っていましたが、Aはそれを見ているだけでした。」と証言した。乙は、被害時の恐怖等により、すっかり2人に殴られたと信じていたため、そのように証言した。一方、丙も、Aも乙を殴っていたと誤認していたが、Aが法廷で真摯な態度をとっていたため、Aをかばおうと思って、自己の認識とは異なる証言をしたのであった。なお、丙は、甲から虚偽のアリバイを証言するように頼まれていたものの、甲のために危険を犯す必要はないと考え、上記のように証言をしたのだった。甲、乙及び丙の罪責について、論じなさい。なお、乙に対する傷害罪の成否については、論じる必要がない。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 暴行：甲のみが乙を殴打、Aは傍観（客観的事実）
- 起訴・併合審理：甲は「Aと共謀」で起訴／丙に虚偽アリバイ証言を依頼
- 乙の証言：記憶どおり「2人に殴られた」（恐怖による誤信）
- 丙の証言：記憶に反し「Aは見ていただけ」（Aをかばう・甲の依頼は無視）

  - 答え：罪責を検討するのは「何か行為をした人」。本問は乙（記憶どおり証言）・丙（記憶に反する証言）・甲（丙へ偽証依頼＝教唆）の3人。
  - 答え：A＝傍観者・乙への傷害＝設問が「論じる必要がない」と明示。ここで切るのが第一歩。
- **Q02［見当づけ］** 各行為は「何罪っぽい？」 ― 見当をつけて
  - 答え：手がかりは2つ。①宣誓した証人か（乙・丙＝○）／②記憶と証言のズレ。乙・丙は記憶と証言にズレがあり偽証罪系、甲は被告人で他人に偽証を依頼＝偽証教唆系。
- **Q03［論点］** 乙で問題になる論点を挙げて（2つ）
  - 答え：CP①：「虚偽」とは記憶に反することか真実に反することか → 「虚偽の陳述」の意義（主観説／客観説）。（主観説＝記憶基準／客観説＝真実基準）
  - 答え：CP②：採る説で故意の対象が変わる → 故意の内容。（主観説＝記憶に反する認識／客観説＝真実に反する認識）
- **Q04［論点］** 甲で「詰まる所」を挙げて（2つ）
  - 答え：CP①：被告人による偽証教唆は可罰か → 被告人による偽証教唆の可罰性。（防御の自由とは別＝他人を巻き込むのは防御権の濫用で可罰）
  - 答え：CP②：丙は依頼を無視し別内容を証言 → 共犯の因果性。（教唆と正犯結果に因果性が要る＝因果的共犯論）

### 骨子（3項目。第1から【論点】ごとに、何が問題→規範→使う事実→結論 の順で組み立てる）

#### 第1　乙の罪責

- 見出しの補足（結論を含む。項目の終わりに読む）：偽証罪・169条
1. 客観的事実（甲のみ殴打）に反するが記憶どおり「2人に殴られた」と証言 → 偽証罪（169）の成否
2. 【論点】「虚偽の陳述」（169条）の意義 → 証人は記憶のままに述べれば足り真実は裁判所が判断・記憶に反する陳述は審判作用を害する抽象的危険 → 「虚偽の陳述」＝記憶に反する陳述（主観説）
   - あてはめ：乙は恐怖により2人に殴られたと信じ記憶どおり証言 ＝ 記憶に反する陳述なし
- 結論：「虚偽の陳述」に当たらず 偽証罪 不成立

#### 第2　丙の罪責

- 見出しの補足（結論を含む。項目の終わりに読む）：偽証罪・169条
1. 客観的真実に合致するが記憶に反する証言 → 同じく偽証罪の成否
2. 【論点】真実に合致する記憶に反する陳述の「虚偽」該当性 → 前述の主観説により記憶に反する陳述なら客観的真実への符合を問わず「虚偽の陳述」に当たる
   - あてはめ：丙は「Aも殴った」と認識しながら「Aは見ていただけ」と記憶に反する証言・Aをかばう動機は成否を左右しない
- 結論：「虚偽の陳述」に当たり 偽証罪 成立

#### 第3　甲の罪責

- 見出しの補足（結論を含む。項目の終わりに読む）：偽証教唆・169条・61①
1. 甲は被告人で偽証の正犯になれないが、丙を教唆した点で偽証教唆罪の成否
2. 【論点】被告人による偽証教唆の可罰性 → 他人を巻き込む偽証教唆は防御の範囲を超える防御権の濫用で適法行為の期待可能性も認められる（可罰説）
   - あてはめ：甲は丙に虚偽アリバイの証言を依頼 → 偽証教唆は成立しうる
3. 【論点】共犯の因果性（依頼を無視した場合） → 共犯の処罰根拠は正犯を通じ結果を惹起する点＝因果的共犯論・教唆と正犯結果に因果性を要する
   - あてはめ：丙は甲の依頼を無視し、別内容（むしろ甲に不利）を証言＝物理的にも心理的にも寄与なし
- 結論：因果性が断ち切られ 偽証教唆罪 不成立
   （配分メモ：乙で主観説の規範を最厚に定立、丙は同規範の裏返しで圧縮、甲は可罰性を一言＋因果性の切断を本丸に）

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「すっかり2人に殴られたと信じていた」 → 乙の記憶（証言と一致するか見る）
- 【拾う事実】『「Aも殴っていたと誤認」＋「Aは見ていただけ」と証言』 → 丙の記憶と証言のズレ
- 【拾う事実】「Aをかばおうと思って」 → 丙の動機（拾うが評価に注意）
- 【拾う事実】『「危険を犯す必要はない」と依頼を無視』 → 丙が甲の依頼に従わなかった
- 【拾う事実】『甲が丙に虚偽アリバイを依頼』 → 甲の関与の中身
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 主体＝乙・丙は宣誓した証人で充足（争いなし）／故意＝記憶に反する認識（あてはめで処理）。争いのない要件は一文で通し、争点である「虚偽の陳述」に紙幅を集める。
- 【効く事実】効く事実（乙）
  - 記憶 → 「すっかり2人に殴られたと信じていた」（恐怖による誤信）／証言 → 「2人から暴行を受けた」／両者は一致＝記憶に反しない。
- 【規範の要点】主観説の規範
  - 「虚偽の陳述」＝記憶に反する陳述。丙は「Aも殴った」と認識しながら「Aは見ていただけ」と記憶に反する証言をした → 客観的真実に合致しても該当。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 被告人が他人に偽証を頼んだら、まず可罰性（不可罰説に触れ可罰説）→ 次に因果性（因果的共犯論）。「丙の偽証が成立だから甲の教唆も成立」と短絡しない。丙が依頼を無視したかが分かれ目。
- 【まぎらわしい選択肢・論点】正当防衛の成否／証拠隠滅罪の成否／共同正犯の成否
- 【まぎらわしい選択肢・結論】偽証罪 成立／偽証教唆罪 成立
- 【まぎらわしい選択肢・規範】客観説／責任共犯論
- 【まぎらわしい選択肢・事実】記憶どおりの陳述／依頼どおりの偽証

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

乙＝「虚偽の陳述」は記憶に反する陳述（主観説）、乙は記憶どおりだから不成立。丙＝同規範の裏返し、真実に合致しても記憶に反するから成立、動機は無関係。甲＝被告人でも防御権濫用で可罰だが、丙が依頼を無視＝因果性なしで教唆不成立。

## 3. 規範クイズ（4問）

- **Q05［規範］** 偽証罪（169条）の保護法益を挙げ、なぜ抽象的危険犯とされるかを一言で説明せよ。
  - 模範解答：保護法益＝国家の審判作用（の適正）。記憶に反する証言は、結果的に真実と合致しても裁判所の心証形成を誤らせる抽象的危険を生じるため、現実の誤判を要しない抽象的危険犯とされる。
- **Q06［規範］** 偽証罪の「虚偽の陳述」について、主観説（判例）の規範と理由づけを述べよ。
  - 模範解答：「虚偽の陳述」＝証人の記憶に反する陳述をいい、客観的事実への符合は問わない。証人は体験した事実を記憶のままに述べれば足り、何が真実かを判断するのは裁判所だから（大判大3.4.29）。
- **Q07［規範］** 被告人が自己の刑事事件について他人を教唆して偽証させた場合の可罰性につき、判例（可罰説）の規範と理由を述べよ。
  - 模範解答：偽証教唆罪が成立しうる。被告人の黙秘・防御の自由と、他人を巻き込んで偽証させることは別であり、後者は防御の範囲を超える防御権の濫用で、適法行為の期待可能性も認められる（最決昭28.10.19）。
- **Q08［規範］** 共犯（教唆）の処罰根拠について因果的共犯論（惹起説）の内容と、そこから導かれる帰結を述べよ。
  - 模範解答：共犯は正犯を通じて間接的に法益侵害の結果・危険を惹起する点に処罰根拠がある。よって共犯行為と正犯結果との間に因果性を要し、因果性を欠けば共犯は成立しない。

## 4. ○×クイズ（6問）

- **Q09［○×］** 偽証罪（169条）の主体は「法律により宣誓した証人」に限られ、宣誓していない者や当事者本人は主体となりえない（身分犯）。
  - 正解：○（正しい）
  - 理由：偽証罪は宣誓した証人という身分を要する真正身分犯。被告人本人は証人になれず主体から外れる。だから被告人の関与は「他人を巻き込む教唆」として別途検討することになる。
- **Q10［○×］** 偽証罪（169条）は、宣誓した証人が虚偽の陳述をした時点で成立し、現実に裁判の結果が誤る必要はない（抽象的危険犯）。
  - 正解：○（正しい）
  - 理由：偽証罪の保護法益は国家の審判作用（の適正）で、虚偽の陳述がされれば裁判所の心証形成を誤らせる危険が生じる＝抽象的危険犯。現実の誤判は不要。
- **Q11［○×］** 偽証罪の故意は「虚偽の陳述」をすることの認識で足りるが、どの説に立つかでその認識対象（記憶に反する／真実に反する）が変わる。
  - 正解：○（正しい）
  - 理由：主観説では「記憶に反することの認識」、客観説では「真実に反することの認識」が故意の対象。客観説では真実と信じていれば故意阻却となり判断が二段階化する。
- **Q12［○×］** 偽証罪の成否は記憶に反する陳述をしたか否かで決まり、証人がどのような動機（他人をかばう等）で陳述したかは成立を左右しない。
  - 正解：○（正しい）
  - 理由：主観説では「記憶に反する陳述」をすれば足り、動機（かばう・恨み等）は成否を左右しない。動機を理由に不成立とすると規範を踏み外す。
- **Q13［○×］** 「虚偽の陳述」を客観的真実に反する陳述と解する客観説では、客観的真実に合致する陳述はそもそも虚偽でなく、偽証罪は成立しない。
  - 正解：○（正しい）
  - 理由：客観説は「真実に反するか」をまず見るため、真実に合致する陳述は虚偽でない。同じ事案でも主観説（記憶基準）と客観説（真実基準）で結論が逆転する典型例。
- **Q14［○×］** 正犯が犯罪を実行しても、教唆行為と正犯の実行との間に因果性が認められなければ、教唆犯は成立しない。
  - 正解：○（正しい）
  - 理由：因果的共犯論からは、教唆行為と正犯結果との因果性が必要。正犯が教唆を無視して別の動機・別内容で犯罪を行った場合、教唆との因果性が断ち切られ教唆犯は成立しない。
