## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

Xは、深夜に宝石店Aに立ち入り、同店内に保管されている時価100万円相当の宝石Bを持ち去った。Xは、騒ぎが収まるまでの間は、自己で保管しておくのは危険であると考えたため、友人の甲に対し、宝石店Aから盗み出した旨を伝えた上で、これを保管するよう依頼したところ、甲はこれを快諾して、預かった。しかし、甲は、自分の部屋に適当な保管場所がなかったため、甲の夫である乙に「盗んできちゃったものなんだけど、あなたの金庫に入れておいてくれない。」と依頼した。乙は、甲が盗んできたものであると誤信し、これを了承し、金庫に保管した。甲及び乙の罪責について、論じなさい。また、甲が、第三者Yに対して、Xから預かった宝石Bを、事情を明かして100万円で売却し、その代金を費消した場合はどうか。甲及び乙の罪責を論ぜよ（後段：甲の処分行為を含む）。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- X、宝石店Aから宝石B（時価100万円）を窃取

- 甲→乙：「盗んできた」と告げ金庫保管を依頼
- 乙：甲が盗んだと誤信し了承・金庫に保管

### 骨子（3項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　甲の罪責

- 見出しの補足（結論を含む。項目の終わりに読む）：前段
1. 盗品と知って保管 → 盗品等保管罪（256条2項）成立
2. 乙にも保管させた → 乙を正犯とする盗品等保管罪の教唆犯（61条1項）
3. 【論点】保管罪と教唆犯の罪数 → 規範：追求権侵害の一個性
- 結論：包括一罪

#### 第2　乙の罪責

1. 関与罪犯人甲からの依頼でも → 盗品等保管罪（256条2項）成立
2. 甲乙は夫婦 → 【論点】257条1項の親族関係は誰と誰の間に必要か → 規範：本犯者基準（本犯者と関与罪犯人の間）
   - あてはめ：本犯X−乙に親族関係なし → 257条適用なし
3. 乙の「甲が盗んだ」誤信 → 【論点】親族関係の錯誤 → 一身的処罰阻却事由＝故意・責任に影響なし
- 結論：盗品等保管罪 成立・刑の免除なし

#### 第3　甲の罪責

- 見出しの補足（結論を含む。項目の終わりに読む）：後段
1. 預かった宝石BをYへ売却・費消 → 横領罪（252条1項）／客体＝宝石店Aの「他人の物」
2. 【論点】無権限者（窃盗犯X）との委託信任関係の要保護性 → 規範：財産秩序維持＋占有説との均衡 → 保護に値する
3. 売却・費消＝不法領得の意思の発現 → 「横領」
4. 事情を明かして売却＝欺罔なし → 詐欺（246条）不成立
- 結論：横領罪 成立（前段と併合罪）

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「盗み出した旨を伝えた上で」 → 甲の知情（盗品の認識）
- 【拾う事実】「甲が盗んできたものであると誤信」 → 乙の認識（本当はXの盗品）
- 【拾う事実】「甲の夫である乙」 → 甲乙の親族関係（夫婦）
- 【拾う事実】『宝石Bは宝石店Aの所有物』 → 客体「他人の物」の所有関係
- 【拾う事実】「事情を明かして100万円で売却」 → Yへの告知の有無
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 盗品該当性＝宝石BはXの窃盗で領得＝盗品／知情＝「盗んできた」と告げられた＝あり／客体＝宝石店Aの所有物。ここは一文で素通り。
- 【効く事実】あてはめで使う事実
  - 本犯＝窃盗犯X（乙とは赤の他人）／親族関係は甲乙の夫婦間のみ＝本犯Xと乙の間にはなし → 257条適用なし。乙の「甲が盗んできた」との誤信＝親族関係の錯誤だが、処罰阻却事由は故意の対象でない＝影響なし。
- 【規範の要点】「委託信任関係の要保護性」の規範
  - 刑法の目的は財産秩序の維持にあり、要保護性は民法とは別に考える。外形上の委任関係を裏切って財物を領得する行為は財産秩序維持の観点から禁圧すべき → 委託者に権利があるかは犯罪の成否に影響しない。窃盗犯の占有も保護される（占有説）こととの均衡からも、無権限者との委託信任関係も保護に値する。売却・費消＝不法領得の意思の発現＝「横領」。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 同一の追求権を侵害する関与行為は包括一罪でまとめる。これと別個の法益（委託信任関係の破壊）を侵害する横領罪は併合罪（45条前段）。罪質が異なる罪は牽連犯・包括一罪にしない、が原則。
- 【まぎらわしい選択肢・論点】正当防衛の成否／不法領得の意思の要否
- 【まぎらわしい選択肢・結論】詐欺罪 成立／刑の免除／遺失物等横領罪 成立
- 【まぎらわしい選択肢・規範】関与罪犯人相互間基準／牽連犯
- 【まぎらわしい選択肢・事実】親族関係あり／欺罔あり

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

甲前段＝盗品と知って保管＝256条2項、乙にも保管させた＝教唆犯、追求権の一個性で包括一罪。乙＝関与罪犯人甲からの依頼でも保管罪、257条は本犯Xと乙に親族関係なしで適用なし、錯誤は処罰阻却事由で影響なし＝保管罪成立・免除なし。甲後段＝窃盗犯Xとの委託信任も財産秩序維持・占有説との均衡で保護に値する＝横領、事情明かしで詐欺なし、前段と併合罪。

## 3. 規範クイズ（全2問・1問目から最後まで全部出す）

- **［規範クイズ 1/2］** 親族間特例（257条1項）の親族関係は「誰と誰の間」に必要か。判例（最決昭38.11.8）の立場を理由とともに述べよ。
  - 模範解答：本犯者と盗品等関与罪の犯人との間に必要。257条の趣旨は親族たる本犯者を庇護する関与行為について期待可能性が減少する点（事後従犯的側面）にあるから、親族関係は本犯者との間にあって初めて意味を持つ。関与罪犯人相互（甲・乙）の親族関係では適用しない。
- **［規範クイズ 2/2］** 257条1項の法的性質と、親族関係の錯誤（親族でない者を親族と誤信した場合）の処理を述べよ。
  - 模範解答：一身的処罰阻却事由（犯罪は成立し、政策的に刑のみ免除）。処罰阻却事由は故意の対象ではないから、親族関係を誤信しても故意・責任に影響せず、犯罪の成否は変わらない。客観的に親族関係がない以上、免除はない。

## 4. ○×クイズ（全7問・1問目から最後まで全部出す）

- **［○×クイズ 1/7］** 盗品等に関する罪（256条）の保護法益は、被害者が盗品の返還・回復を求める権利、すなわち追求権である。
  - 正解：○（正しい）
  - 理由：盗品等関与罪の保護法益は被害者の追求権（盗品の回復請求権）である。盗品の所在を移し追求を困難にする行為が処罰の核心。だから「誰が本犯（領得者）か」を最初に固定すると、追求の対象物と関与者の位置づけが一気に見える。
- **［○×クイズ 2/7］** 盗品等保管罪（256条2項）は、本犯者から依頼を受けた場合に限らず、盗品等関与罪の犯人から依頼を受けて盗品を保管した場合にも成立する。
  - 正解：○（正しい）
  - 理由：保護法益は追求権であり、本犯者からの依頼でなくても、盗品の所在を移して追求を困難にする点で侵害は同じ。だから関与罪犯人（甲）から依頼された乙にも保管罪が成立する。「本犯者からの依頼でないと成立しない」と誤らないこと。
- **［○×クイズ 3/7］** 親族間特例（257条1項）は、犯罪の成立そのものを否定する違法性阻却事由である。
  - 正解：×（誤り）
  - 理由：257条1項は一身的処罰阻却事由であり、犯罪は成立した上で政策的に刑のみを免除する。違法性や責任を阻却するわけではない。だから親族関係の錯誤も故意・責任に影響しない。
- **［○×クイズ 4/7］** 盗品等関与罪における親族間特例（257条1項）の親族関係は、保管等を依頼してきた関与罪の犯人との間にあれば足り、本犯者との間にある必要はない。
  - 正解：×（誤り）
  - 理由：親族関係は本犯者と関与罪犯人の間に必要（最決昭38.11.8）。関与罪犯人相互間に親族関係があっても適用しない。趣旨が「親族たる本犯者の庇護に伴う期待可能性減少」にあるからである。
- **［○×クイズ 5/7］** 横領罪（252条1項）が遺失物等横領罪（254条）より重く処罰される根拠は、委託信任関係を破る点にある。
  - 正解：○（正しい）
  - 理由：横領罪の占有が委託信任関係に基づくことを要する根拠は、まさに本罪が254条より法定刑が重い点にある。委託信任を破る点に強い非難可能性があるからである。この法定刑差が「委託信任関係を要する」という解釈の出発点。
- **［○×クイズ 6/7］** 相手方に事情を明かして（真実を告げて）財物を売却した場合でも、対価を受け取っている以上、詐欺罪（246条1項）が成立する。
  - 正解：×（誤り）
  - 理由：詐欺罪は「人を欺いて財物を交付させる」罪であり、欺罔行為（重要事項を偽ること）が不可欠。事情を明かして売却すれば欺罔がなく、詐欺罪は成立しない。本問の甲→Yの売却も同様。
- **［○×クイズ 7/7］** 数個の犯罪が、それぞれ別個の行為により別個の法益を侵害する場合は、原則として併合罪（45条前段）となる。
  - 正解：○（正しい）
  - 理由：包括一罪や科刑上一罪（観念的競合・牽連犯）にあたらない複数の犯罪は併合罪となる。本問の盗品等保管罪（追求権侵害）と横領罪（委託信任関係の破壊）は、行為も法益も別個だから併合罪である。
