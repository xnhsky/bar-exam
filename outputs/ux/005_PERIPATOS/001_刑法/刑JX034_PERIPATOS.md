### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「虚構の殺人予告」 → ＝人の錯誤を利用する手段／暴行・脅迫でない
- 【拾う事実】「警察官の出動・警戒等の業務」「2日間／本来業務が困難」 → ＝妨害対象が公務・妨害結果の発生
- 【拾う事実】『乙は甲の「弟」』 → ＝親族（落とすと致命傷）
- 【拾う事実】「自分だと言ってほしい」 → ＝犯人自身が他人を動かして自己を庇わせた
- 【拾う事実】「Bは信用せず甲を逮捕」 → ＝既遂に影響しない事情（抽象的危険犯）
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 偽計＝「虚構の殺人予告」で一発該当／妨害結果＝2日間本来業務が困難＝発生／故意・違法性・責任＝阻却事由なし。
- 【規範の要点】公務二分説の規範
  - 強制力を行使する権力的公務は、威力・偽計を実力で自力排除できるから「業務」に含まれない。非権力的公務は私人の業務と区別する必要がなく「業務」に当たる。
- 【ポイント】本問で効く当てはめ
  - 妨害された警察業務に権力的公務（逮捕等）が含まれていても、その強制力は「虚偽の書込みを直ちに看破できない段階」の妨害には及ばない＝偽計を自力排除できない。だから全体が「業務」に当たる。趣旨（強制力による自力排除）に遡って権力的に見える点を克服するのが上位答案。
- 【規範の要点】惹起説の規範
  - 犯人自身の隠避（103条の主体に犯人を含まない＝不可罰）でも、他人を教唆して自己を隠避させれば、正犯（他人）を介した間接的な法益侵害があり、かつ他人を巻き込む点で防御権の濫用＝期待可能性も否定されない → 教唆犯は成立。
- 【ポイント】105条は「二平面」で別々に
  - 乙＝親族が犯人を隠避＝105条適用（任意的免除）。甲＝犯人が親族を教唆＝105条準用は否定（第三者教唆に期待可能性の欠如なし／その理は親族教唆でも妥当）。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 他人を巻き込んだ事案では教唆犯（61条1項）か共同正犯（60条）かの関与形態を選ぶ。両者を分けるのは正犯性＝自己の犯罪として実現する意思で重要な役割を果たしたか。単に決意を生じさせ正犯に委ねたにとどまれば教唆犯。本問は乙が「やむなく」自らの意思で出頭しており、甲は教唆犯が事実に忠実。
- 【まぎらわしい選択肢・論点】公務執行妨害罪の成否／威力業務妨害か偽計業務妨害か
- 【まぎらわしい選択肢・結論】公務執行妨害罪 成立／犯人隠避罪 不成立／証拠隠滅罪 成立
- 【まぎらわしい選択肢・規範】公務全面肯定説／必要的免除
- 【まぎらわしい選択肢・事実】暴行・脅迫の存在／物的証拠の隠滅

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

甲①＝手段は暴行・脅迫でなく公務執行妨害罪（95条）不成立／「偽計」＝虚構の殺人予告／公務二分説（趣旨＝強制力による自力排除）で偽計には強制力の排除作用が及ばず警察公務も「業務」＝偽計業務妨害罪（233条後段）成立。乙＝身代わり出頭・虚偽自供＝「隠避」・抽象的危険犯（Bが信用せずとも既遂）／甲の弟＝親族で105条任意的免除 → 犯人隠避罪（103条）成立・刑は任意的免除。甲②＝自己隠避教唆＝惹起説＋他人を巻き込む防御権濫用で期待可能性は否定されず教唆犯肯定／親族を教唆した甲に105条準用なし → 犯人隠避罪の教唆犯（61条1項・103条）成立。罪数＝甲は併合罪（45条）。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 偽計業務妨害罪（233条後段）の「偽計」の意義と、犯人隠避罪（103条）の「隠避」の意義を、それぞれ一文で書け。
  - 模範解答：「偽計」＝人を欺罔し、又は人の錯誤・不知を利用する違法な行為。「隠避」＝蔵匿（場所提供）以外の方法により、官憲による犯人の発見・逮捕を妨げる一切の行為（身代わり出頭・虚偽自供もこれに当たる）。
- **［規範クイズ 2/3］** 公務が業務妨害罪の「業務」に当たるかについての規範（公務二分説）を、根拠（趣旨）とともに書け。
  - 模範解答：強制力を行使する権力的公務は、威力・偽計を実力で自力排除でき業務妨害罪による保護を要しないから「業務」に含まれない。非権力的公務は私人の業務と区別する必要がなく「業務」に当たる。＝公務二分説。趣旨は「強制力による自力排除の可否」。
- **［規範クイズ 3/3］** 犯人が他人を教唆して自己を隠避させた場合になぜ教唆犯が成立するのか、共犯の処罰根拠から規範を書け。
  - 模範解答：共犯の処罰根拠は正犯を介した間接的な法益侵害にある。正犯（他人）に犯罪が成立する以上、これを教唆すれば法益侵害を惹起しており、しかも他人を巻き込んで自己を隠避させることは防御権の濫用で、定型的に期待可能性がないとはいえない。ゆえに教唆犯が成立する（惹起説）。

## 4. ○×クイズ（全13問・1問目から最後まで全部出す）

- **［○×クイズ 1/13］** 同一人に成立した数個の罪のうち、犯意が別個で行為も時間的に分かれているものは、原則として併合罪（45条）となり、1個の行為が数罪に当たる観念的競合（54条1項前段）とは処理を異にする。
  - 正解：○（正しい）
  - 理由：罪数は「行為が1個か数個か」がまず分水嶺。別個の犯意に基づく数個の行為で数罪が成立すれば併合罪（45条）。1個の行為が数罪に当たる場合だけ観念的競合（54条1項前段・科刑上一罪）になる。
- **［○×クイズ 2/13］** 問題文で「特別法違反の点を除く」と指示があっても、念のため特別法（軽犯罪法・偽計業務妨害類似の特別法等）の成否にも触れておくべきだ。
  - 正解：×（誤り）
  - 理由：設問の限定は守る。検討対象外を書くのは時間と紙幅のロスで加点されない。刑法典上の罪責に絞る。
- **［○×クイズ 3/13］** 業務妨害罪のうち、人を欺罔し又は人の錯誤・不知を利用する手段によるものが偽計業務妨害罪（233条後段）、人の意思を制圧するに足りる勢力を示す手段によるものが威力業務妨害罪（234条）である。
  - 正解：○（正しい）
  - 理由：両罪は「手段」で振り分ける。秘密裏に錯誤・不知を利用するのが「偽計」、公然と意思を制圧する勢力を示すのが「威力」。虚構の予告で密かに動かす類型は偽計に当たる。
- **［○×クイズ 4/13］** 身代わり犯として警察に出頭し虚偽の自供をする行為は、物的証拠を消すわけではないから、犯人隠避罪も証拠隠滅罪も成立しない。
  - 正解：×（誤り）
  - 理由：身代わり出頭は真犯人の発見・身柄確保を妨げる「隠避」に当たり、犯人隠避罪（103条）が成立しうる。物証の有無は無関係。
- **［○×クイズ 5/13］** 制限従属性説によれば、狭義の共犯（教唆・幇助）が成立するには、正犯の行為が構成要件に該当し違法であれば足り、正犯が責任能力を備え有責であることまでは要しない。
  - 正解：○（正しい）
  - 理由：共犯従属性の程度につき通説は制限従属性説。正犯に構成要件該当・違法性まであれば共犯は成立し、正犯の責任（有責性）は不要。だから刑事未成年者を利用しても教唆犯が成立しうる。
- **［○×クイズ 6/13］** 犯人隠避罪は抽象的危険犯であり、捜査機関が身代わりの自供を信用せず真犯人を逮捕しても、隠避罪の成立（既遂）は妨げられない。
  - 正解：○（正しい）
  - 理由：抽象的危険犯は現実の発見・逮捕の妨害という結果を要しない。発見・逮捕を困難にする抽象的危険が生じれば既遂。Bが信用しなかった事情は成否に影響しない。
- **［○×クイズ 7/13］** 業務妨害罪の故意としては、他人の業務を妨害しうる偽計・威力を用いることの認識があれば足り、積極的に業務を妨害する目的（目的意思）までは不要である。
  - 正解：○（正しい）
  - 理由：故意犯の原則どおり、結果発生の認識・認容で足り、特別の目的（傾向犯的な目的意思）は条文上要求されていない。
- **［○×クイズ 8/13］** 公務は性質上すべて「業務」に含まれるから、警察官の職務に対する偽計はおよそ偽計業務妨害罪を構成する。
  - 正解：×（誤り）
  - 理由：判例・通説（公務二分説）は、強制力を行使する権力的公務は「業務」から外す。全部含めると公務執行妨害罪が手段を限定した趣旨を没却する。ここが本問の中核論点。
- **［○×クイズ 9/13］** 公務二分説で権力的公務を業務から外す根拠は、権力的公務は妨害を強制力で自力排除でき、業務妨害罪による保護を要しない点にある。
  - 正解：○（正しい）
  - 理由：趣旨は「強制力による自力排除」。だから自力排除が及ばない偽計の場面では、権力的公務も保護されうる、と一本の糸でつながる。
- **［○×クイズ 10/13］** 犯人自身が自己を蔵匿・隠避する行為は不可罰だが、犯人が他人を教唆して自己を隠避させた場合には、犯人に犯人隠避罪の教唆犯が成立しうる（判例）。
  - 正解：○（正しい）
  - 理由：共犯の処罰根拠（惹起説）から、正犯を介した法益侵害があり、他人を巻き込む点で防御権の濫用＝定型的に期待可能性なしとはいえない。教唆犯肯定が判例・通説。
- **［○×クイズ 11/13］** 親族が犯人を隠避すれば105条で刑が免除されるのだから、犯人が親族を教唆して自己を隠避させた場合も、その犯人に当然105条が準用される。
  - 正解：×（誤り）
  - 理由：105条の趣旨は「親族を庇う期待可能性の欠如」。犯人自身が他人(親族)を教唆して自己を隠避させることに期待可能性の欠如はなく、準用否定が筋（教唆犯肯定との一貫性）。
- **［○×クイズ 12/13］** 犯人蔵匿・隠避罪で「親族による犯罪に関する特例（105条）」は、刑を必要的に免除するのではなく、任意的に免除する規定である。
  - 正解：○（正しい）
  - 理由：105条は「免除することができる」＝任意的免除。必要的免除（〜する）と取り違えないこと。罪は成立し刑が任意的に免除される。
- **［○×クイズ 13/13］** 単に他人に犯罪を依頼した者を教唆犯ではなく共同正犯（60条）と構成するには、共謀（意思の連絡）に加え、自己の犯罪として実現する意思で重要な役割を果たしたこと（正犯性）が必要である。
  - 正解：○（正しい）
  - 理由：教唆犯は他人に決意を生じさせ犯罪を「実行させる」にとどまる。共謀共同正犯は、共謀＋正犯性（自己の犯罪としての重要な役割）を要する（練馬事件・最大判昭33.5.28）。依頼の事実が乏しければ教唆犯にとどまる。
