### 問題文（最初にゆっくり読み上げる）

甲は酒癖が悪く、酔うと是非善悪の判断力を失い、妻乙や子Aに暴行を加えることを繰り返しており、そのことを自覚していた。ある日、甲は飲酒を開始し、3歳のAが茶わんを割ったのを見とがめてAの顔を平手でたたくなどの折檻を始め、飲酒しながらこれを続けた。Aが反抗したため、甲はバットでAの足を殴打して重傷を負わせ、さらにAが反抗したことから、甲は「死んでも構わない」と思いつつAの頭部をバットで強打し、Aを死亡させた。妻乙はその間の一部始終を見ていたが、日ごろAが乙にも反抗的態度をとることもあって、甲の暴行を止めようとはしなかった。甲については、逆上しバットを持ち出す時点以降は是非善悪の判断力が著しく減退していたとして、甲及び乙の罪責を論じなさい。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 甲が飲酒を開始（このとき暴行・殺意なし）
- Aが茶わんを割る → 平手打ち・折檻を開始（飲酒継続）
- Aが反抗 → バットで足を殴打・重傷

- 「死んでも構わない」と頭部を強打 → A死亡
- 乙はその間ずっと見ていたが止めなかった

3. 【論点】原因において自由な行為で39条2項を排除できるか

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「酒癖を自覚していた」 → 原自行為を検討する動機
- 【拾う事実】「判断力が著しく減退」 → 限定責任能力（39条2項の引き金）
- 【拾う事実】『殺意は頭部強打の時に発生』 → 殺意の発生時期（排除の可否を分ける）
- 【拾う事実】「死んでも構わない」 → 甲の未必の故意
- 【拾う事実】『乙は母・室内に他に保護者なし』 → 乙の作為義務（排他的保護）
- 【拾う事実】『甲乙間にやりとり無し』 → 意思連絡の有無（共同正犯／片面的幇助）
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 甲：一連の暴行を重い殺人一個で包括評価／実行行為・因果関係・殺意は問題なく○／違法性も阻却事由なし＝一言で素通り。止まるのは責任（責任能力）だけ。
- 【規範の要点】「甲の原因において自由な行為」の規範
  - 責任能力が要求される根拠は、犯罪結果が責任能力ある状態の意思決定に基づき実現されたときに初めて非難が可能となる点にある。よって、原因行為から結果行為まで自由な意思決定に基づく意思が連続し、両者が同一の意思に貫かれた一個の行為と評価し得る場合には、実行行為時の責任能力の有無を問わず完全な責任を問いうる。
- 【効く事実】効く事実（適用排除の否定）
  - 問題提起 → 「酒癖を自覚していた」＝原自行為を検討すべき動機。適用排除の否定 → 原因行為（飲酒開始・折檻開始）時には殺意がなく、殺意は限定責任能力下で初めて生じた＝同一の意思に貫かれた一個の行為と評価できない。
- 【規範の要点】「罪名を絞り、正犯から幇助へ振り分ける」の規範
  - 不作為による関与は、構成要件の実現過程を支配したといえる行為支配がなければ原則として幇助犯。幇助は正犯行為を物理的・心理的に促進・容易にすれば足り、不作為でも可能。要件は①作為義務 ②作為の可能性・容易性 ③因果性で、③は犯行を確実に阻止できなくても困難にできた可能性があれば足りる。
- 【効く事実】乙で効く事実（三要件の充足）
  - ①作為義務 → 乙はAの母＝監護権者（民820条）／A3歳で自力で逃れられない／室内に甲乙A以外いない＝排他的な保護関係。②可能性・容易性 → 「助けを呼ぶ」程度は可能・容易。③因果性 → 助けを呼べば犯行を困難にできた可能性あり。最後に片面的幇助（意思連絡不要）を一言。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 共同正犯は共同実行の一体性＝相互の意思連絡を要するので、意思連絡を欠く本問では成立しない。これに対し幇助は正犯の犯行を促進・容易にすれば足り、共同実行の一体性は不要だから、意思連絡がなくても片面的幇助として成立する。
- 【まぎらわしい選択肢・論点】正当防衛の成否
- 【まぎらわしい選択肢・規範】構成要件モデル（間接正犯類似説）で完全責任
- 【まぎらわしい選択肢・結論】殺人既遂罪 成立／傷害致死罪の単独正犯 成立
- 【まぎらわしい選択肢・事実】原因行為時から一貫した殺意あり／先行行為による作為義務

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

甲＝一連の暴行を重い殺人一個で包括評価（未必の故意○）→ 限定責任能力で39条2項減軽 → 原自行為（責任モデル）だが殺意は減退後に後発＝同一の意思に貫かれた一個の行為といえず排除できない → 殺人罪成立＋39条2項で必要的減軽。乙＝殺意なし→傷害致死の限度／意思連絡なし→共同正犯不成立／黙認で行為支配なし→不作為の幇助（母＝作為義務○・容易性○・困難化の可能性○）／意思連絡不要の片面的幇助 → 傷害致死罪の幇助犯成立。

## 3. 規範クイズ（2問）

- **Q04［ひっかけ］** この論点のひっかけポイントは？
  - 答え：「酒癖を自覚していたのだから完全責任だ」と安易に39条2項を排除して完全責任にするのが最大の落とし穴（−15〜20点）。本問は殺意の発生時期がネックで排除できない。素材判例（長崎地判平4.1.14）は当初から一貫した暴行の意思があった事案で、本問とは違う。
- **Q05［規範］** 不作為犯の作為義務を基礎づけうる事由を挙げよ（一つに限らない）。
  - 模範解答：法令／契約／事務管理／先行行為／排他的支配の設定／社会継続的保護関係 等を総合判断する。本問の乙は親権者・監護権者（民820条）という法令上の保護義務＋排他的保護関係から作為義務が基礎づけられる。

## 4. ○×クイズ（14問）

- **Q06［○×］** 作為犯と異なり、不作為犯（不真正不作為犯）が実行行為性を備えるには、結果発生を防止すべき法的作為義務を負う者であることを要する。
  - 正解：○（正しい）
  - 理由：不作為が作為と構成要件的に同価値といえるための関門が作為義務。誰でも負う一般的道徳義務では足りず、法令・契約・先行行為・排他的支配などから法的作為義務が基礎づけられて初めて不作為が実行行為になる。だから「不作為」とタグ付けした者は作為義務の有無を必ず詰める。
- **Q07［○×］** 行為者が「死んでも構わない」と思いつつ結果発生に至る行為をした場合、結果の発生を認容しているとして殺意（未必の故意）が認められうる。
  - 正解：○（正しい）
  - 理由：故意とは構成要件該当事実の認識・認容。「死んでも構わない」は死亡結果の認識・認容＝未必の故意。確定的な殺意でなくても殺人罪の故意は足りる。
- **Q08［○×］** 暴行が傷害を経て殺害に至った場合は、暴行罪・傷害罪・殺人罪をそれぞれ別個の罪として常に併せて成立させるべきである。
  - 正解：×（誤り）
  - 理由：時間的・場所的に近接しエスカレートした一連の暴行は、最も重い結果（殺人）一個として包括的に評価するのが筋。先行する暴行・傷害は経過として吸収される。
- **Q09［○×］** 制限従属性説によれば、幇助犯（従犯）が成立するには、正犯の行為が構成要件に該当し違法であれば足り、正犯者自身が有責であること（責任能力を備えること）までは要しない。
  - 正解：○（正しい）
  - 理由：共犯従属性（制限従属性説）の帰結。正犯の違法な実行行為に共犯が従属する以上、共犯の成否は正犯の構成要件該当性・違法性で決まり、正犯の責任段階は問わない。だから正犯の罪を先に固めるが、正犯が限定責任能力でも幇助は妨げられない。
- **Q10［○×］** 心神耗弱（限定責任能力）の状態で犯罪行為が行われた場合、犯罪は成立するが、刑が必要的に減軽される（39条2項）。
  - 正解：○（正しい）
  - 理由：39条2項の効果は「刑の必要的減軽」。犯罪自体は成立する。心神喪失（1項）の責任阻却＝不可罰と混同しないこと。
- **Q11［○×］** 責任主義からは、行為者を非難するために、実行行為の時点で責任能力が存在することを要する（実行行為と責任能力の同時存在の原則）。
  - 正解：○（正しい）
  - 理由：「責任なければ刑罰なし」から、実行行為時に責任能力が要る。原因において自由な行為は、この原則の例外（修正）をどう正当化するかの問題。
- **Q12［○×］** 原因において自由な行為の責任モデル（一連の行為説）では、原因行為と結果行為が同一の意思に貫かれた一個の行為と評価し得る場合に完全な責任を問いうる。
  - 正解：○（正しい）
  - 理由：責任非難を原因行為時に遡らせる責任モデルの核心規範。「同一の意思に貫かれた一個の行為」という連続性の要求が、あてはめの分かれ目になる。
- **Q13［○×］** 構成要件モデル（間接正犯類似説）では、限定責任能力下の自己の故意行為も、責任無能力状態の自己を利用する「道具」として完全責任を基礎づけられる。
  - 正解：×（誤り）
  - 理由：限定責任能力下の自己の故意行為は、なお規範的障害を備えた主体の行為であり、これを「道具」と評価するのは困難。構成要件モデルでも適用排除はしにくい。
- **Q14［○×］** 原因行為の時点で結果（殺害）についての故意がまったくなかった場合でも、原因において自由な行為により結果行為について完全な責任を問えるのが原則である。
  - 正解：×（誤り）
  - 理由：原因行為時に当該結果の故意がなければ、原因行為と結果行為を「同一の意思に貫かれた一個の行為」と評価できない。故意の発生時期は適用排除の可否を左右する決定的事実。
- **Q15［○×］** 他人の犯行を傍観していた者は、正犯者と同じ故意（例：殺意）がなくても、常に正犯と同じ罪名（例：殺人）の関与犯となる。
  - 正解：×（誤り）
  - 理由：関与者には自分の故意の限度でしか罪責を負わせられない。殺意のない傍観者に殺人の幇助は認められず、傷害致死などその者の故意に対応した罪の限度で検討する。
- **Q16［○×］** 作為義務ある者が、他人の犯罪を認識しながら阻止せず放置した場合、行為支配が認められない限り、原則として幇助犯（従犯）が成立する。
  - 正解：○（正しい）
  - 理由：原則幇助犯説（判例・有力）。不作為者は通常、結果へ向かう因果経過を支配しておらず正犯性（行為支配）を欠く。単なる黙認は幇助にとどまる。
- **Q17［○×］** 不作為による幇助の因果性は、作為すれば結果を確実に回避できたことまでは要せず、正犯の犯行を困難にできた可能性があれば足りる。
  - 正解：○（正しい）
  - 理由：作為による幇助が正犯行為を「促進・容易化」すれば足りることとの均衡から、不作為幇助の因果性も緩やかに（結果回避可能性＝困難にできた可能性）判断する。確実な結果回避まで要求すると作為の幇助と均衡を欠く。
- **Q18［○×］** 幇助犯が成立するには、必ず正犯者との間に相互の意思連絡（共同実行の意思）が存在することを要する。
  - 正解：×（誤り）
  - 理由：幇助は正犯の犯行を促進・容易にすれば足り、共同正犯のような共同実行の一体性は不要。よって意思連絡のない片面的幇助も肯定される（片面的共同正犯は逆に否定的）。
- **Q19［○×］** 共同正犯（60条）が成立するには、客観的な共同実行の事実に加え、相互の意思連絡（共同実行の意思）が必要である。
  - 正解：○（正しい）
  - 理由：「共同して」（60条）といえるには共同犯行の一体性を基礎づける意思連絡が要る。意思連絡を欠けば共同正犯は成立せず、片面的幇助の可否へ進む。
