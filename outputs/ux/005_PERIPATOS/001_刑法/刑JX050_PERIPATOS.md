## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

暴力団員である甲は、警察の取締りが厳しくなって収入が減り、生活に苦しみ、組への上納金も納められない状態にあった。そこで甲は、国から生活保護費を不正に受給しようと企み、自己の生活状態について虚偽の申告をして、生活保護費を不正に受給した。しかし受給額が思いのほか少なかったため、甲は不満に思っていたところ、羽振りがよかった数年前にAに対して300万円を貸していたことを思い出した。そこで甲はAのもとを訪れて返済を要求したが、Aが素直に応じなかったため、「恩を忘れたのか。今すぐに返さないと東京湾で魚のエサになるぞ。」と脅し、これにより畏怖したAは300万円を返済した。以上の事例における甲の罪責について論ぜよ（特別法は考慮しない）。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 困窮・上納金払えず → 不正受給を企図
- 虚偽申告で生活保護費を受給
- 受給額に不満 → Aへの300万円貸金を想起
- Aへ「東京湾で魚のエサになるぞ」と脅迫
- 畏怖したAが300万円を返済

### 参考（読み上げない。入口の問いの答えを含むので判定にだけ使う）

登場人物：
- 甲｜暴力団員・行為者（→虚偽申告／脅して取立て）
- 国（福祉事務所）｜被害者①＝詐欺の客体
- A｜債務者・被害者②＝恐喝の客体

### 入口の問い（3問）

- **Q01［事案の整理］** 「引っかかる行為」を挙げて
  - 答え：行為①：虚偽申告で生活保護費を受給（客体＝国／福祉事務所）。行為②：「魚のエサ」と脅して300万円を取立て（客体＝債務者A）。
  - 答え：国もAも被害者＝客体。罪責を負うのは甲だけ。各事象を混ぜず、別々に犯罪論を回すのが第一歩。
- **Q02［見当づけ］** 各行為は「何罪っぽい？」 ― 見当をつけて
  - 答え：行為①：虚偽申告で保護費を「受給」＝欺いて財物を交付させた → 詐欺（246条1項）系。行為②：脅して300万円を交付させた → 恐喝（249条1項）系。被害者が国でも、債権があっても、まずは素直に罪名を当てる。
- **Q03［論点］** 各事象の問題になる論点を挙げて（2つ）
  - 答え：CP①（詐欺）：被害者が国。詐欺罪は個人的法益の罪 → 国家的法益に向けられた詐欺の成否。（＝個人の財産を守る罪を、国に向けても使えるか）
  - 答え：CP②（恐喝）：甲は本当にAへの債権を持つ。構成要件は満たすが → 権利行使と恐喝（違法性阻却の可否）。（＝自分の権利の取立てに脅しを使った場合の評価）

### 骨子（3項目。第1から【論点】ごとに、何が問題→規範→使う事実→結論 の順で組み立てる）

#### 第1　国に対する詐欺罪

- 見出しの補足（結論を含む。項目の終わりに読む）：246条1項
1. 虚偽申告で生活保護費を受給 → 詐欺罪を検討
2. 被害者が国 → 【論点】国家的法益に向けられた詐欺の成否
   規範：国も財産主体→構成要件を満たせば成立（特別法排除を除く）
3. あてはめ：欺罔（受給資格という重要事項の虚偽申告）→錯誤→処分（支給決定）→交付→財産的損害
4. 故意（38条1項）・不法領得の意思 ○
- 結論：国に対する詐欺罪 成立

#### 第2　Aに対する恐喝罪

- 見出しの補足（結論を含む。項目の終わりに読む）：249条1項
1. 畏怖させ300万円を交付 → 恐喝罪の構成要件に該当
2. 甲は真にAへの債権あり → 【論点】権利行使と恐喝
   規範：個別財産の罪→該当／①権利の範囲内＋②手段が社会通念上忍容で違法性阻却
3. あてはめ：範囲内（300万＝債権額）だが 殺害の暗示は社会通念上忍容される程度を逸脱 → 阻却なし
- 結論：Aに対する恐喝罪 成立

#### 第3　罪数

   別個の機会・別個の被害者の二罪
- 結論：併合罪（45条前段）

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「虚偽の申告」をして「不正に受給」 → ─ 欺いて財物を得た流れ
- 【拾う事実】『被害者は「国（福祉事務所）」』 → ─ 相手が公的機関という点が引っかかる
- 【拾う事実】『取立額「300万円」＝貸金「300万円」』 → ─ 数値が一致している
- 【拾う事実】「東京湾で魚のエサになるぞ」 → ─ 脅し文句の強さ（生命への言及）
- 【拾う事実】『Aは「畏怖」して「返済」』 → ─ 畏怖から交付への流れ
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 詐欺：欺罔→錯誤→処分→交付→損害の連鎖は事実で確認。恐喝：畏怖→交付は明らか。違法性・責任は阻却事由が無ければ一言で素通り──ただし本問は違法性の段で恐喝のチェックポイントが待つ。
- 【規範の要点】「国家的法益への詐欺」の規範
  - 詐欺罪は個人的法益の罪だが、国・地方公共団体も財産の帰属主体。欺罔で財物を交付させられれば財産的損害を被るから、構成要件を満たす限り国家に向けた欺罔でも詐欺罪が成立する（特別法が独立処罰し詐欺罪適用を排除する場合は別論）。
- 【効く事実】効く事実（五段に当てる）
  - 欺罔 → 受給資格という「交付の判断の基礎となる重要事項」を虚偽申告／錯誤 → 実施機関が受給資格ありと誤信／処分 → 支給決定／交付 → 保護費を給付／損害 → 受給資格なき者への給付＝相当額の財産的損害。
- 【規範の要点】恐喝罪説の規範
  - 恐喝罪は個別財産に対する罪だから、権利行使でも畏怖させて交付させれば構成要件に該当。もっとも、①権利の範囲内であり、②方法が社会通念上一般に忍容すべき程度を超えない限り違法性は阻却される（最判昭30.10.14）。逸脱すれば恐喝罪成立。
- 【効く事実】効く事実（二段で評価）
  - ①権利の範囲 → 取立額300万円＝貸金債権額300万円＝範囲内（適法方向）／②手段の相当性 → 「東京湾で魚のエサになる」＝生命への加害を暗示する害悪の告知＝社会通念上忍容される程度を逸脱。範囲内なのに違法という二段評価が判例理解の核。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 複数の罪が成立したら最後に罪数処理を一言。観念的競合（54条前段）／牽連犯（54条後段）／併合罪（45条）のどれかを一文で示す。本問のように行為・機会・被害者が別個なら迷わず併合罪。
- 【まぎらわしい選択肢・論点】窃盗罪と詐欺罪の区別／不法領得の意思の要否
- 【まぎらわしい選択肢・規範】権利の範囲内なら常に不可罰（無罪説）／全体財産に対する罪
- 【まぎらわしい選択肢・事実】取立額が債権額を超過／反抗を抑圧する程度の脅迫
- 【まぎらわしい選択肢・結論】詐欺罪 不成立／恐喝罪 不成立（脅迫罪のみ）／観念的競合（54条前段）

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

詐欺＝虚偽申告で生活保護費を受給。国も財産主体→構成要件充足で詐欺成立。恐喝＝畏怖させ300万円交付で構成要件該当。権利の範囲内（=債権額）でも、殺害暗示は手段が社会通念上忍容の程度を逸脱→違法性阻却なし→恐喝成立。罪数＝別個の機会・被害者の二罪→併合罪（45条前段）。

## 3. 規範クイズ（2問）

- **Q04［規範］** 公的給付（生活保護費等）を虚偽申告で不正受給した場合に詐欺罪が成立する理由を、規範の形で一言で述べよ。
  - 模範解答：国も財産の帰属主体であり、欺罔により財物を交付させられれば財産的損害を被る。よって詐欺の構成要件を満たす限り、国家に向けた欺罔的行為でも詐欺罪が成立する（特別法排除がある場合を除く）。
- **Q05［規範］** 権利行使と恐喝につき、違法性阻却が認められるための二要件を判例の文言で挙げよ。
  - 模範解答：①その権利の範囲内であり、かつ②その方法が社会通念上一般に忍容すべき程度を超えないこと。両方そろって初めて違法性阻却。片方でも欠ければ恐喝罪成立。

## 4. ○×クイズ（11問）

- **Q06［○×］** 詐欺罪・恐喝罪は「個別財産に対する罪」であり、財産的損害の有無は、被害者ごと・交付ごとに個別に判断される。
  - 正解：○（正しい）
  - 理由：個別財産説では、個々の交付（財産的処分）それ自体が損害評価の単位。だから被害者・機会の異なる事象は損害も別々に立つ＝事象ごとに犯罪論を回すべき理論的根拠となる（全体財産説なら差引計算になる）。
- **Q07［○×］** 「甲の罪責を論ぜよ」と問われた場合でも、被害を受けた相手方（客体）の側の罪責を併せて検討する必要がある。
  - 正解：×（誤り）
  - 理由：「甲の罪責を論ぜよ」では検討の主体は甲だけであり、被害者（客体）の側の罪責は論点にならないため、答案が問うていない者の犯罪成否まで書くと論点漏れではなく余事記載として評価されない。客体は罪名の選択・損害の帰属先として位置づければ足りる。
- **Q08［○×］** 詐欺罪も恐喝罪も、被害者自身の交付（処分行為）を介して財物を得る点で共通し、この点で被害者の意思によらず占有を奪う窃盗・強盗と区別される。
  - 正解：○（正しい）
  - 理由：詐欺・恐喝はいずれも「交付罪」＝被害者の瑕疵ある意思に基づく処分行為が介在する。処分行為を介さず占有を奪えば窃盗・強盗（盗取罪）。この処分行為の有無が罪名選択の分水嶺になる。
- **Q09［○×］** 暴行・脅迫が相手の反抗を抑圧する程度に至り財物を奪った場合は、恐喝罪ではなく強盗罪を検討すべきである。
  - 正解：○（正しい）
  - 理由：脅迫が反抗抑圧の程度に達し意思を抑圧して奪取＝強盗。畏怖させ被害者が自ら交付＝恐喝。手段の「程度」で線を引く。
- **Q10［○×］** 数個の罪が「1個の行為」によって実現されたか否かは、構成要件的評価を離れた自然的観察のもとで行為が1個と評価できるかで判断され、これにより観念的競合（54条前段）と併合罪（45条前段）が分かれる。
  - 正解：○（正しい）
  - 理由：判例の行為標準説。1個の行為が数罪に当たれば観念的競合（科刑上一罪）、行為が複数なら併合罪。機会・被害者が異なり行為も別個なら併合罪となる。罪数は各罪の成立を確定してから判断する。
- **Q11［○×］** 詐欺罪の客観的構成要件は「欺罔行為→錯誤→処分行為→財物の交付→財産的損害」という因果の連鎖として捉えられる。
  - 正解：○（正しい）
  - 理由：この五段の連鎖（ギ・サ・ショ・コウ・ソン）を一つずつ事実と結合させるのが詐欺のあてはめ。どこか1つでも切れれば詐欺は成立しない。
- **Q12［○×］** 被害者の処分（交付）行為を介して財物を得れば詐欺、処分行為を介さず占有を奪えば窃盗である。
  - 正解：○（正しい）
  - 理由：処分行為の有無が詐欺と窃盗の分水嶺。本問は実施機関の支給決定という処分を介して金銭が移転しているから詐欺。
- **Q13［○×］** 交付の判断の基礎となる重要事項を偽って公的給付を受けた場合、給付された金額が客観的な対価に見合っていても、給付目的に反する財産の喪失をもって財産的損害が認められる。
  - 正解：○（正しい）
  - 理由：実質的個別財産説。詐欺罪は個別財産に対する罪だから、財産的損害は経済的な差引き計算ではなく、交付者が設定した給付目的に反して財産的処分をさせられたこと自体で判断する。ゆえに給付額が客観的な対価に見合っていても、受給資格なき者への給付は給付目的に反する以上、財産的損害が肯定され詐欺罪が成立する。逆に給付目的に反しなければ損害は否定される。
- **Q14［○×］** 恐喝罪説に立つ場合、債権額を超える金額を畏怖させて喝取したときは、債権額を超過する部分についてのみ恐喝罪が成立する。
  - 正解：×（誤り）
  - 理由：恐喝罪は個別財産に対する罪であり、畏怖による交付という1個の財産的処分を全体として捉える。よって債権額を超えて喝取した場合は、超過分のみならず交付させた全額について恐喝罪が成立する。「超過分だけ犯罪」とするのは誤り。
- **Q15［○×］** 恐喝罪は個別財産に対する罪だから、債権という反対給付があり全体財産が減らなくとも、畏怖により本来しなくてよい財産的処分を強いられれば財産的損害が認められる。
  - 正解：○（正しい）
  - 理由：これが恐喝罪説の核心。個別財産説に立つから、畏怖による任意でない処分それ自体が損害。これにより脅迫罪説・無罪説は排斥される。
- **Q16［○×］** 複数の罪が併合罪となる場合、各罪に定められた刑を単純に合算したものが、そのまま処断刑の上限となる。
  - 正解：×（誤り）
  - 理由：併合罪加重は単純合算ではない。有期の懲役・禁錮では、最も重い罪につき定めた刑の長期にその2分の1を加えたものを長期とし、かつ各罪の長期の合計を超えない（47条）。観念的競合・牽連犯（科刑上一罪）なら最も重い刑で処断する（54条1項）。
