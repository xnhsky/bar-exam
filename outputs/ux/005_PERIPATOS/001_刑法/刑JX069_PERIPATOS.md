  - 「罪を犯した者」 → 甲は被疑者として逮捕・留置／「隠避」 → 「真犯人は自分だ」と虚偽出頭し釈放を図る／危険犯 → 警察が取り合わず釈放されず＝結果不要で処理／甲の教唆 → 事前に身代わりを依頼し承諾させた。
- 【規範の要点】可罰説の規範
  - 共犯の処罰根拠は正犯を介した間接的な法益侵害にある → 正犯（乙）に犯罪が成立する以上、これを教唆した犯人は法益侵害を惹起 → 犯人自身による隠避教唆も可罰（大判昭8.10.18）。殺人罪とは併合罪。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 乙の場面の「逮捕勾留中の者」も、丙の場面の「無実の嫌疑者」も、同じ広義の刑事司法作用から導く。丙では故意（無実の認識）の処理を忘れない。
- 【まぎらわしい選択肢・論点】正当防衛の成否／共同正犯の成否／親族による特例（105条）
- 【まぎらわしい選択肢・結論】犯人隠避罪 不成立／証拠隠滅罪 成立
- 【まぎらわしい選択肢・規範】狭義説／侵害犯
- 【まぎらわしい選択肢・事実】真犯人／意思連絡なし

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

乙＝広義の刑事司法作用、拘束中の者も「罪を犯した者」、身柄拘束を免れさせる行為も「隠避」、抽象的危険犯で釈放されずとも成立、犯人隠避罪。甲＝殺人は一文、犯人自身は不可罰だが共犯の処罰根拠＝正犯を介した法益侵害で可罰、教唆で構成、殺人と併合罪。丙＝隠れ家提供は蔵匿、嫌疑者も「罪を犯した者」（広義説）、嫌疑者の認識ありで故意阻却なし、犯人蔵匿罪。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 犯人蔵匿等罪（103条）の保護法益と、そこから導かれる「罪を犯した者」の射程を述べよ。
  - 模範解答：保護法益＝捜査・審判・刑の執行等、広義における刑事司法の作用。ここから「罪を犯した者」には①逮捕勾留中の者（最決平元.5.1）、②嫌疑を受け捜査・訴追中の者（最判昭24.8.9）も含むと広く解する。
- **［規範クイズ 2/3］** 「隠避」の定義と、本罪が侵害犯か危険犯かを述べよ。
  - 模範解答：「隠避」＝蔵匿以外の方法により官憲による発見・逮捕を免れしめるべき一切の行為。本罪は抽象的危険犯で、「免れさせるような性質の行為」で足り現実に免れさせた結果は不要。
- **［規範クイズ 3/3］** 犯人自身による隠避教唆が可罰となる理由（共犯の処罰根拠）を述べよ。
  - 模範解答：共犯の処罰根拠は正犯を介した間接的な法益侵害（惹起説）にある。正犯（乙）に犯罪が成立する以上、これを教唆した犯人は法益侵害を惹起しており、他人利用は防御権の濫用。よって犯人自身でも隠避教唆は可罰（大判昭8.10.18）。

## 4. ○×クイズ（全3問・1問目から最後まで全部出す）

- **［○×クイズ 1/3］** 犯人蔵匿等罪（103条）における「蔵匿」と「隠避」は同義であり、両者を区別する実益はない。
  - 正解：×（誤り）
  - 理由：「蔵匿」は官憲の発見・逮捕を免れるべき隠れ場所の提供をいい、「隠避」は蔵匿以外の方法による発見・逮捕妨害の一切をいう。隠れ家提供は蔵匿、身代わり出頭・変装・逃走資金提供等は隠避。行為態様で正しく振り分けるのが第一歩。
- **［○×クイズ 2/3］** 犯人が他人を教唆して自己を蔵匿・隠避させた場合、判例は、その犯人に犯人蔵匿・隠避罪の教唆犯が成立するとする（可罰説）。
  - 正解：○（正しい）
  - 理由：大判昭8.10.18は可罰説に立ち、判例は一貫している。犯人自身による単独の隠避は不可罰だが、他人を教唆して罪を犯させた以上、共犯の処罰根拠（正犯を介した法益侵害）から教唆犯の責任を免れない。
- **［○×クイズ 3/3］** 真犯人でなくても、犯罪の嫌疑を受けて捜査・訴追されている者をかくまえば、犯人蔵匿罪（103条）の客体「罪を犯した者」を蔵匿したことになりうる。
  - 正解：○（正しい）
  - 理由：最判昭24.8.9の広義説。103条は刑事司法作用の妨害を処罰する趣旨で、真犯人かは裁判で初めて確定するから、嫌疑を受け捜査中の者も「罪を犯した者」に含む。これを否定すると立法目的を達せない。
