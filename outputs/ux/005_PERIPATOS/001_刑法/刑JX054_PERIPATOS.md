## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

甲は、Aを殺害しようと考え、乙にA殺害を依頼し、その準備資金として現金100万円を交付した。乙は、その妻丙と二人で、この100万円を遊興費等として費消した。その後、乙は、実際にはAを殺害していないのに、甲に対し「Aを殺害した」と申し向けて報酬を請求し、これを信じた甲から報酬名目で現金200万円を受け取った。乙は、そのうち100万円を妻丙に与えた。乙及び丙の罪責を論ぜよ（甲の罪責は問わない）。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 甲が乙にA殺害を依頼し、準備資金として100万円を交付
- 乙が妻丙と二人で、その100万円を費消
- 乙が「Aを殺害した」と偽り、甲から報酬名目で200万円を騙取
- 乙が、騙取した200万円のうち100万円を丙に交付

### 参考（読み上げない。入口の問いの答えを含むので判定にだけ使う）

登場人物：
- 甲｜依頼者（殺害を依頼・金銭を交付）＝対象外
- 乙｜実行役（100万円を費消・200万円を騙取）
- 丙｜乙の妻（100万円を共に費消・100万円を受領）
- A｜殺害の対象＝対象外

### 入口の問い（3問）

- **［入口 1/3・事案の整理］** 登場人物と「お金の動き」を挙げて
  - 答え：設問は「乙及び丙の罪責を論ぜよ」。甲は明示的に罪責を問われていない＝検討対象から外す。Aは殺害の対象（被害者）で対象外。
  - 答え：拾う行為は金額で3つ：①乙・丙が100万円を費消／②乙が200万円を騙取／③乙が丙へ100万円を交付。同一人物でも財産移転ごとに別個に検討する。
- **［入口 2/3・見当づけ］** 各行為は「何罪っぽい？」 ― 見当をつけて
  - 答え：①乙が預かった100万円を費消＝横領（252条）系／②乙が嘘で200万円を交付させた＝詐欺（246条）系／③丙が乙の犯罪収益100万円を受領＝盗品等関与（256条）系。
- **［入口 3/3・論点］** 本問で問題になる論点を挙げて（4つ）
  - 答え：CP①：横領の客体「他人の物」。給付済みの100万円は不法原因給付物 → 不法原因給付物の他人性。（＝民708条で返還請求できない物を、刑法で「他人の物」として保護できるか）
  - 答え：CP②：詐欺の客体。200万円は騙取前は正常財産 → 不法原因給付と詐欺。（＝騙取と同時に不法原因給付化＝独立論点不要という処理）
  - 答え：CP③：丙は占有者でない → 共犯と身分（65条1項）。（横領＝真正身分犯への非身分者の加功）
  - 答え：CP④：丙の受領した詐取金の盗品性＋配偶者 → 盗品性と親族特例（257条1項）。（追求権が消えても盗品か／親族なら刑免除）

### 組み立ての順序（入口の問いのあと、骨子に入る前に読み上げる）

- 順番：第1　乙の罪責 → 第2　丙の罪責
- 第1　乙の罪責
  - 論点1：不法原因給付物の他人性
  - 論点2：不法原因給付と詐欺
- 第2　丙の罪責
  - 論点1：共犯と身分（65条1項）
  - 論点2：不法原因給付物の盗品性
  - 論点3：親族特例（257条1項）

この順番の理由（参考。結論・配点には触れず、一言で言い直す）：共犯・身分が絡む者は、その前提となる正犯の成否を先に固める。本問は 乙（横領→詐欺）を単独で先に → 丙（共犯・身分・親族特例）を後に。

### 骨子（2項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　乙の罪責

1. 預かった100万円の費消 → 委託物横領罪（252条1項）
   ├ 客体「他人の物」① 金銭 → 使途を定めた委託金＝なお甲の物（短く）
   - あてはめ：客体「他人の物」② → 不法原因給付物の他人性
   規範：民法と刑法は規律目的を異にし過罰 → 委託物横領罪 成立
2. 200万円の取得 → 一項詐欺罪（246条1項）
   - あてはめ：不法原因給付と詐欺
   規範：騙取と不法原因給付化は同時＝独立論点不要（同時説）
   あてはめ：200万円は騙取前は正常財産 → 一項詐欺罪 成立
3. 横領と詐欺は 併合罪（45条前段）

#### 第2　丙の罪責

1. 100万円の共同費消 → 横領罪の共同正犯（252条1項・60条）
   - あてはめ：丙＝非占有者 → 共犯と身分（65条1項）
   規範：横領＝真正身分犯・占有者は構成的身分
   あてはめ：乙と二人で費消＝共同実行 → 横領罪の共同正犯 成立
2. 100万円の受領 → 盗品等無償譲受け罪（256条1項）
   - あてはめ：不法原因給付物の盗品性
   規範：追求権＋本犯助長性
   あてはめ：詐取金の無償移転 → 盗品性肯定 → 盗品等無償譲受け罪 成立
   - あてはめ：親族特例（257条1項）
   規範：本犯者との親族関係＝一身的処罰阻却事由
   あてはめ：その妻丙＝本犯者乙の配偶者 → 刑の免除（犯罪は成立）

  - 「丙と二人でその100万円を費消」＝共同実行（65条1項）／「そのうちの100万円を与えた」＝詐取金の無償移転（256条1項）／「その妻丙」＝本犯者乙の配偶者（257条1項）。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 同一人に複数の罪が立ったら最後に罪数処理を一言。観念的競合（54条前段）／牽連犯（54条後段）／併合罪（45条）のどれかを一文で。本問の乙は横領と詐欺が別個の行為なので併合罪。本犯者は自ら得た収益につき盗品等罪の主体にならない（不可罰的事後行為）点も一言で押さえる。
- 【まぎらわしい選択肢・論点】金銭の所有と占有の一致による窃盗罪の客体性／不法原因給付物の返還請求権の存否／詐欺罪における財産的損害の要否
- 【まぎらわしい選択肢・結論】横領罪は不成立（不可罰）／詐欺罪は不成立／盗品等罪は不成立
- 【まぎらわしい選択肢・規範】占有離脱物横領（252条2項）として処理／65条2項で加減的身分として科刑を個別化
- 【まぎらわしい選択肢・事実】甲が乙にA殺害を依頼した事実／乙が実際にはAを殺害していない事実

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

乙＝使途を定めた委託金100万を費消。不法原因給付物でも、民法と刑法は規律目的が別（過罰説）で「他人の物」→委託物横領罪成立。さらに「Aを殺した」と偽り200万を騙取（不法原因給付化と騙取は同時＝同時説）→一項詐欺成立。両者は併合罪（45条前段）。丙＝乙と二人で100万を共同費消。非占有者だが横領は真正身分犯で65条1項により横領罪の共同正犯成立。詐取金100万を無償受領→追求権＋本犯助長性で盗品性肯定→盗品等無償譲受け罪成立。ただし本犯者乙の配偶者ゆえ257条1項で刑免除（犯罪は成立）。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 不法原因給付物について横領罪を肯定する過罰説の規範を、理由づけまで含めて書けるか。
  - 模範解答：規範　民法は私人間の利得調整を、刑法は財産的秩序の保護を目的とし、両者は規律目的を異にする。委託を受けて他人のために金銭を占有する者がこれを着服する行為は、その原因の不法を問わず財産的秩序を侵害する。よって不法原因給付物もなお横領罪の「他人の物」に当たる。
- **［規範クイズ 2/3］** 丙が受領した詐取金（不法原因給付物）の盗品性を肯定する理由を、盗品等関与罪の処罰根拠から書けるか。
  - 模範解答：規範　盗品等関与罪は被害者の追求権侵害のみならず、本犯による違法な財産状態を維持・助長する点をも処罰根拠とする。丙の受領はまさに違法状態を維持・助長するものであるから、追求権が708条で消えていてもなお盗品性を肯定できる。
- **［規範クイズ 3/3］** 257条1項の法的性質と、同条の親族関係の主体（誰と誰の間に必要か）を書けるか。
  - 模範解答：規範　257条1項は親族間の情誼を考慮した一身的処罰阻却事由であり、犯罪の成立自体は妨げない（刑の免除）。同条の親族関係は、盗品等関与罪を犯した者と本犯者との間に存することを要する。本問では盗品関与者丙と本犯者乙とが配偶者であるから、257条1項により丙の刑は免除される。

## 4. ○×クイズ（全13問・1問目から最後まで全部出す）

- **［○×クイズ 1/13］** 同一人物が複数回にわたり財産を取得・処分した事案では、金額や客体ごとに行為を切り分け、それぞれ別個に罪責を検討するのが基本である。
  - 正解：○（正しい）
  - 理由：行為ごとに構成要件該当性を検討する。本問の乙も「100万円費消（横領）」と「200万円取得（詐欺）」は別個の行為として切り分ける。
- **［○×クイズ 2/13］** 他人から使途を定めて預かった金銭を、自己の用途に費消した行為は、まず横領罪（252条）系の成否を疑うのが筋である。
  - 正解：○（正しい）
  - 理由：横領罪（252条）の客体は「委託に基づき自己が占有する他人の物」であり、使途を定めて預けられた金銭はなお委託者に属する他人の物だから、これを自己の用途に費消すれば不法領得の意思の発現という要件を満たし、委託物横領の成否をまず疑うのが結論となる。
- **［○×クイズ 3/13］** Bは、Cが詐欺で得た金であると知りながら、Cからその金を無償でもらい受けた。Bには盗品等無償譲受け罪（256条1項）の成否が問題となる。
  - 正解：○（正しい）
  - 理由：詐欺は「財産に対する罪」であり、その騙取金は盗品等（財産罪により領得された物）に当たりうる。無償で受領すれば256条1項を疑う。
- **［○×クイズ 4/13］** 制限従属性説によれば、狭義の共犯（教唆・幇助）が成立するには、正犯の行為が構成要件に該当し違法であれば足り、正犯が有責であることまでは要しない。
  - 正解：○（正しい）
  - 理由：共犯は正犯の違法な実行行為に従属して成立する（共犯従属性）。だから正犯の成否を先に固める必要がある。なお本問の丙は共同正犯（60条）＋身分（65条1項）の局面だが、「共犯は正犯を前提に考える」という発想は従属性に由来する。
- **［○×クイズ 5/13］** 金銭は占有と所有が一致するから、他人から預かった金銭はおよそ横領罪の客体である「他人の物」に当たらない。
  - 正解：×（誤り）
  - 理由：使途を定めて委託された金銭は、なお委託者の所有に属し「他人の物」に当たる（通説・判例）。ここは小論点で短く処理する。
- **［○×クイズ 6/13］** 民法708条により給付者が返還を請求できない不法原因給付物は、その反射的効果として受給者に所有権が移るので、刑法上も当然に横領罪の「他人の物」には当たらない。
  - 正解：×（誤り）
  - 理由：民法上の所有権移転（最大判昭45.10.21）に刑法が従属する必然はない。刑法は財産的秩序の保護という独自目的をもつから、なお「他人の物」と評価しうる（過罰説）。
- **［○×クイズ 7/13］** 欺罔により交付させた金銭が、結果として不法な目的の報酬だったとしても、騙取の時点ではいまだ正常な財産だから、「不法原因給付物に詐欺が成立するか」を独立に論じる必要はない。
  - 正解：○（正しい）
  - 理由：騙取される財物が給付前は被害者の正常な財産だった場合、詐欺罪の成立と不法原因給付物化とは同時に生じる（同時説）から、「不法原因給付物に詐欺が成立するか」を独立の論点として立てる必要はない。既に給付済みで客体性が問題となる横領との事案の区別がここにある。
- **［○×クイズ 8/13］** 横領罪は真正身分犯だから、占有者でない者は、占有者と意思を通じて共同しても横領罪の共同正犯にはおよそなりえない。
  - 正解：×（誤り）
  - 理由：占有者たる身分は構成的身分だが、65条1項により非身分者も構成的身分犯に加功すれば共犯となる。丙も横領の共同正犯となりうる。
- **［○×クイズ 9/13］** 不法原因給付物について横領罪を肯定する過罰説の理由づけは、「民法と刑法は規律目的を異にする」点に求めるべきで、単に結論を宣言するだけでは足りない。
  - 正解：○（正しい）
  - 理由：民法（私人間の利得調整）と刑法（財産的秩序の保護）は目的を異にし、結論の不一致は許容される。この理由づけまで書いて初めて点になる。
- **［○×クイズ 10/13］** 不法原因給付物の横領を肯定するには、民法708条で返還請求できず所有権が反射的に移転しうる点に一旦言及した上で、刑法独自の理由づけで「他人の物」性を肯定する筋がよい。
  - 正解：○（正しい）
  - 理由：反射的移転（最大判昭45）を一旦受け止めてから過罰説で乗り越えると論理が明快。
- **［○×クイズ 11/13］** 盗品等関与罪の親族特例（257条1項）は犯罪の成立自体を否定するものではなく、刑を免除する一身的処罰阻却事由にすぎない。
  - 正解：○（正しい）
  - 理由：257条1項は親族間の情誼を考慮した刑の免除。犯罪は成立する。「犯罪不成立」と書くと誤り。
- **［○×クイズ 12/13］** 盗品等関与罪の保護法益を被害者の追求権のみと解すると、不法原因給付物は追求権が消えているため盗品性を肯定できず、丙は無罪となるほかない。
  - 正解：×（誤り）
  - 理由：追求権侵害に加え本犯による違法な財産状態の維持・助長も処罰根拠とすれば、追求権が消えても盗品性を肯定できる。追求権一本に頼ると行き詰まる。
- **［○×クイズ 13/13］** 財産犯の本犯者自身は、自ら得た犯罪収益を後にさらに処分・取得しても、盗品等関与罪の主体とはならない。
  - 正解：○（正しい）
  - 理由：本犯者の事後処分は不可罰的事後行為。乙は詐欺の本犯だから、自分の詐取金を費消・交付しても盗品等罪は成立しない。盗品等罪が問題となるのは受領した丙の側。
