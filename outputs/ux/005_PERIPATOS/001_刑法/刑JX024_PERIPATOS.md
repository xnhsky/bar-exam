## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

甲は、空き巣を生業としている者であるが、ある日、不法残留者である乙（41歳）、丙（39歳）及び丁（16歳）が甲のところに訪れ、「祖国に帰るためのお金がないから、空き巣をやろうと思う。コツを教えてほしい。」などと頼まれた。甲は乙らの境遇に同情し、協力してやろうと考えたため、乙らに対し、自己が作成した家宅の施錠を解錠するための道具であるピックを交付し、「留守宅を見つけたら、これを使って鍵を開けなさい。」と言った。乙は、ピックを持ってA宅前まで来たが、自分には使いこなせないと考えて使わず、うろうろしていたところ偶然裏口が施錠されていないことに気付き、裏口から侵入して現金10万円を持ち去った。丙は、ピックを持ってB宅前まで来たが、警察に捕まったら大変だと恐くなり、何もすることなくその場を立ち去った。丁は、甲から渡されたピックを用いてC宅の玄関の施錠を解錠して侵入し、テーブル上の腕時計を持ち去った。甲、乙、丙及び丁の罪責について論じなさい。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 乙・丙・丁が甲に「空き巣のコツを教えて」と依頼
- 甲が自作ピックを交付し「これで鍵を開けなさい」と言う
- 乙：使いこなせないと考え未使用 → 偶然の裏口から侵入・現金10万円窃取
- 丙：恐くなり何もせず立ち去る（着手なし）
- 丁：ピックでC宅を解錠・侵入し腕時計を窃取

### 参考（読み上げない。入口の問いの答えを含むので判定にだけ使う）

登場人物：
- 甲｜空き巣の常習者（→ピックを交付した幇助者）
- 乙｜正犯（→ピック未使用・偶然開いた裏口から窃盗）
- 丙｜正犯候補（→恐くなって着手前に離脱）
- 丁｜正犯（→ピックで解錠して窃盗）

一行要約：甲が乙丙丁にピックを交付。乙＝未使用・偶然の裏口で窃盗、丙＝着手前に離脱、丁＝ピックで窃盗。

### 入口の問い（3問）

- **Q01［事案の整理］** 登場人物と「引っかかる行為」を挙げて
  - 答え：行為をしたのは4人全員。乙＝裏口から窃盗／丙＝着手前に離脱／丁＝ピックで窃盗が正犯側、甲＝ピック交付が共犯側。
  - 答え：同じ1個のピック交付でも、乙・丙・丁で結論が分かれるのが本問の肝。ここを意識して拾う。
- **Q02［見当づけ］** 各行為は「何罪っぽい？」 ― 見当をつけて
  - 答え：乙・丁：他人の家に侵入して財物を持ち去り → 住居侵入（130条前段）＋窃盗（235条）。丙：着手前に立ち去り → 不可罰の疑い。甲：道具を渡しただけ → 幇助犯（62条1項）系。
- **Q03［論点］** 三者で問題になる論点を挙げて（3つ）
  - 答え：CP①（乙）：ピック未使用・偶然の裏口 → 幇助の因果性の有無。（因果性＝幇助行為が正犯の実行を物理的・心理的に促進・容易にしたか）
  - 答え：CP②（丙）：着手前に離脱＝正犯不成立 → 正犯なき共犯・共犯従属性。（従属性＝正犯が実行に着手して初めて共犯も処罰できる）
  - 答え：CP③（丁）：ピックで現に解錠 → 因果性肯定で幇助成立 → 幇助犯の罪数。

### 骨子（4項目。第1から【論点】ごとに、何が問題→規範→使う事実→結論 の順で組み立てる）

#### 第1　乙・丙・丁の罪責

- 見出しの補足（結論を含む。項目の終わりに読む）：前提・正犯
1. まず正犯を確定する。甲の幇助を論じる前提として、手を下した乙・丙・丁の罪責を確定する。
2. 乙はA宅裏口から立ち入り現金を窃取、丁はC宅をピックで解錠し腕時計を窃取＝いずれも住居侵入・窃盗の構成要件に該当 → 結論：乙・丁に住居侵入罪（130前段）・窃盗罪（235）が成立し牽連犯（54条1項後段）。丁が16歳でも責任年齢14歳で影響なし。
3. 丙は恐くなって何もせず立ち去り住居侵入・窃盗の実行に着手していない → 結論：丙は不可罰（着手なし＝未遂すら不成立）。

#### 第2　甲の乙に対する幇助

- 見出しの補足（結論を含む。項目の終わりに読む）：幇助の因果性
1. 幇助の因果性が入口。乙に正犯は成立するが、ピックは使われていない。甲のピック交付が乙の犯行を「幇助した」といえるかを問題にする。
2. 【論点】幇助の因果性（共犯の処罰根拠）（規範：共犯の処罰根拠は正犯者を媒介し間接的に法益侵害結果を惹起する点にある〔因果的共犯論〕。よって幇助には因果性が必要で、正犯の実行を物理的又は心理的に促進・容易にしたことで足りる）
   - あてはめ：乙はピックを使わず偶然の裏口から侵入＝物理的因果性なし、「使いこなせない」と考えていた＝心理的因果性もなし
- 結論：甲に乙に対する幇助犯は不成立。

#### 第3　甲の丙に対する幇助

- 見出しの補足（結論を含む。項目の終わりに読む）：正犯なき共犯
1. 【論点】正犯なき共犯・共犯の従属性（規範：共犯行為のみでは結果発生の現実的危険性に乏しいから、正犯が実行に着手して初めて共犯も処罰しうる〔共犯従属性説〕）
   - あてはめ：丙は実行に着手しておらず正犯が成立しない＝従属すべき正犯の実行行為が存在しない
- 結論：甲に丙に対する幇助犯は不成立（乙＝因果性なしと理由を異にする）。

#### 第4　甲の丁に対する幇助と罪数

1. 【論点】因果性肯定と幇助犯の罪数 → 丁は現にピックを用いて解錠・侵入＝物理的因果性あり、空き巣の助言とあいまって心理的因果性もあり → 結論：甲に丁の住居侵入・窃盗の幇助犯が成立。罪数は正犯の牽連犯に対応して牽連犯（観念的競合でも科刑上一罪）。
2. → 結論：甲は乙・丙に幇助不成立、丁への幇助犯（牽連犯）のみ成立と総括。

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】『乙「使いこなせないだろう」と考え未使用』 → 乙への心理的因果性を分ける
- 【拾う事実】『乙は偶然開いていた裏口から侵入』 → 乙への物理的因果性を分ける
- 【拾う事実】『丙は恐くなり何もせず立ち去った』 → 丙の実行の着手の有無
- 【拾う事実】『丁はピックを用いて解錠・侵入』 → 丁への物理的因果性の存在
- 【拾う事実】『甲は1個のピック交付で乙丙丁に関与』 → 丁の幇助犯の罪数
- 【事案の整理】正犯と共犯を仕分ける
  - 手を下したのは乙・丙・丁＝正犯側。道具（ピック）を渡しただけの甲＝共犯側。共犯は正犯の存在を前提とするから、正犯を先に・甲を後に並べる。
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 幇助行為＝ピック交付で共通／故意＝空き巣の手助けの認識あり＝一言で素通り。差がつくのは因果性。乙・丙・丁で因果性・従属性が違うから、ここを各人で割る。
- 【効く事実】あてはめで使う事実
  - 乙＝「使いこなせない」と考え未使用・偶然の裏口（物理的因果性も心理的因果性もなし）／丙＝恐くなって着手前に離脱（正犯の実行着手なし）／丁＝現にピックで解錠（物理的因果性あり）。
- 【ポイント】不成立でも理由が違う
  - 乙＝因果性なし／丙＝正犯なき共犯（従属性）。結論は同じ「不成立」でも理由が別と書き分けられるかが上位答案の分かれ目。
- 【規範の要点】共犯従属性説の規範
  - 共犯の処罰根拠は正犯者を媒介して犯罪実現に加担する点にあり、共犯行為のみでは結果発生の現実的危険性に乏しい → 正犯が実行に着手して初めて共犯も処罰しうる。丙は着手していない＝正犯なき共犯として甲は不可罰。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 正犯（丁）の住居侵入＋窃盗が牽連犯だから、対応する幇助も牽連犯とする（大判大6.10.1）。幇助行為自体は1個だとして観念的競合とする見解もあるが、いずれでも科刑上一罪で結論は変わらない。一文で触れれば足りる。
- 【まぎらわしい選択肢・論点】共謀共同正犯の成否／中止未遂の成否／錯誤による故意阻却
- 【まぎらわしい選択肢・結論】窃盗未遂罪 成立／住居侵入幇助のみ 成立
- 【まぎらわしい選択肢・規範】共犯独立性説／結果無価値論
- 【まぎらわしい選択肢・事実】意思連絡あり／正犯の実行着手あり

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

正犯＝乙・丁は侵入＋窃盗（牽連犯）、丙は着手なしで不可罰。甲→乙＝処罰根拠から因果性、ピック未使用で物理なし・励ましなしで心理なし＝幇助不成立。甲→丙＝正犯なき共犯（従属性）で不成立。甲→丁＝ピック使用で因果性あり＝幇助成立、罪数は牽連犯。

## 3. 規範クイズ（2問）

- **Q04［規範］** 幇助犯の成立に必要な「幇助の因果性」の内容（2類型）を挙げよ。
  - 模範解答：①物理的因果性（道具・手段としての寄与＝正犯の実行を物理的に促進・容易にした）／②心理的因果性（励まし・犯意の強化）。いずれも認められない場合に幇助は不成立。条件関係まで（「あれなければ」）は不要で、促進・容易化で足りる。
- **Q05［規範］** 共犯の処罰根拠を説明する因果的共犯論（惹起説）の内容を一言で述べよ。
  - 模範解答：共犯は、正犯者を媒介して間接的に法益侵害結果又はその危険を惹起する点に処罰根拠がある。ここから共犯行為と正犯結果との間の因果性が必要であることが導かれる。規範定立は必ずこの処罰根拠から書き起こす。

## 4. ○×クイズ（4問）

- **Q06［○×］** 住居侵入罪と窃盗罪が成立する場合、両罪は手段・結果の関係に立ち、牽連犯（54条1項後段）として科刑上一罪となる。
  - 正解：○（正しい）
  - 理由：住居侵入は窃盗の手段として行われるのが通常で、判例は両罪を目的・手段の関係に立つ牽連犯（54条1項後段）として処理する。最も重い刑で処断される科刑上一罪。財産犯の事案で頻出の罪数処理。
- **Q07［○×］** 道具を提供する幇助行為があれば、正犯がその道具を実際に使ったか否かを問わず、当然に幇助犯が成立する。
  - 正解：×（誤り）
  - 理由：幇助犯の成立には幇助行為と正犯結果との間の因果性（物理的又は心理的促進）が必要。道具を渡しても正犯がそれを使わず、励ましにもなっていなければ因果性を欠き幇助は成立しない。
- **Q08［○×］** 共犯従属性説によれば、正犯が実行行為に着手して初めて共犯（教唆・幇助）も処罰しうる。正犯が実行に着手していない場合、これに対する幇助は処罰できない。
  - 正解：○（正しい）
  - 理由：共犯従属性説（通説・判例の前提）は、共犯の可罰性を正犯の実行着手に係らしめる（実行従属性）。正犯が着手していなければ「正犯なき共犯」となり処罰できない。共犯独立性説と対立する。
- **Q09［○×］** 正犯の数罪が牽連犯となる場合、これに対応する幇助犯の罪数も牽連犯とする見解と、幇助行為自体は1個だとして観念的競合とする見解があるが、いずれでも科刑上一罪として処理される。
  - 正解：○（正しい）
  - 理由：牽連犯（54条1項後段）も観念的競合（同項前段）も科刑上一罪で、最も重い刑で処断される点は同じ。幇助犯の罪数は正犯の罪数に対応させる見解（牽連犯）が素直だが、いずれでも結論に差はないため一文で足りる。
