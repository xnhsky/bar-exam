2. テープ固定のみ → 一般人を誤認させる程度に至らず → 偽造未成立

#### 第2　写真コピーを作成・送付した行為

- 見出しの補足（結論を含む。項目の終わりに読む）：前段
1. 卒業証書＝事実証明に関する文書
2. 【論点】写真コピーが「文書」に当たるか → 規範：原本と同一の意識内容・同様の機能と信用性 → 該当
3. 【論点】写真コピーの名義人の確定 → 原本作成名義人C（作成者甲との齟齬）＝偽造／複写署名で有印
4. 行使の目的＋会社へ送付 → 有印私文書偽造罪＋同行使罪（161条1項）＝牽連犯
- 結論：有印私文書偽造罪・同行使罪 成立

#### 第3　PDFデータを作成・送付した行為

- 見出しの補足（結論を含む。項目の終わりに読む）：後段
1. コピー不存在 → 前段ロジック不可／本件書面は偽造未成立
2. 【論点】偽造の程度に行使態様を取り込めるか → 肯定説（規範：想定される行使の形態等も考慮）でPDF化を取り込み偽造

- 結論：有印私文書偽造罪・同行使罪 成立（否定説なら161条の2）

#### 第4　罪数

   各段内部＝牽連犯／前段・後段＝同一文書への信頼を害する → 包括して全体一罪

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】『複写機で複写／印章・署名まで再現』 → 写真コピーの「文書」性
- 【拾う事実】『「A大学学長C」名義／作成者は甲』 → 名義人の確定
- 【拾う事実】『テープで紙片を固定しただけ』 → 原本は偽造未成立
- 【拾う事実】『スキャナーでPDF化／紙のコピーなし』 → 後段は前段と区別
- 【拾う事実】「思い立ち」 → PDF化が当初予定外（遡及性）
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 事実証明文書＝卒業証書は修了の事実を証明＝該当／行使の目的＝会社へ提出する目的あり／違法性・責任＝阻却事由なし。
- 【効く事実】前段で効く事実
  - 「文書」性 → 複写機による機械的・正確な複写／印章・署名まで原本どおり再現／名義人 → 原本作成名義人A大学学長C（作成者＝甲との不一致）／有印 → 「A大学学長C」の署名が複写／前提 → 本件書面はテープが見え偽造未成立。事実は必ず評価語（原本と同一の意識内容・同様の機能と信用性）と結合させる。
- 【規範の要点】肯定説＝大阪地判平8.7.8の規範
  - 偽造の程度に達したか否かは、文書の客観的形状だけでなく、そこから想定される文書の行使の形態等も併せて考慮できる → PDF化で改ざんが判別不能になる点を取り込み「偽造」を肯定しうる。もっとも本問はPDF化が当初予定外（「思い立ち」）で、遡及考慮の不安定性から否定説も有力＝両論可。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 偽造罪と行使罪は手段・目的の関係＝牽連犯（54条1項後段）。前段と後段は同一文書に対する社会的信頼を害するから包括一罪（全体一罪）で処理するのが本書の立場。別評価＝併合罪説も説明があれば可。
- 【まぎらわしい選択肢・論点】詐欺未遂の成否／変造と偽造の区別／公正証書原本不実記載の成否
- 【まぎらわしい選択肢・結論】電磁的記録不正作出罪のみ 成立／有印私文書偽造罪 不成立
- 【まぎらわしい選択肢・規範】不可罰説／無形偽造説
- 【まぎらわしい選択肢・事実】無印（159条3項）／名義人＝甲

## 3. 規範クイズ（全2問・1問目から最後まで全部出す）

- **［規範クイズ 1/2］** 写真コピーが文書偽造罪の「文書」に当たるための規範（写しの「文書」性）を述べよ。
  - 模範解答：写しでも原本と同一の意識内容を保有し、証明文書として原本と同様の社会的機能と信用性を有すると認められる限り「文書」に含まれる（最判昭51.4.30）。「写しだから文書でない」で止めると論点を落とす。
- **［規範クイズ 2/2］** 写真コピーの名義人は誰か、その理由とともに述べよ。
  - 模範解答：原本作成名義人（本問ではC）。写真コピーは印章・署名まで含め原本に接した場合と同様の認識をさせるから。複写者（甲）を名義人とするのは誤り。

## 4. ○×クイズ（全5問・1問目から最後まで全部出す）

- **［○×クイズ 1/5］** 一人の行為者が複数の行為を順次行う事案では、まず行為を時系列で分節し、各行為ごとに成立しうる犯罪を当てはめるのが基本である。
  - 正解：○（正しい）
  - 理由：「罪責を論ぜよ」型では、行為を時系列で分節し、各行為に①対象行為の特定→②構成要件の特定→③客観・主観の検討→④罪数の順で当てはめる。分節を怠ると論点を取りこぼす。
- **［○×クイズ 2/5］** 私文書偽造罪（159条）にいう「偽造」とは、名義人自身が内容の虚偽な文書を作成すること（無形偽造）をいう。
  - 正解：×（誤り）
  - 理由：159条の「偽造」は有形偽造＝作成者と名義人の人格の同一性の齟齬（他人名義の冒用）をいう。名義人自身が虚偽内容を作る無形偽造ではない。私文書では原則として有形偽造のみを処罰する。本問は甲がC名義を冒用する有形偽造。
- **［○×クイズ 3/5］** 「他人の印章若しくは署名」を要する有印私文書偽造罪では、原本に署名があってもその署名が写真コピー上に複写されただけでは「有印」とはいえない。
  - 正解：×（誤り）
  - 理由：他人の署名が複写されていれば、写真コピーの保有する意識内容と別異に解する理由はなく「有印」といえる。本件コピーには「A大学学長C」の署名が複写されているから有印。落とすと軽い無印（159条3項）になってしまう。
- **［○×クイズ 4/5］** 偽造を否定する立場（行使態様考慮否定説）に立つ場合でも、作出されたPDFデータは電磁的記録に当たるから、電磁的記録不正作出罪（161条の2第1項）が受け皿として成立しうる。
  - 正解：○（正しい）
  - 理由：否定説で偽造不成立としても、PDFデータは電磁的記録（7条の2）だから161条の2第1項の不正作出罪が成立し、Dへの送付は供用罪（同3項）。
- **［○×クイズ 5/5］** 文書偽造罪とその偽造文書を行使した偽造文書行使罪は、通常、手段と目的（結果）の関係に立つから、牽連犯（54条1項後段）として科刑上一罪となる。
  - 正解：○（正しい）
  - 理由：偽造は行使の手段、行使は偽造の目的という手段・目的の関係に立つから牽連犯（54条1項後段）。最も重い刑により処断する。
