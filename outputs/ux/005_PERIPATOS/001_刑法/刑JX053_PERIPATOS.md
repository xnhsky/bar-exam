  - 占有＝Xが売却代金を現実に保持＝○／委託信任関係（①②）＝Fの売却委託に基づく＝○／違法性・責任＝阻却事由なし＝一言で素通り。
- 【効く事実】あてはめで使う事実
  - 他人物性 → Fのために売却し引き渡す趣旨で受託した代金＝一行で肯定／横領の実現 → 「700万円で売れた」と虚偽報告し差額255万を借金返済に費消／横領額 → 本来引渡850万−交付595万＝255万を正確に。
- 【規範の要点】「は2つ」の規範
  - あっせん罪（256条2項）＝Xは売却・受領の時点で盗品性の認識なし（Cの告知は後）→ 故意を欠き不成立。委託信任関係＝刑法の要保護性は民法と別／財産秩序の維持から、本権なき者との委託信任関係もひとまず保護に値する → 横領成立を妨げない。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 局面ごとに罪が立ったら最後に罪数処理を一言。観念的競合（54条前段）／牽連犯（54条後段）／併合罪（45条）のどれかを一文で。本問のように時点も対象も異なる別個独立の横領は包括一罪ではなく併合罪。
- 【まぎらわしい選択肢・論点】背任罪(247条)の成否／占有離脱物横領罪(254条)との区別／不可罰的事後行為にあたるか
- 【まぎらわしい選択肢・規範】窃盗罪の不法領得の意思（権利者排除＋利用処分）／民法上は金銭は常に占有者の所有で他人の物にならない
- 【まぎらわしい選択肢・事実】Cの告知で盗品性を認識したまま③を売却／手数料15%の約定は公序良俗違反で無効
- 【まぎらわしい選択肢・結論】二項詐欺罪が別途成立し横領と併合罪／盗品等有償処分あっせん罪 成立／両横領は包括一罪

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

①②255万＝受託した売却代金は金銭でも横領罪の客体「他人の物」。Fの委託信任関係あり。差額255万を「700万で売れた」と偽り借金返済に費消＝不法領得の意思の実現→横領罪成立。嘘の代金報告は横領完遂の手段＝二項詐欺は立てず横領一罪。③300万＝売却・受領時に盗品性の認識なし→あっせん罪不成立。代金300万も金銭で他人の物。Fが本権なくても刑法上の要保護性ありで委託信任関係は保護に値する→借金返済へ費消で横領罪成立。罪数＝別個独立の二横領→併合罪（45条前段）。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 横領罪の「横領」＝不法領得の意思の実現というが、その不法領得の意思の定義を、何も見ずに書けますか。（書けたら○）
  - 模範解答：定義他人の物の占有者が、委託の任務に背いて、その物につき権限がないのに所有者でなければできないような処分をする意思（最判昭24.3.8）。この定義を立ててから事実を当てる。
- **［規範クイズ 2/3］** 横領に随伴する欺罔がなぜ別罪（二項詐欺）を構成しないのか、その理由を一言で書けますか。（書けたら○）
  - 模範解答：理由横領罪は物が既に自己の占有下にある間接的侵害で誘惑的＝非難可能性が低く、詐欺・窃盗より法定刑が低い。横領完遂の手段たる欺罔に二項詐欺を立てると、この法定刑を低くした趣旨を没却するから別罪としない。
- **［規範クイズ 3/3］** 委託者が本権（所有権）を持たない場合でも委託信任関係が保護されるのはなぜか、その理由を書けますか。（書けたら○）
  - 模範解答：理由刑法の目的は個人の法益保護にとどまらず財産秩序の維持にあり、刑法上の要保護性は民法とは別に考えるべきだから。ゆえに所有権を有しない者との委託信任関係もひとまず保護に値する。

## 4. ○×クイズ（全9問・1問目から最後まで全部出す）

- **［○×クイズ 1/9］** 一人の被告人でも、時点や対象を異にする独立した複数の行為があれば、行為（局面）ごとに分けて犯罪の成否を検討するのがよい。
  - 正解：○（正しい）
  - 理由：行為ごとに犯罪が成立するのが原則。局面を分けて拾い出すことが、最後の罪数処理（併合罪か包括一罪か）にも効いてくる。
- **［○×クイズ 2/9］** 委託されて預かった物や金銭を、自分のために費消・着服した行為は、まず委託物横領罪（252条1項）の成否を疑うのが筋である。
  - 正解：○（正しい）
  - 理由：「自己の占有する他人の物」を委託の任務に背いて領得＝横領の典型。占有が委託に基づくか（252条）／基づかないか（占有離脱物横領・254条）で条文が分かれる。
- **［○×クイズ 3/9］** 委託物横領罪（252条1項）と背任罪（247条）の区別について、行為の客体が「物」か「財産上の利益」かで一義的に決まり、両者が観念的に競合することはない。
  - 正解：×（誤り）
  - 理由：横領は「物」自体の領得、背任は権限濫用による「全体財産」侵害という違いはあるが、両罪は重なりうる（通説は法条競合として横領罪を優先適用）。客体が物か利益かだけで機械的に切り分けられるわけではない。本問は預かった代金（物＝金銭）の領得なので横領が軸。
- **［○×クイズ 4/9］** 委託物横領罪の客体「他人の物」に、特定の目的で寄託・受託された金銭はおよそ含まれない。
  - 正解：×（誤り）
  - 理由：特定目的で寄託された金銭は、占有者が費消すれば横領罪の「他人の物」に当たる（判例）。民法の所有占有一致原則をそのまま横領に持ち込まないのがポイント。
- **［○×クイズ 5/9］** 民法上「金銭は占有あるところに所有あり」とされるが、この原則は取引安全のためのものであり、所有権保護を図る横領罪の解釈にそのまま持ち込むべきではない。
  - 正解：○（正しい）
  - 理由：民法原則の趣旨（取引安全）と横領罪の趣旨（所有権保護）は別。だから受託した代金は横領罪の「他人の物」に当たる。否定説は皆無なので一行で肯定し先へ進む。
- **［○×クイズ 6/9］** 横領行為を完遂するための手段としてなされた欺罔行為には、横領罪とは別に二項詐欺罪（246条2項）が成立する。
  - 正解：×（誤り）
  - 理由：横領に随伴し横領完遂の手段にすぎない欺罔は、横領行為の一部であって別途二項詐欺を構成しない（大判昭11.10.19）。別罪を立てると横領罪の法定刑を低くした趣旨を没却する＝横領一罪。
- **［○×クイズ 7/9］** 盗品の売却をあっせん・媒介しても、売却・代金受領の時点で目的物が盗品であることを知らなければ、盗品等有償処分あっせん罪（256条2項）は成立しない。
  - 正解：○（正しい）
  - 理由：故意（盗品性の認識）は行為時に必要。本問は売却・受領の後にCから知らされたので、あっせん行為時には故意がなく不成立。事後の認識で遡って成立はしない。
- **［○×クイズ 8/9］** 委託者が目的物について所有権（本権）を持たない場合、その委託信任関係はおよそ刑法上保護されず、受託者が代金を着服しても横領罪は成立しない。
  - 正解：×（誤り）
  - 理由：刑法上の要保護性は民法と別に考えられ、財産秩序の維持の観点から、所有権を有しない者との委託信任関係もひとまず保護に値する（最判昭36.10.10等）。本権なしを理由に横領を否定しない。
- **［○×クイズ 9/9］** 同一人による別個独立の2個の横領行為について各々横領罪が成立する場合、両罪は併合罪（45条前段）となる。
  - 正解：○（正しい）
  - 理由：時点も対象も異なる独立の横領行為は包括一罪ではなく併合罪。罪数は最後に一文で示せば足りる。
