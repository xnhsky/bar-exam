2. 【論点】片面的幇助の成否（規範：幇助は一方的促進で足り意思連絡不要）
- 結論：丙は 殺人罪の幇助犯（199・62①）成立

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「いきなりAの左ほおを手拳で1回殴打」 → ── 甲が先に手を出した＝反撃の正当化に疑問符
- 【拾う事実】「約266.5m先を左折し約60m進んだ」「直後」 → ── 時間的・場所的な近接性の評価材料
- 【拾う事実】「死にやがれ」＋「胸部をめがけて突き刺し」 → ── 確定的殺意・枢要部攻撃
- 【拾う事実】『乙は「Cに」貸した（甲と直接接触なし）』 → ── 関与経路が正犯と間接的
- 【拾う事実】『丙は甲と「意思連絡なし」で呼び出した』 → ── 関与が一方的（片面的）
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 甲のB殺人＝「死にやがれ」＋胸部刺突＝確定的殺意・実行行為・因果すべて明白 → 一文で殺人成立。甲のAへの手拳1回＝暴行も明白。
- 【規範の要点】平20決定の規範
  - 行為者の暴行が先行する事案で、侵害が①先行暴行に触発された直後の近接した場所での「一連一体の事態」といえ、かつ②侵害が先行暴行の程度を「大きく超えるものでない」場合は、何らかの反撃に出ることが正当とされる状況にない＝正当防衛も過剰防衛も成立しない。
- 【効く事実】「自招侵害」のあてはめで使う事実
  - 一連一体 → 「約266.5m＋約60m」追跡だが先行暴行の「直後」「近接した場所」／程度を大きく超えない → 甲＝手拳1回／Aの攻撃＝自転車上から腕を伸ばした殴打を比較。過剰防衛も否定するのを忘れない。
- 【ポイント】乙：間接幇助で一文
  - 幇助の処罰根拠は正犯を介し間接的に結果へ因果性を及ぼす点。幇助者Cを介してなお正犯甲の実行を促進し結果へ因果性を及ぼす間接幇助も「正犯を幇助した者」に含む → 乙のナイフ提供（Cを介し甲が使用）は間接幇助。
- 【ポイント】丙：共同正犯否定→片面的幇助
  - 共同正犯の一部実行全部責任の根拠は相互の意思連絡を通じた相互利用補充 → 一方的認識の片面的共同正犯は否定。他方、幇助は一方的に正犯を促進し因果性を及ぼせば足り意思連絡不要 → 片面的幇助は成立。丙の呼出しで甲の殺害が容易に。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 複数の罪が成立したら最後に罪数処理を一言。同一相手への軽い暴行がより重い傷害に発展したなら包括一罪。別個の機会・別法益なら併合罪（45条前段）。一個の行為で数罪なら観念的競合（54条前段）。
- 【まぎらわしい選択肢・論点】積極的加害意思（侵害の予期）／緊急避難の成否
- 【まぎらわしい選択肢・結論】正当防衛 成立／殺人未遂罪 成立／共同正犯 成立
- 【まぎらわしい選択肢・規範】急迫不正の侵害＋防衛の相当性／相互の意思連絡で相互利用補充
- 【まぎらわしい選択肢・事実】侵害を予期し積極的加害意思あり／甲・丙に意思連絡あり

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

甲＝Aへの特殊警棒での殴打＝傷害該当、だが先行して自らAを殴打＝自招侵害で、一連一体・程度を大きく超えず「正当とされる状況」なし→正当防衛も過剰防衛も否定で傷害罪、Bへは「死にやがれ」＋胸部刺突＝確定的殺意で殺人罪、罪数は暴行＝傷害に包括一罪・殺人と併合罪。乙＝Cを介しダガーナイフ提供（甲と直接接触なし）＝間接幇助の可罰性、正犯を介し結果へ因果性で殺人罪の幇助犯。丙＝Bを呼出し殺害を容易に（甲と意思連絡なし）、相互利用補充を欠き片面的共同正犯は否定、幇助は一方的促進で足り意思連絡不要→殺人罪の幇助犯。

## 3. 規範クイズ（全2問・1問目から最後まで全部出す）

- **［規範クイズ 1/2］** 自招侵害（行為者の暴行が先行する事案）で正当防衛・過剰防衛を否定する2つの要件を挙げよ。
  - 模範解答：①侵害が先行暴行に触発された直後の近接した場所での「一連一体の事態」といえること、②侵害が先行暴行の程度を「大きく超えるものでない」こと。両者を満たせば「正当とされる状況」がなく正当防衛も過剰防衛も不成立。
- **［規範クイズ 2/2］** 幇助犯の処罰根拠（因果的共犯論）を一文で述べ、そこから①間接幇助が可罰となる理由 ②片面的幇助が成立する理由 を導け。
  - 模範解答：処罰根拠＝正犯を介して間接的に法益侵害結果へ因果性を及ぼす点。①幇助者を介してなお正犯の実行を促進し結果へ因果性を及ぼせば「正犯を幇助した者」に含む＝間接幇助も可罰。②一方的に正犯を促進し因果性を及ぼせば足り、正犯との意思連絡は不要＝片面的幇助も成立。

## 4. ○×クイズ（全8問・1問目から最後まで全部出す）

- **［○×クイズ 1/8］** 犯罪の「正犯」とは自ら構成要件該当行為を行った者を指し、凶器を調達しただけで自ら実行行為に出ていない背後者は、そもそも犯罪の成否を検討する対象とならない。
  - 正解：×（誤り）
  - 理由：正犯＝自ら構成要件該当行為をした者は正しいが、実行行為に出ていない背後者も教唆犯・幇助犯（狭義の共犯）として罪責を負いうる。実行行為の有無による正犯／共犯の区別が、関与者を仕分ける出発点になる。
- **［○×クイズ 2/8］** 狭義の共犯（教唆・幇助）が成立するためには、正犯の行為が構成要件に該当し違法であれば足り、正犯が有責であること（責任能力など）までは要しない。
  - 正解：○（正しい）
  - 理由：制限従属性説（通説）。共犯は正犯の「違法な実行行為」に従属して成立するので、正犯の責任までは要しない。この共犯従属性こそ、正犯の罪名を先に固めてから関与者を共犯として位置づける手順の理論的根拠。
- **［○×クイズ 3/8］** Aの攻撃に対して反撃し傷害を負わせた行為は、反撃である以上、まず正当防衛の成立を肯定する方向で検討に入るのが正しい。
  - 正解：×（誤り）
  - 理由：反撃＝即正当防衛ではない。先に行為者が侵害を招いていないか（自招侵害）を疑う。本問は甲が先に殴っており、ここが最大の山場。
- **［○×クイズ 4/8］** 凶器を正犯に直接手渡さず、間に別の協力者を挟んで渡した者は、正犯と直接の関係がない以上およそ幇助犯になりえない。
  - 正解：×（誤り）
  - 理由：幇助者を介した間接幇助も、正犯の実行を促進し結果へ因果性を及ぼせば「正犯を幇助した者」に含む（判例）。
- **［○×クイズ 5/8］** 自招侵害の判断枠組みでは、侵害が先行暴行に触発された「一連一体の事態」か、かつ侵害が先行暴行の程度を「大きく超えるものでない」か、という客観的事情で「正当とされる状況」の有無を判断する。
  - 正解：○（正しい）
  - 理由：平成20年決定の二要件（一連一体／程度を大きく超えない）。侵害の予期＋積極的加害意思（昭和52年決定）とは別で、客観面のみで判断する点が特徴。
- **［○×クイズ 6/8］** 幇助者を介して正犯の犯行を促進した者（間接幇助）も、正犯の実行行為を促進し結果へ因果性を及ぼす限り、幇助犯として処罰されうる。
  - 正解：○（正しい）
  - 理由：因果的共犯論からは、直接・間接を問わず正犯を介して結果へ因果性を及ぼせば「正犯を幇助した者」に含む。
- **［○×クイズ 7/8］** 正犯と意思を通じていなくても、客観的に犯行を分担すれば、一方的な認識だけで共同正犯（60条）が成立する（片面的共同正犯）。
  - 正解：×（誤り）
  - 理由：共同正犯は相互の意思連絡による相互利用・補充が根拠。一方的認識では相互利用補充関係を欠き片面的共同正犯は否定。ただし片面的幇助なら拾える。
- **［○×クイズ 8/8］** 同一の相手への暴行が、より重い傷害の結果に発展した場合、軽い暴行罪は重い傷害罪に吸収（包括）されて一罪として評価されるのが原則である。
  - 正解：○（正しい）
  - 理由：暴行は傷害の一過程として包括一罪。別個の機会の重い罪（殺人）とは併合罪（45条前段）。罪数の落としは小幅でも失点。

- 【用語】積極的加害意思（せっきょくてきかがいいし） ― 侵害を予期し、その機会を利用して積極的に相手に加害する意思。
