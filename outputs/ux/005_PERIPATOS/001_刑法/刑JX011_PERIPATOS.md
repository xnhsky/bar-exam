## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

甲がA宅の前を歩いていたところ、A宅の庭先で鎖につながれている犬を発見した。Aの犬は、A宅の前を人が通ると興奮して暴れる傾向にあるところ、甲に向かっても同じような態度を示し、甲に向かって吠え始めた。興奮したAの犬は、鎖がつながっている首輪を噛みちぎり、甲に向かっていき、甲の右足に噛みつこうとしたため、甲は、Aの犬の腹部を思い切り蹴りつけ、これによって、Aの犬は、死亡した。この事例における甲の罪責について、Aに、Aの犬をつないでいた鎖及び首輪の管理に過失がある場合とない場合に分けて検討しなさい。なお、Aの犬は大型で力も強く、甲には上記行為に及ぶ以外に犬の攻撃を回避する手段がなかったものとする。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 甲がA宅前を歩行、鎖につながれた犬を発見
- 犬が興奮し甲に向かって吠える
- 犬が首輪を噛みちぎり甲の右足に噛みつこうとする
- 甲が犬の腹部を蹴りつけ、犬は死亡

### 参考（読み上げない。入口の問いの答えを含むので判定にだけ使う）

登場人物：
- 甲｜通行人（→犬を蹴り殺した＝罪責の主体）
- A｜犬の飼主・管理者＝対象外
- Aの犬｜攻撃源かつ客体（物）＝刑事責任なし

### 入口の問い（3問）

- **Q01［事案の整理］** 登場人物と「引っかかる行為」を挙げて
  - 答え：罪責を問われるのは甲だけ。甲の引っかかる行為＝Aの犬の腹部を蹴り殺した（作為）。
  - 答え：Aの犬＝攻撃源だが「物」で刑事責任なし・かつ蹴られた客体。A＝飼主も自ら犯罪行為をしていない → どちらも対象外。ここで切るのが第一歩。
- **Q02［見当づけ］** 各行為は「何罪っぽい？」 ― 見当をつけて
  - 答え：甲が壊した結果＝Aの犬（他人の物）が死亡 → 器物損壊罪＝動物傷害罪（261条）系。生き物でも刑法上は「物」。構成要件該当は争いなし → 勝負は違法性阻却に移る、とアタリ。
- **Q03［論点］** 違法性で問題になる論点を挙げて（2つ）
  - 答え：CP①（過失なし）：侵害源が犬＝物 → 対物防衛の可否。（＝物・動物の侵害に正当防衛の「不正」を認めてよいか） 否定 → 受け皿の緊急避難の4要件へ。
  - 答え：CP②（過失あり）：侵害をAの過失行為へ還元できるか。（＝管理懈怠の現実化として犬の攻撃をAの「不正」と評価） できれば正当防衛でストレート。

### 骨子（4項目。第1から【論点】ごとに、何が問題→規範→使う事実→結論 の順で組み立てる）

#### 第1　共通の前提

- 見出しの補足（結論を含む。項目の終わりに読む）：構成要件該当性
1. 甲が犬を蹴り殺した＝「他人の物」を「損壊」 → 器物損壊罪（動物傷害罪・261条）該当（争いなし）
   - あてはめ：勝負は違法性阻却へ ＝ Aの管理過失の有無で場合分け

#### 第2　Aに過失がない場合

1. 正当防衛(36条1項)？ 侵害源＝犬＝物 → 【論点】対物防衛の可否（規範：「不正」＝人の行為の違法性（否定説））
   - あてはめ：動物の攻撃に「不正」なし → 正当防衛 否定
2. 受け皿 → 【論点】緊急避難(37条1項)（規範：現在の危難・避難の意思・補充性・法益の権衡）
   - あてはめ：噛みつき／回避手段なし／犬（財産）＜身体
- 結論：緊急避難成立 → 違法性阻却 → 器物損壊罪 不成立

#### 第3　Aに過失がある場合

1. 【論点】犬の侵害を「Aの過失行為の一部」と評価 → Aの「不正の侵害」を観念（規範：「不正」＝違法／過失行為も違法たりうる）
   - あてはめ：鎖・首輪の管理懈怠の現実化
2. 正当防衛(36条1項)成立：急迫不正の侵害・防衛の意思・相当性（補充性・厳格な権衡は不要）
- 結論：正当防衛成立 → 違法性阻却 → 器物損壊罪 不成立

#### 第4　結論の対比

1. いずれも 器物損壊罪 不成立
   - あてはめ：経路は 過失なし→緊急避難／過失あり→正当防衛 と異なる＝書き分けが評価の分かれ目

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「甲の右足に噛みつこうとした」 → → 侵害／危難の現在性の根拠
- 【拾う事実】「鎖につながれている／首輪を噛みちぎり」 → → 管理（鎖・首輪）と過失の有無の手がかり
- 【拾う事実】「蹴る以外に回避する手段がなかった」 → → 補充性／相当性の充足（設問が固定）
- 【拾う事実】「Aの犬（死亡）／甲の身体」 → → 失った利益＜守った利益の権衡材料
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 客体＝Aの犬＝「他人の物」／行為＝蹴り殺し＝効用を害する「損壊」／故意＝あり。構成要件は一文で抜ける。
- 【規範の要点】この論点の規範
  - 対物防衛：「不正」＝人の行為の違法性 → 動物の攻撃に「不正」なし → 正当防衛否定。緊急避難(37Ⅰ)：①現在の危難 ②避難の意思 ③補充性 ④法益の権衡。
- 【効く事実】あてはめで使う事実
  - 現在の危難 → 犬が右足に噛みつこうとした／補充性 → 蹴る以外に回避手段がなかった（設問が固定）／法益権衡 → 失った＝犬（財産）＜守った＝甲の身体。事実は必ず要件に紐づける。
- 【規範の要点】「侵害をAの過失行為へ還元」の規範
  - 「不正」＝違法であり、過失行為も違法たりうる。よってAの過失行為に対する正当防衛は当然成立しうる。正当防衛(36Ⅰ)：①急迫不正の侵害 ②防衛の意思 ③相当性（やむを得ずにした行為）。補充性・厳格な権衡は不要。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 設問が「○○がある場合とない場合に分けて」と指示したら、各場合を別々に最後まで通したうえで、最後に経路の違いを一段落で対比する。結論が一致しても安住せず、どの要件・どの阻却事由で分岐したかを明示するのが評価される締め方。
- 【まぎらわしい選択肢・論点】誤想防衛の成否／過剰避難(37Ⅰただし書)
- 【まぎらわしい選択肢・結論】器物損壊罪 成立／正当防衛 不成立で有罪
- 【まぎらわしい選択肢・規範】優越的利益説／防衛の意思不要説
- 【まぎらわしい選択肢・事実】先行行為による危難／急迫性を欠く

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

過失なし＝犬を蹴り殺す＝器物損壊罪（動物傷害・261条）該当、犬は物で違法行為をなしえず「不正の侵害」を観念できない＝対物防衛否定（「不正」＝人の行為の違法性）、よって現在の危難・避難の意思・補充性・法益権衡を満たす緊急避難（37条1項）で違法性阻却→不成立。過失あり＝飼主Aの管理懈怠＝過失行為に犬の侵害を還元、「不正」＝違法で過失行為も違法たりうる→急迫不正の侵害ありとして正当防衛（36条1項）、防衛の意思・相当性を満たし違法性阻却→不成立。結論＝いずれも不成立だが緊急避難／正当防衛と経路を異にする。

## 3. 規範クイズ（2問）

- **Q04［規範］** 緊急避難（37条1項）の成立要件を4つ挙げよ。
  - 模範解答：①現在の危難 ②避難の意思（「避けるため」）③補充性（「やむを得ずにした行為」＝他に手段なし）④法益の権衡（生じた害が避けようとした害を超えない）。
- **Q05［規範］** 正当防衛（36条1項）の成立要件を3つ挙げよ。
  - 模範解答：①急迫不正の侵害 ②防衛の意思（自己又は他人の権利を防衛するため）③相当性（やむを得ずにした行為＝必要最小限度）。緊急避難と違い補充性・厳格な権衡は不要。

- **Q06［○×］** 不作為とは、法的に期待された一定の行為をしないことをいい、不作為が作為犯と同視されるには、結果を防止すべき作為義務（保障人的地位）が必要である。
  - 正解：○（正しい）
  - 理由：行為を作為／不作為に仕分ける意味は、不作為の場合に作為義務（保障人的地位）という別個の成立要件が要求される点にある。本問の蹴り殺しは作為なのでこの関門は問題にならない。
- **Q07［○×］** 他人の飼い犬を殺す行為は、相手が生命ある動物である以上、「物」を客体とする器物損壊罪ではなく、傷害罪（204条）の成否の問題として扱われる。
  - 正解：×（誤り）
  - 理由：傷害罪の客体は「人の身体」に限られる。動物は刑法上「他人の物」に含まれ、殺傷はその効用を害する「損壊」として器物損壊罪（261条＝いわゆる動物傷害）の構成要件に該当する。この位置づけを外すと、続く違法性阻却（対物防衛か緊急避難か）の土俵設定を誤る。
- **Q08［○×］** 正当防衛における「不正の侵害」の「不正」を人の行為の違法性と解する立場（否定説）では、侵害源が人の行為に還元できるか否かによって、正当防衛で処理できるか緊急避難で処理すべきかが分かれる。
  - 正解：○（正しい）
  - 理由：「不正」＝人の行為の違法性と解すると、侵害が人（の故意・過失行為）に帰属できれば正当防衛、人に帰属できない物・自然現象の侵害なら受け皿の緊急避難、という振り分けになる。この帰属の有無が経路を決める。
- **Q09［○×］** 構成要件に該当しても、正当防衛や緊急避難などの違法性阻却事由が認められれば、犯罪は成立しない。
  - 正解：○（正しい）
  - 理由：犯罪の成立には構成要件該当性・違法性・有責性が必要。違法性阻却事由があれば違法性が欠け、犯罪不成立となる。
- **Q10［○×］** 正当防衛（36条1項）の成立には「急迫不正の侵害」が必要であり、ここでいう「不正」とは原則として人の違法な行為を指す。
  - 正解：○（正しい）
  - 理由：正当防衛が緩やかに認められる根拠は侵害者の行為が「不正」だから。よって「不正」＝人の行為の違法性と解するのが筋（対物防衛論の出発点）。
- **Q11［○×］** 動物それ自体による攻撃は人の行為ではないが、身を守るための反撃であれば当然に正当防衛の「不正の侵害」に当たる。
  - 正解：×（誤り）
  - 理由：通説（否定説）は「不正」＝人の行為の違法性と解し、物・動物の攻撃に「不正」を観念しない（対物防衛否定）。受け皿は緊急避難。
- **Q12［○×］** 緊急避難（37条1項）は、他にとりうる手段がなかったこと（補充性）と、生じた害が避けようとした害の程度を超えないこと（法益の権衡）を要件とする。
  - 正解：○（正しい）
  - 理由：緊急避難は正対正の関係なので、正当防衛より要件が厳格。補充性と厳格な法益権衡を要する点が正当防衛との大きな違い。
- **Q13［○×］** 正当防衛の「不正の侵害」は故意による違法行為に限られ、過失行為に対しては正当防衛は一切成立しない。
  - 正解：×（誤り）
  - 理由：「不正」＝違法であり、故意行為に限られない。過失行為も違法たりうるので、過失行為に対する正当防衛は成立しうる。
- **Q14［○×］** 飼主に動物の管理上の過失がある場合、その動物の攻撃を飼主の過失行為の一部と評価して、飼主の「不正の侵害」を観念し正当防衛で処理しうる。
  - 正解：○（正しい）
  - 理由：管理懈怠（過失）が現実化したのが動物の攻撃だと評価すれば、侵害は人（飼主）の不正な行為に還元され、対物防衛論を経ずに正当防衛が立つ。
- **Q15［○×］** 正当防衛は緊急避難と異なり、厳格な補充性や法益権衡を要せず、防衛手段として必要最小限度（相当性）であれば足りる。
  - 正解：○（正しい）
  - 理由：正対不正の正当防衛は要件が緩やか、正対正の緊急避難は補充性・厳格な権衡を要し厳格。侵害を人に帰属できる過失ありの方が、行為者に有利。
- **Q16［○×］** 正当防衛は「正対不正」（不正な侵害者への反撃）の関係であるのに対し、緊急避難は「正対正」（正当な利益どうしの衝突）の関係にあり、この基本構造の違いが両者の要件の厳格さの差をもたらす。
  - 正解：○（正しい）
  - 理由：正当防衛は不正な侵害者を犠牲にするので要件が緩やか（補充性・厳格な権衡は不要）。緊急避難は無関係な正当利益を犠牲にするので補充性・厳格な法益権衡を要する。経路を書き分けるべき理由はこの正対不正／正対正の構造差にある。
