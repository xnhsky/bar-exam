## 2. 答案構成

### 問題文（最初にゆっくり読み上げる）

Xは、知人Aから3カ月間の約束でノートパソコンと50万円を貸して欲しいと頼まれた。そこで、Xは、自己名義の預金口座から50万円を引き出してAに渡すと共に、父親Bが友人Cから借りていたノートパソコンをBの所有物であると思い、Bの書斎から無断で持ち出してAに貸した。Aは、パソコンは返したものの、50万円は返済期限を2カ月過ぎても返そうとしないので、Xは、連日電話で催促したが、Aには全く返す気配がなかった。いつまでも返してくれないことに腹を立てたXは、ある日、たまたま路上でAに出会ったので、「返さないとただではおかないぞ。痛い目にあいたいのか。明日までに返せ。」などと申し向け、これに畏怖したAは翌日50万円をXに返済した。Xの罪責を論ぜよ。

### 事実の要点（問題文の直後に読む。「事実」と言われたら読み直す）

- 自己の50万円を引き出しAへ交付（=無罪）
- BのPC（実はC所有）を誤信し無断持出し→Aへ貸与
- Aが返済遅滞・催促無視（2か月超）
- 路上で害悪告知「痛い目に…」
- 畏怖したAが翌日50万円を返済

### 参考（読み上げない。入口の問いの答えを含むので判定にだけ使う）

登場人物：
- X｜行為者（→PCを無断持出し／取立て）
- B｜父・PCの占有者（Xの親族）
- C｜Bの友人・PCの所有者（Xと非親族）
- A｜知人・借主（恐喝の相手方）

### 入口の問い（3問）

- **［入口 1/3・事案の整理］** 行為者の「引っかかる行為」を挙げて
  - 答え：①50万円を自己口座から引き出してAに渡す＝自分のお金の処分→無罪（ここで切る）。
  - 答え：②父Bの書斎からPCを無断持出し→Aに貸す＝窃盗の疑い。③「痛い目に…」と言って50万円を返させる＝恐喝の疑い。検討対象はこの2つ。
- **［入口 2/3・見当づけ］** 各行為は「何罪っぽい？」 ― 見当をつけて
  - 答え：前半：他人（C所有）のPCを占有者Bの意思に反して持出し → 窃盗（235条）系。父B・友人Cと親族が出たら → 親族相盗例（244条）を疑う。後半：「痛い目に…」と害悪告知で50万円を交付させた → 恐喝（249条1項）系。
- **［入口 3/3・論点］** 各行為で問題になる論点を挙げて（3つ）
  - 答え：CP①：3か月貸す目的の持出し → 不法領得の意思（一時使用なら不可罰）。（＝権利者を排除し経済的用法に従い利用処分する意思）
  - 答え：CP②：父Bは親族 → 親族相盗例で刑が免除されるか。（244条1項＝親族間の財産犯の刑を免除する一身的処罰阻却事由）
  - 答え：CP③：PCをBの物と誤信 → 親族関係の錯誤は故意を阻却するか。
  - 答え：CP④（後半）：正当な債権の取立て → 権利行使と恐喝で違法性が阻却されるか。

### 組み立ての順序（入口の問いのあと、骨子に入る前に読み上げる）

- 順番：第1　PCの無断持出し → 第2　借金の取立て → 第3　罪数
- 第1　PCの無断持出し
  - 論点1：不法領得の意思
  - 論点2：親族相盗例(244Ⅰ)の親族関係の範囲
  - 論点3：親族関係の錯誤
- 第2　借金の取立て
  - 論点：権利行使と恐喝
- 第3　罪数
  - 論点：なし（結論の確認だけ）

この順番の理由（参考。結論・配点には触れず、一言で言い直す）：単独行為者で複数の行為があるときは、原則事実の時系列順。本問は 第1：窃盗（前半）→ 第2：恐喝（後半）→ 第3：罪数。時系列順自体が論理の整合を支える。

### 骨子（3項目。第1から、論点名 → 規範 → あてはめで使う事実、項目の最後に結論）

#### 第1　PCの無断持出し

- 見出しの補足（結論を含む。項目の終わりに読む）：窃盗罪・235条
1. PCはC所有＝「他人の財物」／占有者Bの意思に反し持出し＝「窃取」
2. 【論点】不法領得の意思 → 規範：権利者排除意思＋利用処分意思
   - あてはめ：3カ月の全面的利用排除 → 認定
3. 【論点】親族相盗例(244条1項)の親族関係の範囲
   - あてはめ：規範：占有者・所有者の双方に親族関係が必要（最決平6.7.19）
   - あてはめ：所有者C＝非親族 → 適用なし＝刑免除なし
4. 【論点】親族関係の錯誤 → 一身的処罰阻却事由の錯誤 → 故意阻却せず
- 結論：窃盗罪 成立（刑免除なし）

#### 第2　借金の取立て

- 見出しの補足（結論を含む。項目の終わりに読む）：恐喝罪・249条1項
1. 「痛い目に…」＝害悪告知＝「恐喝」／畏怖→交付 → 構成要件該当
2. 【論点】権利行使と恐喝
   - あてはめ：規範：①権利の範囲内②方法が社会通念上相当（最判昭30.10.14）
   - あてはめ：50万円は債権額の範囲内・身体加害の示唆は相当性を超える → 違法性阻却せず
- 結論：恐喝罪 成立

#### 第3　罪数

   別個の機会・別個の財産権の侵害 → 併合罪（45条前段）

### ヒント（読み上げない。段階ヒントと判定に使う）

- 【拾う事実】「Bの所有物であると思い」 → → 誤信＝錯誤の手がかり
- 【拾う事実】『所有者C／占有者B（父）』 → → 親族が別人＝親族相盗例の範囲
- 【拾う事実】『「3カ月間」貸す』 → → 利用期間＝不法領得の意思の評価
- 【拾う事実】「痛い目にあいたいのか」 → → 害悪の内容（身体加害の示唆）＝方法の相当性
- 【拾う事実】『債権額50万円・請求も50万円』 → → 権利の範囲内か
- 【拾う事実】『2か月の遅滞・催促無視』 → → A側事情＝両面評価の材料
- 【争いのない要件】論点にならず、あっさり認定する要件
  - 前半：PCはC所有＝「他人の財物」○／占有者Bの意思に反し持出し＝「窃取」○。後半：害悪告知＝「恐喝」○／畏怖→交付の因果○。
- 【効く事実】前半で効く事実
  - 権利者排除意思 → 「3カ月間」利用＝所有者Cの利用を全面排除／親族相盗例 → 占有者B＝親族・所有者C＝非親族（誰と誰の間に必要か）／錯誤 → 「Bの所有物であると思い」を引用。
- 【規範の要点】二段階の規範
  - 権利者の取立行為も恐喝罪の構成要件に該当する。もっとも ①その権利の範囲内であり、②その方法が社会通念上一般に忍容すべき程度を超えない ときは違法性が阻却される（最判昭30.10.14）。
- 【効く事実】後半で効く事実（両面評価）
  - 範囲内 → 請求額＝債権額の50万円（範囲内）。方法 → 「痛い目にあいたいのか」＝身体への加害の示唆（重大）。A側 → 2か月の返済遅滞・連日の催促無視（不誠実）も挙げて両面から評価し、一方に決する。
- 【論点どうしの関係】罪数・共犯関係など、論点どうしのつながり
  - 複数の罪が成立したら最後に罪数処理を一言。別個の機会・別個の財産権の侵害なら原則は併合罪（45条）。一個の行為で数罪なら観念的競合（54条前段）、手段・目的なら牽連犯（54条後段）。
- 【まぎらわしい選択肢・論点】「遺棄」に移置を含むか／使用窃盗の不可罰性のみ
- 【まぎらわしい選択肢・規範】占有者との間にのみ親族関係が必要／権利の範囲内であれば方法を問わず適法
- 【まぎらわしい選択肢・事実】所有者Cも親族
- 【まぎらわしい選択肢・結論】窃盗罪 成立・刑免除あり／恐喝罪 不成立（違法性阻却）

### 流れのまとめ（通しの口頭構成のあと、答え合わせに読む）

窃盗＝PCはC所有＝他人の財物、占有者Bの意思に反し持出し＝窃取。3カ月の全面排除→不法領得の意思○。親族相盗例は占有者B＋所有者C双方に親族関係が必要だがCは非親族→適用なし・刑免除なし。親族関係の錯誤は一身的処罰阻却事由の錯誤→故意阻却せず→窃盗成立。恐喝＝「痛い目に…」＝害悪告知→畏怖→交付で構成要件該当。権利行使も50万円は範囲内だが身体加害示唆は方法相当性を超える→違法性阻却せず→恐喝成立。罪数＝別個の機会・財産権で併合罪（45前段）。

## 3. 規範クイズ（全3問・1問目から最後まで全部出す）

- **［規範クイズ 1/3］** 窃盗罪に必要な「不法領得の意思」の定義を述べよ。
  - 模範解答：権利者を排除し他人の物を自己の所有物と同様にその経済的用法に従い利用処分する意思（大判大4.5.21）。＝権利者排除意思＋利用処分意思の2要素。
- **［規範クイズ 2/3］** 親族相盗例（244条1項）が適用されるために、親族関係はどの者の間に必要か（占有者と所有者が別人の場合）を述べよ。
  - 模範解答：窃盗犯人と占有者との間のみならず、所有者との間にも親族関係があることを要する（最決平6.7.19）。本問は所有者C＝非親族なので適用なし＝刑免除なし。
- **［規範クイズ 3/3］** 権利行使としての取立てで恐喝罪の違法性が阻却される要件（二段階）を述べよ。
  - 模範解答：①その権利の範囲内であり、②その方法が社会通念上一般に忍容すべき程度を超えないこと（最判昭30.10.14）。両方を満たして初めて違法性が阻却される。

## 4. ○×クイズ（全9問・1問目から最後まで全部出す）

- **［○×クイズ 1/9］** 1人の行為者が複数の行為をした事案では、各行為を時系列に沿って独立に取り出し、別々に罪責を検討するのが基本である。
  - 正解：○（正しい）
  - 理由：時系列で行為を切り分けると、各行為ごとに構成要件が定まり、罪数処理（最後に併合罪等）も見通せる。
- **［○×クイズ 2/9］** 他人が所有する物を、その占有者の意思に反して自分の支配下へ移したときは、まず窃盗罪（235条）を疑うのが筋である。
  - 正解：○（正しい）
  - 理由：「他人の財物」を「窃取」した＝占有者の意思に反する占有移転、が窃盗の核。所有者と占有者が別人でも「他人の財物」性は所有者基準で判断する。
- **［○×クイズ 3/9］** 正当な貸金債権を持つ者が、害悪を告知して相手を畏怖させ金銭を交付させた。債権がある以上、その行為はそもそも恐喝罪の構成要件には当たらない。
  - 正解：×（誤り）
  - 理由：権利者でも害悪告知＋畏怖＋交付があれば恐喝罪の構成要件には該当する。債権の存在は違法性阻却の段階（権利行使と恐喝）で扱う。
- **［○×クイズ 4/9］** 窃盗罪の成立には、故意のほかに不法領得の意思が必要であり、これは一時使用（使用窃盗）を不可罰とし、毀棄・隠匿罪と区別する機能をもつ。
  - 正解：○（正しい）
  - 理由：不法領得の意思＝権利者排除意思＋利用処分意思（大判大4.5.21）。
- **［○×クイズ 5/9］** 他人の物を3か月間にわたり利用する意思で持ち出した場合、短期間の借用にすぎないから権利者排除意思は認められない。
  - 正解：×（誤り）
  - 理由：3か月もの間その物の利用を全面的に排除するのは、一時使用の域を超え権利者排除意思あり。
- **［○×クイズ 6/9］** 恐喝罪の構成要件該当性は、害悪の告知（恐喝）→相手の畏怖→畏怖に基づく財物の交付、という因果の流れで判断する。
  - 正解：○（正しい）
  - 理由：恐喝→畏怖→交付の因果が骨格。本問は「痛い目に…」で畏怖し翌日返済しており、構成要件には該当する。あとは違法性阻却の可否が勝負。
- **［○×クイズ 7/9］** 他人の物を親族の所有物だと誤信して窃取した場合、親族相盗例（244条1項）の適用があると信じていた以上、窃盗罪の故意は阻却される。
  - 正解：×（誤り）
  - 理由：親族相盗例は一身的処罰阻却事由で、親族関係は構成要件該当事実ではない。故意（38条1項）は構成要件該当事実（他人の物・窃取）の認識で足りるから、処罰阻却事由に関する錯誤は故意に影響しない。
- **［○×クイズ 8/9］** 正当な債権の取立てであっても、その方法が社会通念上一般に忍容すべき程度を超えるときは、違法性は阻却されず恐喝罪が成立する。
  - 正解：○（正しい）
  - 理由：権利の範囲内でも「方法の相当性」を超えれば違法。身体加害の示唆まで用いれば社会通念上の許容限度を超えるのが通常。
- **［○×クイズ 9/9］** 観念的競合（54条1項前段）にいう「一個の行為」とは、法的評価を離れ構成要件的観点を捨象した自然的観察のもとで、行為が社会的見解上1個と評価される場合をいう。
  - 正解：○（正しい）
  - 理由：判例（最大判昭49.5.29）の「一個の行為」判別基準。これに当たれば観念的競合（科刑上一罪）、別個の行為が手段・目的の関係に立てば牽連犯、いずれでもなければ併合罪（45条前段）。本問のように行為・機会が別なら併合罪になる。

（○×クイズはここまで＝全9問。最後の9問目まで出したら「○×クイズ、全9問クリア！」と言って復習へ）
