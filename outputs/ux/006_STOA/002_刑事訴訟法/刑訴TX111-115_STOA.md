#### 全体の物差し（解説の最初に読む）

舞台は、逮捕・勾留されている被疑者の取調べです。捜査機関が「取り調べたいから出て来なさい」と言ったとき、身柄を拘束されている被疑者は、取調室へ出頭し、そこにとどまる（滞留する）義務を負うのでしょうか。この「取調べのための出頭・滞留義務」を、講学上取調受忍義務と呼びます。これがあるかないかで、取調べの現場の姿はまるで変わります。手がかりは刑事訴訟法198条1項です。本文は「必要があるときは被疑者の出頭を求め、これを取り調べることができる」と定め、但書が「被疑者は、逮捕又は勾留されている場合を除いては、出頭を拒み、又は退去することができる」と続けます。在宅の被疑者は取調べを拒んで帰れる、但書はそう保障しています。問題は、この「逮捕・勾留の場合を除いては」という一言を、どう読むかです。一つの読み方は反対解釈です。「逮捕・勾留を除いては自由がある」を裏返せば、逮捕・勾留されている場合には出頭を拒めず退去もできない、つまり出頭・滞留義務がある、と読めます。この裏読みから義務を認めるのが肯定説（見解Ⅰ）。実務・捜査機関はこの立場に親しみます。ある学生は、まさに「但書を反対解釈するのが相当だ」と述べており、肯定説の条文上の入口を突いています。肯定説にはすぐ反撃が来ます。「義務を認めたら、黙秘権があっても実際にはしゃべらされるのでは？」という心配です。肯定説はここで、二つの義務を分けて答えます。取調室にとどまる義務（滞留義務）はあっても、話す義務（供述義務）までは課さない。だから供述を拒む自由＝黙秘権（憲法38条1項）は奪わない、と。別の学生が「自分の見解を採っても、直ちに供述を拒否する自由を奪うわけではない」と反論するのは、この肯定説の自己弁護です。これに対し、義務を認めない否定説（見解Ⅱ）にも強い理屈があります。第一は黙秘権です。取調室に長時間とどまる義務を負わされれば、供述義務がないと言っても実質的には供述を強いられるのと変わらない、ある学生はこう批判します。注意したいのは、この批判が向けられている相手は肯定説だという点。相手を攻撃している以上、その発言者自身は否定説の側に立っています。批判の矛先の反対側に、発言者の立場があるのです。否定説の第二の柱は当事者主義です。現行法が捜査機関と被疑者を対等に相対立する当事者として扱うなら、一方の当事者が他方に「出て来い・とどまれ」と義務を課すのは筋が通らない。第三の柱は逮捕・勾留の目的です。逮捕・勾留は将来の公判に被疑者を出頭させるための身柄確保の処分であって、取調べのための処分ではない。そう考えれば、取調べはそもそも勾留の目的の外にあり、これを根拠に義務を課すことはできません。当事者主義を語る学生も、勾留の目的を語る学生も、行き着く先は否定説です。こうして整理すると、幹は一本です。但書を反対解釈して義務を認めるのが肯定説（見解Ⅰ）／黙秘権・当事者主義・勾留の目的から義務を否定するのが否定説（見解Ⅱ）。あとは各発言が、義務を基礎づける論拠か、義務を否定する論拠かを、向きを間違えずに仕分けるだけです。とりわけ「異なる見解のように考えると困る」という批判や、「私のように考えても不都合はない」という反論つぶしは、発言者がどちら側に立つかを教えてくれる目印。番号（肢6）はその仕分けの結果にすぎません。覚えるべきは、二つの見解と、それぞれを支える論拠の向きです。

### 4. 解説（カード11枚。外した記述のカードを先に）

#### 全体の物差し（解説の最初に読む）

この問題は、黙って話さない自由（黙秘権・供述拒否権）が、被疑者・被告人・参考人・証人という登場人物ごとに、どんな形で保障されるかを問うものです。根っこにあるのは憲法が定める「自己に不利益な供述を強要されない」という自由。ただし、その厚みや使い方は主体と場面で変わります。まず「誰の・どの場面の沈黙か」を見分けるのがコツです。身体を拘束された被疑者に、取調べのため出頭して留まる義務（取調受忍義務）があると考えても、それは「その場にいる義務」にすぎません。判例は、この義務を認めても、供述を拒む自由まで直ちに奪うわけではないと述べます。椅子に座らせることはできても、口を開かせることはできない。義務の対象が身体か供述内容かを分けるのが第一歩です。黙秘権は万能ではありません。守られるのは、自分が刑事責任を問われる虞のある「不利益な事項」の供述です。名前のような身分事項は、原則としてこの不利益事項に当たりません。だから、氏名を明かさず番号と拇印だけで表示した弁護人選任届は、氏名を欠く不適法なものとして突き返され得ます。権利の及ぶ範囲を先に画すのが大切です。取調べのとき、被疑者には「話さなくてよい」という注意書き（供述拒否権の告知）が要ります。では、被害者などの第三者を参考人として聞くときはどうか。参考人の取調べを定める条文は、この告知の規定をわざわざ準用していません。参考人は自分の罪を問われているわけではないから、注意書きは付いてこないのです。舞台が捜査から法廷に移ると、今度は裁判長が被告人に告知します。起訴状を読み上げた後、「黙っていてよい／話してもよい／話せば有利にも不利にもなる」という三点を告げなければなりません。取調べと公判で、告知を担う条文は変わりますが、守っているのは同じ黙秘権です。証人は、被疑者・被告人とは立場が違います。原則として証言する義務を負い、自分が罪に問われる虞のある証言だけを例外的に拒めます。例外を使う以上、「なぜ拒むのか」という事由を示さなければなりません。理由も言わずに黙る、という使い方は認められないのです。この問題は、①被疑者の身体と供述を分ける、②黙秘の対象は不利益事項に限る、③告知は被疑者・被告人にあり参考人にはない、④証人の拒絶は事由を添える、という四つの区別で解けます。番号を覚えるのではなく、「誰の・どの場面の沈黙か」という地図を持てば、正しい記述（取調受忍義務の話と、公判冒頭の告知の話）が自然に浮かび上がります。

### 4. 解説（カード11枚。外した記述のカードを先に）

#### 全体の物差し（解説の最初に読む）

この問題は、弁護人が被疑者・被告人の防御のためにどんな権限をもつかを問うものです。弁護人の権限は大きく三つに分けられます。第一に、身体を拘束された依頼人と自由に会う接見交通権のような「固有権」。第二に、本人の代わりに、しかも本人の意思に反してでも使える独立代理権。第三に、勾留などの裁判に文句を言う不服申立権です。まず「今どの武器の話か」を見分けるのがコツです。身体を拘束された被疑者と弁護人は、立会人なしで自由に会えます（接見交通権）。では、裁判官が「接見禁止」を命じたらどうか。ここが落とし穴です。接見禁止で会えなくなるのは、依頼人と弁護人以外の者との接見だけ。弁護人との接見は禁止の対象に入りません。だから、裁判官に接見を禁じられても弁護人は依頼人と会えます。「会えなくなる」とした記述は誤りです。勾留の期間を延ばすには「やむを得ない事由」が要ります。この事由もないのに延長されたら、弁護人はどうするか。延長は裁判官の裁判なので、これに不服があれば準抗告で争えます。弁護人には準抗告の明文はありませんが、「不服がある者」を広く認める条文の下で、依頼人のための包括的な代理権に基づいて準抗告できます。だからこの記述は正しい。弁護人は、本人の代わりというより、時に本人の意思に反してでも動ける独立の代理人です。その代表が証拠調べの請求。被告人が「その証拠は要らない」と思っていても、弁護人は独立して証拠調べを請求できます。防御に必要だと弁護人が判断すれば、本人の気持ちに縛られず一手を打てる、これが独立代理権の強さです。大事な証拠が消えそうなとき、弁護人は証拠保全を使えます。裁判官に頼んで、今のうちに押収や証人尋問をしてもらう制度です。ただし使えるのは第一回の公判期日より前だけ。公判が始まる前に、被告人側にも証拠を集める道を開いた仕組みです。時期の枠さえ外さなければ、この記述は正しいと分かります。最後は不服申立ての限界です。勾留の更新という裁判所の決定に、弁護人は不服を言えます。しかし「そもそも依頼人は無実だ（犯罪の嫌疑がない）」という理由での抗告は封じられています。無実かどうかは、勾留という付随的な手続ではなく、本案（有罪か無罪か）の裁判で決めるべきだからです。だから「嫌疑がないことを理由に抗告できる」とした記述は誤りです。この問題は、①接見禁止の札は弁護人以外に貼る、②勾留延長には準抗告できる、③本人が要らない証拠も独立して請求できる、④証拠保全は公判前だけ、⑤勾留への抗告に無実は使えない、という五つの区別で解けます。誤っているのは、接見禁止で弁護人まで会えなくなるとした点と、勾留への抗告で犯罪の嫌疑がないことを理由にできるとした点の二つ。番号を覚えるのではなく、「どの武器を、誰に対して、どの条文の枠で使うか」という地図を持てば、迷わず選べます。

### 4. 解説（カード11枚。外した記述のカードを先に）

#### 全体の物差し（解説の最初に読む）

この問題は、逮捕・勾留された人の弁護人ができる活動を並べ、そのうち「法令上の根拠がないもの」（＝それを認める条文が無い活動）がいくつあるかを数えさせます。数える前に、根拠の有無を分ける2本の物差しを持っておくと迷いません。1本目は「不服申立て（準抗告）の対象になるか」、2本目は「逮捕の段階に固有の制度があるか」です。準抗告は、裁判官の裁判や捜査機関の処分に不服があるときの簡易な不服申立てですが、何にでも使えるわけではありません。条文が「これとこれ」と対象を並べた限定列挙で、そのリストに載っていなければ使えません。上訴（控訴・上告）が原則すべての判決を対象にできるのと違い、準抗告は対象が絞られている、ここが最大のポイントです。逮捕状を出す裁判に不満でも、リストには「勾留に関する裁判」はあっても「逮捕に関する裁判」がありません。判例も、逮捕に関する裁判は準抗告の対象にならないとしています。だから逮捕状発付への準抗告は根拠がない、が1つ目の×です。勾留されている人は「なぜ拘束されているのか」を裁判官に説明してもらう手続（勾留理由開示）を使えます。ところが逮捕については、同じような開示の規定が置かれていません。だから逮捕の理由の開示を求める活動も根拠がない、が2つ目の×です。根拠が無いのはこの二つだけで、答えは2個になります。逮捕は最長でも72時間で終わり、そのあと勾留するかどうかの審査で、逮捕が適法だったかも含めてまとめて司法のチェックが入ります。短い逮捕の段階に別途の不服窓口や開示制度を作ると手続が二度手間になるので、法は「逮捕には置かず、勾留にまとめて置く」という作りにしているのです。これが「逮捕には無く、勾留にはある」という、本問を貫く一本の糸です。一方、勾留に関する活動には、ちゃんと根拠があります。勾留の期間を延ばす裁判は「勾留に関する裁判」だから準抗告のリストに載り、争えます。勾留の理由や必要が消えれば取消しを求められ、これは起訴されて被告人になった後でも使えます。勾留は、逮捕と違って是正の道が幾重にも用意されているのです。拘束された人と弁護人が立会人なしに会う接見交通は、弁護人の助力を受けるための最も重要な権利で、条文にしっかり根拠があります。この事案では裁判官が「接見等を禁じた」とありますが、その禁止で止められるのは弁護人以外の面会だけで、弁護人との接見までは止められません。また、検察官が接見の日時などを指定した処分に不満があれば、これは捜査機関の「処分」なので、もう一つの準抗告で争えます。裁判は準抗告、処分ももう一つの準抗告、と入口が2つある点に注意します。こうして並べると、根拠が無いのは「逮捕」に結びついた二つ、逮捕状発付への準抗告と、逮捕理由の開示請求、だけです。残りはすべて勾留・接見という、条文が制度を用意している場面。個数（2個）を丸暗記するのではなく、「逮捕には無く、勾留にはある」と「準抗告は対象がリストで限定される」の二つを持ち帰れば、同種の問題を自分で解けます。

### 4. 解説（カード8枚。外した記述のカードを先に）

#### 全体の物差し（解説の最初に読む）

この問題は、被疑者・被告人に付く弁護人が、刑事手続のどの段階でどれだけ深く関われるかを問うています。ばらばらの条文に見えますが、実は手続の段階（捜査・公判・上訴）と、その場面での関与の強さ（必ず付ける義務なのか、行使できる権利なのか、裁判官が認めればできる裁量なのか）という二つの軸で並べると、迷いがぐっと減ります。カギは、条文の語尾を読むことです。まず捜査の段階です。お金がなくて弁護人を頼めない人には、国が費用を持って弁護人を付ける制度があります。ただし起訴される前の被疑者について、この制度が使えるのは、身体を捕まえて留め置く勾留がされている場合に限られます。身体を拘束されていない在宅の被疑者は、この入口をくぐりません。身体拘束がない段階では弁護人を付ける必要性が相対的に低く、被疑者としての区切りも曖昧だからです。だから「在宅の被疑者にも必ず付ける」という言い方は成り立ちません。同じ捜査の段階で、公判が始まる前に証人がいなくなりそうなとき、検察官が裁判官に頼んで前もって証人を調べておく手続があります。このとき弁護人を立ち会わせるかどうかは、条文が「捜査に支障がないと認めるときは立ち会わせることができる」と書いています。「できる」は裁判官の裁量であって、必ず立ち会わせる義務ではありません。公判の場で証人を調べるときは弁護人に当然の立会権がありますが、公判前の証人尋問は捜査活動の一種なので、立会いは招待制にとどまるのです。次は公判の段階です。証拠を調べ終えた後、弁護人は「以上を踏まえてこう考えます」という最終弁論を述べられます。これは権利で、裁判長は最後に陳述する機会を与えなければならないとされています。述べるかどうかは自由でも、機会そのものを与えることは裁判所の義務です。だから、その機会を飛ばして審理を打ち切れば、手続として違法になります。同じ公判の段階でも、複雑な事件では本番の審理の前に争点と証拠を整理する準備の手続が置かれます。この準備の手続は、被告人に弁護人がいなければ行うことができないと条文が定めています。争点を法律の目で仕分ける作業に、法律家の同席が欠かせないからです。弁護人がいなければ裁判所が職権で付けてでも、この手続には弁護人を確保します。最後は判決が出た後、上級裁判所へ不服を申し立てる上訴の段階です。元の裁判で適法に選ばれた弁護人は、被告人の代理としてではなく自分の権限で上訴できます。これを独立代理権といいます。もっとも、これは万能ではありません。被告人が「上訴しない」とはっきり口に出したときは、その意思に反する上訴はできません。独立して行使できることと、本人の明示した意思には反せないことは両立します。こうして見ると、5つの話は「段階」と「強さ」という一本の軸でつながっています。条文の語尾が「付さなければならない・行うことができない」なら義務、「陳述することができる・機会を与えなければならない」なら権利、「立ち会わせることができる」なら裁量。この物差しを当てれば、在宅被疑者に義務はない（誤り）、期日前尋問の立会は裁量で義務ではない（誤り）、と自然に決まります。番号は結果、覚えるべきは条文の語尾から強さを読む筋道です。
