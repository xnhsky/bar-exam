無効な代諾養子縁組の追認と116条の類推適用

出典: 民JX067　虚偽の嫡出子出生届と養子縁組・親子関係不存在確認と権利濫用

問題の所在

15歳未満の子の養子縁組は法定代理人の代諾を要する（797条1項）。法定代理人でない者の代諾によりなされた縁組は有効な代諾を欠き無効だが、本人が15歳到達後に自ら追認したとき、無権代理の追認規定（116条）を類推して縁組を有効にできるか。さらに、追認前から嫡出子たる身分を有していた第三者を、116条ただし書類推で保護すべきかが問われる。

規範（暗記対象）

本文類推＝追認肯定／ただし書類推＝否定（判例・通説）

15歳未満の子の代諾は法定代理に基づくものであり、その代理権が欠缺した場合は一種の無権代理と解される。有効な代諾を欠く縁組も、養子が15歳に達した後に自ら追認したときは、116条本文の類推適用により縁組の時に遡って有効となる。他方、養子縁組の追認のような身分行為については、事実関係を重視する身分関係の本質に鑑み、取引の安全のための116条ただし書は類推適用されない。

最判昭27.10.3（本文類推・追認肯定）／最判昭39.9.8（百選Ⅲ40・ただし書類推否定）

理由づけ

代諾権の欠缺は無権代理に類似する構造であり、本人の追認は本人の縁組意思の発現だから、その意思を尊重し子の福祉に資する遡及的治癒を認めてよい。他方、116条ただし書は取引の安全を目的とする規定であって、事実関係を重視し画一的に定まるべき身分行為には妥当しない。身分関係を第三者ごとに相対化すると法的安定を害するため、追認の遡及効は第三者にも及ぼす。

あてはめの型

  1. 代諾の瑕疵：法定代理人（797条1項）でない者による代諾 → 有効な代諾を欠く → 無権代理類似（原則無効）。
  2. 追認による治癒：本人が15歳到達後に追認 → 116条本文類推 → 縁組は遡及的に有効（本人意思の尊重）。
  3. 第三者の反論の処理：第三者が「追認前から嫡出子＝ただし書類推で保護」と反論 → 身分行為の本質に反し、ただし書（取引安全）の類推は否定。
  4. 結論：縁組は追認で遡及的に有効・第三者はただし書で保護されない → 縁組無効確認の請求は認められない。
