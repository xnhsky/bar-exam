1周目のやり方 ― この問題を「解こう」としないでください

初見の事例は、考えても答えが出てきません。出てこないのは実力不足ではなく、まだ型（何を・どの順で書くか）を持っていないからです。ここで粘るのが時間を溶かす最大の原因になります。1周目の仕事は答えを出すことではなく、型を写して自分の中に置くことです。

やること（この順に）
  1. 問題文を読み、登場人物と「引っかかる行為」だけ書き出す（5分）。
  2. 解法ナビを上から順に。各ステップでまず自分で一つ出し、すぐ「▶自分で答えてから開く」を開いて答え合わせ。詰まったら5分粘らずに開く。
  3. 骨子（答案構成）まで来たら、見出しと結論の一行だけ紙に写す。
  4. 照合欄で自己採点 → 最後に模範答案を開き、書き方の差だけ見る。
やらないこと：全文起案（答案を最後まで書く）／深掘り層を最初から読む／わからない論点を10分以上考え込む。どれも1周目には早すぎます。
ゴール：この問題で「何を、どの順で書くか」が言えること。知識の完全な理解ではありません。理解は2周目以降に回数で入ります。

目安 25〜35分／終えたら日付をメモし、数日〜2週間あけて2周目へ。

2周目のやり方 ― 今度は解きます。ただし「答案構成まで」

ここからが本当の周回です。読み直すのではなく思い出す。ただし全文は書きません。合否を分けるのは論点の抜け漏れと規範を言えるかで、その2つは答案構成までで判定できるからです。この画面では作法・下書き・ページ内ドリルを隠しています（1周目で済んだ作業です）。

やること（この順に）
  1. 問題文を読み、5分で論点の見出しだけ紙に挙げる（規範やあてはめはまだ書かない）。
  2. 骨子（穴埋めパズル）で、順序と結論を自分で組み立てる。
  3. 照合欄で自己採点。ここで取れた論点は終了＝解説は読み返さない。
  4. 外した論点だけ、その手（▶）か深掘り層へ降りて確認する。
やらないこと：頭から全部読み直す／取れた論点の解説を「念のため」読む／全文起案。時間はここで溶けます。
ゴール：論点の抜け漏れゼロ＋各論点の規範を口で言えること。外した論点は復習カードに任せ、この問題自体は次へ進みます。

目安 10〜15分／初めて見る問題は「1周目」に戻してください（隠れている部分が必要です）。

この場合において、Dは、Cに対し、甲土地の所有権に基づいて、甲土地の明渡しを求めることができるかを論ぜよ。

A｜甲土地の真の所有者（→仮装売買・のち急死） B｜Aの息子・仮装名義人（→乙建物建築、C・Dに処分、Aを単独相続） C｜乙建物買主・借地人（悪意） D｜甲土地買主（善意無過失）＝請求者

SCANSTEP 1
当事者と「請求 → 反論」の構造を棚卸し

登場人物を全員書き出し、各人が甲土地について取得した地位（所有・登記・善意悪意・賃借・相続）を時系列で拾う。誰が誰に何を請求しているかを一言で言い切る。

自分で答えてから開くまず1つ

本問の問いは D → C への甲土地明渡請求。法的性質は所有権に基づく返還請求（物権的請求権）。まずここを固定する。

争いの軸は D（善意無過失の甲土地買主）の所有権 ⇔ C（悪意の借地人）の賃借権。A（真の所有者・急死）とB（仮装名義人・Aを相続）の動きが、この優劣を左右する。

所有権に基づく返還請求（明渡請求）が認められるためには、請求者がその目的物を所有し、かつ相手方がこれを占有していることを要する。

○物権的請求権としての返還請求は「請求者の所有」と「相手方の占有」を要件とする。だからまず請求者が確定的に所有権を取得しているかを固め、次に相手方の占有を正当化する権原（賃借権等）の抗弁を検討する、という順で流れる。
AIMSTEP 2
各主張に「何条っぽい？」のGUESSをする

手がかりは2つ。①キーワード（「仮装」「善意無過失」「他人物」「相続」）／②誰の利益を守る話か。条文の細部は後でよい、まず当たりを付ける。

💡 GUESSの立て方

「仮装」＝通謀虚偽表示（94条）系。Dの「善意無過失」＝94条2項の善意の第三者。Bが処分権限なく貸した＝他人物賃貸借（559条・561条）系。「BがAを相続」＝処分権限の追完（116条類推）系。

相手方と通じてした虚偽の意思表示は無効であるが（民法94条1項）、その無効は善意の第三者に対抗することができない（同条2項）。

○94条1項は真意を伴わない仮装表示に効力を認めず、名義人を無権利者とする。もっとも同条2項は、虚偽の外観を作った者の帰責性を根拠に、外観を信頼した善意の第三者を保護する（権利外観法理）。「1項で無効・名義人無権利 → 2項で第三者保護」という二段構えで使う。
ORDERSTEP 3
攻める順番を決める（論理の川上から川下へ）

物権的請求権は請求原因 → 抗弁 → 再抗弁と論理が一方向に流れる。本問は ①Dの所有権取得 → ②Cの賃借権の抗弁 → ③相続による追完 → ④ただし書によるDへの対抗の限界。

💡 順番のコツ

先にDの所有権を固めないと、Cの賃借権が誰に対する抗弁なのかが定まらない。本問の山場（配点の重心）は③④の相続の追完とその限界。ここに紙幅を残すため、①②は簡潔に通す。

94条2項により保護される「善意の第三者」は善意であることを要するから、虚偽表示が仮装であることを知っていた悪意の者は、同項による保護を受けない。

○94条2項の保護は「善意」の第三者に限られる。Dは善意無過失だから保護され所有権を取得するが、Cは仮装を知って賃借した悪意者だから同項の保護を受けず、賃借権を独立して対抗できる根拠にはならない。この善意悪意の差が、DとCの明暗を分ける第一の分岐。
MARCHSTEP 4
物権的請求権の型で流す ― チェックポイント＝論点

請求を要件で流す：D所有（→94条2項）→ C占有（乙建物を通じ甲土地を占有＝争いなし）。次に Cの抗弁（賃借権）を流す。流していて素直に進めない所が論点。

💡 素直に通す（各一文）

C占有＝乙建物所有により甲土地を占有＝争いなし／Dの登記具備＝問題文に明記＝争いなし。引っかかるのは「Dが94条2項で所有権を取得するか」と「Cの他人物賃借権が相続でどうなるか」の2点。それ以外は一言で通す。

「チェックポイント」を自分で挙げてから開く3つ

CP①：AB売買は「仮装」＝通謀虚偽表示で無効 → Bは無権利者 → Dは無権利者からの譲受人 → 94条2項「善意の第三者」該当性。（新たに独立の法律上の利害関係に入ったか）

CP②：BC賃貸借は締結時Bに処分権限なし → 他人物賃貸借の性質決定（債権契約は有効だが対抗力ある賃借権は生じない）。

CP③：BがA（真の所有者）を相続 → 相続による処分権限の追完（116条本文類推）／その遡及効はDに及ぶか（ただし書類推）。

他人の物を目的とする賃貸借（他人物賃貸借）は、賃貸人が目的物の処分権限を有しないから、債権契約としても無効である。

×他人物売買が有効であること（561条＝売主は権利を取得して移転する義務を負う）の準用（559条）により、他人物賃貸借も債権契約としては有効。もっとも賃貸人に処分権限がない以上、賃借人は所有者に対抗しうる賃借権を当然には取得しない。「有効だが対抗力なし」がスタート地点で、ここを「無効」と誤ると議論全体が崩れる。

【想起】民法94条2項にいう「第三者」の意義（規範）と、その主観的要件・登記の要否を述べよ。

「第三者」とは、虚偽表示の当事者及びその包括承継人以外の者で、虚偽表示に基づき新たに独立の法律上の利害関係を有するに至った者をいう。主観的要件は条文どおり善意で足り、無過失は不要（判例）。判例は登記を備えなくても保護されるとする（真の権利者との対抗問題ではなく外観信頼保護だから）。仮装名義人からの譲受人はその典型。

【想起】無権利者が他人の権利を処分した後に権利者がこれを追認した場合の効力について、判例（最判昭37.8.10）の採る処理を述べよ。

無権利者による他人の権利の処分を、真の権利者が後日追認したときは、無権代理行為の追認に関する民法116条の類推適用により、処分の時に遡ってその効力を生ずる（最判昭37.8.10）。代理権の欠缺と処分権限の欠缺を同視した法理で、本問の相続による処分権限追完の理論的基盤となる。
BREAKSTEP 5
本丸を「4点セット」で割る ― 相続の追完とその限界

各論点を ①問題の所在 → ②規範（名前でよい）→ ③あてはめ（効く事実）→ ④結論 で。本丸は相続による処分権限の追完（116条本文類推）とただし書によるDへの対抗の限界。規範の中身は深掘り層へ。効く事実＝時的先後を掴むのが勝負。

✓ 本問で効く事実

追完 → BがA（真の所有者）を単独相続＝処分の追認と同視／限界 → Dの登記取得（H21.10.9）は相続（A死亡H21.12.16）より前／信頼 → Dは仮装につき善意無過失。時的先後は必ず評価語（「相続前に既に対抗要件を備えた第三者」）と結合させる。

【想起】他人物賃貸人が賃貸借後に目的物の所有者を相続した場合に、処分権限が追完され賃貸借が完全な効力を生ずるとする理論構成（本問採用説）を述べよ。

地位併存説＋信義則：他人物貸主の地位と所有者本人の地位は相続により当然には融合せず併存する。もっとも、相続した貸主が追認を拒絶することは矛盾挙動で信義則（1条2項）上許されない。結局、最判昭37.8.10の趣旨（無権利処分の追認＝116条類推）により、賃貸借は契約時に遡って完全な効力を生ずる（116条本文類推）。

116条本文の類推適用により処分権限が追完されて遡及効が生じると、その遡及効は、追認（相続）より前に目的物について利害関係を取得し対抗要件を備えていた第三者の権利をも覆滅させる。

×116条ただし書は「追認は第三者の権利を害することができない」とし、遡及効を制限する。したがって追認（相続）前に既に権利を取得し対抗要件を備えた第三者は、遡及効によって害されない。本問では、相続前に所有権・登記を備えたDには、追完された賃借権を対抗できない（ただし書類推）。本文だけで止めると結論を誤る。
BREAKSTEP 5′ C側
Cの賃借権を素早く ―「対抗力」の一点

BC賃貸借は他人物賃貸借（債権契約は有効・当初は対抗力なし）→ 相続で追完 → 追完後は借地借家法10条1項で対抗力を得るのが原則。チェックポイントは その対抗力がDに及ぶかの一点。

§ 規範（借地借家法10条1項）で一文

建物所有目的の借地権は、借地権者名義の登記ある建物を土地上に所有すれば、賃借権の登記がなくても第三者に対抗できる → Cは自己名義の乙建物登記あり＝原則は対抗可。もっとも追完の遡及効はDに及ばない（116条ただし書類推）から、Dには対抗できない。

建物の所有を目的とする土地賃借権は、その賃借権自体の登記がなくても、借地権者が土地上に自己名義で登記した建物を所有するときは、これをもって第三者に対抗することができる（借地借家法10条1項）。

○借地借家法10条1項は、賃借権登記に代わる対抗要件として「借地権者名義の建物登記」を認める（借地人保護）。Cは甲土地上に自己名義の乙建物登記を有するから、賃借権が有効に存在すれば原則として第三者に対抗できる。ただし本問はその賃借権の遡及的有効がDに及ばない点で対抗を否定される。

他人物賃貸借であっても、賃借人は賃貸借契約の成立により、当然に目的物の所有者に対抗しうる賃借権を取得する。

×他人物賃貸借は債権契約として有効だが、賃貸人に処分権限がない以上、賃借人は所有者に対抗しうる賃借権を当然には取得しない。本問でCが対抗力を得るのは、あくまでBがAを相続して処分権限が追完された結果であって、賃貸借の成立それ自体からではない。
BRIDGESTEP 6
横断 ― 相続の方向と権利濫用に一言だけ橋を架ける

結論が出たら最後に横断視点を一言。①相続の方向（逆に所有者本人が他人物貸主を相続する場合との均衡＝地位融合ではなく併存＋信義則で捌く理由）／②権利濫用（1条3項）への言及。深入りせず一段落で切る。

💡 打足の橋

本問は結論（Dの請求認容）が出た後、Dの明渡請求が権利濫用にならないかを一言だけ添えて締める。土地1000万／建物700万の価格差からDが乙建物の存在を認識して取得したと評価しうる特段の事情があれば濫用の余地があるが、本問ではそこまでの事情はなく結論は動かさない。一般条項は多用せず要所で。

他人物賃貸人が目的物の所有者を相続して賃借権が遡及的に有効となっても、相続より前に目的物の所有権とその対抗要件を取得していた第三者に対しては、その賃借権を対抗することができない。

○116条ただし書の法意（追認の遡及効は第三者を害し得ない）を類推し、相続前に対抗要件を備えた第三者を保護する。本問のDは相続前に所有権・登記を備えた善意無過失の第三者だから、追完された賃借権はDに対抗できない＝これが結論（Dの明渡請求認容）の決め手。

第1　Dの明渡請求と甲土地所有権の取得

1DのCに対する甲土地明渡請求は、所有権に基づく返還請求（明渡請求）である。これが認められるには、まずDが甲土地の所有権を有することを要する。

2(1)AB間の売買は、Aが差押えを免れるためにBと通じてした仮装の売買であるから、通謀虚偽表示として無効である（94条1項）。したがって、Bは甲土地の所有権を取得しておらず、無権利者Bから甲土地を譲り受けたDも、原則として所有権を取得し得ない。

(2)もっとも、94条2項の「第三者」とは、虚偽表示に基づき新たに独立の法律上の利害関係を有するに至った者をいい、その主観的要件は文言どおり善意であれば足りると解する（権利外観法理）。

(3)Dは仮装名義人Bから甲土地を買い受け、D名義の移転登記を備えた者であるから、これに当たる。そして、DはAB間の売買が仮装であることを知らず、これを知らないことに過失もなかったから、善意（かつ無過失）である。

3よって、Dは94条2項の善意の第三者として、甲土地の所有権を取得する。

第2　Cの賃借権の抗弁

1これに対し、Cは甲土地の賃借権をもってDの明渡請求に対抗することが考えられる。

2もっとも、BがCと賃貸借を締結した時点では、Bは甲土地について何ら処分権限を有していなかった。したがって、BC間の賃貸借は他人物賃貸借である（559条本文・561条準用）。他人物賃貸借は債権契約としては有効であるが、賃貸人に処分権限がない以上、賃借人は所有者に対抗し得る賃借権を取得することはできない。

3また、Cは賃貸借の締結に際してAB間の売買が仮装であることを知っていたから、94条2項の善意の第三者にも当たらず、同項によって甲土地の賃借権を取得することもない。

第3　相続による処分権限の追完

1もっとも、その後、甲土地の真の所有者であったAが死亡し、Bが唯一の相続人としてAの一切の権利義務を相続した。

2無権利者が他人の権利を処分した場合でも、権利者が後にこれを追認すれば、無権代理行為の追認に関する116条の類推適用により、処分の時に遡ってその効力を生ずる（最判昭37.8.10）。他人物貸主が相続により所有者の地位を承継した場合も、同様に116条本文類推により処分権限が追完されると解すべきである。しかも、相続した貸主が追認を拒絶することは矛盾挙動であって信義則（1条2項）上許されない。したがって、BC間の賃貸借は、契約時に遡って処分権限ある者による契約として完全な効力を生ずる。

3そして、BC間の賃貸借は建物の所有を目的とするものであり、Cは甲土地上に自己名義の登記のある乙建物を所有している。したがって、Cは賃借権の登記がなくても、借地借家法10条1項により賃借権を第三者に対抗し得るのが原則である。

第4　Dとの関係（遡及効の制限）

1しかし、116条ただし書は、追認の遡及効が第三者の権利を害し得ないことを定める。

2Dは、Aが死亡してBがこれを相続するより前に、既に甲土地の所有権を取得し、その旨の登記を備えていた。相続という偶然の事情によってDが賃借権の負担を負わされ、甲土地の使用収益を妨げられるのは不当である。DはAB間の仮装につき善意無過失であり、その信頼は保護に値する。そこで、116条ただし書の法意に照らし、Bの相続によってCが取得する賃借権は、相続前から甲土地につき対抗要件を備えていたDに対しては、これを対抗することができないと解する。
