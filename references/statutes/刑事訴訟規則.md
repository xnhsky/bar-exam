# 刑事訴訟規則 条文インデックス（コーパス自動生成）

`scripts/build-statute-index.py --write` が outputs の 📚BASIS 条文カードから
抽出した引用本文の索引。**一次資料ではない**（e-Gov に到達できない環境で、
執筆・監査のときに条文本文を手元で引くための作業用）。引用の食い違いは
同スクリプトの `--check` が検出する。

**帰属のノイズが残る**：カードの見出しが条を明示しない場合や、法令名を書かずに
他法令（警察法・犯罪捜査規範等）を引く場合、条・法域の推定を誤ることがある。
各行の末尾に出典ファイルを付けてあるので、疑わしい行は必ず出典で裏を取る。

- **196条**　裁判長は、検察官の起訴状の朗読に先だち、被告人に対し、その人違いでないことを確めるに足りる事項を問わなければならない。　`刑訴TX193_lex.html` ほか2件
