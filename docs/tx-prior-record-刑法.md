## 2-bis. シート外の 264〜300（移行前ぶん・× 補完）

ユーザー申告（2026-08-17）：「300 くらいから Lexia へ移行しているので、このファイルに無い
ところから 300 くらいまでは × を適用して」。

| 項目 | 値 |
|---|---|
| 範囲 | **264〜300（37 件）・全て ×** |
| 完了日 | シートに記録が無いため、**記録が途切れる直前の最終記録日 2026-04-17 で補完**（SM-2 上は期日超過＝ × の扱いはシート実記録と同じ） |
| 301 以降 | **対象外**（Lexia 側に実記録があるため。仮にこの範囲へ Lexia の記録があっても「学習済みは触らない」ガードが優先される） |
| HTML の有無 | 264〜300 は公式・`_lex` とも 37 件すべて存在（確認済み） |

CSV（`docs/data/tx-prior-record-刑法.csv`）は**シート原本の忠実な写し**なので、この 37 件は
空欄のままにしてある。補完ぶんは Lexia 側のデータセットで `TX_PRIOR_RECORD_PRE_LEXIA` として
シート実記録（`TX_PRIOR_RECORD_SHEET`）と別配列に分けて持つ＝出所が後から追える。

したがって Lexia へ取り込む総数は **300 件（× 245 / △ 55）**。

## 3. Lexia への適用（別リポジトリ）

適用先は Lexia（github.com/xnhsky/lexia）。bar-exam 側は**原本の保管だけ**で、
HTML 生成物には一切手を入れていない。

| 項目 | 決定 |
|---|---|
| 評価 → SM-2 quality | `×`=1 / `△`=3 / `○`=4 / `◎`=5（Lexia の 4 段階評価バッジと同じ語彙） |
| 取り込み総数 | **300 件**（シート実記録 1〜263 ＋ 移行前補完 264〜300） |
| 反映範囲 | 履歴（5周進捗バー・正答率・弱点統計）＋ **SM-2 の復習スケジュールも再計算** |
| 基準時刻 | 現在時刻ではなく**シートの完了日**。× は完了日 +10 分、△ は +10 日＝いずれも期日超過となり復習キューに乗る |
| 既存の学習記録 | Lexia 上ですでに学習済みの問題は**触らない**（実データを正とする） |
| 実装 | `src/data/txPriorRecord.js`（データ）／`src/lib/priorRecord.js`（純ロジック）／`App.jsx` の起動時マイグレーション。詳細は Lexia の `docs/patches/LXA_FEAT_015_TX_PRIOR_RECORD_IMPORT.md` |
