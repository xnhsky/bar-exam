# 刑訴TX101〜120_lex の GIST 外に残る旧法記述・誤りの一覧（THE GIST ストーリー型展開時の副次発見）

2026-09-17、THE GIST をストーリー型（§v14）へ展開した際に、各ファイルの執筆エージェントと独立校閲エージェントが
e-Gov 法令 API（刑事訴訟法・令和8年8月13日施行版）ほかで照合して見つけた、**THE GIST 以外の箇所**の問題の一覧。
THE GIST 側は現行法で書いたが、同じカードの BASIS・段階解説・✍答案圧縮・体系マップ・記憶のフック等は未修正のため、
カード内で項番号や説明が食い違っている箇所がある。**一次資料での再確認のうえ是正すること**（エージェント報告のため誤報を含みうる）。

共通の背景：令和7年法律第39号（刑事手続のIT化）の一部が 2026-05-21 に施行され、記録命令付差押え→電磁的記録提供命令、
218条の項の繰り下がり（令状不要の特則＝旧3項→4項、身体検査の条件＝旧6項→9項。2027-03-31 施行分でさらに10項）、
179条1項・429条1項2号・113条1項・142条・222条1項・321条1項1号括弧書き などの文言変更が生じている。
是正時の注意：✍答案圧縮はカードと正誤表 data-brief-mark の同一文を維持（G73）／判旨の逐語引用は判例原文の項番号のまま（注記で現行へ対応）／
改行様式はバイト単位で保持。見本の是正＝コミット e4542e3f（刑訴TX100 の218条）。
