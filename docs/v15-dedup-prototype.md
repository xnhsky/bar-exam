## 1. 動機（実機指摘 2026-09-22）

- ⚠️間違いやすいポイントが「解説の言い換え」か「解答技術（記述1・5は素直に○）」で、試験で効く隣接命題
  （証人は勾引できるが鑑定人は替えが利くので勾引できない 等）が無かった。
- 同一命題「228条1項→152条準用→更に召喚・勾引できる」がカード1枚＋正誤表1行で約20回出ていた
  （判定・GIST冒頭・GIST判定・条文操作末尾・POINT・BASIS帰結×2・BASIS直後段落・原文帯・ものがたり・転用・図解）。
- 🗝記憶のフック＝GIST🖼イメージが逐語一致（§v14 が「同じ像」と定義したため構造的に二重）。
- 初見の問題は正誤表でなく下の解説を読む使い方なので、図解・比較表はカード側にも要る。
- 解法ナビ副題「226条の対象者（被害者も対象）・227条の圧迫要件削除・228条の立会い（裁量）」が解答前に
  正解を先出し（G19 はリテラル型しか見ず素通り）。

## 2. 試作で入れた構成（1事実1置き場）

| ブロック | 処遇 |
|---|---|
| ✓判定＋📜記述原文＋✍答案圧縮 | 結論を述べる唯一の面（不変） |
| 💡THE GIST | 場面→問題→条文→理由→キーワード は不変。**🖼イメージ面を削除**（フックと同一像）。**判定面は1行**（どの語が合う／ずれるか） |
| 条文操作①② | 末尾の「よって本記述は正しい／誤り」を削除（沿革など固有情報だけ残す） |
| 🗝記憶のフック | **一行・対比圧縮型**（「証人は引っ張れる、鑑定人は替えが利く」） |
| 📌POINT | **廃止**（答案圧縮＋条文操作の圧縮版で全文重複）。G50 の必須要件を任意化 |
| 📚BASIS | 条文本文・要件・趣旨・沿革は不変。**「本問への帰結」kd-item と直後の段落を削除**（記述N参照も消える） |
| ⚠️間違いやすいポイント | **「1語差し替えで裏返る」型**＝隣接命題を1〜2文＋**📐比較表**（`.tx-dgm.is-matrix`・div グリッド・最大4×4） |
| 正誤表 転用行 | 解答技術（「先入観で否定しない」）→ 次の問題へ持ち出す規範に置換 |
| 正誤表 図解帯 | **カードの比較表を単一情報源**にして同一複製（`data-dgm` 同 id） |
| 正誤表 ものがたり帯 | §v13w の3枚（CONTEXT／IN PRACTICE／CASE FILE）へ書き直し。刑訴は実名事件（ロッキード事件で1問貫通） |
| 物語 | 5,900字→約1,100字。骨格（誰が請求・誰が実施）＋**3ルート比較表**だけにし、各記述の結論を再掲しない |
| 解法ナビ副題 | 「見る条文は 226条・227条・179条・228条・152条。」だけに（帰結語を全廃） |

字数（空白除く）：カード 2,400〜2,800字 → 1,800〜2,400字（BASIS の折りたたみ内を含む）。物語 5,861→1,070字。

## 3. 比較表（TX-DGM-MATRIX）の契約

- 置き場：カードの ⚠️罠枠の中（本文 span の直後）。正誤表の行の `.tx-vb-dgm-src` には同一複製。
- 形：`<div class="tx-dgm is-matrix" data-dgm="NNN-0k">` ＋ `<div class="tx-dgm-matrix is-c3|is-c4">` ＋
  `<p class="dgm-cell is-head|is-rowhead|is-ok|is-ng|is-acc|is-flat">`。**`<table>` は使わない**
  （G33 と Lexia の行複製が `tr`／最終 `td` を走査するため入れ子表は両方を壊す・実測済み）。
- 2型：①「こう変えると／答え／根拠」（記述の1語を差し替えた隣接命題）②「主体×措置」（証人／被告人／鑑定人 × 召喚／勾引／過料）。
- セルは短語＋`dgm-src` 条文チップ。偽表の禁止（効く記述だけ・同一ファイル内の同型は置かない）。
- CSS＝`GENESIS-CARD.html` TX-DGM 区画末尾の `TX-DGM-MATRIX`（本コミットで正典に追加済み・他ファイルは
  `tx-lex-css-canonize.py --apply` で配布）。許可クラスは validate G67／`tx-dgm-insert.py` に追加済み。

## 4. 承認後にやること（正典昇格）

1. `GENESIS-CARD.html`／`GENESIS-CARD.placeholder.html`：POINT・GIST イメージ面・BASIS 帰結を外し、罠枠を
   1語差し替え型＋比較表に。`tx-gist-story.py` の面定義（イメージ任意・判定1行）を追従。
2. G67 の同期規則を「物語⇄カード両置き」から「**カード＝単一情報源・正誤表へ複製・物語は任意**」へ
   （試作は片側警告 WARNING が出る＝仕様どおりの残置）。
3. 新 WARNING ゲート：カード内の同一文（30字以上の部分文字列の再出）／カード字数上限／罠枠の解答技術語
   （記述N・素直に・疑いすぎ・組合せ問題・思い込みの罠）／解法ナビ副題の帰結語（削除・裁量・も対象・できる）。
   `trap_depth_flag` の 105 字上限を撤廃。
4. 既存展開：土台（POINT 削除・帰結削除・条文操作末尾の結論文削除・図解のカード側複製）は決定論ツール、
   罠比較表・フック・ものがたり帯・転用行の執筆は TJR 付随（Opus 5・10本/バッチ）で消化。
5. Lexia 側：復習プールのカードは正誤表の行を複製するが `.tx-vb-dgm-src` を描いていない（hidden のまま）。
   `data-brief-story` と同じ要領で図解帯を復元すると、プールでも比較表が出る（LXA 側の別件）。
