# §v13q 付随改訂（TJR-Q 特別枠・headless）

あなたは bar-exam リポジトリの TX `_lex` 1ファイルを §v13q（✍答案圧縮＋GIST自己完結＋訂正チップ最小化＋#basis空箱禁止）へ改訂する執筆者である。作業ディレクトリはリポジトリルート。
**対象ファイル：`{FILE}`**

**git の add/commit/push は絶対にしない**（commit はランナーが行う。復旧用の `git checkout -- {FILE}` のみ可）。対象ファイル以外を編集しない。対象 HTML を直接 Edit しない（注入は必ずツール経由）。

## 手順

1. 素材抽出：`python scripts/v13q-extract.py {FILE}`
   （answer-key・各記述の問題文/判定/記述原文raw/現GIST/path/BASIS/フック・正誤表 brief-mark・#basis 状態が出る）
2. **全記述分を執筆**（この執筆が本務。1文1文丁寧に）：
   - **anscomp（答案圧縮・必須）**：正しい規範の完全文を答案調1〜2文＋（条文・判例）で書く。
     - 典拠は**そのファイルの path/BASIS/現GIST に書いてある条文・判例だけ**。新しい判例引用を発明しない。年月日・表記はファイル内のまま使う。
     - `<strong>` は1〜2語まで。**半角二重引用符 `"` は使用禁止**（鉤括弧「」を使う）。
     - ×記述＝正しい規範そのものを書く（「本記述は誤り」等のメタ文は書かない）。○記述＝記述の規範を答案調に整える。
   - **gist（GIST 差し替え・必須）**：構成＝「**○。/×。**（結論先出し）→ 体系的位置づけ（何罪・どの論点か）→ 規範（専門用語は**用語サンドイッチ**＝直後に生活語で開く。核用語 `<strong>` 1〜2語のみ・用語スープ禁止）→ 理由（保護法益・趣旨から一言）→ **イメージは◯◯——**（その記述の🗝記憶のフックと同系の例え）→ 本記述の当否（〜誤り＝×。／〜正しい＝○。で締める）」。250〜350字。
     - **締めの○×は answer-key と必ず一致**させる（最重要）。
     - 既存 `a.ref-stat` アンカー（id/href）は新 GIST 内に温存して相互リンク（G53）を切らない。
     - 「本問」「記述ア」「①」「A説」等の**問題ローカル記号・記述キーへの言及は禁止**（G32）。禁止句（「絞り込」等・G21）に注意。
   - **fix（訂正チップ最小化）**：×記述の `.tx-stmt-fix` が長文（目安25字超・判例引用入り）なら、最小訂正（判例名は書かない）に。既に短い／○記述／チップが無い・複数ある場合は null。
3. payload JSON を一時ファイル（例 `/tmp/p_{番号}.json` または `%TEMP%`）に書く：
   `{"hide_basis": <extract が「#basis: 空箱(可視)」なら true・それ以外 false>, "stmts": [{"n": "1", "anscomp": "…", "gist": "…", "fix": "→ …" または null}, …全記述分]}`
   - `n` は extract に出た記述キーそのまま（ア〜オ／1〜6 など）。
4. 注入：`python scripts/v13q-inject.py {FILE} <payload>`。assert で落ちたら payload を直して再実行。
5. ゲート：`python scripts/validate-tx-core.py {FILE}`（**ERROR 0 必須**）→ `python scripts/check-tx-lex-engine.py {FILE}`（**PASS 必須**）。
   ERROR が出たら：`git checkout -- {FILE}` で戻し、payload を修正して再注入→再ゲート（最大3回）。
6. 自己照合を1回：①GIST 締めの○×＝answer-key と一致 ②anscomp の条文番号・判例年月日がファイル内記載と一致 ③記号フリー ④anscomp に `"` が無い。
7. 両ゲート PASS を確認したら、最終行に **`V13Q_DONE {FILE}`** とだけ出力して終了する（PASS できなかった場合は `V13Q_FAIL 理由` を出力し、対象ファイルを `git checkout -- {FILE}` で必ず元に戻してから終了する）。

## 品質見本（gold・刑TX425/426 で確定した形）

- anscomp（×記述の例）：
  `収賄罪（刑法197条1項）にいう「職務」とは、当該公務員の<strong>一般的職務権限</strong>に属する事務であれば足り、本人が現に具体的に担当している事務であることを要しない（最判昭37.5.29）。`
- gist（全要素入りの例）：
  `×。収賄罪（刑法197条1項）は、公務員が「職務に関し」賄賂を受け取ると成立する。出発点は「職務」の広さで、判例は、<strong>一般的職務権限</strong>——その公務員が役所で本来任されている仕事の守備範囲——に属していれば「職務」にあたり、いま現に自分が担当している案件であることまでは要しないとする。担当外でも権限の範囲内なら、賄賂を受け取った時点で<strong>職務の公正に対する社会一般の信頼</strong>（公務はカネで動かないという信頼）が汚れるからだ。イメージは役所の引き出し——「職務」は今日机の上に開いているファイルだけでなく、自分の課の引き出しに入っている案件すべてに及ぶ。本記述は、判例が明示的に「要しない」と述べた「現に具体的に担当している事務であること」を必須条件に格上げし、処罰の網を判例より狭めているので誤り＝×。`
- fix 最小化の例：`→ 判例は一般的職務権限に属すれば足り、…（最判昭37.5.29）` → `→ 要しない（一般的職務権限に属すれば足りる）`
